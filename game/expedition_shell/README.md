# Expedition shell — 첫 단계

기존 전투·HEXACO·시뮬레이션을 연결하기 전에 방 하나와 3인 파티를 표시하는 독립 화면.

## 실행

- Godot에서 `game/expedition_shell/main.tscn`을 직접 실행.
- 프로젝트 실행 인자: `-- --expedition-shell`
- 이 변경이 포함된 웹 빌드: URL에 `?demo=expedition` 추가.

기본 게임 진입 경로는 유지한다. 기존 `game/rebuilt`와도 별개다.

## 이번 단계

- 8×8 고정 방, 후면 벽과 기둥 하나.
- `handcrafted_tile_assets.gd`의 실제 64×32 투명 다이아몬드 바닥을 2:1 비율로 표시.
- 기존 DCSS 캐릭터 이미지로 인간·엘프·드워프 3명 표시.
- 뒤에서 앞으로 벽·캐릭터 정렬, 선택 표시, 클릭/터치 칸 좌표 변환.
- 화면 크기에 맞춰 보드 확대·축소, 하단 파티 선택.

`main.gd`는 화면 구성과 선택 UI, `room_view.gd`는 투영·그리기·입력만 담당한다. 기존 PartyPlaytestSession, sandbox, 전투 및 월드 상태에 접근하지 않는다. 타일 아트 도우미만 재사용한다.

이동·전투·HP·HEXACO·원정 진행·저장은 아직 연결하지 않았다. 캐릭터와 방은 표시용 고정 데이터다. 다음 단계는 보드가 소비할 표시 데이터와 기존 전투 엔진의 명령/사건 인터페이스 정의다.

## 확인 범위

Godot 실행 검증은 사용자 요청에 따라 생략했다. 변경 파일 공백 검사, 참조 파일 존재 여부, 360×800/450×800/800×600 크기에서 64개 칸 중심의 투영→역변환 수학 검사를 수행했다. 실제 렌더링·터치 동작은 미확인이다. 웹 진입은 이 코드로 빌드한 뒤 사용할 수 있다.
