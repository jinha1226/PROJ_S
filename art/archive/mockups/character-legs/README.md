## 사용 프롬프트

Use case: precise-object-edit / character design comparison mockup. Make ONE clean horizontal comparison board for a simple fantasy game character using the reference sprite. Preserve its exact recognizable brown round hair, blank peach face with NO facial features, thick dark rounded outlines, plain gray sleeveless tunic and small tan shoulders. This is intentionally minimal, not detailed fantasy illustration. Three evenly spaced columns against a flat muted slate gray background. Left column: faithfully show original legless pawn silhouette as the baseline. Middle column: same head and torso with ONLY two small separated brown boot feet protruding below hem; practically no visible shins. Right column: same head and torso plus two clearly separated SHORT legs with dark charcoal trousers and chunky brown boots, visible gap between legs, legs and boots together approximately 22 percent of full figure height. All heads at equal size and aligned, two added variants remain squat and compact, not tall humans. No weapons, no armor, no belts, no hands added, no facial features, no decorative texture, no shadows. Label the columns with only simple digits 1, 2, 3. Under each large character include an actual tiny duplicate approximately 36 pixels tall so game-size readability is visible. Preserve existing silhouette and color style as much as possible; the only intentional character change is legs/feet. This is a review mockup, not a sprite sheet to apply.
