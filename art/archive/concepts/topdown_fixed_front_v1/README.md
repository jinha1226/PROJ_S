# 고정 정면 탑다운 비주얼 방향 v1

이 폴더는 `concept1.png`, `concept2.png`의 작은 화면 가시성을 참고해 만든
아트 방향 목업이다. 생성 이미지는 최종 런타임 아틀라스가 아니라, 층별 재질과
캐릭터 비율·장비 레이어 규칙을 합의하기 위한 기준 이미지다.

## 확정 방향

- 맵 카메라는 직교 탑다운이고, 한 화면에 약 20×20 논리 칸을 보여 준다.
- 모바일 세로 화면은 18칸 폭을 기본으로 하며, 전투 가시성 검증은 18×18 필드를 사용한다.
- 이동 판정은 8방향이지만 캐릭터 이미지는 회전·반전하지 않는다.
- 모든 인간형은 화면을 향한 고정 정면 자세 하나만 사용한다.
- 모바일 캐릭터는 머리와 둥근 몸통만 사용하고 팔·손·다리·발을 생략한다.
- 머리 60%, 몸통 40% 비율과 굵은 외곽선으로 24~32px 표시 크기에서도 읽히게 한다.
- 종족은 미세 묘사가 아니라 체형, 귀, 머리 덩어리, 피부색의 큰 면으로 구분한다.
- 장비는 `머리 / 몸통 / 주손 / 보조손` 고정 앵커에 독립 레이어로 붙인다.
- 배경은 모듈형 타일로 제작하되 플레이 화면에 격자선과 타일 이음새를 노출하지 않는다.
- 환경보다 캐릭터, 적, 상호작용 물체의 명도와 채도를 한 단계 높인다.

현재 플레이어 선택 종족은 인간·엘프·드워프·오크·수인 5종이다. 고블린은
현재 콘텐츠의 NPC/적대 종족까지 같은 바디 규격으로 검토하기 위해 시트에 포함했다.

## 층별 타일 어휘

### 1층 — 침식된 변경 숲

`젖은 흙 / 이끼 낀 옛길 / 덤불 / 얕은 물 / 과수원 / 폐촌 석재 / 변경 관문 / 중계 유적`

기본색은 숯색·이끼색·탁한 청록·썩은 갈색이며, 횃불만 호박색, 고대 포탈만
청록 발광을 사용한다. 직사각형 방보다 열린 야외와 여러 갈래 길을 우선한다.

### 2층 — 잿빛 황무지와 함몰 주조장

`재 / 검은 슬래그 / 산화 철판 / 폐배수로 / 붕괴 고가로 / 감시 초소 / 주조장 잔해 / 함몰 용광로`

기본색은 재색·먹색·녹슨 갈색이며, 열원은 주황, 고대 설비만 청록 발광을
사용한다. 1층의 구조에 색만 바꾸지 않고 지형 실루엣과 재질 자체를 바꾼다.

## 목업 파일

- `01_floor1_eroded_border_forest_mockup.png`: 1층 20×20 시야 플레이 목표
- `02_floor2_ashen_foundry_mockup.png`: 2층 20×20 시야 플레이 목표
- `03_species_equipment_direction_sheet.png`: 종족 비율과 장비 앵커 방향
- `04_mobile_portrait_18wide_exploration_mockup.png`: 세로로 긴 18칸 폭 탐험 화면
- `05_mobile_portrait_18x18_combat_mockup.png`: 18×18 전투 가시성 기준 화면
- `06_mobile_current_ui_relayout_mockup.png`: 현재 기능 묶음을 유지한 450×800 UI 재배치안
- `07_mobile_time_header_strict_topview_mockup.png`: 중앙 남은 탐험 시간, 우측 빈 영역,
  수직 탑뷰 필드로 보정한 확정 레이아웃

세 번째 이미지는 생성기가 체크무늬를 실제 RGB 배경으로 합성했으므로 투명
런타임 소스로 자르면 안 된다. 최종 에셋은 항목별 RGBA 파일로 다시 만들고
동일 캔버스와 앵커를 검증해야 한다.

## 최종 에셋 제작 계약

- 원본 캔버스: 64×64 RGBA, 화면 표시 목표 24~32px
- 바디 기준 영역: 중앙 40~48px, 바닥 기준선과 중심점 전 종족 동일
- 모바일 바디: 머리+몸통 전용이며 팔다리 레이어와 걷기 프레임을 만들지 않는다.
- 종족 바디: 인간, 엘프, 드워프, 오크, 수인, 고블린 각각 한 장
- 방어구: 천, 가죽, 강철, 미스릴과 후드·투구를 바디와 분리
- 주손: 단검/검, 활, 철퇴, 손도끼, 창, 쇠뇌
- 보조손: 원형 방패, 버클러와 이후 추가 오프핸드
- 어떤 레이어도 방향별 파생본을 만들지 않으며 이동 중에도 같은 그림을 유지한다.

## 사용한 프롬프트 세트

1. `Floor 1 gameplay mockup`: 16:9 직교 탑다운, 약 20×20 시야, 열린 침식 숲,
   고정 정면 SD 파티, 8방향 이동 표식, 모듈 타일, 격자선·3D·방향별 그림 제외.
2. `Floor 2 gameplay mockup`: 같은 카메라와 캐릭터 규칙, 재 평원과 함몰 주조장,
   슬래그·철판·배수로·고가로, 주황 열원과 제한된 청록 고대 설비.
3. `Species and equipment sheet`: 투명 배경을 요청한 고정 정면 시트, 6종 바디,
   천·가죽·강철·미스릴 갑옷과 후드·투구, 검·활·철퇴·도끼·창·쇠뇌·방패,
   짧고 모인 팔다리와 공통 레이어 앵커.
4. `Mobile 18-wide exploration`: 세로형 18칸 폭 필드, 머리 60%+몸통 40% 토큰,
   팔다리 제거, 상단 파티 상태와 하단 아이콘 조작부, 8방향 대각 이동 표식.
5. `Mobile 18x18 combat`: 중앙 18×18 전투 필드와 별도 하단 조작부,
   한 칸당 하나의 고정 정면 토큰, 팔다리 없이 종족 외곽선과 굵은 장비 표식만 사용.
6. `Current UI relayout`: 현재 `VBox/HBox/GridContainer`로 구현 가능한 450×800 구성,
   상단 미니맵·상황 HUD, 4인 파티 스트립, 정사각형 18×18 필드, 2줄 사건 피드,
   3×3 방향패드, 2×3 행동 버튼, 하단 5개 탭을 평면 ASCII 프레임으로 배치.
7. `Time header + strict top view`: 6번 이미지를 편집해 좌측 미니맵은 유지하고,
   중앙을 `남은 탐험 시간 / 05:42 / B1 · 부식된 변경 숲`으로 교체했다. 우측
   기능은 만들지 않고 비웠으며, 필드의 모든 지형·사물은 측면이 보이지 않는
   90도 수직 탑뷰로 제한했다.

모든 프롬프트는 입력 이미지를 스타일·가시성 참고 자료로만 사용했으며,
원본 UI·제목·캐릭터를 복제하지 않도록 제한했다. 생성은 Codex 기본 이미지
생성 도구를 사용했다.
