# 판타지 폰 1차 에셋 원본

2026-09-16 · imagegen 스킬과 내장 image_gen으로 생성.

승인한 [단순한 판타지 폰 목업](../../../docs/mockups/fantasy-pawns/01-simple-fantasy-pawns.png)을 기준으로 만든 첫 시트다. 머리와 몸통, 굵은 외곽선, 작은 크기에서 구분되는 실루엣을 목표로 한다. 현재 게임의 에셋을 교체하지 않는다.

후속 작업: 사용자 승인으로 코드 배경 제거·자르기를 수행한 [게임용 에셋](../../fantasy_pawns_v1/README.md)을 별도 제작하고 메인 원정 화면에 연결했다. 아래 제약은 보존된 원본 시트에 대한 기록이다.

## 내용

| 시트 | 배치 | 구성 |
|---|---|---|
| [종족 베이스](species.png) | 3열 × 2행 | 인간, 엘프, 드워프 / 오크, 수인, 고블린 |
| [맵 타일](tiles.png) | 4열 × 4행 | 바닥 4종 / 벽 4종 / 닫힌 문, 열린 문, 내려가는 계단, 올라가는 계단 / 물, 나무 바닥, 잔해, 구덩이 |
| [아이템](items.png) | 4열 × 4행 | 검, 도끼, 활, 지팡이 / 방패, 투구, 갑옷, 반지 / 물약, 식량, 두루마리, 동전 / 불·냉기·물·전기 몬스터 부위 |

종족 베이스는 같은 회색 기본복을 입고 장비가 없는 정면 한 방향이다. 범용 인간형(`generic_humanoid`)은 인간 베이스 공유를 제안한다. 방향별 이미지·애니메이션·장비 레이어는 포함하지 않는다.

[크기 비교 페이지](preview.html)는 각 셀을 32·48·64px로 표시한다. 시트를 CSS로 균등 분할해서 보는 검토용 페이지이며 이미지 원본은 수정하지 않았다.

## 검증 결과와 적용 조건

- 종족: 1254 × 1254 RGB. **체크무늬가 그려진 불투명 배경**이다.
- 타일: 1254 × 1254 RGB. 불투명 타일 원본이다.
- 아이템: 1261 × 1247 RGB. **체크무늬가 그려진 불투명 배경**이다.
- 종족·아이템은 image_gen으로 배경 제거를 추가 요청했으나 결과에도 알파 채널이 없었다. 실패한 수정본 대신 첫 원본을 보존했다. 투명 스프라이트로 사용할 수 없다.
- 실제 적용 전 종족·아이템 배경 제거와 내부 구멍(반지·활 등)의 투명화가 필요하다.
- 타일은 셀 경계의 검은 선, 바닥 색상과 벽 연결을 검수해야 한다. 자동 연결 타일셋으로 검증하지 않았다.
- 셀 좌표는 의도한 배치만 기록했다. 이미지 크기가 격자 수로 나누어떨어지지 않으므로 개별 자르기 좌표와 여백·기준점 조정이 필요하다.
- 일부 그라데이션과 세부선이 남아 있다. 실제 크기에서 확인한 뒤 더 단순화할 수 있다.

위 조건 때문에 런타임 AtlasTexture와 콘텐츠 매핑은 만들지 않았다. 먼저 디자인과 작은 크기에서의 식별성을 검토하는 **에셋 제작 원본**이다.

## 재현 자료

- [manifest.json](manifest.json): 38개 항목 ID·행열, 원본 규격·색상 모드·SHA-256, 생성 파일명.
- [prompts.json](prompts.json): 시트별 생성 프롬프트, 스타일 참조 경로, 실패한 알파 수정 프롬프트.

검증 범위는 파일 열기, 규격·알파 검사, 항목 수와 ID 중복 검사, 참조 파일과 해시 확인이다. 게임에 적용하지 않았으므로 게임 실행 테스트는 수행하지 않았다.
