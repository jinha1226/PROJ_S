# Generation prompt set

All six source images were generated with the built-in image generation tool. The
common style request was original restrained dark-fantasy game art, broad readable
shapes, crisp rough edges, neutral material lighting, no UI, no text, no watermark,
and legibility after reduction to 24-48 pixels.

1. Seamless cracked charcoal flagstone floor, exact 90-degree vertical top-down,
   axis-aligned, surface only, no side faces or perspective.
2. Seamless ancient masonry wall-cap surface, exact 90-degree vertical top-down,
   axis-aligned, no vertical wall face or perspective.
3. Seamless ancient masonry wall-side material, flat orthographic front elevation,
   no camera tilt, floor, cap, corner, or perspective.
4. One closed battered wooden crate, exact 90-degree top-down, transparent alpha,
   no visible front or side faces.
5. One irregular dark-crimson blood-pool ground decal, exact 90-degree top-down,
   transparent alpha, no floor underneath.
6. One compact iron wall torch, flat orthographic front elevation, transparent
   alpha, no wall fragment, with only a tight amber flame halo.
