# 고정 정면 탑뷰 전신 캐릭터 v3

예시 컨셉아트 `assets/concepts/topdown_fixed_front_v1/03_species_equipment_direction_sheet.png`
첫 줄의 SD 전신 캐릭터를 실제 게임용 96×96 RGBA 에셋으로 분리한 버전이다.
머리와 몸통만 남긴 이전 v2와 달리 짧은 팔·다리와 양쪽 발까지 한 셀 안에
보존한다.

- `source/actors/concept_full_body_species_6x1.png`: 내장 이미지 생성 기능으로
  컨셉 시트 첫 줄만 투명 배경에 분리한 6종 원본
- `runtime/actors/base/*.png`: 인간·엘프·드워프·오크·수인·고블린 전신 베이스
- `review/five_species_base_96px.png`: 장비 없는 원본 크기 검수본
- `review/five_species_base_24px.png`: 장비 없는 줌아웃 모바일 가시성 검수본

게임에는 현재 플레이 가능 종족인 인간·엘프·드워프·오크·수인 5종을 적용한다.
고블린은 원본 보존용이며 현재 플레이어 종족 레지스트리에는 연결하지 않는다.
갑옷과 무기는 등록 상태만 유지하며 이번 가시성 확인에서는 합성하지 않는다.

## 최종 편집 프롬프트

제공된 종족·장비 컨셉 시트의 첫 줄에 있는 인간, 엘프, 드워프, 오크, 수인,
고블린 전신 캐릭터만 분리한다. 원본의 픽셀 아트, 비율, 의상, 색상, 외곽선,
정면 포즈와 얼굴을 유지한다. 머리부터 짧은 팔·다리와 양쪽 발까지 절대 자르지
않고, 동일한 기준선의 6열 가로 시트에 배치한다. 배경은 실제 알파 투명이며
갑옷·무기·그림자·바닥·체크무늬·텍스트는 넣지 않는다.

원본 분리에는 내장 `imagegen` 편집 기능을 사용했다. 런타임 파생본은 공통
96×96 캔버스와 기존 발 앵커에 맞춰 기계적으로 축소·정렬했다.
