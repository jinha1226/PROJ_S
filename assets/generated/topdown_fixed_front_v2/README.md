# 고정 정면 탑뷰 생성 에셋 v2

모바일 줌에서 캐릭터와 타일이 같은 비율로 확대되도록 정리한 96×96 RGBA
페이퍼돌 원본이다. v1보다 얼굴 영역을 줄이고 몸통을 넓고 길게 만들었다.

- `source/actors/species_armor_weapons_6x3_generated.png`: 내장 이미지 생성
  기능으로 만든 원본 출력
- `source/actors/species_armor_weapons_6x3_alpha.png`: 연결된 체크무늬 배경을
  실제 알파로 제거한 작업 원본
- `runtime/actors/base/*.png`: 인간·엘프·드워프·오크·수인 96×96 베이스
- `runtime/equipment/armor/*.png`: 새 몸통에 맞춘 방어구 레이어. 투구와 후드는
  이미 승인된 v1 레이어를 유지한다.
- `review/five_species_layered_24px.png`: 장비를 합성한 실제 24px 가시성 표본
- `review/zoom_scale_25_19_9.png`: 25칸·19칸·9칸 카메라에서 동일 캐릭터가
  타일 배율과 함께 커지는 크기 표본

얼굴에는 눈·코·입·표정을 넣지 않는다. 모든 레이어는 같은 96×96 캔버스와
하단 앵커를 사용하며, 방향 전환·3D·아이소메트릭 표현은 만들지 않는다.

## 최종 생성 프롬프트

정확한 6열×3행 픽셀 아트 시트를 유지한다. 1행은 인간, 엘프, 드워프,
오크, 수인, 빈 칸이고 머리는 작게, 몸통은 넓고 길게 하며 얼굴은 완전히
무표정·무이목구비로 만든다. 2행은 천, 가죽, 강철, 미스릴, 후드, 투구,
3행은 짧은 검, 손도끼, 철퇴, 창, 활, 쇠뇌다. 실제 투명 배경, 공통 앵커,
24~64px 축소 가시성을 유지하고 텍스트·격자선·팔다리·방향 파생본은 넣지
않는다.

원본은 내장 이미지 생성 기능으로 만들었다. 생성된 방어구는 베이스와 정밀
합성했을 때 목 위치가 맞지 않아 그대로 배포하지 않았고, 승인된 v1 방어구를
새 몸통 폭에 맞게 확대한 레이어를 최종 runtime으로 사용했다.
