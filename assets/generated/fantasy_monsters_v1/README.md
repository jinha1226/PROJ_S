# 판타지 몬스터 원본

2026-09-16. 내장 image_gen으로 생성. 기존 판타지 폰의 굵은 외곽선·큰 색면을 참조했다.

- [생성 원본](source/monsters.png): 1448×1086 RGB, 4열 × 3행, 흰 배경.
- [게임용 PNG](../../fantasy_pawns_v1/monsters): 코드로 배경 제거·분리·크기 조정한 128×128 RGBA.
- [크기 비교와 적용 기록](../../../docs/art/fantasy-monsters-v1/README.md).
- [생성 프롬프트](prompt.txt).

배치 순서는 화염도마뱀·서리거미·물슬라임·전기뱀장어 / 쥐·강쥐·목도리도마뱀·놀 / 홉고블린·코볼트·슬라임·딱정벌레다. 게임 ID는 런타임 `extraction.json`에 기록했다.

사용자가 앞서 승인한 코드 배경 제거·자르기 방식을 적용했다. 원본을 보존하고, `python3 tools/art/build_fantasy_monsters.py`로 재생성한다. 닫힌 외곽선을 활용하므로 다른 원본으로 교체하면 자르기와 알파 결과를 다시 확인해야 한다. 생성 결과에는 일부 단순한 명암과 표정이 남아 있다.
