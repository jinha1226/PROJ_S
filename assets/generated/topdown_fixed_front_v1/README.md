# 고정 정면 탑뷰 생성 에셋 v1

승인된 `18×18 모바일 필드 + 머리/몸통 고정 정면 토큰` 방향의 첫 제작
원본이다. 필드 카메라는 정확한 90도 수직 탑뷰이며 아이소메트릭 면을 쓰지 않는다.

## 디렉터리

- `source/terrain/floor1_corroded_border_forest_4x4.png`: 1층 숲 4×4 원본 시트
- `source/terrain/floor2_ashen_foundry_4x4.png`: 2층 주조소 4×4 원본 시트
- `source/actors/species_armor_weapons_6x3_alpha.png`: 종족·방어구·무기 합성 원본
- `runtime/actors/base/*.png`: 인간·엘프·드워프·오크·수인 96×96 RGBA 베이스
- `runtime/equipment/armor/*.png`: 천·가죽·강철·미스릴·후드·투구 96×96 RGBA
- `runtime/equipment/weapons/*.png`: 검·손도끼·철퇴·창·활·쇠뇌 96×96 RGBA
- `review/five_species_layered_24px.png`: 방어구·무기를 합성한 실제 24px 가시성 표본

`runtime` 캐릭터와 장비 파일은 같은 96×96 캔버스, 중심점, 몸통 기준선을
보존한다. 화면에서는 24~32px로 축소해 사용한다. 방향별 파생본과 팔다리
프레임은 만들지 않는다. 몸통 방어구는 얼굴 아래로, 무기는 몸통 오른쪽으로
재배치해 24px 합성 시 종족 얼굴을 가리지 않게 했다.

지형 시트는 생성 원본이다. 각 칸의 연결 규칙과 실제 타일 반복성을 검수한 뒤
잘라야 하며 아직 런타임 TileSet에 연결하지 않았다. 시트 경계가 확정되기 전에
자동 타일 규칙을 묶지 않는다.

## 시트 순서

캐릭터 시트는 6열×3행이다.

- 1행: 인간, 엘프, 드워프, 오크, 수인, 빈 칸
- 2행: 천, 가죽, 강철, 미스릴, 후드, 투구
- 3행: 짧은 검, 손도끼, 철퇴, 창, 활, 쇠뇌

지형 시트는 공통으로 `바닥 변형 → 통로 → 물/배수 → 장애물 → 포탈` 순서의
4열×4행이다. 정확한 의미는 생성 프롬프트에 적힌 행 우선 순서를 따른다.

## 생성 프롬프트 요약

- 1층: 젖은 흙, 이끼, 마모된 석재 길, 얕은 물, 가시덤불, 과수원,
  폐석재·목재 장애물, 비활성/활성 청록 포탈. 4×4, 90도 수직 탑뷰,
  셀 밖으로 돌출 금지, 24px 축소 가시성 우선.
- 2층: 재, 균열 주조장 바닥, 철판 통로, 폐배수로, 슬래그·기계·용광로·레일,
  비활성/활성 선조 기술 포탈. 4×4, 검은 철·녹·주황 열원·제한된 청록 발광.
- 캐릭터: 6×3 공통 앵커 시트. 1행 5종족 머리+몸통, 2행 소재 방어구와
  머리 장비, 3행 무기. 팔다리·방향 프레임·3D·아이소메트릭 제외.

이미지 생성 도구가 투명 요청을 체크무늬 RGB로 합성했기 때문에, 캐릭터 원본은
연결된 배경만 알파로 제거한 뒤 동일 셀을 정사각형으로 패딩하고 96×96로
기계 분할했다. 각 결과는 실제 알파 채널이 있는 RGBA PNG다.
