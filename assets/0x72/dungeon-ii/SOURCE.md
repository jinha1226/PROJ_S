unchanged original metadata. `playtest/dungeon_0x72_regions.gd` mechanically

unverified community comments were incorporated. The provider/adapter code is
written for this project. Runtime preserves image proportions and optionally
mirrors/animates original frames. Water/memory use runtime color modulation.
