# Hollow Warden 3D Art Spike

보스의 예비 동작을 읽고 회피·패링한 뒤 부위를 공략하는 세로형 모바일 3D 액션 게임 스파이크.

[브라우저에서 플레이](https://jinha1226.github.io/PROJ_S/)

현재 검증 범위:

- 코드로 제작한 최종 아트 후보 플레이어 `Masked Wanderer`
- 코드로 제작한 최종 아트 후보 보스 `Hollow Warden`
- 얕은 물, 폐허 기둥, 화로로 구성된 달빛 원형 경기장
- 걷기, 자동 검격, 회피, 패링, 피격, 부위 파괴, 보스 사망 애니메이션
- 휩쓸기, 내려찍기, 돌진의 서로 다른 예고 동작
- 직접 터치로 갈고리 팔, 가드 팔, 핵 선택
- 팔 공격도 전체 체력을 줄이고, 파괴 시 추가 피해와 패턴 제거
- 거리에 따라 전신 구도와 근접 전투 구도를 오가는 3D 카메라
- 타격 정지, 화면 흔들림, 슬로모션, 파편, 충격파 이펙트
- 사망·승리 후 즉시 재도전

조작:

- 모바일: 왼쪽 아래 드래그로 이동, `DODGE` 회피, `PARRY` 패링, 보스 부위 터치로 목표 선택
- PC: WASD/방향키 이동, Space 회피, F 패링, 보스 부위 클릭
- 선택한 부위의 사거리 안에서는 기본 검격을 자동으로 실행

설계 기준은 [보스전 문서](docs/BOSS_PROTOTYPE.md), 시각 기준은 [3D 아트 방향 문서](docs/ART_DIRECTION_3D.md)를 참고한다.

테스트:

    godot --headless --path . --script res://tests/test_runner.gd

기존 슬라임 자동화와 2D 보스전 파일은 프로토타입 비교 및 Git 이력 보존 목적으로 남겨두었다. 현재 메인 씬은 `presentation/views/boss_battle_3d.gd`를 사용한다.
