# 잿빛 원정 — SS 코어 통합 프로토타입

새 세계관 방향: [판타지 메카 기본 컨셉](docs/fantasy-mecha-concept.md).
성격과 기억을 가진 메카가 몬스터 파츠를 회수·장착하는 방향을 정리한 기획 문서이며,
현재 게임의 용어·코드·자산 전환은 아직 적용하지 않았습니다.

Godot 4.6 프로젝트. `new/project.godot`을 열고 F6 대신 **F5**로 실행합니다.

```bash
godot --path /mnt/d/SS/new
```

## 플레이

출정 → **64×64 절차 생성 1층** 탐험 → 심부의 **봉인된 유물** 회수 → 입구 관문으로 귀환 → 결과 정산 → 정비 → 재출정.
유물을 가지고 입구로 돌아와야 임무 성공이며, 유물 없이 귀환하면 중도 귀환으로 전리품만 정산합니다.
전 층 탐색이나 모든 적 처치는 요구하지 않습니다. [솔로 1층 · 유물 회수 계획](docs/solo-floor1-relic-plan.md).

층은 출정마다 새로 생성됩니다. 방 10~12개가 고리 있는 그래프로 이어지고, 입구 야영지·유물의 방·봉인된 보고와 침수 저장고·무너진 창고·목재 회랑 중 2개가 손으로 그린 템플릿으로 들어갑니다. 조우는 방 안에만 있으며 어떤 길로 가도 필수 조우 2~3회를 지나고, 막다른 방의 선택 조우 1~2회는 피할 수 있습니다. 무리 구성은 DCSS식 깊이 테이블(종족별 출현 구간·희귀도·곡선)과 위협 예산(초입 3·중간 5·심부 6·선택 5)으로 정하며, 3마리 이상이면 후위가 하나 이상, 술사는 최대 하나입니다. 상자·흙더미·제단은 주 경로 밖 가지에만 있습니다. [설계](docs/superpowers/specs/2026-09-22-floor-generator-design.md).

3×3 방 선택은 기본 플레이에서 사용하지 않습니다.
화면에는 주인공 주변 10×10 타일이 보이며 카메라가 따라갑니다.
상단 미니맵은 발견한 지형과 현재 보이는 캐릭터를 표시하고, 누르면 전체 지도가 열립니다.
전체 지도는 확인용이며 순간 이동하지 않습니다.
발견한 먼 타일을 누르면 경로를 따라 한 칸씩 이동합니다. 자동탐험은 하단 버튼으로 시작/중지합니다.
두 손가락 핀치로 표시 범위를 6×6~24×24로 조절합니다. PC에서는 휠을 사용할 수 있습니다.
횃불 밝기는 세 단계입니다. **밝음(60 이상)**은 원형 암막 없이 표시하고, **어둑(35~59)**·**암흑(34 이하)**에서는 암막이 짙어집니다.
어두울수록 조사물·제단 전리품이 125%/150%로 늘고 이능 드롭률이 50→65→80%가 되지만, 적 피해가 +1/+2 커지고
암흑에서는 처음 마주친 적이 기습(즉시 1회 행동)합니다. 밝기는 4행동마다 1씩 줄고 횃불 하나가 50을 회복합니다.
실제 시야는 밝을 때 반경 18칸이며, 불이 꺼져도 이전 최대 범위인 반경 7칸을 유지합니다.
밝은 상태에서도 미발견 지역과 벽 뒤의 적은 드러나지 않습니다.
이미 발견한 지형은 어둡게 남지만 시야 밖의 적은 표시하거나 자동 공격하지 않습니다.
장거리 이동과 자동탐험은 적 발견·피해·길 막힘·사용자 조작 시 중단합니다.
자동탐험은 새 조사물을 발견해도 멈춥니다. 잠긴 상자는 열쇠, 흙더미는 삽으로 안전하게 조사할 수 있습니다.
도구 없이 조사할 때는 선택지에 표시된 위험·비용을 감수합니다. [조사물 시스템](docs/exploration-curios.md).

기본 플레이는 주인공 한 명의 솔로 원정입니다. 주인공이 이동·공격·대기를 하면
주변 적도 한 번씩 행동합니다. 이동과 근접 공격은 8방향입니다.
`공격`은 발견한 적에게 접근하거나 인접한 적을 공격합니다.
솔로에서는 적 체력을 45%(20~32)로 줄여 한 무리를 몇 번의 교환으로 끝내게 했습니다.
동료 시스템(`Session.new(seed, true, true, true)`)은 테스트와 이후 확장을 위해 유지하며,
동료가 있을 때는 초상화 짧게 누르기가 다음 행동 예약을 엽니다.
이번 1층의 적은 원본 전술 선택기로 접근 또는 일반 공격을 결정합니다.
이전 방별 보스 패턴 모드는 기본 실행에서 제외하고 회귀 테스트용으로 보존했습니다.

모바일 세로 화면 가로폭을 사용합니다. 초상화를 0.6초 길게 누르면 신체·성격·기억·숙련·이능을 확인합니다.
상단은 작은 미니맵과 위치, 한 줄로 배치한 식량·횃불 수량 및 게이지로 구성합니다.
게임 화면 아래에는 최근 로그 세 줄을 표시하며, 누르면 전체 화면에서 이번 실행의 전체 기록을 읽을 수 있습니다.
초상화 위 스킬 두 칸과 아래 파티 공용 소모품 한 줄을 사용합니다.
`이능` 탭의 `사용 방침`에서 스킬마다 대상과 조건을 정합니다. 기본 스킬 `엄호`는 인접한 아군 한 명을 골라 이번 라운드에
그 아군이 받을 피해를 대신 받고 절반만 입습니다(조건은 `아군이 이번 라운드 공격받으면 죽을 때` 하나뿐이며, 인접 아군이 없으면 버튼이 꺼집니다).
출정 준비 화면의 '시험 로드아웃'은 플레이테스트용으로 모든 이능을 습득 상태로 만든다(장착은 이능 탭).
적이 보이지 않는 안전한 곳에서 성장 투자와 파츠 습득·교체가 가능합니다.
인접한 보급 상자·야영지·중계석을 눌러 한 번씩 이용할 수 있습니다.
봉인된 유물은 시야에 처음 들어올 때 발견되며, 인접해서 조사하면 회수 팝업이 열립니다.
팝업 열기는 무료이고 실제 회수만 행동 1회를 씁니다. 보이는 적이 있으면 회수할 수 없습니다.
회수한 유물은 가방의 임무 항목으로 표시되며 사용·판매·장착이 불가능합니다.
귀환은 입구 관문에 인접하고 적이 보이지 않을 때만 확인창을 거쳐 가능합니다.
상단 목표 칩(◎)이나 하단 `원정` 버튼에서 목표 설명, 입구 위치 보기, 원정 포기를 이용합니다.
원정 포기는 적이 보이지 않을 때 가능합니다. 임무 유물·완료 보너스를 포기하고 전리품·이능·성장·부상·기억을 유지하며, 생존자 스트레스가 20 증가합니다.
패배는 이번 출정의 획득물과 보급품을 잃고, 기존 재도전 규칙대로 주인공의 출정 전 상태를 복원합니다.
출정 전 마을에서 자금으로 물자를 삽니다(시작 자금 45). 식량 1·횃불 4·치유 물약 8·정신 안정제 6·활력 물약 6·화염 5·물 4·붕대 3·열쇠 6·삽 5.
마을에서 식량 12·횃불 2·치유 물약 1·붕대 1·열쇠·삽 1개를 무료 지급하며 구매분은 그 위에 더합니다.
성공·중도 귀환·포기 시 남은 구매/발견 보급품은 구매가 합계의 10%로 자동 환전(소수점 버림)하고 다음 출정에 이월하지 않습니다.
무료 지급분은 먼저 소비되며 환전 대상에서 제외합니다. 정산 후 다음 출정용 기본 보급을 새로 지급합니다. 10%는 본 프로젝트의 초기 밸런스 수치입니다.
같은 방문 중에 산 물건은 전액 환불할 수 있습니다.
결과 화면의 `정비하기`는 무료로 체력 최소 80%·스트레스 최대 60까지 회복합니다.
정비 후 출정 옆의 `요양 · 20 자금`으로 체력 20·스트레스 40을 추가 회복할 수 있습니다.
`원정` 창의 `입구까지 이동`은 발견한 안전 경로를 따라 이동하며, 적 발견·피해 시 멈춥니다. 도착 후 귀환 확정은 별도입니다.

목재에 점화, 물로 진화, 젖은 칸/금속을 따라 방전할 수 있습니다.
원소 피해는 아군에도 적용됩니다. 팔·다리 손상은 공격력·이동 범위에 영향을 줍니다.
감수성과 상처·상실 기억이 스트레스를 증폭합니다. 솔로 연속 층에서는 누적량을 절반으로 줄이고,
스트레스 150 이상이면 받는 피해가 1 증가합니다. 정신 안정제로 낮출 수 있습니다.
행동력은 계속 1이며, 기존 방 모드에서는 스트레스 150부터 행동력이 1로 줄어듭니다.
연속 층에서는 20행동마다 식량 1, 4행동마다 밝기 1을 소비합니다. 굶주림과 어둠은 스트레스를 높입니다.
연속 층에서는 상태창의 어디서나 귀환이 없습니다. 3×3 방 모드에서만 전투 철수 시 전리품의 절반을 잃습니다.
정상 귀환과 포기에서는 부상·기억이 다음 원정에도 유지됩니다. 연속 층의 패배에는 위의 복원 규칙을 적용합니다.

이식 출처와 범위: [연속 1층 이식 기록](docs/continuous-floor-port.md).

## 가져온 파츠와 새로 작성한 부분

| 원본 SS 구성요소 | 통합 사용처 |
|---|---|
| `sim/turn_engine.gd`, `combat_kernel.gd`, `game/rebuilt/min_heap.gd` | 경로 탐색, 공격 피해 계산, 시야 판정 |
| `sim/dungeon_population/hexaco_profile.gd` | 결정론적 HEXACO 성격 및 성격 설명 |
| `sim/party_memory_state.gd` | 사건 ID 중복 방지, 중요도 기반 최대 8개 기억 유지 |
| `sim/body_*`, `game/rebuilt/body_bridge.gd` | 부위별 조직 손상, 혈액 회복, 부위 기능에 따른 행동 제약 |
| `sim/environment_rules.gd` | 물에 의한 화재 억제, 화재 감소·피해 |
| 해당 JSON 데이터·레지스트리 및 글꼴 | 원본 정의 및 한국어 표시 |

`expedition/session.gd`는 새 탐험 호스트입니다. 방·복도 진행, 물자, 야영,
기억 생성과 스트레스 연결, 적의 추적 공격과 강력한 기술 예고, 행동력, 전류 전파를 담당합니다.
`expedition/main.gd`와 `board.gd`는 UI와 10×10 전투판입니다.
원본 파일은 `tools/import-core.mjs`로 필요한 의존성만 복사했습니다.
원본 SS 전체 라운드 시스템과 WorldState를 이식한 것은 아니며, 공통 전투 코어를
새 호스트에 연결한 첫 수직 슬라이스입니다. 원본 SS 프로젝트는 수정하지 않았습니다.

## 현재 범위와 제한

- 기본 플레이는 1인 연속 1층 유물 회수입니다. 기존 3인·3×3 방과 동료 보스 모드는 회귀 테스트용으로 남아 있습니다.
- 기억은 현재 실행 중 원정 간 유지됩니다. **디스크 저장/불러오기는 아직 없습니다.**
- 기존 전체 환경 시뮬레이터의 확산·재질·예약 큐 및 세계 생태는 아직 연결하지 않았습니다.
- 기존 관계 평가·자율 동료 AI는 연결하지 않았습니다. 스트레스는 신규 탐험 규칙입니다.
- 부위 손상은 유지되며 현재 재생 치료는 없습니다. 밸런스, 적 유형, 장비, 스킬은 초기 범위입니다.
- 모바일 세로 레이아웃을 사용합니다. 최종 아트와 모바일 실기 조작감 검수는 남아 있습니다.

다음 통합 작업에서는 호스트의 사건/상태 계약을 유지하면서 기존 원소 시스템과
라운드 시스템의 어댑터, 저장·복원, 관계 평가를 순서대로 연결할 수 있습니다.

첫 출정 8개 시드와 동일 캐릭터의 연속 4회 출정을 검사합니다. 안전할 때 정신 안정제를 사용하며,
연속 출정은 무료 정비와 유료 요양을 모두 확인합니다.
`solo_recovery.gd`는 실제 UI의 요양 경로, 잔액 차감, 솔로 붕괴 피해와 안정제, 입구 이동·귀환 확인 및 세로 화면 배치를 검사합니다.
`torch_tradeoff.gd`는 밝기 단계 경계, 단계별 전리품·이능 드롭·적 피해, 암흑 첫 조우 기습(1회), 밝기 감소율을 검사합니다.
`solo_provisioning.gd`는 시작 자금, 상점 가격·구매·잔액 부족 거부, 같은 방문 환불, 최소 지급 보충, 물자 정산 후 기본 보급 재지급, 층에서의 거래 차단, 상점 팝업 배치를 검사합니다.

통합 검증은 이동 거부, 예고 회피, 밀치기, 원소 아군 피해, 진화,
부상·기억 유지, 재방문 보상 중복 방지, 전리품 정산, 전투 철수, 전멸을 검사합니다.

회복·전리품 방의 보장, 시드 재현성 및 지도 변화를 검사합니다.
플레이스루는 실제 공개 행동만으로 보스를 처치하고 귀환하는지 검사합니다.
UI 검증은 헤드리스 장면/입력 실행이며 실제 화면의 시각 검수는 아닙니다.

`expedition_settlement.gd`는 포기/패배 구분, 고정 스트레스 페널티, 보급품 환전·무료 지급분 제외, 중복 정산 방지, 위협 중 포기 차단, 실제 귀환 직전 물자 기록과 소모품 행동 중 패배를 검사합니다.
