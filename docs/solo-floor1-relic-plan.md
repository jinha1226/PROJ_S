# 솔로 1층 탐험 · 유물 회수 구현 계획

작성일: 2026-09-22
상태: 2026-09-22 구현 완료. 적용 결과와 계획 대비 변경점은 [구현 결과](solo-floor1-relic-results.md)에 기록했다.

후속 변경: 포기 시 획득물 유지·스트레스 +20, 보급품 환전 규칙은 [구현 결과](solo-floor1-relic-results.md)의 마지막 절을 따른다. 아래는 최초 구현 당시 계획이다.

## 1. 목표와 범위

주인공 한 명으로 준비 → 탐험 → 전투·수색 → 유물 획득 또는 중도 귀환 → 결과 정산 → 정비 → 재출정의 전체 루프를 만든다.

유물 없이도 안전하게 돌아오면 부분 성공이다. 유물을 얻는 순간이 아니라 **유물을 가지고 입구로 귀환했을 때** 임무 성공으로 처리한다. 전 층 탐색이나 모든 적 처치는 요구하지 않는다.

첫 출정 목표 시간은 10~15분으로 두되, 실제 이동 행동 수와 테스트 결과로 조정한다. 100×100 외형을 채우기 위해 적이나 오브젝트 수를 늘리지는 않는다.

동료 시스템·기존 보스 테스트는 삭제하지 않는다. 이번 기본 플레이만 솔로로 변경한다. 메카 설정 및 아트 교체, 2층, 마을 시설 확장, 영구 사망, 저장/불러오기는 이번 범위에서 제외한다. 초기 검증은 같은 실행 세션 안의 연속 출정으로 한다.

## 3. 플레이 흐름

### A. 준비

- 한 명의 주인공, 기본 무기, 장착 이능 두 칸으로 시작한다.
- 기존 물자 지급을 우선 유지한다. 식량 27, 횃불 5, 밝기 90, 열쇠·삽 각각 2개와 기존 소모품이다. 감소량을 측정한 뒤 조정한다.
- 출정 화면에 ‘심부의 유물을 찾아 입구로 돌아오세요. 유물 없이 귀환해도 전리품은 정산됩니다.’를 표시한다.
- 이전 출정에서 확보한 장비·이능·숙련·기억은 정상 귀환 시 유지한다.

### B. 탐험과 전투

- 탑뷰, 8방향 이동·근접 공격, 한 행동 후 적 행동이라는 기존 규칙을 유지한다.
- 먼 칸 이동·자동탐험은 적이나 새 상호작용 물체 발견, 피해, 사용자 입력 시 정지한다. 유물 발견도 반드시 정지 사유에 포함한다.
- 초입은 추격병 단독, 중간은 근접+궁수, 심부는 근접+술사를 기본 조합으로 한다. 기존 5개 무리 배치를 우선 활용한다.
- 전투 중 물약·스킬도 한 행동을 소비한다. 가방 열기, 설명 읽기, 유물 조사 팝업 열기는 무료다.
- 식량·횃불은 실제 행동에 따라 감소하며, UI를 여는 것만으로 감소하지 않는다.
- 맵은 주 동선과 선택 샛길로 읽히게 한다. 샛길 보상은 귀환에 필요한 필수 물자를 독점하지 않는다.

### C. 유물 발견·획득

- 한 출정에 임무 유물 하나를 생성한다. 임시 명칭은 ‘봉인된 유물’로 한다.
- 처음부터 정확한 위치를 공개하지 않는다. 첫 시야 진입 시 로그와 지도에 발견 표시를 남긴다.
- 캐릭터가 인접하여 조사하면 ‘유물을 회수한다 / 닫기’ 팝업을 표시한다. 실제 획득에만 한 행동을 소비한다.
- 첫 버전은 현재 시야에 적이 없을 때만 획득할 수 있다. 기존 safe 판정을 재사용하며, 층 전체의 적 처치를 요구하지 않는다.
- 획득 후 월드 오브젝트는 비활성화하고 임무 보유 상태를 설정한다. 가방의 일반 슬롯을 소비하지 않는 임무 항목으로 표시한다.
- 유물은 사용·판매·버리기·장착이 불가능하다. 중복 클릭으로 두 번 지급되지 않는다.
- 획득 시 목표를 ‘유물을 가지고 입구로 귀환’으로 변경한다. 자동 귀환이나 자동 이동은 시작하지 않는다.
- 획득에 따른 적 재생성, 강제 추격, 추가 횃불 소모, 이동 속도 저하는 넣지 않는다. 왕복 자원 관리만 먼저 검증한다.

### D. 귀환

- 입구 관문에 인접하고 현재 시야에 적이 없으면 귀환 확인 창을 연다.
- 유물 미보유: 부분 성공. 가지고 돌아온 일반 전리품만 정산한다.
- 유물 보유: 임무 성공. 일반 전리품과 최초 회수 보너스를 정산하고 유물은 반납 처리한다.
- 임시 회수 보너스는 출정당 100 자금으로 한다. 기존 출구 보상과 중복 지급하지 않는다.
- 상태창의 어디서나 귀환 버튼은 제거한다. 필요하면 ‘입구 위치 보기’를 제공하되 순간이동은 하지 않는다.
- 막힌 테스트에서 나올 수 있도록 ‘원정 포기’를 확인창과 함께 제공한다. 일반 귀환이 아니며 유물·이번 출정 보상을 잃는다.
- 귀환 행동은 월드 적 턴을 추가 실행하지 않고 원정을 종료한다. 결과 화면에 진입하기 전에 자동 이동과 입력 예약을 취소한다.

### E. 결과·정비·재출정

- 결과는 성공 / 중도 귀환 / 패배 / 포기로 구분한다.
- 유물 회수 여부, 정산 자금, 얻은 아이템·이능, 숙련 변화, 부상·기억을 요약한다. 내부 육체 수치를 나열하지 않는다.
- 결과를 먼저 확정한 뒤 맵과 임무 데이터를 정리한다. 창을 다시 열거나 버튼을 반복해서 눌러도 자금이 재지급되지 않는다.
- 첫 테스트에서는 마을 무료 재정비로 생존 가능 상태까지 복구할 수 있게 한다. 기존 유료 요양과 구분하고, 돈이 없어 다음 출정을 못 하는 상황을 막는다.
- 패배·포기 시에는 출정 시작 스냅샷을 복원해 이전에 확정된 자금·장비·성장을 지킨다. 이번 출정에서 얻은 전리품·이능·숙련·기억은 함께 되돌리는 단순한 규칙으로 시작한다.
- 정상 귀환에서는 이번 출정의 성장·기억·부상이 보존되며 이후 정비에서 처리한다. 패배 후에도 같은 주인공으로 재출정할 수 있다.
- 재출정은 새로운 층 시드와 새 유물을 생성하고 이전 유물 보유·발견·정산 상태를 남기지 않는다.

## 4. 유물 배치 규칙

1. 층 생성 완료 후, 실제 플레이어와 같은 8방향·모서리 통과 규칙으로 입구에서 도달 가능한 칸과 최단 경로 거리를 계산한다. 적 점유는 배치용 영구 장애물로 취급하지 않는다.
2. 기존 심부 출구 위치를 우선 후보로 사용한다. 도달 가능하고, 유물에 접근할 인접 칸이 있으며, 입구와 충분히 멀 때 채택한다.
3. 대체 후보는 도달 가능한 바닥 중 경로 거리 상위 20% 구간에서 선택한다. 벽, 입구, 기존 수색물·휴식 지점, 적 시작 위치 및 위험 지형과 겹치지 않게 한다.
4. 후보 선택은 출정 시드로 결정해 재현 가능하게 한다. 필요하면 먼 쪽부터 적합한 칸을 찾는다.
5. 유물이 있는 칸만이 아니라 상호작용 가능한 인접 칸까지 도달 가능한지 확인한다. 열쇠·삽 소비나 강제 피해 없이는 접근 불가능한 배치는 허용하지 않는다.
6. 유효 후보가 없으면 제한된 횟수만 재생성하고, 검증된 기본 레이아웃으로 대체한다. 무한 재시도 또는 유물 없는 출정은 금지한다.

기존 여러 relic 랜드마크는 임무 유물로 일괄 변환하지 않는다. 기존 효과를 가진 ‘제단’ 등 별도 종류로 분리해 정확히 하나의 임무 유물과 구별한다. 입구·출구·랜드마크 Dictionary 등록 순서 때문에 같은 칸의 feature가 덮어써지지 않는지도 검사한다.

## 5. 상태와 데이터 설계

월드 전투는 연속 층에서 기존 BATTLE 상태를 유지한다. 탐험/전투를 표현하려고 기존 phase를 전면 재작성하지 않고 별도 원정 목표 데이터를 둔다.

- expedition_objective: 출정 ID, 유물 ID, 위치, 상태(UNDISCOVERED / DISCOVERED / CARRIED / DELIVERED / LOST).
- expedition_snapshot: 출정 전 영구 상태의 독립 스냅샷. Dictionary뿐 아니라 육체·기억 객체 등 참조형 데이터의 직렬화/복원을 검증한다. 단순 얕은 복사는 금지한다.
- expedition_result: 종료 이유, 획득/손실 내역, 최종 정산액, settled 플래그. 출정 ID에 대해 한 번만 확정한다.
- 현재 출정 임무 상태는 새 층 생성 시 초기화한다. 결과는 사용자가 닫을 때까지 보존한다.
- 유물 획득 검증과 효과 실행은 세션 계층 한 곳에 둔다. UI·자동 이동·지도에서 보유 상태를 직접 수정하지 않는다.
- 발견 기록과 미니맵의 유물 마커 갱신은 상태 변경 시에만 처리한다. 매 턴 전체 층 BFS 또는 10,000칸 마커 재생성을 하지 않는다.

## 6. 모바일 UI

- 상단 HUD 높이를 늘리지 않는다. 현재 위치 옆에 작은 목표 아이콘을 두고 터치하면 목표 설명을 연다.
- 목표 문구: ‘유물 찾기’ → ‘입구로 귀환’. 발견·획득 시에는 로그로 안내한다.
- 맵에는 발견 전 유물 위치를 숨기고 발견 후 표시한다. 회수 후 지도 마커는 제거하거나 회수 완료 상태로 바꾼다. 이미 알려진 입구는 유지한다.
- 초상화는 하나만 표시하고 동료 예약·동료 전술 안내를 감춘다. 길게 누르는 상태창 진입은 유지한다.
- 초상화 두 개를 무조건 큰 하나로 늘리지 말고, 기존 하단 높이 안에서 한 초상화와 두 이능을 배치한다. 공용 소모품 한 줄과 자동탐험·공격·가방·대기는 유지한다.
- 결과 화면은 요약 카드와 ‘정비하기’ 하나의 진행 버튼으로 구성한다.

부모 프로젝트 ../에서 정산·목표물·단독 파티 UI 관련 코드를 먼저 검색하고 재사용 가능성을 확인한다. 가져오는 파일/규칙과 현재 호스트에 맞춘 변경점은 문서에 기록한다. 기존 최적화된 층 생성·경로·미니맵 코드를 다시 만들지 않는다.

## 8. 검증 계획

자동 테스트:

- 최소 100개 시드에서 유물 1개, 입구/물체 비중첩, 상호작용 지점까지 접근 가능.
- 시야 밖 유물이 보드·미니맵·자동 이동 대상으로 노출되지 않음.
- 팝업 열기 무료, 원거리·벽 너머·적 보이는 중 획득 거부, 성공 획득은 정확히 한 행동.
- 중복 획득/반납/결과 확인으로 보상 증가 없음.
- 유물 미보유 귀환은 부분 성공, 보유 귀환은 성공, 획득만으로는 성공 처리하지 않음.
- 기존 심부 출구 및 상태창 버튼으로 귀환 조건을 우회할 수 없음.
- 사망·포기 복원은 보관 자금과 이전 성장을 유지하고 출정 중 획득분만 제거.
- 유물 획득 직후 행동 처리 중 사망하면 성공 대신 패배.
- 연속 두 번 이상 출정해 이전 임무 상태·자동 이동·예약이 남지 않음.
- 솔로 및 기존 동료·보스 테스트를 함께 실행해 다른 모드 회귀 방지.

실제 화면/플레이 검증:

- 모바일 세로 화면에서 목표·초상화·가방·결과창이 잘리지 않고 터치 가능.
- 유물 발견→획득→귀환 목표 전환을 설명 없이 이해할 수 있는지 확인.
- 적을 모두 잡지 않아도 회수 가능하며, 샛길을 선택하거나 일찍 돌아갈 이유가 있는지 확인.
- 귀환길 반복 이동이 지루하면 알려진 안전 경로의 연속 이동을 개선한다. 즉시 귀환으로 목표 루프를 먼저 없애지 않는다.
- 행동 수, 경로 길이, 왕복 소요 시간, 남은 체력/횃불/식량, 물약 사용 수, 중도 귀환 이유를 기록한다. 수치는 검증 후 조정한다.

## 9. 이번 버전의 최종 완료 정의

주인공 한 명으로 실행해 유물을 발견·획득하고 입구로 돌아와 결과를 확인한 뒤, 정비하고 다시 출정할 수 있다. 중도 귀환·사망·포기도 동일한 종료 흐름에서 안전하게 처리된다. 유물은 중복 지급되지 않으며 모든 생성 맵에서 접근 가능하다.
