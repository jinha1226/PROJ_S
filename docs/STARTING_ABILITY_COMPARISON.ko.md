# 1층 이능 비교용 드롭

기준: `aacbea5`. 새 게임의 시작 지면 아이템에 `GROUND_START_FIREBOLT` / `ESSENCE_FIRE_BOLT` 한 개를 추가한다. 캐릭터에게 자동 결속하거나 기존 저장을 수정하지 않는다. 시작 아이템이므로 재방문 때 추가 생성하지 않으며 기존 아이템 소유권·줍기·결속·저장 재현을 사용한다.

## 모바일 확인

1. 새 게임 → 마을에서 출발 → 1층 시작 칸의 [줍기].
2. 초상화 길게 누르기 → `숙련·이능`에서 화염탄 이능을 결속한다. 확정하면 획득물을 소비한다. 현재 해제는 지원하지 않으므로 흡수 전후 비교는 수치를 기록하거나 새 게임을 사용한다.
3. 화염탄은 능동 기술이므로 결속만으로 **일반 공격력은 변하지 않는다**. 결속 전에는 없던 화염탄을 기술 목록에서 선택해 사용한다. 현재 이 드롭은 패시브 공격력 보너스 테스트가 아니다.
4. 시작 가방의 단검·손도끼·철퇴·창·활 등을 바꾸고 상태창/초상화 공격력을 비교한다. 무기 종류의 기본 피해 및 능력치 보정이 적용된다. 원거리 무기는 원거리 숙련을 사용한다.
5. 레벨업으로 얻은 포인트를 해당 숙련에 투자한다. 근접/원거리 숙련은 해당 무기의 일반 공격, 마법 숙련은 화염탄 등 마법의 효과량을 높인다. 마법 숙련을 올려도 근접 무기의 일반 공격력 칸은 그대로인 것이 정상이다. 시험용 경험치·숙련 포인트를 자동 지급하거나 새 전투 배수를 추가하지 않았다.

화염탄의 마법 숙련 0/5 기본 위력은 32/45이다. 실제 피해는 INT 보정·대상 내성 등을 적용하므로 전투 숫자가 이 값과 반드시 같지는 않다.

## 검증

`tests/starting_ability_drop_acceptance.gd`는 실제 출발 직후 발밑 드롭, 줍기·결속·기술 획득·일반 공격력 불변, 실제 가방 무기 교체 시 공격력 변화, 저장 재현을 검사한다. 별도 순수 계산으로 무기 종류/숙련 배수 차이를 확인하며, 테스트용 rank 변경을 실제 원정에는 주입하지 않는다. 기존 줍기 회귀 검사는 시작 칸의 추가 아이템 수를 고려하도록 조정한다.

- 시작 이능 드롭 acceptance: PASS. 비교용 공격자 power=20/능력치 각 5인 순수 계산에서 단검 24, 손도끼 26, 근접 숙련 5의 손도끼 36을 확인했다. 이 값은 실제 시작 캐릭터의 수치를 약속하는 것이 아니다.
- `mobile_combat_loot_torch_acceptance.gd`: PASS. 추가 시작 아이템이 있어도 한 번에 한 항목만 줍는다.
- Web release export 및 별도 경로의 PCK 기동 검사: 종료 코드 0, 스크립트 오류 없음.
