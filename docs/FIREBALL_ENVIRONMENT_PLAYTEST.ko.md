# 화염구 · 증발 효과 플레이테스트

## 사용법

던전에서 주인공 초상화를 선택한 뒤 공용 스킬 줄의 세 번째 `화염구(시험)`을 누르고,
5칸 이내의 보이는 물/바닥을 누른다. 대상 선택 자체는 무료이며 성공하면 MP 3과
시전 시간 120(시전 속도로 보정)을 소비한다. 같은 스킬 버튼을 다시 누르거나 Esc로 취소한다.
주인공에게만 임시 부여하며 기존 저장에도 파생 스킬로 나타난다. 동료 장비·저장 구조는 바꾸지 않는다.

## 이번 구현

- `FIREBALL`은 적 ID 대신 타일 좌표를 받는 **환경 가열 시험 스킬**이다.
- 지정 칸에 공용 환경 API로 열 1,400을 전달한다. 완성형 광역 폭발/직접 피해 스킬이 아니며,
  가연성 바닥은 기존 환경 규칙으로 발화하고 물 표면은 증발한다.
- 기존 `shallow_water` 지형은 연못/물 공급원으로 취급한다. 표면층이 없으면 시험 스킬이
  물 1,000의 샘플을 표면에 옮긴 다음 가열한다. 연못 전체가 영구적으로 마르는 기능은 아니다.
- 실제 증발 이벤트에 흰 픽셀 수증기가 올라오는 1초 효과를 연결했다.
  수증기가 남아 있는 동안 지도에도 흰 픽셀 구름이 표시된다. 시야 밖에는 표시하지 않는다.
- 화염구 발사에는 주황색 궤적·밝은 중심·착탄 링의 1초 효과를 사용한다.
  효과는 결과 이벤트를 받아 한 번만 재생하며, 렌더링이 시뮬레이션 시간을 진행하지 않는다.
- 세이브/저널의 타일 지정 명령, 스킬 이벤트 검증과 MP 이력을 함께 연결했다.

## 검증

```sh
godot --headless --path . --script tests/fireball_environment_acceptance.gd
godot --headless --path . --script tests/portrait_skills_acceptance.gd
godot --headless --path . --script tests/run_environment_regression_tests.gd
```

버튼→물 타일 선택, MP/시간 소비, 잘못된 타일의 무변이 거절, 실제 증발,
저장 저널 재실행, 수증기의 실제 지도 연결/시야 차단, 효과 수명 검증을 포함한다.
환경 회귀와 화염구 acceptance는 Pages CI에서 실행한다.

검사 결과: 화염구 acceptance PASS, 초상화 스킬 acceptance PASS,
환경 회귀 62/62 PASS, 동료 AI 37/37 PASS. X11 화면 캡처에서 주인공 세 번째 버튼과
실제 지도 수증기 표시를 확인했다. 이번 변경에서 전체 저장소 회귀를 다시 실행한 것은 아니다.

Godot 4.6.2 Linux headless 및 X11/Compatibility 렌더러에서 검사하며,
`-- --capture` 옵션으로 `/tmp/lw-fireball-steam.png`에 화면을 저장할 수 있다.
새 이미지 에셋이나 외부 코드는 사용하지 않고 기존 그리기 경로에 픽셀 도형 효과를 추가했다.
