# 특수 부위 섭취와 사선 전술 보드

기준: 9ad3f68. 이전 `TELEGRAPH_COMBAT_AND_MONSTER_MEAT.ko.md`의 고기 획득·모드 선택 정책을 아래 내용으로 대체한다.

## 섭취와 발견

- 일반 고기 21종: 해당 몬스터 사망 시 독립 확률 45%, 포만감 +20. 기존 식량 자동 섭취 및 아이템창 직접 먹기 대상이다. 돌 골렘은 일반 고기를 주지 않는다.
- 특수 부위 22종: 기존 16종의 드롭 확률은 유지하고 DCSS 계열 6종은 각각 20%로 추가했다. 기존 보상 드롭도 유지한다.
- 특수 부위는 자동 섭취하지 않는다. 아이템창에서 직접 먹는다. 최초에는 이름과 먹기·버리기만 표시하고 설명·효과·경고·확인창을 숨긴다.
- 성공적으로 먹은 정확한 부위 ID만 현재 원정의 파티 공용 지식에 기록한다. 이후 같은 부위의 인벤토리·바닥 표시에서 효과를 공개한다. 감정 스크롤로는 공개되지 않는다.
- 섭취 즉시 변이를 얻고 상시 효과와 사용 기술을 함께 제공한다. 모드 전환은 사용하지 않는다. 다른 부위가 같은 변이를 주더라도 그 부위의 섭취 지식은 별개다.
- 중복 변이 또는 슬롯 부족이면 소비하지 않고 일반적인 섭취 불가 메시지만 표시한다. 기존 안전한 장소·포만감 제한을 유지한다.
- 22개 부위가 16개 구현된 변이에 연결된다. 추가된 6개 부위는 기존 변이를 공유한다. 부위별 개별 그림은 아직 없으며 공통 DCSS 고기 아이콘을 사용한다.
- 내부 ESSENCE ID와 직렬화 필드는 호환 자료로 남기되 화면 명칭은 변이로 바꾼다.

## 카메라와 지형

- 제품 게임 화면 기본값을 고정 2:1 사선 격자로 변경했다. 기존 DCSS 바닥 텍스처를 마름모에 투영하고 벽은 낮은 입체 면, 캐릭터는 서 있는 스프라이트로 표시한다.
- 화면 좌표의 역변환을 터치 타일 선택에 사용하고 카메라 이동·배우 위치·공격 예고는 같은 투영을 따른다. 상단 HUD·게임·로그·초상화·버튼 구조는 유지한다.
- 관측된 지형만 캐시해 그린다. 사체·아이템은 지형과 별도 레이어다. 엔진에서의 성능 개선 수치는 아직 측정하지 않았다.
- 1·2층 방 내부에 돌기둥·짧은 벽·잔해·침수 구간을 추가했다. 벽은 실제 이동·시야를 막고 잔해와 물은 기존 지형 규칙을 사용한다. 주요 연결 통로와 출입·보급·모집·전투 시작 지점을 보호한다.
- 벽의 높이는 시각 표현이다. 고저차 전투, 파괴 가능한 벽, 낙사 등의 새 전투 규칙은 이번 범위에 없다. 기존 적 행동 예고를 유지하며 Into the Breach 전체 규칙을 복제한 것은 아니다.

## 저장과 검증

밸런스 ID는 `dcss-balance-0.34.1-mutation-board-v3`다. 기존 저장 파일을 삭제하지 않지만 이전 버전 원정은 새 게임으로 시작해야 한다.

사용자 지시로 **Godot은 GUI·headless 모두 실행하지 않았다.** 엔진 파싱, 실제 렌더링, 모바일 터치, 저장 재생, 실전 효과와 성능은 미검증이다.

`node tests/mutation_board_static_check.mjs` 통과:

- 특수 부위 22종·고기 21종, 드롭 참조·확률 범위·수량·중복 검사
- 화면 크기 4개 × 줌 3개에서 좌표 왕복 계산 2,156건
- 배치 규칙을 독립적으로 옮긴 JS 모델의 100개 시드에서 주요 지점 연결과 통로 보존
- 지식 마스킹·기본 뷰 연결의 소스 가드와 새 모듈 preload 경로

좌표·배치 검사는 GDScript 실행을 대신하는 별도 모델 검사이며 엔진 통합 통과를 의미하지 않는다. 기존 모드 전환을 기대하는 Godot 테스트도 새 정책에 맞게 후속 갱신이 필요하다. `git diff --check`로 공백 오류를 확인했다.
