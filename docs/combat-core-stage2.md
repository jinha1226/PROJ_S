# 전투 코어 2단계

독립 원형에 8방향 이동/공격, 행동별 시간, 시야와 지형 기억을 추가했다.
외부 코드를 이식하지 않고 1단계 코어를 확장했다.

- 대각선 옆 두 지형 중 하나라도 열려 있으면 이동/공격 허용. 둘 다 벽이면 차단.
- 적 경로 탐색과 직접 입력 모두 같은 이동 규칙 사용.
- 유클리드 반경 6칸과 격자 중심 간 광선 검사. 벽 자체는 보이고 뒤는 차단.
  정확한 모서리 교차 시 양쪽 벽이 모두 막힌 경우 차단한다.
- 화면 공개와 적 감지는 동일한 `sees` 함수를 각 관찰자 위치에서 사용한다.
  적은 현재 플레이어가 안 보이면 대기한다. 마지막 위치 추적은 후속 범위다.
- 코어가 탐색한 지형만 기억하고 화면은 시야 밖 적을 표시하지 않는다.
- 행동별 양의 정수 비용 사용. 원형 화면은 플레이어 이동/대기 100, 공격 140,
  적 이동 120, 공격/대기 100. 대각선에 추가 비용 없음.

검증: stage1 회귀 및 stage2 모서리 이동, 양방향 LOS 대칭, 반경,
지형 기억, 미감지 적 대기, 서로 다른 공격 비용의 실행 횟수 검사.
독립 장면 headless 실행으로 스크립트 오류 확인. 모바일 체감 확인은 별도다.

실행 주소는 배포 후 `?prototype=combat`. 기존 게임 코어에는 아직 연결하지 않는다.
