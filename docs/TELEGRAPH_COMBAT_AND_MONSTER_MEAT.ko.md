# 예고형 전투 / 몬스터 고기 — 첫 적용

기준: `9099bc5`. 사용자 요청: 사망 후 이상한 바닥 이미지 점검, 적 이동·공격 예고와 대응 중심 전투, 정수 대신 몬스터 고기 섭취로 이능 획득.

## 전투 계약

- 필드 입력 직전 보이는 적의 행동을 계산한다. UI와 실제 턴은 동일한 순수 계획 함수를 사용한다. 전투 중 적뿐 아니라 보이는 순찰 이동도 대상이다.
- 붉은 연결선·X는 공격 칸, 노란 화살표는 이동 목적지다. 시야 밖 적·숨은 목적지는 표시하지 않는다.
- 플레이어와 동료의 행동 이후 적이 행동한다. 공격은 예고된 **좌표**를 향하며 플레이어를 따라 재조준하지 않는다. 해당 칸으로 들어온 다른 파티원은 대신 공격받을 수 있다.
- 공격 칸이 비거나 공격자가 밀려나면 대기한다. 예고 목적지가 막혀도 다른 길로 즉시 우회하지 않는다. 사망·행동 불능은 기존 스케줄러가 취소한다.
- 플레이어의 긴 행동 중에도 예고한 적 행동은 한 번만 실행한다. 그 입력 도중 새로 보인 적은 다음 입력에서 대응 기회를 준다.
- 기존 행동 시간·방어·명중·회피·피해 계산과 화면 밖 시뮬레이션은 유지한다. 느린 적이 다음 입력에서 아직 준비되지 않았으면 행동하지 않을 수 있다. 예고는 각 입력 경계에서 갱신하는 현재 대응 기회의 계획이며, 여러 입력에 걸친 영구 예약이 아니다.
- UI 예고는 시간·이벤트·파티·아이템 revision 키로 캐시한다. 프레임마다 AI를 다시 돌리지 않는다.

이는 Into the Breach의 전체 전투 규칙 이식이 아니라 **예고 → 대응 → 고정 칸 실행**의 첫 단계다. 확정 피해, 다중 타일 특수 공격, 환경 목표물·연쇄 충돌·적끼리의 피격은 이번 범위에 없다. 다음 밸런스 검토에서는 후퇴 반복의 이득과 이동/공격 패턴을 함께 봐야 한다.

## 고기

- 기존 이능 획득물 16종의 표시 이름·그림·소비 동작을 몬스터 고기로 변경한다. DCSS CC0 `item/food/chunk.png` 원본을 사용한다.
- 아이템창과 숙련·이능창에서 직접 먹는다. 확인창에서 획득 조건과 영구 체득을 안내한다. 자동 식량 보충에는 사용하지 않는다.
- 포만감 +20, 현재 최대치까지만 회복. 배부르거나 보이는 적이 있으면 소비하지 않는다.
- 미보유 이능이고 레벨에 따른 빈 칸이 있으면 실제 이능을 체득한다. 중복 또는 빈 칸 없음은 영양만 적용한다. 자동 교체·중복 중첩은 없다.
- 체득 후 안전한 던전에서 패시브/액티브 전환이 가능하다. 기존 필드 전체 전환 금지도 보이는 적이 있을 때만 제한하도록 수정했다.
- 현재 식사는 기존 결속 동작과 같이 별도 턴을 소비하지 않는 안전 구간 동작이다. 포만감은 기존 **파티 공유 수치**이며 개인별 소화 상태는 추가하지 않았다.
- 내부 `ESSENCE_*`, `essence_id`, `BIND` 및 `party.ability_bound`는 저장·이벤트·드롭 연결 식별자로 보존한다. 화면에 정수로 표시하거나 별도의 정수 아이템을 생성하지 않는다. 현재 드롭률과 몬스터 연결을 유지한다. DCSS 추가 6종의 비어 있는 이능 연결은 아직 별도 미완료 작업이며, 모든 종의 고기 드롭을 보장한 것은 아니다. 무생물 고기 명칭/섭취 세계관도 추가 설계 대상이다.

## 이미지 문제

- 실제 사망 처리는 시체 위치로 소지품과 보상을 떨어뜨리며 지형을 교체하지 않는다.
- 남아 있던 자원 에셋 경로에서 `STONE → 0x72 floor_4`, `TIMBER → crate` 매핑을 확인했다. 자원 더미는 작은 도형으로, 아이템 `STONE`은 DCSS 돌로 표시하도록 수정했다. 지형을 자원 아이콘으로 그리는 경로를 제거했다.
- 바닥 전리품에 작은 어두운 배경·테두리를 추가하여 지형과 구분한다.
- 환경 불길의 실제 지형 손상, 문·계단의 상태 변경은 별도 정상 기능이다. 사용자 화면에 나타난 모든 증상의 원인이 동일하다고 단정하지 않는다.
