# 이능 결속 구현 결과

> 아래 최초 결과에 이어 **후속 마무리**를 완료했다. 현재 상태는 마지막 절을 기준으로 한다.

- 완료일: 2026-09-10
- 기준 프로토콜: `docs/ABILITY_BINDING_PROTOCOL.ko.md`

## 구현 결과

- 캐릭터별 `bound_ability_ids`를 party schema v25에 추가했다.
- 레벨별 6칸 결속 DTO와 잠금 슬롯의 해금 레벨 표시를 추가했다.
- `ESSENCE_FIRE_BOLT`를 보관 후 `FIREBOLT`로 결속하는 원자적 서비스를 추가했다.
- 결속 시 아이템 소비, 결속 이벤트, command journal을 기록하고 실패 시 rollback한다.
- 동일 능력과 alias ID의 중복 결속을 차단한다.
- v24 저장은 빈 결속 상태로 안전하게 마이그레이션한다.
- 기존 상세 UI를 실제 결속 상태·보관 이능 아이템 표시와 결속 callback에 연결했다.
- 제거는 정책 미정 상태를 명시적으로 반환하며 UI에서도 잠겨 있다.

## 남은 결정

흡수=결속은 이번 구현의 안전한 권장 가정으로 확정했다. 제거 후 소멸·회수·재아이템화와 비용, 패시브 효과 수치, 결속 액티브의 전투 버튼 노출은 계획서의 미정 항목으로 남겨 두었고 임의로 삭제·자동 노출하지 않았다.

## 후속 마무리: 실제 결속 → 사용 → 저장 재현

### 변경

- `active_skill_ids()`가 결속한 등록 액티브를 포함한다. 직업 스킬과 같은 ID는 한 번만 노출한다. 기존 직업·환경 시험 스킬은 보존한다.
- 3개 버튼을 유지하면서 넘침 스킬 페이지 버튼을 추가했다. 캐릭터별 페이지를 유지하며 전환은 턴을 소비하지 않는다. 기존 2칸 구형 화면도 같은 방식으로 넘친 스킬에 접근한다.
- 아이템 클릭은 미리보기 확인창만 연다. 소모·슬롯 점유·현재 해제 불가를 알리고 최종 확인 후에만 서비스가 실행된다. 취소·중복 확인은 소모하지 않는다.
- 길드 `GUILD_TUTORIAL_BIND` 수락 후 획득물이 없을 때 화염탄 정수를 한 번 지원한다. 기존 획득물이나 완료·지원 기록이 있으면 거절한다. 자연 드랍은 별도 아이템 작업 범위다.
- 전체 저장 재생 시 journal의 이능 ID와 실제 결속 결과가 다르면 로드를 거절한다.
- CI에 이능 단위·게임플레이 통합 검증을 추가했다.

### 범위와 남은 정책

- 현재 실제 획득물 매핑은 `ESSENCE_FIRE_BOLT → FIREBOLT`다. 이 경로는 보관부터 실제 전투까지 연결했다.
- 새로운 패시브 정의·효과 수치 및 해제 비용/회수 정책은 만들지 않았다. 현재 등록된 결속 대상은 액티브이고 해제는 계속 잠겨 있다. 패시브 시스템 전체를 구현했다는 의미가 아니다.
- UI는 headless 노드 배치·신호·게임 입력 경로를 검증했으며 실기기 브라우저 터치 체감과 화면 캡처 검수는 별도다. 전체 93개 회귀를 이번에 재실행한 것은 아니다.
