# 횃불 3단계 구현 결과

- 기준 코드: `1dee9b1`
- 범위: 횃불 장비·점화·소화·연료·동적 조명·손 표현과 모바일 적 시야 V버튼
- 상태: 3단계 구현 완료

## 구현 내용

- `TORCH` 아이템을 `OFF_HAND` 장비 슬롯에 등록했다. 아이템 인스턴스 스키마는 변경하지 않고 `torch.ignited`·`torch.extinguished` 이벤트와 월드 시간으로 연료를 계산한다.
- 초기 연료는 1000 시간 단위, 점화·소화·일반 아이템 행동 비용은 100 시간 단위다. 켜진 횃불만 경과 시간만큼 감소하며 메뉴·시야 토글은 시간을 진행하지 않는다.
- 횃불은 장착된 개체의 공유 조명원으로 시야 질의에 들어간다. 플레이어 시야와 적 인지 경로가 같은 `VisionRules.lighting_for_world()`를 사용한다.
- 장착 해제·버리기·폐기·다른 보조 손 장비로 교체할 때 켜진 횃불을 별도 소화 이벤트로 닫는다. 소진 상태는 `torch_depleted`와 연료 게이지로 제공하고, 소진 순간에는 한 번의 UI 알림을 표시한다.
- 인벤토리 슬롯에는 자체 횃불 아이콘을, 필드에는 손의 횃불 문양과 고정된 따뜻한 광원 풀을 추가했다. 광원 깜박임은 렌더링만 바꾸고 시뮬레이션 질의를 다시 계산하지 않는다.
- 제품 HUD에 44×44 터치 영역의 `V` 버튼을 추가했다. `V` 키와 같은 적 시야 오버레이를 켜고 끄며 월드 시간·연료·의심 상태를 변경하지 않는다.

## 검증

다음 명령이 통과했다.

```text
godot --headless --log-file /tmp/godot-env2.log --path . --script res://tests/run_environment_regression_tests.gd
---- Environment regression: 74 tests, 0 failed ----
```

포함된 3단계 테스트는 아이템 등록과 보조 손 장착, 점화·소화, 경과 시간에 따른 연료 감소, 공유 조명원, 저장 스냅샷 복원, 모바일 V버튼 크기와 무시간 동작을 확인한다.

추가로 기존 묶음을 확인했다.

- Item ASCII presentation: 3/3 통과
- Party companion AI: 37/37 통과
- Item core: 12/13 통과. 기존 레거시 파티 스키마 마이그레이션 1개 테스트가 `invalid_party_encounter_keys`로 실패했다.
- Phase 4: 87/93 통과. 기존 제품 UI·스키마 진행 변경과 관련된 실패가 남아 있다.
- Product 전체: 실행 및 파싱은 완료됐고, 기존 진행 중인 UI/시각 회귀 실패가 포함되어 전체 통과 기준으로 표시하지 않았다.

## 알려진 범위

- 기존 제품 시나리오의 기본 주변광은 회귀 호환을 위해 유지했다. 횃불 광원과 실제 어두운 조명 프로필의 결합은 3단계 테스트에서 검증하며, 어두운 원정 프로필 튜닝은 후속 검토 대상이다.
- 횃불은 현재 자동 교체·자동 재점화를 하지 않는다. 소진 뒤 `torch_depleted` 상태와 한 번의 알림만 제공한다.
- 식량·포션·횃불을 카드로 편집하는 원정 준비 UI와 어둠 스트레스 누적은 각각 4·5단계 범위로 남겨 두었다.
