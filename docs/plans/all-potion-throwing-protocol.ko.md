# 전 포션 투척 protocol

## 목표

모든 포션을 직접 마시거나 시야 내 대상에게 던질 수 있게 하고, 명중 대상에게 포션 본래 효과를 동일하게 적용한다.

## 규칙

- 포션 사용자는 공용 가방 대상 선택에서 먼저 고른다.
- 사용 방식은 `직접 마시기` 또는 5칸 이내 보이는 생명체를 향한 `투척`이다.
- 아군과 적군 모두 투척 대상이 될 수 있다.
- 회복 포션은 대상 HP, 마력 포션은 대상 MP, 강화·약화·독·정화 포션은 대상 상태에 적용한다.
- 미감정 포션도 대상을 고를 수 있지만 효과는 사용 전까지 공개하지 않는다.
- 이미 가득 찬 자원처럼 효과를 적용할 수 없는 대상이면 소모하지 않는다.
- 성공 시 한 개와 기존 포션 행동 시간을 소모하며 저장·재현 가능한 사건을 남긴다.

## 판정 기준

1. 일반 회복 포션과 모든 미감정 포션에 마시기·투척 선택지가 표시된다.
2. 회복·MP·강화·약화 계열이 선택 대상에게만 적용된다.
3. 투척자가 아닌 대상의 자원과 상태가 정확히 바뀐다.
4. 취소·무효 대상·효과 없음은 포션과 시간을 보존한다.
5. 기존 직접 사용과 미감정 판정, 저장 복원이 유지된다.
