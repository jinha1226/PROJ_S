# 최근 생성 탑뷰 64px 타일 적용 protocol

## 목표

탑뷰 그래픽 모드가 기존 0x72 16px 던전 타일 대신 최근 생성한 `topdown_tactical64_v1` 지형과 `topdown_walls_doors64_v1` 벽·문 에셋을 사용한다.

## 매핑

- 일반 바닥은 돌·금간 돌·이끼 돌을 좌표 기반으로 안정적으로 섞는다.
- 흙, 풀, 잔해, 얕은 물, 깊은 물, 철판, 가시, 용암은 같은 이름의 64px 타일에 대응한다.
- 1층 벽은 돌·이끼 돌·폐허 돌, 2층 벽은 벽돌·철·자연암 계열을 좌표 기반으로 섞는다.
- 닫힌 문과 열린 문은 `door_closed`, `door_open`에 대응하며 주변 통로 방향으로 가로·세로 이미지를 선택한다.
- 기둥, 낮은 엄폐물, 상자, 출구 룬은 관측 데이터에 같은 지형·기능 ID가 있을 때 해당 이미지를 사용한다.

## 불변 조건

- 탑뷰 모드에서만 새 정사각형 타일을 사용한다.
- 아이소메트릭 모드는 기존 `handcrafted64` 다이아몬드 타일을 유지한다.
- 에셋 선택은 표현 전용이며 이동 가능 여부, 시야, 문 상태와 저장 데이터는 변경하지 않는다.
- MEMORY 셀은 같은 타일을 어둡고 저채도로 표시하고 UNSEEN 셀은 그리지 않는다.

## 검증

각 권위 지형 ID가 올바른 64×64 텍스처로 결정되는지, 문 방향과 상태가 구분되는지, 좌표 매핑과 시뮬레이션 데이터가 바뀌지 않는지 검사한다.
