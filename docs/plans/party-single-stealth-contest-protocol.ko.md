# 파티 단일 은신 판정 protocol

## 목표

파티원 여러 명이 한 적의 시야에 들어와도 그 적의 인지 갱신은 한 번만 수행한다. 시야 안에서 가장 발각되기 쉬운 파티원을 대표로 삼아 거리와 실제 은신 수치를 반영한다.

## 규칙

- 인지 판정 단위는 `적 1명 × 인지 갱신 1회`다.
- 적의 공통 시야 판정을 통과한 배치 파티원만 대표 후보가 된다.
- 각 후보의 발각값은 기존 의심도 공식에 후보와의 거리 및 장비·특성에서 계산된 실제 은신 보너스를 넣어 계산한다.
- 의심도 증가량이 가장 큰 후보 한 명만 대표가 된다. 동률이면 거리, 엔티티 ID 순으로 고정해 저장·재현 결과를 안정적으로 유지한다.
- 대표가 아닌 파티원 수만큼 판정을 반복하거나 의심도를 합산하지 않는다.
- 인접 접촉의 기존 선제행동 여유와 즉시 추적 규칙은 유지하되, 대상 기록은 같은 대표 선정 결과를 사용한다.

## 판정 기준

1. 한 적이 파티원 3명을 동시에 보아도 의심도는 후보별 증가량의 최댓값만큼 한 번 증가한다.
2. 더 가까운 인원이 있어도 은신이 높아 덜 발각되면, 더 멀지만 발각값이 큰 인원이 대표가 된다.
3. 마지막 목격 위치와 인지 전환 사건의 대상은 대표 파티원을 가리킨다.
4. 단독 행동, 시야 차단, 인접 접촉, 저장·재현의 기존 동작이 유지된다.
