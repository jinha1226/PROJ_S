# 픽셀 월드 마커와 바닥 아이템 로그 protocol

## 목표

픽셀 타일·캐릭터 위에 표시되는 조작 피드백도 같은 픽셀 문법을 사용하고, 주인공이 바닥 아이템 칸에 도착하면 아이템 이름을 화면 기록에 알린다.

## 표시 규칙

- 이동·타겟·집중·위험·선택 표시는 원형 벡터 링 대신 정수 좌표의 각진 셀 테두리와 모서리 마커를 사용한다.
- 선 두께와 좌표는 화면 픽셀에 맞추고 안티앨리어싱을 사용하지 않는다.
- 바닥 아이템의 `+`는 원 안의 벡터 십자가 대신 어두운 정사각형 배지와 계단형 픽셀 십자가로 표시한다.
- 탑뷰는 정사각형 셀, 아이소메트릭은 다이아몬드 셀 외곽을 따른다.
- 마커는 표현만 바꾸며 선택·명중·이동 판정은 변경하지 않는다.

## 아이템 기록

- 주인공이 아이템이 있는 칸에 도착하면 개수만 표시하지 않고 관측 가능한 아이템 이름을 함께 표시한다.
- 여러 종류는 중복 이름을 제거하고 쉼표로 연결한다.
- 이 문구는 즉시 피드백과 최근 사건 표시 양쪽에 전달한다.
- 미확인 아이템은 현재 아이템 DTO가 허용하는 표시 이름만 사용한다.

## 검증

마커 사양이 픽셀 정렬·비안티앨리어싱 계약을 지키는지, 바닥 아이템 안내가 실제 표시 이름과 개수를 포함하는지 검사한다.
