# SRPG 입력 및 재방문 수정 결과

상태: 완료

- 배치 허용 거리를 입구 기준 최대 2칸으로 코드와 표시 양쪽에서 제한했다. 배치 중 모든 활성 동료 초상화를 표시하고 동료 계획도 편집·확정한다.
- 캐릭터 선택 시 이동 범위, 목적지 선택 시 캐릭터 실루엣과 그 위치 기준 무기 공격 범위를 표시한다. 공격 범위의 적을 한 번 누르면 공격을 예약하고 적 머리 위 표식을 표시한다.
- 계획은 권한 상태를 바꾸지 않으며 `턴 종료` 때 이동과 공격 속도 예산의 공격을 함께 실행한다.
- 획득 이력이 있는 층 식량은 재생성하지 않는다. 동적으로 다시 계산되는 자원 채집 지점을 아이템 별표와 분리해 재방문 때 아이템이 살아난 것처럼 보이던 표시도 제거했다.

검증: `stage_counterplay_acceptance`, `srpg_party_turns_acceptance`, `stage_context_ui_acceptance`(360×800 X11), `srpg_item_projection_acceptance`, Web export 통과.
