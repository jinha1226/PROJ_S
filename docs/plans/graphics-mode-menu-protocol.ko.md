# 그래픽 모드 메뉴 protocol

## 목표

게임 메뉴에서 탑뷰와 기존 아이소메트릭 표현을 즉시 전환하고 다음 실행에도 선택을 유지한다.

## 규칙

- 메인 메뉴에 현재 모드를 함께 표시하는 `그래픽 · 탑뷰/아이소메트릭` 항목을 둔다.
- 항목을 누를 때마다 `FLAT_2D`와 `DIORAMA_2_5D`를 전환한다.
- 전환은 현재 `PartyGridView` 인스턴스에 즉시 적용하며 월드 시간, 사건, 명령 기록을 바꾸지 않는다.
- 선택값은 별도 `user://` 설정 파일에 저장하고 새 UI 인스턴스에서 복원한다.
- 알 수 없는 설정값이나 읽기 실패는 탑뷰를 기본값으로 사용한다.
- 전환 뒤 메뉴 문구도 현재 모드와 일치하게 갱신한다.

## 판정 기준

1. 메뉴에 그래픽 모드 항목이 보인다.
2. 한 번 누르면 아이소메트릭, 다시 누르면 탑뷰로 즉시 바뀐다.
3. 전환 전후 시뮬레이션 스냅샷과 명령 기록이 같다.
4. 새 UI 인스턴스가 마지막 선택 모드를 복원한다.
