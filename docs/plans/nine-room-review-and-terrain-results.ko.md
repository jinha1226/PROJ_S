# 9방·개인 휴식 재검증 및 64픽셀 타일 연결

기준 commit: `a81b4ab`. 검토 대상 구현은 `07eb953`/`7371ca8`의 9방 구조와
`c94786a`의 개인별 휴식이다. 기존 미추적 import/uid/Blender 백업은 보존했다.

## 계획 대비 결과

- 상위 계획의 8×8×9방, 방 경계 이동·후퇴·추격, 저장 유지: 재실행한 핵심 검사 통과.
- 후속 계획의 식량을 사용하는 개인별 휴식: 검사 통과. 비전투 대기/이동의 무소모·무회복,
  실제 전투 MOVE/HOLD 회복, 고정 휴식 비용, 부상 보정, 조직 회복 및 저장/저널 복원을 확인했다.
- 입구 2칸 내 자유 배치, 신규 궁수 공통 사선 처리, 보급 상자 보호전은 **아직 미구현**이다.
  기존 결과 문서도 이 기능을 완료 범위에서 제외했다. 전체 후속 계획이 완성된 것은 아니다.
- 현재 검사에서 구현된 범위의 차단성 실패는 재현되지 않았다. 아래 실행 범위 밖의 모든
  전투·소비품·환경 조합을 검증했다는 의미는 아니다.

## 타일 적용

- HTML에서 승인한 64픽셀 원본을 실제 Godot 에셋 의존성으로 복사했다.
- 현재 방의 공개 DTO에 `biome`을 전달해 던전/동굴/숲 테마를 연결했다.
  테마가 없는 안전방 등은 던전을 기본값으로 사용한다. 다른 방의 숨겨진 정보를 조회하지 않는다.
- 바닥 4종은 좌표 기반 고정 선택, 물은 별도 타일이다. 적 사망·아이템 생성·재방문으로
  무늬가 바뀌지 않는다. 이미지의 이미 기울어진 마름모를 다시 사각 UV로 투영하지 않는다.
- 던전은 승인한 벽면 텍스처, 동굴은 암반, 숲은 나무 장애물을 사용한다.
  기존 시야/메모리·충돌·경로·전투 규칙은 유지한다.
- 64×32 바닥, 64×64 장애물, 32×48 벽면 샘플을 공유 캐시로 유지하고 nearest로 출력한다.
- HTML의 장식용 문·상자·횃불은 이번에 가짜 상호작용 오브젝트로 복제하지 않았다.
  외곽 장식의 전체 이식, 캐릭터/아이템 교체, 조명/UI 재디자인도 이번 범위 밖이다.
- HTML 미리보기 폴더에 `.gdignore`를 추가했다. 실제 게임 참조가 없음을 확인했고,
  개발용 `.blend`가 CI에서 Blender 임포트를 요구하는 문제를 차단한다. HTML에는 영향이 없다.

## 검증

Godot 4.6.2. 작업 폴더에서 휴식·전환·전투 검사를 실행하고, NTFS 임포트 지연을 피하기 위해
기준 commit의 게임 파일을 `/tmp/handcrafted-runtime-review-ReMPKf`에 펼친 뒤 이번 수정 파일을
덮어쓴 검증본에서도 검사했다. 기존 Linux 임포트 캐시는 재사용하고 에디터 임포트로 갱신했다.

| 검사 | 결과 |
|---|---|
| `nine_room_care_acceptance.gd` | PASS — 개인 회복·비용·부상·스냅샷 |
| `nine_room_care_replay.gd` | PASS — 이동→교전→후퇴→휴식, UI와 저널 재생 |
| `nine_room_generation.gd` | PASS — 100 seed × 2층 |
| `handcrafted_rooms_acceptance.gd` | PASS — 수작업 방 연결성과 배치 |
| `nine_room_transitions.gd` | PASS — 전환/왕복/보존 |
| `nine_room_combat.gd` | PASS — 후퇴·추격·기존 적 기회 |
| `handcrafted_tile_assets_acceptance.gd` | PASS — 픽셀 크기·투명 모서리·변형·캐시·3테마 렌더러 |
| `nine_room_ui.gd` | PASS — 360×800/390×844, 타일 좌표·5버튼·실제 방 테마 전달 |

UI 검사는 논리 viewport와 content scale 크기를 함께 설정하도록 보완했다.
OpenGL Compatibility/llvmpipe에서도 UI 검사를 통과했고 실제 숲 전투 화면을 캡처하여
바닥·나무·예고 타일의 정렬을 육안 확인했다. `--capture` 인자로 재현할 수 있다.
[실행 화면](nine-room-handcrafted64-runtime.png).

환경 이슈: 동시 Godot 프로세스의 기본 로그 회전에서 한 번 엔진이 종료되어 해당 검사를
고유 `--log-file` 경로로 재실행했고 통과했다. Linux 에디터 실행에는 sandbox 소켓/설정 저장
권한 경고가 있었다. 게임 테스트의 스크립트 파싱 오류는 없었다.

실제 휴대폰/웹 export 및 성능 수치 재측정은 하지 않았다. 이 결과로 모바일 프레임 성능이나
전체 HTML 목업과의 완전한 시각적 동일성을 보장하지 않는다. 푸시는 별도 요청 전까지 하지 않는다.
