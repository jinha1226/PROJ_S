# 화면 밖 NPC 행동 로그 protocol

## 목표

던전에서 파티가 볼 수 없는 먼 NPC의 행동과 그 결과를 화면 로그에 표시하지 않는다.

## 규칙

- 원본 월드 사건은 시뮬레이션, 저장, 재현을 위해 그대로 보존한다.
- 필드 진행 중 파티원이 관여하지 않은 NPC 사건은 사건 위치가 현재 파티 시야에 있을 때만 주요 로그에 포함한다.
- 공격처럼 NPC가 시작했더라도 대상이나 원인이 파티원이면 파티 관련 사건으로 보고 표시한다.
- 파티원 행동과 위치가 없는 전역 진행 사건, 마을에서 발생한 사건은 기존대로 표시한다.
- 장비뿐 아니라 공격, 피해, 상태, 아이템 사용 등 주요 로그 대상인 모든 NPC 사건에 같은 필터를 적용한다.

## 판정 기준

1. 화면 밖 NPC의 장비·공격·피해 사건이 최근 사건 로그와 전투 로그에 나타나지 않는다.
2. 같은 종류의 사건이 파티 시야 안에서 발생하면 표시된다.
3. 화면 밖에서 NPC가 파티원을 공격한 사건은 표시된다.
4. 필터 전후 월드 사건과 저장 스냅샷은 바뀌지 않는다.
