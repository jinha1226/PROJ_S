# 육체 상태 압축 및 필드 보조 패널 제거 protocol

## 목표

상태창의 육체 정보를 손상 중심의 한 줄 요약으로 줄이고, 필드 지도를 가리는 주변 인물 보조 UI를 제거한다.

## 규칙

- 육체 상태는 전신 부위의 각 조직층에서 가장 낮은 내구도를 사용한다.
- 조직층 이름은 `피부`, `근육`, `뼈`로 표시한다.
- 내구도 1000은 정상으로 보고 표시하지 않는다.
- 손상된 조직층은 남은 내구도에 따라 `상`(700~999), `중`(350~699), `하`(0~349)로 표시하며 한 줄에서 ` · `로 구분한다.
- 필드 오른쪽 아래의 몬스터·NPC 목록은 그리지 않고 입력 영역도 만들지 않는다.
- 필드 왼쪽 위의 가까운 NPC 상세 카드는 갱신하거나 표시하지 않는다.
- 지도 위 인물 직접 선택과 정식 상세 모달, 대화·전투의 시뮬레이션 기능은 유지한다.

## 판정 기준

1. 정상 신체는 피부·근육·뼈 상태 문구를 출력하지 않는다.
2. 서로 다른 손상도의 피부·근육·뼈가 정확히 한 줄의 상·중·하 문구로 출력된다.
3. 주변 인물 목록의 그리기 사양은 항상 숨김이고 지도 입력을 가로채지 않는다.
4. 가까운 NPC 카드가 탐험 중에도 표시되지 않는다.
