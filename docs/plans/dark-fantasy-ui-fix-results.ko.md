# 원정 화면과 지도 연결 수정

- 방 선택 패널을 CenterContainer에 배치하고 긴 방 이름이 지도 너비를 늘리지 않도록 했다.
- 실제 지도에서 완료된 전투방을 원정 진행에 반영한다. 완료한 층/방 키를 저장하여 재방문 중복 집계를 막고 CLEAR_STAGE 명령의 저장·재생을 연결했다.
- 지도에 캠프 진입, 동료별 회복/진정/부상 치료, 캠프 종료를 연결했다. 캠프를 건너뛰고 이동하면 기회는 소멸한다.
- 새 원정의 철수 버튼은 새 정산 경로를 사용하며, 세 전투 완료 시 완주 결과와 생존자 상태를 표시한다. 정산 후 추가 방 이동을 차단한다.
- 지도 표시 중 보드 클릭과 직접 전투 실행을 차단한다.
- Pages 빌드에서 명시적인 --import 단계를 사용해 리소스 임포트 후 내보내도록 했다. 로컬의 기존 누락 임포트 캐시는 이 코드 변경만으로 복구되지 않으며 에디터 임포트가 필요하다.

검증: git diff --check 및 호출/저장/재생 경로 정적 검토. 사용자 요청에 따라 Godot 실행 검증은 수행하지 않았다. 실제 화면 동작과 배포 성공은 확인하지 않았다.

기존 계획의 Death Token 사망 통합·구조 물자 UI·거점 치료 경제 등 미구현 범위는 이번 수정에 포함되지 않는다. 철수/완주는 원정 결과 화면에서 종료된다.
