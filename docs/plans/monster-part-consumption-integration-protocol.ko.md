# 몬스터 특수 부위 섭취·이능 획득 통합 protocol

## 목표

몬스터 사망 시 확률적으로 떨어지는 특수 부위를 줍고, 공용 가방에서 `먹기`를 눌러 파티원을 선택하면 그 캐릭터가 대응 이능을 습득하도록 실제 UI 흐름을 완성한다.

## 범위

- 기존 16종 종족별 특수 부위 드롭 테이블과 시체 드롭 물질화를 유지한다.
- 특수 부위를 아이템창에서 사용 가능한 소비 아이템으로 표시한다.
- 설명에 획득 이능과 패시브·액티브 효과를 표시한다.
- 먹일 캐릭터 선택창을 열고, 성공 시 부위 한 개를 소모해 선택 캐릭터에게만 이능을 귀속한다.
- 중복 습득, 슬롯 부족, 전투 중 사용은 기존 거부 규칙과 무소모 롤백을 유지한다.

## 판정 기준

1. 16종 몬스터의 특수 부위가 실제 사망 드롭 후보로 존재한다.
2. 드롭된 부위를 일반 줍기 경로로 가방에 넣을 수 있다.
3. 아이템 상세창에 `먹기` 버튼과 이능 설명이 표시된다.
4. 대상 선택 후 해당 캐릭터만 이능을 얻고 부위는 한 개 소모된다.
5. 저장·불러오기와 기존 파티 공용 가방 검증이 통과한다.
