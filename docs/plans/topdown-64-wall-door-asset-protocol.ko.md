# 탑뷰 64px 벽·문 에셋 제작 protocol

## 목표

`topdown_tactical64_v1` 지형과 같은 색감·명암·탑뷰 시점으로 벽 재질과 문 개폐 상태를 추가한다.

## 4×4 구성

1. 석벽, 이끼 석벽, 벽돌벽, 붕괴 석벽
2. 목재 벽, 보강 목재 벽, 철제 벽, 자연 암벽
3. 석조 가로 닫힌 문, 석조 가로 열린 문, 석조 세로 닫힌 문, 석조 세로 열린 문
4. 목재 가로 닫힌 문, 목재 가로 열린 문, 목재 세로 닫힌 문, 목재 세로 열린 문

## 판정 기준

- 개별 타일 16개는 각각 정확히 64×64이다.
- 아틀라스는 정확히 256×256인 4×4 배열이다.
- 벽은 바닥보다 밝은 상단 테두리와 깊은 측면/접지 그림자로 통행 불가임을 나타낸다.
- 닫힌 문은 문짝이 통로를 가로막고, 열린 문은 문짝이 벽 옆으로 젖혀져 중앙 통로가 보인다.
- 가로·세로 방향과 석조·목재 재질이 작은 화면에서도 구분된다.
