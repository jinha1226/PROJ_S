# 전체 맵 아이소메트릭 전환 protocol

## 목표

현재 원정의 80×80/96×96 전체 맵, 시야, 이동, 전투 규칙을 그대로 유지하면서 그래픽 메뉴에서 정사각형 탑뷰와 2:1 다이아몬드 아이소메트릭 화면을 전환한다.

## 범위

- 예전 8×8 전술 방에 쓰였던 다이아몬드 좌표 투영과 역투영만 복원한다.
- 방 크기 8×8 고정, 방 경계 카메라, 스테이지 이동 제한은 복원하지 않는다.
- 아이소메트릭에서도 현재 주인공 중심 카메라와 현재 확대 단계가 전체 맵을 따라 이동한다.
- 렌더링 좌표와 터치 좌표만 변환하며 시뮬레이션의 정수 격자 좌표는 바꾸지 않는다.
- 기존 `DIORAMA_2_5D`는 경사 탑뷰로 취급한다. 제품 메뉴는 `FLAT_2D`와 `TACTICAL_ISOMETRIC`을 전환한다.
- 기존 메뉴에서 아이소메트릭을 선택해 저장된 `DIORAMA_2_5D` 값은 실제 아이소메트릭 모드로 이전한다.

## 판정 기준

1. 메뉴가 `그래픽 · 탑뷰/아이소메트릭`을 정확히 표시한다.
2. 아이소메트릭에서 X축과 Y축 이동이 서로 반대의 화면 가로 방향을 가지며 두 축 모두 아래 방향으로 진행한다.
3. 화면 좌표를 다시 터치 좌표로 역변환하면 같은 전체 맵 셀을 선택한다.
4. 전환 전후 세계 크기, 관측 데이터, 진행 기록은 변하지 않는다.
5. 8×8 방 정보가 없어도 아이소메트릭 투영이 작동한다.

## 종료 범위

좌표 투영, 입력 역변환, 메뉴 및 설정 이전, 회귀 검증까지만 수행한다. 새 아이소메트릭 전용 64px 지형 에셋 제작은 별도 작업으로 둔다.
