# 파티 소비 아이템 대상 선택 UI 점검 protocol

## 질문

공용 가방의 물약·음식·특수 부위를 사용할 때 대상 선택창에서 고른 파티원에게만 효과가 적용되고, 취소나 사용할 수 없는 대상 선택은 아이템을 소모하지 않는가?

## 범위

- 현재 `feat/legacy-shell-new-core`의 아이템 상세창과 `ConsumableTargetPicker` 경로를 사용한다.
- 회복 물약을 주인공과 동료 중 동료에게 먹이는 실제 버튼 콜백을 검증한다.
- 대상 선택 취소 시 상태와 수량이 보존되는지 검증한다.
- 공용 가방의 소유자가 누구인지와 무관하게 선택한 수령자에게 적용되는지 검증한다.
- 점검 중 발견된 실행 차단 오류와 대상 선택 오류만 수정한다.

## 판정 기준

1. 프로젝트와 대상 UI 테스트가 Godot 4.6.2에서 컴파일된다.
2. 사용 버튼을 누르면 배치된 파티원별 대상 버튼이 열린다.
3. 동료 버튼을 누르면 동료 HP만 회복되고 주인공 HP는 변하지 않는다.
4. 아이템 수량은 성공 시 한 개만 줄고, 취소 또는 거부 시 유지된다.
5. 기존 파티 성장·공용 가방 및 미감정 아이템 UI 테스트가 함께 통과한다.
