# 1층 9개 방 구현 결과

## 적용 범위

- 1층은 고정 설계된 8×8 방 9개를 3×3으로 연결한다. 출구 방향으로 이동하면 기존 방 전환 규칙을 사용한다.
- 승인된 64픽셀 던전·동굴·숲 타일을 그대로 사용한다. 방 이름과 진입 안내를 표시한다.
- HP, 피해, 피부·근육·뼈 및 부상·회복 공식은 변경하지 않았다.
- 방 전체 공개, 적의 즉시 인식, 일부 적의 방 간 추격은 유지한다.
- 일반 NPC 생성은 중단한다. 새 게임에서 동쪽 이벤트방에 레아 한 명만 등장하고, 식량 지원 후 기존 합류 절차로 동료가 된다. 2층에는 새 독립 NPC를 배치하지 않는다.

## 배치

| 북서 | 북 | 북동 |
|---|---|---|
| 무너진 감시소: 전투·회복약 | 깊은 곳으로 향하는 계단: 2층 이동 | 갈라진 제단: 전투·감정 스크롤 |
| 갈라진 샘: 얕은 물·식량 | 빛이 남은 입구: 시작·방패·방어구·식량 | 홀로 남은 탐험가: 레아·식량 |
| 뿌리 덮인 저장터: 전투·식량 | 무너진 경비실: 전투·회복약 | 물에 잠긴 보급고: 얕은 물·보급 |

중앙 입구에서는 서쪽·동쪽·남쪽으로 나간다. 중앙과 북쪽 계단방 사이에는 직접 연결이 없고, 동서 측면을 돌아서 접근한다. 나머지 인접 방들은 연결된다.

전투방은 4곳, 각각 고블린·코볼트·쥐 3마리로 총 12마리다. 지형과 출발 위치가 다르며, 이번 변경에서 신규 궁수 AI나 보급품 보호 승리 조건을 추가하지는 않았다. 모든 방을 클리어해야 계단을 이용하는 제한도 추가하지 않았다. 2층 지형은 기존 생성 방식을 유지한다.

## 저장 호환성

방 생성 버전은 2다. 이전 버전 저장을 새 지형에 잘못 덮어 씌우지 않도록 불러오기에서 새 게임이 필요하다는 안내를 반환한다. 저장 파일 자체는 삭제하지 않는다. 이번 1층은 **새 게임**으로 테스트한다.

## 검증 및 한계

- 100개 시드 × 2개 층 생성: 방 연결성·출구 접근·역할 개수 검증 통과.
- 실제 종족 선택 진입: 5종족 출발 검증 통과.
- 신규 이벤트: NPC 정확히 한 명, 이벤트방 대기, 식량 지원, 합류, 중복 합류 방지, 저장·재생 일치 검증 통과.
- 기존 방 전환·추격·전투·UI 및 타일 템플릿 검증 통과.
- 단순 솔로 정책으로 전체 순회를 시도한 진단에서는 두 번째 전투방에서 사망했다. 해당 정책은 장비·물약·동료를 사용하지 않는다. 전체 클리어 가능성이나 적정 난이도를 입증한 결과가 아니며, 수치를 바꿔 성공을 강제하지 않았다.
- 재현용 `tests/first_floor_solo_balance_probe.gd`는 필수 통과 테스트가 아닌 난이도 진단이다. 사망하면 실패 코드로 종료한다.
- 브라우저·실기기 터치 플레이의 전체 1층 클리어는 아직 검증하지 않았다.

권장 테스트 순서는 입구 보급 확인 → 동쪽 레아에게 식량 지원·합류 → 전투방 탐험 → 북쪽 계단이다. 생존·휴식·부상 누적 난이도는 실제 플레이 후 별도로 조정한다.
