# 탑뷰 64px 지형 에셋 제작 protocol

## 목표

기존 `illustrated_front/terrain.png`의 어두운 석재 질감과 색감을 유지하면서 모바일 탑뷰 전투에서 지형 기능이 즉시 구분되는 64px 정사각형 타일 세트를 만든다.

## 구성

4×4 배열을 다음 순서로 고정한다.

1. 기본 석재, 균열 석재, 이끼 석재, 흙
2. 풀, 잔해, 얕은 물, 깊은 물
3. 석벽 상단, 원형 기둥, 낮은 엄폐물, 나무 상자
4. 철판, 가시 함정, 출구 룬, 용암

## 산출물

- 생성 원본 타일시트
- 정확히 64×64인 개별 PNG 16개
- 개별 타일을 결합한 정확히 256×256인 런타임 아틀라스
- 4배 최근접 확대 검토 이미지
- 타일 순서와 용도를 기록한 manifest

## 판정 기준

- 모든 개별 타일은 64×64이며 알파가 아닌 완전한 정사각형 배경을 가진다.
- 아틀라스는 256×256이고 4×4 셀 경계가 정확하다.
- 물은 청색, 위험 지형은 청록 또는 주황 강조색으로 일반 바닥과 구분된다.
- 기둥·엄폐물·상자는 탑뷰 실루엣과 접지 그림자로 통행 불가/엄폐물임을 알아볼 수 있다.
- 글자, 캐릭터, UI, 아이소메트릭 투시가 없다.
