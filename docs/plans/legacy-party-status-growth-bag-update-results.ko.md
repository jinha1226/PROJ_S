# 기존 필드 전투용 파티 UI 업데이트 결과

상태: 완료

- `991c8f6`의 연속 필드 턴과 탑뷰 구조를 유지했다. 방 배치, 계획형 라운드, SRPG 이동 코드는 추가하지 않았다.
- 선택한 동료의 상태창에 해당 동료의 레벨, 경험치, 전투 수치, 장비를 표시한다. 아이템 비교 수치도 현재 보고 있는 동료의 능력치와 숙련을 사용한다.
- 동료가 독립된 근접·원거리·마법·방어 숙련과 이능 결속 상태를 가지며 저장·로드 저널에 포함된다.
- 파티의 미장착 아이템은 공용 목록과 하나의 용량을 사용한다. 장착 슬롯은 인물별로 유지하며 공용 아이템을 선택한 동료에게 장착하거나 사용한다.
- 음식, 포션, 특수 부위의 수령 대상을 동료로 지정할 수 있고 실패한 전달·사용은 원자적으로 롤백한다.

검증 통과: `party_growth_bag_acceptance`, `growth_ui_acceptance`, `character_views_acceptance`, `field_turn_ui_acceptance`, `solo_start_acceptance`.
