# 싱글 플레이 조작·탐험·24px 그래픽 수정

기준 커밋: `dc18bd4`. 2026-09-10 작업.

## 확인한 원인과 변경

1. 방어: 기존 근접/무기 HP 계산에는 이미 25% 감소가 있었다. 하지만 부상 계산은 방어 전 `base_damage`를 다시 사용했다. 새 규칙에서는 부상 입력에서도 `guard_reduction`을 차감한다. 피해 숫자에는 `(방어 -N)`을 함께 표시한다. 불·출혈 등 모든 피해에 무조건 방어 감소를 적용하는 변경은 아니다.
2. 휴식: 원래 HP·MP가 모두 찰 때까지 반복하는 매크로였으나 던전 전체의 경계 중인 적이 회복을 막았다. 새 규칙은 살아 있는 적 중 8칸 이내 위협만 회복을 막는다. 직접 피해, 적 발견, 굶주림, 위험한 지형/상태이상은 계속 중단 사유다. 버튼의 작은 손떨림도 취소로 처리하지 않도록 터치 허용 폭을 24px로 늘렸다.
3. 물약: 물약 효과보다 먼저 시간을 진행해 자연 회복 또는 적 공격 뒤 사용이 거절될 수 있었다. 새 규칙은 물약 소비·회복을 먼저 확정하고 100시간 동안 세계가 반응한다. 실패 시 전체 거래를 롤백한다. 실제 화면의 사용 버튼을 16px 흔들린 터치로 눌러 소비 1회와 저장 재생을 확인했다.
4. 혼자일 때 초상화: HP·MP·스트레스 3색 막대와 기존 수치를 함께 그린다. 스트레스 최대값은 1000이며, 다인 파티의 압축 표시와 선택 강조는 유지한다.
5. 활: 깨끗한 새 게임에서는 장착 API와 고정 터치 모두 정상임을 확인했다. 아이템 팝업 버튼의 12px 이동 취소가 손떨림에 취약해 버튼 동작은 24px 허용으로 바꿨다. 스크롤 영역 자체의 이동 임계값은 유지했다. 실제 터치로 기존 무기에서 활로 교체하는 회귀 테스트를 추가했다. 필요 스탯 제한은 제거하지 않았다.
6. 독립 NPC: 기존 목표는 자신의 주변 2칸짜리 세 지점이었다. 도달 가능한 방 중심을 골라 최대 8개 탐색 목표를 저장한다. 화면에서 멀어도 300시간 단위로 진행하며, 주변 NPC의 정상 이동·전투·귀환·성격 판단은 유지한다. 다음 최대 8걸음만 저장·재검증해 매 걸음 전체 경로를 다시 찾는 비용을 줄였다.
7. 미니맵: 전체 지도가 먼저 소비한 갱신분 때문에 작은 지도가 전체 재구축으로 돌아갈 수 있었다. 화면 표시용 정렬 목록과 별도로 발견 순서 목록을 제공해 소비자별 커서를 유지한다. 전체 지도 열기는 불필요한 상세 게임 화면 DTO도 만들지 않는다. 지도는 닫힌 상태에서 프레임 처리하지 않는다.

## 저장 호환성

`campaign.living_expedition_initialized.version = 4`인 **새 게임/재시작**에 부상 방어·물약 선적용·근거리 회복 위협·확장 NPC 탐험을 적용한다. 기존 version 3 저장은 원래 규칙으로 정확히 재생하며 강제로 변환하지 않는다. 입력·초상화·미니맵·그래픽은 기존 저장에도 적용된다. 새 게임으로 새 시뮬레이션 규칙을 테스트해야 한다.

## 그래픽

- 인간의 기존 8방향 유지, 엘프·드워프·오크·수인·코볼트·슬라임·딱정벌레의 8방향 연결. 총 8종/64방향. **고블린은 생성 도구 두 차례 실패로 정면 유지, 미완료**.
- 모든 연결된 캐릭터 방향은 실제 24×24 텍스처. 정면은 기존 파일 내용 그대로 유지한다. 큰 생성 이미지는 실행 중 사용하지 않는다.
- 평면 게임 화면의 벽 연결 문자와 바닥 재질 문자를 제거하고 타일 이미지로 표현한다. 횃불·출입구·문·우물·유물·핏자국·물·기름·얼음·수증기·연기·가스·불꽃·타격/사망 입자도 이미지 경로로 연결했다.
- 숫자·이름·경고와 경로 화살표 같은 UI 표시는 문자로 남긴다. 개발용 ASCII 투영 모드는 제거하지 않는다. 생성한 24개 효과/소품 중 일부는 후속 용도의 예비 칸이며, 모두가 매 화면에 등장하는 것은 아니다.
- 이미지 생성 스킬의 기본 내장 도구를 사용했다. [에셋 안내](../assets/pixel24_v4/README.md), [전체 프롬프트 세트](../assets/pixel24_v4/PROMPTS.md).

## 검증

- 새 `solo_gameplay_acceptance`: 활·물약 실제 터치와 손떨림, 자동 MP 회복, 1인 막대 영역, 지도 반복 토글/누락 갱신분, 실제 방어 버튼의 HP 감소, version 4 및 기존 version 3 저장 재생. X11에서도 통과.
- 새 `eight_way_visual_acceptance`: 8종×8방향 매핑, 서로 다른 이미지, 24×24 크기, 여백, 자원 막대 비율, 24개 소품 크기 통과. X11 캡처 검토.
- field turn, lifecycle, solo start, input recovery, portrait skills, pixel24 asset, field UI, environment VFX 기존 수용 테스트 통과.
- body injury 4/4, growth/recovery 6/6, minimap 9/9, full map 8/8 통과. 지도 테스트의 옛 UI 스타일 이름 기대값은 현재 공통 스킨 상수로 정정했다. 기존 minimap 테스트에는 테스트 노드 해제 누락 경고가 남아 있다.
- 새 경로 캐시 적용 뒤 headless 단일 실행 참고 측정: 6회 대기 기준 지도 토글 전 542,814µs, 5회 열기/닫기 뒤 490,633µs. 작은 지도 재구축 횟수는 계속 1회. NPC 처리 평균은 각각 33,015µs / 18,187µs. 이는 서로 다른 세계 시간대의 측정으로 엄밀한 A/B 성능 비교나 모바일 FPS 보장은 아니다.

- Web release 내보내기 종료 코드 0. 소스가 없는 별도 임시 폴더에서 배포 PCK 단독 실행도 종료 코드 0이며 스크립트/리소스 오류가 없었다.
