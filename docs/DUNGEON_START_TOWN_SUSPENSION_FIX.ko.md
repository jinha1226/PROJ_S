# 새 원정 시작의 마을 생활 경로 제거

2026-09-16 · 기준 56a19a2. 사용자 요청: 정착지·마을 시스템 비활성화 상태에서 새 원정 시작 실패 수정.

## 원인

종족 선택은 새 던전 세계를 만든 뒤에도 `town_life_command(START)`와 `depart_town()`을 무조건 실행했다. 정착지 플래그는 frontier 인자와 일부 UI만 제한했다. 새 원정의 구조 규칙 활성화가 command journal에 기록되므로, 여관 서비스의 빈 journal 조건에 걸려 `town_life_started`로 거절됐다. 이미 던전은 만들어졌지만 선택 창은 오류 상태로 남았다.

## 변경

- 제품용 `TOWN_ENABLED=false`를 명시했다. 비활성 상태에서는 여관 초기화·마을 출발을 전혀 호출하지 않고 생성된 던전 1층으로 바로 시작한다.
- 마을 생활·서비스 UI 명령을 차단했다. 기존 마을 저장 상태의 화면은 마을 서비스 대신 새 원정 시작을 제공한다. 저장 데이터와 레거시 서비스 구현은 보존한다.
- 다섯 종족의 실제 터치/마우스 선택 검사에 오류 없는 창 닫기, 지도 잠금 해제, 마을 생활 및 frontier 비활성, 마을 명령 부재를 추가했다.
- 이 새 원정 진입 검사를 Pages Actions에 추가해, 단순 초기 화면 실행만 통과하는 배포를 방지한다.
