# 공통 전투 코어 실제 게임 연결

## 적용 범위

기본 게임 던전의 field turn 경로와 원형이 `sim/combat_kernel.gd`를 함께 사용한다.
별도 테스트 화면으로 기본 게임을 대체한 것이 아니다. 기존 화면의 직접 이동,
자동이동의 각 걸음, 공격, 대기, 기술은 기존 field 진입점을 통해 새 실행 루프로 들어간다.
기본 웹 주소가 실제 게임이며 `?prototype=combat`는 같은 코어의 작은 조작 시험 장면이다.

## 교체한 부분

- 행동 실행 반복/시간 진행: `Kernel.advance`가 후보를 받아 시간 순으로 실행한다.
  행동 주체 선택의 동시간 순서는 `Kernel.earlier` 하나에서 처리한다.
  기존 게임의 환경/상태 tick은 주인공 다음 입력 시각 경계까지 처리한다.
- 이동/공격 지형 모서리: `Kernel.open_edge`와 `Kernel.sees` 사용.
  한쪽 벽 허용, 양쪽 벽 차단. 현장 적과 플레이어는 같은 이동 규칙을 사용한다.
- 현장 파티 시야: 종족별 표시 반경과 별도 감지 반경을 고정 6칸 유클리드 반경으로 통일.
  화면 공개와 파티 적 감지는 동일한 질의를 사용한다. 적 LOS도 같은 코어 사용.
- 원형에 중복되던 시간 루프/광선/모서리 구현 삭제.
- 원형 시야로 변경한 뒤에도 남아 있던 방향별 밝기 보간/메시 재생성 제거.

## 기존 데이터 연결

`field_turn_system.gd`는 캠페인 연결부다. 기존 WorldState, 행동 평가, 장비/육체 피해,
성격 기반 동료 제안, 사망/드롭, 사회적 사건, 환경 tick, rollback과 저장 journal을
연결한다. 피해 공식을 원형의 고정 피해로 바꾸지 않았다. 새 코어 자체는 이를 알지 못한다.
기존 캠페인 연결부와 구형 시나리오/마을의 legacy 실행 코드를 모두 삭제한 것은 아니다.
이번 작업은 운영 던전의 시간 실행과 기하/시야를 공통 코어로 교체한 범위다.

## 검증과 한계

- 원형 stage1/2: 입력 거절, 즉시 사망, 행동 비용, 시야/모서리, 재현성.
- 현장 통합: 실제 이동/공격/기술, 저장 재현, 환경 실패 rollback, 타일 공개/감지 일치.
- 실제 UI: 입력 없을 때 시간 정지, 대기/명령의 시간 소모, 동료 선택.
- 암흑 표시 회귀 검사.

새 규칙에서 생성한 저장의 재현은 검증한다. 모든 과거 버전 세이브의 경로와
전투 결과가 그대로 재현된다는 보장은 없다. 모바일 체감은 배포 후 확인이 필요하다.
현재 소스는 Pixel Dungeon/DCSS 코드를 복사한 포트가 아니라 독립 구현이다.
