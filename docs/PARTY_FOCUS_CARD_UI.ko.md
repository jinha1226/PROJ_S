# 몬스터 카드 집중 공격 UI

## 범위

- 왼쪽 상단 몬스터 카드를 탭하면 기존 `ATTACK_TARGET` 파티 전술을 지정한다.
- 스킬 대상 선택 중에는 기존 스킬 대상 선택이 우선한다.
- 전술 메뉴는 계속 사용할 수 있다. 명령 검증, 턴 비용과 동료 AI는 기존 규칙을 사용한다.
- 개인 공격 대상의 지속 테두리는 제거하고 파티 집중 표적만 표시한다.

## 표시와 터치

- 지정된 카드: 청록색 강조 및 `집중` 문구.
- 지정된 몬스터: 청록색 네 모서리 조준 표시와 상단 점. 지정 시 650ms 동안 조준 표시가 좁혀진다.
- 지속 표시는 유효한 파티 명령에서 읽는다. 다른 전술 지정, 표적 사망 등으로 집중 명령이 해제되면 제거한다.
- 맵 표시는 현재 관측된 개체에만 그린다. 화면 밖이나 시야 밖 개체의 위치를 드러내지 않는다.
- 화면 터치는 카드가 지도보다 먼저 처리한다. 같은 카드에서 탭을 완료해야 지정하며, 가로 드래그는 스크롤한다. 취소·다중 터치·에뮬레이션 마우스 중복으로 명령을 재발행하지 않는다.
- 이펙트 시간은 UI 시간만 사용하며 월드 시간, RNG, 사건 ID를 소비하지 않는다.

## 검증

- `tests/party_focus_card_acceptance.gd`: 통과. 390×800 화면 터치, 취소·스크롤 무발행, 명령 단일 발행, 개인 근접 공격과 구분, 카드/맵 표시, 효과 종료, 시야 밖 표시 숨김, 다른 명령으로 해제, 저장 재생.
- `tests/attack_button_acceptance.gd`: 통과. 기존 일반 공격 입력 및 저장 재생 회귀 검사.
- 실제 모바일 기기에서의 시각적 가독성과 손가락 스크롤 감각은 별도 확인이 필요하다.
