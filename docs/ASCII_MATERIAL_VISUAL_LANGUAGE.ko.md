# ASCII 재질형 2D 탑뷰 시각 언어

## 목표

메인 파티 화면은 익숙한 ASCII 문자를 사용하되, 각 글자의 색·겹침·미세 동작으로 물질감을 구분한다. 맵 전체에는 단일 중립 배경만 두고, 셀별 색 면·슬랩·벽 면·그림자·광원 원은 그리지 않는다. 이는 표현 계층일 뿐이며 시뮬레이션 지형, 충돌, FOV, 입력, 저장과 RNG를 바꾸지 않는다.

## 문자 문법

| 계층 | 문자 |
|---|---|
| 주인공 | `@` |
| 종족 | 인간 `h`, 고블린 `g`, 코볼트 `k`, 드워프 `d`, 엘프 `e`, 오크 `o`, 수인 `b`, 양서인 `a`, 슬라임 `s`, 미상 `?` |
| 사망 | `x` |
| 장비 | 무기 `/ \| 7 ! ^ ) +`, 방어구 `[ ]` |
| 인지 | 의심 `?`, 경계 `!`, 추적 `>`, 수색 `~`, 복귀 `<` |
| 구조물 | 입구 `<`, 잠긴 출구 `X`, 열린 출구 `>`, 열린 문 `/` |
| 지도 | 주인공 `@`, 위협 `!`, 출구 `>`, 벽 `#`, 바닥 `.` |

주인공은 종족과 무관하게 항상 `@`다. 파티원과 중립 인물은 종족 문자를 사용한다. 장비 문자는 몸체와 같은 셀에 정적으로 배치되며 클릭·충돌 영역을 바꾸지 않는다. 행위자와 적은 어두운 외곽선으로 지형에서 분리한다.

## 재질 규칙

| 재질 | 문자 | 동작 |
|---|---:|---|
| 바닥 | `.` | 정적 |
| 돌 | `:` | 정적 |
| 나무 | `=` | 정적 |
| 금속 | `+` | 정적 |
| 잔해 | `,` | 정적 |
| 벽 | `#` | 정적, 상하좌우 인접 벽의 중심 사이에도 표시용 `#` 추가 |
| 피 | `;` | 정적 |
| 얼음 | `*` | 정적 |
| 안개 | `.` | 정적 |
| 물 | `~` | 낮은 주기의 수평 흐름 |
| 풀 | `"` | 작은 좌우 흔들림 |
| 불 | `^` | 상하 흔들림과 점멸, 주변 글자 밝기 변화 |
| 독 | `%` | 맥동하며 조금 위로 떠오름 |

동작은 셀 좌표 해시로 위상을 어긋나게 하며 시뮬레이션 RNG를 소비하지 않는다. `VISIBLE` 셀만 움직이고 `MEMORY`는 같은 재질 문자를 정적으로 유지하며 `UNSEEN`은 아무 정보도 내보내지 않는다. 벽 사이의 추가 `#`도 두 끝이 같은 가시 상태일 때만 그리며 새 타일·충돌·클릭 영역을 만들지 않는다. 18셀 이상 와이드 줌에서는 모든 재질 동작을 고정하고, 가까운 화면에 움직이는 재질이 하나도 없으면 환경 타이머를 중지한다.

## 전투와 구현 경계

근접 공격은 무기 회전 대신 캐릭터 전체 범프, 대상 셀 타격선·섬광·파편, 히트스톱과 화면 흔들림을 사용한다. 활/쇠뇌를 장착하면 주 공격 버튼은 `[사격]`이 되며 각각 2–8칸/2–10칸에서 보이는 적을 공격한다. 쇠뇌는 사격 전 전투 조작부의 `[RELOAD]`로 장전한다. 아이템 행은 장비의 STR/DEX/INT 요구치를 표시한다. 모든 재질 동작과 광원은 글자의 위치·색·밝기만 바꾸며 이미지·셰이더나 셀 배경 도형을 요구하지 않는다. 선택적 `presentation_material_id`/`material_id`로 `grass`, `poison`, `ice`, `fog`를 표현할 수 있지만 권위 지형이나 세이브 형식으로 역전파하지 않는다.
