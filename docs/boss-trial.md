# 1인 보스 패턴 테스트

메인 화면은 `Session.new(seed, true, true)`로 주인공+동료 보스 시험 모드를 시작한다. `Session.new(seed, true)`는 1인 테스트다.
기존 3인 원정은 `Session.new(seed)`로 유지해 회귀 테스트에 사용한다.

- 3×3 연결 지도와 8×8 전장을 유지. 입구 포함 9개 방 모두 보스 한 마리.
- 전장은 정사각형 탑뷰. 캐릭터·벽·전력탑은 해당 타일 안에 표시한다. 보스 안내 영역은 없으며 대기는 하단 버튼 줄에 있다.
- 수렁 포식자 / 폭탄 암살자 / 과부하 거인을 방 번호 순서로 반복 배치.
- 수렁: 물 위에서 턴마다 3 회복. 인접 시에만 충전 가능. 주변 맨해튼 거리 2 폭발 예고.
- 암살자: 대상 위치 중심 3×3 폭탄 예고, 폭발 후 빈 모서리로 이동.
- 수렁/암살자는 최초 일반 행동 4회, 폭발 후 탈진 1회와 일반 행동 6회를 거쳐 다시 충전한다. 원작 그대로가 아닌 현재 전투용 조정이다. 밀치기로 차징이 취소된 경우에도 재충전 대기시간을 적용한다.
- 거인: 체력 절반 이하에서 한 번 보호막. 빛나는 전력탑과 인접한 뒤 탑을 터치하면 행동력 1로 파괴.
- 일반 행동은 8방향 한 칸 추격 후 사거리에 들어오면 같은 행동에 공격한다. 일반 피해 8, 강공격 피해 16. 강공격은 주황색 ! 칸에만 적중.
- 행동 기반 턴제: 한 칸 이동·공격·밀치기·방어·대기·아이템·전력탑 파괴 후 즉시 적과 환경이 한 번 진행한다. 공격 범위 내 적 터치 시 확인 버튼 없이 즉시 공격한다. 실패한 입력은 시간 소비 없음.
- AP 표시와 턴 종료 제거. 내부 행동 예산은 호환성을 위해 1로 유지하며 매 행동 자동 갱신한다.
- 넓은 폭발은 두 번의 플레이어 행동 후 발동해 한 칸씩 피할 수 있다.
- 승리 후 체력과 부상을 회복하는 시험용 편의 규칙. 원정 자원과 소모품은 유지.
- 원작의 모든 페이즈를 재현하지 않으며, 보스 외형은 기존 임시 자산을 사용.

패턴 참고: https://pixeldungeon.fandom.com/wiki/Shattered_Pixel_Dungeon/Bosses
원작 코드·아트는 복사하지 않고 패턴만 축약하여 독립 구현했다.
