# 주문 목록 (학파 5 × Lv1~10)

기준: `data/content/combat.json` `spells`/`books`/`summons`, `expedition/spells/spells.gd`. 이 문서는 데이터의 정리본이며, 수치는 데이터가 규범이다.

## 규칙

- **학파** 화염(fire) · 냉기(ice) · 기류(air) · 변이·제어(hex) · 소환(summon). 각 학파 Lv1~10, 주문 id는 `<학파>_<Lv>`.
- **MP**는 주문 데이터 기준(현재 학파 주문은 2 + Lv). **실패율** = `8 + Lv·9 + 둔중·5 − INT − 캐릭터 레벨·4 − 학파 영혼석 보정 10`(0~85%). 실패해도 MP는 쓴다. 확정 시전 효과는 별도 적용한다.
- **습득**: 관련 영혼석 흡수. 주문서·숙련 조건은 폐기했다. 영혼석마다 명시된 주문 중 요구 레벨 이하인 하나를 선택한다. 같은 종족의 부위도 독립 선택이다. 연결표는 [영혼석 마법 연결](soulstone-spells.ko.md).
- **선택**: 안전한 지역·야영지에서 변경. 흡수 시 첫 열린 주문을 자동 선택하고, 캐릭터 레벨업으로 잠긴 첫 주문이 열려도 자동 반영한다.
- **사용**: 여섯 영혼석의 선택 주문을 모두 사용한다. HUD 바로가기는 다섯 개, 기술 메뉴에는 여섯 번째 주문도 나타난다. 동일 주문은 중복 표시하지 않는다. 봉인된 영혼석의 주문은 사용할 수 없다.
- **성장**: 캐릭터 레벨이 주문 요구 레벨의 상한이다. 숙련 rank로 주문을 해금하지 않는다.
- **시간**: 100 tick = 주인공 행동 1회(기준). 아래 "턴"은 100 tick.

## 효과 원시 8개

| shape | 뜻 |
| --- | --- |
| `bolt` | 시야·사거리 안 적 하나 |
| `line` | 시전자에서 8방향 직선 n칸(목표 칸이 직선 위에 있어야 한다 — 아니면 "직선이 아님") |
| `cone` | 목표 방향 부채꼴 3칸 |
| `burst` | 목표 중심 반경 r, **적만** 맞는다(아군·소환수 무사) |
| `wall` | 목표 방향 3칸 장벽, 지속 동안 통행 불가(불벽은 닿으면 화상) |
| `self` | 자기 버프. "다음 X" 충전은 쓸 수 있는 주문에만 1회 소진 |
| `mark` | 대상에 상태 부여(`expires_at`) |
| `summon` | 인접 빈칸에 소환수. 명령 없음, 영입·명부·이력 제외, 만료 시 사라짐, 죽어도 파티 스트레스 없음 |

## 상태 10개

| 상태 | 효과 |
| --- | --- |
| `slow` | 이동·행동 비용 ×3/2 |
| `freeze` | 이동·공격 불가(몬스터도) |
| `bind` | 이동 불가, 인접 공격은 가능 |
| `burn` | 경계 tick마다 화염 4(주문 화상) |
| `weak` | 주는 피해 −30% |
| `brittle` | AC −4 |
| `distort` | 명중 −30% |
| `vulnerable` | 받는 피해 +30% |
| `confuse` | 무작위 행동 |
| `dominate` | 편이 바뀐다: 파티 AI·위협 목록·범위 주문·보스 표적에서 아군, 자기 동족을 공격 |

보조 표식: `extend`(걸린 상태 +2턴), `spread_burn`(화상이 인접 적으로), `spread_status`(상태가 인접 적에 복사), `summon_power`(소환수 피해 ×1.5).

## 소환수

| 종류 | HP | 피해 | 속도 | 지속 |
| --- | --- | --- | --- | --- |
| 사냥개 | 20 | 7 | 100 | 300 tick |
| 임프 | 12 | 5 | 90 | 250 |
| 쥐 | 8 | 4 | 80 | 200 |
| 늑대 | 40 | 10 | 90 | 350 |

소환수는 기존 동료 AI(돌격형)로 싸운다. `결속`(HP +50%)·`지속 강화`(+200 tick)·`공명`(피해 ×1.5)·`소환 지배`(회복·지속 갱신)가 이들에게 걸린다.

## 유물 주문 (학파 밖)

옛 이식본의 주문 `blast/blink/mend/passwall/ward/turret/ignite`는 데이터에 남아 있지만 영혼석에 연결되지 않고 드롭되지 않는다. `blast`(화염 폭발 반경 1)·`blink`(무작위 순간이동)·`mend`(HP +12, 느려짐)만 효과가 있고, 나머지는 시전 시 "아직 쓸 수 없는 유물"로 거부된다. 옛 학파 주문 id(`bolt/cone/cloud/confuse/hound`)는 삭제됐다.

## 미확정·다음 밸런스 라운드

- `둔화 강화`(냉기 4) 위력 10, `돌풍`(기류 3) 위력 6은 스펙에 수치가 없어 임시값이다.
- 지배당하지 않은 보스는 파티만 노린다(NPC·소환수는 표적에서 제외, 기존 동작).
