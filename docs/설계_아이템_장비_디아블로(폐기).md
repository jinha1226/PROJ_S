# 장비 시스템 설계 (디아블로식)

상태: ❌ 교체됨 — 84a14403에서 구현, 388182ad에서 DCSS식으로 교체

작성일: 2026-09-29 · 대상: `dungeon.html` · 프롬프트: `추가_아이템_장비.txt`

## 0. 플레이어가 느껴야 할 것

- 장비가 떨어지면 빛기둥 색만 보고도 설렌다.
- 주우면 바로 "지금 것보다 나은가, 내 빌드에 맞는가"를 비교하고 싶다.
- 입으면 내 인형이 눈에 띄게 바뀐다. 깊이 내려갈수록 점점 멋있어진다.
- 그래도 빌드의 중심은 영혼석이다. 장비는 영혼석 빌드를 받쳐주거나 한쪽으로 기울게 한다.

## 1. 원칙

1. **옵션은 이 게임의 규칙에 걸린다.** 숫자만 올리는 옵션은 전체의 절반 이하. 나머지는 원소·형태·지형·소모품·영혼석·스킬에 걸린다.
2. **장비 < 영혼석.** 전설 장비 하나의 영향이 영혼석 두 개를 넘지 않는다. 수치에는 상한이 있다(§4).
3. **비교가 쉬워야 한다.** 모든 옵션은 한 줄이고, 바뀌는 값은 초록(오름)·빨강(내림)으로 보인다.
4. **외형은 칸마다 한 가지가 분명히 바뀐다.** 디오라마 인형 스타일을 유지한다.

## 2. 장비 칸

| 칸 | 개수 | 들어가는 것 | 외형 |
| --- | ---: | --- | --- |
| 무기 | 1 | 장검·손도끼·철퇴·전투 망치·단검·창 | 손에 든 무기 모양 |
| 보조 | 1 | 방패, 횃불, 두 번째 무기 | 왼손 |
| 머리 | 1 | 두건·가죽 모자·투구·뿔 투구·왕관 | 머리 모양 |
| 몸통 | 1 | 천옷·가죽·사슬·판금 | 몸 색과 두께 |
| 장갑 | 1 | 천·가죽·판금 장갑 | 손 크기와 색 |
| 신발 | 1 | 천·가죽·판금 신발 | 발 크기와 색 |
| 목걸이 | 1 | 목걸이 | 가슴의 작은 보석 |
| 반지 | 2 | 반지 | 없음(광택만) |

- 지금의 "무기 두 개 교체"(`G.wpn`, `G.wi`)는 **무기 칸 + 보조 칸**으로 옮긴다. 보조에 무기가 있으면 지금처럼 버튼 하나로 무기와 보조를 맞바꾼다(턴 소모 없음, 지금 규칙 유지).
- 보조가 방패나 횃불이면 무기 교체 버튼은 비활성.

## 3. 기본 아이템

### 3.1 무기 (지금 `WEAPONS` 유지)

| 무기 | 형태 | 피해 | 기본 특성 |
| --- | --- | --- | --- |
| 장검 | 베기 | 3~5 | — |
| 손도끼 | 베기 | 4~6 | 명중 −5% |
| 철퇴 | 타격 | 3~5 | — |
| 전투 망치 | 타격 | 4~6 | 명중 −5% |
| 단검 | 찌르기 | 2~4 | 급소 확률 +10% |
| 창 | 찌르기 | 3~5 | 2칸 거리 공격(사이가 비어야 함) |

### 3.2 방어구

재질이 무거울수록 방어는 오르고 회피는 내려간다.

| 재질 | 몸통 | 머리·장갑·신발 | 외형 |
| --- | --- | --- | --- |
| 천 | 방어 0, 회피 +5% | 회피 +2% | 밝은 천색, 얇음 |
| 가죽 | 방어 1 | 방어 0, 회피 +1% | 갈색 |
| 사슬 | 방어 2, 회피 −3% | 방어 1, 회피 −1% | 회색 격자 무늬 |
| 판금 | 방어 3, 회피 −6% | 방어 1, 회피 −2% | 은색, 두꺼움 |

### 3.3 보조

| 보조 | 효과 |
| --- | --- |
| 방패 | 방어 +1, 막기 15%(막으면 피해 0, 초록 영혼석은 발동) |
| 횃불 | 시야 +1, 붙어 있는 적을 칠 때 불 1(풀·기름 반응) |
| 두 번째 무기 | 무기 교체 가능 |

## 4. 수치 기준과 상한

주인공 기본: HP 30, 방어 0, 회피 10%.

| 수치 | 뜻 | 상한 |
| --- | --- | --- |
| 방어 | 받는 피해 −N(최소 1) | 6 |
| 회피 | 공격을 피할 확률 | 40% |
| 막기 | 방패만. 피해 0 | 30% |
| 최대 HP | — | 기본 +20 |
| 원소 저항 | 해당 원소 피해 −N% | 50% |

상한은 캐릭터 정보 창에 "최대" 표시로 보인다.

## 5. 등급

| 등급 | 색 | 옵션 | 이름 |
| --- | --- | --- | --- |
| 일반 | 흰색 | 0 | 기본 이름 |
| 마법 | 파랑 | 1~2 | 접두어·접미어 ("불타는 장검", "여우의 장갑") |
| 희귀 | 노랑 | 3~4 | 무작위 두 단어 ("잿빛 속삭임") |
| 전설 | 주황 | 기본 옵션 1~2 + 고유 효과 1 | 고유 이름 |

### 5.1 층별 드롭 확률 (장비가 떨어질 때 등급)

| 층 | 일반 | 마법 | 희귀 | 전설 |
| --- | ---: | ---: | ---: | ---: |
| 1~3 | 60% | 35% | 5% | 0% |
| 4~6 | 40% | 45% | 13% | 2% |
| 7~9 | 25% | 45% | 25% | 5% |
| 10~12 | 15% | 40% | 35% | 10% |
| 보스 | 0% | 0% | 70% | 30% |

- 옵션 수치는 등급 T1(1~6층)과 T2(7~12층) 두 단계.
- 같은 전설은 한 판에 한 번만 떨어진다.

## 7. 전설 (처음 6개)

| 이름 | 칸 | 고유 효과 | 기울이는 빌드 |
| --- | --- | --- | --- |
| 물안개 망토 | 몸통(천) | 대기할 때마다 내 주변 1칸이 젖는다 | 보라 + 감전·빙결 |
| 피의 송곳니 | 단검 | 출혈 중인 적이 죽으면 피가 터져 주변 1칸 적에게 출혈 2 | 빨강 출혈·추가 타격 |
| 가시 판금 | 몸통(판금) | 맞으면 초록 영혼석이 두 번 발동. 받는 피해 +20% | 초록 |
| 번개 감긴 반지 | 반지 | 번개가 번질 때 1칸 더 멀리 번진다 | 감전 연쇄 |
| 거인의 철퇴 | 철퇴 | 밀치기가 1칸 더 멀리. 벽 충돌 시 주변도 흔들려 1 피해 | 밀치기·충돌 |
| 연금술사의 장갑 | 장갑 | 던지는 물건이 두 개로 나뉘어 날아간다 | 소모품·지형 |

- 전설 효과 설명은 두 줄 이내.
- 영혼석을 대체하지 않는다. 해당 영혼석이 없으면 효과가 약하거나 거의 없어야 한다.

## 8. 미확인

- 희귀·전설은 미확인 상태로 떨어진다. 이름은 "미확인 투구"처럼 보이고 옵션은 "???".
- 입을 수는 있다. 입으면 옵션이 하나씩 드러나고, 한 층을 내려가면 전부 드러난다.
- 확인 두루마리(소모품에 추가)는 즉시 전부 드러낸다.
- 미확인 장비와의 비교 창에는 기본 수치(방어·피해)만 비교된다.

## 9. 드롭

| 출처 | 장비가 떨어질 확률 |
| --- | --- |
| 일반 몬스터 | 12% |
| 갑옷 고블린·돌진형 | 25% |
| 상자(층마다 1~2개) | 100% |
| 보스 | 100%, 2개 |

- 떨어진 장비는 바닥에 남는다(지금 무기 줍기와 같은 방식). 밟으면 줍기 버튼.
- 가방이 가득 차 있으면 줍지 못하고 "가방이 가득 찼다"가 뜬다.

## 10. 아이템 창

### 10.1 화면 (모바일 세로)

```text
┌──────────────────────────────┐
│         [머리]               │
│ [무기]  (인형 회전)  [보조]   │
│ [장갑]    [몸통]    [신발]    │
│ [목걸이]  [반지]    [반지]    │
├──────────────────────────────┤
│ HP 38  방어 3  회피 14%  피해 4~6 │  ← 누르면 정보 창
├──────────────────────────────┤
│ 가방 12/20                   │
│ ▢▢▢▢▢                        │
│ ▢▢▢▢▢  (등급색 테두리)        │
│ ▢▢▢▢▢                        │
│ ▢▢▢▢▢                        │
└──────────────────────────────┘
```

- 인형은 3D 그대로 보이고 드래그로 돌려볼 수 있다.
- 가방 칸은 등급색 테두리. 지금 입은 것보다 나은 장비에는 작은 초록 화살표.

### 10.2 가방 장비를 눌렀을 때

- 같은 칸에 입은 장비가 없으면 설명 창 하나: 이름(등급색), 종류, 기본 수치, 옵션, [장착] [버리기].
- 입은 장비가 있으면 **두 창을 위아래로 나란히**(위: 입은 것, 아래: 새것). 새 창의 각 줄 끝에 차이값을 표시(+2 초록, −1 빨강). 새것에만 있는 옵션은 초록 "새 옵션", 사라지는 옵션은 빨강 줄 긋기.
- 반지는 두 칸과 각각 비교하는 탭 두 개. 장착 시 고른 탭의 반지와 바뀐다.
- 무기는 형태가 다르면 "형태: 베기 → 찌르기"를 눈에 띄게.

### 10.3 입은 장비를 눌렀을 때

- 설명 창 + [해제]. 가방이 가득 차면 [해제]가 비활성이고 "가방이 가득 찼다".

### 10.4 규칙

- 안전할 때(보이는 적 없음) 장착·해제는 자유.
- 전투 중 장착·해제는 한 턴(적이 한 번 움직인다). 창을 닫지 않고 연달아 바꾸면 바꾼 횟수만큼 턴.
- 버리기는 발밑에 떨어뜨린다(다시 주울 수 있음).

### 10.5 캐릭터 정보 창

- 최종 수치(HP, 방어, 회피, 막기, 피해, 원소 저항, 급소 확률).
- 각 수치를 누르면 출처가 펼쳐진다: "방어 3 = 몸통 판금 3 + 투구 1 − ... (최대 6)".

## 11. 외형

| 칸 | 바뀌는 것 |
| --- | --- |
| 무기 | 무기 메시 모양(칼날 길이, 도끼날, 망치 머리, 창 자루, 단검 크기) |
| 보조 | 방패(원형, 등급색 테두리) / 횃불(주변 빛 반경 +) / 두 번째 무기는 등에 멤 |
| 머리 | 두건(천 덮개), 가죽 모자, 투구(둥근 철), 뿔 투구(뿔 둘), 왕관(전설 전용 금색) |
| 몸통 | 재질색(천 베이지, 가죽 갈색, 사슬 회색, 판금 은색) + 몸 두께(판금이 가장 둥글고 큼) |
| 장갑 | 손 구의 크기·색 |
| 신발 | 발 구의 크기·색 |
| 목걸이 | 가슴 앞 작은 보석(원소 옵션이면 그 원소 색) |
| 반지 | 없음 |

- 등급 광택: 마법은 옅은 파란 테두리광, 희귀는 노란 테두리광, 전설은 주황 테두리광 + 몸 주변을 도는 작은 불꽃 파티클 4~6개.
- 장착 순간: 인형이 한 번 찌그러졌다 펴지며(기존 피격 탄성 재사용) 해당 부위에서 반짝이 파티클.

## 12. 드롭 연출

- 바닥의 장비는 등급색 빛기둥. 일반은 없음, 마법 낮음, 희귀 중간, 전설 높고 밝음 + 천천히 회전하는 빛.
- 이름표는 주인공이 3칸 안에 있을 때만.
- 전설이 떨어지면 화면이 0.3초 주황빛으로 번쩍이고 로그에 주황 글씨.

## 13. 코드 연결 (`dungeon.html`)

- 새 상태: `G.eq = { weapon, off, head, body, hands, feet, neck, ring1, ring2 }`, `G.bag = []`(최대 20), 장비 객체 `{ id, base, slot, rarity, name, affixes:[{id, v}], legendary, known }`.
- 기존 `G.wpn`/`G.wi` → `G.eq.weapon`/`G.eq.off`로 옮기고, 무기 교체 버튼은 둘을 맞바꾼다.
- 바닥 무기 `G.weps` → 바닥 장비 `G.gear`(Map)로 일반화. `takeWeapon`은 가방에 넣는 `pickGear`로 바뀐다.
- `calcStats()`(새): 기본값 + 장비 + 보호막 → 최종 수치. 공격·피격·이동 판정은 이 값을 읽는다. 상한은 여기서 자른다.
- 옵션 효과는 이미 있는 발동 지점에 건다: 적중(`weaponHit`), 피격, 대기, 원소 반응(`synergy`), 던지기, 스킬 사용.
- 외형: 주인공 인형 생성 부분에 칸별 부품을 붙였다 떼는 `dressHero(eq)`. 장착·해제 때마다 호출.
- 새 이벤트: `emit('equip', {slot, item})`, `emit('gearDrop', {x, y, rarity})`.

## 14. 범위 밖

- 제작·강화·분해(정착지 3차와 함께).
- 세트 장비.
- 장비 거래·상점.
- 캐릭터 레벨과 요구 레벨.

## 15. 확인 목록

1. 첫 3층 안에 마법 장비를 2개 이상 줍는다.
2. 비교 창에서 차이값 색이 맞고, 반지는 두 칸과 각각 비교된다.
3. 전투 중 장착하면 적이 한 번 움직인다.
4. 칸마다 외형이 바뀌고, 해제하면 원래대로 돌아간다.
5. 수치가 상한을 넘지 않는다(방어 6, 회피 40%).
6. 전설 6개가 각각 설명대로 동작하고, 해당 영혼석이 없으면 효과가 약하다.
7. 장비만 좋은 판과 영혼석만 좋은 판을 비교했을 때 영혼석만 좋은 판이 더 강하다.

## 16. 열린 결정

- 전투 중 장착을 아예 막을지(지금 안: 한 턴 소모).
- 죽으면 장비도 잃는지(3차 죽음 규칙과 함께 정한다. 추천: 입은 장비는 잃고 정착지 창고 장비는 남음).

## 17. 적용 (2026-09-29)

코드: `js/data/gear.js`, `js/core/gear.js`, `js/render/hero-doll.js`, `js/render/gear-view.js`, `js/render/gear-preview.js`, `js/ui/inventory.js` + 발동 지점(`core/combat.js`, `core/elements.js`, `core/stones.js`, `core/items.js`, `core/skills.js`, `core/fov.js`). 확인: `tests/gear.mjs`.

- **열린 결정(§16)**: 전투 중 장착은 한 턴(막지 않음). 죽으면 입은 장비·가방은 잃고 정착지 창고(`META.gear`)는 남는다.
- **3차와 합친 것**: 무기 두 자루(`G.wpn`) → 무기 칸 + 보조 칸. 바닥 무기(`G.weps`) → 바닥 장비(`G.gear`). 정착지 대장간의 무기·갑옷 제작 → 장비(명품 = 마법 등급, 가죽 갑옷 = 최대 HP, 뼈 흉갑 = 층마다 보호막 — 제작 전용 옵션 `floorShield`). 방패(대장간)·횃불(사냥꾼)·확인 두루마리(서재) 제작법 추가. 출발문의 무기·갑옷 선택 → 아이템 창(정착지에서는 창고 칸이 함께). 저장본 v3 → v4 자동 이전.
- **해석한 것**:
  - "원소 피해 +"는 무기 공격만이 아니라 내가 일으킨 그 원소 피해 전체(스킬·영혼석·반응)에 붙는다.
  - "명중 −5%"(손도끼·망치)는 빗나감으로 구현했다. 그 전에는 주인공 공격이 늘 맞았다.
  - 회피·막기는 적의 직접 공격(근접·화살·돌진)에만, 방어는 물리 피해(공격·충돌)에, 저항은 원소 피해에 적용한다.
  - "같은 전설은 한 판에 한 번"은 모험가 한 명 기준(`hero.legends`)이다.
  - 가시 판금의 "초록 두 번"은 한 번 발동한 초록 영혼석이 같은 자리에서 한 번 더 발동하는 것으로 했다.
- **확인 못 한 것**: §15-7 "장비만 좋은 판 < 영혼석만 좋은 판"은 수치 비교를 하지 않았다(직접 해봐야 한다).
