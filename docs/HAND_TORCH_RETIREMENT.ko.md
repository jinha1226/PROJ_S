# 휴대 횃불 제거

- 휴대 횃불의 상점 판매, 지급, 장착, 점화·소화, 장비 변경 시 소화 이벤트를 제거했다.
- HUD의 횃불 이미지·개수·연료 게이지·소진 알림을 제거했다. 식량 표시는 유지한다.
- 시야 계산과 캐릭터 표현에서 휴대 횃불 광원을 제거했다. 매 시야 갱신 시 전체 인벤토리의 횃불을 찾지 않는다.
- 1층 밝기 700, 2층 이상 500으로 유지해 후속 층도 휴대 광원을 요구하지 않는다. 벽·지형에 의한 시야 차단, 탐험 기억, 벽 불빛과 모닥불은 유지한다.
- 과거 아이템/이벤트의 스냅샷 해석용 정의는 남긴다. 옛 횃불은 재장착·사용할 수 없으며 해제·폐기만 가능하다. 횃불 명령이 포함된 구형 전체 세션 저널의 재생 호환은 보장하지 않으므로 새 게임을 권장한다.

## 포션·스크롤 감정

드롭되는 18종은 최초 미감정이며 판마다 외형 대응이 바뀐다. 사용하면 같은 종류 전체를 알게 된다. 감정 스크롤은 대상 아이템을 소모하지 않고 종류를 밝힌다. 감정된 감정 스크롤은 대상을 선택할 수 있고, 아직 미감정인 감정 스크롤은 효과 유출 없이 적격 대상을 자동 선택한다. 기존 시작 회복 물약은 감정된 보급품이다.

## 검증

- PASS — `tests/main_hud_acceptance.gd`: 390px HUD 배치, 횃불 UI 부재, 판매/지급/점화 금지와 무변경, 식량 유지.
- PASS — `tests/expanded_consumables_acceptance.gd`: 18종 미감정·사용·감정·상태 효과 및 롤백.
- PASS — `tests/potion_latency_death_layout_regression.gd`: 물약 사용, 저장·불러오기, 실패 롤백, 사망 후 모바일 레이아웃 유지.
- 기존 횃불 장착/연료 성공을 요구하는 과거 횃불 전용 테스트는 폐기된 기능의 기록이며 현재 합격 기준이 아니다.
