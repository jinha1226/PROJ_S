# 바닥 모닥불 원형 광원 protocol

- 작업 ID: `RADIAL-DARKNESS-003`
- 기준 commit: `3464c4a`
- 사용자 요청: 던전 바닥에 배치된 모닥불도 주변을 밝히는 독립 광원으로 보여야 한다.

## 구현 범위

- `landmark_camp` 바닥 모닥불과 실제 `fire_intensity > 0` 화염을 fire light source로 수집한다.
- 모닥불은 주황색 거리 감쇠 광원과 암흑 alpha의 연속 그라데이션을 함께 적용한다.
- 이미 발견한 정적 `landmark_camp`는 `MEMORY`에서도 유지해 현재 시야 밖에서도 주변 알려진 지형을 밝힌다.
- 중간 벽은 광원을 차단하고 `UNSEEN`은 표시하거나 밝히지 않는다.
- 화염 피해·확산 등 시뮬레이션 규칙은 변경하지 않는다.

## 검증

- 모닥불 중심에서 멀어질수록 밝기가 감소해야 한다.
- 모닥불 광원이 암흑 mesh에 반영되어야 한다.
- MEMORY 정적 모닥불 주변은 밝아지되 벽 뒤와 UNSEEN은 밝아지지 않아야 한다.
- 기존 방사형 암흑, 환경 시각 및 제품 시작 회귀를 통과한다.
