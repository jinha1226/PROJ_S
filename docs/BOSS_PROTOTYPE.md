# Backview Posture Duel

## 한 줄 기획

2D 백뷰 경기장에서 보스의 예고 동작을 읽고, 자유롭게 간격을 조절하며 검격을 받아쳐 자세를 무너뜨리는 반턴제 결투.

## 화면과 이동

- 플레이어는 화면 아래에서 등을 보이고 보스는 화면 위에서 정면을 보인다.
- 논리 좌표는 `x=-1..1`, `depth=0.27..0.92`를 사용한다.
- `depth`가 커질수록 플레이어를 화면 아래에 더 크게 그려 3D 원근감을 만든다.
- 플레이어는 항상 보스를 향한다. 좌우 입력은 스트레이프, 아래 입력은 백스텝이다.
- 카메라는 회전하지 않으며 보스 뒤로 넘어갈 수 없다.

## 반턴제 흐름

평상시 이동과 행동은 실시간이다. 보스가 패턴을 시작하면 `TELEGRAPH` 동안 전투 시간이 약 43% 속도로 느려진다. 플레이어는 이 집중 구간에 이동 경로와 대응 행동을 선택하고, `ACTIVE`가 시작되면 정상적인 충돌 속도를 체감한다.

    IDLE → TELEGRAPH → ACTIVE → RECOVERY
                              ↘ BROKEN

명시적인 턴 번호나 카드 메뉴는 사용하지 않는다. 보스의 한 번의 예고와 실행을 한 턴처럼 취급해 액션의 흐름을 유지한다.

## 플레이어 행동

### 공격

- 보스와의 깊이가 `0.53` 이하이고 중앙 공격 범위 안일 때 명중한다.
- 기본 명중은 체력 5, 자세 13 피해를 준다.
- 보스 회복 구간에는 체력 7, 자세 19 피해를 준다.
- 자세가 붕괴된 보스에게 명중하면 체력 34의 결정타를 실행한다.

### 받아치기

- 입력 후 처음 `0.17초`가 정확 받아치기 구간이다.
- 정확 받아치기는 피해를 막고 보스 자세를 22만큼 무너뜨린다.
- 늦은 입력은 일반 방어가 되어 플레이어 자세가 증가한다.
- 휩쓸기는 받아칠 수 없으므로 회피해야 한다.

### 회피

- 현재 조이스틱 방향으로 이동하며 약 `0.25초`의 무적 시간을 얻는다.
- 방향 입력이 없으면 카메라 쪽으로 후퇴한다.
- 공격과 정확히 겹치면 보스 자세에 소량의 압박을 준다.

## 보스 패턴

| 패턴 | 판정 | 주요 대응 |
|---|---|---|
| 베기 | 근거리의 넓은 전방 | 받아치기 또는 후퇴 |
| 찌르기 | 예고 시작 위치를 향한 좁은 직선 | 좌우 스트레이프 또는 받아치기 |
| 연속 베기 | 짧은 간격의 2연타 | 연속 받아치기 |
| 휩쓸기 | 근거리 전체 | 방향 회피 또는 거리 이탈 |

## 자세와 결정타

- 플레이어와 보스는 체력과 별도로 `0..100` 자세 게이지를 가진다.
- 보스 체력이 낮을수록 자세 회복 속도가 느려진다.
- 보스 자세가 100이 되면 2.25초 동안 결정타 기회가 열린다.
- 기회를 놓치면 보스 자세가 일부 회복되고 전투가 계속된다.
- 플레이어 자세가 붕괴하면 잠시 행동할 수 없지만 즉시 사망하지는 않는다.

## 첫 재미 판정 기준

다음 항목을 만족하기 전에는 장비, 스킬 트리, 다수 보스를 추가하지 않는다.

1. 보스의 네 패턴을 동작과 궤적으로 구분할 수 있는가?
2. 앞뒤 거리 조절과 좌우 스트레이프가 실제 회피 수단이 되는가?
3. 연속 받아치기의 소리와 화면 반응이 만족스러운가?
4. 공격과 방어를 섞어 자세 회복을 막을 이유가 있는가?
5. 자세 붕괴 후 결정타가 한 전투의 명확한 목표로 느껴지는가?
