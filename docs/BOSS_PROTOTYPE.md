# Colossus Prototype

`PROJ_S`의 현재 메인 게임은 세로형 모바일 보스전 프로토타입이다. 기존 슬라임 자동화 코드는 Git 기록과 레거시 파일로 유지하지만 새 게임의 설계를 제한하지 않는다.

## 한 줄 기획

거상의 예비 동작을 읽고 회피한 뒤, 선택한 신체 부위를 자동 반격으로 파괴하는 세로형 보스 러시.

## 첫 재미 검증 범위

- 세로 화면과 한쪽 이동 패드
- 조건부 자동공격
- 큰 회피 버튼과 정확 회피 판정
- 원거리에서는 보스 전체, 근거리에서는 목표 부위를 보여주는 자동 카메라
- 보스 패턴: 휩쓸기, 충격파, 돌진
- 선택 가능한 왼팔, 오른팔, 핵
- 팔 파괴 시 해당 공격 패턴 제거
- 사망 또는 승리 후 즉시 재도전

## 조작

- 화면 왼쪽 아래를 드래그하거나 WASD/방향키로 이동한다.
- 보스의 팔이나 핵을 직접 터치해 자동공격 목표를 선택한다.
- 선택 부위의 사거리 안에 머무르면 기본 공격을 자동 실행한다.
- 화면 오른쪽 아래 `DODGE` 또는 Space로 회피한다.
- 공격 방향 반대로 이동하면 다음 자동공격을 시작하지 않는다.

## 카메라 규칙

- 플레이어와 보스의 거리가 멀면 전체 전투를 보여주는 배율로 축소한다.
- 가까워지면 플레이어와 선택 부위 사이를 중심으로 확대한다.
- 충격파와 돌진 예고 중에는 근거리에서도 강제로 시야를 넓힌다.
- 정확 회피, 타격, 부위 파괴는 짧은 확대와 흔들림으로 강조한다.
- 작은 거리 변화는 지수 보간으로 흡수해 카메라가 떨리지 않게 한다.

## 재미 판정 기준

다음 질문에 긍정적으로 답하기 전에는 장비, 성장, 탐험, 스토리를 추가하지 않는다.

1. 예고 동작만 보고 세 패턴을 구분할 수 있는가?
2. 피격했을 때 플레이어가 이유를 이해할 수 있는가?
3. 정확 회피 후 반격이 만족스러운가?
4. 어느 팔을 먼저 파괴할지 선택할 이유가 있는가?
5. 죽은 직후 다시 시도하고 싶은가?
