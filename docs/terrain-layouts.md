# 10×10 탑뷰 전장

각 방은 100칸이며 화면 폭은 그대로 유지한다. 타일은 종전 8×8 대비 80% 크기다.
3×3 방 연결 지도와 행동 기반 턴은 유지한다.

개방형(흩어진 잔해), 중앙 장애물형(기둥과 측면 통로), 두 갈래형(분리벽과 열린 통로),
수로형(물과 나무 통로)의 네 기본형을 시드와 방 번호로 배치한다.
적 숫자는 늘리지 않는다. 벽은 이동·시야·원거리 공격을 막고,
물·나무·금속은 기존 원소 규칙을 그대로 사용한다.
입장 위치·문·보스·전력탑 위치는 접근 가능하게 보존한다.
보스 초기화가 지형을 평지로 덮지 않으며 수렁 포식자 방에는 작은 물웅덩이를 보장한다.

## 타일 출처

기존 프로젝트 `../assets/topdown_fixed_front/terrain/floor{1,2}_atlas_16x1_16.png`
두 파일을 변경 없이 `assets/topdown/`에 복사했다.
기존 생성 자산이며 원본 설명은 `../assets/pixel24_v3/source/TERRAIN_FLOOR{1,2}_PROMPT.md`를 참고했다.
16px 셀을 AtlasTexture로 선택하며 nearest 필터로 표시한다.
돌 0/2/3, 나무 4, 금속 5, 물 7, 막힌 벽 9번 셀을 사용한다.

## 검증

`tests/terrain_layouts.gd`: 100개 시드의 900개 방에서 모든 보행 칸 연결,
문·전력탑·보스 위치 접근성, 생성 위치와 새 외곽의 이동·스킬 범위를 검사한다.
전투판 터치 테스트도 100칸으로 확장했다.
