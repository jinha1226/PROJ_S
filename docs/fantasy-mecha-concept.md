# 판타지 메카 — 기본 컨셉

정리일: 2026-09-21
상태: 세계관·기획 방향 정리. 게임 코드와 데이터는 아직 전환하지 않았다.
프로젝트명은 임시로 기존 이름을 유지한다.

## 한 문장

성격과 기억을 가진 메카들이 던전을 탐험하고, 쓰러뜨린 몬스터의 파츠를 회수해 자신의 전투 능력을 바꾸는 판타지 메카 전술 RPG.

## 확정된 기본 방향

- 장르는 판타지 메카다. 기계와 판타지적 힘이 공존한다.
- 모든 플레이어 캐릭터와 동료는 메카 계열 캐릭터로 표현한다.
- 기존 이능 획득의 의미를 **몬스터 파츠 획득**으로 전환한다.
- 몬스터마다 고유한 공격·기능이 있고, 회수한 파츠를 통해 그 능력을 사용한다.
- 기존 성격·기억 시스템을 버리지 않는다. 외형과 육체 표현이 기계로 바뀌어도 인물별 차이는 유지한다.
- 이번 컨셉 정리는 전투 규칙의 전면 재설계가 아니다.

## 유지할 플레이 구조

- 모바일 세로 화면, 탑뷰 10×10 전장.
- 주인공 한 명으로 시작해 최대 3인 파티로 확장하는 방향. NPC 영입은 후속 작업이다.
- 주인공 행동에 따라 시간이 진행되는 행동 기반 턴제.
- 동료는 설정한 행동방침대로 움직이며 필요할 때 플레이어가 행동을 예약한다.
- 8방향 이동·공격, 밀치기, 장애물과 원소 지형을 활용한 전투.
- 절차 생성 층을 내려가며 전투·탐험·야영·파츠 획득을 반복하는 흐름.
- 스탯과 숙련 성장은 유지한다. 세부 명칭·수치는 테마 전환과 분리해 검토한다.

## 파츠 획득·장착 흐름 — 채택 제안

**몬스터 처치 → 확률적으로 파츠 회수 → 공용 가방 보관 → 야영 중 장착 → 해당 능력 사용**

- 현재의 ‘정수를 먹어 스킬을 영구 습득’하는 표현과 흐름은 이 방향으로 대체한다.
- 특수 파츠 슬롯은 현재 이능 슬롯과 같은 **2칸**을 기본으로 한다.
- 장착한 파츠만 전투에서 사용한다. 해제한 파츠는 보관한다.
- 파츠 자체를 보유하고 동료 사이에서 옮겨 장착하는 방식을 우선 검토한다.
- 이 경우 파츠 1개를 여러 캐릭터에게 동시에 장착할 수 없도록 소유 수량을 관리해야 한다.
- 중복 파츠를 같은 캐릭터에게 장착할 수 있는지, 개별 내구도를 가질지는 아직 정하지 않았다.
- 현재 드롭 확률·쿨다운은 프로토타입 수치다. 새 컨셉의 확정 밸런스로 간주하지 않는다.

### 기존 적을 활용한 예시 — 명칭 미확정

| 몬스터 | 회수 파츠 예시 | 사용할 수 있는 기능 |
|---|---|---|
| 수렁 포식자 | 압력낭 / 충격파 발생기 | 주변 충격파 |
| 폭탄 암살자 | 투척팔 / 폭탄 발사기 | 폭탄 투척 |
| 과부하 거인 | 철갑 외피 / 방어 모듈 | 일시적인 피해 감소 |

단순한 무기 이름으로 바꾸기보다는, 파츠의 외형과 기능에 원래 몬스터의 특징을 남긴다.
모든 몬스터까지 기계 생물인지, 생물의 기관도 메카에 결합하는지는 세계관 결정 사항으로 남긴다.

## 기존 시스템의 테마 전환안

| 기존 표현 | 전환 후보 | 유지할 의미 |
|---|---|---|
| 신체·조직 | 프레임·장갑·구동부 | 부위별 손상과 기능 저하 |
| 팔·다리 부상 | 공격 구동부·이동 관절 손상 | 공격·이동 성능에 영향 |
| 이능 | 특수 파츠 | 장착한 두 능력과 자동 사용 방침 |
| 정수 섭취 | 파츠 회수·장착 | 몬스터 유래 능력 획득 |
| 치유·물약 | 수리·응급 복구 키트 | 전투 중 제한적인 회복 |
| 식량 | 야영용 연료 | 야영 자원 관리 |
| 스트레스 | 인격이 겪는 정신적 스트레스 | 성격과 기억에 따른 반응 |

위 표는 용어·표현 후보이며 현재 구현에는 기존 식량 이름을 사용한다.
스트레스를 단순 과열 게이지로 치환하지 않는다. 과열은 도입하더라도 별도 검토 사항이다.
기존 혈액·피부·뼈 데이터도 이름만 바꿔 확정하지 않고, 기계 부위에 맞는 의미를 먼저 정한다.

## 성격·기억과 손상 연출

- 몸은 수리할 수 있지만 전투 경험과 동료에 대한 기억은 남는다는 방향을 지향한다.
- 성격과 기억은 인물성을 담당하고, 파츠는 전투 기능을 담당한다.
- 일반 피해에는 기본 타격·피격 효과만 사용한다.
- 부위가 새로 기능 상실·절단되는 순간에만 줌인·슬로우·강한 효과를 준다.
- 기계식 표현 후보: 불꽃, 파편, 장갑 파손, 구동부 정지. 단순 체력 감소마다 연출하지 않는다.
- 코어 손상 시 사망인지, 인격 복구가 가능한지, 부활 규칙은 미정이다.

## UI 방향

승인된 캐릭터 탭 목업의 배치와 비율을 유지하고 테마에 맞춰 용어·아이콘을 바꾼다.

- 상태: 체력/기체 상태, 능력치, 부위 실루엣과 손상 상태.
- 숙련: 근접·원거리·마법·방어의 2×2 카드 구조 유지. 계열 명칭은 추후 결정.
- 성격·기억: 캐릭터의 인격 정보를 계속 표시한다.
- 이능 탭: ‘파츠’ 등의 명칭을 검토한다. 기본 화면에는 **장착된 2개 카드만** 표시한다.
- 파츠 카드: 이름, 짧은 기능 설명, 자동 사용 여부, 사용 방침, 교체.
- 교체: 해당 카드에서 시작해 보유 파츠를 선택한다. 1번/2번 슬롯을 다시 묻지 않는다.
- 파츠 종류가 늘어나도 공용 조건 UI로 방침을 설정한다. 스크립트 입력은 사용하지 않는다.

## 아직 결정하지 않은 것

- 자율 인격 메카, 영혼이 깃든 기계, 별도 조종사가 있는 기체 중 인격의 정체.
- 적 몬스터의 생물/기계 범위와 파츠를 결합할 수 있는 세계관적 이유.
- 파츠의 개별 아이템화, 중복 장착, 내구도, 강화·분해·수리 비용.
- 기본 밀치기·방어가 내장 기능인지, 슬롯을 쓰는 시작 파츠인지.
- 사망·코어 회수·복구 및 장착 파츠 유실 규칙.
- 자원과 탭의 최종 명칭, 캐릭터별 기체 디자인.

이 항목들은 컨셉에서 자동으로 따라오는 필수 시스템이 아니다. 구현 전에 범위를 정한다.

## 후속 구현 순서 제안

1. 용어와 기체·파츠 시각 방향을 정한다.
2. 파츠의 소유·보관·장착 데이터 계약을 정하고 기존 정수/습득 구조의 전환 방법을 설계한다.
3. 드롭 → 가방 → 교체 → 사용 방침 → 전투 사용을 연결한다.
4. 부위 손상·회복 표현과 탐험 자원을 전환한다.

현재 구현 설명은 [이능과 성장](abilities-growth.md), [동료 전술](companion-tactics.md),
[10×10 전장](terrain-layouts.md)을 참고한다. 본 문서는 새 컨셉의 방향이며 해당 기능들이 이미 전환됐다는 뜻은 아니다.
