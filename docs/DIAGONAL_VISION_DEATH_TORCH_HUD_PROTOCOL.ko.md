# 대각선 시야·적 즉시 사망·횃불 HUD protocol

- 작업 ID: `VISION-DEATH-TORCH-HUD-001`
- 기준 commit: `a788c30`

## 대각선 시야와 암흑 표현

- 이동·근접 공격·대상 기술의 권위 방향은 4방향 축약 없이 8방향 단위 벡터를 보존한다.
- 인간 기본 후방·주변 2셀 규칙은 직교 방향과 대각선 방향에서 동일하게 적용한다.
- 어두운 전방 cone은 정규화된 벡터 내적으로 판정해 대각선과 직교 방향의 각도 의미를 같게 한다.
- 횃불을 들지 않은 기본 암흑 그라데이션은 완전한 원이 아니라 현재 방향으로 완만하게 늘어난 비대칭 거리장을 사용한다.
- 손에 든 횃불과 고정 광원의 원형 빛은 광원 표현이므로 유지한다.
- 진형 배치는 기존 4방향 배치 간격을 유지하도록 8방향 시야와 별도로 cardinal 방향을 사용한다.

## 적 즉시 사망

- 구조 대상인 파티원은 기존 `ACTIVE → DOWNED → 회복/사망` 규칙을 유지한다.
- 파티 적과 구조 불가능한 몬스터는 HP가 0이 된 피해와 같은 commit에서 `ACTIVE → DOWNED(terminal) → DEAD` 사건을 완결한다.
- 근접 공격과 대상 기술에서 치명 피해 직후 적의 점유·행동 가능 상태와 전투 승리 판정이 즉시 갱신되어야 한다.
- 사건·저장·재현 검증이 가능한 기존 canonical lifecycle 사슬은 유지한다.

## 상단 횃불 HUD

- 제품 상단 HUD의 식량 줄에 장착 횃불 상태를 별도 label로 표시한다.
- 켜진 횃불은 남은 유지시간, 꺼진 횃불은 꺼짐과 남은 연료, 소진된 횃불은 소진 상태를 표시한다.
- 횃불을 장착하지 않았거나 던전 밖이면 label을 숨긴다.
- 남은 시간이 짧으면 경고색, 소진되면 위험색을 사용한다.

## 검증

- 대각선 네 방향 각각에서 정확한 후방 2셀은 보이고 3셀은 보이지 않아야 한다.
- 권위 방향 save/load와 runtime invariant가 8방향을 허용해야 한다.
- 적의 치명 피해 결과에 같은 턴 `entity.died`가 포함되고 최종 상태가 `DEAD`여야 한다.
- 파티원 치명 피해의 구조 가능한 `DOWNED` 규칙은 유지해야 한다.
- 횃불 HUD가 점화·시간 경과·소화·소진 상태를 정확히 반영해야 한다.
