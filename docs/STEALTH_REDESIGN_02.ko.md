# 은신 재설계안 — 거리와 확률, 의심과 추적

## 사용자 의도와 이번 수정

가까워지면 발견 가능성이 높아져야 하지만 두 칸 이내라는 이유만으로 무조건 발견되어서는 안 된다. 높은 은신으로 접근하는 선택도 남겨야 한다.

새 원정 규칙 7에서는 이전 작업의 두 칸 이내 즉시 추격 예외를 제거했다. 인접 한 칸의 고정 의심도 600과 무조건 추격 예외도 새 규칙에서 제외해 실제 은신 수치를 공통 의심도 공식에 넣는다. 이전 규칙 5·6 저장은 원래 규칙대로 재현한다.

**아래 확률 모델은 기획안이며 아직 적용하지 않았다.** 이번 수정은 확률형 은신 구현 완료가 아니다. 공통 시야·은신 판정을 복구한 상태에서 조정 기준을 제시한다.

## 현재 둔감해 보이는 이유

1. 시야 후보 선정과 발각 판단이 두 단계다. 어두운 곳의 유효 거리·방향 제한을 통과하지 못하면 은신 대결 자체가 발생하지 않는다.
2. 실제 발각은 확률 추첨이 아닌 의심도 누적이다. 기본 은신 500, 고블린 감지 520이면 두 칸에서 한 번에 245가 쌓여 경계 기준 1000까지 여러 번 관찰해야 한다.
3. 시야를 잃으면 한 번에 180씩 감소한다. 짧은 시야 노출과 방향 전환이 반복되면 근처에 있어도 발견하지 못하는 것처럼 보인다.
4. 인접 예외는 반대로 은신 수치를 무시했다. 거리만으로 강제 발견하는 패치는 이 불일치를 확대한다.

## 권장 플레이 규칙

### 보일 수 있는가

벽·닫힌 문·차단 수준의 연기는 시각 후보를 막는다. 거리는 후보 범위를 정하되, 근거리 후보가 되었다는 사실을 발견 성공으로 간주하지 않는다. 방향과 조명은 가능하면 성공 확률의 보정으로 사용해 후보 제외와 의심도 감소가 중첩되는 구간을 줄인다.

### 알아봤는가

적 한 명의 인지 갱신마다 한 번만 판정한다. 파티원별로 주사위를 반복해서 인원이 많다는 이유로 발각 확률이 폭증하지 않게 한다. 후보 중 가장 발각되기 쉬운 인원을 대표로 택한다.

- 적 감지력, 파티원의 실제 은신, 거리, 조명, 전방/후방, 최근 행동, 기존 의심을 반영한다.
- 판정값은 월드 시드·적 ID·확정 행동 번호로 고정한다. UI 조회·미리보기·로드는 다시 추첨하지 않는다.
- 성공하면 인물을 식별하고 경계/추격으로 전환한다. 실패해도 큰 소리나 반복 근접 노출은 의심을 남긴다.
- 발견 성공 여부를 매 렌더 프레임이나 이동 애니메이션마다 판단하지 않는다.

초기 비교용 확률 목표(확정 밸런스 아님): 보통 장비의 근접 정면 노출은 한 번에 60–80%, 높은 은신의 어두운 후방 접근은 15–35%. 반복 노출에는 의심 보정이 붙어 낮은 확률로 무한히 적 앞에 서 있을 수 없게 한다.

### 발견 뒤 어떻게 행동하는가

- 미인지: 자기 행동을 계속한다.
- 의심: 마지막 소리/기척 방향을 확인한다. 아직 플레이어의 정확한 현재 위치는 모른다.
- 식별·추격: 확인한 상대를 추격한다. 직접 공격을 당하면 은신 실패 추첨을 기다리지 않는다.
- 수색: 시야를 잃으면 마지막 목격 위치까지 이동한다. 벽 뒤 플레이어의 현재 위치를 읽지 않는다.
- 복귀: 정해진 시간 동안 단서를 못 찾으면 경계를 낮춘다.

## 화면 피드백

보이는 적에게 `?`(의심), `!`(식별), 수색 표시를 제공한다. 숨은 적을 UI로 노출하지 않는다. 은신 수치뿐 아니라 현재 접근이 위험한 이유를 짧게 설명한다. 정확한 내부 확률을 상시 노출할지, 낮음/중간/높음으로 표시할지는 다음 UI 결정 항목이다.

## 후속 구현 판정 기준

- 같은 거리·지형에서 실제 은신이 높을수록 발각 빈도가 낮다.
- 같은 은신에서 밝은 정면/빠른 접근이 어두운 후방/조심스러운 접근보다 위험하다.
- 같은 행동 로그를 재생하면 발견 결과가 완전히 같다.
- 파티원 수가 늘어도 적 한 명의 한 갱신에 추첨을 중복하지 않는다.
- 한 번 실패했다고 적이 플레이어를 보지 못한 채 영원히 멈추지 않는다.
- 벽 뒤 추적, 정지 반복 추첨, UI 조회로 RNG 소비, 저장 후 재추첨이 발생하지 않는다.
