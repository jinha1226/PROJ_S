# 몬스터 이능 정수 드롭 연결

## 범위

16종 후보를 몬스터 종족 ID별 이능 정수 아이템으로 등록했다. 기존 사망 → 바닥 아이템 → 줍기 파이프라인을 사용한다. 각 처치당 20%로 정수 1개를 드롭하며, 확률은 임시 밸런스 값이다. 기존 마석·식량·돈 보상은 유지한다.

| 몬스터 ID | 이능 |
|---|---|
| goblin | 포식 신경 |
| kobold | 투척 본능 |
| wolf | 사냥꾼의 도약 |
| boar | 질긴 가죽 |
| beetle | 갑각 |
| slime | 부식성 혈액 |
| bat | 반향 감각 |
| fire_lizard | 화염샘 |
| frost_spider | 서리실 |
| electric_eel | 축전 기관 |
| viper | 독니 |
| troll | 재생 조직 |
| stone_golem | 암석 골격 |
| shadow_beast | 그림자막 |
| leech | 흡혈 기관 |
| aberration | 심층안 |

## 구현과 한계

- `monster_abilities.json`: 정수·종족·이능 ID와 패시브/액티브 설명을 함께 관리한다. 효과 상태는 `PLANNED_DUAL_MODE`로 명시했다.
- `items.json`: 정수 아이템을 등록했다. 화염샘은 기존 `ESSENCE_FIRE_BOLT`를 재사용한다.
- `species_drop_tables.json`: 기존 결정론적 종족 드롭을 이용한다. 같은 시드와 사망 사건이면 같은 결과이고 중복 처리 방지 장부를 유지한다.
- 모든 정수를 UI의 몬스터 이능 보상으로 분류하고, 사용 목적에 모드 선택 구현 예정임을 표시한다. 새 효과가 작동한다고 위장하지 않는다.
- **이번 작업은 드롭·수집 연결이다. 16종 효과 실행 및 패시브/액티브 모드 선택 UI는 아직 구현하지 않았다.** 기존 화염탄 결속 경로만 계속 사용할 수 있다.
- 현재 던전의 일반 적은 고블린/코볼드다. 나머지 종족의 드롭 정의는 준비됐지만 새 몬스터 배치·신체·AI는 추가하지 않았다.
- 구형 패시브 자동 해금은 별도로 남아 있다. 신규 정수 흡수·선택 체계를 구현할 때 통합해야 한다.
- 드롭 표를 변경했으므로 이전 드롭 표를 전제로 하는 오래된 저장 재생 호환은 보장하지 않는다. 저장 파일을 삭제하거나 덮어쓰지는 않았다.

## 검증

결과: `MONSTER ABILITY DROPS: PASS (16 mappings)`, 사망 드롭 회귀 9개 전부 통과.

- 16종 각각 아이템 등록, 보상 분류, 두 모드 설명, 200개 사망 ID의 재현 가능한 확률 드롭을 검사한다.
- 사망 드롭 회귀에 실제 고블린 사망 → 포식 신경 정수 생성 → 줍기 → 스냅샷 복원 검사를 추가했다.
- 기존 사망 테스트의 입력 피해가 현재 저항에 막혀 비치명적이던 fixture를 충분한 피해량과 일치하는 원인 사건으로 수정했다. 게임 피해 공식은 바꾸지 않았다.
