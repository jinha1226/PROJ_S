# 혈액 고갈 판정과 정착지 일시 중단

## 원인과 수정

신체 손상은 `current_blood`를 줄였지만 생존 판정은 HP만 참조했다. 현재 필드 턴 경로에서 각 행동의 피해 처리가 끝나면 혈액 고갈을 검사하고, 혈액 0인 활동 중 캐릭터는 남은 HP를 소진해 기존 사망·시체·전투 종료 경로로 전환한다. 고정된 동시 공격 묶음의 HP 검증을 마친 직후, 다음 행위자가 행동하기 전에 처리한다.

`body.blood_depleted` 사건으로 원인과 공격자 귀속을 남긴다. 이미 상처와 혈액 0을 가진 이전 저장의 생존자는 다음 필드 행동 실행 전에 같은 판정을 받는다. 기존 저장·정착지 데이터를 삭제하지 않는다. 낮은 혈액량의 단계별 능력치 페널티나 새로운 수혈/회복 체계까지 추가한 작업은 아니다. 일반 HP 회복은 혈액을 회복하지 않으며 기존 치유소 치료는 유지한다.

## 제품 구성

`playtest/product_features.gd`의 `SETTLEMENT_ENABLED=false`로 정착지 제품 진입을 일시 중단했다.

- 새 게임: 종족 선택 후 바로 던전 1층으로 출발.
- 기존 정착지 저장: 건설·주민 작업 화면 대신 마을 준비 UI 제공.
- 거점 현황 메뉴, 거점 구입/건설 진입, 정착지 자동 작업 시계 비활성화.
- 시장·치유소·동료·장비·원정 준비는 유지. 정착지 시뮬레이션과 기존 저널 재생 서비스는 삭제하지 않음.

## 검증

아래 네 검사를 모두 통과했다.

- `tests/blood_depletion_acceptance.gd`: 혈액 경계값 fixture에 실제 피격 적용 → 같은 시간 사망, 행동 거부, 세계 검증, 저장 복원. 이전 혈액 0 생존 저장도 검사. 초기 혈액값만 경계 조건으로 설정하며 사망 결과를 주입하지 않는다.
- `tests/settlement_suspended_acceptance.gd`: 390×844 UI에서 기존 정착지 화면/메뉴 숨김, 자동 작업 중지, 새 게임 던전 진입. X11 렌더러 사용.
- `tests/monster_all_abilities_acceptance.gd`: 이능 전투·저장 회귀.
- `tests/run_ability_binding_tests.gd`: 결속 회귀 6개.

실제 휴대폰 플레이 및 장기 출혈 밸런스 검수는 별도로 필요하다.
