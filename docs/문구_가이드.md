# 문구 가이드

상태: ✅ 적용됨 (2026-09-29, §7 적용 기록) · 2026-09-30 실시간 전환: 시간은 초(§1.10)

작성일: 2026-09-29 · 대상: 게임 안에 보이는 모든 한국어 문구(`js/data/*`, `js/core/*`의 `log`·`add`, `js/ui/*`, `js/town/*`의 `toast`·창 글)

게임 문구가 "AI가 쓴 설명"처럼 읽히지 않게 하는 기준이다. 새 문구를 쓸 때도, 고칠 때도 이 문서를 따른다.

## 0. 목표

- 플레이어는 **게임 속 세계의 말**을 듣고, **짧은 규칙 한 줄**을 읽는다. 해설을 듣지 않는다.
- 규칙 설명은 정확하고 짧게. 분위기 문장은 구체적이고 담담하게.
- 같은 내용을 두 번 말하지 않는다(대상 정보 창, 길게 누르기 설명, 로그가 겹치지 않게).

## 1. 없앨 패턴

### 1.1 줄표(—)로 문장 잇기

줄표는 거의 쓰지 않는다. 두 문장으로 나누거나, 조사로 잇거나, 뒤를 지운다.

| 전 | 후 |
| --- | --- |
| `약점 발견 — 해골은 타격에 약하다!` | `해골은 타격에 약하다.` |
| `이솔의 등잔 — 아직 따뜻하다. 횃불 +40` | `이솔의 등잔. 아직 따뜻하다.` (횃불 수치는 HUD의 불꽃이 보여준다) |
| `○○ — 속성 하나가 드러났다` | `○○의 속성 하나를 알아냈다.` |
| `전투가 끝났다 — 영혼석 스킬이 모두 준비됐다` | `전투가 끝났다.` (칸이 밝아지는 것으로 충분) |

### 1.2 조사 얼버무림

`이(가)`, `을(를)`, `은(는)`, `과(와)`를 쓰지 않는다. 이름이 변수면 반드시 `jo(이름, '이가')` 같은 조사 함수로 맞춘다.

| 전 | 후 |
| --- | --- |
| `` `${v.npc.name}이(가) 불빛을 보고 찾아왔다` `` | `` `${jo(v.npc.name, '이가')} 불빛을 보고 찾아왔다.` `` |
| `` `${e.name}이(가) 주문을 외운다` `` | `` `${jo(e.name, '이가')} 주문을 외운다.` `` |

### 1.3 로그가 조작 설명서가 되는 것

로그는 **일어난 일**만 적는다. 무엇을 누르라는 말, 어떻게 하라는 명령은 넣지 않는다. 조작 안내는 상황 버튼·길게 누르기·도움말이 맡는다.

| 전 | 후 |
| --- | --- |
| `장검이 떨어져 있다 — 줍기 버튼` | `장검이 떨어져 있다.` (상황 버튼이 뜬다) |
| `마법사가 주문을 외운다 — 붉은 칸에서 벗어나라!` | `마법사가 주문을 외운다.` (붉은 칸과 위험 경고가 보인다) |
| `멧돼지가 발을 구른다 — 화살표 경로에서 비켜라!` | `멧돼지가 발을 구른다.` |
| `○○을 풀어 주었다 — 곁에 둔 채 계단까지 데려가자` | `○○을 풀어 주었다.` (처음 한 번만 도움말로 안내) |
| 아이템 설명의 `— 장비 창에서 [강화]` | 삭제 (두루마리를 누르면 창이 열린다) |

### 1.4 한 줄에 규칙 몰아넣기

설명 한 줄에는 **핵심 효과 하나**와 **가장 중요한 반응 하나**까지만. 나머지 반응은 원소 도움말이나 길게 누르기 상세에 둔다.

| 전 | 후 |
| --- | --- |
| `4 화염 + 화상. 풀 번짐, 기름 폭발, 빙결 증기 폭발, 중독 독 폭발` | `불 4, 화상. 풀과 기름에 불이 붙는다.` |
| `5 번개. 물·젖은 대상이면 이어진 곳 전체 감전(+2, 기절)` | `번개 5. 젖은 적과 물을 타고 번진다.` |
| `2 피해 + 빙결 2턴(젖었으면 5턴). 십자 범위 물을 얼음으로` | `냉기 2, 2턴 얼린다. 젖은 적은 더 오래.` |

### 1.5 개발자 말투

문장 안에 `→`, `+2`만 덩그러니, `(…규칙 동일)`, `(상한 +6)`, `(최소 2)`, `3×3`, `R`, `cd` 같은 표기를 쓰지 않는다. 숫자가 필요하면 **"피해 4", "3초", "2칸"**처럼 단위와 함께 쓴다.

| 전 | 후 |
| --- | --- |
| `붙은 적을 3칸 밀치고 기절 1턴 (벽 충돌 규칙 동일)` | `붙은 적을 3칸 밀쳐 한 턴 기절시킨다.` |
| `무기 하나를 +1 (상한 +6)` | `무기 하나를 강화한다.` (상한은 강화할 수 없을 때 버튼이 꺼지는 것으로) |
| `십자 5칸에 물웅덩이. 닿은 적은 젖는다 → 번개가 번지고, 얼면 오래 간다.` | `십자 모양으로 물을 쏟는다. 닿은 적은 젖는다.` |
| `빨강 영혼석 기본 쿨타임 −1 (최소 2)` | `빨강 영혼석이 한 턴 빨리 돈다.` |

- 예외: 영혼석 칸의 숫자, HP·횃불 숫자, 피해 숫자 팝업처럼 **UI 요소 자체**는 숫자만 써도 된다.

### 1.6 괄호 속 보충 설명

괄호로 조건을 덧붙이지 않는다. 중요하면 문장으로, 아니면 지운다.

| 전 | 후 |
| --- | --- |
| `한 턴 동안 빛이 모인 뒤 정착지로 돌아간다(그 사이 맞으면 피해는 받는다). 전리품은 챙기지만 이 구역은 처음부터 다시. 보스 층에서는 쓸 수 없다.` | `한 턴 뒤 정착지로 돌아간다. 이 구역은 처음부터 다시 해야 한다.` (보스 층 금지는 쓰려 할 때 로그로) |
| `거리를 두고 조준(붉은 점선)한 뒤 다음 턴에 쏜다.` | `거리를 두고 조준한 뒤 다음 턴에 쏜다.` |

### 1.7 과한 극적 표현·느낌표

느낌표는 정말 드문 순간(유품 발견, 보스 처치, 레벨 업)에만. 나머지는 마침표.
`모든 것이 섞인다. 아껴 둔 것을 쓸 때다.` 같은 **해설자 목소리**를 쓰지 않는다.

| 전 | 후 |
| --- | --- |
| `무지갯빛 — 유물이다!` | `무지갯빛이 번진다.` |
| `○○ 처치 — 산산조각!` | `○○이 산산이 부서졌다.` |
| `모든 것이 섞인다. 아껴 둔 것을 쓸 때다. 이 층의 계단을 내려가면 탈출.` | `얼어붙은 회랑의 끝. 계단 너머에서 무언가 기다린다.` |
| `상자를 열었다!` | `상자를 열었다.` |

### 1.8 주제를 대사로 말하기

주민 대사에서 게임의 주제(이름·기억·불)를 직접 설명하지 않는다. 사람은 자기 일과 걱정을 말한다. 주제는 **행동과 상황**에서 드러난다.

| 전 | 후 |
| --- | --- |
| `불가에 앉아요. 이름을 불러 줄 사람이 많을수록 따뜻하대요.` | `불가에 앉아요. 수프 남았어요.` |
| `잊힌 이름에도 이야기가 남아 있을 거야.` | `저 아래 비석, 글자가 아직 읽혀.` |
| `서로 이름이라도 불러요, 제발.` | `…누구 거기 있어요?` |
| `누구든 불가에 앉을 자리는 있어요.` | `자리 좁혀 드릴게요.` |

- 주제를 말하는 대사는 결말과 조각 넣기 연출(목소리들)에만 허용한다.

### 1.9 이모지

로그와 사건 문장 앞의 이모지는 **아이콘 자리에만**(사건 목록의 머리 아이콘, 버튼 아이콘). 문장 속 이모지(`뿔나팔(📯)`, `⚡번개`)는 쓰지 않는다.

### 1.10 시간은 초, 파티 문구는 짧게 (2026-09-30)

실시간 전환(`설계_실시간_전환.md`)으로 턴이 없어졌다.

- 시간은 **"N초"**로 쓴다. "턴", "한 턴", "N턴"은 쓰지 않는다. 전투 라운드 1초, 걸음 한 칸 0.3초 기준.
- 거리는 칸이 아니라 시간·모양으로 말하는 쪽이 낫다. 꼭 필요하면 "2칸"보다 "가까이", 상세 창에서만 "2m".
- 파티 명령·파티원 이름표는 짧게: `집중` `흩어져` `모여` `물러나` `자동`. 두 글자~세 글자, 설명은 길게 누르기에.

| 전 | 후 |
| --- | --- |
| `냉기 2, 2턴 얼린다.` | `냉기 2, 2초 얼린다.` |
| `한 턴 뒤 정착지로 돌아간다.` | `1초 뒤 정착지로 돌아간다.` |
| `모두 한 적을 노려라` | `집중` |

## 2. 종류별 목소리

| 종류 | 목소리 | 길이 | 예 |
| --- | --- | --- | --- |
| **아이템·영혼석 설명** | 규칙을 담담하게. 주어 없이 "~한다." | 한두 문장 | `붙은 적을 두 번 벤다. 두 번째는 출혈 중인 적에게 더 아프다.` |
| **몬스터 설명** | 관찰한 사실 | 한 문장 | `바닥에 표식을 남기고, 다음 턴에 그 자리에 주문을 떨어뜨린다.` |
| **몬스터 팁** | 경험 많은 동료의 한마디. 명령형 "~해라"는 피하고 "~하면 ~한다" | 한 문장 | `표식 밖으로 비켜서면 주문은 빗나간다.` |
| **로그** | 일어난 일, 과거형 또는 현재형, 마침표 | 한 문장, 20자 안팎 | `고블린을 쓰러뜨렸다.` `화살이 빗나갔다.` |
| **토스트** | 짧은 알림 | 한 구절 | `가방이 가득 찼다.` |
| **주민 대사** | 그 사람의 말투. 구체적인 일상 | 한 문장 | `망치 자루가 또 쪼개졌어.` |
| **정착지 사건** | 이야기책처럼 담담한 과거형 | 한두 문장 | `도윤이 새로 온 서연을 데리고 마을을 돌았다.` |
| **구역·층 소개** | 장소 묘사 한 줄, 조언 없음 | 한 문장 | `물이 발목까지 차오른 지하실.` |
| **도움말** | 여기서만 조작과 규칙을 설명한다 | 필요한 만큼 | — |

## 3. 숫자와 규칙 정보를 두는 곳

- 한 줄 설명(`line`, `desc`)은 짧게. **정확한 수치가 필요한 정보**는 길게 누르기 상세 창에 표처럼 둔다(피해 4 · 3턴 · 사거리 5).
- 같은 정보를 로그·설명·상세에 반복하지 않는다.
- 원소 반응 전체 목록은 도움말의 "원소" 한 곳에만.

## 4. 금지 목록 (검색해서 없앤다)

`이(가)` `을(를)` `은(는)` `과(와)` · 문장 속 `—` · 문장 속 `→` · `규칙 동일` · `(상한` · `(최소` · 문구 속 `턴`(→ `초`) · 로그 속 `버튼` · 로그 속 명령형 `~라!` · 해설자 문장("~할 때다", "모든 것이") · 문장 속 이모지

## 5. 확인 목록

1. 금지 목록 검색 결과가 0(도움말·결말 연출의 의도된 예외는 주석으로 표시).
2. 로그 한 줄이 대체로 25자를 넘지 않는다.
3. 아이템·영혼석 설명이 두 문장을 넘지 않는다.
4. 주민 대사에 "이름·기억·불"을 설명하는 문장이 결말·조각 연출 밖에 없다.
5. 조사 함수(`jo`)를 쓰지 않은 변수 이름 + 조사가 없다.
6. 문구만 바뀌고 게임 규칙·수치는 바뀌지 않았다. `npm run test:all` 통과(테스트가 문구를 검사하면 테스트 쪽 기대 문구를 함께 고친다).

## 6. AI에게 줄 프롬프트

```
첨부한 docs/문구_가이드.md에 따라 게임 안의 모든 한국어 문구를 고쳐주세요.
대상: js/data/*.js(설명·팁·대사·이름표), js/core/*.js의 log()·add(), js/ui/*.js와 js/town/*.js의 toast()·창 글, index.html의 고정 문구.

1. 규칙과 수치는 바꾸지 마세요. 문구만 바꿉니다. 설명에서 뺀 수치가 게임에 꼭 필요하면 길게 누르기 상세 창으로 옮기세요(§3).
2. §1의 패턴을 모두 없애고, §2의 종류별 목소리에 맞추세요. §4 금지 목록은 검색해서 하나씩 지우세요.
3. 이름이 변수인 곳은 조사 함수 jo()를 쓰세요.
4. 주민 대사(js/data/lines.js)는 §1.8에 따라 구체적인 일상으로 바꾸되, 성격(정직·감정성·외향성·원만성·성실성·개방성)과 높음/낮음의 차이는 유지하세요.
5. 로그가 조작을 안내하던 곳(줍기 버튼, 붉은 칸에서 벗어나라 등)은 로그에서 지우고, 처음 한 번만 뜨는 도움말이 필요하면 도움말 쪽에 넣으세요.
6. 끝나면 §5 확인 목록을 확인하고, 파일별로 바꾼 줄 수와 금지 목록 검색 결과, 판단이 애매했던 문구 10개(전·후)를 보고해주세요.
7. 이 문서 첫머리 상태 줄을 "적용됨(커밋)"으로 바꾸고 끝에 적용 기록을 남기세요.
```

## 7. 적용 기록

- 2026-09-29: 37개 파일, 약 430줄. 데이터 설명 · 주민 대사와 정착지 · 던전 로그 · 화면과 도움말 네 묶음으로 나눠 고쳤다.
- 금지 목록 검색 결과: 조사 얼버무림·"규칙 동일"·"(상한"·"(최소" 0. 남은 `→`·`—`는 주석, 장비 비교 행(`색: A → B`), 유품 인용 출처뿐.
- 함께 고친 버그: 등불지기 잇기 장면의 잘못된 조사, 영혼석 제단의 "보라이 된다".
- 도움말에서 코드와 맞지 않던 설명(쿨타임은 전투 뒤에도 이어짐, 없어진 무기 교체)을 고쳤다.
- 층 소개가 장소 묘사로만 바뀌면서, 거기 있던 조언(예: 마지막 층 "계단을 내려가면 탈출")은 도움말·"지금 할 일"로 옮길 거리로 남았다.
- 테스트: smoke 10, items 20, story 12, stones 19, settlement 14 통과. dungeon의 "사망 요약" 한 항목은 이 작업 전부터 실패(사망 화면에 찾는 단어가 없음, 3985ccd4).
