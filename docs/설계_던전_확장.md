# 던전 설계 (묵직한 던전 크롤링: 소모 · 위협 · 맵 · 도주)

상태: 🟨 1단계 · 5단계 구현됨 (§14 적용 기록) · 2~4단계 대기

작성일: 2026-09-29 · 대상: `js/core/`(전투·AI·층 생성·턴), `js/data/`(적·층·소모품), `js/render/`·`js/ui/`(연출·정보 카드)
이어지는 문서: `설계_영혼석_스킬.md`(쿨타임 규칙이 바뀐다), `밸런스_기준.md`(회복·체급 곡선), `설계_진행_레벨디자인.md`(1장 튜토리얼 던전과 난이도 곡선), `설계_아이템_장비.md`, `문구_가이드.md`
이 문서가 바꾸는 것: 싸움마다 초기화되는 흐름, 적 4종·맵 한 가지, 되돌아갈 수 없는 층

## 0. 플레이어가 느껴야 할 것

- **한 층 내려갈 때마다 가진 것이 줄어든다.** HP, 영혼석, 소모품, 횃불. 계단 앞에서 "한 층 더 갈까, 돌아갈까"를 고민한다.
- **처음 보는 적은 무섭다.** 모든 적이 공격을 미리 알려 주지는 않는다. 정보 카드를 읽고, 복도를 고르고, 싸울지 말지 정한다.
- **도망도 전술이다.** 빠른 적과 느린 적이 있고, 계단으로 물러날 수 있다.
- **층마다 모양이 다르다.** 동굴, 좁은 굴, 기둥 홀, 특별한 방. 내려갈 때마다 "이번엔 뭐지?"
- **죽음은 아프지만 납득된다.** 무엇에, 왜 죽었는지 안다.

지금은 이렇지 않다. 싸움이 끝나면 영혼석이 모두 준비되고, HP가 저절로 차며, 대부분의 공격이 예고되고, 적은 네 종류, 맵은 방과 복도 한 가지다. 그래서 싸움 하나하나가 따로 노는 퍼즐이 되고, 무게가 쌓이지 않는다.

## 1. 원칙

1. **소모는 이어진다.** 싸움과 싸움 사이에 공짜 초기화가 없다. 회복에는 늘 대가(횃불, 소모품, 위험)가 따른다.
2. **위협은 읽히되, 다 읽히지는 않는다.** 지금의 예고형 적(마법사·멧돼지·궁수)은 그대로 두고, 예고 없이 빠르거나 세거나 숨어 있는 적을 섞는다. 예고가 없는 대신 **정보는 준다**: 정보 카드, 처음 만날 때의 경고, 머리 위 표시.
3. **도망칠 수 있어야 공정하다.** 모든 층에 물러날 길(올라가는 계단)이 있고, 탈출 소모품이 드물게 있다.
4. **새 적은 새 판단이다.** 색만 바꾼 적은 만들지 않는다. 적 하나는 "이렇게 대처한다" 한 줄로 설명된다.
5. **무게는 규칙이 먼저, 연출은 뒷받침.** 규칙이 가벼우면 어두운 화면으로도 무거워지지 않는다.
6. **튜토리얼은 가볍게.** 1장 무너진 우물(`설계_진행_레벨디자인.md` §4)은 이 문서의 소모 규칙을 약하게 적용한다(§3.6).

## 2. 무엇이 바뀌나

| 항목 | 지금 | 바뀐 뒤 |
| --- | --- | --- |
| 영혼석 쿨타임 | 전투가 끝나면 모두 준비 | **초기화 없음.** 턴마다 1씩(전투 밖도), 색 감소 규칙 그대로 |
| HP 자동 회복 | 6턴마다 1(전투 중에도) | **그대로 둔다**(2026-09-29 결정). 휴식·물약·레벨업·샘이 더 빠른 회복 |
| 휴식 | 최대 40턴, 턴당 횃불 0.5 | 턴당 횃불 1, 3턴마다 HP 1, **방랑하는 적이 올 수 있다** |
| 적 종류 | 일반 4종 + 보스 4 | 구역마다 3~4종 추가(총 17종 안팎) + 강적(이름 붙은 적) + 깊이 밖의 적 |
| 적 속도 | 모두 같음 | 빠름(한 턴 두 칸) · 보통 · 느림(두 턴에 한 번) |
| 예고 | 거의 모두 | 기존 예고 적 + 예고 없는 적(정보는 준다) |
| 맵 | 방 + 복도 한 가지 | 생성기 5종 + 특별 방 + 층 특성 |
| 층 이동 | 내려가기만 | **올라가는 계단**(이전 층 그대로), 1층 계단으로 걸어서 귀환 |
| 연출 | 가볍고 통통 튄다 | 큰 피해의 멈칫·흔들림, 빈사 화면, 사망 요약 |

## 3. 소모 (1단계)

### 3.1 HP

- **자동 회복은 그대로 둔다**(6턴마다 1, 2026-09-29 결정). 소모의 무게는 쿨타임·휴식·방랑하는 적이 맡는다.
- 회복하는 길:
  - 휴식(§3.3). 횃불을 태우고, 들킬 수 있다.
  - 치유 물약. 지금 그대로.
  - **레벨업**: 최대 HP +2(지금) + **잃은 HP의 절반 회복**.
  - 샘(특별 방, §5.2). 한 번만.
  - 정착지 귀환.
- 기준: 1구역 일반 전투 한 번에 평균 HP 5~8을 잃는다. 한 층을 다 돌면 휴식이나 물약 없이는 버티기 어렵다(`밸런스_기준.md` §7 체급 곡선에 맞춰 조정).

### 3.2 영혼석 쿨타임

- **전투가 끝나도 초기화하지 않는다**(`stones.js` `endRound`의 전투 밖 초기화 삭제).
- 내 턴이 끝날 때마다 1씩 준다(지금 규칙). 전투 밖에서도 같다. 색 감소(빨강 적중·보라 대기·초록 피격)도 전투 중에만 그대로.
- 결과: 큰 스킬을 쓴 뒤 바로 다음 방으로 들어가면 손이 비어 있다. 기다리면 횃불이 준다. 이것이 **소모와 시계를 잇는 고리**다.
- `설계_영혼석_스킬.md` §2의 "쿨타임은 전투 중에만 흐른다(전투 밖이면 즉시 준비)", §5의 "전투 밖에서는 0", §6-5를 이 규칙으로 고친다. 그 규칙의 이유였던 "전투 전 대기로 미리 채우기"는 여기서도 생기지 않는다. 쿨타임은 0 아래로 쌓이지 않으므로 기다려서 얻는 것은 준비 상태뿐이고, 그 값은 횃불로 치른다.

### 3.3 휴식

| 항목 | 값 |
| --- | --- |
| 횃불 | 휴식 한 턴마다 1 (보통 턴은 지금처럼 0.5) |
| HP | 3턴마다 1 |
| 영혼석 | 턴마다 1 (보통 턴과 같다) |
| 방랑하는 적 | 휴식 한 턴마다 2%(횃불 25 미만이면 4%)로 가까운 방에 무리 하나가 생겨 다가온다 |
| 멈춤 | 적이 보이거나 맞으면(지금 규칙) |

- 로그: `어디선가 발소리가 다가온다.` (방랑하는 적이 생길 때)
- 휴식은 "HP·영혼석 ↔ 횃불·위험"의 교환이다. 횃불이 모자라면 쉬지 못하고, 쉬지 못하면 다친 채 싸운다.

### 3.4 횃불

- 시계 역할은 그대로(`밸런스_기준.md` §6.1). 휴식이 두 배로 태우므로 등잔·불씨 단지의 값이 오른다.
- 어둠의 사나움과 드롭 배율(2026-09-29 적용)은 그대로 둔다.

### 3.5 소모품

- 드롭 수는 지금 그대로. 소모가 이어지므로 같은 물약도 더 귀해진다.
- 미확인 물약에 나쁜 효과(혼란·어둠·중독) 섞기는 **열린 결정**(§12).

### 3.6 튜토리얼과 1구역

- 무너진 우물(1장)은 자동 회복을 켜 두고 방랑하는 적이 없다(배우는 곳).
- 1구역(3장)부터 이 문서의 규칙을 모두 적용한다. 목표: 처음 하는 사람 사망률 30~50%(`설계_진행_레벨디자인.md` §8).

### 4.3 강적과 깊이 밖의 적

- **강적(이름 붙은 적)**: 층마다 8%로 하나. 보통 적 하나를 바탕으로 HP ×2, 능력 하나 더(예: 외눈 그락 = 고블린 족장의 부하, 나팔을 분다). 드롭: 장비 확정 + 영혼석 확정.
- **깊이 밖의 적**: 층마다 10%로 다음 구역의 적 한 무리.
- 둘 중 하나가 있는 층은 들어설 때 로그 한 줄: `불길한 기운이 감돈다.` 정체는 보여주지 않는다.

### 4.4 예고와 정보

- 기존 예고 적은 그대로. 새 적의 절반은 예고가 없다.
- 예고 대신 정보:
  - **처음 만날 때** 적 이름 옆에 `처음 보는 적` 표시가 한 번 뜬다. 길게 누르면 정보 카드가 열린다.
  - 정보 카드에 **속도**(`빠름: 도망칠 수 없다` / `느림`)와 **위험** 한 줄을 넣는다.
  - 머리 위: 빠름 `»`, 느림 `«`.

### 4.5 속도

| 속도 | 규칙 |
| --- | --- |
| 빠름 | 한 턴에 두 번 움직인다. 공격은 한 번(움직이고 공격 가능) |
| 보통 | 지금 그대로 |
| 느림 | 두 턴에 한 번 행동한다 |

- 가속 물약(`haste`)의 규칙과 같은 틀로 만든다.

### 4.6 수치 기준

- 1구역 일반 적 셋에 둘러싸이면 **4~5턴 안에 위험**(합산 턴당 피해 5~6)해야 한다.
- 1구역 한 층의 적 수는 지금(약 15)을 유지하고, 종류가 섞인다.

## 5. 맵

### 5.1 생성기

| 생성기 | 모양 | 전술 | 잘 나오는 구역 |
| --- | --- | --- | --- |
| 방과 복도 | 지금 방식 | 복도에서 한 줄 | 모두 |
| 동굴 | 셀룰러 오토마타, 불규칙한 넓은 공간 | 시야가 트여 원거리가 강하다 | 1, 4 |
| 좁은 굴 | 구불구불한 한 칸 통로와 작은 방 | 매복, 도망이 어렵다 | 2, 3 |
| 기둥 홀 | 기둥이 늘어선 큰 방 + 곁방 | 기둥 뒤로 시야를 끊는다 | 2, 4 |
| 무너진 지대 | 방과 복도 + 무너진 벽 + 구덩이 | 적을 구덩이로 밀면 떨어진다(즉사, 드롭 없음) | 3, 4 |

- 구덩이에 주인공이 떨어지면 다음 층으로 떨어지고 HP 5를 잃는다(열린 결정 §12).
- 크기는 40×40(2026-09-29) 그대로.

### 5.2 특별 방 (손으로 만든 작은 틀)

층마다 0~2개. 각 틀은 `js/data/vaults.js`의 작은 글자 지도.

| 방 | 내용 |
| --- | --- |
| 보물고 | 잠긴 문, 강적 하나가 지킨다. 장비 2개 |
| 괴물 둥지 | 무리 둘 + 보상 상자 |
| 옛 등불지기의 야영지 | 등잔 + 기록 한 장 + 비석 |
| 샘 | 한 번 HP 전부 회복(쓰면 마른다) |
| 영혼석 제단 | 가진 영혼석 하나를 바치면 다른 색 하나를 준다 |
| 버려진 대장간 | 무기 하나 강화 +1 (한 번) |
| 물에 잠긴 신전 | 물 가득, 거머리, 가운데 보물 |
| 감옥 | 갇힌 사람(지금의 구출 NPC)을 이곳에 둔다 |

### 5.3 층 특성

들어설 때 한 줄로 알린다. 층마다 25%로 하나.

| 특성 | 효과 | 로그 |
| --- | --- | --- |
| 물이 불었다 | 물 칸 두 배 | `물이 발목까지 차 있다.` |
| 짙은 어둠 | 횃불 소모 ×1.5 | `빛이 금방 삼켜진다.` |
| 고요 | 적 절반, 보물 +1 | `이상하게 조용하다.` |
| 둥지 | 무리 +2 | `여기저기서 긁는 소리가 난다.` |

## 6. 도주와 귀환

### 6.1 올라가는 계단

- 층마다 도착 지점에 **올라가는 계단**이 생긴다. 오르면 **이전 층이 떠날 때 그대로** 있다(층 상태 저장).
- 계단을 오르내릴 때 **붙어 있던 적만** 따라온다(DCSS와 같다).
- 1층의 올라가는 계단으로 나가면 **걸어서 귀환**한다: 전리품은 챙기고, 구역 진행은 처음부터(귀환 두루마리와 같다).
- 결과: "한 층 더"와 "돌아가기"가 층마다 선택이 된다.

### 6.2 탈출 소모품

| 소모품 | 효과 | 지금 |
| --- | --- | --- |
| 순간이동 두루마리 | 층 안 무작위 칸으로 | 있음(`tele`) — 드롭 비율을 올린다 |
| 연기 단지 | 시야를 끊는 연기 | 있음(`smoke`) |
| 섬광 | 주변 적 2턴 실명(따라오지 못한다) | 새로 |

### 6.3 원정 길이

- **구역 = 5층**(1~4층 + 5층 보스). 2026-09-29에 정하고 적용했다(`ZONE_FLOORS`). 적 HP는 층마다 +5%(예전 +8%), 보스 HP는 층당 +2.5%로 낮춰 20층 끝이 예전 12층과 비슷하다. 장비 품질·드롭 표는 층이 아니라 구역을 본다.

## 7. 연출 무게 (규칙을 뒷받침)

- **큰 피해**(최대 HP의 20% 이상): 짧은 멈칫(hitstop 80ms) + 화면 흔들림 + 화면 가장자리 붉은 테.
- **빈사**(HP 30% 이하): 화면 가장자리가 어둡게 조여 들고 낮은 심장 소리. 자동 탐험이 켜지지 않는다.
- **처음 보는 적 · 강적 층**: 짧은 낮은 울림.
- **적의 공격**: 튕기듯 가벼운 움직임 대신 한 번 물러났다 내딛는 무게 있는 동작.
- **사망 요약**: 누구에게, 무엇으로 죽었는지. 마지막 5턴 기록, 층·턴·처치 수. 비석에 새길 한 줄.
- 색·빛: 이펙트 채도를 조금 낮추고, 치비 인형의 튕김을 줄인다(모양은 그대로).

## 10. 확인 목록 (1단계)

1. 전투가 끝나도 영혼석 쿨타임이 그대로 남고, 전투 밖에서도 턴마다 1씩 준다.
2. 휴식은 턴마다 횃불 1을 쓰고, 3턴마다 HP 1을 채운다(자동 회복 6턴마다 1은 그대로).
3. 휴식 중에 방랑하는 적이 올 수 있고(횃불 25 미만이면 두 배), 보이면 휴식이 멈춘다.
4. 레벨업 때 잃은 HP의 절반이 찬다.
5. 빠른 적은 한 턴에 두 칸, 느린 적은 두 턴에 한 번 움직이고, 머리 위에 `»`/`«`가 보인다.
6. 쥐 떼(빠름·무리), 거머리(물속에 숨음·출혈), 고블린 주술사(치유·보호막)가 1구역에 섞여 나온다.
7. 처음 만난 적에 `처음 보는 적` 표시, 정보 카드에 속도와 위험 한 줄.
8. 1장 튜토리얼 던전(생기면)은 자동 회복이 켜져 있다.
9. `npm run test:all` 통과(새 검사는 `tests/dungeon.mjs`), 페이지 오류 0.

## 11. 정한 것 (2026-09-29)

- 목표는 "묵직한 던전 크롤링"(DCSS의 무게). 전술 퍼즐(예고)은 버리지 않고 섞는다.
- 소모가 이어지는 것이 첫째. 콘텐츠(적·맵)는 그 위에 쌓는다.
- 구역은 5층(1~4층 + 5층 보스). 적용함.

## 12. 열린 결정

- 층 상태 저장: 저장 크기(40×40 층 여러 개)와 모바일 메모리.
- 구덩이에 주인공이 떨어질 때: 다음 층 + HP 5 vs 떨어지지 않음(가장자리에서 멈춤).
- 미확인 물약의 나쁜 효과(혼란·어둠·중독)를 넣을지.
- 방랑하는 적 확률(2%/4%), 강적 8%, 깊이 밖의 적 10%.
- 도둑 쥐인간이 훔친 물건: 잡으면 돌려받는다 vs 층을 나가면 잃는다.
