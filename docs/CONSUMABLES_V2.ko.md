# 포션·스크롤 확장 v2 (2026-09-13)

## 범위와 결정
사용자 승인: 긍정 6종·부정 3종을 포션과 스크롤에 각각 추가/정리하고 메인에 푸시.
기존 이능과 전투·이동 파이프라인을 재사용한다. 새 정착지 기능이나 몬스터 수 변경은 없다.

- 실제 드롭 목록은 포션 9종, 스크롤 9종. 기존 회복 스크롤 2종은 저장 호환용으로 유지하되 신규 드롭에서 제외한다.
- 사망 시 소모품 추가 드롭 확률 18%는 유지한다. 소모품 내부 선택은 긍정 75%, 부정 25%이며 각 그룹 내 균등 선택이다. 기존 장비·마석·이능 드롭 난수는 변경하지 않는다.
- 처음에는 번호가 붙은 봉인병/문양만 보이고 효과와 수치는 숨긴다. 외형 대응은 판마다 시드 기반 순열이며 저장·층 이동 중 유지한다. 기존 이미지와 병 변형을 재사용하고, 가방·바닥에 같은 외형 번호를 그린다.
- 사용 시 같은 종류 전체를 감정한다. 미감정 대상형 스크롤은 적합한 자동 대상을 사용하고, 대상이 없으면 효과 없이 감정한다. 감정 후 점멸·봉인·감정·독 투척은 선택창을 연다. 취소/잘못된 대상은 소모하지 않는다.
- 지속시간 표기의 1턴은 게임 시간 100이다. 사용 행동 자체도 시간이 지나므로 사용 직후 남은 시간은 표의 최초 지속시간보다 짧을 수 있다. 캐릭터 창에 현재 상태와 남은 시간이 보인다.

## 세부 규칙 / 의도적인 제한

- 독은 4회까지 표준 물리 피해 경로로 처리한다(방어 적용). 물약 독 자체로 마지막 HP 1을 제거하지 않는다. 적에게 받은 공격까지 막아주는 것은 아니다.
- 재생은 5회까지 매 회 HP 6을 회복하며 최대 HP를 넘지 않는다.
- 정화는 물약의 독·둔화·쇠약·혼란과 기존 이능의 독·둔화를 지운다. 불붙은 지형 자체를 지우지 않는다.
- 쇠약은 명중 -20%p 및 장비/버프 방어 기여분 최대 3 감소(0 미만으로 내리지 않음)로 구현했다. 무기 공격력 원본은 바꾸지 않는다.
- 봉인은 스킬 사용과 일반 공격의 출혈 부가효과를 차단한다. 일반 공격 자체는 가능하다. 몬스터에 새로운 특수공격 AI를 추가하는 작업은 아니다.
- 공포는 적의 이동 판단을 플레이어에게서 멀어지는 방향으로 바꾸고, 빈칸이 없으면 대기한다. 이동 예약 충돌 때 다시 접근하는 대안을 선택하지 않는다.
- 점멸/불안정 전이는 최대 5칸이며 벽·점유·물·용암·고열·연기 타일을 피한다. 벽 너머 미탐색 공간으로 순간이동하지 않는다. 점멸은 감정 후 상대좌표 목록에서 선택한다.
- 충격파는 보이는 2칸 내 적을 최대 2칸 밀어낸다. 막힌 지형/점유를 관통하지 않는다.
- 지도는 주변 10칸의 지형을 희미한 기억으로만 공개한다. 적/NPC의 현재 위치나 시야를 공개하지 않는다.
- 소란은 10칸 내 적의 경계를 올리고 사용 위치를 추적 목표로 전달한다. 반경 밖의 적을 전역 활성화하지 않는다.
- 새 소비/상태/지도/이동 이벤트와 선택 명령을 기록한다. 실패 시 수량·상태·시간·명령을 롤백한다.
- v5 드롭을 추가했으며 v4의 기존 4종 소모품 확률표는 과거 드롭 검증용으로 고정했다. v2 외형 순열 도입으로 기존 v1 저장의 미감정 외형 번호는 업데이트 시 바뀔 수 있다. 실제 효과/감정 여부는 바뀌지 않는다.
