# 몬스터·이능 콘텐츠 목록

- 작성일: 2026-09-10
- 상태: 콘텐츠 기준안. 이 문서에 적힌 항목이 모두 런타임에 등록됐다는 뜻은 아니다.
- 목표 규모: 몬스터 8계통 × 기본형·전문형·상위형 3종 = 24프로필, 흡수 가능한 계통 이능 16개

## 1. 현재 구현 기준

현재 실제 종족 카탈로그와 종족 드롭은 고블린까지 연결되어 있다. 코볼트·슬라임·딱정벌레는 일부 맵·성장·시각·미술 경로에 이름이나 표현이 있으나, 모두가 완전한 몸체·장비·드롭·AI 프로필을 가진 상태는 아니다.

`STRIKE`, `SHOVE`, `FIREBOLT`, `BARRIER`, `MEND`는 행동 비용과 대상을 갖는 전투 기술이다. 이 문서의 **몬스터 이능**은 주로 `PASSIVE`, `ON_HIT`, `ON_HURT`, `INTERACT`로 발동하는 결속 효과다. 전투 기술을 쓰는 몬스터를 처치했다고 그 기술을 자동 획득하지 않는다. `ESSENCE_FIRE_BOLT`는 이미 존재하는 액티브 이능 획득물 후보이므로 별도 예외로 유지하며, 실제 화염 사용자와 흡수 서비스가 연결되기 전까지 드롭하지 않는다.

이능은 같은 canonical ID를 중복 결속하지 않고, 캐릭터 레벨에 따른 최대 6칸을 공유한다. 제거·회수 정책은 아직 미정이므로 이 목록에서 제거 비용이나 영구 소멸을 확정하지 않는다.

## 3. 흡수 가능한 몬스터 이능 16개

수치는 구현 시 공용 피해·방어·시야·환경 계산의 기존 단위를 사용해 정한다. 이능이 만든 추가 피해나 상태는 다른 이능을 다시 발동시키지 않으며, 하나의 원본 행동에서 이능 발동은 최대 2회로 제한한다.

| 계통 | 이능 ID | 표시명 | 트리거 | 효과 계약 | 명시적 대가 | 현재 상태 |

## 4. 전투 기술 배정 원칙

| 기술 ID | 용도 | 우선 사용자 | 이능 드롭 방침 |
|---|---|---|---|
| `STRIKE` | 단일 근접 강타 | 약탈꾼, 멧돼지, 철갑충 | 기본 전투 기술이므로 자동 드롭하지 않음 |
| `SHOVE` | 근접 위치 제어 | 멧돼지, 철갑충, 상위 수호형 | 기본 전투 기술이므로 자동 드롭하지 않음 |
| `FIREBOLT` | 단일 원거리 화염 피해 | 고블린 불주술사, 불씨 정령 | `ESSENCE_FIRE_BOLT`의 명시된 출처 후보. 흡수 서비스 전에는 드롭 잠금 |
| `BARRIER` | 아군 보호 | 균사 수호자, 상위 주술형 | 몬스터 보유 가능, 획득물은 별도 설계 전까지 없음 |
| `MEND` | 실제 손실 체력 회복 | 균사 수호자, 지원형 정예 | 몬스터 보유 가능, 무한 회복 방지를 위해 횟수·기력 제한 사용 |

시험용 지면 기술 `TEST_WATER`, `TEST_FROST`, `TEST_SPARK`, `FIREBALL`은 환경 검증 도구이므로 콘텐츠 목록과 드롭 풀에 넣지 않는다. 정식 지면 기술로 승격할 때 별도 ID와 비용·범위·AI 사용 조건을 확정한다.

## 5. 첫 구현 묶음

첫 콘텐츠 배치는 현재 표현 자산과 저층 동선을 활용할 수 있는 아래 6프로필로 제한한다.

1. `GOBLIN_SCAVENGER`: 현행 고블린을 기본형으로 정규화한다.
2. `KOBOLD_TUNNEL_SCOUT`: 코볼트 시야 덮어쓰기와 8방향 표현을 실제 종족·몸체에 연결한다.
3. `GOBLIN_HEXER`: 실제 `FIREBOLT` 사용자이자 `ESSENCE_FIRE_BOLT` 출처 검증용으로 둔다.
4. `DUNGEON_SLIME`: 기존 슬라임 표현을 점액 몸체와 느린 지역 방해 역할에 연결한다.
5. `CAVE_BEETLE`: 기존 딱정벌레 표현을 갑각 방어형에 연결한다.
6. `SPARK_BEETLE`: 현행 물·전기 전도 규칙을 사용하는 첫 환경 전문형으로 둔다.

이 묶음에서 활성화할 이능은 기존 `PREDATOR_NERVE`와 연결 비용이 작은 `NIGHT_SIGHT`, `HARD_SHELL`부터 검토한다. `FIREBOLT`는 전투 기술 실행과 획득물 생성까지 검증하되, 결속 확정 서비스가 준비되기 전에는 정수를 보관만 한다. 새 몬스터는 종족 카탈로그, 몸체 템플릿, 시야·위험 친화도, 전투 loadout, 드롭, AI 역할, 맵 출현표가 모두 유효해진 뒤에만 실제 층에 배치한다.

## 6. 보류 항목

- 이능 제거 후 소멸·회수 여부와 제거 비용
- 액티브 기술을 결속 이능으로 흡수할 수 있는 범위
- 각 효과의 수치, 발동 확률, 교전당 횟수
- 상위형의 정예 판정과 확정/확률 이능 획득 방식
- 24프로필의 정확한 층별 출현 가중치와 혼합 조합

목록의 ID는 구현 전 충돌 검사를 거쳐 canonical ID로 확정한다. 효과 훅이 없는 이능이나 완전한 출처 프로필이 없는 획득물은 드롭 테이블에 먼저 등록하지 않는다.
