# 메인 HUD 적용

- 승인 시안: `main-hud-approved.png` (식량 게이지, 횃불 개수 포함).
- 실제 UI는 기존 네이티브 컨트롤과 금속 프레임 사용. 생성된 던전 그림/캐릭터를 게임 에셋으로 교체하지 않음.
- 상단 76 논리 픽셀: 미니맵, 층수/귀환시간, 식량, 횃불, 메뉴 순서.
- 식량 숫자 = 현재 조작 캐릭터 소지 FOOD_RATION 개수. 게이지 = 파티 ration/ration_max 포만도. 가방 용량 대비 개수 게이지로 오해하지 않도록 `포만` 표시.
- 횃불 개수 = 소유 테이블의 TORCH quantity 합계. 장착분은 이미 테이블에 있으므로 중복 합산하지 않음. 연료는 현재 장착한 횃불 기준, 약 100시간단위당 1턴으로 기존 환산 유지. 미장착/꺼짐/소진 구분.
- 적 시야 표시 기능은 삭제하지 않고 메뉴로 이동.
- HUD → 게임 → 로그 3줄 → 초상화 → 하단 명령 구조 유지. 기존 전투/이능/자동 명령을 목업의 5개 예시 버튼으로 축소하지 않음.
- 초상화 도형 영역 확대. 체력·기력·긴장 및 전투 수치는 유지.
- 최대 25개 내외의 소유 아이템만 집계. UI 갱신 시 과거 이벤트 전체를 추가로 스캔하지 않음.
