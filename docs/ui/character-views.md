# 상태·관계·아이템 UI / 메인 HUD 시안

## 반영

- 상태: 체력·기력 막대, 세 능력치, 2×2 전투 수치, 육체 실루엣과 기존 신체 데이터, 감정·상태 효과·회복·재능. 기존 내성/세부 설명 유지.
- 관계: 인물 목록에서 선택한 관계의 신뢰·감사·두려움·적대·원한을 개별 게이지로 표시. 관계 방향은 `선택 인물 → 상대`로 실제 DTO를 따름. 목업의 예시 인물을 생성하거나 관계 점수를 주입하지 않음. 최근 기록은 실제 `recent_reaction`이 있는 경우만 표시.
- 아이템: 실제 다섯 장비 슬롯과 캐릭터, 전체/장비/소모품/재료 분류, 선택 상세를 가방 아래에 표시. 기존 장착·해제·사용·버리기 처리와 저장 journal 유지. 무기 공격력·공격시간의 현재→선택 값 비교 추가.
- 목업에 있던 머리/발 슬롯을 새 장비 규칙으로 추가하지 않음. 배낭은 실제 20칸 유지. 좁은 화면에서는 세로 스크롤.
- 육체 실루엣은 해부학 에셋이 아닌 정적인 코드 도형. 기능 상실/절단 부위만 실제 condition을 보고 강조하며, 상처 데이터는 텍스트로 보존.
- 메인 HUD는 **시안만 생성**, 실제 게임 HUD는 아직 변경하지 않음.

## 디자인 자료

승인된 imagegen 목업의 금속 프레임, 어두운 패널, 수치 중심 구성을 네이티브 Godot 컨트롤로 옮겼다. 래스터 목업을 UI 배경 전체로 붙이지 않는다. 기존 게임 에셋과 코드 도형을 사용하므로 생성 이미지와 픽셀 단위로 동일하지 않다.

메인 HUD는 내장 imagegen 스킬/도구로 생성했으며 CLI는 사용하지 않았다. 최종 프롬프트는 `main-hud-prompt.txt`에 보관. 제안은 HUD → 게임 → 로그 3줄 → 초상화 → 하단 버튼 순서이며 수치·턴 표기는 예시이다. 실제 구현 때 현재 시간/연료 단위에 맞춘다.
