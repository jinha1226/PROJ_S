# 전투·탐험 하단 UI 및 공격 예고 전투 구현

## UI

- 기존 아이소메트릭 보드, 타일과 카메라·줌 코드는 변경하지 않았다.
- 상단은 층/방 또는 배치 안내·증원까지 남은 턴, 식량, 메뉴로 축소했다. 행동 순서 막대와 소형 미니맵은 숨겼으며 전체 지도는 메뉴에 남겼다.
- 로그는 기존 3줄 영역을 유지한다. 기존 서술 로그가 비어 있으면 실제 이동·피해·증원 이벤트를 최근 3줄로 표시한다.
- 전투/배치 중에는 선택 파티원 초상화와 HP·MP, 액티브 슬롯 2개, 배치 완료/진행 버튼을 표시한다.
- 전투가 없으면 최대 3명의 초상화와 HP·MP를 나란히 표시한다. 방 역할이 아니라 실제 라운드 활성 상태를 기준으로 바뀐다.
- 초상화를 누르면 기존 상태·숙련·변이·아이템 창을 연다. 전투 중 다른 파티원은 보드에서 선택한다.
- 스킬이 없는 칸은 빈 슬롯으로 표시한다. 여러 액티브를 보유하면 스킬 버튼을 길게 눌러 다음 두 개로 넘긴다. 표시된 스킬을 누르면 기존 대상/범위 선택 흐름을 사용한다.
- 기본 공격은 적을 눌러 계획한다. 직접 지정한 이동 뒤 공격/스킬은 그 이동을 보존하지만, AI가 제안한 이동은 새 공격 지시로 교체한다.
- 휴식·줍기·계단/상호작용·자동탐험·대기는 상단 메뉴로 접근한다. 전투 중 휴식 메뉴는 비활성화한다.

## 턴 구조

1. 처음 적과 조우한 방에서는 배치 단계로 멈춘다. 최초 진입 위치 주변 2칸 이내의 경로로 배치를 조정한다. 장애물·점유·이동 예산 검사를 유지한다.
2. 배치 완료 시 HP/MP 회복이나 전투 시간 경과 없이 배치를 확정하고 적이 먼저 이동한다.
3. 적은 설정된 최대 3칸 및 자신의 이동 예산 안에서 이동한다. 사거리에 들어오면 이동을 멈추고 공격 대상 **칸**을 공개한다. 닿을 수 없는 적은 그 차례에 공격하지 않는다.
4. 아군의 이동·공격·스킬 계획을 수정한다. 동료의 기존 자동 제안도 유지하며 수정할 수 있다.
5. 진행을 누르면 아군 행동 전체 → 살아 있고 공격 가능한 적의 예고 공격 → 기존 100시간 경과/회복/상태 처리 → 다음 적 이동·예고 순서로 처리한다.

즉, 개별 아군 클릭 즉시 행동을 소모하는 방식이 아니라 기존 계획 편집/일괄 실행을 유지한 진영 우선 처리다. 적은 공격 시 빈 칸을 따라 재조준하지 않는다. 적이 밀려 원래 공격 위치에서 벗어나면 해당 공격을 취소한다. 기존 고정 칸 공격의 아군/적 교차 피격 판정은 유지한다.

## 증원 설정

설정 파일: `data/content/stage_counterplay.json`

- 시험 기본값: 완료된 전투 **6턴마다 2마리**.
- 현재 방의 미처리 적이 있을 때만 증원한다. 마지막 적을 제한 턴에 처치해도 증원하지 않는다.
- 최대 활동 적 8마리. 안전한 외곽 빈 칸을 사용하고 파티 바로 옆에는 소환하지 않는다. 공간이 없거나 상한에 닿으면 미룬다.
- 도착한 증원은 해당 턴에 기습 공격하지 않는다. 다음 적 이동/예고 뒤 아군에게 대응 기회가 있다.
- 방별 턴과 증원 횟수는 저장하며 방/층 전환 시 유지한다. 배치, 관찰, 계획 수정, 비전투 이동/대기는 증원 턴을 소모하지 않는다.
- 기존 HP·피해·부상 공식은 변경하지 않았다. 6턴/2마리가 적절한지는 모바일 실제 플레이 후 조정해야 한다.

## 검증

- `stage_counterplay_acceptance.gd`: 입구 배치 제한, 배치 무시간 처리, 적 선이동, 아군 우선 순서, 고정 칸 공격/대상 회피, 관찰 불변성, 라운드 저장 재생, 6턴째 증원 2마리, 전멸 후 증원 없음, 증원 상태 스냅샷 복원.
- `stage_context_ui_acceptance.gd`: 실제 Godot 뷰포트 터치로 초상화 상세창 열기, 배치 완료 한 번 실행, 진행 한 번에 100시간, 360px 화면 버튼 크기/위치 검사.
- `nine_room_ui.gd`: 360/390px 화면, 전장 타일 좌표, 신규 하단과 기존 UI 숨김 검사.
- 기존 방 전체 시야, 층 전환 호환성, NPC 상세창 지원·합류, 100시드×2층 생성, 5종족 시작, CI 정착지 단위 검증을 수행했다.

Godot 네이티브 테스트이며 실기기 브라우저에서 전체 1층 클리어·난이도 검증을 마쳤다는 의미는 아니다. 과거 개별 이니셔티브 순서/즉시 전투 진입을 전제로 한 모든 테스트를 새 규칙으로 이식한 것은 아니다.

## 저장과 이미지

새 전투 상태 형식에 맞춰 생성 버전을 3으로 올렸다. 이전 저장 파일은 삭제하지 않지만 이번 버전은 새 게임으로 시작한다.

`runtime.png`는 실제 Godot 네이티브 360×800 화면이다. 목업 캐릭터나 타일 이미지를 런타임 에셋으로 대체하지는 않았다.
