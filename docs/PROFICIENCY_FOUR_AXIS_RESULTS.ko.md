# 4계열 숙련 내부 시스템·UI 연결 결과

- 날짜: 2026-09-12
- 기준 계획: [4계열 숙련 계획](PROFICIENCY_FOUR_AXIS_PLAN.ko.md)
- 상태: 모바일 테스트용 구현. 수치 밸런스 확정 또는 모든 이능 구현 완료가 아니다.

## 실제 연결

- 근접·원거리·마법·방어 4계열로 대체. 기존 8계열별 경험치·집중 훈련과 명중/속도 숙련 중복 보정을 제거했다.
- 처치 보상은 캐릭터 경험치다. 레벨업마다 포인트를 받고, 전투 밖에서 직접 투자한다. 동료도 성장 화면의 인물 선택으로 투자한다.
- 공격 숙련은 해당 효과량에 한 번 적용한다. 방어는 적중 후 피해 감소 한 경로에 적용하며 방패·회피 확률까지 중복 증폭하지 않는다.
- 새 콘텐츠 데이터: `data/content/rebuilt_progression.json`, `rebuilt_equipment.json`. 기존 실행부용 JSON의 ID 의미를 바꾸지 않고, 새 실행부의 별도 규칙 버전을 명시했다.
- 성장 창은 숙련/장비/이능 탭이다. 4계열 전체, 잔여 포인트, 현재 효과, 투자 전후 확인, 캐릭터 경험치 게이지를 제공한다. 레벨업은 로그와 성장 버튼의 P 표시로 알린다.
- 확인 취소 시 미소비, 중복 확인 시 한 번만 소비, 오래된 확인 상태는 재검증한다.
- 활 사격: 장착, 대상 터치, LOS/사거리, 화살, 행동 시간, 원거리 배수, 신체 손상 연결. 활 장착 중 일반 근접 이동 공격은 맨손으로 처리해 무료 활 공격을 방지한다.
- 화염탄: 실제 화염탄을 사용하는 적의 정수 드롭 → 줍기/보관 → 확인 후 결속 → 대상 터치 시전 → MP/행동 시간/마법 배수/화염 저항/화염 부위 손상 연결. 결속은 기존 최대 6칸·레벨별 슬롯·중복 금지 규칙을 재사용한다.
- 화염탄 사용 적은 주황색 표식으로 구분한다. 회복약은 현재 HP·혈액과 MP를 회복한다.
- 성장/자원/장착/결속을 저장하고 위조된 포인트, 음수, 초과 투자, 미지원 이능을 거절한다.

## 모바일 시험 방법

1. 기본 주소로 접속한다. `?legacy=1`, `?prototype=combat`은 제거한다.
2. 하단 **성장**에서 숙련 4개와 장비/이능 탭을 확인한다.
3. 첫 레벨 포인트는 0이다. 1층 적 4명 처치로 총 경험치 100을 얻으면 레벨 2/포인트 1이 된다.
4. 보이는 적이 없는 곳에서 +1 → 미리보기 → 확정한다. 동료도 인물 선택으로 확인한다.
5. 장비 탭에서 활 장착 → 창 닫기 → 사격 → 보이는 적 터치. 화살 필요, 사거리 6칸.
6. 화염탄 사용자 처치 후 정수를 줍고 이능 탭에서 결속한다. 이후 화염탄 버튼 → 대상 터치. MP 부족 시 회복약을 사용한다.

## 조정 가능한 초기값

미정이던 값에 구현용 초기값을 부여했다. 장기 밸런스 합의나 최적값이 아니다.

- 최고 레벨 21, 초기 포인트 0, 레벨업당 1점, 계열별 최대 10점.
- 누적 레벨 경험치 `100 × (레벨−1)²`. 처치당 `20 + 층×5`를 살아 있는 파티원에게 지급.
- 공격 계열 점당 +8%, 기본 ×1.00/최대 ×1.80. 정수 효과량은 반올림한다.
- 방어 점당 피해 2% 감소, 최대 20%, 양의 적중 피해 최소 1. 별도 회피/방패 확률 성장 없음.
- 전투 밖 투자, 투자 자체는 시간 미소비. 재분배 미지원임을 확인창에 표시하며 기존 포인트를 자동 초기화하지 않는다.
- 활 기본 30발, 화살 획득당 10발. 화염탄 기본 피해 12/MP 4/시간 110/사거리 6, 기본 MP 20.

## 검증과 범위

- `rebuilt_growth_acceptance.gd`: 레벨 경계/포인트 보존/투자 취소·중복 확인/위조 저장 거부/배수·방어 상한/활 비용·벽 차단/결속 중복 차단/마법 MP·저항·부위 손상/층 이동 유지.
- `rebuilt_equipment_acceptance.gd`, `rebuilt_party_body_acceptance.gd`, `rebuilt_runtime_acceptance.gd`: 새 규칙에 맞춘 회귀 검사.
- Web 릴리스 내보내기 및 소스 폴더 밖의 PCK 로드 확인. Chromium 390×844에서 성장 4계열 화면 표시 확인.
- 실제 모바일 기기의 입력 체감/장시간 성능/밸런스 비교는 미검증이며 사용자 테스트 대상이다.
- 원거리/마법의 대표 경로는 연결했지만 쇠뇌·투척·냉기·전격·패시브·혼합 이능·반사/흡혈 연쇄의 전체 콘텐츠는 미구현이다. 해당 효과를 지원한다고 UI에 노출하지 않는다.
- 동료 장비/이능 탭은 보기 전용이며, 동료의 숙련 투자만 직접 지원한다.
- 신규 저장은 `user://rebuilt_dungeon_v4.json`. 기존 저장은 이전/삭제/덮어쓰기하지 않는다. 첫 진입 시 새 성장 규칙으로 시작한다.
