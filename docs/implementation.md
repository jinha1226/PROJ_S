# 새 구현 적용 기록

상태: 최초 구현 / GitHub Actions 검증 대상으로 제출.

- 1차: 20Hz 고정 틱, 입력 시 흐름, 자유 이동·충돌·문·시야, 공격 형태, 여섯 적 원형, 공격 예고, 원소·지형·상태, 소모품·횃불·등잔, 다섯 층과 족장, 디오라마와 모바일 HUD.
- 2차: 열두 무기, 열 장비 칸, 강화·브랜드·에고·유물·유품, 사용에 따른 확인, 레벨·사망, 장비 비교와 실제 3D 인형.
- 3차: 첫 주민 구조 튜토리얼, 모닥불·이름·계승·결말, 칸 건설·방 인식·프리셋·추천·사각형·복사·회전·되돌리기·비용, 주민 작업·성격·관계·방문자·달력.
- 4차: 훈련장과 구역 진행으로 동료 자리 개방, 역할과 성향·스킬·명령·위협·예고 회피, 부상과 원정 인력 공백.
- 5차: 마지막 구역의 5인 레이드, 단계·흩어짐·모이기·소환·원소 전환·격노, 새벽 이후 주간 씨앗.

## 연결 조건

첫 네 구역 클리어마다 파티 최대 인원이 하나씩 늘어나 다섯 명이 된다. 치유사와 주술사는 두 구역 후 선택할 수 있다. 원정 중 마을 시간은 흐른 시뮬레이션 시간만큼 진행한다. 냉기·번개 구슬을 시작 소모품에 넣어 장비 속성 없이도 1차 원소 조합을 쓸 수 있다. 열두 무기는 형태별 변형을 포함한다. 저장은 정착지만 저장한다.

## 검증 범위와 남은 일

규칙 회귀 테스트는 정지·씨앗·충돌·공격 예고·원소·장비·파티·레이드·건설·계승·저장·결말을 검사한다. 브라우저 테스트는 제목→이동→정지→가방→귀환→건설→저장 재접속을 검사한다. 브라우저 테스트에서 CDN 모듈은 같은 버전의 npm 패키지로 대체한다.

첫 버전은 모든 구역에 동일한 다섯 층 생성기를 사용한다. 구역별 독립 보스와 개별 주민 장편 사건은 아직 세분화하지 않았다. 튜토리얼 방마다 별도 잠금·학습 조건은 아직 없다. 벽은 전체 반투명이며 카메라 가림을 개별 판정하지 않는다. 전투 측정은 단일 전투의 12씨앗 회피 봇이며, 전체 구역 사망률·층당 시간과 실제 모바일 기기의 60fps는 아직 확인하지 않았다. 연출과 밸런스는 초기 수치다. 주민의 관계 사건은 짧은 일상 사건이며, 레이드 후 개별 관계 서사는 후속 확장이 필요하다.
