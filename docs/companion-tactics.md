# 동료 전술 프로토타입

메인 화면은 `Session.new(seed, true, true)`로 2인 보스 원정을 시작한다.
선택한 대원을 직접 조작하고, 나머지 생존 대원은 플레이어의 유효 행동 뒤 한 번 행동한다.
그다음 적과 환경이 한 번 진행한다. 대원 선택·방침 변경·실패한 입력은 턴을 소비하지 않는다.
자동 행동은 `Session.act`로 실행하되 재귀적인 턴 진행을 차단한다.

## 설정

하단 **전술**에서 각 대원의 스킬 조건과 우선순위를 설정한다.

- 밀치기: 보호용(아군 위협 감소 또는 예고 차단), 공격용(충돌/불 지형), 수동 전용.
- 방어: 위험할 때, 체력 절반 이하이면서 위험할 때, 수동 전용.
- 우선순위 교체: 조건에 맞는 밀치기 또는 방어를 우선한다. 위험 칸 탈출이 항상 먼저다.
- 수동 전용은 자동 사용만 막으며 직접 스킬 사용은 가능하다.
- 마지막 자동 행동 이유는 전술 창의 대원 이름 옆에 표시한다.
- 조작 중이 아닌 동료 머리 위에 현재 전장 기준 다음 행동을 표시한다(밀치기/방어/공격/이동/대기 예정). 스킬은 금색, 일반 행동은 푸른색이다. 방침·조작 대원 변경 시 갱신한다.
- 예고는 예약이 아니다. 플레이어 행동으로 대상·위치·위험이 바뀌면 실제 실행 직전 다시 판단한다. 예고 조회는 선택 대원이나 전투 상태를 변경하지 않는다.
- 설정은 같은 세션의 귀환/재출정 사이에 유지된다. 앱 재시작 시 저장하는 기능은 아직 없다.

## 기존 코드 활용과 변경점

`../sim/abilities/tactical_action_selector.gd`의 후보 생성, 유효 피해/처치 가치,
이동 전후 위협 비교, 결정론적 후보 정렬을 현재 Session에 맞게 옮긴
`expedition/tactical_action_selector.gd`를 사용한다.
기존 실험장의 timeline/energy/SHOVE 피해 규칙은 가져오지 않는다.
현재의 PUSH(빈칸 이동 또는 충돌 피해 + 예고 취소)를 기준으로 평가한다.

기존 위협 감소의 양수 가점만 사용하던 방식과 달리, 다른 아군의 위협을
늘리는 밀치기는 거절한다. 수렁 보스를 회복 가능한 물로 밀거나 특별한
보호 이득 없이 다른 아군의 근접 공격 범위 밖으로 밀어내는 행동도 제외한다.
동료마다 실행 직전의 변경된 전장을 평가한다. 아직 여러 행동에 걸친 탐색이나
전체 원소 연쇄의 정확한 시뮬레이션은 하지 않는다.

현재는 두 대원 모두 밀치기/방어를 사용한다. 치유·보호막·원소 스킬의
사용 방침, 성격/기억에 따른 선호 가중치는 후속 작업이다.

검증: `godot --headless --path . --script res://tests/companion_tactics.gd`
