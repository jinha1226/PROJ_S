# 동료 전술 프로토타입

메인 화면은 `Session.new(seed, true, true)`로 2인 보스 원정을 시작한다.
주 조작 대원을 직접 조작하고, 나머지 생존 대원은 플레이어의 유효 행동 뒤 한 번 행동한다.
동료 초상화는 조작 전환 대신 다음 행동 예약 모드를 연다. 이동 칸/적/스킬을 선택하면
동료의 행동 한 번을 예약하고 주 캐릭터 조작으로 돌아온다. 자기 칸은 대기 예약이다.
예약은 턴을 소비하지 않으며 기존 예약을 덮어쓸 수 있다. 초상화를 다시 누른 뒤
게임 화면의 예약 취소 버튼으로 자동 방침에 복귀한다.
동료 스킬 버튼도 즉시 실행하지 않고 예약한다. 공격·밀치기는 적의 ID를 추적한다.
실행 직전 사거리·생존·점유 상태를 재검사하고 불가능하면 자동 방침으로 대체한다.
예약은 한 번 처리한 뒤 소모되며 새 전투에서 초기화된다.
그다음 적과 환경이 한 번 진행한다. 대원 선택·방침 변경·실패한 입력은 턴을 소비하지 않는다.
자동 행동은 `Session.act`로 실행하되 재귀적인 턴 진행을 차단한다.

## 설정

하단 **전술**에서 대원 선택 → 스킬 카드의 설정 버튼으로 편집한다. 스크립트 입력은 없다.

- 누구에게: 스킬에 맞는 대상만 표시(현재 가까운 적 / 체력이 낮은 적 / 자신).
- 언제: 사용 가능할 때 / 체력 기준 / 특정 상태 / 대상이 공격 준비 중 / 자신이 공격받을 위험.
- 체력 기준을 선택하면 자신·대상, 10~100% 슬라이더, 이하·이상만 추가 표시한다.
- 상태를 선택하면 자신·대상과 젖음·불 위에 있음 목록을 추가 표시한다.
- ↑ 먼저 사용 / ↓ 나중에 사용 버튼으로 순서를 변경한다. 위험 칸 탈출 이후 첫 번째 사용 가능한 규칙을 실행한다.
- 자동 OFF는 자동 사용만 막으며 직접 사용은 가능하다. 변경 즉시 반영하며 기본값 복원이 가능하다.
- 스킬 기본값은 충전 중인 적 밀치기 → 자신의 체력 50% 이하 방어이다.
- 일반 공격은 스킬 카드와 분리된 **기본 행동**이다. 대상만 가까운 적(기본값) / 체력이 낮은 적 중 선택하며 조건·자동 토글·순서 설정은 없다.
- 위험 칸 회피 → 사용 가능한 스킬 → 일반 공격 → 안전한 접근/대기 순서로 판단한다. 일반 공격 대상은 현재 공격 가능한 적 중에서만 고르며, 범위 밖 저체력 적을 쫓느라 가능한 공격을 포기하지 않는다. 동률은 피해/처치 가치와 좌표로 결정한다.
- 기본 행동 설정도 대원별로 독립적이며 턴을 소비하지 않는다. 기본값 복원은 스킬과 일반 공격 설정을 함께 초기화한다.
- 각 카드의 설정 형식은 `tactic_rules.gd` 공통 카탈로그·조건 평가기를 공유한다. 새 스킬은 사용 가능한 대상과 조건을 등록하고 실제 효과 평가/실행기를 연결해야 한다.
- 마지막 자동 행동 이유는 전술 창의 대원 이름 옆에 표시한다.
- 조작 중이 아닌 동료 머리 위에 현재 전장 기준 다음 행동을 표시한다(밀치기/방어/공격/이동/대기 예정). 스킬은 금색, 일반 행동은 푸른색이다. 방침·조작 대원 변경 시 갱신한다.
- 자동 예고는 확정이 아니다. 플레이어 행동으로 상황이 바뀌면 실제 실행 직전 다시 판단한다. 직접 지정한 행동은 머리 위에 ‘예약’으로 구분하며 유효하면 자동 방침보다 우선한다. 예고 조회는 전투 상태를 변경하지 않는다.
- 설정은 같은 세션의 귀환/재출정 사이에 유지된다. 앱 재시작 시 저장하는 기능은 아직 없다.

## 기존 코드 활용과 변경점

`../sim/abilities/tactical_action_selector.gd`의 후보 생성, 유효 피해/처치 가치,
이동 전후 위협 비교, 결정론적 후보 정렬을 현재 Session에 맞게 옮긴
`expedition/tactical_action_selector.gd`를 사용한다.
기존 실험장의 timeline/energy/SHOVE 피해 규칙은 가져오지 않는다.
현재의 PUSH(빈칸 이동 또는 충돌 피해 + 예고 취소)를 기준으로 평가한다.

기존 위협 감소의 양수 가점만 사용하던 방식과 달리, 다른 아군의 위협을
늘리는 밀치기는 거절한다. 수렁 보스를 회복 가능한 물로 밀거나 특별한
보호 이득 없이 다른 아군의 근접 공격 범위 밖으로 밀어내는 행동도 제외한다.
동료마다 실행 직전의 변경된 전장을 평가한다. 아직 여러 행동에 걸친 탐색이나
전체 원소 연쇄의 정확한 시뮬레이션은 하지 않는다.

현재는 두 대원 모두 밀치기/방어 규칙과 별도의 일반 공격 대상을 설정한다. 치유·보호막·원소 스킬의
실제 후보 평가/실행, 성격/기억에 따른 선호 가중치, 다중 조건은 후속 작업이다.

검증: `godot --headless --path . --script res://tests/companion_tactics.gd`
