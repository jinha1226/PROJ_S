# 타일 조준과 초반 바닥 재질

## 변경

- 필드의 모든 사용 가능한 스킬을 `스킬 선택 → 대상 칸 선택`으로 통일했다. 인물을 눌러도 그 인물의 칸을 선택한다. 자기 강화도 즉시 시전하지 않고 자신의 칸을 선택한다.
- 적/아군이 있는 칸은 기존 대상 평가와 효과 실행을 사용한다. 사거리, 시야, 진영, MP, 회복 가능 피해, 도약 착지 조건을 유지한다.
- 화염탄·물 분사·냉각 분사·전도 방전·서리실은 빈 칸에도 사용할 수 있다. 각각 열·물·냉기·방전·고정 서리 지대를 적용한다.
- 직접 타격/흡혈/독 주입/도약 공격 등 인물이 필요한 기술은 해당 인물이 있는 칸을 지정한다. 빈 칸에 치유하거나 타격 대상을 만들지는 않는다. 잘못된 지정은 시간·MP를 소비하지 않고 선택 상태를 유지한다.
- 기존 적 ID 지정 명령은 그대로 지원한다. 파티 AI와 과거 저장의 명령 형식을 유지한다.

## 바닥

새 절차적 게임은 생성 규칙 버전 8을 기록한다. 1층의 돌바닥 사이에 나무·얕은 물·금속·잔해를 방별 3×3 구역으로 배치한다. 입구·계단·앵커의 칸은 유지하며 모든 지형이 통행 가능하다. 별도의 시드 난수열을 써서 기존 방·통로·적 배치 추첨에 영향을 주지 않는다.

그림만 바꾸는 장식이 아니라 실제 `terrain`을 설정한다. 기존 환경 시스템의 가연성·전도도·수분 노출·이동 비용을 사용한다. 물을 뿌린 나무·금속·잔해에도 젖은 바닥 표현을 적용한다. 물이 마르면 바탕 재질이 다시 보인다.

기존 버전 5–7 저장은 원래 생성 규칙을 사용한다. 새 재질 배치는 새 게임의 1층에 적용하며, 기존 저장의 타일을 덮어쓰지 않는다. 2층 생성 규칙은 기존 설계를 따른다.

## 검증

- `rest_parts_water_acceptance`: 통과. 기존 물 분사·디버프 HUD·저장 복원.
- `procedural_dungeon_acceptance`: 통과. 경로 연결·시드 재현·기존/새 저장 불러오기.
- `elemental_parts_acceptance`: 통과. 기존 적 대상 원소 기술·파티 AI·저장 후 결정적 진행.
- `tile_skills_materials_acceptance`: 통과. 50개 시드 재질·연결성 검사, 빈 칸 원소 시전과 저장 후 진행, 실제 UI의 자기 강화 타일 선택, 모든 몬스터 부위 기술의 기존 대상/타일 대상 평가 및 실행 검증.

서리실의 기존 적 대상 효과를 검사하면서 순찰 이동 기록 검증 오류를 발견했다. 적의 둔화는 이동 후 `enemy_busy_rows`에 적용되는데, 저장 검증은 파티원처럼 이동 이벤트 비용에도 둔화가 들어가야 한다고 요구했다. 기록 검증을 실제 실행 방식에 맞췄다.
