# 승인 목업 기반 정착지 화면

2026-09-13. 기존 채집/건설/원정 시스템은 유지하고 정착지 UI만 변경한다.

- [승인 목업](ui/settlement-mobile-approved-mockup.png)을 화면 구성 참고로 사용했다. 생성된 배경을 실제 타일맵이나 충돌 데이터로 사용하지 않았으며 건물/캐릭터는 기존 에셋이다.
- 피난처 첫 화면과 관리 화면을 지도 중심의 동일 화면으로 연결했다. 기존 중복 상단 HUD와 하단 사건 영역을 해당 화면에서만 숨기고, 다른 화면에서는 복원한다.
- 상단에는 정착지 이름, 메뉴, 목재/돌/약초/식량 아이콘과 실제 수량을 표시한다. 하단에는 건설/주민/작업/원정 메뉴를 고정한다.
- 지도에서 시설이나 자원을 선택하면 하단 패널이 열린다. 채집 구역 선택, 채집 시작/중지, 주민 배정, 진행 작업 취소는 기존 명령을 사용한다.
- 패널 닫기 상태, 마지막 메뉴, 채집 구역을 UI 상태로 유지한다. 패널을 닫거나 다른 메뉴로 이동하면 미확정 건설 배치를 취소한다.
- 원정 메뉴는 기존 출발 조건을 사용하며 발견하지 않은 폐광은 비활성화한다. 상단 메뉴/캐릭터 접근과 시장·장비 화면도 유지한다.
- 외부 에셋 추가 없이 자원/메뉴 아이콘을 작은 코드 기반 도형으로 제작했다. 승인 목업의 건물·풍경 퀄리티까지 구현한 것은 아니다.

검증: 기존 작업 회귀, 실제 모바일 크기 shell의 채집/하단 메뉴/패널 닫기·열기/독립 스크롤/팝업 메뉴 및 기존 구조·귀환 흐름. 실기기 성능 측정은 별도다.

- `tests/settlement_work_unit.gd`: PASS.
- `tests/frontier_campaign_acceptance.gd`: PASS.
- `tests/settlement_mobile_acceptance.gd`: X11 렌더링 모드 PASS. 360×640, 390×844 창 크기로 레이아웃·입력을 검증했다.
- [실제 실행 화면](ui/settlement-mobile-layout-runtime.png). 화면 배율은 Godot viewport 설정을 따른다.

## 후속 시각 정리

버튼의 대괄호를 제거하고 본문/버튼 최소 글자 크기를 18로 올렸다. 자원 수량은 20, 하단 메뉴는 18로 통일했다. 패널 여백·그림자·상태별 버튼 색을 정리하고 상세 패널 높이를 화면에 맞춰 늘렸다. 채집 자원 탭은 선택 상태를 강조한다. 픽셀폰트와 기존 지도 에셋은 유지한다.

현재 건설은 `sim/base_settlement_rules.gd`의 16×16 격자에 시설 단위(3×2 또는 3×3)로 배치하는 방식이다. 벽/문/바닥 개별 배치, 방 경계 판정, 실내 가구 배치는 아직 없다. 타일 기반 자유 건설은 별도 기능이며 이번 UI 변경에 포함하지 않는다.
