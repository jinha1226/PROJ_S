# 던전 도움 → 동행 수락

## 동작

- 종족 선택 뒤 마을 UI 없이 던전 1층으로 들어간다. 기존의 기록 가능한 마을 START/출발 명령을 화면 표시 전에 실행해 주민, 장비, 자율 탐험 NPC 배치를 초기화한다. 마을 데이터나 귀환 시스템 자체를 제거하지 않는다.
- 독립 탐험 NPC가 휴식 또는 귀환 중일 때 체력이 부족하면 회복 물약, 식량이 없으면 식량으로 도울 수 있다. 단순히 쉬는 건강한 NPC는 대화만 가능하다.
- 옆 칸(대각선 포함)에서 안전한 탐험 상태일 때만 돕거나 동행을 수락할 수 있다. 사망·전투불능·이미 합류·이미 귀환한 NPC는 대상이 아니다.
- 물약/식량은 소유자의 묶음에서 정확히 1개만 소비한다. 물약은 NPC 체력을 회복하고, 식량은 NPC에게 1개를 지급한다. 물약이 신체 부위 손상을 전부 치료하는 기능은 아니다.
- 도움은 자동 영입이 아니다. 같은 원정 동안 도움을 기억하고 별도 **동행 수락** 버튼으로 확정 합류한다. 성격에 따른 수락 확률이나 추가 물품 요구는 없다.
- 파티 정원은 주인공 포함 3명이다. 정원이 찬 상태에서도 도움을 줄 수 있고, 수락 권한은 같은 원정 동안 유지된다.
- 합류한 NPC는 현재 위치를 유지한 DEPLOYED 동료가 되어 기존 필드 전투/이동/성격 AI를 사용한다. 독립 탐험 목록에서 제외하므로 두 AI가 동시에 움직이지 않는다.
- 이번 원정의 임시 동행이며, 귀환 시 편성에서 빠진다. 이미 플레이어 조작을 승계한 NPC는 강제로 해제하지 않는다. 영구 탐험대 가입과는 별개다.

## UI

- 보이는 가까운 독립 NPC도 기존 인물 카드에 표시한다.
- 기존 가까운 인물 카드와 NPC 상세창에 `회복 물약 1개 주기` / `식량 1개 나누기` / `동행 수락`을 상황에 맞춰 연결했다.
- 상세창에서 도움을 준 뒤 창을 다시 열 필요 없이 다음 수락 버튼을 갱신한다.
- HUD/게임/로그/초상화/하단 버튼 배치는 변경하지 않는다.

## 검증 범위

아래 두 테스트는 모두 PASS. 390×844 X11 렌더링에서 [동행 수락 화면](previews/expedition-aid-offer.png)을 확인했다.

- `tests/expedition_aid_recruitment_acceptance.gd`: NPC 배치, 초기화 저장/재생 일치, 읽기 전용 평가, 거리 제한, 도움 전 영입 차단, 물품 1개 소비, NPC만 회복, 중복 도움/수락 차단, 명시적 UI 수락, 정원 및 도움 기억, 귀환 후 해제, 월드 유효성.
- `tests/dungeon_0x72_acceptance.gd`: 실제 종족 선택에서 던전 직행, 동료 허용, 자율 탐험 NPC 배치, 기존 에셋/장비/타일 검증.
- 도움·정원·귀환 테스트는 통제된 NPC 위치/체력 fixture를 사용한다. 초기화 저장 재생은 조작 없는 명령 경로를 검증한다. 실제 장시간 모바일 성능이나 모든 도움 이후 저장 재생 경로를 검증한 것은 아니다.
