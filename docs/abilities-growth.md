# 이능과 성장 통합

## 기존 코드에서 가져온 구조

- `../sim/abilities/monster_ability_catalog.gd`: 아이템과 이능을 연결하는 카탈로그 구조.
- `../sim/systems/corpse_loot_system.gd`: 죽음 한 번당 드롭 한 번이라는 중복 방지 규칙.
- `../sim/growth_build_state.gd`의 `commit_mutation_swap`: 습득 목록과 장착 슬롯 분리, 미습득/중복/슬롯 범위 검사, 안전한 상황에서 교체.
- `../game/rebuilt/progression.gd`: 누적 경험치의 제곱 성장 곡선, 레벨별 숙련 포인트, 4개 숙련 축과 랭크별 배율.
- `../sim/growth_build_registry.gd`: 근력/민첩/지능 3종, 3레벨마다 스탯 포인트.

대형 world/event/inventory 의존 코드를 그대로 복사하지 않고 현재 Session 사전에 맞춰
`expedition/abilities.gd`, `expedition/growth.gd`로 축소 이식했다. 아래 수치는 현 프로토타입용이며
구버전 전체 성장 규칙과 동일하지 않다. 초기 버전의 처치 즉시 변이 습득은 사용하지 않는다.

## 이능

보스의 핵/부위는 처치 시 항상 공용 가방에 들어간다. 일반 몬스터의 파츠는 기존 드롭 확률을 사용한다.
같은 사망을 재처리해도 드롭이나 경험치를 다시 주지 않는다. 바닥 줍기는 생략한다.

| 보스 | 아이템 | 이능 |
|---|---|---|
| 수렁 포식자 | 수렁의 핵 | 수렁 충격파: 주변 맨해튼 2칸, 기본 피해 16 |
| 폭탄 암살자 | 암살자의 화약낭 | 폭탄 투척: 사거리 4, 대상 중심 3×3, 기본 피해 16 |
| 과부하 거인 | 거인의 철갑핵 | 철갑 방어: 이번 적 차례 피해 75% 감소 |

플레이어용 이능은 원본 보스 패턴을 축약한 즉시 행동이다. 폭탄은 적 대상만 지정한다.
공격 이능은 벽 너머로 피해를 주지 않는다. 충격파는 시전자 제외, 폭탄은 시전자 포함 아군 피해가 있다.
재사용 간격은 3턴(사용한 턴 처리 후 남은 3), 매 세계 턴마다 감소한다.

획득한 파츠는 공용 가방에 보관하고, 야영 중 캐릭터의 두 슬롯에 장착한다.
시작 기술 밀치기/방어는 가방에 1개씩 있으며 빈 슬롯으로 Run을 시작한다.
장착 시 행동방침 규칙이 추가되고 장착한 기술만 AI가 평가한다. 직접 사용/예약도 장착과
재사용 시간을 검사한다. 동료 AI는 공격 이능으로 아군을 맞히는 후보를 제외한다.

## 스탯·숙련

- 생존 파티원 각자 보스 처치 XP 100, 일반 적 XP 25. 막타 소유와 무관하다.
- 레벨 1~21, 누적 XP 문턱 `100 × (레벨−1)²`.
- 레벨마다 최대 HP +4, 현재 HP +4, 숙련 포인트 +1.
- 3/6/9…레벨에 스탯 포인트 +1. 상태 탭에서 투자한다.
- 근력: 근접 기본 위력 +2/점. 민첩: 원거리 기본 위력 +2/점. 지능: 마법 기본 위력 +2/점.
- 숙련은 근접/원거리/마법/방어 각 최대 10. 공격 3축은 위력 +8%p/점,
  방어는 받는 피해 −4%p/점(최소 피해 1). 장비·명중·회피 시스템 전체를 이식한 것은 아니다.
- 일반 공격/밀치기 충돌은 근접, 폭탄은 원거리, 수렁 충격파는 마법 적용.
- 성장 투자는 안전한 곳이나 야영 중에, 파츠 장착·교체·해제는 야영 중에만 가능하다. 턴을 소비하지 않는다. 재분배는 없다.
- 행동방침 기본값 복원은 포인트·습득·장착 상태를 초기화하지 않는다.

같은 Run에서 층을 내려가는 동안 유지된다. 앱 종료 후 디스크 저장/불러오기는 아직 없다.
기존 고정 화염/물 두루마리의 환경 효과량에는 새 성장 배율을 적용하지 않는다.

검증: `tests/abilities_growth.gd` 및 기존 7개 테스트 모음. CI에도 추가했다.
