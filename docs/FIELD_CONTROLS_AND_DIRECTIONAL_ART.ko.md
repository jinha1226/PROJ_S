# 필드 입력·8방향 인간·시드별 구성

## 조작 계약

- 초상화 짧은 탭/클릭: 행동 준비가 된 해당 동료로 조작 전환. 시간은 소모하지 않는다.
- 초상화 550ms 유지: 해당 인물 상태창. 손을 떼어도 조작 전환은 발생하지 않는다.
- 8px 이상 드래그하면 초상화 탭/길게 누르기를 취소한다.
- 조작 중인 인물: 초상화 금색 테두리/점과 맵 금색 모서리 표시. 상태창 열기는 선택을 바꾸지 않는다.
- 초상화 위 스킬: 캐릭터별 두 슬롯. 준비/기력/상태 조건을 충족할 때 대상 선택 후 사용한다.
- 초상화 HP, MP, STR: 현재/최대 체력, 현재/최대 기력, 스트레스 원수치(0–1000).
  MP는 기존 기력의 표시명이며 별도의 마나 자원을 추가한 것이 아니다.

전술 버튼의 터치 대상/실행 분기에 누락된 연결을 추가했다. 스킬은 명시적
터치/마우스 경로 하나로 처리하며 중복 pressed 실행을 막는다. 스킬 대상 선택이
화면 갱신 때 옛 ENGAGED 검사로 취소되던 문제도 수정했다.

## 예상 행동 표시

현재 조작자를 제외한 배치된 동료에 대해 실제 AI의 성격·지속 명령·대형 판단을
읽기 전용으로 사용한다. 다음 한 칸 이동은 파란 점선, 공격 대상은 붉은 점선/X,
대기는 현재 칸 표시다. 현재 조작자는 금색 하이라이트와 직접 지정 경로로 구분한다.
동료가 행동하기 전에 플레이어/다른 개체가 움직일 수 있으므로 **확정 계획이 아닌 예상**이다.
남은 행동 대기시간을 무시하고 추가 행동을 부여하지 않는다. 예측 조회는 RNG,
월드 시간, 이벤트, 저장 상태를 바꾸지 않는다. 보이지 않는 타일에는 선을 그리지 않는다.

## 시드와 저장

새 living 게임은 bootstrap v3를 사용한다. 월드 시드와 성격 시드를 함께 해시한
별도의 초기 구성 RNG로 시작 동료 이름/종족/두 스킬 유형, 모험가 5–8명과
필수 마을 직업 6명의 종족, 고블린/코볼트 몬스터 조합을 결정한다.
필수 마을 직업은 유지하며 후보 이름은 기존 신원 목록에서 선택한다.
같은 두 시드는 동일, 새 성격 시드는 지형을 유지하면서 구성을 바꾼다.
같은 게임 재시작은 구성을 유지한다. 기존 v2 및 비-living 저장의 초기화 규칙은 유지한다.
