# 자동탐험 진행 보장·이동 렌더링 최적화·숙련 UI

기준: main `dc30b99`. 기존 `party_encounter_sandbox` / `PartyPlaytestSession`에 적용한다. 기본 씬과 HUD → 지도 → 로그 3줄 → 초상화 → 버튼 순서는 변경하지 않는다.

## 자동탐험

- 매 걸음 가장 가까운 경계를 다시 선택하지 않고, 선택한 안전 경로를 목표 도착까지 유지한다.
- 이미 밟아 확인한 경계는 새 탐험 목표에서 제외한다. 벽에 가려 계속 미탐색 셀과 인접해 있는 두 경계 사이를 반복 왕복하지 않는다.
- 매 걸음 현재 시야의 적·점유·위험을 확인한다. 경로가 막히거나 위험해지면 다시 계획한다. 출구/상호작용/적 발견에 따른 정지 규칙은 유지한다.
- 경로가 유지되는 동안에는 경로·대각선 옆칸·현재 보이는 셀만 새로 구성한다. 재계획 시에는 발견된 전체 지형을 다시 사용한다. 시야 밖 NPC·위험 정보는 계획에 사용하지 않는다.
- 경로/방문 경계 캐시는 자동탐험 실행에만 존재한다. 새 실행·로드·리셋 시 초기화하며 저장 자료에 넣지 않는다.

실제 기본 캠페인 시드 77, 적은 미관측 위치에 고정한 경로 격리 검증에서 80걸음 / 전체 경로 탐색 25회. 두 칸 3회 연속 왕복은 없었다. 로컬 headless 명령 시간 중앙값 18.6ms, p95 29.0ms. 적 행동을 포함한 실기기 성능을 뜻하지 않는다.

## 이동 중 끊김

- Session과 field turn이 각각 만들던 동일한 rollback memento를 하나로 공유한다. 실패 시 복원 및 정식 저장 검증은 유지한다.
- 평면 타일 사각형은 폴리곤 생성 후 경계 계산을 거치지 않고 직접 계산한다. 투영 모드의 기존 폴리곤 경로는 유지한다.
- 암흑 mesh의 삼각형 포함 여부에는 셀 가시성만 필요하다. 중점 864개에서 계산 후 버리던 광원/거리/감쇠 값을 제거한다. 정점 색·ring 수·segment 수·시야 규칙은 그대로다.
- 지형 이미지 선택 결과는 관측/투영 캐시에 저장하고 매 애니메이션 프레임에 재사용한다. 관측·층·기하 변경 시 갱신한다.
- field 턴, 화면 그리기, 명령 실행, 다음 프레임 대기를 분리한 opt-in 측정 항목을 추가했다. 평소에는 비활성이다.

`tests/waterside_performance_probe.gd`, Godot 4.6.2 headless, 390×800, 좌우 이동 6회, 동일 로컬 환경의 단회 표본:

| 측정 항목 | 렌더링 수정 전 | 최종 렌더링 수정 후 |
|---|---:|---:|
| 건조 지형 draw_world 평균/호출 | 23.5ms | 16.8ms |
| 물 지형 draw_world 평균/호출 | 25.1ms | 17.5ms |
| 암흑 그리기 평균/호출, 건조/물 | 9.4 / 9.4ms | 4.2 / 4.3ms |
| 건조 지형 6회 명령+프레임 총합 | 465ms | 365ms |
| 물 지형 6회 명령+프레임 총합 | 510ms | 394ms |

호출 평균은 mesh 재생성과 캐시 재사용을 함께 포함한다. 모바일 GPU/브라우저 FPS 측정이 아니며 장시간 렉 해결이나 60fps를 보증하지 않는다. NPC 행동·사회 시스템을 삭제하거나 보이지 않는 NPC의 시간을 멈추지 않았다.

## 기존 화면의 4계열 숙련

접근: 메뉴 **숙련 · 이능**, 또는 주인공 상세의 **숙련·이능** 탭. 숙련 아래에 기존 이능 결속 UI가 계속 표시된다. 새 데모 World를 생성하지 않는다.

- 레벨/경험치, 남은 포인트, 네 계열의 현재 rank·배수·효과 설명, 48px `+1` 버튼을 표시한다.
- 투자 전 배수 변화를 확인하고 확정한다. 확인 중 포인트/rank가 바뀌면 낡은 요청을 실행하지 않는다.
- 레벨업마다 1점, 총 20점, 계열별 최대 10. 전투 밖에서 투자하며 시간 소모는 없고 재분배는 지원하지 않는다.
- 기본 캠페인의 기존 경험치/레벨 곡선과 처치 보상은 유지한다. 숙련 포인트 한도와 rank당 8%는 기존 4계열 설정 파일을 공유한다.
- 근접: 도검/도끼/둔기/창/맨손, STRIKE/SHOVE의 물리 효과. 원거리: 활/쇠뇌. 마법: FIREBOLT/FIREBALL/MEND의 수치 효과. 근접·원거리 일반 공격에는 피해 배수를 적용하고 구형 무기별 자동훈련 rank를 더하지 않는다.
- 방어: 기존 보호·회피·막기 수치를 배수 강화한다. 별도 최종 피해 감소율이 아니다. 실제 판정 상한과 정수 반올림을 유지한다. 원래 막기 수치가 0이면 새 막기 능력이 생기지 않는다.
- 마법 숙련은 새로운 이능이나 속성을 지급하지 않는다. 환경 생성량·지속 시간·사거리·MP 비용 등 명시하지 않은 효과에는 배수를 적용하지 않는다.
- 현재 포인트 배분 대상은 주인공이다. 동료의 기존 장비·행동·신체 시스템은 유지하며 동료 숙련 UI/별도 포인트 원장은 이번 범위에 포함하지 않는다.

저장: `protagonist_growth.mastery_ranks`, `growth.mastery_spent` 이벤트, `SPEND_MASTERY_POINT` journal 명령. 포인트 예산·rank 상한·이벤트/rank 일치를 검증하고 공격 당시 숙련은 과거 이벤트에서 복원한다. 구형 필드가 없는 성장 상태는 rank 0으로 읽지만 이전 진행 데이터 호환은 목표가 아니며 모바일 확인은 새 게임을 권장한다.

## 확인

- `auto_explore_progress_acceptance.gd`: occluded 경계 왕복, 경로 유지/위험 재계획, 기본 캠페인 80걸음, 제한 관측과 전체 관측의 안전 셀 일치.
- `run_party_auto_explore_tests.gd`: 기존 9개 결정성/시야 밖 정보 비노출/정지/재현 검사.
- `mastery_live_acceptance.gd`: 포인트 예산, 잘못된 저장 거절, JSON/rollback 보존, 기존 UI 투자, 적 앞 투자 거절, 투자 후 실제 캠페인 공격 검증, 실제 처치 XP → 투자 → 세션 저장의 정확한 재현.
- `legacy_shell_engine_acceptance.gd`: 기존 화면/새 엔진 연결과 저장 재현.
- `field_turn_acceptance.gd`: 실제 이동/공격/기술, 실패 rollback, 마을 출발, 저장 재현.
- `radial_darkness_acceptance.gd`: 원형 감쇠·횃불·안개/기억 분리·단일 mesh·광원 LOS 재사용.
- X11/OpenGL 360px 숙련 UI 렌더링 확인. Web 릴리스 내보내기로 배포 가능 여부 확인.

모바일 확인: 새 게임 → 같은 복도에서 자동탐험 → 물 가장자리 이동 → 적 발견 시 정지 → 처치 후 안전 지역에서 숙련 투자 → 재접속 후 포인트 보존 확인. 실제 장시간 이동의 프레임 간격은 추가 확인이 필요하다.
