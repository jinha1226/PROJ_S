# 레이드 전투 방식 비교 시제품

상태: ⬜ 미구현 · 실험

작성일: 2026-09-29 · 목적: `설계_레이드.md`의 전투를 **턴제 / 격자 실시간 + 멈춤 / 완전 실시간** 세 방식으로 같은 상황에서 직접 해보고 하나를 고른다.

## 0. 원칙

- **본 게임과 분리한다.** 별도 페이지 `raid-lab.html` + `js/lab/` 모듈. 본 게임의 흐름·저장·테스트에 영향이 없어야 한다.
- **같은 전투, 방식만 다르게.** 지도·파티·보스·수치는 세 방식이 모두 같다. 방식 전환은 화면 위 토글.
- **빨리, 단순하게.** 그래픽은 지금의 DioramaKit을 그대로 쓰고 새 모델은 만들지 않는다. 버려질 수 있는 코드다.
- 규칙(원소·지형·상태 이상·피해 계산)은 가능한 한 본 게임의 `js/core/`를 불러 쓴다. 못 쓰면 `js/lab/`에 작게 다시 만든다.

## 1. 시나리오 (세 방식 공통)

- **지도**: 16×16 방 하나. 가운데 물웅덩이(3×3), 한쪽 풀밭, 기둥 4개(시야·이동 막음), 벽 틈 2곳(졸개가 나오는 곳).
- **파티**
  - 등불지기(플레이어): HP 40, 무기 장검. 영혼석 스킬 3개 고정 — 번개(빨강), 물벼락(보라), 반격 자세(초록).
  - 동료 4(AI): 수호자(도발·방패 막기), 검사(휩쓸기·출혈 베기), 궁수(관통 사격·물러나며 쏘기), 치유사(치유·보호막). 성향은 모두 기본(역할에 맞게).
- **보스: 잊힌 파수병(간이판)** HP 120, 기믹 셋.
  1. **표적 집중 + 부채꼴 내려치기**: 위협이 가장 높은 대상 쪽으로 부채꼴(반경 3) 예고 → 내려침(피해 12).
  2. **흩어져라**: 모두의 발밑에 원(반경 1) 예고 → 겹쳐 있으면 피해 두 배.
  3. **졸개 부르기**: HP 60% 아래에서 벽 틈으로 해골 궁수 2.
- 격노: 턴제 30라운드 / 실시간 90초.

## 2. 세 방식

### 2.1 A. 턴제 (기준)

- `등불지기 → 동료 넷 → 적` 차례. 동료·적 연출은 한 명당 0.2초, 두 번 탭하면 건너뜀.
- 예고는 "다음 턴".

### 2.2 B. 격자 실시간 + 멈춤 (추천안)

- 격자 위에서 **시간이 흐른다.** 모든 유닛이 자기 행동 간격마다 행동한다: 기본 0.6초, 빠른 적 0.45초, 무거운 행동(내려치기) 1.2초.
- 등불지기 조작: 칸 탭 → 그 칸으로 이동하거나 붙은 적 공격(다음 행동 때 실행, 이후 계속 그 대상을 공격). 영혼석 칸 → 대상 칸 탭 → 다음 행동 때 발동.
- **멈춤**: 화면 위 ⏸ 버튼. 멈춘 동안에도 이동·대상·스킬·파티 명령을 고를 수 있고, 다시 누르면 흐른다.
- **자동 멈춤**(토글, 기본 켜짐): 보스가 기믹 예고를 시작할 때 한 번 멈춘다.
- 예고는 초 단위: 칸 위에 차오르는 막대(내려치기 1.5초, 흩어져라 2초).
- 속도: 0.5× · 1× · 2×.

### 2.3 C. 완전 실시간 (자유 위치)

- 커밋 `63c33bf2`의 자유이동 코드를 `js/lab/`로 가져와 쓴다: `js/core/space.js`(거리·경로·충돌), `js/core/free.js`·`free-ai.js`(행동·AI), `js/ui/free-input.js`(플로팅 조이스틱). **본 게임 경로에 되살리지 않는다.**
- 연속 좌표, 원형 충돌체. 1칸 = 1m, 사거리·범위도 m.
- 등불지기 조작: 플로팅 조이스틱으로 이동, 적 탭 → 대상 고정(사거리 안이면 자동 공격), 영혼석 버튼 → 조준(끌어서 방향·지점) → 놓으면 발동.
- 동료·적은 같은 행동 간격(0.6초 기준)으로 스킬을 쓰고, 이동은 연속.
- 예고는 바닥의 원·부채꼴이 차오르는 모양(같은 초).
- 멈춤 버튼은 비교를 위해 여기에도 둔다(자동 멈춤은 없음).

### 2.4 공통

- 파티 명령 5개(🎯 집중 · ⤧ 흩어져 · ⤨ 모여 · ↩ 물러나 · 🤖 자동)는 세 방식 모두 같다.
- 파티 줄(5명 얼굴·HP), 보스 체력·단계·남은 시간(또는 라운드)은 같은 HUD.
- 원소 시너지(물벼락으로 적시고 번개로 번지게)는 세 방식 모두 된다.

## 3. 비교 기록

전투가 끝나면(승리·전멸·격노) 결과 창에 아래를 보여주고 `localStorage`에 쌓는다. 세 방식의 기록을 나란히 보는 **비교 표** 버튼이 있다.

| 기록 | 뜻 |
| --- | --- |
| 걸린 시간 | 실제 초 |
| 입력 수 | 탭·조이스틱 조작 횟수 |
| 멈춤 횟수 · 멈춘 시간 | B·C |
| 기다린 시간 | A: 내 차례가 아닌 동안의 실제 초 |
| 기믹 피함 / 맞음 | 내려치기·흩어져라 |
| 쓰러진 동료 | 수 |
| 결과 | 승리 · 전멸 · 격노 |

- 결과 창에서 세 가지를 1~5로 매긴다: **재미 · 한눈에 읽힘 · 조작 부담**. 한 줄 메모도 남길 수 있다.

## 5. 확인 목록

1. `raid-lab.html`이 열리고, 본 게임(`index.html`)과 테스트는 그대로 통과한다.
2. 세 방식 모두 같은 지도·파티·보스로 끝까지 싸울 수 있다(승리 또는 전멸).
3. B: 시간이 흐르고, ⏸로 멈춘 채 지시할 수 있고, 기믹 예고 때 자동으로 멈춘다(끌 수 있음).
4. C: 조이스틱 이동·대상 고정·끌어서 조준이 된다. 자유이동 코드는 `js/lab/`에만 있다.
5. 동료 넷이 역할대로 움직인다(수호자 도발, 치유사가 가장 다친 동료).
6. 흩어져라·모여라 명령이 세 방식 모두에서 기믹을 푼다.
7. 결과 창에 §3 기록과 점수가 남고, 비교 표에서 세 방식이 나란히 보인다.
8. 폰에서 한 라운드(A) 또는 10초(B·C) 동안 프레임이 끊기지 않는다.
