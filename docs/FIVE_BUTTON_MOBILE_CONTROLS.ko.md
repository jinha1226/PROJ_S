# 모바일 하단 다섯 버튼

- 고정 순서: 공격 / 대기·휴식 / 탐험 / 전술 / 가방.
- 현재 보이는 적이 없고 탐험 가능한 상태라면 두 번째 버튼은 휴식이다. 적이 보이거나 기존 전투 단계에서는 대기다. 숨은 적의 정보를 UI에 노출하지 않는다.
- 휴식은 기존 파티 HP·MP 회복 루프를 사용한다. 회복 완료, 적 발견, 피해, 굶주림, 회복 불가 시 중단한다. 휴식 중 버튼은 ‘휴식 중지’가 된다.
- 적 근처 대기는 한 번의 기존 HOLD 행동이다. 별도 전투 계산은 추가하지 않는다.
- 탐험 중 같은 버튼이 ‘중지’로 바뀐다. 포탈·여행자 선택·재장전 등 기존 상황별 상호작용은 고정 줄 위에 필요할 때만 나타난다.
- 별도 줍기 버튼은 없다. 다른 타일 탭은 이동만 수행한다. 현재 조작 캐릭터의 타일(캐릭터 포함)을 다시 누르면 하나의 아이템은 즉시 줍고, 여러 개는 선택 목록을 연다. 빈 타일의 재탭은 시간과 행동을 소비하지 않는다.
- 목록 열기·취소에는 비용이 없다. 아이템 획득은 기존 검증과 시간 비용을 따른다. 발밑에 아이템이 있으면 캐릭터 옆에 금색 + 표식을 표시한다.

## 검증

- `tests/five_button_pickup_acceptance.gd` 통과: 360/390/450 폭의 다섯 버튼, 최소 터치 폭, 안전 지역 휴식 표시, 적 발견 후 대기 전환 및 화면 터치로 단일 HOLD, 캐릭터 타일 화면 터치로 줍기, 복수 선택, 빈 타일 무행동, 저장 재생.
- `tests/attack_button_acceptance.gd` 통과: 기존 공격 및 저장 재생.
- 기존 UI 테스트의 제거된 버튼 관련 기대값을 새 계약에 맞췄다. 전체 기존 테스트 모음은 실행하지 않았다.
- 실제 휴대폰의 시각적 가독성 및 조작 감각은 별도 확인이 필요하다.
