# 필드 구역 콘셉트

## 방향

던전은 같은 모양의 방에 재질을 무작위로 흩뿌리는 공간이 아니라, 문턱을 넘을 때 한눈에
성격이 바뀌는 여러 작은 필드의 연속으로 구성한다. 기본 표기는 순수 ASCII를 유지하고
`docs/ASCII_MATERIAL_VISUAL_LANGUAGE.ko.md`의 재질 문법을 사용한다.

필드의 차이는 배경 이미지나 색 면이 아니라 다음 네 요소로 만든다.

1. 같은 재질 문자를 가까운 칸에 묶어 덩어리로 배치한다.
2. 실제 이동·연소·전도 규칙이 있는 재질과 장식 재질을 명확히 분리한다.
3. 움직이는 것은 물 `~`, 풀 `"`, 불 `^`, 독 `%`으로 제한한다.
4. 벽 `#`과 바닥 `.`은 모든 필드를 이어 주는 공통 골격으로 둔다.

## 필드 어휘

| 구역 | 주 문자 | 현재 의미 | 분위기와 플레이 단서 |
|---|---:|---|---|
| 침수 저수조 | `~` | 얕은 물 지형 | 이동이 느리고 물 노출·전도가 높다. 물결이 수평으로 흐른다. |
| 폐쇄된 주조장 | `+` | 금속 지형 | 전도성이 높은 길과 젖은 금속 위험을 읽게 한다. |
| 탄 목재 회랑 | `=` `^` | 가연성 나무와 실제 불 | 불길이 번질 수 있는 방으로 읽힌다. |
| 무너진 채굴실 | `,` | 잔해 지형 | 이동이 느린 돌무더기와 좁은 전투 동선을 만든다. |
| 잠식된 정원 | `"` | 돌바닥 위 식생 표현 | 풀만 미세하게 흔들리며 폐허가 오래됐다는 인상을 준다. |
| 얼어붙은 묘실 | `*` | 돌바닥 위 빙결 표현 | 차갑고 날카로운 정적 재질이다. 미끄러짐 규칙은 아직 없다. |
| 안개 회랑 | `.` | 돌바닥 위 안개 표현 | 낮은 대비의 정적 점으로 시야 분위기만 바꾼다. |

독성 구역 `%`은 시각 문법과 애니메이션은 준비돼 있지만 현재 생성기에는 넣지 않는다.
독처럼 보이는 칸이 실제 위험하지 않으면 플레이어를 속이게 되므로, 환경 독 농도·피해·경로
평가가 같은 권위 상태로 연결될 때 함께 도입한다.

## 층 진행에 따른 조합

- 초반부: 무너진 채굴실, 잠식된 정원, 작은 침수 저수조로 재질 읽는 법을 익힌다.
- 중반부: 폐쇄된 주조장, 탄 목재 회랑, 안개 회랑을 조합해 전도와 화재 선택을 만든다.
- 심층부: 얼어붙은 묘실을 늘리고, 독 시스템이 완성되면 독성 구역을 추가한다.
- 보스층: 새 문자를 더하기보다 해당 구간에서 배운 두 재질을 넓고 명확하게 결합한다.

한 층에 모든 구역을 반드시 넣는 규칙은 아니다. 현재 단일 96×96 원정은 검증을 위해 일곱
구역을 모두 한 번씩 배치하며, 다층 생성기가 생기면 위 진행표에 따라 3~5종만 선택한다.

## 생성 규칙 v1

- 입구·출구 방은 읽기 쉬운 돌바닥으로 남긴다.
- 실제 재질인 물·금속·나무·잔해는 서로 다른 방 하나씩에 중앙 덩어리로 배치한다.
- 장식 재질인 풀·얼음·안개도 각각 독립된 방 하나에 배치한다.
- 출입구, 적 생성점, 목적지에는 재질을 덮지 않는다.
- 같은 seed는 구역 선택, 칸, 위험 위치까지 완전히 동일하다.
- 장식 재질은 충돌, 이동비용, FOV, 저장, 시뮬레이션 RNG를 바꾸지 않는다.
- `VISIBLE`에서는 해당 재질을 그리고, `MEMORY`에서는 정지된 재질만 기억하며,
  `UNSEEN`에서는 구역 정체를 노출하지 않는다.

기존 `sector-rooms-snake-v3-96x96-large-chambers` 세이브는 종전의 흩어진 재질 지형으로
재생성한다. 새 원정만 `sector-rooms-snake-v4-clustered-field-regions`를 사용한다.
