# 1층 조도 튜닝 결과

- 실험 ID: `DARKNESS-FLOOR1-001`
- 실제 원정 1층 기본 조도를 `900`에서 `600`으로 낮췄다.
- 마을 `900`, 2층 `400`, 3층 이상 `120`과 기존 횃불·종족 시야·암흑 스트레스 규칙은 변경하지 않았다.
- 조도 `600`은 `DIM` 구간이므로 인간 기본 시야는 개방 지형 전방에서 최대 6칸에서 5칸으로 줄고, 기존 어둠 방향 제한이 적용된다.

## 검증

- `tests/run_darkness_v2_regression.gd`: 통과. 층별 조도와 마을 조도를 확인했다.
- `tests/run_darkness_living_regression.gd`: 통과. 실제 원정 저장 복원 후 1층 조도를 확인했다.
- `tests/run_darkness_compatibility.gd`: 12/12 통과. 기존 종족 시야·횃불·암흑 계약을 확인했다.
