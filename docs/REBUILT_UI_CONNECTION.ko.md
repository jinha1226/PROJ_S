# 새 던전 시스템과 기존 UI 연결

- 날짜: 2026-09-12
- 기준 commit: `6095424`
- 요청: 현재 시스템과 기존 UI 연결을 먼저 진행. 앞서 요청한 방어 숙련의 방어 수치 보정도 반영.

## 적용 범위

기본 진입점의 `game/rebuilt/game.gd`에서 기존 `DarkPixelUISkin`, `AsciiGauge`, `illustrated_action_button.gd`를 재사용한다. 새 World가 상태의 정본이며, UI는 World의 명령과 조회를 사용한다. 기존 캠페인 실행부를 동시에 실행하지 않는다.

- 상단: 층/레벨, HP/MP/경험치 게이지, 횃불 점등과 잔여 시간. 횃불은 행동 시간 100을 기준으로 남은 약 턴 수를 표시한다. 물 이동·공격 시간에 따라 실제 행동 횟수는 달라진다.
- 하단: 기존 아이콘의 대기/탐험/가방/동료 버튼과 회복약/사격/화염탄/횃불/성장/상태/계단/메뉴.
- 가방은 장비 탭, 성장은 숙련 탭, 상태는 신체 상태 탭을 바로 연다. 인물 선택으로 동료의 숙련과 실제 신체 상태를 확인한다.
- 상태 탭: 성격/HP/스트레스/피부 질김/뼈 강도/혈액/충격/부위 손상/장비와 최종 전투 수치.
- 장비 변경 시 HUD와 사격 가능 여부 갱신. 사격은 활과 화살, 화염탄은 결속과 MP가 있어야 활성화된다. 다음 층은 계단 위에서 활성화된다.
- 창을 열면 자동탐험/자동이동/대상 선택을 중지하고 버튼 표시도 갱신한다. 저장과 새 게임은 메뉴 안에 배치한다.
- 100px 고정 버튼 너비와 430px 지도 최소 높이를 제거하고, 캐릭터 탭에 세로 스크롤을 추가했다. 대화창 너비는 뷰포트에 맞춘다.

이 연결은 기존 UI 부품을 재사용한 새 던전 화면이다. 기존 마을/상점/관계/명령 편집 화면 전체 이식, NPC 원거리 시뮬레이션 분리, 동료 장비 변경과 모든 이능 콘텐츠는 포함하지 않는다.

## 방어 숙련 변경

이 문서가 이전 4계열 결과 문서의 일괄 피해 감소 규칙을 대체한다.

- 점당 방어 수치 +8%, 10점에서 ×1.80. 최종 정수 수치는 반올림한다.
- 갑옷 보호력과 사용 가능한 방패 확률에 적용한다. 천옷의 보호 0과 방패 없음의 확률 0은 그대로 0이다. 팔 부상이나 양손 무기로 사용 불가능한 방패도 효과가 없다.
- 기본 회피 5에 방어 숙련을 적용한다. 회피 값은 상대 물리 명중 확률에서 차감한다. 방패 확률 상한은 60%다.
- 예: 10점에서 사슬 갑옷 보호 5→9, 회피 5→9, 소형 방패 12%→22%.
- 적중 후 숙련 피해 감소를 제거했다. 화염탄은 마법 숙련과 대상 화염 저항을 사용하며 방어 숙련의 추가 일괄 감소를 받지 않는다.
- 투자 확인창에 현재 장비 기준 보호/회피/방패의 전후 값을 표시한다. 낮은 기본값은 반올림 때문에 한 점 투자로 최종 수치가 바뀌지 않을 수 있다.
- 보정은 기존 장비 수치 캐시에 포함한다. 매 프레임 신체·장비 계산을 추가하지 않는다.
- 저장 schema 4와 포인트는 유지하며, 보정 수치는 새 규칙으로 계산한다. 초기 밸런스이며 장기 실전 밸런스 검증은 별도다.

## 검증

Godot 4.6.2에서 다음을 통과했다.

- `tests/rebuilt_ui_acceptance.gd`: 360×800 배치, 기존 게이지/스킨 재사용, 창 진입 시 자동행동 취소, 가방 탭 연결, 활 장착 후 사격 활성화, MP에 따른 화염탄 활성화, 포인트/HP 갱신, 동료 창 너비.
- `tests/rebuilt_growth_acceptance.gd`: 기존 성장/명령/저장 검사와 방어 수치 보정, 없는 갑옷/방패 효과 생성 방지, 화염 저항과 방어 숙련의 분리.
- `tests/rebuilt_equipment_acceptance.gd`, `tests/rebuilt_party_body_acceptance.gd`, `tests/rebuilt_runtime_acceptance.gd`: PASS.
- 기본 씬 실행 및 Web 릴리스 내보내기 성공.
- X11/OpenGL 소프트웨어 렌더링의 390×844 화면에서 HUD, 숙련, 신체 상태 탭을 시각적으로 확인했다. 실제 모바일 브라우저 터치·장시간 성능 검증과는 구분한다.
