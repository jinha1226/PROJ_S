# UI-GAMEPLAY-01 결과

2026-09-16 · 기준 commit 088cec4. GAMEPLAY_INTEGRATION_PLAN의 모바일 맵 중심 UI를 우선 반영했다.

## 변경

- 상단 정보줄 76→60px, 파티 카드 84→68px. 기술 줄은 기본 접힘이며 하단 기술 버튼으로 연다.
- 탐험에서는 탐험, 적이 보이면 공격을 노출한다. 동료가 있을 때 전술을 표시한다. 기존 상호작용·구조·휴식 동작을 연결한다.
- 파티 카드에서 이름, HP/MP, 체력 바와 정성적 상태를 표시한다. 전투불능 상태에서는 유예시간을 우선한다. 자세한 능력치는 기존 상세 화면에서 확인한다.
- 최신 의미 있는 턴의 사건에서 행동·결과·반응을 최대 3줄 선택한다. 중복 문구와 이동 등의 반복 기록을 제외하며, 새 획득 기록에 이전 전투를 섞지 않는다. 기록된 문구를 사용하고 반응을 새로 생성하지 않는다. 긴 문장은 말줄임하고 전체 기록은 메뉴에 남긴다. 휴식 중 안내도 유지한다.
- 가방 버튼과 겹치던 빌드 번호를 제품 화면에서 숨기고 메뉴 툴팁으로 옮겼다.

## 검증

- `tests/gameplay_mobile_ui_acceptance.gd`: PASS. 320×640, 390×844, 450×800 배치, 맵 높이 50% 이상, 44px 터치 영역, 기술 열기/닫기, 표시만으로 시뮬레이션이 바뀌지 않음, 사건 요약, 전투불능 시간 우선 표시를 검사한다.
- 실제 렌더 검사도 PASS. 같은 검사를 X11 / GL compatibility로 실제 렌더링해 화면 배치와 글자 겹침을 확인했다.
- `tests/main_hud_acceptance.gd`: PASS. HUD 경계와 자원 표시 회귀 검사.
- `tests/field_turn_ui_acceptance.gd`: `wait button spends exactly one turn` 한 항목 실패. HEAD의 수정 전 shell을 별도 스크립트로 로드해 같은 실패를 재현했다. 안전한 탐험에서 해당 버튼은 휴식을 시작하므로 즉시 한 턴 대기한다는 기존 검사와 맞지 않는다. 이번 변경에서 턴·휴식 규칙이나 이 검사는 수정하지 않았다.
