# 액티브 전투 실험 모드

## 범위

시작 종족 선택 화면 또는 게임 메뉴의 **4인 전투 테스트 · 마법**에서 진입한다. 일반 원정 시작은 그대로 보존한다. 주인공을 포함한 4인 파티와 근처 몬스터 5마리, 18×18 맵으로 시작한다. 고정 시드 44를 사용해 같은 조건에서 비교한다.

이는 **독립적인 전투 프로토타입**이다. 기존 Simulator의 저장/재생/상처/사망/전체 감정·기억·전투 시간 처리와 아직 통합하지 않았다. 캠페인 세계를 변경하지 않으며 테스트 중 기존 입력/자동 이동/자동 전투는 멈춘다. 종료하면 원래 화면으로 돌아간다. 기존 동료 1회 지시 기능은 본 게임에 있고, 이 실험 모드에는 별도 연결하지 않았다.

## 기술과 자원

- 캐릭터별 공용 기력 12. 물리 액티브와 마법이 공유한다.
- 강타: 비용 3, 인접 피해 30.
- 화염탄: 비용 3, 사거리 5, 화염 피해 32. 화염 저항을 적용한다.
- 보호막: 비용 4, 사거리 4, 피해 28 흡수. 합산하지 않는다. 대상의 행동 기회 2회 후 만료한다.
- 응급 치유: 비용 4, 사거리 4, 최대 24 회복. 실제 체력 피해의 50%만 치유 가능하며 사용한 회복 한도는 소진한다.
- 밀치기: 비용 3, 인접 피해 8 + 한 칸 밀기. 벽/다른 인물이 있는 칸으로 밀 수 없다.
- 기본 공격/이동/대기는 기력 0. 이번 프로토타입은 기력 자연 회복·이능·쿨타임을 넣지 않았다. 재시작하면 초기화한다.
- 장착 액티브 2개. 주인공은 첫 행동 전에 `기술 구성`으로 세 프리셋 중 선택한다.

## 조작과 자동 행동

주인공: 적 터치로 인접 기본 공격, 빈 인접 칸 터치로 이동. 기술 버튼 → 유효 대상 강조 → 맵/아군 카드에서 대상 선택 → 사용. 취소/선택은 턴과 기력 소모 없음. 한 번 확정하면 주인공·동료·적 순으로 각 한 번 행동하는 정규화된 라운드를 진행한다. 본 게임의 시간축과 동일하다고 간주하지 않는다.

동료: 합법적인 기본 공격/기술/이동 후보를 효용 점수로 선택한다. 기존 HEXACO 생성기의 A/C가 지원 가치와 자원 절약 가중치에 반영된다. 전체 감정·기억 시스템은 아직 이 프로토타입에 연결하지 않았다. 선택 점수는 model.decisions, 행동 기록은 model.history에서 확인한다.

## 모듈과 검증

- sim/abilities/active_skill_registry.gd: 초기 수치와 기술 정의.
- sim/abilities/active_effect_model.gd: 입력을 변경하지 않는 사거리/시야/진영/기력/효과 평가. 향후 본 전투의 권위 있는 명령 처리에서 재사용할 대상.
- playtest/active_combat_lab_model.gd: 프로토타입 상태와 실행/간단한 동료 AI.
- playtest/active_combat_lab_board.gd: 기존 타일/배우 에셋으로 그리는 보드와 입력.
- playtest/active_combat_lab.gd: 모바일 UI.

검증 명령:

```
godot --headless --path . --script tests/active_effect_smoke.gd
godot --headless --path . --script tests/active_combat_lab_smoke.gd
```

효과 평가의 무변경성, 자원 부족, 저항, 벽 모서리 시야 차단, 밀치기 충돌, 보호막 흡수/만료, 치유 한도, 자동 행동, 고정 시드 재현, 두 세로 해상도의 UI 선택/확인을 검사한다. 프로토타입에서 확인된 규칙을 본 게임으로 옮길 때는 별도의 상태 직렬화·이벤트·턴 검증·재생 테스트가 필요하다.
