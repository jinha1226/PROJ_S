# 인간과 개인 재능 MVP

2026-09-08: 새 본 게임은 종족을 선택하지 않고 인간으로 거점에서 시작한다. 종족 데이터와 구버전 로딩은 삭제하지 않는다. 기존 저장을 불러오면 그 저장의 종족·능력치·재능 유무를 그대로 유지한다.

## 개인 차이

- 재능: 인물 생성 시 고정되는 작은 능력치 강점. 주인공·동료·부상당한 여행자·길드 후보 모두 하나씩 받는다.
- 성격: 기존 HEXACO 및 감정·관계·행동 판단을 유지한다. 재능으로 대체하지 않는다.
- 장비·이능·기술: 기존 시스템을 유지한다. 재능을 스킬이나 마법의 필수 사용 조건으로 만들지 않는다.

| 재능 | 현재 효과 |
| --- | --- |
| 타고난 근력 | 힘 +1 |
| 정교한 손 | 민첩 +1 |
| 마력 감응 | 지능 +1 |
| 강인한 체질 | 방어 +1 |
| 날렵한 반사신경 | 회피 +3%p |
| 안정된 방어 | 막기 +3%p |

새 캠페인의 사람은 인간 기본 능력치와 최대 체력 120으로 생성한다. 부상·장비·성장에 의한 차이는 별도다. 재능은 성격 시드와 인물 ID에서 생성하되 별도 해시를 사용하여 전투 난수와 성격 계산을 소모하지 않는다. 새 게임에서는 재능을 다시 생성하고, 이어하기는 생성된 재능을 보존한다. 재능의 강도가 서로 동등하다는 뜻은 아니며, 첫 플레이테스트에서 효과와 가시성을 확인할 초기값이다.

인물 상태창과 스킬 목록에 이름 및 실제 보너스를 표시한다. 새 인물의 종족 특성 성장 선택은 비활성화한다. 마법과 이능을 새로 추가하는 작업은 이번 범위가 아니다. 초자연적인 종족 특징은 나중에 이능으로 재설계하며 단순 개명으로 이전하지 않는다.

## 구현 경계

- `sim/personal_talent_rules.gd`: 6종 정의, 결정론적 생성, 저장 태그 해석, 능력치/전투 보너스.
- 새 캠페인 시작 기록으로 인간 생성 정책을 구분한다. 이전 저장은 해당 기록 없이 예전 생성 규칙으로 재현한다.
- 공용 능력치 및 방어 계산에 연결한다. 새 인간 동료도 주인공과 같은 장비/재능 방어 경로를 사용한다.
- UI는 생성된 값만 표시한다. 화면을 다시 열거나 저장을 불러오면서 재능을 재추첨하지 않는다.
- 본 게임 대상 변경이며 기존 별도 전투 실험실과 역사적 종족 테스트 시나리오는 유지한다.

로컬 검사는 `tests/human_talents_smoke.gd`, `tests/duo_autobattle_smoke.gd`, `tests/base_progress_ui_smoke.gd`, `tests/run_base_settlement_rules_tests.gd`로 한다. GitHub Actions에 무거운 검사를 추가하지 않는다.

위 네 검사 통과: 인간/재능 생성과 기존 저장 호환, 전투 후 탐험/저장 복원, 360/390px 거점 UI, 건설 규칙 3개. 자동전투 후 이탈 완료 기록이 있는데도 현재 동료를 과거의 배치 상태로 검증하던 오류도 함께 수정했다. 실제 휴대전화 가독성과 재능 간 밸런스는 플레이테스트 대상이다.
