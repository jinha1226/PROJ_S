# 2인 자동전투 실험

기본 시작 시나리오는 `DUO_AUTOBATTLE_V1`. 주인공과 나래의 2인 파티로 시작한다. 이전 솔로 실험과 파티 저장의 시나리오 ID 및 재현 규칙은 유지한다. 신규 영입은 막아 이번 실험을 2명으로 제한한다.

탐험 이동은 기존 직접 이동과 경로 이동을 사용하고 동료는 기존 그룹 이동 규칙을 따른다. 적 조우 시 기존 대형 배치와 파티 전투 코디네이터로 진입한다. 주인공 행동도 기존 동료 판단기의 평가로 선택하고 동료·적의 행동, 피해, 재집결은 본 게임의 공용 전투 처리와 명령 기록을 사용한다. 별도 실험장 결과를 HP만 복사하는 방식은 사용하지 않는다.

전투는 표시 시간 약 0.7초 간격으로 한 번씩 진행한다. 내부 행동 비용은 기존 턴 규칙 그대로다. 일시정지/재개, 집중 표적, 후퇴, 공격 중지, 자리 지키기, 자율 전투 복귀 지침을 제공한다. 지침 선택 팝업·인물/지도 창·대상 선택·터치 중에는 자동 진행을 멈춘다. 전투가 끝나면 자동 진행을 멈추고 기존 재집결 후 탐험으로 돌아간다. 잘못된 계획은 반복 실행하지 않고 일시정지한다.

현재 연결한 본 게임 PartyActionCommand의 행동은 MOVE/MELEE/HOLD다. 별도 ActiveCombatLab의 마법·보호막·치유 및 행동 타임라인 전체가 이 엔진에 통합된 것은 아니다. 두 모델을 구분하고 후속 공통 행동 확장에서 마법 시너지를 연결한다. 이번 변경은 확정 난이도 조정이 아니다.
