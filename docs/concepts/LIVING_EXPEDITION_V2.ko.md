# 탐험 개편 1차 구현

2026-09-09. 모바일 세로 화면에서 종족·장비·장소·NPC 행동이 읽히는 첫 적용판.

## 범위

- 정면 탑뷰 유지. 머리/몸통형 캐릭터 5종(인간·엘프·드워프·오크·수인), 몬스터와 장비의 일관된 미술 방향.
- 종족 선택 및 마을/NPC 종족 복구. 개인 재능과 성격은 독립적으로 유지. 기존 저장을 임의 재추첨하지 않는다.
- 1층: 침식 숲 / 침수 유적, 2층: 잿빛 주조장. 큰 구조물·휴식처·갈림길이 있는 짧은 발견 구간부터 구현.
- 던전의 중립 NPC: 탐색, 실제 공통 규칙 전투, 안전한 휴식, 부상/물자 부족 시 귀환. 플레이어 동료로 자동 편입하지 않는다.
- 성격·체력·보급에 따라 위험 감수와 휴식/후퇴 판단이 달라진다. 이름/상태창/관계/사망 결과는 같은 인물을 가리킨다.
- 행동은 월드 시간에 연결하며 화면 갱신으로 월드가 변하지 않는다. 일시정지/상태창에서는 시간도 정지한다.

## 저장과 검증

새 규칙은 시작 이벤트로 구분한다. 기존 원정의 NPC/맵/종족은 재작성하지 않는다.
이동 가능성, 주요 지점 연결, 종족 생성/장착/인물창, NPC 공격/피격/휴식/귀환,
중립성, 시간 정지, 저장 재생을 집중 검사한다. CI에 장시간 시뮬레이션을 추가하지 않는다.
