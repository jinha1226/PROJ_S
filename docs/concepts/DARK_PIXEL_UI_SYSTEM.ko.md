# 어두운 픽셀 던전 UI 시스템

기준 목업: [`ui/dark_inventory_mockup_v1.png`](ui/dark_inventory_mockup_v1.png)

목업은 분위기와 정보 위계만 정의한다. 화면 전체를 한 장의 이미지로 사용하지 않는다.
실제 제품 UI는 Godot 컨테이너와 입력 시스템으로 배치하고, 프레임·슬롯 상태는
`playtest/dark_pixel_ui_skin.gd`의 공통 토큰으로 그린다. 아이콘만 24px 래스터 에셋을
사용한다.

## 시각 원칙

- 검은 철과 청흑색 표면을 기본으로 사용한다.
- 텍스트는 순백색 대신 뼈색을 사용한다.
- 평상시 테두리는 저채도 철색으로 억제한다.
- 선택 상태만 황동색 2px 테두리와 네 모서리 브래킷으로 강조한다.
- 위험 행동은 탁한 혈색을 사용한다.
- 장식보다 타일, 아이콘, 수치의 판독성을 우선한다.
- 모서리는 둥글게 만들지 않으며 그라데이션 대신 1~2px 명암 단계를 사용한다.

## 컴포넌트 계약

- 인벤토리: 장비 5칸 + 가방 5×4칸
- 슬롯 최소 크기: 52×52px, 터치 영역은 항상 44px 이상
- 기본 아이콘: 24×24px, nearest 필터
- 팝오버: 선택한 슬롯 가까이에 열고 장착·사용·버리기 행동을 제공
- 모바일과 데스크톱은 동일한 컴포넌트를 사용하고 컨테이너 크기만 반응형으로 조절

## 적용 순서

1. 아이템창을 기준 화면으로 완성한다.
2. 같은 패널·버튼·강조 규칙을 상태창과 NPC 정보창에 확장한다.
3. HUD와 마을 화면에 필요한 변형만 공통 스킨에 추가한다.
4. 개별 화면에서 임의 색상이나 중복 StyleBox를 만들지 않는다.

생성 목업은 방향성 참고 자료이며 배포 빌드가 직접 참조하지 않는다.
