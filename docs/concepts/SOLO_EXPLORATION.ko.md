# 솔로 탐험 전환

이 문서는 보존된 솔로 실험을 설명한다. 현재 기본 시작 흐름은 `DUO_AUTOBATTLE.ko.md`의 2인 자동전투 실험으로 대체되었다.

신규 기본 시나리오는 `SOLO_EXPLORATION_V2`다. 플레이어 한 명으로 탐험하며 영입·자동 합류·길드 후보 생성을 비활성화한다. 시작 화면의 4인 전투 실험 진입 버튼도 제거한다. 기존 파티 엔진과 실험 코드는 삭제하지 않는다.

NPC 구조와 물약 제공, 성격·관계·감정·기억 및 기존 자율행동은 유지한다. 도움을 주어도 동료로 전환하지 않는다. 앞으로의 시뮬레이션 중심은 지형·상태·피해 상호작용이며, 감정은 NPC의 행동 선택에 활용한다. 이번 변경은 새로운 감정 AI나 전격 증폭 계수를 추가하는 작업은 아니다.

이전 시나리오 저장은 기존 규칙으로 복원하여 모집 기록의 재현을 보존한다. 새 규칙은 기본 시작 화면에서 새로 시작한 게임에 적용된다. 기존 저장의 동료를 강제 삭제하지 않는다.

기존 적 수와 전투 계수는 이번 전환에서 변경하지 않았다. 솔로 전투 난이도, 스킬·소모품으로 환경 조합을 만드는 수단, NPC 행동의 가독성은 후속 플레이테스트 항목이다.
