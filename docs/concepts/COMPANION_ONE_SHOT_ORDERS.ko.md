# 동료 다음 행동 1회 지시

동료는 기본 자동전투를 유지한다. 인물창에서 `다음 행동 지시`를 열면 기존 하단 행동 영역을 교체하며, 이동/근접 공격/대기 중 하나를 대상 선택 후 예약한다. 예약과 취소는 월드 시간이나 명령 저널을 진행시키지 않는다. 주인공 행동 시 동료의 기존 행동 기회를 대체하고, 한 번 실행 후 자동 판단으로 복귀한다. 바쁜 동료에게 추가 행동권을 부여하지 않는다.

- 예약은 초상화의 금색 점으로 표시. 인물창에서 변경하거나 취소 가능.
- 실행 시 다시 전체 전투 규칙으로 검증. 잘못된 대상/경로/충돌은 임의 재지정하지 않고 해당 행동을 대기로 전환, 예약 취소를 알린다.
- 저장된 월드 상태가 아니라 미확정 UI 예약이다. 불러오기/새 게임 시 제거한다. 실제 실행은 기존 party_turn 저널의 override로 기록한다.
- 현재 실제 명령 종류는 HOLD/MOVE/MELEE. 액티브·마법과 그 자원은 아직 구현하지 않았으며 UI에 가짜 사용 버튼을 노출하지 않는다.
- `companion_order_queue.gd`: 턴 초안과 독립적인 예약, 실행 후보 검증, 성공 시 소비.
- `companion_order_editor.gd`: 행동/대상 선택과 확인 UI.
- 세션은 기존 권위 있는 턴 검증·실행·재생을 사용하며 코디네이터의 성격 점수나 전투 시간 규칙을 수정하지 않는다.

검증: `godot --headless --path . --script tests/companion_order_smoke.gd`. 예약 무시간, 주인공 초안 교체 후 유지, 자동 추천 대체, 1회 소비, 수동 취소, 대기 중 보존, 잘못된 대상의 대기 전환, 실제 인물창에서 예약까지 확인한다.
