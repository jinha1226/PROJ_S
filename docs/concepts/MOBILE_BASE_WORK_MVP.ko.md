# 모바일 거점 운영 MVP · 2026-09-08

## 이번 구현

던전 탐험/교전 → 목재·석재·약초 확보 → 입구/활성 포탈로 귀환 → 창고 보관 → 건설/증축 지시 → 주민 작업 → 시설 이용.

- 기존 16×16 거점에 자유롭게 시설 위치를 지정한다. 통로, 나무, 기존 시설을 막는 배치는 거절한다.
- 한 번에 공사 하나만 진행한다. 작업 우선순위 표나 주민별 수동 배정 화면은 만들지 않는다.
- 건설 지시는 재료를 먼저 확보한다. 주민이 접근 가능한 경로로 공사 현장 옆까지 이동하고 6 작업 단계를 완료해야 시설이 열린다.
- 거점에 머무는 동안 0.5초마다 한 작업 단계가 진행된다. 던전 탐험 시간과는 별개이며, 앱 비활성/던전 출발 중에는 진행하지 않는다. 오프라인 시간 정산은 없다.
- 진행 중인 공사는 저장된다. 취소하면 예약 재료를 전부 반환한다. 같은 공사 재요청, 중복 완료, 중복 환불은 거절한다.
- 창고/숙소 증축, 진료소/시장/대장간 건설은 기존 기능과 연결된다. 레벨·효과는 기존 거점 규칙을 그대로 사용한다.
- 청사진과 작업 진행 막대, 현장으로 이동하는 주민을 지도 위에 표시한다. 주요 시설은 지붕 대신 내부 가구가 보이는 탑뷰로 그린다.
- 두 손가락 핀치/트랙패드/마우스 휠로 1~3배 확대한다. 확대 후 한 손가락 드래그로 화면을 움직인다. 건설 배치 모드의 드래그는 건물 위치를 옮긴다.
- 카메라는 선택/공사 진행/시설 화면 재구성 사이에 유지한다.

## 재료 수집

- 기존 층별 물자 더미: 목재 3, 석재 3, 약초 2 단위. 인접한 안전한 위치에서 수집하며 시간과 운반 한도를 적용한다.
- 몬스터가 죽으면 사망 위치에 건설용 회수 물자 1개가 남는다. 고블린은 목재, 코볼트는 석재, 쥐는 약초. 나머지는 고정된 개체 ID에 따라 세 종류 중 하나다. MVP용 드롭 구성으로 후속 콘텐츠/밸런스 조정 대상이다.
- 화면을 열 때 무작위로 다시 뽑지 않는다. 원정 번호와 정식 사망 이벤트로 물자 ID를 결정하고 수집 이력을 차감한다.
- 전투 종료 후 전리품 창에서 일반 장비와 함께 선택한다. 층 전체가 아니라 **적 무리 하나를 전멸시켜도** 창을 연다. 적이 살아 있는 상태의 이탈은 원격 수집을 허용하지 않는다.
- 일반 가방 20칸과 별도로 기존 원정 물자 한도를 쓴다(창고 1/2/3단계: 8/12/18). 한도가 차면 남은 물자는 바닥에 남는다.
- 확보한 물자는 귀환 전까지 운반 물자이고, 귀환해야 창고 재고가 된다. 기존 건설·증축·교환과 같은 장부를 사용한다.

## 생존 파티 규칙

- 새 DUO 게임은 첫 전투 전부터 행동 가능한 파티원이 한 명이라도 있으면 진행한다. 전원이 사망/다운 상태일 때 패배한다.
- 주인공의 정체성·종족·장비를 동료에게 복사하지 않는다. 생존한 동료가 탐험 이동, 아이템 이용, 귀환, 다음 원정의 기준이 된다.
- 기존 성장·숙련 장부의 주인공 소유권은 바꾸지 않는다. 동료별 성장 장부를 통합하는 기능은 이번 수정과 별개다.
- 최신 개별 행동은 `individual_survival_step` 저널로 기록한다. 구 `individual_step`은 구 규칙으로 재생하여 예전 저장의 사건 결과를 변경하지 않는다. 초기 적용 여부는 별도 부트스트랩 태그로 구분한다.
- 명시한 집중공격은 두려움에 의한 후퇴보다 우선한다. 건강한 동료(HP 25% 초과)는 스트레스만으로 자동 후퇴하지 않는다. 직접 후퇴 지시, 저체력 자기보호, 기존 위험 자동 일시정지는 유지한다.

## 후속 확장 1 · 진료소 생산

- 진료소 완공 후 약초 2개로 기존 회복 물약 아이템 1개를 제조한다. 무료 시간 생산이 아니라 던전 재료를 소비하는 원정 준비 기능이다. 수치는 MVP 임시값이다.
- 진료소 선택 → `1개 제조` → 주민 접근 및 8 작업 단계 → 진료소에 완성품 보관 → `가방으로 1개` 순서다. 기존 0.5초 작업 시계를 사용한다.
- 건설/증축/제조가 작업 슬롯 하나를 공유한다. 반복 생산, 작업자 배정, 대기열은 아직 넣지 않는다. 취소하면 예약한 약초를 반환한다.
- 완성품은 원정 간 유지되는 거점 재고다. 최대 6개까지 보관하며 한도가 차면 새 제조 지시를 막는다. 가방이 꽉 차면 수령만 거절하며 물약은 사라지지 않는다.
- 지도에서 제조 중인 시설은 금색 테두리/진행 막대, 완성품이 있는 시설은 숫자 배지로 표시한다. 제조/수령 버튼은 기존 48px 터치 영역을 사용한다.
- `sim/base_production_rules.gd`는 조합법·완성품 재고 투영·표시 상태를 담당한다. `playtest/base_production_service.gd`는 제조 준비·완료·실제 아이템 수령 트랜잭션을 담당한다. 건설 서비스에는 생산 세부 규칙을 합치지 않는다.
- 저장은 기존 `base_work` 저널에 엄격한 `PRODUCE`/`CLAIM` 명령을 추가한다. 기존 건설 명령의 이벤트 형식과 비용은 변경하지 않는다.
- 검증: 실제 던전 약초 수집, 시설 필요 조건, 재료 예약·환불, 공유 작업 슬롯, 중간/완료 저장 재생, 실제 가방 수령, 가방 포화 시 원자적 거절, 중복 수령 거절, 원정 출발/귀환 사이 재고 보존 및 원격 수령 거절, 360px 버튼 입력. 휴대폰 실기기 검사는 별도다.

## 후속 확장 2 · 숙소 휴식

- 숙소 선택 → 주민별 긴장과 가장 큰 부정 감정 확인 → `휴식 · 15골드` → 선택한 주민이 문을 통해 침상으로 이동 → 10 휴식 단계 → 마음 회복.
- 건설/제조와 같은 단일 작업 슬롯, 0.5초 작업 단계를 사용한다. 던전 시간은 흐르지 않으며 원정 중/앱 비활성 중 작업은 멈춘다. 주민 배정표나 별도 휴식 관리 화면은 추가하지 않는다.
- 기존 신전 회복량을 그대로 사용한다: 숙소 수준별 긴장 감소 및 공포 300·분노 150·슬픔 120·죄책감 100 감소. 체력·절단된 신체는 회복하지 않는다.
- 이용 조건은 기존보다 넓혔다. 긴장이 0이어도 회복 가능한 부정 감정이 남으면 쉴 수 있다. 자연 감소를 반영한 감정과 긴장이 모두 0이면 지불을 막는다. 예상 감정 값도 실제 감정 모델의 자연 감소를 적용하여 계산한다.
- 휴식비는 지시 시 예약해서 다른 구매에 쓰이지 않는다. 취소 시 전액 반환. 완료 시 예약금을 해제하고 기존 `town.shrine_service` 비용·감정/사기 이벤트를 한 트랜잭션으로 처리하여 한 번만 청구한다.
- 새 DUO 화면의 기존 신전 경로도 숙소의 주민별 휴식 버튼으로 연결한다. 구 저장의 즉시 신전 명령은 재생 호환성을 위해 유지한다.
- `playtest/base_rest_service.gd`가 대상 평가·침상 경로·회복 처리를 담당한다. 공유 작업 서비스는 주문·예약·진행·취소만 연결한다. `PartyEmotionModel.town_rest_projection`은 변경 없는 예상치 조회다.
- 검증: 실제 전투·귀환 후 휴식, 예약 비용·취소 환불, 효과 선지급 금지, 중간/완료 저장 재생, 침상 도착, 감정 예상치와 실제 결과, 체력 회복 없음, 중복 완료 방지, 360px 휴식 버튼. 휴대폰 실기기 확인은 별도다.

## 모듈 경계

- `sim/base_work_rules.gd`: 작업 이력 투영, 작업자 경로, 명령 형식.
- `playtest/base_work_service.gd`: 건설/증축 주문·진행·취소의 원자적 처리와 저널.
- `playtest/base_work_clock.gd`: 거점 화면에서만 작업 진행 요청. 저장 상태의 권위는 갖지 않는다.
- `sim/base_monster_supply_rules.gd`: 사망 이력에 결합된 물자 더미.
- `playtest/base_resource_icon.gd`, `base_room_renderer.gd`, `base_map_camera.gd`: 자원 아이콘, 내부 시설 렌더링, 카메라.
- `sim/party_survival_rules.gd`: 불변 주인공 ID와 현재 조작 기준 분리, 전원 무력화 판정.

## 검증 및 범위

- 테스트: 실제 적 공격으로 주인공 사망 → 동료 전투 지속 → 적 무리 처치 → 물자 선택 → 입구 이동 → 귀환 → 다음 원정 → 저장/재생. 별도 분기에서 전원 무력화 패배 검증.
- 공사: 중간 저장/복원, 취소·재료 반환, 중복 주문 거절, 완공·기능 해금, 비용 1회 차감, 모바일 지도 확대.
- 기존 전투 예약/드래그/전리품/건물 배치 수락 테스트를 유지한다. GitHub Actions에 추가 테스트 작업은 넣지 않는다.
- 로컬 같은 던전 진입 조건(적 39마리)에서 약 5.4초 → 0.32초. 기존 전체 인벤토리 반복 복사/검증을 새 개체 전용 준비로 줄였고, 저장 입력과 최종 월드 검증은 유지한다. 휴대폰 실측은 아니다.
- 1층 여행자는 새 DUO 게임에서 생성하지 않는다. 구 저장의 여행자는 재생 호환성을 위해 유지한다.
