# 모바일 마을 UI 벤치마크와 적용

2026-09-09. 마을 메뉴 개선 요청에 따라 공식 소개·개발자 설명·공개 이미지를 확인했다.
원작 이미지 파일은 참고만 하며 프로젝트 에셋에 넣지 않는다.

Wartales의 [The Tavern Opens! 공식 소개](https://store.steampowered.com/app/2903960/Wartales/)도 검토했다.
탐험하면서 개인 여관을 확보·발전시키는 흐름은 관련 있지만, 경영 시스템 확대는 이번 UI 수정 범위에서 제외한다.

위 게임들의 효과를 사용자 테스트로 검증한 것은 아니다. 오른쪽 적용 열은
우리 게임의 모바일 크기·기존 기능에 맞춘 설계 판단이다. Darkest Dungeon은
허브 기능 구조 참고이며, 열어 본 홍보 포스터를 실제 UI 스크린샷으로 취급하지 않는다.

## 구현된 화면 구조

- 공통 상단: 마을·보유 금화, 인물 정보, 게임 메뉴.
- 광장: 지도 / 여관·시장·치유소·내 거점 / 출전 요약·장비 / 원정 준비.
- 여관: 모험가·탐험대·주민 필터, 선택 인물 한 명의 상세 카드, 제한된 높이의 명단 스크롤.
- 시장: 구입과 물자 판매를 탭으로 분리. 상품명과 재고, 금액이 있는 구매 버튼.
- 치유소: 대원 초상화·체력·치료 비용. 불가능한 행동의 이유를 화면에 표시.
- 장비: 대원 선택 후 해당 가방만 표시. 전달 대상은 선택 상자 하나로 지정.
- 거점 미소유: 구입 조건과 진행 수치를 별도 화면에만 표시. 구입 후 기존 건설 UI 연결.
- 원정 준비: 출전 대원·체력 확인, 편성 변경, 입구·활성 포탈 선택.
- 모든 서비스에서 같은 ‘마을’ 뒤로가기. 시설 전환 시 스크롤 초기화.
- 공공 보관소는 물자 판매, 개인 거점은 ‘내 거점’으로 분리. 영입 성공 시 탐험대 탭으로 이동.
- 청록색 이중 테두리 버튼을 줄이고 어두운 석재색/차분한 금색으로 선택·주 행동 구분.
- 새 일러스트를 생성하지 않고 기존 캐릭터 초상화와 코드 기반 시설 아이콘 사용.

## 검증 범위

`tests/town_navigation_acceptance.gd`는 320×640 / 360×800 / 430×932 화면에서
광장 출발 버튼 위치, 48 논리 픽셀 이상 바로가기, 포인터 클릭·서비스 이동·대화 상태 유지·실제 구매를 검사한다.
테스트는 Godot의 고정 450×800 스케일을 그대로 둔 채 물리 창 크기만 바꾸지 않고,
각 논리 뷰포트 크기를 명시해 좁은 레이아웃을 실제로 검사한다.
`tests/town_life_ui_smoke.gd`는 새 게임부터 원정 출발 및 NPC 상세 동작을 확인한다.
헤드리스 배치 검증은 휴대폰의 실제 시각적 품질·터치 감각 확인을 대신하지 않는다.
게임 규칙과 저장 형식, GitHub Actions는 변경하지 않는다.

로컬 Godot 4.6.2에서 위 두 검사가 PASS했다. 320×640의 출발 버튼 하단은
539px, 360×800에서는 699px로 확인했다. 헤드리스 검사이며 실제 폰 화면을
캡처하거나 폰에서 플레이한 결과로 주장하지 않는다.
