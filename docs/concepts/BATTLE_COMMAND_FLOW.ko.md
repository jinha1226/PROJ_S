# 전투 준비와 실시간 지휘

2026-09-08 구현.

- DUO 자동전투에 들어오면 첫 행동 전에 일시정지한다. 기존 탐험 줌을 보관하고 가로 11칸 시야로 확대한다(사용자가 이미 더 확대했다면 유지). 전투가 끝나면 기존 탐험 줌으로 복귀한다. 전투 중에도 핀치 확대/축소는 유지한다.
- `시작`으로 전투를 재개하고, 진행 중에는 같은 버튼을 `지휘`로 표시한다. 지휘 중 다시 `재개`한다. 기존 기술 선택 시 일시정지/이전 정지 상태 복원 규칙도 유지한다.
- 캐릭터/아군 초상화를 빈 타일로 드래그하면 해당 인물에게 이동 위치를 예약한다. 미리보기 타일과 확정 목적지를 표시한다. 정지 중에는 위치/시간이 바뀌지 않으며, 재개 후 각자의 실제 행동 순서와 지형 이동 비용에 따라 한 칸씩 이동한다.
- 도착한 인물은 위치를 유지하면서 이미 공격 가능한 적을 기본 공격한다. 길이 임시로 막히면 기다렸다가 다시 경로를 찾는다. 다른 인물에게 예약한 동일 위치, 벽, 현재 점유된 타일, 경로가 없는 목적지는 거절한다.
- 이미 예약한 기술은 해당 인물의 다음 행동에 우선 실행하고, 이후 위치 지시를 따른다. 위치 지시는 새 목적지로 교체하거나 기존 개인 지침/자율 버튼으로 해제할 수 있다.
- 맵 몬스터 또는 적 초상화 탭은 파티 전체 집중공격이다. 기존 개인 위치 지시는 해제한다. 스킬 대상 선택 중 탭은 해당 기술의 대상을 고르는 동작을 우선한다.
- 생존 파티원이 체력 25% 이하로 내려가면 현재 행동 직후 다음 행동을 실행하기 전에 자동 일시정지한다. 맵 빨간 원/느낌표, 아군 초상화 빨간 테두리, 위험 인물 이름을 표시한다. 위험 상태로 재개해도 반복해서 멈추지 않으며 35% 초과 회복 후 재무장한다. 이는 체력 경고이며, 고체력에서 발생하는 즉사 피해를 예측하거나 막는 기능은 아니다.

모듈:

- `playtest/battle_command_flow.gd`: 정지, 확대, 위험 알림. 정규 월드 상태를 변경하지 않는다.
- `sim/systems/battle_position_order.gd`: 이동 목적지 검증과 실제 행동 선택. 기존 경로 탐색/이동 규칙 재사용.
- `playtest/individual_battle_session.gd`: 인물별 위치 예약과 `reserve_move` 저널. 기존 저널은 그대로 재생하며 새 예약과 실행도 저장/재생한다.

검증: `tests/battle_command_flow_acceptance.gd`와 기존 초상화 드래그·스킬 탭·취소 테스트. 자동 일시정지/줌은 화면 정책이므로 저장된 전투를 열 때 다시 준비 상태로 시작한다.
