# 하단 초상화 타기팅

2026-09-08 구현 범위.

- 자동전투 중 사건 요약 칸을 적 초상화 줄로 전환한다. 아군 초상화/스킬 바로 위에 배치하며, 적이 많으면 가로로 스크롤한다.
- 아군 초상화 또는 맵 캐릭터에서 적 초상화/맵 적으로 드래그하면 해당 인물의 공격 지침을 지정한다.
- 스킬 버튼에서 적/아군 초상화 또는 맵 인물로 드래그하면 다음 개인 행동에 기술을 예약한다. 기존 스킬 탭 후 대상 탭도 유지한다.
- 호버는 표시만 변경한다. 맵의 같은 엔티티에 원과 화살표, 하단 초상화에 강조 테두리를 표시한다. 다른 초상화로 옮기면 즉시 전환한다.
- 실행 가능 여부는 기존 공용 전투 API로 평가한다. 불가능한 대상은 빨간 표시와 사유를 보여 주고, 손을 떼어도 예약/공격 지침을 생성하지 않는다. 확정 시 API가 다시 검증한다.
- 드래그 중 전투 시계를 보류하고 초상화 목록을 고정한다. 빈 곳 드롭, 취소 터치, 두 번째 손가락, Escape는 명령 없이 취소한다.
- 같은 대상 위의 연속 포인터 이동은 평가 결과를 재사용한다. 월드/단계/파티 리비전/시전자/기술/대상이 바뀌면 다시 평가한다.

검증: `tests/battle_portrait_target_acceptance.gd`의 360×640 실제 입력 테스트, 기존 모바일 조작 및 액티브 스킬 회귀 테스트.

별도 미완료 범위: 주인공 사망 후 생존 동료로 계속 진행하기. 이 변경은 여기 포함하지 않는다. 현재 원본 주인공 ID는 성장·저장 검증·이동·재집결·귀환의 기준으로 쓰인다. 인물의 정체성/장비/능력치를 바꾸지 않고 조작 대표만 분리하고, 생존 동료 승리 후 이동·전리품·귀환·저장 재생까지 검증해야 한다.
