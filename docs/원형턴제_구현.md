# 원형 턴제(자유 위치) 모드 — 적용 기록

원본 요청: `docs/prompts/추가_원형턴제_전투.txt`. 기존 격자 모드는 그대로 두고, 화면 오른쪽 카메라 버튼 아래 **▦ 격자 / ◯ 원형** 토글로 바꾼다(던전 안에서도 그 자리에서 전환, 선택은 localStorage `torch-mode`에 저장).

## 구조

| 파일 | 내용 |
| --- | --- |
| `js/data/free.js` | 수치: 이동 거리(주인공 5m, 무리·궁수 4m, 마법사·돌진형 3m), 몸 반지름, 근접 1.5m / 창 2.5m / 궁수 6m, 탐험 걷기 속도, 물 비용 ×1.5 |
| `js/core/space.js` | 연속 좌표 공간: 원형 충돌(벽을 따라 미끄러짐), 8방향 Dijkstra 이동 비용(모서리 못 자름·물 1.5배·다른 캐릭터가 막음) + 줄 당기기 경로, 원·띠 안의 칸 |
| `js/core/free.js` | 탐험 ↔ 전투, 발견/기습, 턴(내 턴 → 소환수 → 적마다 순서대로), 이동 예산, 기회 공격, 불·물·얼음 이동 효과, 밀치기, 예고(원·띠·조준선) |
| `js/core/free-ai.js` | 적 AI: 이동 범위 안 후보 칸을 점수로 골라 걷고 행동 하나(무리 = 둘러싸기, 궁수 = 거리 유지, 마법사 = 원 예고, 돌진형 = 띠 예고) |
| `js/render/free-view.js` | 분신 인형·남은 거리, 닿는 적 붉은 빛, 기회 공격 ⚠, 적 턴 카메라 추적, 전투 시작 연출 |
| `js/ui/free-input.js` | 플로팅 조이스틱(화면 아래쪽)·키보드, 탭 = 경로 걷기, 분신 → [이동], 적 탭 두 번 = 걸어가서 공격(예상 피해), 조준(분신 기준 사거리 원, 밖이면 이동 제안), 적 턴 두 번 탭 = 3배속 |

## 격자 규칙과 함께 쓰는 법

- 위치는 `e.px, e.py`(실수)와 `e.x, e.y`(= 반올림 칸)를 **둘 다** 갖는다. 지형·원소·영혼석·부상은 칸 단위 기존 함수를 그대로 쓰고, 거리·이동·충돌만 실수 좌표로 잰다.
- `G.free` = 이 모드인가, `G.fc` = 전투 상태(`null`이면 탐험). `act()`는 원형 모드에서 행동 하나를 쓰고(`spendAction`), 걷기·턴 끝은 `freeRun()`.
- 탐험 중 시간은 `FREE.envEvery`(1.4초)마다 `exploreTick`으로 흐른다(불 번짐·재사용 대기·회복).
- 격자로 돌아갈 때는 모두 칸 중심으로 옮기고, 한 칸에 둘이면 가까운 빈 칸으로 비킨다.

## 남은 것 / 다른 점

- 스킬·소모품의 효과 범위 미리보기는 격자 모드의 `previewFor`(칸 단위)를 그대로 쓴다. 분신 자리에서 쏠 때는 이동 후 실제 위치에서 다시 계산된다.
- 부채꼴(브레스) 예고를 쓰는 적은 아직 없다(장판 셰이더는 원·띠만).
- 확인: `node tests/free.mjs` (토글·연속 이동·발견/기습·이동 예산·걸어가서 공격·기회 공격·마법사 원 회피·분신 [이동]·턴 끝·스킬 조준·격자 복귀·무작위 진행 오류 0).
