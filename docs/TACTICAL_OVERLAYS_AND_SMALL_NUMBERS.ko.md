# 전술 타일 표시와 작은 전투 수치 제안

## 반영한 표시 변경

- 아이소매트릭 모드의 경로·이동 목적지·커서·스킬 범위·적 행동 예고는 실제 타일 투영에서 얻은 네 꼭짓점을 사용한다. 화면상의 사각형을 별도로 만들지 않는다.
- 타일 안쪽 8% 여백, 얇은 테두리, 낮은 채움 불투명도를 공통 적용한다.
- 이동 예고는 옅은 목적지 타일과 가는 화살표, 공격은 더 진한 목적지 타일과 작은 바닥 방향 교차 표식이다. 기존 예고 색상과 관측 조건을 유지한다.
- 경로는 완료하지 않은 타일만 옅게 표시하고 기존 중심선·방향 표시를 유지한다. 평면 뷰의 경로 표시는 그대로다.
- 전투 판정, 좌표, 시야, HP·MP·공격력 등의 실제 수치는 변경하지 않았다.

## 검증

- `godot --headless --path . --quit-after 3`: 종료 코드 0, 스크립트 오류 없음.
- `godot --headless --path . --script tests/tactical_overlay_regression.gd`: `TACTICAL OVERLAYS: 0 failures`.
- 회귀 검사는 2:1 마름모·실제 타일 꼭짓점과의 일치·경로의 공통 도형 사용·이동/공격 예고 노출·화면 밖 숨김·평면 뷰 호환 및 그리기 경로 실행을 확인한다.
- `git diff --check` 통과. 실제 모바일 화면의 가독성은 배포 후 확인이 필요하다.

## 수치 단순화 제안 — 미적용

작은 수치는 행동 예고를 보고 생존 가능한 타격 수를 계산하는 전투에 적합한 설계 방향이다. 다음은 확정된 밸런스가 아니라 출발점 제안이다.

- 플레이어 HP 12~20, 기본 피해 2~4, 약한 적의 피해 1~2.
- MP 6~10, 일반 사용 기술 비용 1~3. 화면에는 짧은 바와 정수 현재/최대값을 유지한다.
- 먼저 기존의 생존 타격 수·처치 타격 수·기술 사용 횟수를 기준으로 삼는다. 전체 숫자를 일괄 나누거나 표시만 축소하지 않는다.
- 방어의 피해 1 감소, 회복의 HP 1 증가, 독의 턴당 피해 1은 모두 큰 비중을 차지한다. 해당 효과와 다단 공격·회복 주기까지 함께 조정해야 한다.
- 작은 숫자에서 +1의 가치가 커지는 만큼 모든 성장을 피해 +1로 표현하지 않는다. 숙련·장비·변이의 차이를 범위·위치 변경·조건부 효과·자원 효율에도 배분한다.
- 명중·회피·막기 등 확률 규칙 변경은 별도 결정 사항이다. HP를 줄이는 것만으로 확정 결과형 전술 전투가 되지는 않는다.
