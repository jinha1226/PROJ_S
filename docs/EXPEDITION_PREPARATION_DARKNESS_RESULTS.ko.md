# 원정 준비·암흑 스트레스 구현 결과

## 구현 범위

- 원정 준비 화면의 물자 투영에 식량·치유 물약·횃불을 함께 표시한다.
- 실제 활성 대원의 배낭 소유권 원장에서 휴대 수량을 계산한다. 장비 슬롯은 배낭 아이템을 참조하므로 다시 더하지 않는다. 횃불은 보조 손 장착 여부를 별도로 표시한다.
- 물자 카드에 종류별 벡터 아이콘과 횃불의 장비·점화 안내를 추가했다.
- 암흑 노출을 `darkness.exposure_changed` 이벤트로 기록한다. 어두운 상태에서는 노출이 누적되고, 광원이 있으면 감소한다.
- 노출 300 시간 단위의 유예 구간 뒤 종족별 저항값을 적용해 `party.morale_changed`의 `DARKNESS` 원인으로 스트레스를 반영한다.
- 일반 턴, 액티브 스킬, 파티 턴, 필드 턴의 시간 경계에서 동일한 규칙을 실행한다.
- 세션 상태·파티 카드에 노출량, 심부 암흑 여부, 조도, 유예 잔여량을 노출한다.

## 최초 구현 검증 (v1)

`tests/run_darkness_stage5.gd`에서 다음을 확인했다.

- 어두운 고정 시나리오에서 4회 시간 경과 후 노출량 400과 사기 스트레스가 발생한다.
- 횃불 점화 후 공유 조도가 밝음 기준을 넘고 심부 암흑이 해제되며, 이후 노출이 더 누적되지 않는다.
- 암흑 이벤트 체인과 사기 이벤트가 세계 기록 검증을 통과한다.
- 시뮬레이터 스냅샷 복원 후 암흑 상태가 동일하다.

기존 환경·시야 회귀군은 새 규칙 추가로 인한 파서 오류 없이 실행되며, 전체 회귀 실행은 장시간 테스트 묶음에서 제한 시간에 도달해 결과를 별도로 기록하지 않았다. 전용 암흑 회귀는 2/2 통과했다.

## 검토 후 보완 (2026-09-10, v2)

검토 기준: `be8c8a7`. 길드·아이템의 동시 작업과 분리한 암흑 보완이다.

### 수정 사항

1. **전투 사기 중복 반영 제거.** 행동/스케줄별로 처리한 피해·사망 이벤트를 최종 암흑 경계에서 다시 전달하지 않는다. 최종 경계는 스트레스를 발생시킨 새 암흑 이벤트만 사기에 전달한다.
2. **실제 원정에 조도 연결.** 마을과 1층은 900(밝음), 2층은 400(어스름), 3층부터 120(심부 암흑)이다. 초기 튜닝값이며 `vision_rules.gd`에서 관리한다. 명시적 시야 테스트 맵은 자체 조도를 유지한다. 고정 광원과 횃불 광원도 함께 유지한다.
3. **장착 횃불 중복 집계 제거.** 배낭에 보관된 소유권과 장비 슬롯 참조를 두 개의 물건으로 계산하지 않는다.
4. **노출 상한 이후에도 스트레스 유지.** 노출 표시 상한 2000에 도달해도 추가 암흑 체류 시간에 비례해 스트레스가 발생한다. 정수 나머지를 보존해 같은 시간이 여러 행동으로 나뉘어도 반올림 오차가 누적되지 않는다.
5. **행동 내부의 조도 변화 반영.** 이동/환경/스케줄 경계마다 이전 조도의 경과 시간을 먼저 적분하고 새 조도를 기록한다. 한 행동 도중 횃불 연료가 끝나면 밝은 구간과 어두운 구간을 분리한다. canonical 암흑 이벤트는 최종 턴 경계에서만 생성한다.
6. **반복 전체 기록 탐색 제거.** 캐릭터별 최신 암흑 이벤트와 규칙 활성 여부를 파생 인덱스로 조회한다. 추가 이벤트만 읽으며, 기록 축소/복원 시 재구성한다. 인덱스는 저장 상태의 권위가 아니다.
7. **암흑 대기로 스트레스 상쇄되는 문제 제거.** 암흑 저항이 100%가 아닌 캐릭터는 심부 암흑에서 일반 안전 회복을 받지 않는다. 암흑 전용 사기 배치도 동료에게 추가 안전 회복을 주지 않는다. 밝은 곳의 기존 회복은 유지한다.

### 저장 호환성

- `darkness.rules_activated` / `darkness-stress-v2` 이벤트와 `darkness_rules` 저널 행으로 버전 경계를 명시한다.
- Living 원정의 **성공한 출발 직후** 활성화한다. 새 게임 부트스트랩은 빈 저널을 유지하므로 여관 생활 시작을 막지 않는다.
- 기존 저장을 로드할 때 과거 명령은 v1로 그대로 재현한다. 기존 원정 중 저장은 귀환 후 다음 출발부터 v2로 전환한다. 로드만으로 과거 결과를 변경하지 않는다.
- 물약 등 중첩 트랜잭션 내부에서는 버전 전환을 하지 않는다. 소모/회복/시간 진행 실패 시 기존 rollback 계약을 유지한다.
- v2 기록은 노출·나머지 연쇄, 구간 시간 합, 조도 범위, 저항값, 재계산 스트레스 일치를 검증한다.

### 보완 검증

Godot 4.6.2 headless에서 실행한다.

| 실행 파일 | 확인 범위 | 결과 |
|---|---|---|
| `tests/run_darkness_compatibility.gd` | 기존 종족 시야·가림·횃불 연료/저장·모바일 V 버튼·v1 암흑 | 12/12 통과 |
| `tests/run_darkness_v2_regression.gd` | 시간 분할 불변성, 상한 이후 스트레스, 면역, 안전 회복, 기록 변조 거부, 횃불 만료 구간, 중간 조도 변경, 인덱스 rollback, 수량, 실제 전투 사기 중복, v1/v2 저장 재현 | 통과 |
| `tests/run_darkness_living_regression.gd` | 새 게임 여관 시작, 기존 마을 저장 복원, 출발 시 명시적 v2 전환, 전환 저널 재현 | 통과 |
| `tests/potion_latency_death_layout_regression.gd -- --living` | 실제 마을/원정, 물약 소모·회복·실패 rollback, 저장 재현, 사망/완료 화면 크기 | 통과 |

물약 회귀의 이 실행에서 사용 처리 약 107ms(이벤트 302개)를 관측했다. 단일 데스크톱 headless 측정이며 모바일 성능이나 장기 원정 성능을 보장하는 수치는 아니다. 전체 테스트 모음을 통과했다고 주장하지 않는다.

## 남은 제품 검증

- 실제 모바일 빌드에서 원정 준비 카드와 횃불 아이콘의 크기·가독성을 확인해야 한다.
- 암흑 스트레스 수치와 회복 곡선은 플레이테스트 데이터를 모은 뒤 밸런스 조정한다.
