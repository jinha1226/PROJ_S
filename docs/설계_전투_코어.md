# 설계: 실시간 전투 코어

`docs/설계_실시간_전환.md`의 2·3·4단계(자동 공격·적 AI·예고, 상태이상·원소 초 단위, 격자 코드 정리)를 **새 전투 코어**로 한 번에 한다. 1단계(시간·입력·이동·탐험)는 이미 들어가 있다.

## 0. 왜, 무엇을 지키나

- 지금 전투는 속이 턴제다. 0.3초마다 옛 `endTurn`이 돌며 모든 적이 **같은 박자에 한 칸씩** 움직이고, 박자가 오면 **바로** 친다. 예고·힘 모으기가 사실상 없어 피할 수 없고, 전투가 1.9초 만에 끝난다.
- 처음부터 다시 만든 시도(Codex, 되돌림 `388d8b3`)는 조작감·그래픽·콘텐츠·완성도 모두 나빠졌다. 그래서 이번에는 **전투 규칙만 갈아 끼우고 나머지는 그 자리에 둔다.**
- 지키는 것: 통통 걸음·보간(`953ce61`), 디오라마 그래픽·인형, HUD, 정착지, 장비(DCSS식), 이야기, 데이터 표, 지도 생성, 원소 반응 규칙.

## 1. 성공 기준

1. 적도 연속 좌표로 부드럽게 움직이고, **적마다 자기 박자**가 있다(한꺼번에 움직이지 않는다).
2. 모든 적 공격은 보고 피할 수 있다: 근접은 힘 모으기 0.35초, 주문·화살·돌진은 바닥 예고.
3. 무기 12종이 `설계_실시간_전환.md` §4 표의 모양·범위·박자대로 친다.
4. 상태이상은 초 단위, 원소 환경은 1초마다.
5. 측정 봇: 일반 전투 5~15초·최대 HP 15~35% 손실, 족장전 30~60초·50~90% 손실.
6. 기존 테스트(smoke·items·story·settlement)가 통과하고, 폰에서 걷는 느낌은 지금과 같다(이동 속도만 빨라짐).

## 2. 구조

- **세계 상태는 지금의 `G`를 그대로 쓴다.** 지도·존재(`G.ents`)·아이템·장비·횃불이 모두 `G`에 있다. 이것을 새로 짜지 않는다.
- 새 전투 코어는 `js/sim/`. DOM·THREE·`window`·`Math.random`·`Date`를 쓰지 않는다(난수는 `util/rng.js`). Node에서 바로 불러 테스트한다.

| 파일 | 하는 일 |
|---|---|
| `sim/tick.js` | 한 틱(1/20초)의 순서: 입력 → 두뇌 → 이동·충돌 → 행동 → 투사체 → 예고 → 상태이상(1초마다) → 환경 `envTick`(1초마다) → 걸음 경제(횃불·회복·떠도는 무리, 걸은 거리 기준) |
| `sim/body.js` | 모든 유닛: `px, py`(소수 위치), `x, y`(발밑 칸 = 반올림), 반지름, 속도, 바라보는 각도. 지금 `core/space.js`의 충돌(`sweep`)·길찾기를 모든 유닛에 쓴다 |
| `sim/action.js` | 행동 하나 = **힘 모으기 → 타격 → 경직**. 등불지기 자동 공격·적 공격·주문이 같은 함수를 쓴다. 대상이 힘 모으기 동안 닿는 거리 + 0.3 밖으로 빠지면 헛친다 |
| `sim/shapes.js` | 판정 모양: 앞(±35°), 부채꼴(±60°), 반달(180°), 직선(폭 0.5), 원, 띠 |
| `sim/projectile.js` | 화살·석궁·투석·부메랑: 틱마다 나는 실체. 벽에 막히고, 꿰뚫음·왕복 |
| `sim/telegraph.js` | 예고 목록 `G.teles`(모양·중심·방향·크기·남은 시간·총 시간·원소). 번개가 물을 타고 번질 칸도 예고에 담는다 |
| `sim/brains/` | 원형: `melee`(쫓아와 에워쌈), `ranged`(거리 유지·조준선·붙으면 도망), `caster`(원 예고 → 원소 주문), `charger`(돌진 띠 → 끝까지 돌진, 벽에 박히면 기절), `healer`(다친 동료 치유), `lurker`(물속에 숨음) + 보스 넷의 고유 기믹, `ally`(구한 주민 따라오기) |
| `sim/status.js` | 상태이상을 초 단위로: 출혈·중독·화상은 1초마다 피해, 빙결·기절·골절·젖음·두려움·가속은 지속 초 |
| `sim/damage.js` | 피해 계산 한 곳 `dealDamage(src, dst, packet)`: 명중 → 회피·막기 → 기본 → 더하기 → 곱하기 → 약점·부상 → 방어·저항 → 보호막 → HP. 치명 조건·색 배율 없음 |

- 모든 유닛은 같은 모양이다: `team`(`party` · `foe` · `neutral`), `ctrl`(`player` · `ai`), `brain`, `act`(진행 중인 행동), `cd`(쿨타임 초). 등불지기는 `ctrl: 'player'`인 유닛일 뿐이고, 나중에 동료는 `team: 'party', ctrl: 'ai'`로 붙는다.
- 순서가 정해진 결정적 시뮬레이션: 같은 씨앗·같은 입력이면 같은 결과.
- 사건(`emit`)은 **그 틱에 바로** 화면으로 간다. 로직은 연출을 기다리지 않는다.

### 지우고 끄는 것

- 지움: 0.3초 턴 루프(`endTurn`/`worldTick` 호출), 적 칸 걸음(`stepToward`·`stepEnt`·`enemyAct`), 연출 대기열(`TL`·`Anim`·`atkGate`), 치명 조건 11가지와 미리보기, `act()`의 턴 의미(즉시 실행 함수로 남긴다).
- 계속 끔: 영혼석(파일은 남기되 불러오지 않는다).
- 옛 `core/combat.js`·`core/ai.js`에서 쓸 것(밀치기·문·구출·전리품·죽음 처리·원소 호출)은 새 코어로 옮기고, 나머지는 지운다.

## 4. "대기" 장비

대기 행동이 없어져 발동할 길을 잃은 효과를 **제자리에서 시간을 흘릴 때(⏳ 누르고 있기·Space)** 로 바꾼다.

- 기다림 망토: 제자리에서 1초 흘릴 때마다 보호막 +2(최대는 지금 규칙대로).
- 물안개 망토: 제자리에서 1초 흘릴 때마다 주변 1칸이 젖는다.
- 고요 목걸이: 들키기 전에 제자리에서 흘리는 동안 적이 알아채지 못한다.

## 5. 화면 (최소 변경)

- 적 인형도 등불지기처럼 매 프레임 틱 사이를 보간해 세운다(통통 걸음·발밑 고리 같이 쓴다). 칸 트윈(`move` 사건)은 순간이동·밀치기에만 쓴다.
- 새로 그리는 것: 바닥에 차오르는 예고(레이드 실험실 E 그림을 옮긴다), 적 힘 모으기 표시(몸을 뒤로 젖히며 빛남), 무기 모양 궤적.
- 나머지(HUD·창·정착지 화면)는 그대로.

## 6. 테스트

- 새 `tests/sim/*.test.mjs`(`node --test`, 브라우저 없이, 씨앗 고정, 틱 단위):
  1. 흐르지 않으면 100틱을 돌려도 아무것도 변하지 않는다.
  2. 적 여럿이 각자 다른 박자로 행동한다.
  3. 장검은 앞 ±35° 1.6 안만, 대검 반달은 뒤를 못 친다, 창은 줄지은 적을 꿰뚫는다.
  4. 힘 모으기 중 빠지면 헛치고, 가만히 있으면 맞는다.
  5. 마법사 원 예고 1.2초 뒤 터지고, 밖에 있으면 피해 0. 젖은 무리는 번개가 번진다.
  6. 돌진 띠 1초 뒤 돌진, 비키면 벽에 박혀 기절.
  7. 출혈 3이 1초마다 1씩 3초. 빙결 동안 행동 없음.
  8. 전투 중 자동 회복 없음, 전투 뒤 회복.
  9. 같은 씨앗·같은 입력 두 번 → 같은 상태.
- 측정: `tools/arena.mjs`(Node)로 층별 표준 무리(고블린 3 + 주술사, 쥐 3, 마법사 1, 족장)를 봇으로 20번씩 싸워 전투 시간·손실을 출력한다.
- 기존 playwright 스위트: smoke·items·story·settlement 통과. `realtime.mjs`는 새 규칙에 맞게 고친다. `dungeon.mjs`는 새 코어 기준으로 다시 써서 `test:all`에 되돌린다. `stones.mjs`는 계속 뺀다.
