# Legacy 사용 기반 숙련 구현

기준: `d685c33` (Model B 도입 직전). 브랜치: `feat/legacy-use-based-skills`.

ChatGPT `model-b-skill-rework` 설계의 사용 기반 숙련을 legacy에 구현한다. 기존 신체, 동료, 흡수 능력, 맵, 저장 및 행동 비용을 보존한다. 기존 저장은 기존 규칙으로 유지하고 새 게임에 새 규칙을 적용한다.

숙련은 커밋된 전투 이벤트에서 재구성한다. 미리보기, 실패, 취소, 대기, 처치 XP는 숙련을 만들지 않는다. 동일 상대 반복 사용에 상한을 적용한다. 무기 다섯 계열, 마법 다섯 학파, 방어 세 계열과 기존 맨손 호환성을 표시한다. 기존 능력을 학파에 연결하며 새 주문이나 융합 효과는 추가하지 않는다.

검증: 실제 Session 행동 순서, 무효 입력 원자성, 숙련 전후 전투 검증, 저장 복원, 기존 field 회귀, 런타임 UI 확인. 지원되지 않는 설계 항목은 결과 문서에 명시한다.
