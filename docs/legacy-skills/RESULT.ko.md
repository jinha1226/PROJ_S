# Legacy 사용 기반 숙련 이식 결과

기준 버전: `d685c33`, Model B 도입 직전 legacy. 작업 브랜치: `feat/legacy-use-based-skills`.

사용자의 요청으로 현재 변경을 커밋하고 작업 브랜치를 푸시한다. main 병합 또는 배포는 수행하지 않는다.

## 구현

- 새 원정에서 사용 기반 성장 적용. 기존 저장은 기존 규칙 유지.
- 검·창·둔기·도끼·활, 화염·냉기·대기·주술·소환, 갑옷·회피·은신 표시. 기존 맨손 호환성 유지.
- 커밋된 공격·시전 및 실제 위험 상황의 이벤트에서 숙련 복원. 무효 입력·미리보기·안전한 대기는 숙련을 지급하지 않음.
- 같은 상대와 계열에서 성장 기회 3회 상한. 성장 곡선은 `10*r*(r+1)`.
- 처치 XP는 캐릭터 성장에 유지하며 새 규칙에서 무기 숙련 배분을 중단.
- 무기 피해, 지정된 기존 마법 효과량, 회피, 장비 회피 페널티 완화, 탐지 억제에 연결.
- 전사·궁수·마법사 시작 선택. 기존 장비·화염탄 사용. 직업 레벨이나 전용 성장 트리 없음.
- 저장된 초기 규칙과 직업을 journal replay에 연결. 과거 공격은 당시 숙련으로 검증.

## 확인한 결과

- `legacy_usage_skills_acceptance.gd`: 3개 seed, 197개 검사, 실패 0. 이동→공격/시전→숙련→저장→복원과 UI 표시 검증.
- `compact_campaign_save_smoke.gd`: 기존 두 맵 형식 저장 복원, 실패 0.
- `git diff --check`: 통과.

## 미확인 및 제한

- 실제 GUI 검증 실행 승인은 사용자에 의해 중단됨. `legacy_usage_skills_gui.gd`는 실행 확인 전이다.
- 기존 `field_turn_ui_acceptance.gd`의 대기 버튼 한 턴 검사 실패. 변경 전 기준 버전과 비교는 완료하지 못했으며 기존 문제라고 단정하지 않는다.
- legacy에 소환 능력이 없어 소환 숙련은 성장 입력이 없는 상태로 표시한다. 새 주문을 추가하지 않았다.
- 갑옷의 현재 장비 회피 페널티를 완화한다. 별도의 새로운 encumbrance 시스템은 만들지 않았다.
- 12개 Model B 주문을 이식하지 않았다. legacy의 기존 흡수 능력과 마법을 학파에 연결했다.
- 동료의 기존 성장 규칙은 유지한다. 사용 기반 규칙은 주인공에 적용한다.
- 모든 능력·장비 조합이나 모바일 터치 전체를 검증한 완성판으로 주장하지 않는다.

## 직접 확인

새 원정에서 시작 직업을 선택하고 스킬 탭을 확인한다. 다른 무기를 장착해 공격하고 해당 숙련이 증가하는지 확인한다. 마법사의 화염탄을 시전한 뒤 위치·MP·턴을 확인한다. 빈 칸 미리보기나 무효 대상을 반복해 숙련이 증가하지 않는지 확인한다. 저장하고 다시 불러온 뒤 숙련과 기존 신체·흡수 능력 상태를 확인한다.
