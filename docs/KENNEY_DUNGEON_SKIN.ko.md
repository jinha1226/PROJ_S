# Kenney 무료 에셋 적용

2026-09-12. Kenney Tiny Dungeon 1.0 (CC0), 원본 atlas 192×176 / 16px 132칸.
출처·원본 archive hash·라이선스는 `assets/kenney/tiny-dungeon/`에 동봉했다.

## 실제 연결

- 메인 던전 바닥·벽·문·계단·횃불·전리품, 캐릭터·몬스터, 초상화, 인벤토리 아이콘.
- 공통 `kenney_dungeon_assets.gd`가 atlas 영역을 한 번 만들고 재사용한다.
- 장착 무기·방패·횃불은 기존 장비 authority의 `equipment_visual`을 통해 갱신한다.
  상태 상세/파티 카드에도 같은 DTO를 제공한다. 무기는 손 옆에 별도 작은 이미지로 겹친다.
- 인간 NPC는 entity ID에 따라 팩의 인물 이미지 중 하나를 안정적으로 사용한다.
- 마을 건물은 같은 팩의 시설 기호로 표시한다. 기존 큰 건물 일러스트는 표시하지 않는다.
- 옛 원본 이미지 파일은 삭제하지 않았다. 활성 에셋 facade의 옛 preload는 제거했다.
- HUD 배치, 게임 수치, 이동·공격 규칙, 아이템 종류, 종족 능력은 변경하지 않았다.
- 기존 retained terrain chunk 캐시는 유지하며 물 tint도 캐시 무효화 조건에 포함한다.
- 바닥 아이템에 정의별 아이콘이 있으면 공통 전리품 표시보다 우선한다.

## 팩에 없는 내용 — 임시 대응을 명시

- 8방향/걷기 애니메이션 없음: 고정 자세로 이동한다. 논리적 방향과 이동 보간은 유지.
- 종족 전용 원화 없음: 엘프·수인·코볼트 등 일부는 가까운 팩 캐릭터를 임시 대응.
  에셋이 게임 종족을 정확히 묘사한다는 뜻이 아니다.
- 방어구별 몸통 착용 레이어 없음: 장비 효과/슬롯은 유지하지만 몸통 그림은 바뀌지 않는다.
- 창·석궁·스크롤·재료 등 정확한 그림이 없는 품목은 같은 팩의 기호를 공유한다.
  활/석궁은 같은 아이콘이며 상세 이름으로 구분한다. 식량은 버섯 기호이다.
- 모닥불은 횃불 기호, 마을 건물은 시설 기호로 임시 표시한다.
- 물은 팩 바닥에 청색 tint를 적용한다. 혈흔·연기·얼음 등의 게임 효과는
  기존 생성 이미지 대신 같은 팔레트의 단순한 픽셀 도형으로 구분한다.

  과거 시각 golden 검사는 이번 16px 스킨의 기준으로 사용하지 않았다.
