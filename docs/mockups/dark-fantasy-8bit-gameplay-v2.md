# 8비트 던전 게임플레이 목업 v2

캐릭터·타일·오브젝트를 모두 논리 32px 픽셀 클러스터로 통일한 모바일 게임플레이 목업이다. 실제 런타임 화면이 아니라 아트 방향과 배치 검토용이다.

- 이미지: `dark-fantasy-8bit-gameplay-v2.png`
- 구성: 상단 미니맵/HUD, 석조 던전과 캐릭터·몬스터·오브젝트, 전투 로그, 캐릭터 카드, 아이템 슬롯, 하단 행동 버튼.
- 한국어 표기는 `1층 · 잊힌 회랑`, `식량`, `횃불`, `공격`, `대기`, `자동탐험`, `전술`, `가방`을 사용했다.
- 기존 `dark-fantasy-32px-v1.png`, `dark-masonry-tiles-v1-game.png`, `dark-fantasy-characters-v1.png`, `assets/topdown/environment-v1/objects.png`를 시각 참조로 사용했다.
- 실제 UI·게임 로직·런타임 에셋은 변경하지 않았다.

생성 프롬프트는 `dark-fantasy-8bit-gameplay-v2-prompts.json`에 보관한다.
