## 공통 규칙

- 세로 화면 853×1844 기준. 작은 글씨보다 아이콘·수치·짧은 버튼명을 우선한다.
- 검은 석재 바탕, 낮은 채도의 황동 테두리, 선택된 요소에만 밝은 금색을 쓴다. HP는 빨강, MP는 파랑, 스트레스는 황색으로 구분한다.
- 상단 HUD의 위치를 바꾸지 않는다. 왼쪽 미니맵, 가운데 `n층 / 지역명`, 오른쪽 식량 수와 메뉴 순서다.
- 설명문·튜토리얼 문장·획득 팝업을 화면의 주 정보로 쓰지 않는다. 사건은 짧은 로그에 남긴다.
- 메뉴와 NPC 팝업은 탐험 화면 위에 작게 얹는다. 다른 선택형 팝업(계단, 조사물, 적 정보)도 같은 외곽선과 버튼 규격을 따른다.
- 이미지의 장비명·주문명·능력치·로그는 생성된 예시다. 구현 시 현재 카탈로그와 실제 세션 상태를 표시해야 한다.

## 제작 기준

기존 [수동 로그라이크 탐험 목업](../manual-roguelike-ui-v1.png)을 이미지 생성의 스타일 참조로 사용했다. 최종 생성 지시는 “기존 다크 픽셀아트 탐험 화면의 석재·황동·한글 UI 스타일을 유지하고, 상단 HUD를 미니맵/현재 위치/식량·메뉴로 재배치한다. 같은 비율과 시각적 언어로 상태·성격·기억·숙련·파츠·가방·전술·시작·야영·지도·기록·메뉴·NPC 팝업을 만든다. 짧은 게임 라벨만 쓰고 설명문은 넣지 않는다”였다. 기존 화면 편집과 신규 화면 생성을 함께 사용했다.
