# 휴식·섭취 반응성과 물분사

## 동작

- 휴식: 턴 사이 표시 대기를 90ms → 30ms로 줄인다. 턴 비용, 회복량,
  적 발견·피해·회복 완료 시 중단은 변경하지 않는다. 실제 속도는 처리 시간에 좌우된다.
- 특수부위 섭취: 전체 저장 스냅샷 대신 기존 아이템 처리와 동일한 복구용 메모리를
  사용한다. 중복된 사전 전체 검사를 제거하고 최종 상태 검사 및 실패 시 복구를 유지한다.
- 초상화: 평온 표시 자리에 `화상 3턴`, `오한 2턴` 등 효과와 남은 턴을 표시한다.
  해로운 효과는 붉은색, 만료 시 기본 상태로 복귀한다. 여러 효과는 툴팁에서도 확인한다.
- 물분사: 사거리 4칸의 보이는 빈 바닥에 시전 가능하다. MP 2, 물 공급 80 및
  환경 상호작용은 기존 수치를 사용한다. 벽·범위 밖·잘못된 칸에는 시전하지 않는다.
- 젖은 일반 바닥/돌바닥: 보이는 동안 물 타일 에셋을 사용한다. 원래 지형을
  덮어쓰지 않으므로 마르면 기존 바닥으로 돌아온다. 계단·문 등 표식과 얼음은 보존하며
  시야 밖 기억 타일에 현재 물 상태를 노출하지 않는다.
- 기존 적 대상 물분사 명령과 이벤트는 그대로 읽고 실행해 저장/AI 호환성을 유지한다.

## 확인

- `five_button_pickup_acceptance`: PASS — 현재 공용 휴식/대기 버튼 경로.
- `corpse_parts_growth_acceptance`: PASS — 섭취, 디버프, 만료, 저장/복원.
- `elemental_parts_acceptance`: PASS — 기존 적 대상 원소 기술/AI.
- `rest_parts_water_acceptance`: PASS — 화상 HUD·만료, 중복 섭취 거절,
  빈 바닥 물분사, 잘못된 시전의 무소모, 젖음 저장/복원, 물 타일·건조·기억·얼음.
- 오래된 `rest_and_pickup_regression`은 별도 휴식 버튼을 기대해 실패하여 중단했다.
  지금은 휴식/대기가 하나의 버튼이다. 이 변경에서 오래된 전투/마을 fixture는 수정하지 않았다.

`godot --headless --path . --script tools/benchmark_part_ingestion.gd`로
2caec2d의 전체 스냅샷 경로와 변경 경로를 비교한다. 동일 초기 상태 1회 로컬 측정:
194.149ms → 76.105ms. 전체 UI나 모바일 실기기 벤치마크는 아니며, 실행 이력과
기기에 따라 달라진다. CI 합격 기준으로 시간 임계값을 사용하지 않는다.

실제 화면 캡처는 `rest_parts_water_acceptance.gd`를 GUI 모드로 실행하면
`/tmp/ingestion-hud.png`, `/tmp/water-spray-floor.png`에 출력한다.
