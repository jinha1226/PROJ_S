# 영혼석 획득 카드

몬스터·보스·상자 등의 영혼석 보상은 기존 드롭 확률과 부위 판정을 유지한다. 획득 로그를 남긴 뒤 현재 행동과 전투 연출을 끝내고 카드를 띄운다. 여러 개면 획득 순서대로 한 장씩 선택한다.

- 카드: 영혼석 이름, 아이콘, 현재 전투 규칙의 보상 능력치와 효과.
- 인물별: 이름, 열린 슬롯 사용량, 현재 조합과의 연계, 흡수 버튼. 빈 슬롯 없음·이미 흡수함·쓰러짐은 선택 불가.
- 흡수: 선택한 주인공 또는 동료의 빈 슬롯에 즉시 영구 흡수. 이번 카드의 영혼석만 전투 중에도 허용하며, 가방의 일반 흡수는 기존 안전 구역 조건을 유지한다.
- 가방에 보관: 이번 보상을 가방에 남긴다. 카드 바깥 터치나 Escape로 닫아도 보관한다.
- 두고 가기: 이번 보상 한 개만 버린다. 같은 영혼석의 기존 가방 재고는 유지한다.

선택 중에는 자동탐험·장거리 이동·새 행동을 멈춘다. 이미 실행한 행동의 동료·몬스터 턴은 끝까지 처리한다. 감정·강화 선택, NPC 제안, 보스 배너는 먼저 마치며 카드 대기열은 보존한다. 다른 화면이나 세션으로 바뀌면 오래된 버튼은 새 보상을 소비할 수 없다.

공격·대기 규칙에서는 실제 효과 데이터의 상태 부여와 조건을 연결해 `연계 가능`, `준비 필요`, `연계 보완`, `효과 중복`, `독립 효과`로 표시한다. 화상→폭발, 둔화→빙결→파쇄, 젖음+직접 전기 피해, 축복, 소환수, 조준과 원거리 무기를 고려한다. 조건부 부여 효과 자체에도 선행 조건이 필요하며 봉인된 영혼석은 제외한다. 이는 현재 조합의 발동 가능성 안내이며 적 상태·지형·명중률까지 반영한 성능 점수가 아니다.

기존 전투 규칙에서는 실제 역할·원소 세트 단계가 오르면 `조합 강화`, 그 외에는 `같은 계열` 또는 `새 계열`로 표시한다. 공격·대기 규칙의 연쇄 효과를 기존 원정에 있는 것처럼 표시하지 않는다.

게임 UI가 있는 세션만 카드를 사용한다. 자동 밸런스 시뮬레이션은 기존 가방 지급 방식으로 진행한다. 검증은 `tests/stone_drop.gd`, `tests/stone_drop_ui.gd`에 있고 CI에 포함한다.
