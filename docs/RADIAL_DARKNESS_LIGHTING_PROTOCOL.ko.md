# 연속 원형 암흑·횃불 조명 protocol

- 작업 ID: `RADIAL-DARKNESS-001`
- 기준 commit: `bd604c5`
- 질문: 기존 타일 기반 시야 권위를 유지하면서 화면의 암흑을 캐릭터 중심의 연속 원형 감쇠로 표현할 수 있는가?

## 시각 계약

- 캐릭터 중심에서 멀어질수록 암흑이 연속적으로 증가한다. 한 타일 전체가 같은 명암으로 갑자기 바뀌는 표현을 사용하지 않는다.
- 점화된 휴대 횃불은 캐릭터 중심의 둥근 광원으로 표시하며 중심은 밝고 가장자리로 갈수록 부드럽게 감쇠한다.
- 광원은 현재 `VISIBLE` 셀 안에서만 밝힘 효과를 내므로 벽과 LOS 뒤의 `MEMORY`·`UNSEEN` 정보는 밝히지 않는다.
- 지형, 액터, 아이템의 권위 시야 및 입력 가능 여부는 변경하지 않는다.
- 층별 조도는 원형 암흑의 강도와 무횃불 감쇠 반경에 반영한다.
- 선택·위험·체력 등 의사결정용 HUD 표식은 암흑 위에 그려 가독성을 유지한다.

## 구현·검증 범위

- 화면 타일을 더 작은 투영 조각으로 나눠 연속 거리 함수를 샘플링한다. 별도 상태·저장 필드는 추가하지 않는다.
- 기존 휴대 횃불의 딱 잘리는 두 원 표현을 연속 감쇠 표현으로 교체한다.
- 중심→중간→가장자리 암흑의 단조 증가, 횃불 점화 시 밝은 중심과 넓어진 반경, `MEMORY`·`UNSEEN` 비조명, 360/450 화면 범위를 검증한다.
- Godot import, 관련 시각 smoke, 제품 시작 smoke를 실행한 뒤 추가 밸런스 변경 없이 종료한다.
