# 장비 시스템 설계 (DCSS식)

상태: ✅ 구현됨 (388182ad, §20 적용 기록). 지금 게임의 장비 규칙

작성일: 2026-09-29 · 대상: `js/` 모듈
디아블로식(84a14403)을 대체했다. 이전 문서: `설계_아이템_장비_디아블로(폐기).md`. 데드셀식 무기 색 제안: `설계_아이템_장비_데드셀안.md`(미결정).
**이미 만들어진 아이템 창(장비 칸, 장착·해제, 비교, 인형 외형 변화)은 그대로 살리고**, 그 안에 들어가는 아이템의 종류와 규칙을 DCSS식으로 바꾼다.

## 0. 플레이어가 느껴야 할 것

- 장비는 자주 떨어지지 않는다. 대신 **하나하나가 판단거리**다.
- 미확인 장비를 **입어볼까, 두루마리를 아낄까** 고민한다.
- 강화 두루마리를 **어디에 쓸지**(무기? 갑옷?) 고르는 것이 한 생애의 성장이다.
- 랜다트는 "이번 판은 이걸로 간다"를 정하게 만들고, 픽다트(옛 등불지기의 유품)는 이름과 이야기로 기억에 남는다.
- 빌드의 중심은 여전히 영혼석이다. 장비는 체급과 방향을 받쳐준다.

## 1. 원칙

1. **기본템이 주력이다.** 대부분의 판은 잘 강화한 평범한 장비로 끝난다(DCSS처럼).
2. **속성(브랜드·에고)은 게임 규칙에 걸린다.** 원소·공격 형태·지형·횃불·영혼석 색.
3. **숫자는 작게.** 주인공 HP 30, 무기 피해 3~6 기준.
4. **정보는 숨겨져 있다가 드러난다.** 확인이 판단이 된다.

## 2. 디아블로식에서 바뀌는 것 한눈에

## 3. 장비 칸 (10칸)

| 칸 | 들어가는 것 | 외형 |
| --- | --- | --- |
| 무기 | 장검·손도끼·철퇴·전투 망치·단검·창 | 손에 든 무기 모양 |
| 방패 | 버클러, 방패 | 왼팔 |
| 머리 | 두건·가죽 모자·투구 | 머리 모양 |
| 몸통 | 천옷·가죽·사슬·판금 | 몸 색과 두께 |
| 망토 | 망토 | 등 뒤 천 |
| 장갑 | 장갑 | 손 크기와 색 |
| 신발 | 신발 | 발 크기와 색 |
| 목걸이 | 목걸이 | 가슴 앞 작은 보석 |
| 반지 ×2 | 반지 | 없음 |

- 지금 아이템 창의 칸 구성이 이와 다르면(보조 칸 등) 칸 이름만 맞춘다. 창의 배치와 동작은 바꾸지 않는다.
- 횃불은 칸을 차지하지 않는다(모닥불의 불씨는 등불지기가 늘 지니는 것, `설계_HUD.md` §7).
- 무기 교체: 공격 버튼 길게 누르기로 가방의 "마지막으로 쓴 다른 무기"와 바꾼다. 전투 중에는 한 턴.

## 4. 수치

| 수치 | 뜻 |
| --- | --- |
| 방어 | 물리 피해를 0~방어 사이 무작위만큼 줄임(최소 1은 들어감) |
| 회피 | 적의 직접 공격(근접·화살·돌진)을 피할 확률 |
| 막기 | 방패만. 막으면 피해 0 (초록 쿨타임 감소는 일어남) |
| 원소 저항 | 불·냉기·번개·독 각각 −3~+3 단계. 출처마다 ±1, 합산 후 −3~+3으로 자름 |

주인공 기본값, 피해 계산 순서, 저항 배율은 `밸런스_기준.md` §1~§3을 따른다.

### 5.1 무기

| --- | --- | --- | --- |
| 장검 | 베기 | 3~5 | — |
| 손도끼 | 베기 | 4~6 | 명중 −5% |
| 철퇴 | 타격 | 3~5 | — |
| 전투 망치 | 타격 | 4~6 | 명중 −5% |
| 단검 | 찌르기 | 2~4 | 급소 +10% |
| 창 | 찌르기 | 3~5 | 2칸 거리 공격(사이가 비어야 함) |

### 5.2 방어구

| 몸통 | 방어 | 회피 |
| --- | ---: | ---: |
| 천옷 | 0 | +5% |
| 가죽 | 2 | 0 |
| 사슬 | 4 | −4% |
| 판금 | 6 | −8% |

| 그 밖 | 방어 | 비고 |
| --- | ---: | --- |
| 두건 / 가죽 모자 / 투구 | 0 / 1 / 1 | 투구는 회피 −1% |
| 망토 | 1 | — |
| 장갑 | 1 | — |
| 신발 | 1 | — |
| 버클러 | 1 | 막기 10% |
| 방패 | 2 | 막기 20%, 회피 −2% |

## 6. 강화 (+N)

- 무기: +0~+6. +1마다 피해 +1, 명중 +2%.
- 방어구: 몸통 +0~+4, 그 밖 +0~+2. +1마다 방어 +1.
- 떨어지는 장비의 강화치: 대부분 +0, 가끔 +1~+3, 드물게 **−1~−3**(나쁜 장비).
- **강화 두루마리**(무기용·방어구용 두 종류)로 +1. 상한을 넘을 수 없다. 음수 장비도 끌어올릴 수 있다.
- 강화 두루마리는 층마다 평균 0.5장. 한 생애 동안 몇 장을 어디에 몰아줄지가 성장의 중심.
- 정착지 대장장이: 마석 1 + 광석 2로 창고의 장비 하나를 +1(상한까지). 성실한 대장장이는 가끔 재료를 덜 쓴다.

## 7. 속성

### 7.1 무기 브랜드 (하나만)

| 브랜드 | 효과 | 연결 |
| --- | --- | --- |
| 화염 | 적중 시 불 2, 풀·기름·빙결·중독과 반응 | 원소 |
| 냉기 | 적중 시 냉기 2, 젖은 적은 1턴 빙결 | 원소 |
| 번개 | 25% 확률로 번개 3, 젖었으면 번짐 | 원소 |
| 독 | 적중 시 중독 2 | 원소 |
| 피 (베기 무기만) | 출혈 +2 | 공격 형태 |
| 파쇄 (타격 무기만) | 골절 확률 두 배, 골절 시 1칸 밀침 | 공격 형태·벽 충돌 |
| 꿰뚫기 (찌르기 무기만) | 급소 피해 +50% | 공격 형태 |
| 흡혈 | 적중 피해의 30% 회복(해골 제외) | 생존 |
| 공명 | 적중 시 빨강 영혼석 쿨타임 감소가 라운드 제한을 한 번 무시 | 영혼석 |

### 7.2 방어구 에고 (하나만)

| 에고 | 붙는 칸 | 효과 |
| --- | --- | --- |
| 화염·냉기·번개·독 저항 | 몸통·망토·방패 | 해당 원소 저항 +1 |
| 가시 | 몸통 | 근접으로 나를 때린 적에게 2 피해 |
| 보호 | 몸통·방패 | 층마다 보호막 4로 시작 |
| 기다림 | 망토 | 대기 시 보호막 +2 (보라 빌드) |
| 되갚음 | 몸통·방패 | 맞으면 다음 무기 공격 피해 +2 (초록 빌드) |
| 통찰 | 머리 | 시야 +1, 적의 약점 형태를 처음부터 앎 |
| 물걸음 | 신발 | 물 위 불이익 없음, 얼음에서 미끄러지지 않음 |
| 불씨 품기 | 망토 | 횃불이 25% 느리게 탐 |
| 강타 | 장갑 | 벽 충돌 피해 +2 |
| 투척 | 장갑 | 던지는 물건 사거리 +1 |

### 7.3 장신구 (반지·목걸이)

DCSS처럼 모양만 보이고(루비 반지, 뼈 목걸이) 정체는 미확인이다.

| 반지 | 효과 |
| --- | --- |
| 보호 | 방어 +2 (강화치 −2~+4) |
| 회피 | 회피 +5% (강화치 있음) |
| 힘 | 피해 +1 (강화치 있음) |
| 체력 | 최대 HP +5 |
| 원소 저항 | 원소 하나 저항 +1 |
| 색의 반지 (빨강·보라·초록) | 그 색 영혼석의 기본 쿨타임 −1 |
| 투시 | 벽 너머 2칸의 적이 보임 |

| 목걸이 | 효과 |
| --- | --- |
| 기억 | 횃불이 30% 느리게 탐. 등잔에서 +20 더 |
| 재생 | 전투 밖에서 2턴마다 HP 1 |
| 연쇄 | 연쇄 연출 단계가 1단계 높게 시작, 연쇄 3단계 이상이면 보호막 +2 |
| 반사 | 화살을 20% 확률로 되돌림 |
| 고요 | 발견되기 전 대기하면 적이 나를 지나칠 확률 |

## 8. 랜다트 (무작위 유물)

- 기본템 + 강화치 + **속성 2~4개**(브랜드·에고·장신구 효과·수치 보정에서 뽑음). 무작위 이름("잿빛 속삭임", "굶주린 송곳니의 장갑").
- **대가가 붙을 수 있다**(40%): 최대 HP −3, 횃불 소모 +25%, 시야 −1, 회피 −5%, 한 색 영혼석 쿨타임 +1 중 하나.
- 강화 두루마리로 강화할 수 없다.

## 9. 픽다트 (옛 등불지기의 유품)

고정된 이름·효과·이야기를 가진 유물. 모두 **돌아오지 못한 옛 등불지기의 유품**이다. 줍는 순간 주인의 이름이 "기억할 이름들"에 오르고 모닥불 밝기 +1(`설계_스토리_정착지.md`).

| 이름 | 칸 | 효과 | 이야기 한 줄 |
| --- | --- | --- | --- |
| 물안개 망토 | 망토 | 대기할 때마다 주변 1칸이 젖는다 | 호숫가 뱃사공 출신 등불지기가 두르던 것 |
| 피의 송곳니 | 단검 +2 | 출혈 중인 적이 죽으면 주변 1칸 적에게 출혈 2 | 굶주린 해에 사냥으로 마을을 먹여 살린 이의 칼 |
| 가시 판금 | 판금 +1 | 맞을 때마다 초록 쿨타임이 추가로 1 줄지만 받는 피해 +20% | 물러서지 않았던 문지기의 갑옷 |
| 번개 감긴 반지 | 반지 | 번개가 번질 때 1칸 더 멀리 | 폭풍을 셌던 학자의 반지 |
| 거인의 철퇴 | 철퇴 +1 | 밀치기가 1칸 더 멀리, 벽 충돌 시 주변 1 피해 | 광산 붕괴에서 동료를 파낸 광부의 망치 |
| 연금술사의 장갑 | 장갑 | 던지는 물건이 두 개로 나뉘어 날아감 | 불씨 단지를 처음 만든 이의 장갑 |
| 첫 불씨 등잔 | 목걸이 | 횃불이 0이 되어도 시야 3칸 유지 | 모닥불을 처음 옮겨 붙인 등불지기의 등잔 |
| 이름 없는 투구 | 머리 | 적의 예고를 한 턴 먼저 봄 | 누구의 것인지 아무도 기억하지 못한다 |

- 한 세계(저장)에 같은 픽다트는 한 번만 나온다. 등불지기가 죽으면 **입고 있던 픽다트는 그 층에 남아** 다음 등불지기가 찾을 수 있다(유품이 다시 유품이 됨).

## 10. 확인 (미확인)

| 종류 | 처음 보이는 것 | 알게 되는 법 |
| --- | --- | --- |
| 무기·방어구 | 기본템 이름. 강화치는 "?", 속성이 있으면 "빛나는"만 | 입고 30턴(무기는 적중 10번), 또는 확인 두루마리 |
| 장신구 | 모양만(루비 반지) | 효과가 눈에 띄는 것(체력 +5 등)은 끼는 즉시, 나머지는 확인 두루마리 |
| 랜다트 | 무작위 이름과 "유물" 표시, 속성은 "???" | 입고 30턴마다 하나씩, 또는 확인 두루마리 |
| 픽다트 | 이름과 이야기, 효과 | 줍는 즉시 전부 |

- 음수 강화 장비도 입어보기 전에는 모른다. 벗는 데 제약은 없다(저주 없음).
- 정착지 학자는 귀환할 때마다 창고의 미확인 장비 하나를 확인해 준다.

## 11. 드롭

| 출처 | 장비 |
| --- | --- |
| 층마다 바닥 | 1~2개 |
| 상자 | 층마다 0~1개, 장비 확정 |
| 일반 몬스터 | 5% |
| 갑옷 고블린·돌진형 | 15% |
| 보스 | 1개 확정(랜다트 이상 30%) |

| 떨어진 장비의 종류 | 1~3층 | 4~6층 | 7~9층 | 10~12층 |
| --- | ---: | ---: | ---: | ---: |
| 평범(+0, 속성 없음) | 70% | 55% | 45% | 35% |
| 강화치 있음(±1~3) | 20% | 25% | 25% | 25% |
| 속성 있음 | 8% | 14% | 20% | 25% |
| 랜다트 | 2% | 5% | 8% | 12% |
| 픽다트 | 0% | 1% | 2% | 3% |

- 장신구는 전체 장비의 20%.
- 바닥의 장비는 빛기둥 없이 놓여 있고, 속성·유물만 은은하게 빛난다(속성은 그 원소 색, 랜다트는 무지갯빛, 픽다트는 금빛).

## 12. 아이템 창 (지금 것 유지 + 바뀌는 표시)

- 창의 배치, 인형 회전, 장착·해제, 두 창 비교, 반지 두 칸 비교, 캐릭터 정보 창의 출처 펼치기는 **지금 구현 그대로** 둔다.
- 바뀌는 것:
  - 가방 칸 테두리: 등급 색 대신 — 평범은 없음, 속성은 원소 색, 랜다트 무지갯빛, 픽다트 금빛, 미확인은 "?".
  - 이름 표기: "+2 화염 장검", "장검 ?", "루비 반지", "잿빛 속삭임(유물)".
  - 비교 창: 모르는 값은 "?"로 두고 차이값을 내지 않는다.
  - 설명 창 버튼: [장착] [버리기] + 두루마리를 들고 있으면 [확인] [강화].
  - 정착지에서는 창고 칸이 함께 보여서 가방과 창고 사이로 옮길 수 있다.

## 13. 외형 (지금 것 유지 + 추가)

- 칸별 외형 변화는 지금 구현을 그대로 쓴다. 망토 칸이 없으면 등 뒤 천을 추가한다.
- 추가:
  - 무기 브랜드: 칼날에 원소 빛(화염은 불꽃, 냉기는 서리, 번개는 튀는 전기, 독은 녹색 방울).
  - 방어구 에고: 테두리에 그 색.
  - 강화치 +3 이상: 은은한 광택.
  - 랜다트는 무지갯빛 테두리광, 픽다트는 금빛 테두리광 + 고유 모양 하나(첫 불씨 등잔은 가슴의 작은 등잔, 이름 없는 투구는 얼굴을 가리는 투구).
- 등급 색 광택과 전설 오라는 뺀다.

## 14. 성장과의 관계

- 한 생애의 성장: 레벨(영혼석 칸), 영혼석 진화, **강화 두루마리**, 좋은 기본템을 찾는 것.
- 대를 넘는 성장: **창고**(좋은 장비를 다음 등불지기에게), 대장장이 강화, 학자 확인, 층에 남은 픽다트.
- 죽으면 입은 장비와 가방은 잃는다. 입고 있던 픽다트만 그 층에 남는다. 창고는 남는다.

## 15. 코드 연결

- **유지:** 아이템 창 UI, 장착·해제, 비교, 인형 외형, 창고.
- **교체:** 등급·옵션·전설 데이터와 생성 규칙 → 이 문서의 기본템·강화·브랜드·에고·장신구·랜다트·픽다트.
- 데이터: `BASES`, `BRANDS`, `EGOS`, `RINGS`, `AMULETS`, `RANDART_PROPS`, `RANDART_COSTS`, `UNRANDS`, 드롭 표.
- 규칙: `makeItem(depth, source)`, `identify(item, how)`, `enchant(item)`, `calcStats()`. 브랜드·에고 효과는 이미 있는 지점에 건다: 적중, 피격, 대기, 원소 반응, 던지기, 횃불 소모, 영혼석 쿨타임 감소.
- 소모품 추가: 강화 두루마리(무기용·방어구용), 확인 두루마리.
- 저장: 장비 객체 형식이 바뀌므로 저장 버전을 올린다. 이전 등급 장비는 기본템 + 강화치(마법 +1, 희귀 +2, 전설 → 가까운 픽다트 또는 +3)로 옮긴다.

## 16. 범위 밖

- 저주, 무게, 요구 능력치.
- 상점.
- 세트 장비.

## 17. 확인 목록

1. 층마다 장비가 2~4개 정도 나오고, 대부분 평범한 기본템이다.
2. 미확인 무기를 입으면 적중 10번 뒤 강화치와 속성이 드러난다. 음수 강화도 있다.
3. 강화 두루마리로 +1, 상한을 넘지 못한다. 랜다트는 강화할 수 없다.
4. 화염 브랜드 무기로 풀 위의 적을 치면 불이 번진다.
5. 색의 반지를 끼면 그 색 영혼석의 기본 쿨타임이 1 준다.
6. 픽다트를 주우면 주인의 이름이 "기억할 이름들"에 오르고 모닥불 밝기 +1.
7. 죽으면 입고 있던 픽다트가 그 층에 남는다.
8. 비교 창에서 알려진 수치만 차이가 나오고 모르는 값은 "?".
9. 아이템 창의 기존 동작(장착·해제·비교·인형 회전·외형 변화)이 그대로 동작한다.
10. 이전 저장의 등급 장비가 새 형식으로 옮겨진다.

## 18. 열린 결정

- 강화 두루마리 빈도(층마다 평균 0.5장).
- 랜다트의 대가 확률(40%).
- 보조 무기 칸을 따로 둘지(지금 안: 방패 칸만, 무기 교체는 가방에서).
