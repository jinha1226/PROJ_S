# 원형 조명 후속 수정 protocol

- 작업 ID: `RADIAL-DARKNESS-002`
- 기준 commit: `9abd682`
- 사용자 관측: 벽 횃불의 시야 밖 광원이 보이지 않고, 횃불 장착 후 주변이 밝아지지 않으며 전체 화면이 과도하게 어둡다.

## 수정 범위

- 제품 가방에서 횃불을 장착하면 성공 직후 자동 점화한다. 코어 API의 장착/점화 분리와 저장·연료 규칙은 유지한다.
- 현재 시야 밖이라도 이미 발견된 `MEMORY` 벽 횃불은 알려진 지형과 LOS 안에서 주변을 원형으로 밝힌다. `UNSEEN` 지형·액터·아이템은 노출하지 않는다.
- 벽 횃불의 glyph와 warm pool도 MEMORY에서 실제 광원처럼 보이게 한다.
- 1·2·3층의 전체 암흑 alpha를 낮추되 층별 상대 차이와 횃불 효용은 유지한다.

## 검증

- 무횃불보다 휴대 횃불의 중심·중간 반경이 밝아야 한다.
- MEMORY 벽 횃불 주변은 먼 MEMORY보다 밝고, 가림벽 뒤와 UNSEEN은 밝아지지 않아야 한다.
- 횃불 장착 UI가 점화 상태와 한 개의 동적 광원을 만든다.
- 관련 전용 회귀와 제품 시작 smoke를 통과한 뒤 종료한다.
