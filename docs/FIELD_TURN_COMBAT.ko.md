# 탐험·전투 통합 턴

2026-09-10. 기존 `1443da6`의 조우 → 배치 → 실시간 행동 예약 구조를
새 원정의 입력 기반 턴 처리기로 교체한다.

## 제품 동작

- 새 DUO 원정은 `field_turns_v1` 규칙을 사용한다. 적 발견, 첫 공격,
  추격 종료, 적 처치로 전투 모드에 진입하거나 배치·재집결하지 않는다.
- 탐험 맵의 적 터치는 사거리 안이면 즉시 공격한다. 이동 방향의 적도
  같은 공격 경로를 사용한다. 공격 버튼은 사거리 밖의 적에게 한 칸 접근한다.
- 이동·공격·대기·기술은 `FieldTurnSystem`에서 처리한다.
  아이템 사용에 붙는 시간도 같은 처리기를 사용한다.
- 입력 없이 렌더 프레임이 지나도 세계는 진행하지 않는다. 자동 탐험·휴식은
  명시적으로 시작한 이동·대기의 반복이며, 적이 보이면 중단한다.
- 동료는 던전에 들어올 때 각자 칸을 배정받고 이후 실제 이동으로만 따라온다.
  전투 시작·종료 순간의 순간이동이 없다.
- 지도·공격 표적·동료 AI는 파티 공유 시야와 같은 LOS를 사용한다.

## 시간 계약

플레이어 턴은 모든 배우에게 행동 1회씩을 지급하는 라운드가 아니다.
주인공 행동을 현재 시각에 적용하고 그 행동의 소요시간 동안 발생하는
환경·상태 처리 및 동료·적의 행동을 준비 시각 순으로 해결한다.
각 배우는 직전 행동을 마친 뒤 `busy_until`에 다시 행동할 수 있다.
행동 직전에 표적·경로·성격·감정·체력을 다시 평가한다.

동일 시각에는 환경/상태 cadence가 배우보다 먼저, 배우끼리는 entity ID 순으로
처리한다. 턴 끝 시각의 cadence는 정착시키고, 그 시각에 준비된 배우의 행동은
다음 플레이어 입력 뒤 처리한다. 피해·감정·기억·관계도 각 행동 직후 반영한다.
실패하면 해당 플레이어 턴 전체를 되돌린다.

`action_speeds`는 MOVE/ATTACK/CAST의 독립 백분율이며 기본값은 각각 100이다.
시간은 `ceil(기본 비용 × 100 / 속도)`이다. 대기는 속도와 무관하다.
이동 기본 비용은 지형, 무기를 사용하는 공격은 무기의 공격 시간,
기술은 기존 기술 시간표를 사용한다. 기존 성격 수치나 DEX를 임의의 속도로
재해석하지 않는다. 현재 이 값은 저장 가능한 기본 속도이며 전투 중 속도 버프를
변경하는 API는 제공하지 않는다.

| 배우 | 행동 비용 | 주인공이 100시간을 쓸 때, 모두 처음에 준비된 경우 |
|---|---:|---|
| 보통 동료 | 100 | 0에 행동, 다음 준비는 100 |
| 빠른 동료 | 50 | 0·50에 행동, 다음 준비는 100 |
| 느린 동료 | 150 | 0에 행동, 다음 턴에도 150까지 기다림 |

## 동료 명령과 성격

### 탐험 대형과 직접 조작

`전술 → 탐험 대형`에서 자유·종대·횡대·쐐기를 설정한다. 현재 조작 중인
배우가 대형의 기준이며 마지막 이동 방향을 기준으로 자리가 회전한다.
동료는 자신의 이동 시간으로 배치에 접근한다. 막힌 칸은 일반 따라오기로
대체하고, 전투 시에는 명령과 성격 판단이 대형보다 우선한다.
대형 변경 자체는 시간을 소비하지 않으며 순간이동이나 행동 대기 초기화도 없다.

입력 대기 중 지도 위 동료나 초상화를 누르면 해당 동료를 직접 조작한다.
원래 주인공을 다시 누르면 돌아간다. 선택만으로 시간은 흐르지 않고,
선택된 배우의 이동·공격·시전 비용만큼 다음 입력까지 시간이 흐른다.
나머지 배우(원래 주인공 포함)는 명령·성격 AI로 행동한다.
이전 행동의 대기시간이 남은 배우나 무력화된 배우로는 전환할 수 없다.
대형과 조작 대상 변경은 이벤트와 journal에 저장하고 재생한다.
초상화의 기존 상세 보기 경로(더블 탭)는 유지한다.

각 초상화 위에는 해당 배우의 장착 스킬 두 칸을 표시한다. 스킬이 없는
칸에는 버튼이나 대체 공격을 만들지 않는다. 동료 스킬을 누르면 해당 동료를
조작 대상으로 선택하고 대상을 지정한다. 선택·취소는 시간을 쓰지 않으며
확정된 기술은 시전자의 속도·기력으로 처리한다. 행동 대기 중이거나 무력화,
불안, 기력 부족 상태이면 버튼을 비활성화한다.

전술 메뉴는 탐험 중에도 사용할 수 있는 동료 지속 명령이다. 명령을 확정하면
주인공이 한 턴을 소비한다. 메뉴를 여는 것과 취소는 시간을 쓰지 않는다.
주인공은 동료 명령 때문에 자동으로 공격하거나 후퇴하지 않는다.

| 명령 | 동료 행동 |
|---|---|
| 공격 대상 지정 | 지정 표적을 우선하되 성격 평가에 따라 공격·보호·후퇴를 선택 |
| 따라오기 | 안전할 때 주인공을 따르고 적이 보이면 성격에 따라 행동 |
| 공격 중지 | 공격하지 않고 주인공 곁으로 이동 |
| 자리 지키기 | 현재 칸을 지키며 사거리 안의 적만 공격 |
| 후퇴 | 공격하지 않고 적과 거리를 벌리며 주인공 쪽으로 후퇴 |

기존 HEXACO appraisal, utility score, 스트레스, 감정, 기억, 관계 시스템을
사용한다. 이전 자동전투의 ‘건강한 동료는 후퇴 후보를 제거’와 ‘지정 표적은
무조건 공격’ 강제 규칙은 새 필드 규칙에서 사용하지 않는다.

## 구조와 저장

주요 구현: `sim/systems/field_turn_system.gd`, `sim/field_turn_rules.gd`,
`sim/field_action_timing.gd`. 기존 피해·장비·시야·원소·상태 시스템은 재사용한다.
`IndividualBattleScheduler`와 배틀하트 실시간 시계는 새 원정의 실행 경로가 아니다.
기존 조우 API와 테스트 장면은 과거 시뮬레이션 검증용으로 남아 있다.

저장 wire의 `safe_phase=GROUPED`는 새 필드 전체에서 고정이며 전투 여부를
뜻하지 않는다. 적이 모두 죽어도 이 값을 바꾸지 않고 실제 생존 적 수로
출구·다음 층 개방을 판단한다. `DEPLOYED`는 필드에서 각자 칸을 점유함을 뜻한다.

새 로컬 저장 슬롯은 `living_world_field_turns_v1.json`이다.
이전 `living_world_party_encounter_v3.json`은 덮어쓰거나 삭제하지 않는다.
이전 DUO 저장은 자동 변환하지 않으며 새 원정이 필요하다는 메시지로 거부한다.
새 저장은 field_action 및 동료 명령 journal을 재생하고 스냅숏과 완전 일치해야
불러올 수 있다.

## 참고 범위

DCSS의 [동료 명령 구현](https://github.com/crawl/crawl/blob/master/crawl-ref/source/shout.cc)
`issue_orders`, `_set_friendly_foes`, `_set_allies_patrol_point`, `_set_allies_withdraw`와
[근접 공격 구현](https://github.com/crawl/crawl/blob/master/crawl-ref/source/melee-attack.cc)을
동작 설계 참고로 읽었다. 명령 대상·지속 행동과 실제 공격 판정을 분리하는
방식을 참고했으며 C++ 코드는 복사하지 않았다. 소환 생성·소환 지속시간이나
DCSS의 신·주문 체계는 도입하지 않았다.
