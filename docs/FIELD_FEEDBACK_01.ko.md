# 원정 플레이 피드백 수정

## 범위와 확인 방법

- 적 생존 상태에서 계단까지 실제 이동하고 2층 진입 및 월드 검증을 확인한다.
- 두 칸 이내 시야가 열린 적은 즉시 추격하고, 벽 뒤 대상은 인식하지 않는지 확인한다.
- 390×844 화면의 인물 상세창에 터치 이벤트를 보내 물약 전달, 회복, 한 턴 소비, 모달 해제와 다음 입력을 확인한다.
- 즉시 합류 성격 세 가지에서 물약 중복 전달 거부, 다음 턴과 저장 기록의 정확한 재현을 확인한다.
- 숙련 UI의 근처 적 제한을 제거하고 실제 포인트 소비, 예산 제한, 전투 적용 및 획득 포인트 저장 재현을 확인한다.
- 기존 절차적 생성 100개 시드 검사와 이전 규칙 버전 5 저장 재현을 확인한다.

## 변경

1. 필드 원정의 중간층 계단은 적을 모두 처치하지 않아도 열린다. 전멸 보상과 최종층 완료 조건은 별도로 유지한다. 행동불가 동료를 해결해야 하는 조건도 유지한다.
2. 새 원정에서 시야가 열린 두 칸 이내 적은 방향·어둠으로 놓치지 않고 즉시 추격한다. 벽과 명시적 은신은 기존 판정을 따른다.
3. 인물 상세창의 물약 버튼을 실제 전달 동작에 연결하고 터치, 처리 중 표시, 중복 실행 차단을 추가했다. 성공 시 상세창을 닫아 다음 입력을 받는다. 하단 버튼의 원래 터치 실패는 로컬에서 재현되지 않았다.
4. 인물 제목 아래 종족/역할/생명 상태 나열을 제거했다. 성장 정보가 있으면 레벨만 표시한다.
5. 숙련은 턴 처리가 끝난 의사결정 시점에 투자할 수 있다. 적이 보인다는 이유로 막지 않으며 포인트 수, 최대 등급, 유효 파티원, 종료 상태 검사는 유지한다.
6. 장비 탭이 열린 상태에서 장비를 변경할 때 전투 수치도 갱신하도록 상세창 갱신 경로를 연결했다.
7. 마을을 끄면서 함께 차단됐던 동료 모집을 새 원정에서 허용한다. 성격에 따라 즉시 합류하는 NPC의 위치를 주인공 위치로 간주하던 저장 검증 오류를 공통 이동 기록 검증으로 수정했다.

## 호환성

새 원정은 행동 규칙 버전 6을 기록한다. 기존 버전 5 저장은 이전 인식·동료 허용 규칙으로 재현한다. 새 인식과 동료 모집을 확인하려면 새 게임을 시작해야 한다. 계단·숙련 UI 수정은 현재 필드 플레이에도 적용된다.
