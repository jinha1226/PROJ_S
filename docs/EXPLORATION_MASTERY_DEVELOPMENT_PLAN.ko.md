# 탐험 재생성·숙달 경험치 개발서

- 작성일: 2026-09-10
- 상태: 문서 분리. 층 초기화는 합의 방향, 숙달 상세는 권장 설계다.
- 범위: 층 수명·영속 상태·경험치. 아이템 개발자가 이 전체 범위를 자동 구현하지 않는다.
- 연계: [아이템 개발서](ITEM_REWARD_PROGRESSION_DEVELOPMENT_PLAN.ko.md)는 깊이별 소재와 유한 필수 재료의 배치 계약을 담당한다.

## 1. 1·2층 초기화와 3층 이후 영속성

### 1.1 사용자 결정

- 1·2층은 초기화 가능한 저층 구간이다.
- 3층부터는 마을 귀환으로 초기화하지 않는다.
- 저층은 보급·복구의 역할을 갖고, 상위 성장 소재는 영속 구간에서 확보한다.

### 1.2 실행 의미 — 제안 기본안

초기화는 **마을에서 새 원정을 확정할 때 원정 세대당 한 번** 수행한다. 층 계단 왕복·저장 로드·준비 UI 취소로 실행하지 않는다. 1·2층의 일반 적·자원·일반 상자·일시적 환경은 새 세대로 생성한다. 지형 자체의 재생성은 기존 지도 생성과 호환되는 범위에서 결정하되 연결 계단·3층 접근 경로는 항상 유효해야 한다.

- 캠페인 최초 발견/귀환 보너스, 고유 보상 수령, 이능, 개체별 숙달 기록은 재생성 대상이 아니다.
- 고유 아이템과 캠페인 보상은 `campaign + reward_id`, 일반 저층 보상은 `campaign + floor + generation + source_id`처럼 서로 다른 중복 방지 범위를 사용한다.
- 재생성 시 미회수 일반 전리품의 소멸 여부를 출발 전에 명시한다. 기본 제안은 저층 미회수 생성 전리품 소멸이다.
- 플레이어가 버린 물건과 지속 NPC의 소유품은 출처를 구분해 보존/안전 회수 정책을 먼저 정한다. 무단 삭제·복제 금지. NPC를 리셋된 층과 영속 층 양쪽에 중복 생성하지 않는다.
- 3층 이후는 적 사망·부상·위치, 회수한 상자·자원, 바닥 물품, 문·지형·환경 상태를 저장한다. '초기화 안 함'은 시간이 멈춤을 뜻하지 않는다. 기존 시간 규칙의 변화를 따르되 별도의 무제한 재생성은 추가하지 않는다.
- 층 세대 번호와 영속 상태는 canonical 저장/저널에 기록한다. 미리보기나 화면 갱신에서 생성 난수를 소비하지 않는다.

### 1.3 유한 자원 소진 방지

3층 이후의 재료는 유한하므로 원정마다 초기화된다는 가정으로 드롭률을 잡으면 안 된다. 필수 성장 재료는 접근 가능한 고정 보상/최소 배치량을 두고, 확률 드롭은 추가분으로 취급하는 방안을 우선한다.

대표 장비 하나의 진행 재제작에 필요한 수량, NPC가 선점하는 양, 선택 가능한 추가 무기의 비용을 함께 검증한다. 필수 재료를 판매·폐기한 경우의 복구 경로도 정한다. 먼저 여러 무기를 만들었다고 진행이 영구 봉쇄되면 안 된다. 복구는 해당 깊이 도달/공략 조건에 묶인 주문 등으로 설계할 수 있으나, 이는 미정이며 저층 골드만으로 깊이 조건을 우회해서는 안 된다.

## 2. 숙달 경험치 — 권장 설계, 아직 수치 미정

질문에 대한 권장 답은 **개별 몬스터 인스턴스나 층이 아니라 몬스터 전투 유형별**이다. 예: 고블린 전사와 고블린 주술사는 별도, 같은 전사의 새 개체는 공유한다. 단순 이름·색·층·체력 배율 차이만으로 새로운 유형을 만들지 않는다. 정예가 실제로 새로운 공략을 요구할 때만 별도 키를 준다.

- 권장 기록 단위: `성장 주체(캐릭터) + mastery_group_id`. 영입 동료의 경험 공유 여부는 후속 정책으로 분리한다.
- 경험치 지급 여부는 정식 처치/기여 보상 경로에 연결한다. 다른 캐릭터가 잡은 적을 봤다는 이유로 신규 캐릭터의 숙달을 소진시키지 않는다.
- 획득 경험치의 개념식: `기존 처치 보상 × 유형 숙달 계수 + 최초 공략 보너스`.
- 계수는 미숙달→학습 중→숙달로 내려가는 데이터이며 최종 0 허용을 권장한다. 횟수와 감쇠 수치는 테스트 후 결정한다.
- 종족 최초 보너스와 유형 최초 보너스를 중복 신설하지 말고 한 보상 경로로 정리한다.
- 층/깊이는 출현 유형과 위험도·소재를 결정한다. 해당 층에서 몇 마리를 잡았다는 이유로 처음 보는 모든 몬스터의 경험치를 막지 않는다.
- 숙달은 능력 장착 한도를 만드는 캐릭터 레벨 경험치에 적용하는 제안이다. 기존 growth/스탯/무기 숙련 보상이 별도로 남아 무한 저층 성장을 허용하는지 함께 감사하고, 제한 범위 변경은 기록한다.
- 제거한 이능을 다시 흡수하거나 층을 재생성해도 숙달 기록을 되돌리지 않는다. 기존 저장에 충분한 과거 정보가 없으면 0으로 단정하는 대신 명시적 마이그레이션 경계를 둔다.

유한 영속 층과 유한 경험치를 함께 쓰므로 전체 몬스터 구성으로 목표 레벨에 도달 가능한지 검증한다. 새로운 플레이어가 희귀 유형을 놓쳤다는 이유로 주요 이능 슬롯을 영구적으로 못 열게 되지 않도록 한다. 보물 발견/탐험 목표의 일회성 경험치 추가는 보완 후보이며 별도 승인 전 자동 도입하지 않는다.


## 3. 검증·반환

- 원정 세대당 저층 재생성 1회, 계단 왕복/로드/출발 취소 시 재생성 없음.
- 3층 이후 사망·회수·문·환경·바닥 아이템 상태와 지속 개체의 소유권을 저장/로드 후 비교한다.
- 숙달·고유 보상·튜토리얼 기록은 층 재생성과 독립적으로 유지한다.
- 숙달을 구현할 때 새 개체 ID로 경험치 제한을 우회하지 못하고 다른 공략 유형은 구분되는지 검증한다.
- 성장/스탯/숙련의 다른 경험 경로도 감사하되 승인 없는 전면 변경은 하지 않는다.
- 코드·테스트·결과를 커밋해 반환하고 별도 요청 없이는 푸시하지 않는다.
