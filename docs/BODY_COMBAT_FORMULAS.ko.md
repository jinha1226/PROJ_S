# 육체 전투 규칙 v2

## 기존 계산과 유지 범위

HP 피해와 부위 손상은 병렬 계산한다. 피부·뼈 수치는 HP 방어력에 직접 더하지 않는다. 명중 후 부위는 머리 10%, 몸통 35%, 팔 각각 15%, 다리 각각 12.5%의 가중치로 결정하며 절단된 부위는 제외한다. 재현 가능한 공격 해시를 사용한다.

부위별 피부·연부조직·뼈 내구도는 각각 1000에서 시작한다. 연부조직은 근육·지방 등 내부 조직을 추상화한 완충층이다. 완충 수치가 높으면 타격 전달량과 충격이 줄어든다. 연부조직 내구도와 완충 능력치는 서로 다른 값이다.

F=무기 힘×20/접촉 크기, P=관통, S=충격력, K=피부 질김, C=연부조직 완충, B=뼈 강도. 방어구 베기 방호 A, 찌르기 방호 Q, 충격 완충 U, 강성 R은 현재 일반 방어 수치의 각각 10배로 투영한다. 모든 정수 나눗셈은 버림이며 max(0,…)로 음수 손상을 막는다.

| 공격 | 피부 손상 D | 연부조직 손상 T | 뼈 손상 J |
|---|---|---|---|
| 베기 | max(0,F+P/2−A−K) | max(0,(P+D/4−R)/2) | max(0,F/2+S/2−U−B)/4 |
| 찌르기 | max(0,F+2P−Q−R−K) | D/2 | max(0,P+F/4−R−B)/3 |
| 타격 | max(0,F+S−U−C)/2 | max(0,F−U−K)/8 | max(0,F+S/2−U−R/2−B)/2 |

각 손상은 해당 층의 남은 내구도까지만 차감한다. 이 계산은 새로 도입한 확률 공식이 아니라 기존 누적 손상 계산을 유지한 것이다. 무기 힘과 충격력은 무기의 기준 피해 대비 해당 공격의 피해로 비례 조정한다. 피부만 완전히 손상되어도 자동 절단되지 않으며, 기존 절단은 베기 공격에서 세 층이 모두 0일 때만 발생한다.

화염은 피부=피해, 연부조직=피해/4, 전기는 피부=피해/4, 연부조직=피해/8이며 기계적 골절은 만들지 않는다. 충격은 별도 누적 기록이지만 의식 저하·실신은 아직 연결되어 있지 않다. 의식 값과 의식 저항은 저장 항목이며 현재 게임 플레이 효과가 없다. 혈액·출혈 필드는 호환 기록만 남았고 혈액 소모·출혈 피해를 재활성화하지 않는다.

## UI 등급

피부 질김: 25 미만 하 / 25~39 중 / 40 이상 상.
뼈 강도: 70 미만 하 / 70~99 중 / 100 이상 상.
근육(내부명 연부조직 완충): 25 미만 하 / 25~39 중 / 40 이상 상. 근육량·근력 자체가 아니라 내부 조직 완충의 UI 명칭이다.
종족 내부 상대평가가 아닌 전체 공통 절대 기준이다. 현재 대다수 기본 피부는 중, 드워프의 기본 뼈는 상이다. UI 표시는 수치 대신 등급을 쓰되 실제 판정은 정수 값을 그대로 사용한다.

## 부상 단계와 페널티 — 이번 적용 기준

- 연부조직 내구도 ≤700: 깊은 상처. 뼈 내구도 ≤600: 골절.
- 기존 기능 상실·절단이 최우선이다. 같은 부위는 가장 심한 단계 하나만 적용한다.
- 팔 한쪽: 깊은 상처 −10%, 골절 −25%, 기능 상실/절단 −25%의 일반 물리 공격력. 양팔 합산, 최대 −50%. 기존 무기 사용 불가 판정도 유지한다.
- 다리 한쪽: 깊은 상처 +25%, 골절 +50%, 기능 상실/절단 +100% 이동 시간. 양다리 합산, 최대 기본 시간의 3배. 이동 불가 상태로 만들지는 않는다.
- 전체 부위 중 가장 심한 단계에 따라 HP 자연회복 −20% / −40% / −60%. MP 회복·물약·능동 회복은 그대로다. 회복량이 1 미만이어도 장기적으로 회복되도록 누적 펄스 차이로 계산한다.
- 전체 HP 숫자, 피부·뼈 저항 공식, 개별 무기 밸런스는 이번에 축소하지 않는다.

공격력 감소는 일반 물리 공격 경로에 적용하며 변이·마법의 고정 피해를 일괄 낮추지 않는다. 부상 단계는 내구도에서 파생하며 별도의 저장 상태를 중복 관리하지 않는다. 과거 공격 검증은 당시 페널티 기록을 사용해야 하므로 치료 후에도 이전 피해를 다시 계산해 바꾸지 않는다.

## 안전한 휴식과 내구도 회복

기존 안전 회복 판정과 500 시간단위 대기, 이후 300마다 회복하는 주기를 공유한다. HP·MP가 가득 차도 부위가 손상되어 있으면 회복은 계속된다. 안전한 탐험 이동·대기도 같은 기존 자연회복 경로를 사용한다.

한 회복 주기마다 절단되지 않은 각 부위의 피부 +25, 근육 +15, 뼈 +8(최대 1000). 부상에 의한 자연치유력 감소는 HP 회복에만 적용하고 조직 회복을 추가로 늦추지는 않는다. 기능 상실 부위는 근육 >700 및 뼈 >600일 때 기능을 회복한다. 절단은 일반 휴식으로 재생되지 않는다. 상처 개수는 과거 기록이므로 내구도 회복과 함께 삭제하지 않으며 현재 단계·페널티는 내구도에 따라 사라진다.

휴식 버튼도 조직 손상 여부를 확인한다. HP·MP가 가득 차도 조직 손상만으로 시작할 수 있고, 조직 회복을 진행으로 인정하므로 HP가 늘지 않는다는 이유로 중단하지 않는다. HP·MP와 회복 가능한 조직이 모두 차면 종료한다. 적 발견·피격·굶주림·위험 지역에 따른 기존 중단 규칙은 유지한다.

밸런스 ID `dcss-balance-0.34.1-body-penalties-v4`부터 적용하며 이전 진행은 새 원정으로 시작한다. 기존 저장 파일을 삭제하지 않는다.

## 검증 결과

Godot 4.6.2 headless에서 다음 검사를 통과했다.

- `tests/body_penalty_regression.gd`: 등급 경계, 깊은 상처·골절 경계, 중복 페널티 방지, 조직별 회복, 기능 상실 회복/절단 유지, HP·MP가 가득 찬 상태의 휴식 시작·진행·종료, 실제 필드 전투와 저장 재생 일치, 골절 팔 공격과 치료 후 과거 기록 검증, 골절 다리 실제 이동.

- `tests/rest_and_pickup_regression.gd`: 전투·아이템 줍기·휴식·저장 재생. 첫 실행은 예전 ENGAGED 모드 종료만 승리로 인식하는 테스트 조건 때문에 실패했다. 현재 필드 전투에서 공격한 적의 사망도 승리로 판정하도록 테스트를 갱신한 후 통과했다.
- `tests/solo_start_acceptance.gd`: 솔로 시작·종족 선택·출발·저장 재생.
- `git diff --check`: 통과.

실제 모바일 기기에서의 시각·조작 검증은 수행하지 않았다. 부상 경계의 합성 상태는 스냅샷 검증에만 사용했으며, 명령 재생 검사는 별도의 실제 전투 흐름으로 수행했다. 수치들은 첫 게임 밸런스 기준으로 플레이 테스트 후 조정할 수 있다.
