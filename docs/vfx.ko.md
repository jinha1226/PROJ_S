# 전투 효과 VFX

현재 그래픽 위에 코드로 그리는 순간 효과와 지속 상태 연출이다. 새 이미지 에셋은 추가하지 않는다. 순간 효과는 기본 0.46초이며, 지속 효과는 실제 상태가 남아 있는 동안 반복한다. 타일 크기에 맞춰 선과 도형이 줄어든다.

|---|---|
| 베기 / 찌르기 / 타격 | 밝은 궤적 / 직선 관통 / 충격파와 파편 |
| 불 / 얼음 / 번개 / 독 | 솟는 불꽃 / 결정 / 꺾인 전류 / 녹색 방울 |

## 모바일 지속 상태

`expedition/ui/status_vfx.gd`는 실제 `statuses`와 만료 시간을 읽는다. 화상은 몸 양옆 불꽃·불티, 중독은 오른쪽 녹색 독 방울·연기, 출혈은 아래로 떨어지는 붉은 핏방울, 빙결은 몸을 감싼 반투명 결정, 전하는 몸 양옆 스파크로 표시한다. 둔화는 발밑 냉기이며 빙결 중에는 중복 표시하지 않는다. 저주·낙인, 축복, 기절·혼란, 속박, 골절·약점, 보호·가속에도 작은 지속 표식을 붙인다. 같은 모양의 상태는 하나로 합치며 핵심 원소 상태들은 표시 위치를 나누어 함께 보인다.

이동·피격 중에도 캐릭터를 따라간다. 입력을 기다릴 때도 화면 시계로 움직이며 정화·해제·만료·사망하면 사라진다. 시야 밖 NPC와 적의 상태는 표시하지 않는다. 전투 재생은 상태를 복사한 프레임과 그 당시 게임 시간을 사용해, 이미 해제된 미래 상태가 이전 연출에 섞이지 않게 한다.

지속 표식은 최대 30회/초로 전경 레이어만 다시 그린다. 타일 맵은 애니메이션 때문에 매번 다시 그리지 않으며 상태가 없으면 반복 그리기를 멈춘다. 게임 시간·난수·피해·상태 지속 시간·효과 이벤트 대기열에는 관여하지 않는다. 기존 피해·폭발·확산·파쇄·번개 연쇄의 순간 연출은 함께 유지한다.

## 순간 효과 연결 기준

- `expedition/ui/effect_vfx.gd`에서 의미별 색·도형·수명과 보조 이벤트를 관리한다. 한국어 알림 문자열을 분석하거나 역할군 이름만 보고 실제로 발생하지 않은 효과를 그리지 않는다.
- 피해는 기존 피해 이벤트에 `vfx`, `element`를 붙인다. 부가 피해도 원소 정보가 보존된다. 출혈 틱은 무기 베기와 구분된다.
- 상태는 실제 적용되고 기존에 없을 때, 회복은 실제 HP를 회복했을 때 그린다. 저항·실패와 단순 수치 조회에는 성공 연출이 없다. 면역이 공격을 막은 경우에는 방어 연출을 낸다.
- 스택·MP·보호막은 실제 증가를 기준으로 표시한다. 기본 능력치와 상시 보너스는 계속 반짝이지 않는다.
- 같은 행동의 같은 위치·종류 보조 이벤트는 중복을 합친다. 보조 연출은 앞선 공격과 같은 박자를 사용해 후속 공격을 늦추지 않는다.
- 화면은 현재 시야 또는 재생 프레임에 기록된 시야를 사용한다. 대상이 보이지 않으면 그리지 않는다. 공격자나 궤적 중간 칸이 보이지 않으면 대상의 피격 효과만 남긴다.
- VFX는 게임 난수·행동 비용·피해량·회복량에 관여하지 않는다. 시뮬레이션이 집계할 피해 이벤트를 장식 이벤트가 밀어내지 않는다.

## 검증

`tests/effect_vfx.gd`는 의미별 도형, 수명과 타일 크기, 실패·중복 적용, 원소 부가 피해, 반사·흡혈·소환의 위치, 시야와 재생 프레임, 공격 간격, 실제 CanvasItem 그리기를 검증한다. GitHub Actions 테스트 목록에 포함한다.

지속 표식은 상태 해제·사망·만료·시야 밖 제거, 재생 당시 상태와 시간 보존, 입력 대기 중 반복, 실제 CanvasItem 그리기를 같은 검사에서 확인한다. 이번 지속 연출 변경은 VFX와 전투 재생 검사만 실행해 통과했다.

로컬 검증: 전체 98개 테스트 통과. 이후 시야 밖 재생 대기·소비품·그리기 보완은 관련 14개 테스트를 다시 실행해 통과했다.
