## 연결 기준

- `expedition/ui/effect_vfx.gd`에서 의미별 색·도형·수명과 보조 이벤트를 관리한다. 한국어 알림 문자열을 분석하거나 역할군 이름만 보고 실제로 발생하지 않은 효과를 그리지 않는다.
- 피해는 기존 피해 이벤트에 `vfx`, `element`를 붙인다. 부가 피해도 원소 정보가 보존된다. 출혈 틱은 무기 베기와 구분된다.
- 상태는 실제 적용되고 기존에 없을 때, 회복은 실제 HP를 회복했을 때 그린다. 저항·실패와 단순 수치 조회에는 성공 연출이 없다. 면역이 공격을 막은 경우에는 방어 연출을 낸다.
- 스택·MP·보호막은 실제 증가를 기준으로 표시한다. 기본 능력치와 상시 보너스는 계속 반짝이지 않는다.
- 같은 행동의 같은 위치·종류 보조 이벤트는 중복을 합친다. 보조 연출은 앞선 공격과 같은 박자를 사용해 후속 공격을 늦추지 않는다.
- 화면은 현재 시야 또는 재생 프레임에 기록된 시야를 사용한다. 대상이 보이지 않으면 그리지 않는다. 공격자나 궤적 중간 칸이 보이지 않으면 대상의 피격 효과만 남긴다.
- VFX는 게임 난수·행동 비용·피해량·회복량에 관여하지 않는다. 시뮬레이션이 집계할 피해 이벤트를 장식 이벤트가 밀어내지 않는다.

## 검증

`tests/effect_vfx.gd`는 의미별 도형, 수명과 타일 크기, 실패·중복 적용, 원소 부가 피해, 반사·흡혈·소환의 위치, 시야와 재생 프레임, 공격 간격, 실제 CanvasItem 그리기를 검증한다. GitHub Actions 테스트 목록에 포함한다.

로컬 검증: 전체 98개 테스트 통과. 이후 시야 밖 재생 대기·소비품·그리기 보완은 관련 14개 테스트를 다시 실행해 통과했다.
