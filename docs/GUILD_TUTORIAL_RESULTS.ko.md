# 길드 튜토리얼 구현 결과

- 구현일: 2026-09-10
- 규칙셋: `guild-tutorial-v1`
- 캠페인 ID: `GUILD_TUTORIAL_CAMPAIGN_V1`

## 구현 범위

- `sim/guild_tutorial_rules.gd`에 다섯 의뢰의 이벤트 기반 진행을 추가했다.
  - 이동 3회와 대각선 1회
  - 대기 방어 1회와 적 대상 유효 공격 1회
  - 주인공의 물약 회복 이벤트 1회
  - 1층 전리품 또는 거점 물자 획득 1회
  - 같은 원정에서 1층 전리품 획득 후 실제 귀환
- 상태는 `AVAILABLE → ACTIVE → COMPLETED → CLAIMED`로 파생한다. 수락 이전 이벤트, 실패 이동·공격, 주민 대상 공격은 진행시키지 않는다.
- `guild_tutorial_command()`를 세션에 연결했다. 수락·지원·보고는 마을에서만 가능하고, 보상 거래와 이벤트 기록을 한 트랜잭션으로 처리한다.
- 회복 물약 지원은 주인공에게 물약이 없을 때만 한 번 허용한다. 보상은 아이템 지급 이벤트와 골드 계산에 연결했다.
- 마을 생활 화면의 길드 메뉴와 레거시 길드 화면 모두에 게시판과 버튼을 추가했다. 메뉴 조작은 세계 시간을 소비하지 않는다.
- 저널 wire 검증과 저장 재생 분기에 `guild_tutorial` 명령을 추가했다.

- 수락·중복 수락 거절·마을 시간 불변·저널 wire·저장 재생 일치
- 물약 보유 시 지원 거절 및 인벤토리 불변
- 이동·방어/공격·원정 전리품/귀환의 canonical 이벤트 판정

화면 폭별 실제 렌더링과 모바일 터치 위치는 실행 환경에서 추가 확인이 필요하다.

## v2 보완 및 사용자 추가 의뢰 (2026-09-10)

- 기본 5개에 이능 결속·액티브 사용·무기 재제작·사지 부상·사지 치료를 더해 총 10개다. 상세 조건/보상은 개발서에 기록했다.
- 1층 전리품을 얻은 원정이면 심층에서 귀환해도 인정한다. 출발 없는 기록 및 시작 물건 버리기/재줍기는 인정하지 않는다. 생성된 몬스터 드롭의 인스턴스 출처와 원정 번호를 확인하며, 거점 자원은 실제 양수 획득을 인정한다.
- `guild_tutorial_index.gd`는 추가 이벤트만 처리하고 복원/rollback 때 재구성한다. 의뢰별 전체 기록 재탐색을 일반 HUD에서 제거했다.
- 지도 하단에 독립적인 44px 한 줄 HUD를 올렸다. 지도 레이아웃 크기는 바꾸지 않는다. 의뢰 선택, 작은 ‘의뢰’ 버튼으로 접기/펼치기, 터치로 목표·조작 도움말 열기가 가능하다. 전투 로그 세 줄을 덮지 않는다.
- 완료 전이 때 1회 알림을 표시한다. 불러온 완료 상태에는 알림을 재생하지 않는다. 사지 부상은 왼팔/오른팔/왼다리/오른다리 이름과 상태창 안내를 표시한다. 도움말은 무기 사용/이동 기능 저하와 HP 회복·부위 치료 차이, 절단 복구 불가를 설명한다.
- 실제 적 공격의 사지 손상 결과에 `guild.tutorial_limb_injured`, 실제 치유소의 손상 부위 치료에 `guild.tutorial_limb_treated`를 연결했다. 두 의뢰 중 하나라도 수락한 경우만 기록한다. NPC 자신의 부상·치료는 주인공 목표로 인정하지 않는다. 치료 의뢰는 수락 후 확인된 같은 사지를 치료해야 한다.
- 새 길드 명령 저널에 `guild-tutorial-v2`를 명시한다. 버전 없는 구 저널은 원래 판정/이벤트 버전으로 재생한다. 기존 보상·지원 수령 기록은 보존하고 중복 지급하지 않는다.
- 이능 제거 정책, 이능 드롭/결속 콘텐츠와 재제작 UI 자체는 다른 담당 범위다. 튜토리얼은 성공 이벤트에 연결하며 이 기능들을 새로 대체 구현하지 않는다. 성장·부상 의뢰도 원정 출발의 필수 조건이 아니다.
