## 환경 시험 사용법

일반 탐험 화면의 상단 `☰` 메뉴에서 환경 시험 기술을 선택하고, 주인공 기준
보이는 5칸 이내 바닥을 누른다. 기존 세 칸 스킬바를 늘리거나 기존 기술을 교체하지 않는다.
주인공에게만 임시 시험 기술이 파생 부여되며, 신규 저장 스키마는 없다.

| 시험 | 사용 순서 | 확인할 변화 |
|---|---|---|
| 결빙/해빙 | 물 생성 → 냉각 → 화염구 | 물 → 얼음 → 물, 얼음 바닥과 반응 이펙트 |
| 증발 | 물 생성 → 화염구 | 온도/잔여 물에 따라 수증기 발생 |
| 전도 | 물 생성 → 방전 | 전기 전파, 기존 전기 피해 경로 |
| 소화/점화 | 불에 물 생성 / 가연물에 화염구 | 소화 또는 점화 |

물 생성·냉각·방전은 MP 1, 화염구는 MP 3. 기본 시전 시간은 120이며 기존 속도 규칙을 따른다.
같은 메뉴 기술을 다시 선택하거나 Esc로 취소한다. 방전은 실제 위험한 기술이다.
냉각은 온도만 내리며 실제 결빙 판정은 기존 환경 틱에 맡긴다.
직접 상태 변경 치트가 아니라 정상 명령·MP·시간·이벤트·저장 재생 경로를 사용한다.

## 입력과 휴식 변경

- F1~F4를 파티 순서의 직접 조작 선택에 연결했다. 동료의 행동 대기시간/행동 불가 제한은 유지한다.
- 마우스 초상화 제스처는 버튼 객체 수명이 아닌 이름과 화면 좌표로 추적한다.
  HUD 재생성 시 `mouse_exited`가 길게 누르기를 취소하지 않도록 했다.
- 휴식 안내에 MP 현재/최대치를 추가했다.
- 회복이 장시간 진행되지 않으면 노출 평가를 통해 어느 동료의 물·불·가스 등이 원인인지 표시한다.
- 회복 수치/안전 조건/시간 계약은 바꾸지 않았다. 안전 500 시간단위 후 첫 회복,
  이후 300 시간단위 간격이며 파티원 한 명의 환경 위험도 파티 회복을 막는다.
