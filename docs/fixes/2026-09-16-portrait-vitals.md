# 파티 초상화 HP·MP·XP 바

- 현재 게임의 상단 파티 카드에 HP(빨강), MP(파랑), XP(금색) 세 바를 표시한다.
- 이미지 에셋을 추가하지 않고 코드로 배경·채움·테두리·수치를 그린다.
- 기존 68px 카드 높이와 선택/위험/행동예약 표시는 유지한다. 좁은 카드에서도 20px 초상화와 세 바를 표시하며, 전투불능 유예 시간 등 상태 문구는 하단에 남긴다.
- 넓은 바에서는 현재/최대 수치, 좁은 바에서는 종류와 현재 수치를 표시한다.
- XP는 각 캐릭터의 `member_progression`에 있는 `xp_current / xp_required`를 사용한다. 동료에게도 자신의 진행도 DTO를 제공한다.
- 검증: `tests/portrait_vitals_acceptance.gd`를 headless로 실행. 70–320px 카드 폭에서 바 경계·간격, 자원 비율, 0 분모, 캐릭터별 진행도 연결, 조회 전후 시뮬레이션 불변을 확인한다.
