# PARTY-RESCUE-01 구현 결과

2026-09-15. 기준 코드 `d58f2dc`(실행 protocol 포함). 기존 실행 세션에 queue를 접수할 수 없어, 사용자의 `ㄱㄱ` 승인에 따라 현재 세션에서 구현했다.

## 적용 동작

- 기본 게임의 새 회차에서 `party-rescue-v1` 활성화. HP 0이면 주인공과 현역 동료 모두 전투불능이며, 그 시점부터 **1000 world_time**의 유예를 갖는다. 기본 100 시간 행동을 기준으로 10턴이다. 이동 속도나 부축에 따라 실제 입력 횟수는 달라진다.
- 마감은 actor queue의 독립 항목이다. 100 단위에 맞지 않는 마감도 정확히 처리하며, 같은 시각의 안전 회복보다 사망이 먼저다. 주인공의 실제 사망이 회차를 종료한다. 동료 사망은 영구적이다.
- 쓰러진 주인공 대신 살아 있는 동료를 조작한다. 전원 전투불능 또는 회복 대기 중이면 위기 진행 버튼으로 100 시간을 진행한다. 렌더 시간은 유예를 소모하지 않는다.
- 인접한 동료를 부축하거나 내려놓는 데 각각 100 시간. 부축 이동은 기존 지형·속도 비용의 150%이며, 대상이 부축자의 이전 칸으로 따라온다. 점유는 분리되고 불법 이동은 거부된다. 부축 중 공격·기술은 사용할 수 없다.
- 공유 전투 시야에서 위협이 사라지고 대상의 환경 노출 위험이 없으면 HP 1로 회복한다. 카메라 이동이나 줌으로는 안전 판정을 바꿀 수 없다. 전원 전투불능일 때 빈 시야로 자동 회복하지 않도록 쓰러진 인물 주변도 관찰 범위에 포함한다.
- 유예를 보장하기 위해 전투불능 진입 때 출혈 상태를 종료하고, 추가 마무리 공격·출혈 사망을 막는다. 기존 신체 부상은 그대로 남는다. 환경 피해와 굶주림의 HP 0 경로에도 같은 유예를 적용한다.
- 부축 시작 → 실제 이동 → 안전 회복이 이어진 경우에만 실제 구조자를 기록한다. 자동 안전 회복에는 구조자를 붙이지 않는다. 부축자의 무력화·대상 회복/사망·강제 이동으로 인한 분리는 연결을 해제한다. 구조를 마치지 않은 상태의 귀환·층 이동·해고는 차단한다.

## 기억·대화·UI

- `RESCUED_BY` 기억을 기존 성격 기반 기억 강도와 동료 판단에 연결했다. 구조 대상의 구조자에 대한 관계 반응도 기록한다.
- 안전한 곳에서 두 인물이 인접하면 사건에 연결된 **1턴 휴식 대화**를 제공한다. 안심시키기와 상호 구조 약속을 선택할 수 있다. 자동 휴식 완료 팝업 대신 별도 휴식 행동으로 구현했다.
- 같은 구조 사건의 대화는 한 번만 가능하다. 약속은 이후 구조 후보 우선순위를 높이며, 같은 두 사람의 약속을 반복해 무한히 가산하지 않는다. 대화 문구는 동료의 성격에 따라 달라진다.
- 동료 AI는 인접한 전투불능 동료를 구조 후보로 삼으며, 부축 중에는 가까운 적과 거리를 벌리는 합법 이동을 선택한다. 먼 곳의 동료까지 찾아가는 장거리 구조 경로 계획은 이번 구현에 포함하지 않았다.
- 전투불능 패널에 잔여 턴·현재 조작 인물·부축/놓기·위기 진행을 표시한다. 초상화는 DOWNED와 DEAD를 구분하고 카드에도 잔여 턴을 표시한다. 새 전투불능 사건은 자동 탐험과 휴식을 중단한다.

## 저장·검증 구조

활성화 명령을 session journal에 남긴다. 기존 저장에는 활성화 사건이 없으므로 기존 규칙으로 재생한다. 부축 연결·구조 완료·소비한 대화·약속은 사건에서 재구성하며, 파생 조회 캐시는 저장하지 않는다. 위치의 정방향·역방향 검증, 생명주기 검증, 구조 사건의 인과 검증을 확장했다. 부축 이동 비용도 사건 당시의 연결 상태로 검증한다.

## 플레이 확인 방법

기본 게임에서 새 회차를 시작한다. 동료를 편성한 상태에서 HP 0인 인물이 생기면 전투불능 패널을 확인한다. 조작 가능한 인물을 쓰러진 동료 옆으로 이동시켜 부축하고, 적이 보이지 않는 안전한 곳으로 이동한다. 회복 후 인접한 상태에서 휴식 대화와 상호 구조 약속을 확인한다.

유예 길이·부축 비용·안전 회복 HP·구조 AI의 선택 강도는 첫 구현의 조정값이다. 이번 검증은 기능과 상태 일관성의 근거이며, 실제 플레이의 구조 난이도와 재미를 검증한 결과는 아니다.
