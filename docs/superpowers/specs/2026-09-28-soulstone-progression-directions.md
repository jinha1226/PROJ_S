# 영혼석 성장 방식 검토

작성일: 2026-09-28 · 상태: **논의 중, 방식 미확정**

이 문서는 영혼석을 어떻게 얻고 선택할지에 관한 대안을 남긴다. 구현 지시서가 아니며, [현재 6칸·영구 흡수 규칙](../../soulstones.ko.md)과 [공격·대기 전투 규칙](2026-09-27-attack-wait-soulstone-rules-design.md)을 아직 대체하지 않는다. 전투 효과 자체를 다시 액티브 기술이나 MP 소비 방식으로 바꾸자는 논의도 아니다.

## 출발점

현재 일반 원정은 12층, 캐릭터 최대 레벨 10, 영혼석 최대 6개다. 영혼석은 몬스터 등에서 무작위로 얻어 빈칸에 영구 흡수하고 교체할 수 없다. 효과는 주로 공격·대기·피격과 상태 연쇄로 자동 발동한다. 최근 [28개 조합 예비 실험](../../balance/build-combo-probe.md)에서는 세 개 안팎의 영혼석만으로도 전투 흐름을 만들 수 있었지만, 특정 조합의 후속 효과는 자동 전투에서 활용되지 않았다. 이 실험은 조합의 전투 가능성을 본 것이지 획득 운이나 실제 원정 완주율을 검증한 것은 아니다.

따라서 이번 논의의 질문은 영혼석 수를 더 줄일지가 아니다. **조합을 즐기는 플레이어에게는 탐색의 여지를 주면서, 조합을 덜 즐기는 플레이어에게는 성장 선택을 숙제로 만들지 않을 방법**이 필요하다. 기본 공격·대기·위치 판단은 어느 성장 방식에서도 재미있어야 한다.

## 검토한 방식

| 방식 | 획득과 선택 | 장점 | 부담·전제 |
| --- | --- | --- | --- |
| A. 현재 방식 | 무작위 드롭 → 빈 6칸 중 하나에 영구 흡수 | 몬스터 처치와 보상이 직접 연결되고 매 판의 재료가 다름 | 필요한 부위가 안 나오면 빌드가 막힘. 영구 선택 때문에 첫 드롭의 부담이 큼 |
| B. 직접 선택형 | 성장 보상으로 포인트를 받아 열린 영혼석 중 원하는 효과를 선택 | 원하는 조합을 계획할 수 있고 추천 빌드를 그대로 따라가기 쉬움 | 매 판 비슷한 빌드가 될 수 있음. 선택 가능한 목록을 그대로 펼치면 모바일에서 과밀함 |
| C. 역할군 유도 3택1 | 만렙 18을 가정하고 3레벨마다 역할군 방향을 정함. 매 레벨업에 관련 영혼석 후보 3개를 보여 주고 하나를 고름 | 빌드 방향을 정하면서도 카드 제안이 매 판 달라짐 | 1레벨에서 18레벨까지 17번의 선택이 생김. 6칸과 획득한 나머지 영혼석의 관계를 정해야 함. 순수 무작위 후보는 연계를 다시 운에 맡김 |
| D. 역할군 포인트 요구치 | 매 레벨업 역할군 하나에 포인트를 투자. 영혼석마다 해당 역할군의 누적 포인트 요구치를 둠 | 선택한 성장 방향으로 사용 가능 효과가 넓어짐. 필요한 조합을 계획할 수 있음 | 역할군 분류가 애매한 영혼석이 있고, 요구치·6칸·후반 재구성을 함께 설계해야 함 |

여기서 `역할군 포인트`는 **몬스터의 AI 역할이나 전투 태세**가 아니다. 영혼석 후보를 유도하거나 해금하는 성장 자원으로만 논의한다. 현재 영혼석의 공격형·방어형·연쇄형은 효과의 발동 역할이며, 성장 역할군과 같은 축으로 취급하지 않는다.

### B. 직접 선택형의 구체안

포인트를 얻을 때 현재 열린 카탈로그에서 영혼석 하나를 고른다. 추천 빌드는 다음 효과 3~4개를 순서대로 강조하고, 자유 선택 화면에서는 같은 카탈로그의 다른 효과를 고를 수 있다. 추천 빌드에 별도 수치나 전투 규칙을 주지 않는다. 몬스터 드롭이 필수 영혼석을 직접 공급하지 않는다면, 처치 보상에서 영혼석이 맡던 자리를 무엇으로 채울지도 함께 정해야 한다.

6칸을 영구 고정한 채 구역마다 효과를 개방하면, 초반에 채운 칸 때문에 4구역의 새 조합을 만들기 어렵다. 그래서 이 안을 채택한다면 안전한 장소에서 활성 영혼석을 재배치하는 방안도 함께 검토한다. 포인트 지급 층과 재배치 제한은 아직 정하지 않았다.

### C. 3레벨마다 역할군 방향 + 매 레벨 3택1

역할군 선택과 영혼석 카드 선택은 서로 다른 결정이다. 역할군 선택은 이후 카드 후보에 영향을 주고, 영혼석 선택은 실제로 쓸 효과를 정한다. 카드 세 장을 모두 순수 무작위로 뽑으면 특정 상태를 준비해야 하는 연쇄형이 혼자 남을 수 있다. 시험할 때는 `현재 조합과 이어지는 후보 1개 / 선택한 역할군 후보 1개 / 다른 방향 후보 1개`처럼 제안 규칙을 명시해야 한다. 어느 슬롯도 항상 같은 정답 카드를 강제해서는 안 된다.

매 레벨 영혼석 하나를 고른다면 만렙 18에서는 최대 17개를 얻지만 동시에 활성화할 수 있는 것은 6개다. 채택 전 다음 중 하나를 골라야 한다.

- 획득한 효과를 학습 목록에 남기고 안전한 장소에서 6개를 골라 사용한다.
- 여섯 칸이 찬 뒤에는 새 효과를 고를 때 기존 효과 하나를 교체한다. 버린 효과를 다시 고를 수 있는지도 정한다.
- 영혼석 카드는 매 레벨이 아닌 일부 성장 시점에만 제시한다. 이 경우 `매 레벨 3택1`이라는 원안과 선택 빈도가 달라진다.

### D. 매 레벨 역할군 포인트 + 영혼석 요구치

가장 최근에 논의한 안이다. 레벨업마다 역할군 포인트 1개를 원하는 방향에 투자한다. 예를 들어 `근접 3`이 필요한 효과는 근접 투자량이 3 이상일 때 사용 가능하다. 이 예시는 수치 제안이 아니다. **포인트는 해금 조건으로만 읽고, 영혼석을 고를 때 다시 소비하지 않는 방식**이 우선 검토안이다. 해금과 구매에 같은 포인트를 두 번 요구하면 선택 비용을 이해하기 어려워진다.

해금된 모든 영혼석을 동시에 쓰지는 않는다. 활성 영혼석은 최대 6개이며, 활성 칸이 레벨에 따라 언제 열리는지 정해야 한다. 시작부터 여섯 칸을 열어 둘 경우 낮은 요구치 효과 여러 개를 한꺼번에 장착할 수 있으므로 초반 전투도 다시 맞춰야 한다. 안전한 장소에서 영혼석을 바꿀 수 있는지와 역할군 포인트도 재분배할 수 있는지는 별개 결정이다.

처음에는 영혼석마다 **주 역할군 요구치 하나**를 붙이는 편이 읽기 쉽다. 지원·방어·근접 효과가 섞인 영혼석에 여러 역할군 요구치를 겹치기 시작하면 혼합 빌드의 비용이 급격히 올라간다. 현재의 역할군 구분과 영혼석별 귀속을 먼저 확인해야 하며, 요구치가 전투 효과의 공격형·방어형·연쇄형을 대신해서는 안 된다. D안을 고르면 무작위 3택1을 기본 해금 경로에 함께 넣지 않는 편이 낫다. 둘을 동시에 적용하면 요구치와 제안 운이 이중 관문이 된다.

## 어느 방식에도 적용할 화면 원칙

추천 빌드와 자유 조합은 **같은 영혼석·같은 효과 규칙**을 사용한다. 추천 빌드는 `약점 연사`, `전열 반격`, `화상 폭발`처럼 전투 흐름을 보여 주고 다음 선택을 강조하는 안내다. 자유 조합은 전체 카탈로그와 조건을 직접 살펴보는 보기 방식이다. 추천 경로가 필요한 영혼석의 획득을 보장하지 않는 A·C안에서는, 만들 수 없는 빌드를 완성 약속처럼 제시하지 않아야 한다.

기본 성장 화면은 현재 활성 효과, 다음에 달라질 효과, 선택 가능한 후보만 짧게 보여 준다. 전체 목록과 상세 조건은 별도 보기에서 연다. 이전 UI 결정에 따라 **레벨업 직후에는 로그만 남기고**, 카드 선택이나 재배치는 전투가 끝난 안전한 시점에 처리한다. 선택을 미룬 동안 전투가 어떻게 진행되는지도 각 안에서 정해야 한다.

## 방식 결정 전에 확인할 문제

1. **성장 속도:** 현재 만렙 10을 18로 바꾸면 12층 원정에서 17번의 레벨업을 어느 층에 배치할지 XP 곡선을 다시 잡아야 한다. 6칸이 너무 일찍 또는 최종 보스 직전에만 완성되지 않아야 한다.
2. **영혼석의 역할:** 드롭을 없앨 경우 몬스터 처치 보상과 부위·종족 정체성을 어떻게 남길지 정한다. 역할군 포인트·6칸과 별도의 강화 재화를 당연한 구성요소로 추가하지 않는다.
3. **후반 전환:** 4구역에서 처음 열리는 효과 3~4개짜리 조합이 실제로 가능한지 확인한다. 영구 포인트·영구 흡수와 구역별 해금을 모두 유지한다면 성립하지 않는 조합이 생긴다.
4. **NPC·동료:** 주인공에게 선택지를 늘려도 동료와 독립 NPC는 같은 영혼석 효과·칸 제한을 쓴다. 포인트 배분과 사용 효과를 어떻게 생성·성장시킬지 별도로 정한다.
5. **기존 데이터:** 현재 영혼석의 고정 능력치, 6칸 보너스, NPC 초기 영혼석, 도감, 드롭 카드, 전투 시험과 저장 데이터는 현행 규칙을 전제로 한다. 방식 확정 후 한 번에 변경 범위를 정한다.

## 현 시점의 판단

조합을 계획할 권한을 늘리려는 목적에는 **D안이 우선 검토 대상**이다. 매 레벨 한 번의 역할군 투자로 방향을 정하고, 요구치를 충족한 실제 효과를 6칸에 구성할 수 있다. C안은 매 판 다른 카드 제안 자체가 주된 재미인지 확인할 때 비교 대상으로 남긴다. B안은 선택의 무작위성을 가장 적게 만들지만 전체 카탈로그를 고르는 화면 부담을 해결해야 한다. 어떤 안도 아직 최종 결정이나 구현 승인으로 간주하지 않는다.

## 결정 (2026-09-28)

A안(무작위 드롭)을 유지하고 영구성만 푼다: 흡수는 영구(학습 목록), 빈 칸 배치는 언제든, **교체·빼기는 구역 보스 뒤 휴식처에서만(무제한)**, 흡수 전 영혼석은 가방에 최대 3개. B·C·D안과 만렙 18은 채택하지 않는다. 설계: [휴식처와 영혼석 재배치](2026-09-28-rest-stops-design.md).
