# 영혼석 전투 규칙 — 공격·대기·상태 연계

작성일: 2026-09-27 · 상태: 전투 시험 구현 / 원정 기본 적용 전

구현 결과와 실제 부위별 효과는 [공격·대기 실행 매핑](../../attack-wait-soulstones.ko.md)에 기록한다. 전투 시험에서 `attack_wait_v1`을 선택할 수 있으며 일반 원정은 아직 `legacy`다. 아래 수치는 최종 밸런스 확정이 아니다.

대기 방어·화상 폭발·중독 전이는 설계 원리를 보여 주는 예시다. 이 문서는 화염·독에 한정하지 않고 냉기·전기·출혈·정신·저주·축복·물·바람·방어·회복·소환·사령과 물리 공격의 조건까지 같은 문법으로 정리한다. 영혼석 자동 효과는 MP 없이 시험한다. 수치가 적힌 범위·감소율·한도는 시험 시작값이며 확정 밸런스가 아니다. 현재 실행 규칙은 [영혼석 문서](../../soulstones.ko.md), 적용 순서와 호환성은 [모바일 전투 계획](../plans/2026-09-27-mobile-combat-simplification.md)을 따른다.

## 1. 기본 원칙

- 주인공은 이동·공격·대기를 선택한다. 영혼석 기술을 매번 선택·조준하지 않는다.
- 공격·대기는 각각 기존 행동 시간을 소비한다. 자동 효과가 추가 턴을 소비하지 않는다. 대기도 적에게 행동 기회를 준다.
- 효과 역할은 **공격형 / 방어형 / 연쇄형**이다. 발동 시점은 공격 확정·적중·대기·피격·회피·막기·처치·소환 등이다. 대기 시 화상은 공격형, 대기 시 얼음 갑옷은 방어형이다. 역할과 발동 시점을 같은 분류로 취급하지 않는다.
- 영혼석 6개 영구 흡수, 레벨별 슬롯, 봉인·중복·교체 불가 계약을 유지한다. 아래 효과를 전부 기본 지급하지 않으며 각각 실제 영혼석 연결이 있어야 작동한다.
- 시작 구성에서 처음 제공하는 영혼석은 혼자서 작동하는 발동 효과다. 순수 연결 영혼석은 필요한 상태·조건이 흡수 전에 표시된다. 관련 상태가 아직 없어도 흡수는 가능하지만 효과가 이미 발동 가능한 것처럼 표시하지 않는다.
- 기본 자동 효과와 후속 연계에는 MP 비용이 없다. 강한 효과는 범위·발동 조건·개별 재사용·소환 한도로 조절한다. 모든 효과에 재사용을 일괄 부여하지 않는다.
- MP 능력치·아이템·기존 주문·저장 데이터 전체의 삭제는 이 규칙의 구현과 별도로 매핑한다. 기존 원정에서는 MP 규칙이 유지된다. 새 시험 구성은 MP 회복·최대 MP 보너스를 필수 보상으로 제공하지 않는다.
- 탱커·근접 딜러·원거리 딜러·캐스터·서포터는 도감 분류이며 숨은 효과가 아니다. 속성과 발동 계열을 섞어 흡수할 수 있다.
- 몬스터의 대표 효과는 기존 규칙을 유지한다. 주인공·동료·NPC는 새 인물 규칙을 사용하고, 적대 NPC도 몬스터로 변환하지 않는다.

## 2. 전체 계열의 공격형·방어형·연쇄형

속성은 모두 새 피해 타입이라는 뜻이 아니다. 기존 피해 타입 `fire / ice / air / poison / will / physical`을 재사용하며 출혈은 물리 지속 피해다. 저주·축복·물·바람·소환·사령은 상태·지원·행동 계열이다. 전기의 내부 ID `air`는 유지한다. 의미가 다른 전하 표식·축복·사령 낙인은 새 시험 프로필에서 구현한 상태이며 기존 원정에는 자동 지급하지 않는다.

각 칸의 효과는 별도 영혼석 후보다. 한 영혼석이 한 계열의 공격·방어·연쇄를 모두 지급하지 않는다. 여섯 칸을 공격 2·방어 2·연쇄 2로 강제하지 않으며 공격 집중·방어 집중·혼합 구성을 허용한다. 역할·속성 이름만으로 표의 효과를 자동 부여하지 않는다.

- 공격형: 피해·상태 부여·공격 준비·소환수 공격에 기여한다.
- 방어형: 피해 감소·저항·회피·회복·보호·접근한 적 견제에 기여한다. 모든 방어형에 피해 감소를 동시에 주지 않는다.
- 연쇄형: 이미 존재하거나 방금 부여한 상태·성공한 행동을 다음 결과에 연결한다.

범위·확률·한도는 시험 시작값이다. 방어 태세의 얼음은 피해를 버티고, 화염은 근접 적에게 즉시 반응하고, 독·출혈은 공격자에게 지속 피해를 남기고, 전기는 일정 확률로 공격자의 다음 행동을 막는다. 같은 방어 수치에 색만 달리하지 않는다.

기존 세부 유형 17개의 설계 범위도 빠뜨리지 않는다. 다음 대응은 콘텐츠를 배치하는 기준이며 소분류 이름만으로 효과를 부여하는 코드 규칙이 아니다.

추가타는 동일 기본 행동 안에서 유한한 횟수만 수행한다. 연타·속사의 추가타도 명중 판정이 필요하며 자신의 연타·속사를 다시 발동하지 않는다. 출혈·화상 같은 부여를 추가타에 허용할지는 명시적 규칙으로 정하고 기본값은 기본 적중만이다. 순수 소환수 집중 효과는 소환수를 이미 갖춘 연결 영혼석이며 단독 시작 보상으로 제공하지 않는다.

### 기본 효과의 발동 계약 예시

효과 이름과 ID는 제안이며 기존 부위에 이미 연결된 것으로 취급하지 않는다. 각 행은 별도의 영혼석 효과다. 동일 속성의 공격형·대기형을 한 영혼석에서 모두 주는 것을 기본으로 삼지 않는다.

| 독 묻은 공격 | 기본 공격 적중 | 대상에게 중독 적용 시도 | 해당 공격 대상, 기존 상태 저항 |
| 독 안개 | 의도적 대기 | 자신 주변의 유효 적에게 중독 적용 시도 | 거리 4 이내, 유효 대상 모두 |
| 독 전이 | 중독된 대상에 기본 공격 적중 | 주변 유효 적에게 중독 전이 시도 | 대상 주변 거리 1, 기본 공격당 1회 |
| 방어태세 | 의도적 대기 | 다음 자신의 행동까지 받는 피해 감소 | 시험값 20%, 갱신만 가능, 누적 강화 없음 |
| 시선 끌기 | 연속 의도적 대기 | 자신을 인식한 적의 대상 선택에서 위협도 증가 | 최대 3단계, 공격·이동 등 다른 행동 시 초기화 |

거리 계산은 기존 대각선 타일 거리 정의를 재사용한다. '유효 적'은 적대 관계·생존·거리·기술의 공격 경로를 만족하는 인물이다. 주인공의 공격성 자동 효과는 현재 시야도 만족해야 한다. 벽 뒤에 보이는 적에게 벽을 관통해 적용하지 않는다. NPC는 자기 인지·시야를 사용하며 주인공 화면에 보이는지와 무관하게 행동한다.

광역 대상은 안정적인 인물 ID 순으로 처리한다. 불의 장막·독 안개는 사용자 예시대로 초기 시험에서 범위 내 모든 유효 적을 대상으로 한다. 대상 수를 줄이는 실험은 별도 데이터로 기록하며 표시 없이 일부 대상만 고르지 않는다.

## 3. 계열별 상세 규칙

### 화염 — 상태를 건 뒤 공격해서 터뜨린다

```text
대기 → 주변 3칸 화상
기본 공격 적중 → 화상 확인 → 대상 주변 1칸 화염 폭발
```

- 화상은 지속 피해이며 폭발은 즉시 피해다. 폭발은 적이 모였을 때 가치가 커진다.
- '불붙이는 공격 + 화염 폭발'도 조합할 수 있다. 같은 기본 적중에서 새 화상을 건 뒤 폭발까지 연결한다. 두 영혼석의 연결을 느끼기 위해 첫 공격부터 연계가 가능하다.
- 폭발 자체는 기본 공격 적중 이벤트를 다시 만들지 않는다. 초기 시험의 폭발은 화상을 새로 부여하지 않는다. 폭발에서 다시 폭발이 반복되지 않는다.
- 이미 화상인 적을 새 기본 공격으로 적중하면 다시 폭발할 수 있다. 화상이 새로 걸린 순간에만 한 번 터지는 규칙이 아니다.
- 다른 동료가 건 화상도 조건을 만족한다. 폭발 피해의 소유자는 폭발 영혼석을 가진 공격자다. 기존 화상의 지속 피해 소유권은 유지한다.

### 독 — 상태를 퍼뜨리고 다른 적을 상대한다

```text
대기 → 주변 4칸 중독
기본 공격 적중 → 중독 확인 → 대상 주변 1칸으로 전이
```

- 중독은 지속 피해이며 전이는 새 즉시 폭발 피해를 주지 않는다. 상태를 퍼뜨린 뒤 이동·다른 대상 공격을 선택할 수 있다.
- '독 묻은 공격 + 독 전이'는 같은 기본 적중에서 중독 적용 뒤 전이까지 연결한다.
- 전이 범위는 공격자 주변이 아니라 공격 대상 주변이다. 대기 안개의 가장자리 적을 공격하면 안개 범위 밖의 인접 적에게도 전이할 수 있다.
- 전이는 원래 대상의 남은 지속시간을 복사한다. 단순 전이만으로 남은 시간을 최대값으로 계속 초기화하지 않는다.
- 전이된 중독이 즉시 다른 적으로 재전이하지 않는다. 이후 새로운 기본 공격으로 적중한 경우에는 다시 전이할 수 있다.
- 이미 중독된 적은 더 긴 남은 지속시간을 유지한다. 같은 중독 상태가 복제되어 지속 피해 횟수가 늘어나지 않는다. 기존 상태를 단순 갱신할 때 소유자를 빼앗지 않는다. 새로 전이된 상태의 소유자는 전이 효과를 실행한 공격자다.

화상·중독의 기본 지속시간·주기·피해는 기존 상태 처리를 시작점으로 실측한다. 반복 적용은 지속시간 갱신이며 기본 피해의 무한 중첩이 아니다. 속성 저항·상태 면역을 유지한다. 두 효과의 피해 수치는 첫 조우의 행동 수와 기여를 측정한 뒤 정한다.

### 3.3 냉기 — 느리게 만들고 얼리거나 깨뜨린다

- 얼음 갑옷의 방어력 보정과 둔화·빙결 부여는 별도 영혼석이다. 방어 영혼석만으로 적이 자동 빙결하지 않는다. 시작 상태는 `slow` 둔화이며 기존 속도 보정을 사용한다. 둔화를 여러 번 부여해 속도를 계속 낮추지 않는다.
- 둔화 적중 영혼석과 빙결 연결 영혼석이 있으면 같은 기본 적중에서 둔화 → 짧은 `freeze` 빙결이 가능하다.
- 대기형은 주변 3칸 유효 적의 둔화다. 광역 둔화만으로 모든 적을 즉시 빙결시키지 않는다. 특정 적을 기본 공격으로 적중해야 빙결 연결이 발생한다.
- 파쇄 영혼석은 이미 빙결된 대상의 직접 기본 적중에서 추가 피해를 주고 빙결을 해제한다. 이번 적중의 연결 단계에서 막 만들어진 빙결은 별도의 다음 기본 적중에서 파쇄한다. 빙결 연결과 파쇄를 한 단계에서 무조건 실행해 제어 효과를 없애지 않는다.
- 빙결·기절 등 행동 봉쇄는 공유 재적용 제한을 둔다. 봉쇄가 끝난 대상이 정상 행동을 한 번 수행하기 전까지 같은 그룹의 봉쇄를 새로 적용하거나 연장하지 않는다. 강제 건너뛰기는 정상 행동으로 세지 않는다. 영혼석·동료 수를 늘려 무한히 행동을 빼앗지 않는다.
- 보스·저항·면역 처리는 기존 기준에서 시작하며 차이는 데이터에 명시한다. 범위 둔화와 단일 빙결의 실제 적 행동 감소를 각각 측정한다.

### 3.4 전기 — 한 대상을 잡아 연쇄한다

- 전기막의 확률적 마비와 공격형 전하·연쇄 번개는 별도 효과다. 전하 표식은 상태 조건용 신규 표식이며 기본적으로 행동을 막거나 기존 `marked` 취약 보정을 자동 부여하지 않는다.
- 적중형은 대상에 표식을 붙인다. 대기형은 4칸 내 가장 가까운 유효 적 1명에 표식과 작은 전기 피해를 준다. 단독 영혼석도 전투 효과가 있다.
- 연쇄 영혼석은 전하 대상 기본 적중에서 대상과 주변 3칸의 다른 적에게 번개를 이어 간다. 시작 대상을 포함해 최대 3명이며 가까운 대상·안정적인 인물 ID 순으로 고른다.
- 한 연쇄에서 같은 인물을 두 번 맞히지 않는다. 각 도약은 직전 대상에서 경로를 확인한다. 연쇄 피해는 자신에게 새 전하·새 기본 적중·새 연쇄 시작을 부여하지 않는다.
- 표식은 연쇄 실행 때 소비한다. 이미 그 행동에서 실행 가능한 것으로 확정된 한 번의 연쇄를 진행하고, 표시 순서 때문에 같은 표식을 여러 번 소비하지 않는다.
- 처치 전이는 대상 주변의 가장 가까운 적 1명에게 표식을 넘긴다. 표식 전이 자체는 피해나 연쇄 번개를 만들지 않는다. 다른 기본 공격이나 명시적인 후속 이벤트가 있어야 다시 연결된다.
- 화염은 대상 주변의 밀집, 전기는 도약 가능한 적의 배치를 활용한다. 전기의 기본 정체성을 매 적중 기절로 두지 않는다.

### 3.5 저주 — 공격력을 낮추고 취약하게 만든다

- 저주 문양은 피격 반응의 방어형, 능동적인 약화 부여는 공격형이다. 기본 저주는 `weak` 약화다. 공격형은 기본 적중 대상, 대기형은 주변 3칸의 가까운 적 최대 2명에게 적용한다.
- 약화 대상 기본 적중에 연결 영혼석이 있으면 `vulnerable` 취약을 적용한다. 상태의 의지 저항·면역을 유지하고 여러 약화가 공격력을 계속 곱해서 낮추지 않는다.
- 마무리 영혼석은 약화·취약 상태의 적을 자신이 처치했을 때 인접 적 1명에게 약화를 전이한다. 여러 유해 상태를 설명 없이 전부 복제하지 않는다.
- 확장 후보는 속박(`bind`), 왜곡(`distort`), 유해 상태 지속 연장이다. 각각 연결 영혼석의 실제 효과로 부여하며 저주라는 분류만으로 전부 적용하지 않는다.
- 상태 개수에 비례하는 추가 피해를 넣을 때에는 인정하는 저주 목록과 상한을 명시한다. 출혈·화상 등 모든 상태를 무제한 합산하지 않는다.
- 혼란·지배를 묶어 숨은 진영 변경을 만들지 않는다. 기존 지배 주문을 새 연결로 옮길 때에는 지속·해제·관계 처리 계약을 먼저 정한다.

### 3.6 축복 — 자신을 강화하고 아군을 보호한다

- 축복은 유익 효과의 연결 조건이다. 공격형은 다음 기본 공격 강화, 방어형은 신성 보호이며 실제 보정·보호가 적용돼야 한다. 표시용 표식만 붙여 단독 영혼석이 아무 효과도 없게 만들지 않는다. 신규 축복 식별 상태와 실제 보정의 지속·소비를 함께 기록한다.
- 공격형은 기본 적중 후 자신에게 다음 공격의 축복을 준다. 이번 기본 피해를 소급 강화하지 않는다. 방어형은 대기로 자신과 주변 2칸의 실제 아군에게 신성 보호를 준비한다. 신성 보호도 축복 연결 조건을 만족하지만 숨은 공격 강화까지 추가하지 않는다.
- 실제 아군은 동료·전투 중 우호 관계가 확인된 NPC·자기 편 소환수다. 단순히 몬스터가 아니라는 이유로 중립 NPC를 아군으로 취급하지 않는다.
- 보호 연결은 축복 상태에서 기본 적중할 때 자신에게 다음 적대 직접 공격의 피해를 줄이는 보호 1회를 준다. 보호는 1회만 준비되고 반복 적중은 갱신이다. 보호 준비가 치유·축복을 다시 발동하지 않는다.
- 치유 마무리는 축복 중 자신이 실제 적을 처치했을 때 가까운 부상 아군 1명을 회복한다. 유효 치유량이 0이면 치유 성공 반응을 만들지 않는다.
- 신성 보호와 일반 방어태세는 다른 효과다. 서로의 피해 감소를 중복 계산하지 않고 기존 방어 계산의 각 명시적 보정을 한 번만 적용한다. 공격형 축복 보정은 다음 합법적인 기본 공격에서 한 번 보정·소비한다.
- 유익 상태의 신규 적용·갱신은 구분한다. 현재 유해 상태에 집중된 상태 이벤트를 그대로 '축복 성공'으로 간주하지 않고 실제 유익 효과 성공을 읽는 이벤트를 보강한다.

### 3.7 출혈 — 계속 공격하고 처치로 회복한다

- 적중형은 기존 `bleed` 출혈 적용이다. 대기형은 다음 기본 공격의 출혈 피해·지속 강화 준비이며 새로운 원거리 출혈 장판을 기본으로 만들지 않는다.
- 출혈 연결은 출혈 대상 기본 적중에 유한한 추가타다. 같은 적중에서 새 출혈을 건 뒤 추가타까지 가능하다. 추가타가 자신의 추가타나 새 기본 적중을 생성하지 않는다.
- 처치 회복은 실제 출혈 대상의 자기 처치·자기 출혈 지속 피해 처치에만 반응한다. 동료가 마지막 타격을 했다면 별도로 아군 처치 반응 영혼석이 없는 한 자기 처치 회복은 없다.
- 부여·지속 강화·추가타·처치 회복은 별도의 역할이다. 한 영혼석으로 모든 효과를 얻지 않는다.

### 3.8 정신 — 판단을 흐리고 정신 피해로 연결한다

- 정신 장벽은 의지 저항의 방어형이고 혼란은 공격형 부여다. 시작 상태는 기존 `confuse` 혼란이다. 공격형은 적중 대상, 대기형은 4칸 내 가까운 적 1명에게 적용을 시도한다.
- 연결은 혼란 대상 기본 적중의 추가 `will` 피해다. 물리 명중과 혼란 저항을 각각 확인하며 추가 정신 피해가 새 기본 적중이나 새 혼란을 반복 부여하지 않는다.
- 마무리는 혼란 대상 자기 처치 시 다음 기본 공격의 정신 피해 강화 1회를 준비한다. 축적하지 않고 준비량을 갱신한다.
- 기존 혼란에는 독립적인 AI 판단 방해 처리가 없으므로 새 프로필에서 부여한 혼란은 물리 공격 명중을 20%p 낮춘다. 행동 건너뛰기·아군 공격·NPC 적대 전환은 만들지 않는다. 기존 프로필 혼란은 유지한다. 정신·저주는 공통 의지 저항을 사용하되 서로 다른 역할로 표시한다.

### 3.9 물·바람 — 지형과 위치를 연결한다

- 물막은 화염 저항의 방어 효과이며 젖음은 공격·연결 상태다. 물막만으로 주변 적이 자동으로 젖지 않는다. 물은 새로운 물 피해 타입을 추가하지 않고 기존 `wet` 젖음과 물 지형을 사용한다. 적중형은 대상의 젖음, 대기형은 주변 3칸 유효 적의 젖음이다.
- 젖음은 혼자서 피해를 주지 않는 연결 상태이므로 시작 지급용 단독 공격 영혼석으로 사용하지 않는다. 물결 밀치기·정화 등 독립 효과를 가진 부위 또는 냉기·전기와 연결한 구성에서 제공한다. 전투 도중 젖음이 풀렸으면 과거 표식만으로 연계하지 않는다.
- 바람은 돌풍·밀치기·회피 준비다. 대기 시 돌풍 준비 1회, 다음 기본 적중에 대상 뒤 방향으로 밀친다. 기존 이동 후 첫 공격 조건도 재사용한다.
- 밀치기는 실제 비어 있는 이동 가능한 칸만 사용한다. 벽·인물 때문에 움직이지 못한 경우의 충돌 효과는 별도 영혼석이 있을 때만 준다. 공간을 통과하거나 밀침 없이 충돌 피해를 반복하지 않는다.
- 바람의 실제 밀침 후 추가타는 같은 대상에 한 번만 연결되며 새 밀치기·새 기본 적중을 재시작하지 않는다.

### 3.10 소환·사령 — 실제 인물을 생성하고 행동을 연결한다

- 공격 소환수와 호위 소환수는 데이터의 실제 소환 종류·전술로 구분한다. 대기 소환은 실제 빈 인접 칸에 소환수 1명을 생성한다. 기존 전체 소환 한도와 지속시간을 사용하고, 칸·한도가 없으면 실패한 소환의 재사용을 시작하지 않는다.
- 소환 준비에 개별 재사용을 두어 여러 대기형 소환 영혼석이 한 행동에 무제한 인물을 만들지 않는다. 소환 능력을 얻었다고 몬스터·동료·NPC 인원 제한을 모두 같은 값으로 바꾸지 않는다.
- 기본 적중의 집중 표시는 주인의 소환수에게 해당 대상의 우선순위만 준다. 공격 경로·실제 사거리·소환수 다음 행동 시간을 무시하는 즉시 무료 공격 명령이 아니다.
- 결속은 주인과 자기 소환수가 같은 대상을 실제 적중한 뒤 소환수의 다음 공격 강화 1회다. 단순 목표 지정만으로 성공 처리하지 않으며 소환수 공격이 주인의 기본 적중 효과를 다시 실행하지 않는다.
- 사령 낙인(`death_mark`)은 신규 상태다. 첫 영혼석에는 낙인 대상에 대한 작은 추가 정신 피해처럼 독립 효과를 함께 주고, 해골 생성 연계는 별도 영혼석에 둔다.
- 낙인 사망의 해골 생성은 소환 한도·공간·재사용을 지킨다. 사망 한 건을 자신·동료·지속 피해의 별도 이벤트로 중복 생성하지 않는다. 몬스터 사체만 대상으로 하며 NPC·동료 사망을 자동 수확하는 기본 규칙은 없다.
- 해골 사망 반응은 자기 해골이 적의 공격으로 죽었을 때 주변 1칸 유효 적에게 약한 저주 또는 정신 피해를 준다. 자연 만료·층 이동 정리·사용자 소환 해제로 죽음 연쇄를 농사짓지 않는다.
- 소환수는 주인의 영혼석 전체를 복제하지 않는다. 명시적인 소환수 강화·반응만 상속하고 소환수 처치 기여의 원인·주인 소유권을 보존한다.

### 3.11 회복·재생 — 실제 부상에 반응한다

- 공격 회복은 실제 적에게 준 유효 HP 피해에 비례하며 자기 회복 상한을 가진다. 아군·소환수 공격, 과잉 피해, 피해 0, UI 예측에는 회복이 없다.
- 대기 치유는 자신·인접 부상 아군 중 HP 비율이 가장 낮은 1명을 대상으로 한다. 초기 시험은 HP 70% 이하·유효 적대 조우·조우당 2회로 제한한다. MP 대신 이 효과만의 사용 횟수이며 아이콘에서 남은 횟수를 확인한다. 소환수가 쓰러질 때마다 횟수를 리셋하지 않는다.
- 조우당 횟수는 적이 잠깐 시야 밖으로 나갔다고 재충전하지 않는다. 기존 조우 종료·새 조우 판정으로만 복원하고, 같은 적을 재인식해서 회복을 농사짓지 않는지 검사한다.
- 재생은 실제 적에게 받은 직접 피해 뒤 짧은 회복 구간을 준비한다. 같은 피해 이벤트로 재생을 여러 번 쌓지 않고, 자기 피해·환경 피해·아군 피해로 무제한 준비하지 않는다.
- 대기 재생은 유효 부상과 적대 조우에서만 시작·갱신하고 개별 재사용을 가진다. 재사용 없이 무한히 완전 회복하는 일반 패시브로 시작하지 않는다.
- 유효 치유 후 보호막은 별도 연결 효과다. 보호막 적용이 다시 치유 성공 이벤트를 생성하지 않는다. 정화는 실제로 존재하는 해로운 상태 1개를 안정적인 우선순위로 제거하며 상태가 없으면 아무 반응도 만들지 않는다.
- 일반 공격·대기·기본 원소에는 조우당 횟수 제한을 붙이지 않는다. 횟수는 원정의 누적 피해를 지워버릴 수 있는 강한 회복 효과만의 제약이다.

### 준비 효과의 공통 규칙

대기 후 다음 공격의 연타·강타·출혈·돌풍 준비는 1회이며 반복 대기는 갱신이다. 합법적인 기본 공격을 실행하면 빗나가도 준비를 소비하고, 거부된 입력·접근 이동에는 소비하지 않는다. 이동 초기화는 집중 조준처럼 명시된 효과에만 적용한다. 조준은 대기당 +1, 최대 3이며 다음 합법적인 기본 원거리 공격에서 한 번 보정·소비한다. 일반 근접 공격 등 다른 공격으로 조준을 계속 보존하는 예외를 만들지 않는다.

반사·반격은 실제 적대 직접 피격·회피·막기 성공을 조건으로 한다. 반사 피해가 새로운 반사·반격을 만들지 않으며 환경·자기 피해에는 발동하지 않는다. 추가 반사·급소·광폭 영혼석의 강화도 행동당 한도와 지속·소비를 데이터로 명시하고 준비만으로 새로운 기본 행동을 생성하지 않는다.

## 4. 같은 행동의 처리 순서

새 인물 프로필은 다음 순서를 고정한다. 기존 원정의 효과 순서를 일괄 변경하지 않는다.

1. 합법적인 기본 공격을 확정하고 기존 명중·기본 피해를 계산한다. 빗나가면 적중형 부여·연계는 없다.
2. 생존한 대상에게 적중형 상태 부여 효과를 먼저 처리한다. 부여 순서는 영혼석 흡수 순서나 UI 순서로 바뀌지 않는다.
3. 부여 후 실제 상태를 읽어 화염 폭발·독 전이 같은 연계를 처리한다. 상태 면역으로 부여되지 않았다면 없는 상태의 연계는 발동하지 않는다.
4. 대상이 기본 피해로 사망했다면 죽기 직전 상태·위치를 읽는다. 이미 화상·중독 상태였으면 해당 연계가 가능하다. 사체에 새 상태를 부여하여 조건을 만드는 것은 불가하다.
5. 후속 피해·상태·처치·명시적인 사망 반응을 제한된 큐에서 처리하고 전투 종료를 확정한다. 마지막 적의 사망으로 정당한 연계·처치 회복이 누락되지 않게 한다.

대기 광역은 대기 이벤트에 연결된 효과만 시작한다. 화상·중독을 여러 대상에게 적용했다고 기본 공격 적중 이벤트를 발행하지 않는다. 따라서 대기 한 번으로 불의 장막과 화염 폭발이 동시에 자동 실행되는 것은 아니다.

후속 효과마다 원인 행동·발동 주체·규칙·대상·상태/피해 소유자를 기록한다. 규칙당 기본 행동당 1회 발동을 기본으로 하고, 광역의 여러 대상 처리는 한 번의 발동 안에서 모두 수행한다. 유한한 예외는 데이터에 명시한다. 모든 추가 피해의 반응을 차단하지는 않되 허용한 후속 이벤트만 전달한다. 정상 연계를 막는 낮은 전역 깊이 제한을 밸런스 수단으로 쓰지 않는다.

## 5. 공통 방어 규칙·방어태세·위협도

### 원소별 방어의 공통 규칙

- 방어는 해당 방어 영혼석이 있어야 작동한다. 공격형 화염 영혼석을 흡수했다고 화염막도 자동 지급하지 않는다.
- 대기로 준비한 갑옷·저항·자세는 다음 자기 행동 시작에 끝난다. 다시 대기하면 갱신할 수 있지만 동일 보정을 무한 누적하지 않는다.
- '자기 행동 시작'은 합법적으로 확정한 행동이다. 대상 없음·이동 불가 등 거부된 입력만으로 방어 준비를 지우지 않는다. 다운·사망·봉인은 준비를 정지·해제하고 강제 시간 경과는 새 방어 준비를 지급하지 않는다.
- 화염막·독막·가시·전기막·저주 문양의 반응은 대기로 준비한 뒤 실제 적대 직접 피격이 있어야 한다. 지속 피해·환경·자기·아군·반사 피해에는 발동하지 않는다.
- 이 규칙의 피격은 피해 감소 후 실제 HP 손실이 발생한 직접 공격이다. 완전 막기·회피는 해당 성공 반응으로만 처리하며 피격으로 중복 세지 않는다. 전기막·저주 문양은 공격자가 주변 3칸의 유효 대상일 때만 시도한다.
- 각 반응 준비는 다음 정상 자기 행동까지 최대 1회다. 여러 적의 행동마다 준비를 새로 열지 않으며, 다음 자기 행동 시작에 만료한다. 조건과 경로를 충족한 피격에 시도하면 준비를 소비하고 확률 실패로도 소비한다. 대기로 다시 준비할 수 있다.
- 공격자가 죽었거나 범위·시야·공격 경로를 만족하지 않으면 해당 대상 반응은 없다. 화염막은 피격 순간 인물 주변의 유효 적에만 피해를 주며 범위 밖 공격자에게 자동 피해를 주지 않는다.
- 전기막 마비는 `stun` 계열의 짧은 행동 봉쇄다. 시험 확률 15%는 직접 유효 피격의 시도에만 RNG를 사용하고 UI·AI 예측은 기대값을 읽는다. 냉기와 공유하는 재봉쇄 제한·저항·면역을 지킨다.
- 피격 후 마비·약화·밀치기 반응은 이미 받은 피해나 확정된 이번 공격을 소급 취소하지 않는다. 이후 정상 행동·대상 선택에 반영한다.
- 얼음 갑옷은 방어력 보정이며 물막은 화염 저항, 정신 장벽은 의지 저항이다. 서로 다른 보정을 전부 일괄 피해 감소로 바꾸지 않는다. 같은 통계 보정의 합산·상한은 기존 전투 계산으로 한 번 적용한다.
- 바람막·회피 준비는 기존 명중/회피 판정에 보정하는 것이며 반드시 회피하는 무적 상태가 아니다. 회피 성공이 없으면 반격 연결도 없다.
- 신성 보호는 다음 적대 직접 피격의 보호 1회다. 준비된 동일 보호는 누적하지 않고 갱신한다. 유익 상태의 성공은 실제 보호 준비와 구분해 기록한다.
- 호위 소환수는 공격 소환수와 기존 전체 한도를 공유한다. 실제 인접 아군을 기존 엄호·피해 분담 경로로 보호하며 독립된 무제한 보호막을 지급하지 않는다. 사령 분담은 자기 해골 1명에게만 유효하며 같은 피해를 재분담하는 순환을 막는다.
- 반사·반격·방어막의 피해가 새 방어 반응을 다시 시작하지 않는다. 실제 처치 같은 명시적 후속 연쇄는 허용한다.

### 방어태세와 시선 끌기

두 효과는 서로 다른 영혼석이다. 방어태세만 있어도 버틸 수 있고 시선 끌기를 더하면 파티의 다른 인물을 보호하는 구성이 된다.

### 방어태세

- 대기 확정 시 자세를 얻고, 다음 자신의 행동을 시작할 때 기존 자세가 끝난다. 다시 대기하면 새 자세로 갱신한다.
- 공격·이동·자리 교환·아이템 사용을 선택하면 방어태세를 끝낸 뒤 그 행동을 처리한다. 방어와 공격을 동시에 기본 보상으로 주지 않는다.
- 연속 대기는 효과를 연장할 뿐 피해 감소를 계속 쌓지 않는다. 방어태세 20%가 대기 세 번으로 60%가 되지 않는다.
- 기본 시험은 인물에게 귀속된 직접 피격 피해를 줄인다. 기존 화상·중독·출혈의 지속 피해나 환경 피해는 줄이지 않는다. 다른 피해 감소와의 합산은 기존 방어 계산을 따르며 중복 적용하지 않는다.
- 기절·사망·다운·봉인 후 자세가 유효한 것처럼 남지 않는다. 강제 시간 경과는 새 자세를 주거나 기존 자세의 만료를 무한 연장하지 않는다.

### 시선 끌기

- 인물의 연속 의도적 대기 횟수에 따라 1·2·3단계로 올라간다. 대기한 인물이 자신의 행동을 기준으로 세며 다른 인물의 턴은 연속성을 끊지 않는다.
- 공격·이동·자리 교환·수동 기술·아이템·구조 등 다른 행동이나 강제 행동 건너뛰기는 연속성을 끊는다. 다운·사망·봉인·조우 종료도 초기화한다.
- 이미 그 인물을 인식한 적이 유효한 여러 대상을 비교할 때 위협도 점수를 더한다. 전 층의 적을 끌어들이거나 시야 밖에 새로 위치를 알려주지 않는다.
- 단계별 보정은 기존 대상 점수 규모에 맞춰 실측한다. 거리·공격 가능 여부·성격·전술·위기 판단을 무시하는 강제 도발이 아니다. 궁수나 술사가 무조건 근접하도록 만들지 않는다.
- 이미 확정·예고된 공격을 중간에 다른 대상에게 돌리지 않는다. 다음 정상 대상 선택 시점부터 반영한다.
- 솔로에서는 공격 불가능한 적을 강제로 접근시키는 보너스가 아니다. 파티에서 대상 집중을 유도하는 효과이며 별도의 경험치·전리품 보상을 주지 않는다.

방어를 유지할수록 더 많은 공격을 받아낼 가능성이 커지는 선택을 만든다. 혼합 구성에서는 대기 방어와 화상·중독 부여가 같은 행동에서 함께 작동할 수 있다. 인식 밖 적 호출이나 무한 피해 감소로 이를 표현하지 않는다.

## 6. 서로 다른 계열의 연결

아래는 교차 연결 영혼석 후보다. 상태 두 개가 있다는 이유만으로 전부 자동 발동하는 숨은 레시피가 아니다. 해당 연결 영혼석·조건이 실제로 있어야 실행한다. 부위·연결 수치는 매핑 단계에서 정하고, 흡수 전 필요한 상태와 결과를 보여 준다.

| 연결 | 명시적 발동 규칙 | 다른 조합과 구별할 결과 |
| --- | --- | --- |
| 물 + 전기 | 젖은 대상을 전기 계열로 직접 적중 | 기본 연쇄의 제한된 도약 수·유효 범위 강화. 자동 무한 기절은 없음 |
| 물 + 냉기 | 젖은 둔화 대상을 기본 적중 | 빙결 연결 강화. 공유 행동 봉쇄 제한은 그대로 유지 |
| 화염 + 독 | 화상·중독 대상 기본 적중 | 대상 주변 1칸에 작은 독성 폭발. 상태를 자동 삭제하지 않음 |
| 화염 + 출혈 | 화상·출혈 대상 기본 적중 | 해당 대상에 작은 즉시 추가 피해. 남은 출혈 전체를 매번 재계산해 무한 피해로 바꾸지 않음 |
| 냉기 + 강타 | 빙결 대상 강타 기본 적중 | 빙결을 소비하는 파쇄를 강화. 일반 파쇄와 추가 피해를 두 번 계산하지 않음 |
| 저주 + 정신 | 약화·혼란 대상 기본 적중 | 추가 정신 피해 또는 의지 저항을 거친 짧은 제어. 강제 영구 진영 변경은 없음 |
| 축복 + 방어 | 축복된 자신이 실제 적대 공격을 막음 | 가까운 아군 1명에게 보호 1회. 보호·막기 반응의 자기 재발동은 없음 |
| 바람 + 원거리 | 기본 원거리 적중으로 실제 밀침 성공 | 다음 자기 이동의 회피 준비. 무료 순간이동·새 사격 턴은 없음 |
| 저주 + 사령 | 저주·사령 낙인 대상 사망 | 해골에 짧은 강화. 해골 생성 한도·사망 한 건의 중복 생성 제한 유지 |
| 축복 + 소환 | 자신이 실제 아군 소환에 성공 | 생성된 소환수에 짧은 축복. 축복이 추가 소환을 생성하지 않음 |

교차 효과는 해당 효과의 구체 조건으로 판정한다. 물 + 전기의 직접 적중은 기본 공격에 명시적인 전기 피해가 포함된 경우이며 단순 표식 부여·상태 틱·연쇄의 후속 피해를 다시 직접 적중으로 간주하지 않는다. 필요한 직접 원소 피해가 없는 구성이라면 흡수 전 미충족 조건을 표시한다.

현 코드의 `Reactions.status_react`는 화상+독의 상태 소비·폭발, 빙결+물리의 파쇄, 출혈+화염 반응 등을 자동 실행한다. 새 규칙과 동시에 적용하면 상태가 사라지거나 폭발이 중복된다. 따라서 **원인 행동·효과의 반응 정책**을 분리한다.

- 기존 원정과 몬스터의 기존 대표 효과는 기존 반응 정책을 사용한다.
- 새 인물 효과에서 시작한 행동·부여·후속 피해는 명시적 영혼석 연결만 실행한다. 같은 반응을 기존 자동 처리에도 보내지 않는다.
- 환경의 물·증기·얼음 지형은 보존하되 새 효과와 어떤 반응을 공유하는지 정책으로 명시한다. 중복 판정과 아군 광역 피해를 몰래 추가하지 않는다.
- 상태가 섞이는 대상의 종류나 플레이어 화면만으로 정책을 고르지 않는다. 원인 효과·지속 피해·소환수 행동에도 출처를 전달한다.
- 새 프로필의 교차 조건은 기본 적중 시 상태 부여 뒤 확정한 실제 상태를 사용한다. 단계 안에서 새로 생긴 연결 상태가 또 다른 연결을 시작하는 것은 명시적인 후속 이벤트가 있을 때만 허용한다.

## 7. 표시와 선택

- 영혼석 상세·도감은 **공격형 / 방어형 / 연쇄형** 역할 표시를 갖는다. 발동 시점은 적중·대기·피격 등의 짧은 문구로 따로 표시한다. 같은 계열의 모든 역할을 이미 얻은 것으로 표시하지 않는다.
- 하단 입력은 공격 / 대기 / 탐색 / 전술 / 가방을 유지한다. 자동 효과 아이콘을 공격·대기 위에 표시하며 조준 버튼으로 바꾸지 않는다.
- 영혼석 상세는 '적중 시 화상', '대기 시 주변 3칸 화상', '화상 대상 적중 시 주변 폭발'처럼 발동과 실제 효과를 짧게 쓴다.
- 흡수한 구성의 실제 요약은 공격 / 대기 / 반응으로 묶는다. 관련 영혼석을 아직 얻지 않았으면 완성 조합의 효과를 적용 중인 것처럼 표시하지 않는다.
- 방어태세 아이콘과 위협도 1·2·3단계를 인물 카드에 표시한다. 위협도 상승과 실제 적의 대상 변경은 같은 의미로 표시하지 않는다.
- 화상·중독·폭발·전이는 구분되는 기존 VFX를 사용한다. 광역 발동의 동일 로그는 묶고 발동마다 설명 팝업을 띄우지 않는다.
- 동료가 건 상태에 내가 연계할 수 있음을 상세에서 확인한다. 별도 연계 대상 설정 메뉴는 추가하지 않는다.

## 8. 전체 계열의 검증과 남은 수치 작업

설계·데이터 매핑은 전체 계열을 대상으로 한다. 구현은 작은 묶음으로 진행해도 나머지 계열의 발동·연결·제약을 미정 상태로 남기지 않는다. 계열별 공격·방어·연쇄 부위, 실제 발동 시점, 대상·지속·저항·재사용·소유권·VFX를 매핑 표에 기록하고 빈 행을 완료로 간주하지 않는다.

모든 계열을 영혼석 1·2·3·6개, 솔로·최대 3인, 적 밀집·분산·궁수·좁은 통로·막힌 경로에서 조합한다.

- 화염: 적중 부여 + 폭발 / 대기 부여 + 폭발. 첫 조합은 한 번의 적중, 두 번째는 대기 후 적중으로 연계가 달라지는지 확인한다.
- 독: 적중 부여 + 전이 / 대기 부여 + 전이. 전이가 단순 중복 갱신에 그치지 않고 주변 적·범위 밖으로 기여하는지 확인한다.
- 방어: 자세 단독 / 자세 + 시선 끌기 / 자세 + 대기 화염·독. 솔로와 파티에서 방어·공격 분담이 달라지는지 확인한다.
- 냉기: 둔화 → 빙결 → 다음 적중의 파쇄. 같은 대상의 반복 빙결·동료 기절이 정상 행동을 무한히 막지 않는지 확인한다.
- 전기: 단일 표식 → 최대 3명 연쇄 → 처치 표식 전이. 도약 경로·중복 대상·후속 연쇄 재시작을 검사한다.
- 저주·정신: 약화·취약·혼란의 실제 공격/행동 변화와 의지 저항을 확인하고 NPC 진영·관계가 숨은 효과로 바뀌지 않는지 검사한다.
- 축복·회복: 유익 상태·보호·실제 치유·정화의 성공/갱신을 구분한다. 만피·중립 NPC·같은 적 재인식·조우 횟수 복원으로 회복을 농사짓지 않는지 확인한다.
- 물·바람: 젖음의 냉기/전기 연결, 실제 밀침·막힌 이동·충돌·사격 준비의 차이를 확인한다.
- 출혈·물리: 상태 부여와 추가타, 강타·속사·집중·급소·광폭·회피·반사의 유한한 강화·소비를 검사한다.
- 소환·사령: 소환 한도·공간·집중 대상·결속·사령 낙인·실제 사망과 자연 만료·처치 소유권을 확인한다.
- 각 계열 방어: 얼음 갑옷·화염막·독막·전기막·가시·정신 장벽·저주 문양·신성 보호·물막·바람막·호위·사령 분담을 직접/지속/환경/아군/반사 피해에서 구분해 검사한다. 준비 소비·갱신·확률·재봉쇄 제한·다중 공격·분담 순환을 확인한다.
- 교차 연결: 해당 영혼석이 없을 때의 비발동, 기존 반응의 이중 처리, 상태 소유권·범위·아군 피해·지속 피해의 원인 정책을 검사한다.
- 보완: 상태 면역 적, 이미 죽은 대상, 마지막 적 처치, 빗나감, 대상 없음, 벽 뒤 적, 강제 대기, 봉인·다운·복원, 지속 피해·동료 처치 소유권을 검사한다.
- NPC는 같은 연계의 예상 가치를 읽되 예측만으로 피해·상태·관계를 바꾸지 않는다. 몬스터 기존 대표 효과와 대상 AI 변경의 범위를 따로 검사한다.

이 규칙에 모든 영혼석의 피해 숫자를 미리 배정하지 않는다. 기준 무기·레벨·방어를 고정하고 행동당 유효 피해·지속 피해·피해 예방·위협도에 따른 대상 변경·원정 누적 피해를 측정한다. 영혼석을 추가했을 때 숫자뿐 아니라 대상·위치·공격과 대기의 순서가 바뀌는지 사람이 확인한다.

전체 계열의 기본 규칙과 교차 연결은 이 문서에서 정의하고 피해·지속·저항·재사용의 최종 수치는 실측 후 정한다. 전 층 공격 같은 신규 확장은 별도 설계다. 재사용·조우당 횟수는 필요한 개별 효과에만 붙이고 기본 원소·물리 연계를 MP 고갈 때문에 사용할 수 없게 만들지 않는다.
