# 영혼석 전투 규칙 — 공격·대기·상태 하나

작성일: 2026-09-27 · 개정 2 · 상태: 일반 원정 적용

일반 원정과 동료·NPC는 `attack_wait_v1`을 사용한다. 몬스터는 기존 고유 기술을 유지한다. 실제 부위별 효과·수치·고정 보상은 [실행 매핑](../../attack-wait-soulstones.ko.md)에 기록한다. 이번 개정은 이전 문서의 체력·이동·회피·처치·복합 상태·확률 발동 규칙을 대체한다.

## 1. 플레이어가 알아야 하는 문법

| 문법 | 예시 | 조건 |
| --- | --- | --- |
| 공격 | 적중 시 화상 / 공격력 증가 / 추가타 | 기본 공격 확정 또는 적중 |
| 대기 | 주변 중독 / 갑옷 / 회복 / 소환 / 다음 공격 강화 | 의도적인 대기 한 번 |
| 연쇄 | 화상 적중 시 폭발 / 축복 중 적중 시 보호 / 소환수와 대기 시 강화 | 공격·대기 + 상태 하나 또는 자기 소환수 존재 |

효과 역할은 공격형·방어형·연쇄형이다. 대기 시 화상은 공격형이고 대기 시 갑옷은 방어형이다. 연쇄형에는 추가 조건이 정확히 하나 있으며 다른 역할에는 없다. 상태 부여와 같은 공격의 연쇄는 허용한다. 다만 새 빙결은 다음 공격부터 파쇄할 수 있다.

## 2. 제거하는 조건

- HP가 특정 비율 이하일 때만 발동하는 조건.
- 직전에 이동·회피·막기·처치·정화·소환수 처치를 했는지 확인하는 조건.
- 같은 적을 반복 공격하거나 연속 대기·조준을 누적해야 하는 조건.
- 원거리 무기, 강타 효과, 특정 직접 원소 피해와 상태를 함께 요구하는 조건.
- 상태 둘 이상을 동시에 요구하는 조건.
- 영혼석 효과 자체의 추가 발동 확률.

기본 공격의 명중·회피·방어·저항, 범위·사거리·시야·유효 대상, 봉인과 강한 효과의 재사용·횟수 제한은 유지한다. 피해나 회복이 실제로 발생해야 성공으로 기록하는 규칙도 유지한다.

## 3. 실행 계약

공격 확정·적중·의도적 대기 세 사건만 영혼석의 시작 사건이 된다. 접근 이동·거부된 입력·강제 대기는 발동하지 않는다. 효과가 만든 추가타·피해는 새 기본 적중을 만들지 않는다. 기존 이벤트 엔진의 몬스터·장비 효과는 별도 경로를 유지한다.

대기 방어는 다음 합법적인 자기 행동까지 유지하며 감소 수치는 중첩하지 않는다. 피격 반응은 다음 유효 직접 피격에 한 번 확정 발동한다. 범위 밖 피격이나 무효 피해는 준비를 소모하지 않는다. 전기막은 재사용 3턴과 기존 재봉쇄 면역으로 반복 봉쇄를 제한한다.

대기 유인은 고정 위협 보정을 주며 추가 대기로 증가하지 않는다. 집중은 다음 공격 +20%를 한 번 준비하고 추가 대기로 누적하지 않는다. 이동은 준비를 해제한다. 준비와 상태 아이콘으로 현재 효과를 확인한다.

치유는 HP가 부족한 실제 아군을 선택한다. 강한 대기 치유는 조우당 2회·재사용 3턴이다. 소환은 주인당 한도 1명·빈 인접 칸·재사용 3턴이다. 소환수 강화·연장·축복은 자기 소환수 존재 조건 하나를 사용한다. 지속 연장은 현재 시간 기준 최대 5턴을 넘지 않는다. 호위와 피해 분담은 실제 피해 경로를 사용한다.

영혼석은 MP와 추가 행동을 소비하지 않는다. 6칸·레벨별 슬롯·영구 흡수·교체 불가·봉인 계약을 유지한다. 기존 부위와 변형 ID를 유지하므로 조합 선택과 흡수 규칙은 바꾸지 않는다.

## 4. 표시와 원정

상태창은 공격·대기 두 묶음으로 실제 효과를 요약한다. 효과 설명에 같은 조건을 다시 덧붙이지 않는다. 흡수 카드의 적합성은 필요한 상태 하나나 소환수를 현재 조합이 만들 수 있는지만 확인한다. 서로 연쇄로만 이어지는 영혼석은 시작 상태를 만들 수 있을 때만 연결 가능으로 표시한다.

일반 원정의 MP·수동 기술 UI는 숨긴다. 장비의 주문력·최대 MP와 MP 회복은 공격력·최대 HP·HP 회복으로 매핑하며 재충전은 효과 재사용만 해제한다. 조우당 횟수는 복원하지 않는다. 상세 매핑은 실행 문서를 따른다.

수치는 초기값이다. 단순한 조건으로 전환한 효과의 기대 화력과 유지력을 실제 모바일 원정에서 다시 확인한다. 기본 명중 판정을 없애거나 전투를 자동으로 진행하는 변경은 이번 영혼석 개정에 포함하지 않는다.
