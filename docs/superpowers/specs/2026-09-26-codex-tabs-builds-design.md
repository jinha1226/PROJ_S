## 0. 결정

1. **메인 화면에 "도감" 메뉴**(도감 설계에서 이미 시작 화면 버튼으로 들어감).
2. **도감 탭은 셋: 영혼석 · 아이템 · 빌드.** 몬스터 탭은 따로 두지 않고 영혼석 탭의 종족 머리줄에 합친다.
3. **예시 빌드**는 설계 검증·플레이 테스트·나중 밸런스 측정의 기준이다. 빌드 탭에서 보고, 전투 시험(아레나)에서 바로 끼워 싸워 본다.

## 1. 영혼석 탭

- 구역별 → 종족마다 **머리줄**: 몬스터 그림(못 봤으면 실루엣), 이름, 역할군, 처치 수. 머리줄을 누르면 몬스터 상세(공격 형태·피부·뼈, 대표 효과, 액티브).
- 머리줄 아래 부위 셋: 모은 것은 이름·세부 유형·효과 문구·키워드 칩, 못 모은 것은 흐리게 + "베기로 마무리" 힌트.
- 거르기: 역할군 5칩 → 고르면 세부 유형 칩(역할군 설계 §5).
- 위쪽 완성률: "영혼석 n/m · 몬스터 n/m".

## 2. 아이템 탭

| 묶음 | 내용 | 공개 |
| --- | --- | --- |
| 무기 | 7종: 이름, 형태, 피해, 지연, 한손/양손 | 항상 |
| 왼손 | 방패, 보조 무기 3종(형태), 오브 | 항상 |
| 갑옷 | 4종: 방어, 회피 불이익, 둔중 | 항상 |
| 반지 | 기본 반지 6종 | 항상 |
| 옵션 | 랜다트 빌드 옵션(증폭·보완·형태): 이름, 문구, 세부 유형 | **본 것만**(주운 장비에 붙어 있던 옵션) |
| 고정 아티팩트 | 12종: 이름, 칸, 효과, 대가 | **찾은 것만**, 나머지는 칸 종류와 "???" |

- 기록: 도감 파일에 `affixes: {옵션 id: {"found": n}}`를 더한다. 장비를 주울 때(`Randart.make` 결과가 가방에 들어갈 때) 옵션 id와 고정 아티팩트 id를 기록.

## 3. 빌드 탭

- **예시 빌드 목록**: 카드마다 이름, "탱커 · 방어", 무기, 흐름 첫 줄.
- **빌드 상세**:
  - 역할군·세부 유형, 무기·왼손·갑옷, 레벨 10
  - 영혼석 10개: 부위 이름, 세부 유형, 효과 문구. **도감에서 모은 부위는 표시(✓)**, 못 모은 부위는 흐리게(이름은 보임 — 예시 빌드는 스포일러로 치지 않는다)
  - 흐름 2~3줄(데이터의 `flow`)
  - 역할군 조합 결과("탱커 6개 · 6구간")
  - 버튼 **"전투 시험에서 해보기"** → 아레나 설정을 열고 1번 인물에 이 빌드를 넣는다.
- **파티 예시**(3인 4개): 이름, 세 빌드 이름. 버튼 "전투 시험에서 해보기" → 아레나 인원 3, 각 인물에 빌드.

## 4. 예시 빌드 적용

- `ExampleBuilds.apply(s, actor, build_id)`: 레벨 10, 영혼석 10개 흡수·장착(가방을 거치지 않음), 학파 주문은 그 레벨의 가장 높은 주문, 무기·왼손·갑옷 기본 등급, 태세.
- **도감에 기록하지 않는다**(아레나는 원래 기록하지 않음).
- 아레나 설정의 인물 카드에 "예시 빌드" 선택(없음 + 11개). 빌드를 고르면 파츠 두 칸 선택은 숨긴다(빌드의 종족 액티브를 쓴다).

## 5. 데이터 형식 (`example_builds.json`)

```json
{"version":1,
 "builds":[{"id":"wall","name":"철벽","group":"TANK","subtype":"DEFENSE","level":10,
   "weapon":"mace","offhand":"shield","armour":"plate","rings":[],
   "stones":["HOB_TAUNT/pierced", "..."], "schools":{"<영혼석 id>":"fire"},
   "stance":"GUARDIAN","flow":["...", "..."]}],
 "parties":[{"id":"classic","name":"정석 파티","members":["wall","blood_hunter","elementalist"]}]}
```

- 영혼석은 정규 id(`BASE/part`). 활·지팡이는 양손이라 `offhand`가 빈 문자열.
- `group`·`subtype`은 역할군 설계의 id. 역할군 개편 전에는 표시만 옛 이름으로 대신한다.
