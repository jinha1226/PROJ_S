# 휴식처와 영혼석 재배치

작성일: 2026-09-28 · 상태: **합의됨(아래 §0), 세부는 초안**
근거: [영혼석 성장 방식 검토](2026-09-28-soulstone-progression-directions.md)의 A안(무작위 드롭)을 유지하면서 영구·교체 불가의 부담만 푼다. 데드셀의 구역 사이 통로처럼 **구역 보스를 잡은 뒤 들르는 휴식처**를 둔다.
현재 규칙: [영혼석 — 6개 영구 흡수](../../soulstones.ko.md). 이 설계가 구현되면 그 문서의 "교체·해제 불가", "가득 찬 경우 흡수 거부"를 대체한다.
기존 코드: `expedition/progression/essences.gd`(`absorb`·`bind`·`free_slot`·`equip`/`unequip`/`put`/`take`는 지금 항상 거부), `expedition/progression/stone_drop.gd`(드롭 즉시 선택: 흡수 / 가방 / 두고 감), `expedition/run/descent.gd`(`descend`), `expedition/level/zones.gd`(`is_boss_floor`: 3·6·9·12층), `expedition/actors/boss_ai.gd`(`on_boss_defeated`), `expedition/run/camp.gd`(야영)

## 0. 결정

1. **흡수는 영구다.** 흡수한 영혼석은 그 인물의 **학습 목록**(`actor.essences`)에 원정 끝까지 남는다. 되돌리거나 다른 인물에게 넘길 수 없다.
2. **빈 칸 배치는 언제든(지금 흡수가 되는 곳이면).** 흡수할 때 빈 활성 칸이 있으면 바로 그 칸에 들어간다.
3. **교체·빼기는 휴식처에서만, 횟수 제한 없음.** 휴식처에서는 학습 목록 안에서 활성 6칸을 자유롭게 다시 고른다.
4. **가방에 든 흡수 전 영혼석은 최대 3개.** 파티 공용 가방 기준이다.
5. **휴식처는 3·6·9층 보스를 잡은 뒤** 다음 층으로 내려가기 전에 들른다(원정당 3번). 12층 보스는 원정 끝이라 휴식처가 없다.

## 1. 영혼석 규칙

| 항목 | 지금 | 바뀐 뒤 |
| --- | --- | --- |
| 활성 칸 | 레벨당 1칸, 최대 6 | 같음 |
| 흡수 | 빈 칸에 즉시 적용, 가득 차면 거부 | **학습 목록에 영구 추가.** 빈 활성 칸이 있으면 바로 배치, 없으면 비활성으로 학습만(아래 §1.1) |
| 교체·해제 | 불가 | **휴식처에서만**, 무제한 |
| 빈 칸 채우기 | 흡수할 때만 | 흡수할 때 + 학습 목록의 비활성 영혼석을 빈 칸에 넣기(안전한 곳 어디서나) |
| 중복 | 같은 부위·속성은 한 인물에 1회 | 같음(학습 목록 기준) |
| 가방 | 제한 없음 | **최대 3개** |
| 봉인 | 효과만 정지, 칸 점유 | 같음. 휴식처에서 봉인된 영혼석을 칸에서 뺄 수 있다(빼도 봉인 상태는 그 영혼석에 남음) |

### 1.1 가득 찬 인물의 흡수 (검토 필요)

활성 6칸이 모두 찬 인물도 흡수를 **허용**하는 안을 제안한다. 흡수한 영혼석은 비활성으로 학습 목록에만 들어가고, 다음 휴식처에서 끼울 수 있다.

- 이유: 가방이 3개로 줄어서, 좋은 영혼석을 가방에 계속 쌓아 둘 수 없다. 가득 찬 인물이 흡수만 해 두고 휴식처에서 바꾸는 흐름이 없으면, 휴식처 재배치에 쓸 재료가 생기지 않는다.
- 기본 능력치·패시브·기술·주문·역할 조합은 **활성 칸의 영혼석만** 적용한다. 비활성 학습 영혼석은 아무 효과도 없다.

### 1.2 가방 3개 상한

- 드롭 선택 창(`stone_drop.gd`)의 선택지: **흡수(인물 선택) / 가방에 넣기 / 두고 감.**
- 가방이 3개로 차 있으면 "가방에 넣기"는 **가방의 하나를 버리고 넣기**로 바뀐다(버릴 것 선택). 새 것을 두고 가는 것도 그대로 가능.
- 시험 장비(`grant_test_loadout`), 난이도 게이트, 아레나 등 개발용 경로는 상한을 적용하지 않는다(`s.stone_bag_limit`가 0이면 무제한, 일반 원정 기본값 3).
- 보스 영혼석(보상으로 받는 것)도 같은 가방 규칙.

## 2. 휴식처

### 2.1 흐름

1. 3·6·9층 보스가 쓰러지고 층이 안전해진다.
2. 계단을 내려가면(`descend`) 다음 층을 만들기 전에 **휴식처**(`phase = "REST"`)에 들어간다.
3. 휴식처 화면에서 할 일을 한다.
4. "다음 구역으로" 버튼 → 다음 층 생성(`floor_state.build`) → `phase = "EXPLORE"`.

- 휴식처는 층이 아니라 **화면**이다. 맵·적·시간 진행이 없다.
- 드롭 선택이 남아 있으면(`pending_stone_drops`) 휴식처에 들어가기 전에 먼저 처리한다(지금 `descend`와 같은 규칙).

### 2.2 휴식처에서 하는 것

| 기능 | 내용 |
| --- | --- |
| **회복** | 들어올 때 파티 전원 HP·MP 전부, 스트레스 −30, 식량 소모 없음. 빈사(`Downed`) 인물은 일어난다 |
| **영혼석 재배치** | 인물마다: 활성 6칸 + 학습 목록. 칸을 누르면 학습 목록에서 고르거나 비우기. 무제한 |
| **가방 흡수** | 가방의 영혼석을 인물에게 흡수(§1) |
| **동료** | 동료의 재배치도 같은 화면에서(인물 탭). NPC 동료도 플레이어가 직접 |
| **추천 배치** | 인물마다 버튼 하나: 학습 목록에서 그 인물의 주 역할군·세부 유형에 가장 맞는 6개를 끼운다(§2.3) |
| **도감** | 도감 열기 |
| (자리만) 상점·저장 | 이후 단계. 휴식처가 원정 저장 지점이 된다 |

### 2.3 추천 배치

- 기준: 인물의 현재 활성 영혼석 중 가장 많은 역할군(동률이면 첫 칸의 역할군). 활성 칸이 비어 있으면 학습 목록 전체에서 가장 많은 역할군.
- 그 역할군 영혼석을 먼저, 그다음 같은 세부 유형을 공유하는 다른 역할군 영혼석, 그다음 기본 스탯 순으로 6개. 동률은 영혼석 id 순.
- 결과를 바로 적용하지 않고 **미리보기 → 확인**. 되돌리기 버튼.
- NPC·동료 AI의 영혼석 선택(`npc_essences.gd` `choose`)과 같은 점수 함수를 쓴다(새 점수 규칙을 만들지 않는다).

### 2.4 화면 (모바일)

```text
[휴식처 · 3층 보스 격파]            (완전 회복됨)
인물 탭: 아린 | 브란 | 세라
활성 6칸 (3×2)        ← 칸을 누르면 학습 목록에서 선택
학습 목록 (비활성)     ← 누르면 빈 칸에 넣기 / 선택한 칸과 교체
[추천 배치]  [되돌리기]
가방 영혼석 (최대 3)   ← 누르면 흡수할 인물 선택
[도감]                     [다음 구역으로]
```

## 3. NPC·동료

- 파티에 합류한 동료는 플레이어가 휴식처에서 재배치한다.
- 파티 밖 독립 NPC는 지금처럼 사냥으로 얻은 영혼석을 흡수한다. 활성 칸이 차 있으면 학습만 하고, **구역이 바뀔 때(플레이어가 휴식처에 들어갈 때) 추천 배치로 한 번 재배치**한다.
