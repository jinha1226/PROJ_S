# 휴식처와 영혼석 덮어쓰기

작성일: 2026-09-28 · 상태: **합의됨(§0), 세부 수치는 초안**
근거: [영혼석 성장 방식 검토](2026-09-28-soulstone-progression-directions.md)의 A안(무작위 드롭)을 유지하고, 칸이 막혔을 때만 **구역 보스 뒤 휴식처**에서 바꿀 수 있게 한다(데드셀의 구역 사이 통로처럼).
현재 규칙: [영혼석 — 6개 영구 흡수](../../soulstones.ko.md). 구현되면 그 문서의 "교체·해제 불가"를 "휴식처에서만 덮어쓰기"로 바꾼다.
기존 코드: `expedition/progression/essences.gd`(`absorb`·`bind`·`free_slot`, `equip`/`unequip`/`put`/`take`는 지금 항상 거부), `expedition/progression/stone_drop.gd`(드롭 즉시 선택: 흡수 / 가방 / 두고 감), `expedition/run/descent.gd`(`descend`), `expedition/level/zones.gd`(`is_boss_floor`: 3·6·9·12층), `expedition/run/camp.gd`

## 0. 결정

1. **영혼석 칸은 레벨당 1칸, 최대 6칸(지금과 같음). 칸 수보다 많이 흡수하지 않는다.** 학습 목록·예비 영혼석은 없다.
2. **흡수는 빈 칸에만, 안전한 곳 어디서나**(지금과 같음). 칸이 모두 차면 흡수할 수 없다.
3. **휴식처에서만 덮어쓰기**: 가방의 영혼석을 이미 찬 칸에 흡수하면 그 칸에 있던 영혼석은 **사라진다**. 횟수 제한 없음(가방에 영혼석이 있는 만큼).
4. **가방(흡수 전 영혼석)은 파티 공용 최대 3개.**
5. **휴식처는 3·6·9층 보스를 잡은 뒤** 다음 층으로 내려가기 전에 들른다(원정당 3번). 12층 보스는 원정 끝이라 없다.

## 1. 영혼석 규칙

| 항목 | 지금 | 바뀐 뒤 |
| --- | --- | --- |
| 칸 | 레벨당 1칸, 최대 6 | 같음 |
| 흡수 | 빈 칸에 즉시, 가득 차면 거부 | 같음 |
| 교체 | 불가 | **휴식처에서만 덮어쓰기.** 옛 영혼석은 사라짐. 되돌리기 없음 |
| 칸 비우기 | 불가 | 불가(덮어쓰기만 있음) |
| 중복 | 같은 부위·속성은 한 인물에 1회 | 같음. 덮어써서 사라진 영혼석은 다시 흡수할 수 있다 |
| 가방 | 제한 없음 | **최대 3개** |
| 봉인 | 효과만 정지, 칸 점유 | 같음. 봉인된 칸도 휴식처에서 덮어쓸 수 있다 |

### 1.1 가방 3개 상한

- 드롭 선택 창(`stone_drop.gd`)의 선택지: **흡수(빈 칸이 있는 인물) / 가방에 넣기 / 두고 감.**
- 가방이 3개로 차 있으면 "가방에 넣기"가 **가방의 하나를 버리고 넣기**로 바뀐다(버릴 것 선택). 새 것을 두고 가는 것도 그대로 가능.
- 보스 영혼석 보상도 같은 가방 규칙.
- 개발용 경로(시험 장비 `grant_test_loadout`, 난이도 게이트, 아레나)는 상한을 적용하지 않는다: 세션 값 `stone_bag_limit`(일반 원정 3, 개발 경로 0 = 무제한).

### 1.2 덮어쓰기 확인

- 덮어쓰기 전에 확인 창: "◯◯(을)를 흡수하면 ▢▢(이)가 사라집니다" + 두 영혼석의 효과를 나란히.
- 덮어쓴 뒤 능력치·패시브·기술·주문·역할 조합을 즉시 다시 계산한다(흡수와 같은 경로).
- 사라진 영혼석의 주문 선택·재사용 대기는 함께 지운다. 같은 종족의 다른 부위가 남아 있으면 그 공유 기술은 남는다(기존 공유 규칙).

## 2. 휴식처

### 2.1 흐름

1. 3·6·9층 보스가 쓰러지고 층이 안전해진다.
2. 계단을 내려가면(`descend`) 다음 층을 만들기 전에 **휴식처**(`phase = "REST"`)에 들어간다. 드롭 선택이 남아 있으면 먼저 처리한다(지금 `descend` 규칙).
3. 휴식처 화면에서 할 일을 한다.
4. "다음 구역으로" → 다음 층 생성(`floor_state.build`) → `phase = "EXPLORE"`.

- 휴식처는 층이 아니라 **화면**이다. 맵·적·시간 진행이 없다.

### 2.2 휴식처에서 하는 것

| 기능 | 내용 |
| --- | --- |
| **회복** | 들어올 때 파티 전원 HP·MP 전부, 스트레스 −30, 식량 소모 없음. 빈사(`Downed`) 인물은 일어난다 |
| **흡수·덮어쓰기** | 가방의 영혼석을 인물의 빈 칸에 흡수하거나, 찬 칸에 덮어쓰기(§1.2) |
| **동료** | 동료 인물도 같은 화면에서(인물 탭) |
| **도감** | 도감 열기 |
| (자리만) 상점·저장 | 이후 단계. 휴식처가 원정 저장 지점이 된다 |

### 2.3 화면 (모바일)

```text
[휴식처 · 3층 보스 격파]            (완전 회복됨)
인물 탭: 아린 | 브란 | 세라
영혼석 6칸 (3×2)
가방 영혼석 (최대 3)   ← 누르면 넣을 칸 선택: 빈 칸은 흡수, 찬 칸은 덮어쓰기 확인
[도감]                     [다음 구역으로]
```

## 3. NPC

- 파티에 합류한 동료는 플레이어가 휴식처에서 관리한다.
- 파티 밖 독립 NPC는 지금 규칙 그대로(사냥으로 빈 칸만 채우고 교체하지 않음).
