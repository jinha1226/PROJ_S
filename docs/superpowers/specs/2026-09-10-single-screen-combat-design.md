# 화면 하나 전투 설계 (전투 모드 제거)

작성일 2026-09-10. 2026-09-09 주인공 턴제 설계를 대체한다. 플레이어가 보는 "전투 모드"를 없앤다.
탐험 화면 하나에서 이동·공격·스킬·퇴각을 모두 처리하고, 시뮬의 조우 단계
(CONTACT/ENGAGED/재집결)는 원장 규칙으로만 남아 화면에 드러나지 않는다.

## 목표

- 화면 전환 없음. 턴 시계(타임라인 바), 자동/수동 토글, 진행·자율 버튼, 대형 선택 안내 삭제.
- 탭 한 번 = 주인공 행동 하나. 그 사이 동료·적은 자기 행동 시간대로 자동으로 움직인다.
- 이동과 공격은 분리한다. 칸 탭은 이동, 인접한 적 탭은 공격. 내가 더 빠르면 이동 뒤에 한 번 더
  탭해서 공격이 들어간다.
- 조우는 "적이 우리를 인지했을 때" 또는 "우리가 먼저 공격할 때"만 일어난다. 보기만 한 적은 지도에
  보이고 피해 갈 수 있다.
- 퇴각 버튼 하나로 파티 전체가 물러난다. 추적하는 적이 사정거리 밖으로 벗어나면 시뮬이 스스로
  탐험으로 되돌린다(기존 규칙).

## 1. 조우 규칙 (시뮬)

현재: 아군 누군가의 시야에 적이 들어오면 즉시 조우. 적은 시야+거리로 즉시 감지.

새 규칙(상태의 `legacy_contact_rule = false`; 원정(DUO) 시나리오에서만 켠다. 단독 픽스처·쇼케이스
시나리오와 스키마 23 이하 저장본은 `legacy_contact_rule = true`로 기존 시야 규칙을 유지한다):

- 후보 적 = 시야(LOS)가 닿고, 경계 상태가 `ALERT` 또는 `HUNTING`이며, 거리 ≤ 적 감지 반경.
  아군 시야만으로는 후보가 되지 않는다. 가장 가까운 후보가 접촉 적.
- 종류: 아군 중 누군가 그 적을 보고 있으면 `DETECTED`, 아니면 `ENEMY_AMBUSH`.
- 선공(`PARTY_AMBUSH`): 아군이 아직 조우가 아닌 적을 공격(근접·스킬)하면 그 명령 안에서 접촉 →
  배치 → 공격이 한 번에 처리된다. 접촉 이벤트 데이터에 `first_strike: true`를 더한다.
- 경계 상승은 기존 인지 규칙 그대로(의심 누적, 인접 시 즉시 HUNTING).
- 검증기(`world_state` 접촉 검증)는 새 규칙에서 접촉 시점의 경계 이벤트 이력으로 후보를 다시
  계산한다. `legacy_contact_rule` 이면 기존 거리 기반 검증 유지.

## 2. 입력 규칙 (탐험·전투 동일)

| 입력 | 뜻 |
|---|---|
| 빈 칸 탭 | 그 칸까지 한 칸씩 이동. 전투 중에도 같다(도망 가능). 걸음마다 동료·적이 움직인다. |
| 인접한 적 탭 | 그 적을 공격(주인공 개인 표적 지정 + 이번 차례 실행). 인접하지 않으면 "인접해야 공격" 안내. |
| 조우 전 적 탭(인접) | 선공. 접촉·배치·공격이 한 탭에 끝난다. |
| 스킬 버튼 | 사거리 안 칸을 붉게 표시. 그 칸의 적(또는 아군 스킬이면 아군)을 탭하면 사용. 다른 곳 탭은 취소. |
| 적 초상화 탭 | 파티 집중 표적(동료 지침). |
| [공격] | 항상 같은 자리. 가장 가까운 보이는 적: 인접하면 공격(조우 전이면 선공), 아니면 한 칸 접근. 적이 없으면 안내. |
| [대기] | 한 턴. 전투 중엔 방어(자동 공격 없음), 탐험 중엔 제자리 대기. |
| [휴식] | HP가 찰 때까지 휴식. 적이 가까우면 이유를 띄우고 거부. |
| [탐험] | 자동 탐험 토글. 적이 보이면 즉시 멈춘다. |
| [줍기] | 발밑 아이템 전부 줍기. 없으면 비활성. |
| [퇴각] | 파티 명령 RETREAT + 주인공도 적에게서 멀어지는 자동 걸음. 다른 입력이 오면 해제. 추적하는 적이 없으면 비활성. |
| [가방] | 주인공 아이템 탭. |

주인공 차례 대기(`hero_turn_waiting`)는 유지하되 표시만 없앤다. 주인공 이벤트가 커밋되면 다음
차례에 다시 멈춘다. 자동 전투(`battle_mode = "AUTO"`)는 테스트용 내부 옵션으로만 남긴다.

## 3. 배치

지도 → 사건 피드(3줄) → 스킬 줄(주인공 스킬, 44px) → 초상화 줄 → 명령 독(고정 8칸: 공격·대기·휴식·탐험·줍기·퇴각·가방·상황 버튼) → 하단 탭.
독의 라벨과 순서는 탐험·전투에서 절대 바뀌지 않는다. 쓸 수 없는 버튼은 비활성으로만 표시한다.
적 초상화 줄은 전투 중 초상화 줄 오른쪽 끝(기존 `battle_enemy_strip`).
전투 중 지도 틴트는 유지(붉은 테두리), 비네트 삭제.

## 4. 조우 처리

어떤 경로로 CONTACT가 되든(내 이동, 적 접근, 휴식·자동이동 중) 다음 갱신에서 즉시 배치를
끝낸다: 동료가 있으면 첫 번째 가능한 대형으로 자동 배치, 없으면 단독 진입. 미리보기 프레임 없음.

## 5. 불변식

- 저널에 새 종류는 없다. 선공은 기존 `deployment` + 근접/스킬 명령의 조합이다.
- 접촉 이벤트 키는 `["contact_kind","enemy_id","enemy_position","facing"]` 또는 선공 시
  `+ "first_strike"`.
- 구버전 저장(`legacy_contact_rule = true`)은 기존 규칙으로 재생·검증된다.

## 6. 테스트

- 삭제: 타임라인 바·컨트롤러·프리젠터 테스트(`battle_timeline_*`, `test_battle_timeline_presenter`).
- 재작성: `hero_turn_combat_acceptance` → `single_screen_combat_acceptance`(탭=행동 하나, 인접 적
  탭=공격, 비인접 안내, 먼 칸 탭으로 이탈 후 탐험 복귀, 퇴각, 스킬 붉은 칸, 저장/재생).
- 신규: `awareness_contact_regression`(보기만 하면 조우 아님, 경계 시 조우, 선공, 구버전 재생).
- 갱신: 비주얼·레이아웃 스모크(독 5개, 스킬 줄), 솔로 접촉 회귀(적 접근 조우 후 다음 탭 즉시 처리).
