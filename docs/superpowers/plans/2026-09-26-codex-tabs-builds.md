# 도감 3탭과 예시 빌드 구현 기록

상태: 구현 완료. 기준: [설계](../specs/2026-09-26-codex-tabs-builds-design.md).

## 반영한 내용

- [x] 영혼석·아이템·빌드 3탭으로 변경했다. 기존 적 정보의 몬스터 도감 진입은 영혼석 탭의 해당 종족 상세로 연결한다.
- [x] 영혼석 목록을 구역 → 종족 머리줄 → 부위 순으로 구성했다. 종족 그림·역할·처치 수, 미발견 실루엣, 부위 잠금과 마무리 형태 힌트를 표시한다.
- [x] 역할군 5개를 선택하면 세부 유형 칩이 나타난다. 유형 필터는 같은 종족 안에서도 해당 부위만 표시한다.
- [x] 아이템 탭에 기본 무기 7종, 왼손 장비, 갑옷, 반지를 공개한다. 무작위 장비 옵션은 습득한 것만, 고정 유물은 발견 여부에 따라 이름·효과·대가를 표시한다.
- [x] 도감 v1에 `affixes` 절을 추가했다. 이전 파일은 빈 절로 채우며 알 수 없는 절을 보존한다. 중앙 장비 습득 경로에서 기록한다.
- [x] 예시 빌드 11개와 3인 파티 4개를 표시한다. 상세에서 영혼석 10개, 장비, 전투 흐름, 실제 역할 조합과 수집 여부를 볼 수 있다.
- [x] 빌드·파티의 시험 버튼을 아레나 설정에 연결했다. 인물마다 '예시 빌드 없음' 또는 빌드를 선택할 수 있고, 선택한 빌드는 기존 파츠 두 칸 선택을 대체한다.
- [x] 아레나 시작 시 예시 빌드를 실제 장착한다. 영혼석·장비·주문·태세와 레벨 성장 HP·MP를 적용하며, 1인 호위형을 돌격형으로 처리하는 기존 규칙은 유지한다.

## 구현 계약

`ExampleBuilds.apply(s, actor, id)`는 유효한 빌드일 때 레벨 10, 정규 영혼석 10개, 기본 5칸 장비와 태세를 설정한다. 현재 레벨에서 가능한 최고 단계 주문을 준비한다. 양손 무기는 왼손을 비우고, 이전 슬롯·주문·규칙·봉인·쿨다운을 교체한다. 알 수 없는 빌드는 인물을 변경하지 않는다.

적용은 가방·원정 발견 목록·수집 도감을 건드리지 않는다. 아레나는 기록이 꺼진 별도 세션이다. 진행 중인 원정의 도감에서 시험으로 들어온 경우 원정 세션을 보관하고, 아레나 설정의 '원정으로'로 돌아올 때 복원한다. 시험 중 앱을 멈추거나 닫을 때 보관한 원정의 도감도 저장한다. 시험이나 메뉴를 보는 동안 원정 턴은 흐르지 않는다.

목록은 가로 스크롤 없이 세로로 읽는다. 영혼석 효과 문구는 작은 화면에서 읽을 수 있도록 종족 아래에 부위별로 배치했다. 키워드 설명은 별도 팝업을 사용한다. 지연된 크기 맞춤은 사용자가 닫은 팝업을 다시 열지 않는다.

예시 상세의 미수집 영혼석 이름은 의도적으로 공개하되 흐리게 표시한다. 일반 영혼석 목록의 잠금 정책과 구분한다.
