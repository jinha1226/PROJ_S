# 역할군 5개와 세부 유형 구현 기록

상태: 구현 완료. 기준: [설계](../specs/2026-09-26-role-groups-design.md).

## 반영한 내용

- [x] 현재 30종과 보스 영혼석 3개의 역할을 `TANK / MELEE / RANGED / MAGIC / SUPPORT`로 전환했다. 영혼석 기본 스탯과 가장 높은 2·4·6 구간 하나를 적용한다.
- [x] 기존 부위 효과 90개를 각각 세부 유형 하나로 분류했다. 새 종족 8개의 부위는 이번 범위에 포함하지 않았다.
- [x] `Subtypes`가 17개 유형의 이름·역할군과 효과의 유형을 읽는다. 유형 자체는 수치 보너스를 만들지 않는다.
- [x] `families` 배열을 제거했다. 장비 효과도 가까운 유형으로 옮겼으며, 분류가 없는 대가·형태 선택 효과는 빈 유형을 허용한다.
- [x] 회피·연사·강화 반지 옵션을 보강했다. 기존 저격 옵션은 사거리와 조준 상한을 유지한다. 옵션 문구는 실제 효과 수치를 보여 준다.
- [x] 동료 성격 선호와 같은 빌드 판정을 역할군·세부 유형으로 옮겼다. 실제 선택한 태세는 변경하지 않고, 태세 추천에 역할군을 사용한다.
- [x] 영혼석·인물 화면의 빌드 비율과 도감 필터를 세부 유형으로 표시한다.
- [x] 전체 CI에 `subtypes`, `role_groups`, `role_combos`를 등록했다.

## 설계에서 구체화한 계약

`BuildSense.subtype_profile`은 화면에 쓰는 17개 유형의 비율이다. `profile`은 전술 점수 함수가 사용하던 내부 채널로 합산한다. 목표 적합도·위험 회피·직접 명령·마무리 양보의 규칙은 유지한다. 재생·반사처럼 새로 분리한 유형의 분류가 달라지므로 옛 빌드 비율과 모든 선택이 같다고 보장하지는 않는다. 실제 효과가 적용할 수 있는 상태인지 확인하는 절차는 유지한다.

지원의 회복 보너스는 **회복을 주는 인물**의 조합을 읽는다. 보호 보너스는 `ward` 지속값을 늘린다. 해로운 상태나 일반 엄호의 피해 분담 비율은 늘리지 않는다. 지원 공격 보너스는 같은 편의 생존 인물 가운데 가장 높은 구간 한 번만 읽는다.

마딜의 MP +2는 가장 높은 구간이 **4일 때만** 적용한다. 6구간은 주문력 +30%와 실패 면제다. 이는 설계의 '가장 높은 구간 하나만' 원칙을 따른다. 최종 보스의 `set_boost`도 그대로 적용한다.

지원 6의 정화는 인접 동료마다 25% 판정하며, 가장 오래 남은 해로운 상태 하나를 지운다. 동률은 상태 id 순으로 정해 재현성을 유지한다.

몬스터용 `Bestiary.ROLES / ROLE_HP / ROLE_ATTACK`과 `floor_monsters.json`은 유지했다. 몬스터의 옛 역할은 영혼석 호환 별칭이 아니다. 역할군 개편 전 수치를 고정한 `tests/fixtures/monster_stats_before_role_groups.json`과 **30종 × 12층 = 360건**을 비교한다.

## 검증

- 전체 CI **97개 스위트, 실패 0**.
- 역할군 406, 역할 조합 195, 세부 유형 277, 효과 데이터 382개 검사 통과.
- 기존 동료 태세 113, 보호 38개 검사 통과. 기존 검사 의도를 새 역할·수치로 갱신했고 검사 수를 줄이지 않았다.
- 기존 90개 부위와 기존 장비의 `rules / limit / roles / source / slots / gear_kind`는 개편 전과 동일하다. 추가한 장비 옵션 3개만 새 전투 효과다.
- 난이도 진단 12개 검사 통과. 수치 결과는 [난이도 게이트](../../balance/difficulty-gate.md)에 갱신했다.

## 남은 밸런스 작업

기능 회귀 통과와 원정 난이도 합격은 별개다. 이번 재측정도 목표 HP 손실 25~40%에 들어오지 않았다. 2층 검 킷의 전투당 손실은 40.5% → 60.9%, 5층 화염 킷 승률은 33% → 20%다. 몬스터 수치는 이번 범위에서 유지했으므로, 다음 밸런스 작업에서 새 역할의 실제 획득·장착 분포와 조우 난이도를 함께 조정해야 한다. 이 진단은 전투마다 HP·MP를 채우는 자동 전술 봇의 결과이며 원정 완주율이 아니다.
