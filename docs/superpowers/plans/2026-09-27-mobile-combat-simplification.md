# 모바일 전투 단순화 설계·구현 계획 — 공격·대기 발동과 영혼석 연쇄

작성일: 2026-09-27 · 상태: 일반 원정 적용 · 조건 단순화 개정 2

구현 결과와 실제 부위별 효과는 [공격·대기 실행 매핑](../../attack-wait-soulstones.ko.md)에 기록한다. 일반 원정은 `attack_wait_v1`을 기본으로 사용하며 전투 시험에서도 선택할 수 있다. MP 관련 장비·재충전 두루마리의 변환도 적용했다. 아래 수치는 최종 밸런스 확정이 아니다.

이번 개정은 이전 계획의 **주력·보조 기술 바로가기 두 개** 안을 대체한다. 전투의 기본 입력은 이동·공격·대기이며, 영혼석이 그 행동에 기술과 반응을 붙인다. 별도의 기술 선택·조준 버튼을 늘리는 대신 **영혼석 하나로 행동이 달라지고, 두세 개부터 효과가 연결되는 전투**를 만든다.

현재 실행 규칙은 [영혼석 6개 영구 흡수](../../soulstones.ko.md)와 [영혼석 마법 연결](../../soulstone-spells.ko.md)에 기록되어 있다. 전 속성·상태·물리·지원·소환 계열의 발동과 연계는 [공격·대기 영혼석 규칙](../specs/2026-09-27-attack-wait-soulstone-rules-design.md)을 따른다. 이 문서는 새 시험 프로필의 설계와 원정 적용 단계를 구분한다. 기존 원정의 규칙을 소급 변경하지 않는다.

## 개정 2 — 현재 적용 규칙

2026-09-27 추가 단순화를 구현했다. 아래 최초 계획 중 체력 임계값·이동·회피·막기·처치·무기 종류·조준 누적·복합 상태·확률 조건은 폐기한다. 발동은 공격 확정·적중·의도적 대기에 한정하고 연쇄에는 상태 하나 또는 자기 소환수 존재만 요구한다. 대기 한 번으로 준비하며 추가 대기로 위협·조준을 누적하지 않는다. 강한 치유·소환·제어의 기존 재사용과 한도는 유지한다.

데이터 106개 효과와 기존 영혼석 연결 ID는 보존했다. 실행기·NPC 예상 가치·상태창·흡수 카드의 연계 판단을 같은 규칙으로 맞췄다. 변경 영역의 검사 세 묶음(432 / 38 / 23항목)이 통과했다. 현재 계약은 [개정된 규칙](../specs/2026-09-27-attack-wait-soulstone-rules-design.md)과 [실행 매핑](../../attack-wait-soulstones.ko.md)을 우선한다. 아래 내용은 최초 구현 순서의 기록이다.

## 1. 참고 방향과 유지할 기반

Path of Achra의 공식 소개는 간단한 조작, 캐릭터 구성, 발동 효과의 조합을 강조한다. 참고할 부분은 행동에 효과를 연결하고 그 결과가 다음 효과로 이어지는 구조다. 아래 공격·대기 분류, 영혼석 수, 연쇄 제한과 예시는 **우리 프로젝트의 설계**이며 Achra의 원본 규칙·수치를 재현한다는 뜻이 아니다. 출처: [개발자 공식 소개](https://store.steampowered.com/app/2128270/Path_of_Achra/).

현재는 기본 스탯·부위 패시브·종족 액티브·선택 주문·역할 조합·속성 조합을 함께 이해해야 한다. 새 구성에서는 흡수한 영혼석의 효과가 공격·대기·반응 중 어디에 연결되는지 바로 드러나게 한다. 별도 주문 선택 단계와 반복적인 기술 메뉴 진입을 기본 전투에서 없앤다.

유지하는 계약:

- 전통 턴제. 주인공은 직접 행동하고, 동료·NPC·몬스터는 기존 행동 시간과 Utility AI를 사용한다. 새로운 자동 전투 모드로 전환하지 않는다.
- 영혼석은 레벨당 1칸, 최대 6칸. 흡수 즉시 적용, 교체·해제 불가, 같은 부위·속성 중복 흡수 불가. 가득 차면 추가 흡수를 거부한다.
- 안전한 지역·야영에서 흡수한다. 봉인은 효과만 일시 정지하고 칸과 원래 연결을 보존한다.
- 캐릭터 레벨 최대 10과 최대 3인 파티를 유지한다. 능력치·장비·신체·성격·관계·적대·구조 시스템은 전면 재작성하지 않는다.
- 동료·NPC·몬스터는 시야 밖에서도 기존 자율 행동을 계속한다. 화면에 보이지 않는 효과도 시뮬레이션에서는 정상 처리한다.
- 대각선 이동·공격, 기본 공격의 한 칸 접근, 탐색 중지, 자리 교환은 기존 조작을 유지한다.
- 새 에셋은 적용 전에 사용자 검토를 받는다. 첫 시험은 기존 에셋과 VFX를 사용한다.

## 2. 효과 역할·발동 시점·콘텐츠 분류

효과 역할과 발동 시점을 구분한다. 큰 분류나 이름만으로 숨은 효과를 부여하지 않는다.

| 축 | 기본 표시 | 역할 |
| --- | --- | --- |
| 효과 역할 | 공격형 / 방어형 / 연쇄형 | 피해·방어·연결 중 무엇에 기여하는가 |
| 발동 시점 | 공격 확정 / 적중 / 대기 / 피격 / 회피 / 막기 / 처치 / 소환 등 | 어떤 사건으로 시작하는가 |
| 효과 분류 | 탱커 / 근접 딜러 / 원거리 딜러 / 캐스터 / 서포터 | 어떤 종류의 효과인가 |
| 연결 속성 | 출혈 / 독 / 불 등 | 다음 효과가 무엇에 반응하는가 |

대기 시 화상은 공격형이고 대기 시 얼음 갑옷은 방어형이다. 화상 대상 적중 시 폭발은 연쇄형이다. 한 영혼석이 세 역할을 모두 주지 않는다. 여섯 칸에 역할별 개수를 강제하지 않는다. 처치·피격·회피·상태 부여·소환수 행동은 발동 사건 또는 **반응**이며 별도 조작 버튼으로 늘리지 않는다. 이동 후 첫 공격 강화 같은 기존 조건도 보조 조건으로 남긴다. 모든 효과를 공격·대기 이벤트로 억지로 바꾸지 않는다.

큰 분류는 기존 내부 ID `TANK / MELEE / RANGED / MAGIC / SUPPORT`를 유지한다. 표시 이름은 세계적으로 통하는 역할 용어로 한다: 탱커·근접 딜러·원거리 딜러·캐스터·서포터. 세부 유형(방어·회피·출혈 등)이나 속성(출혈·독·불)과 겹치는 단어를 쓰지 않는다. 기존 세부 유형 17개는 호환·AI용으로 남길 수 있지만 기본 도감·상태창에서는 다섯 분류를 사용한다. 별도의 직업 → 공격형/대기형 → 속성 선택 절차를 추가하지 않는다.

- 몬스터의 대표 효과는 기존 규칙을 그대로 쓴다. 공격·대기 발동 체계를 몬스터에 맞추지 않는다. 같은 세션 안에서도 인물 종류로 적용 범위를 구분한다. 적대 NPC는 새 인물 규칙을 유지하며 몬스터로 취급하지 않는다.

## 3. 공격과 대기의 실행 계약

### 3.1 공격형

공격 버튼은 현재 대상에게 기본 공격하거나, 사거리 밖이면 한 칸 접근한다. 실제로 확정한 기본 공격에서 공격형 효과를 시작한다.

- **공격 시**와 **적중 시**를 구분한다. 합법적인 공격이 빗나가도 공격 시 효과는 가능하지만 적중 시 출혈은 발생하지 않는다.
- 접근 이동·자리 교환·자동탐색 이동에는 공격형 효과가 발동하지 않는다.
- 대상 없음·사거리 초과·시야 밖 등 거부된 공격 입력은 행동 시간·MP·재사용·조준을 소비하지 않는다.
- 추가타·화염 피해·소환수 공격을 주인공의 새 기본 공격으로 취급하지 않는다. 이어질 수 있는 반응은 영혼석 데이터에서 명시한다.
- 공격 대상 선택, 기본 명중·방어·피해 계산은 기존 경로를 사용한다. 화면의 아이콘이 별도 공격 판정을 수행하지 않는다.

### 3.2 대기형

대기는 **자기 위치에서 의도적으로 한 행동을 확정하는 것**이다. 현실 시간으로 아무 입력도 하지 않는 것, 제자리에서 공격한 것, 전역 라운드가 지난 것을 대기형 발동으로 취급하지 않는다.

- 합법적인 대기 행동마다 대기 이벤트를 정확히 한 번 발행한다. 상태 갱신과 전역 라운드 처리는 별도로 유지한다.
- 대기에는 기존 행동 비용이 든다. 적·NPC·지속 피해·시간 제한도 진행한다. 효과마다 추가 AP나 새 턴을 소비하지 않는다.
- 대상·재사용·소환 한도 때문에 일부 효과가 발동하지 않아도 대기 자체는 정상 실행된다. 실패한 자동 효과는 재사용을 시작하지 않는다.
- 기절·행동 불능으로 강제로 시간을 넘긴 경우, AI의 머뭇거림·길막에 따른 강제 대체 대기는 대기형 효과를 발동시키지 않는다. 의도적 대기와 강제 시간 경과를 행동 사유로 구분한다.
- **새 시험의 영혼석 자동 효과는 MP를 소모하지 않는다.** 대기 화상은 주변 3칸, 대기 중독은 주변 4칸의 유효 적에게 적용한다. 범위·공격 경로·위치·기존 행동 시간으로 먼저 조절하고 재사용은 필요한 개별 효과에만 둔다. 기존 MP 소모 안을 대체하며, MP 능력치·아이템·회복 효과의 전체 제거는 새 원정 전환 단계에서 별도로 매핑한다.
- 전투용 치유·소환은 초기 시험에서 유효한 적대 조우가 있을 때만 발동한다. 적이 없는 곳에서 대기를 반복해 무제한 회복·소환하는 구조를 만들지 않는다. 이를 주인공 화면의 시야 여부만으로 판정하지 않는다.
- 대기는 식량 하나를 즉시 소모하는 휴식으로 되돌리지 않는다. 기존 시간·원정 자원 규칙을 사용한다.

**대기와 이동하지 않음은 서로 다른 조건이다.** 기존 `KOBOLD_HEART`의 완료 라운드 조준·이동 초기화는 기존 프로필에서 유지한다. 새 집중 구성에 대기 시 조준을 붙일 때에는 기존 라운드 조준과 중복 적립하지 않도록 해당 구성의 조준 획득원을 하나로 정한다.

### 3.3 자동 대상·자원·재사용

기술마다 자동 대상 규칙을 데이터로 정한다. 플레이어가 매번 조준하거나 자동 대상 설정 메뉴를 편집하게 하지 않는다.

| 효과 | 기본 대상 규칙 |
| --- | --- |
| 공격에 연결된 추가 효과 | 기본 공격 대상. 광역 중심도 그 대상의 위치 |
| 대기형 공격·저주 | 효과에 명시한 단일 대상 또는 광역 범위. 첫 화상·중독 효과는 사거리·시야·경로를 만족하는 범위 내 유효 적 모두 |
| 자기 방어·조준 | 자신 |
| 자동 치유 | 범위 내 자신·살아 있는 아군 중 HP 비율이 가장 낮은 인물 |
| 소환 | 기존 소환 한도와 빈 인접 칸 판정, 안정적인 칸 선택 순서 |

동률은 안정적인 인물 ID·좌표 순서로 결정한다. UI 갱신 때 RNG를 사용하지 않는다. 주인공의 공격성 자동 효과는 현재 시야와 해당 기술의 공격 경로를 지킨다. NPC·몬스터는 자신의 인지·사거리·공격 경로를 사용하며 주인공의 시야에 의존하지 않는다. 주변이 보이는 것과 벽을 관통해 공격 가능한 것은 구분한다.

새 인물 프로필의 자동 효과와 후속 연계는 MP 비용 없이 시험한다. 기존 주문을 모두 무료 실행하는 방식이 아니라 명시적으로 매핑한 시험 효과의 계약이다. 강한 치유·소환은 유효 부상·적대 조우·범위·개별 재사용·소환 한도를 정하고 검사 후 실제 실행에만 재사용을 시작한다. 기존 원정의 MP·주문 규칙은 보존한다. 물약·두루마리는 보유 수량을 사용한다.

기본 적중의 상태 부여를 먼저 처리하고 실제 상태를 읽어 폭발·전이 같은 연계를 처리한다. 같은 적중에서 새로 부여한 상태도 연결될 수 있다. 같은 단계 안에서는 명시된 우선순위와 효과 ID 순으로 실행하고 소환 한도·대상을 실행 직전에 다시 확인한다. 표시 순서나 흡수 순서 때문에 결과가 달라지지 않는다. 기본 효과는 확정 발동하되 명중·상태 저항은 기존 규칙을 따르며, 기존 주문의 실패율은 기존 프로필에서 유지한다.

물약·두루마리·장비 사용과 전술 명령은 수동 조작으로 남긴다. 자동으로 바뀌는 것은 새 프로필에서 명시적으로 연결한 영혼석 기술이다.

## 4. 전체 영혼석 규칙과 예시 구성

새 영혼석은 **공격형 / 방어형 / 연쇄형** 중 역할과 실제 발동 시점이 분명해야 한다. 발동 효과·상태 연결·행동 강화는 이 역할의 구체적인 동작이다. 이름·기본 스탯·트리거·대상·효과·비용·재사용은 흡수 전에 확인한다. 종족 전체에서 액티브를 암묵적으로 물려받거나 흡수 후 주문 목록을 다시 고르게 하지 않는다.

- 영혼석 0개에서도 기본 무기 공격으로 전투가 가능하다.
- 시작 구성에서 처음 제공하는 영혼석은 혼자서 바로 작동한다. 다른 영혼석이나 희귀 장비가 있어야 하는 순수 연결 영혼석을 단독 시작 보상으로 주지 않는다. 연결 영혼석의 필요한 상태·조건은 흡수 전에 표시한다.
- 두세 개부터 조건과 효과의 연결을 확인할 수 있어야 한다. 최대 여섯 개는 완성·변형의 폭이며 작동을 위한 필수 개수가 아니다.
- 혼합 구성도 허용하고 흡수한 효과는 모두 적용한다. 효과 역할·발동 시점이 다르다는 이유로 일부 효과를 비활성화하지 않는다.
- 교체 불가이므로 흡수 전 현재 구성과 연결되는 효과를 보여 준다. 흡수를 자동 실행하거나 특정 예시 구성만 강제하지 않는다. 드롭 선택 보상 추가는 별도 결정 사항이다.

### 4.1 전체 설계 범위

화염·독·방어는 구조를 설명하는 예시이며 전체 콘텐츠 범위가 아니다. 전 계열에 공격형·방어형·연쇄형의 영혼석 후보를 정의하고 적중·대기·피격 등 발동 시점을 별도로 연결한다. [구체 규칙](../specs/2026-09-27-attack-wait-soulstone-rules-design.md)에 다음 계열의 공격형·대기형 시작, 상태·조건 연결, 마무리, 제약을 모두 정의한다.

- 원소·피해: 화염·독·냉기·전기·출혈·정신.
- 상태·지원: 저주·축복·물·바람·방어·회복·재생.
- 인물 생성·반응: 소환·사령.
- 물리 방식: 연타·강타·속사·집중·급소·광폭·회피·반사.
- 교차 연결: 물+전기/냉기, 화염+독/출혈, 냉기+강타, 저주+정신/사령, 축복+방어/소환, 바람+원거리.

기존 피해 타입과 상태를 재사용한다. 전하 표식·축복·사령 낙인 등 신규 상태 제안은 기존 구현과 구분한다. 피격형 원소 방어는 다음 자기 정상 행동까지 유효 시도 1회로 제한하고 확률 실패에도 준비를 소비한다. 갑옷·저항·자세는 갱신하며 동일 보정을 무한 누적하지 않는다. 기존 세부 유형 17개에 대응하는 설계와 매핑 검증도 포함한다. 구현을 작은 묶음으로 진행하더라도 다른 계열의 규칙을 미정 상태로 남기지 않는다.

### 4.2 화염 — 부여 후 적중으로 폭발

| 영혼석 역할 | 효과 | 행동 차이 |
| --- | --- | --- |
| 적중형 부여 | 기본 적중 시 화상 | 직접 공격하면서 상태를 건다 |
| 대기형 부여 | 대기 시 주변 3칸 유효 적 모두에게 화상 | 적이 모인 위치에서 대기로 준비한다 |
| 연결 | 화상 대상 기본 적중 시 대상 주변 1칸 화염 폭발 | 상태를 건 뒤 기본 공격으로 터뜨린다 |

적중형 부여 + 폭발은 같은 기본 적중에서 연계된다. 대기형 부여 + 폭발은 대기 후 기본 적중으로 연계된다. 대기의 상태 부여나 폭발 피해를 새 기본 적중으로 취급하지 않는다. 폭발은 초기 시험에서 화상을 새로 부여하지 않는다.

### 4.3 독 — 부여 후 적중으로 전이

| 영혼석 역할 | 효과 | 행동 차이 |
| --- | --- | --- |
| 적중형 부여 | 기본 적중 시 중독 | 직접 공격한 적에게 지속 피해를 남긴다 |
| 대기형 부여 | 대기 시 주변 4칸 유효 적 모두에게 중독 | 범위 안의 여러 적에게 상태를 건다 |
| 연결 | 중독 대상 기본 적중 시 대상 주변 1칸으로 전이 | 주변 적·대기 범위 가장자리 밖으로 상태를 퍼뜨린다 |

전이는 남은 중독 지속시간을 복사하며 즉시 폭발 피해를 주지 않는다. 이미 중독된 적은 더 긴 남은 시간을 유지하고 중독 피해 횟수가 중복되지 않는다. 같은 행동 안에서 전이가 전이를 다시 부르지 않는다. 이후 새 기본 적중으로는 다시 전이할 수 있다.

### 4.4 방어 — 대기로 버티고 시선을 끈다

방어태세와 시선 끌기는 별도 영혼석이다. 방어태세는 대기로 갱신하는 일정한 직접 피해 감소이며 다음 자신의 행동 시작에 끝난다. 시험값 20%이고 연속 대기로 감소율을 누적하지 않는다.

시선 끌기는 연속 의도적 대기에 따라 위협도 1·2·3단계로 상승한다. 다른 행동·강제 건너뛰기·다운·봉인·조우 종료 시 초기화한다. 이미 그 인물을 인식한 적의 다음 대상 선택에만 보정하며 전 층 적 호출·강제 근접 이동·확정 공격 대상 변경을 만들지 않는다. 기존 성격·거리·전술 판단과 함께 평가한다.

### 4.5 전체 계열 검증

모든 계열을 영혼석 1·2·3·6개와 솔로·최대 3인 파티에서 비교한다. 실제 부위별 발동·범위·대상·상태·지속·소유권·재사용·연쇄를 매핑하고 누락된 계열을 전체 완료로 간주하지 않는다. 위 화염·독·방어를 엔진의 첫 검증 묶음으로 사용할 수 있지만 나머지 원소·저주·축복·소환·물리 규칙도 같은 계획의 구현 범위다.

냉기의 반복 빙결·전기 연쇄·축복 보호·조우당 치유·소환 한도와 원소별 갑옷·화염막·독막·확률 마비·저항·회피·피해 분담 계약은 [구체 규칙](../specs/2026-09-27-attack-wait-soulstone-rules-design.md)에 명시한다. 기존 조건·상태·소환 처리를 재사용하고 누락된 영혼석을 몰래 비활성화하지 않는다.

## 5. 연쇄의 허용 범위와 실행 순서

**의도한 연쇄를 살리고 순환 발동을 막는다.** 추가 피해를 전부 말단 효과로 취급하면 조합의 재미가 줄어든다. 반대로 모든 추가타를 새 기본 공격으로 취급하면 무한 발동과 과도한 피해가 발생한다.

현 구현의 제약:

- `EffectEngine.EVENTS`에 `ATTACK / HIT / KILL / STATUS_GIVEN / SUMMON` 등이 있지만 대기 전용 이벤트는 없다.
- `EffectEngine.MAX_DEPTH = 2`와 `Reactions.once`가 재발동을 제한한다.
- `Reactions.SECONDARY`와 피해 처리 경로는 추가·반응 피해의 여러 패시브 발동을 억제한다.

기존 `Reactions.status_react`의 자동 화상+독 폭발·상태 소비·빙결 파쇄도 새 명시적 연결과 겹치지 않게 원인 효과의 반응 정책으로 분리한다. 몬스터의 기존 대표 효과와 기존 원정 정책은 보존하고, 새 인물의 자동 효과·지속 피해·소환수 행동에는 출처를 전달한다.

따라서 이벤트 이름 하나를 추가하거나 `MAX_DEPTH` 숫자만 올리는 것으로 끝내지 않는다. 새 프로필은 허용된 후속 이벤트를 명시적으로 전달하는 제한된 처리 큐를 설계한다. 기존 프로필의 재귀·2차 피해 처리는 그대로 둔다.

실행 계약:

1. 합법적인 기본 행동을 확정하고 기존 행동 번호를 한 번만 연다. 후속 효과에서 새 행동 번호나 `begin_action`을 호출하지 않는다.
2. 기본 공격의 명중·피해를 기존 계산으로 확정한다. 새 인물 프로필은 적중형 상태 부여 후 실제 상태로 연계를 판정한다. 이번에 새로 건 화상·중독도 연결될 수 있지만 기본 명중·피해를 소급 변경하지 않는다. 사망한 대상은 죽기 직전 상태·위치만 사용하고 사체에 상태를 새로 부여하지 않는다.
3. 상태 적용·처치·소환 등이 실제 성공한 경우에만 후속 이벤트를 등록한다. 면역으로 막힌 상태·실패한 소환은 성공 이벤트를 만들지 않는다.
4. 큐의 이벤트는 원인 행동 번호·발동 주체·효과/규칙 ID·대상·피해 및 처치 소유자·부모 이벤트를 가진다. 시간 경과의 지속 피해와 소환수 행동은 각각 자신의 원인 행동에 귀속한다.
5. 효과별로 연결 가능한 이벤트와 행동당·대상당 발동 한도를 데이터에 명시한다. 기본은 규칙당 행동당 1회이며 다중 대상·연타 예외는 유한한 한도를 선언한다.
6. 추가타가 일반 공격형 효과를 재시작하지는 않지만, 명시한 적중·상태·처치 반응은 이어질 수 있다. 같은 규칙의 동일 대상 재진입은 한도 없이 허용하지 않는다.
7. 광역 효과의 다중 대상 처리는 큐 한도에 의해 임의로 첫 적만 맞지 않도록 검증한다. 규칙 한도와 전체 비상 한도는 구분한다.
8. 큐 안정화 뒤 기본 행동 비용·전투 종료·다음 인물 행동 처리를 기존 순서에 연결한다. 마지막 적 처치의 전이·회복이 전투 종료로 누락되지 않게 한다. 발동 주체가 사망하면 살아 있어야 하는 효과는 중지하고 명시적인 사망 반응만 처리한다.

전체 이벤트 수의 비상 한도는 비정상 데이터·순환을 잡는 개발용 보호 장치다. 정상 빌드에서 자주 도달하는 제한을 밸런스 수단으로 쓰지 않는다. 한도에 도달하면 원인과 누락을 테스트·리포트에 기록하며 조용히 성공 처리하지 않는다.

최초 데이터는 짧은 `행동 → 상태 → 반응` 연결부터 검증한다. 피해 상한을 일괄 적용해 연결을 무의미하게 만들기보다 효과별 피해·범위·재사용·발동 횟수를 조절한다.

## 6. 모바일 UI와 피드백

새 시험 프로필에는 별도 영혼석 기술 바로가기 바를 두지 않는다. 기본 아래 화면은 다음 순서다.

```text
로그: 최대 4줄, 한 줄에 한 문장
인물 카드: 이름 / HP / 필요한 상태 (기존 프로필은 HP·MP)
공격·대기 버튼 바로 위: 현재 발동 가능한 작은 효과 아이콘
공격 | 대기 | 탐색 | 전술 | 가방
```

효과 아이콘은 조작 버튼이 아니다. 빈 아이콘 때문에 고정 높이의 큰 영역을 남기지 않는다. 공격·대기를 한 번 누르면 행동을 실행하며 효과 선택 창을 띄우지 않는다. 물약·두루마리 등 수동 대상 선택은 가방의 기존 조작을 사용한다. 기존 미니맵·현재 위치·턴수·식량·메뉴 HUD와 맵 중심 화면을 유지한다.

표시 계약:

- 공격·대기별 자동 대상과 유효한 조건을 읽어 지금 실행 가능한 효과를 표시한다. 미래 RNG 결과·명중·저항 성공을 확정된 것처럼 보여 주지 않는다.
- 재사용·소환 한도·유효 대상 없음은 아이콘 상태와 상세에서 확인한다. 부가 효과가 준비되지 않았다고 기본 공격·대기 버튼을 비활성화하지 않는다. 새 시험에서 자동 효과의 MP 부족 표시는 없다.
- 조준은 `1 / 2 / 3`, 이동 후 강화는 공격 버튼 강조, 출혈·화상은 대상의 상태 아이콘과 지속값으로 표시한다.
- 원소별 방어 준비·사용 횟수·방어태세와 위협도 1·2·3단계를 인물 카드에 표시한다. 위협도 상승과 실제 적의 대상 변경을 구별한다. UI는 판정 자료를 읽기만 한다. 미리보기에서 피해·MP·스택·재사용·RNG·관계 상태를 바꾸지 않는다.
- 공격·대기·수동 아이템 조작 시 자동탐색·장거리 이동을 멈춘다. 취소 후 터치 이동을 정상 복원한다.
- 이동·카메라는 부드럽게 유지한다. 발동마다 큰 팝업·화면 흔들림·말풍선을 붙이지 않는다. 짧은 VFX로 불꽃 → 화상 → 확산의 원인을 구분한다.
- 로그는 여러 적에게 발생한 같은 발동을 묶어 한 문장으로 표시한다. 자세한 원인 연쇄는 개발 리포트로 남기고 게임 화면에 전부 나열하지 않는다.
- 기존 제작 에셋을 사용하고 버튼 터치 영역은 최소 44 논리 픽셀을 목표로 한다. 맵 타일의 터치 영역을 겹치게 확대하지 않는다.

영혼석 탭은 기존 3열 × 2행 여섯 칸을 유지한다. 실제 적용되는 효과를 다음처럼 요약한다.

```text
공격: 적중 시 출혈 · 출혈 대상 추가타
대기: 조준 · 보호막
반응: 출혈 대상 처치 시 회복
```

이 예시 요약은 해당 효과가 모두 실제 흡수·활성화된 구성에만 표시한다. 준비되지 않은 조건을 항상 적용되는 합산 수치로 바꾸지 않는다. 봉인된 효과는 적용 요약에서 제외하고 칸에 봉인을 표시한다. 가방의 흡수 전 상세도 같은 발동 계열·효과·조건·비용을 보여 준다.

도감 기본 필터는 탱커·근접 딜러·원거리 딜러·캐스터·서포터다. 영혼석의 공격형·방어형·연쇄형 역할과 적중·대기·피격 등 발동 시점은 별도 짧은 표시로 구별한다. 역할 조합 표시는 남기는 경우 실제 얻는 효과만 표시하고, 기본 화면에 17개 세부 유형 비율이나 복잡한 분포를 늘어놓지 않는다.

## 7. NPC·기존 원정·수치 체계

NPC·동료는 같은 영혼석·자동 대상·비용·발동 규칙을 사용한다. 주인공에게만 효과가 더 적용되는 별도 전투 수학을 만들지 않는다.

Utility AI는 기본 공격·이동·의도적 대기의 **연결 효과까지 포함한 가치**를 비교한다. 유효 대상·재사용·소환 공간·연계 상태를 만족하지 않으면 준비된 효과처럼 점수를 주지 않는다. 새 자동 효과는 MP를 후보 조건으로 사용하지 않는다. 예측은 실제 상태를 바꾸지 않으며 효과 실행은 공통 경로에서 한 번만 한다. 자동으로 전환된 기술을 수동 기술 후보에도 중복 등록하지 않는다. 성격·전술·적대·위기·구조 판단은 유지하며 효과가 있다는 이유로 대기만 강제하지 않는다.

호환성은 세션별 프로필과 인물 종류로 분리한다. 몬스터의 대표 효과는 같은 시험 세션에서도 기존 규칙이다. 적대 관계가 바뀐 NPC는 새 인물 효과를 유지한다.

- 기존 원정 및 프로필 필드가 없는 데이터는 기존 액티브·선택 주문·역할 조합 규칙을 사용한다.
- 새 프로필은 먼저 아레나에서만 적용한다. 전역 static 데이터 변경으로 다른 세션에 영향을 주지 않는다.
- 새 프로필에 명시적으로 매핑한 영혼석만 시험한다. 누락된 기술을 숨긴 채 기존 카탈로그 전체를 가져오지 않는다.
- 매핑한 영혼석은 새 발동 연결을 적용하고 이전 액티브·선택 주문을 중복 부여하지 않는다. 원본 `active / spells / rules` 데이터는 기존 원정용으로 보존한다.
- 기존 원정의 주문 선택·흡수 상태·저장 데이터는 자동 변환하거나 소실시키지 않는다. 런타임 보조 큐·예측 캐시는 저장하지 않고 복원 시 다시 만든다.
- 역할 2·4·6개와 속성 2·3개 개수 보너스는 새 시험 프로필에서 끈 구성을 먼저 시험한다. 기본 스탯과 고정 효과는 유지하며 기존 프로필의 보너스는 바꾸지 않는다. 유지 여부는 별도 비교 후 결정한다.

## 8. 데이터와 코드 적용 위치

새 연결은 기존 효과의 이벤트·조건·동작을 재사용하며 구체적인 부위 데이터에서 지정한다. 설명·역할·속성 문자열만 읽어서 기술을 추론하지 않는다.

권장 연결 필드는 `effect_ids`, `effect_role`(공격/방어/연쇄), `target_policy`, `cooldown`, `followup_events`, `proc_limit`, `summary`다. 발동 사건은 기존 `rules.when`으로 기록하고 역할 필드와 섞지 않는다. 새 자동 효과에 MP 비용 필드는 필수가 아니며 기존 수동 능력의 비용과 구분한다. 기존 `rules.when / if / do`가 표현할 수 있는 값은 중복 저장하지 않는다. 이 필드와 대기 이벤트 이름은 **설계 제안이며 현재 구현된 스키마가 아니다.** 표시용 효과 역할·발동 시점과 실행 규칙은 검증기로 일치 여부를 확인한다.

## 9. 구현 단계와 완료 조건

### 단계 1 — 기준선과 두 구성의 데이터 계약

현재 커밋·장비·레벨·파티 인원·시드를 고정한다. 전체 계열을 구체 규칙의 공격·방어·연쇄 역할과 발동 시점·제약에 맞춰 실제 부위 ID·효과·범위·재사용·연쇄·VFX로 매핑한다. 화염·독·방어는 공통 엔진의 첫 아레나 묶음으로 사용한다. 시험 프로필을 분리하고 MP 없는 시험 보상과 기존 MP 관련 보상을 구분한다.

완료 조건: 영혼석 0·1개에서도 전투가 가능하며 기존·시험 세션을 동시에 생성해도 서로 영향을 주지 않는다. 미매핑 부위·알 수 없는 이벤트·제한 없는 순환은 검증에서 드러난다.

### 단계 2 — 공격·대기 발동과 제한된 연쇄

의도적 대기 이벤트, 자동 대상, 기본 행동 번호를 재사용하는 큐를 구현한다. 기본 적중의 상태 부여 후 연계, 광역 대기, 방어 갱신·연속 대기 위협도를 연결한다. 행동 시간·상태 저항·처치 귀속·전투 종료를 공통 처리 경로에 연결한다.

완료 조건: 실제 기본 공격 또는 대기 한 번만 시간 비용을 소비한다. 합법적인 연결은 끝까지 처리하고 순환은 제한된다. 공격 이동·강제 대기·면역·거부된 입력이 잘못 발동하지 않는다.

### 단계 3 — 모바일 요약과 결과 피드백

새 프로필에서 기존 기술 바를 제거하고 공격·대기 위에 발동 아이콘을 연결한다. 흡수 전 상세, 영혼석 여섯 칸, 공격/대기/반응 요약을 같은 실제 데이터로 만든다. `320×568 / 390×844 / 430×932`에서 가로·세로 범위와 실제 캔버스 배율을 확인한다.

완료 조건: 기본 전투를 기술 메뉴 없이 한 번의 공격·대기 터치로 진행한다. 어떤 효과가 준비됐고 무엇 때문에 연쇄가 발생했는지 화면에서 구분한다. 상세·긴 이름·여섯 칸 때문에 화면 크기가 늘어나지 않는다.

### 단계 4 — 1·2·3·6개 구성의 플레이 확인

같은 조우에서 영혼석 추가 전후와 화염·독·방어 구성을 비교한다. 인접 적·궁수·막힌 경로·밀집·분산 적을 사용하고 공격만 또는 대기만 반복하는 전략도 시험한다. 역할·속성 개수 보너스 비교는 다른 조건을 고정한 별도 실험으로 둔다.

완료 조건: 추가 영혼석이 숫자 증가 외에 대상·위치·행동 순서에 변화를 준다. 화염·독 구성이 대기를 주력으로 쓰는 것은 허용하되 모든 상황에서 같은 안전한 반복만 최적이면 대상·범위·재사용·적 대응을 수정한다. 연쇄의 기여가 보이고 정상 구성에서 비상 한도가 발생하지 않는다.

### 단계 5 — 나머지 전체 계열과 NPC AI

공통 엔진 검증 후 냉기·전기·정신·출혈·저주·축복·물·바람·회복·소환·사령·물리 조건과 교차 연결을 같은 입력에 구현한다. NPC가 각 공격·방어·연쇄와 확률 방어의 기대값을 예상해 공격·의도적 대기를 선택하도록 기존 Utility AI 후보를 보강한다. 공유 제어 제한·유익 상태·조우당 회복·소환 한도·빈칸·지속시간·시야 밖 행동을 확인한다.

완료 조건: 구체 규칙에 적힌 전 계열과 기존 세부 유형 17개의 실제 매핑·회귀 검증이 완료된다. 부분 매핑을 전체 완료로 표시하지 않는다. 동료 영입 후 기술 편집이 필수가 되지 않는다. 예측·실행의 대상·범위·재사용·소환 한도가 일치하고 시야 밖에서도 진행한다. 성격·전술·관계·적대·구조 행동이 유지된다.

### 단계 6 — 새 원정 적용과 현재 규칙 문서 갱신

사람이 모바일 조작·연쇄의 가시성·화염·독·방어 구성의 차이를 확인한 뒤 새 원정 기본 프로필을 결정한다. 매핑된 영혼석부터 확대하고 이전 원정은 기존 규칙으로 남긴다. 적용한 결과를 [영혼석 문서](../../soulstones.ko.md)와 [마법 연결 문서](../../soulstone-spells.ko.md)에 프로필별로 반영한다. 새 원정의 MP 자원·장비·영혼석 보정·회복 효과·NPC 판단을 제거하거나 대체하는 매핑을 완성한 뒤 원정 기본값을 전환한다.

완료 조건: 1인·최대 3인 기준 조우, 층 누적 자원·후퇴·사망을 검증한다. 기존 저장·선택 주문·봉인이 유지되고 새 원정에는 불완전한 매핑이 들어가지 않는다.

## 10. 검증과 수집할 자료

기존 `part_effects / effect_engine / effect_data / part_stones / role_combos / essence_spells / stone_magic / build_actives / mobile_hud / essence_ui / npc_essences / companion_tactics` 검사를 프로필별로 유지한다. 다음 회귀 검사는 실제 실패 가능성에 집중한다.

- 기본 공격·대기 한 번의 이벤트 중복, 접근 이동·자리 교환·강제 대기의 잘못된 발동.
- 거부된 입력·실패한 효과의 시간·재사용 소비, 새 자동 효과의 잘못된 MP 소비 또는 MP 부족 차단. 기존 프로필의 MP 계약은 유지한다.
- 적중형 화상·중독 부여 뒤 정상 연계가 누락됨, 상태 면역인데 연계가 발동함, 폭발·전이·추가타의 자기 재발동.

- 마지막 적 처치 뒤 회복·전이 누락, 사망한 주체의 불법 발동, 지속 피해·소환수 처치 소유권 소실.

- 방어태세의 무한 누적·행동 후 잔존, 위협도의 전 층 인식·강제 접근·확정 공격 변경, 적대 NPC의 잘못된 몬스터 효과 전환.
- 반복 빙결·기절의 무한 행동 봉쇄, 전기 연쇄의 중복 도약, 유익 상태·보호의 재발동, 회복 횟수의 같은 적 재인식 리셋, 소환수 자연 만료의 사망 농사.

| 성장 | 영혼석 1·2·3·6개에서 효과 작동·연결·기여의 변화 |
| 원정 | 경과 tick, HP·MP·식량·소모품·야영, 층 도달·후퇴·사망 분포 |

첫 사람 확인에서는 '첫 영혼석의 효과를 알아봤는가', '두 번째 효과가 왜 연결됐는지 이해했는가', '같은 적을 다른 방식으로 상대했는가'를 기록한다. 설명을 늘리는 대신 행동·효과·표시를 먼저 수정한다.

밸런스는 [기존 방법론](../../balance-method.ko.md)의 전투·전술·조우·원정 계층을 유지한다. 연쇄 효과의 수만 위협이나 행동 가치로 합산하지 않고 실제 행동·시간·유효 피해·위험 노출로 측정한다. 회귀 검사 통과·자동 승률 개선만으로 재미를 판정하지 않는다. 수치 목표는 기준선 실측 뒤 정하며 사람의 모바일 플레이 확인과 함께 판단한다.
