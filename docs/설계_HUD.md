# 던전 HUD 설계

상태: ✅ 구현됨 (71eae4a4, b79bfc4e, 1058c664, 13f5492a). §10 적용 기록 — 구현하면서 바뀐 배치가 이 문서에 반영돼 있다

작성일: 2026-09-29 · 대상: `js/` 모듈
이 문서 하나가 던전 화면 UI 전반(상단·로그·하단·버튼·대상 정보·경고)의 기준이다. 상단에 표시되는 횃불 자원의 규칙도 §7에 함께 둔다. (이전 `추가_HUD_횃불.txt`를 대체한다.)

- 모듈 구조는 `코드정리_가이드.md`를 따른다: UI는 `ui/`, 횃불 규칙은 `core/torch.js`, 수치는 `data/torch.js`.
- 게임 규칙과 격자 조작은 바꾸지 않는다.
- 그래픽 톤은 지금의 디오라마 스타일을 유지한다(다크 판타지 전환은 보류).

## 0. 원칙

- **정보는 위에서 보고, 손은 아래에서만 움직인다.** 한 손 엄지로 모든 조작이 가능해야 한다.
- HP, 횃불, 쿨타임 숫자, 적 수는 한눈에 읽혀야 한다.
- 위험(예고 범위 안에 서 있음)은 놓칠 수 없게 보여준다.

## 2. 상단 HUD

1. **미니맵**(왼쪽): 가 본 곳, 계단, 나, 보이는 적을 점으로. 누르면 전체 지도가 화면을 덮고, 다시 누르면 닫힌다.
2. **위치와 턴**(오른쪽 첫 줄): 구역-층 번호, 구역 이름, 턴 수.
3. **횃불**(미니맵 오른쪽): 실제로 타오르는 작은 횃불 그림 + 남은 양 숫자(§7).
4. **보이는 적 수**(오른쪽 끝): 👁 3. 없으면 흐리게 0.
5. **보스 체력바**: 보스 층에서만 상단 HUD 바로 아래에 보스 이름과 함께.
6. 상단에는 상태 이상 아이콘을 두지 않는다(하단으로).

## 3. 로그

1. 던전 화면 바로 아래에 최근 로그 3~4줄. 오래된 줄일수록 흐려진다.
2. 누르면 전체 기록이 화면을 덮으며 펼쳐지고 스크롤된다. 다시 누르거나 닫기로 돌아간다.

## 4. 하단 HUD

### 4.1 HP · 보호막 · 상태 이상 (맨 위 줄)

- HP 막대와 숫자, 보호막 수치. 피해를 받으면 막대가 줄어드는 잔상(`hpghost`)을 유지한다.
- 그 오른쪽에 내 상태 이상 아이콘(남은 턴 작게). 많으면 겹쳐서 작아지고, 누르면 목록과 설명이 펼쳐진다.

### 4.2 소모품 빠른 슬롯 · 영혼석 스킬 (한 줄씩)

- 위 줄: 소모품 빠른 슬롯 6칸. 누르면 사용(던지는 물건은 조준), 길게 누르면 설명.
- 아래 줄: 영혼석 스킬 6칸.

- 사용 가능하면 밝게, 쿨타임 중이면 어둡게 남은 턴 숫자. 색 감소 연출("−1" 번쩍임)과 조준 방식은 `설계_영혼석_스킬.md`를 따른다.

### 4.3 버튼 5개 (맨 아래 한 줄, 같은 크기, 최소 높이 52px)

| 버튼 | 누르기 | 길게 누르기 |
| --- | --- | --- |
| **공격** | DCSS의 Tab처럼: 칠 수 있는 적(창 2칸·원거리 사거리)이 있으면 공격, 없으면 선택한 적(없으면 가장 가까운 보이는 적) 쪽으로 한 칸 | 지금 무기 정보 (무기 교체는 없다 — 가방에서 장착) |
| **대기** | 한 턴 쉼 (보라 쿨타임 감소) | 휴식: HP가 찰 때까지 쉬다가 적이 보이거나 맞으면 멈춤. 휴식도 횃불을 태운다 |
| **탐험** | 안 가 본 곳을 자동으로 돌아다닌다. **적이 보이거나 맞을 때만 멈춘다.** 보이는 물건·장비·영혼석·재료는 걸어가서 줍고 계속 간다. 횃불이 부족하면 등잔에도 들른다. 적이 보이면 비활성 | — |
| **상태** | 상태 창(§4.5). 하단의 상태 이상 아이콘을 눌러도 열린다 | — |
| **가방** | 장비 창을 바로 연다. 창 안의 서브탭: 🛡 장비(정착지에서는 창고 포함) · 🧪 소모품(누르면 사용, 던지기는 조준) · 💎 영혼석(6칸, 영혼석 가방, 같은 색 교체, 버리기 — 던전에서만) | — |

### 4.4 상황 버튼 (떠오르는 버튼)

- 처음 설계의 "5번째 버튼 = 상황"은 **상태 버튼으로 바뀌었다.** 상황 행동은 할 일이 있을 때만 하단 바 위에 떠오르는 버튼이 된다.
- 계단 ⬇내려가기, 등잔 🕯불씨 옮기기, 물건 ✋줍기, 쓰러진 사람 🤝구하기, 문 🚪열기/닫기.
- 영혼석을 밟으면 선택 창: 빈 칸에 흡수 / 같은 색 칸과 교체 / 가방에 넣기 / 두고 가기(바로 흩어진다 — 고르지 않고 움직여도 흩어진다).

### 4.5 상태 창

등불지기(몇 대째, 이전 직업, 시작 특성) · HP·보호막·횃불과 시야 · 상태 이상과 지속 오라 · 영혼석 스킬과 쿨타임 · 영혼석 가방 · 전투 수치와 출처 · 알고 있는 약점 · 이번 원정 기록.

## 5. 대상 정보 (길게 누르기)

1. 적을 0.4초 길게 누르면 정보 카드: 이름, HP, 약점 공격 형태(알려진 경우), 상태 이상, 준비 중인 행동(예고)과 그 범위. 카드가 떠 있는 동안 그 적의 예고 범위를 바닥에 강조한다. 손을 떼거나 바깥을 누르면 닫힌다.
2. 지형이나 물건을 길게 누르면 같은 방식으로 그 칸의 설명(물웅덩이: 감전 전도 등).

## 6. 위험 경고

- 내가 서 있는 칸이 적의 예고 범위 안이면 화면 가장자리가 붉게 맥동한다.

## 7. 횃불

### 7.1 설정

- 이 세계의 어둠은 **잊음**이다. 보통 불은 타기는 해도 어둠을 밀어내지 못한다.
- 어둠을 밀어내는 것은 사람들이 서로를 기억하는 힘으로 타는 **모닥불의 불**뿐이고, 등불지기의 횃불은 그 **불씨**를 옮겨 붙인 것이다.
- 불 영혼석 스킬의 불은 몬스터에게서 뜯어낸 불이라 풀을 태우고 적을 태울 수는 있어도 **횃불을 대신하지 못한다.**

### 7.2 규칙

1. 횃불은 식량 대신 쓰는 유일한 시간 자원이다. 최대 100.
2. 행동 1턴마다 0.5씩 탄다(휴식·탐험·대기 포함). **불 스킬은 횃불을 쓰지 않는다**(다른 불이다).
3. 횃불 양에 따라 빛 반경(시야)이 바뀐다.

| 횃불 | 시야 | 그 밖 |
| --- | --- | --- |
| 50 이상 | 기본 | — |
| 25~49 | −2 | — |
| 1~24 | −4 | 경고 연출 |
| 0 | 1칸 | 적이 나를 먼저 발견, 기습 판정(첫 공격 피해 +50%) |

4. 불 스킬로 붙은 불(타는 풀, 기름 폭발, 화상 입은 적)은 잠깐 주변을 비추지만 금방 꺼지고, **시야 계산에는 들어가지 않는다.** 색도 구분한다: 스킬 불은 붉은 주황, 모닥불 불씨(횃불·등잔)는 금빛.

### 7.3 채우기

| 방법 | 양 | 설명 |
| --- | ---: | --- |
| **옛 등불지기의 등잔** | +40 | 먼저 내려갔다 돌아오지 못한 등불지기들이 남긴 등잔. 층마다 1~2개. 상황 버튼 "🕯불씨 옮기기" |
| **모닥불 불씨 단지** | +60 | 정착지에서 만들어 가져가는 소모품(가방 한 칸). 요리사나 제단지기가 만든다 |
| 정착지 출발 | 가득 | 모닥불 밝기 60 이상이면 출발 시 최대치 +20 (`설계_스토리_정착지.md` §1.0) |

- 보통 연료(기름 재료 등)로는 채울 수 없다.
- 수치는 한 구역(3층)을 서두르지 않고 돌면 한 번쯤 채워야 하는 정도로 맞춘다. 너무 오래 머물거나 휴식을 남발하면 어둠이 다가오는 압박이 느껴져야 한다.

### 7.4 등잔의 이름

- 등잔마다 옛 등불지기의 **이름**이 새겨져 있다. 불씨를 옮기면 이름이 로그에 뜬다("○○의 등잔 — 아직 따뜻하다").
- 처음 보는 이름이면 정착지의 "기억할 이름들"에 추가되고, 모닥불 밝기가 +1 오른다(잊힌 사람을 다시 기억하는 것이 불을 키운다).
- 이름은 이 판에서 쓰러진 등불지기가 아니라, 게임 시작 전부터 있던 옛 등불지기들의 이름 목록에서 뽑는다(최대 20개).

### 7.5 횃불 표시

1. 상단 HUD의 작은 횃불 그림: 나무 자루 위에서 불꽃이 실제로 일렁이며 탄다(캔버스나 CSS 애니메이션, 또는 작은 3D 장면). 금빛 불꽃.
2. 남은 양에 따라 모습이 바뀐다.

| 횃불 | 모습 |
| --- | --- |
| 50 이상 | 크고 밝은 금빛 불꽃, 불씨가 위로 튐 |
| 25~49 | 불꽃이 작아지고 붉어짐, 자루가 짧아짐 |
| 1~24 | 작게 꺼질 듯 흔들리고 가끔 꺼질 뻔 깜빡임, 연기가 오름 |
| 0 | 불꽃 없이 붉은 숯과 연기만 |

3. 채우면 불꽃이 확 살아나는 짧은 연출.
4. 옆에 작은 숫자(62)로 정확한 양.
5. 게임 화면 속 주인공 횃불의 불꽃 크기와 빛 반경도 같은 단계로 맞춘다. 빛 반경이 줄 때 눈에 띄게 작아져야 한다.

## 8. 코드 연결

- 새 상태: `G.torch`(0~100), 저장은 `META.hero.torch`. 출발 시 `enterDungeon`에서 가득 채움(+모닥불 보너스).
- `endTurn`/`worldTick`에서 0.5 감소. 시야: `computeFOV`의 `FOV_R`을 `torchSight()`로 바꿈.
- 0일 때 기습: 적의 발견 판정(`canSee`/`wakeAround`)에서 플레이어가 먼저 발견된 것으로 처리.
- 등잔: `genFloor`에서 층마다 1~2개 배치(새 타일 또는 물건). 상황 버튼으로 사용.
- 불씨 단지: `ITEMS`에 소모품 추가, `RECIPES`에 요리사·제단지기 제작법.
- 스킬 불의 빛: `View`의 불 타일 광원은 유지하되 `computeFOV`에는 넣지 않는다. 색 구분.
- UI: `ui/hud.js`(상단·하단 배치, 횃불 그림, 상태 아이콘, 보이는 적 수, 위험 경고), `ui/panels.js`(로그 펼침, 대상 정보 카드, 가방 탭), `ui/input.js`(길게 누르기, 버튼 5개).
- 제거: 기존 스킬 버튼 줄(`#skills`, 영혼석 액티브 전환과 함께), 식량 관련이 있다면 전부.

## 9. 확인 목록

1. 상단: 미니맵(누르면 전체 지도), 위치·턴, 타오르는 횃불과 숫자, 보이는 적 수. 상태 아이콘 없음.
2. 로그 3~4줄, 누르면 전체 기록.
3. 하단: HP·보호막·상태 아이콘 한 줄, 소모품 빠른 슬롯 한 줄, 영혼석 6칸 한 줄, 버튼 5개(공격·대기·탐험·상태·가방).
4. 공격 길게 누르기 → 무기 정보, 대기 길게 누르기 → 휴식(적이 보이면 멈춤).
5. 상황 버튼이 계단·물건·문·쓰러진 사람·등잔에서만 떠오르고, 탐험은 적이 보일 때만 멈추며 물건을 주워 간다.
6. 적 길게 누르기 → 정보 카드와 예고 범위 강조.
7. 예고 범위 안에 서면 화면 가장자리가 붉게 맥동.
8. 횃불이 턴마다 줄고, 단계마다 시야와 불꽃 모습이 바뀐다. 0이면 기습당한다.
9. 불 스킬은 횃불을 쓰지 않고, 스킬 불은 시야를 넓히지 않는다.
10. 등잔에서 불씨를 옮기면 +40, 새 이름이면 "기억할 이름들"에 추가되고 모닥불 밝기 +1.
