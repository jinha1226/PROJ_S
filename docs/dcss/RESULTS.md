# Model B 구현 결과

## 구현 범위

기본 실행을 Model B로 전환했다. 재사용한 기존 코드는 맵/경로/시야/턴 엔진과 타일·캐릭터·폰트·보드다. 신체 손상, 성격/동료 관계, 몬스터 흡수 이능은 신규 런에 연결하지 않았으며 기존 모듈을 수정하거나 삭제하지 않았다. 기존 실행/저장도 별도로 남아 있다.

- 8층의 되돌아갈 수 있는 분기 그래프, 층 상태 유지, 2룬→오브→지상 귀환과 귀환 추격자.
- 3종족, 목표 자동훈련 10축, 24적 원형/역할, 12주문/5마법군, 3신앙 계약.
- 7무기/4방어구/6반지/방패, 브랜드·강화·유물 보물, 5소모품 유형, 주문서 발견.
- 이동/공격 지연, AC/EV/SH, 저항, 주문 실패/부담, 독/화염/빙결/물/안개/함정, 범위 아군 피해.
- 세로 UI, 터치 공격, 범위 미리보기, 길게 눌러 적 상세, 안전 탐색/휴식, 저장/복원, 영구 죽음.
- 테스트 전용 GitHub Actions와 Web/Windows artifact 생성. Pages 배포 workflow에도 Model B 검증 gate 추가.

## 수행한 검증

| 검사 | 결과/범위 |
|---|---|
| Simulation acceptance | **1,560 assertions, failures=0**. 16 seeds×8층 연결/점유/저장, 두 룬→오브→귀환, 모든 주문/계약, 저항/환경, 자동 탐색 모서리 정지 회귀, 결정적 저장 재개, 잘못된 저장 원자적 거절, 죽음 저장 |
| UI smoke | **failures=0**. 4개 화면 크기, 가방/성장/신앙 패널, 저장 생성 |
| 재사용 턴 엔진 | **PASS**. 기존 `turn_engine_acceptance.gd` |
| Windows용 export pack | checkout 없는 경로에서 외부 acceptance script로 **1,560 assertions, failures=0**. Windows exe 생성 완료 |
| Web runtime | Chromium 450×800에서 종족 선택·던전·탐색 입력 및 화면 확인. 최종 pack만으로 외부 acceptance를 실행해 **1,560 assertions, failures=0** |
| Workflow 정적 검사 | 두 workflow YAML 파싱과 모든 run 블록 bash 구문 검사 통과 |

원본 출력은 `validation/`에 보관한다. assertion 수는 독립 테스트 시나리오 수와 다르다. 사람의 전체 런 플레이테스트, 난이도/승률/45–75분 런 시간, Android/iOS 실기기 성능은 아직 측정하지 않았다. Windows 실행 파일은 내보냈으나 Windows OS 자체에서 GUI를 실행한 결과는 아니다. GitHub Actions는 파일을 추가했지만 **아직 원격 push/실행하지 않았다**. 로컬 성공을 GitHub CI 성공이라고 보고하지 않는다.

## 구조적 제한

전투/콘텐츠는 첫 Model B 프로토타입 수치다. 원작의 모든 신/종족/branch/주문 예외를 포팅한 버전은 아니다. 기본 적 행동은 역할 기반이며 원작 DCSS의 전체 AI를 재현하지 않는다. 일부 몬스터는 기존 자산을 공유한다. 유물은 브랜드+강화의 보물 변형이며 원작 전체 randart property generator는 포함하지 않는다. 아이템 식별·허기·횃불 유지·마을은 이번 런에서 제외했다. 상세 품질을 넓히기 전에 사용자가 순수 Model B의 판단·입력 부담을 평가할 수 있는 상태를 목표로 했다.

후속 우선순위는 사용자 플레이테스트 결과에 따른 밸런스/UI 조정이다. 신체/성격/흡수 시스템 연결은 별도 지시 뒤에 수행한다.
