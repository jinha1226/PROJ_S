# Model B 숙련 시스템 개편 계약

이 문서는 Model B 숙련 개편의 구현 기준을 고정한다. 기존 focus 기반 경험치 임의 배분을 제거하고, 실제 플레이에서 사용한 계열이 성장하는 방식으로 전환한다.

## 숙련 분류

### 무기 숙련
- 검술 (`sword`)
- 창술 (`spear`)
- 둔기술 (`mace`)
- 도끼술 (`axe`)
- 궁술 (`bow`)

단검은 우선 검술 계열에 포함한다. 지팡이는 별도 무기 숙련을 추가하지 않고 마법 운용 장비로 취급한다.

### 마법 학파
- 화염 (`fire`)
- 냉기 (`ice`)
- 대기 (`air`)
- 변이·제어 (`hex`)
- 소환 (`summon`)

주문의 `school`이 해당 학파 숙련과 직접 연결된다.

### 방어/전술 숙련
- 갑옷 (`armour`)
- 회피 (`dodging`)
- 은신 (`stealth`)

## 성장 원칙

1. 플레이어가 XP를 임의 배분하지 않는다.
2. `focus` 선택 UI와 최대 2개 focus 규칙을 제거한다.
3. 무기 숙련은 해당 무기로 의미 있는 공격을 수행했을 때 성장한다.
4. 마법 학파는 해당 학파 주문을 실제로 시전했을 때 성장한다.
5. 갑옷/회피/은신은 반복 노가다를 만들지 않도록 단순 행동 횟수가 아니라 실제 위험이 있는 플레이 상황에서만 성장시킨다.
6. 허공 공격, 무효 행동, 취소된 타기팅, preview, 안전한 장소에서의 반복 행동은 숙련 경험치를 주지 않는다.
7. 캐릭터 레벨용 XP와 숙련 경험치는 분리한다. 몬스터 처치 XP는 레벨 성장에는 계속 사용할 수 있지만 숙련 배분 재화로 사용하지 않는다.
8. 짧아진 목표 플레이타임에 맞춰 숙련 성장 곡선은 기존 Model B보다 빠르게 재조정한다.

## 숙련 역할

- 검술: 검/단검 계열 운용
- 창술: 창 계열 운용
- 둔기술: 철퇴/망치 계열 운용
- 도끼술: 도끼 계열 운용
- 궁술: 활/석궁 계열 운용
- 갑옷: 무거운 갑옷의 encumbrance 및 관련 페널티 완화
- 회피: EV 중심의 기동 방어 성장
- 은신: 탐지 억제 및 기습 계열의 기반

숙련은 단순 수치 보너스에만 머무르지 않고 향후 신체/원소 시뮬레이션과 연결할 수 있어야 한다. 다만 이번 개편에서 해당 시뮬레이션을 새로 구현하지 않는다.

## 시작 직업

사용 기반 숙련에서는 시작 직업이 초기 방향을 제공한다. 직업은 성장 경로를 고정하지 않는다.

직업은 다음만 결정한다.
- 초기 숙련치
- 시작 무기/방어구
- 시작 주문 또는 준비 주문

직업 레벨이나 직업 전용 성장 트리는 만들지 않는다. 플레이 중 다른 무기/마법을 사용하면 해당 숙련이 자연스럽게 성장해야 한다.

## 접근성 원칙

숙련 시스템의 내부 깊이는 유지하되 플레이어에게 XP 배분 작업을 요구하지 않는다. 핵심 설명은 다음 한 문장으로 가능해야 한다.

> 사용하는 무기와 마법, 실제 전투 방식이 자연스럽게 숙련됩니다.

상세 숙련 수치와 성장 계산은 상세 화면에서 확인할 수 있게 하고, 기본 전투 화면에는 필요한 정보만 노출한다.

## 회귀 금지

이번 작업은 Model B의 이동/타기팅/턴 semantics를 변경하지 않는다. 특히 최근 수정된 이동 입력을 숙련 개편 때문에 되돌리거나 우회하지 않는다.
