# 이능 연결 현황

## 범위와 완료 여부

**16종 전체 연결은 미완료. 이번 구현은 공통 모드 선택 기반과 화염샘 1종이다.** 나머지 15종은 드롭/설명 등록 상태이며 결속 가능하도록 허위 개방하지 않았다.

## 실제 연결

- 기존 화염탄 정수를 소비해 결속한다. 저장상 canonical ID는 `FIREBOLT`를 유지한다.
- 정비 상태에서 패시브/액티브 중 하나를 선택한다. 두 모드가 동시에 작동하지 않는다. 필드 진행 중 무료 모드 교체는 막는다.
- 패시브: 일반 무기 공격 적중 후 살아 있는 대상에게 기본 화염 피해 6. 마법 숙련·종족 화염 저항·기존 환경 방어를 거친다. MP는 추가 소모하지 않는다. 일반 공격으로 이미 죽은 적에게 중복 피해를 주지 않는다.
- 액티브: 기존 화염탄 경로 유지(기본 위력 32, MP 3, 사거리 5).
- 파생 피해는 패시브를 재발동하지 않는다. 필드의 플레이어/동료 행동 직후 동일 트랜잭션으로 실행한다.
- 패시브 발동에 불꽃 VFX와 화염 피해 숫자가 나온다. 기존 가시성 필터를 사용한다.
- 모드 상태·변경 이벤트·명령 저널을 저장한다. 이전 저장에는 새 필드가 없어도 액티브 모드로 읽는다.
- 아직 구형 변이 4종의 신규 이능 통합은 하지 않았다. 레거시 비필드 전투 루프와 독립 rebuilt 데모는 신규 패시브 실행 대상이 아니다.

## 남은 작업

포식 신경, 투척 본능, 사냥꾼의 도약, 질긴 가죽, 갑각, 부식성 혈액, 반향 감각, 서리실, 축전 기관, 독니, 재생 조직, 암석 골격, 그림자막, 흡혈 기관, 심층안의 두 모드 실행과 개별 수치/비용/검증이 남았다. 범위 피해·상태 지속·탐지·자원 소모를 기존 저장/피해 인과 검증에 연결해야 한다.

## 검증

- `tests/monster_dual_mode_acceptance.gd`: 실제 정수 결속, 모드 UI 전환, 자연 이동·일반 공격의 패시브 화염 피해, VFX DTO, 전체 상태 검사와 저장 재실행 비교.
- `tests/run_ability_binding_tests.gd`: 기존 결속 회귀 6개.
- `tests/monster_ability_drops_acceptance.gd`: 16종 드롭 매핑.

실제 휴대폰의 시각적 체감 및 16종 전체 효과 검증을 완료했다는 의미가 아니다.
