# 몬스터 이능 16종 연결 결과

## 완료 범위

현재 메인 플레이의 필드 턴 전투에 16종 모두 정수→결속→패시브/액티브 선택→실행 경로를 연결했다. 기존 화염샘에 더해 나머지 15종을 구현했다. 상태/피해는 UI 애니메이션이 아니라 시뮬레이션 이벤트로 실행한다.

모드는 정비 중 선택하며 한 이능에서 두 모드를 동시에 쓰지 않는다. 기존 슬롯/레벨 제한과 정수 소비 정책은 유지한다. 미구현 해제·환급 정책이나 정착지 제거는 이번 범위가 아니다.

## 실제 효과

100시간은 기본 이동 한 번에 해당하는 내부 턴 시간이다. 숙련은 직접 피해/회복/방어량에 해당 축으로 적용하며, 상태의 범위/지속시간에는 적용하지 않는다.

## 구현 세부와 한계

- 적의 모습·HP·공격 정보를 벽 너머로 공개하지 않는다. 탐지는 별도 기척/위험 표식이다. 일반 시야나 공격 가능 여부를 확장하지 않는다.
- 지속 방어/둔화 구역/독은 별도 표식이 남으며 발동 시에는 기존 VFX 렌더러를 재사용한다. 16종 전용 신규 그림 에셋을 만든 것은 아니다.
- 질긴 가죽·갑각·암석 골격은 기존 방어/신체 손상 계산에 방어량으로 기여한다. 골절 면역이나 영구 피부/골격 스칼라 변경을 뜻하지 않는다.
- 산성·독 등은 별도 화학 시뮬레이션이 아니라 현재 공용 HP 피해 경로(physical 이벤트 채널)를 사용한다. 산성 지형 부식·중독 신체 장기 손상까지 구현한 것은 아니다.
- 그림자막은 직접 광원을 기준으로 판정한다. 1–2층 가독성용 주변 밝기 때문에 패시브가 영원히 꺼지지 않도록 주변광과 분리했다. 이미 추적 중인 적의 기억을 지우거나 인접 공격을 무효화하지 않는다.
- 반격의 처치 귀속은 반격자에게 돌아간다. 파생 피해에서 다른 패시브를 재귀 발동시키지 않는다. 장착된 이능은 공용 6슬롯 한도 안에서 각각 판정한다.
- 상태 투영은 이벤트 꼬리만 읽는 캐시다. 저장에는 원본 이벤트를 남기고 불러오면 캐시를 재구축한다. 매 프레임 전체 이력을 다시 읽지 않는다.
- 기존 standalone rebuilt 데모와 구형 실험용 전투 전체를 통합한 작업은 아니다. 제품의 현재 필드 전투가 기준이다.

## 검증

- PASS — `tests/monster_all_abilities_acceptance.gd`: 나머지 15종 정수 소비/결속, 액티브 비용·실제 실행, 패시브 모드/발동·수치·표식, 전체 상태 검사, 저장 복원 및 다음 턴 결과 일치. 테스트 위치는 기록된 이동으로 구성한 고정 fixture이며 자연 플레이 난이도 검증과 구분한다. 모든 패시브의 실전 상황을 망라한 검사는 아니며 재생의 비전투 회복과 그림자막의 광원별 인지는 별도 플레이 검수가 필요하다.
- PASS — `tests/monster_dual_mode_acceptance.gd`: 화염샘 모드 UI, 자연 이동·공격의 실제 화염 추가 피해, VFX, 전체 세션 저널 재실행. X11 렌더러에서 실행했다.
- PASS — `tests/run_ability_binding_tests.gd`: 기존 결속/중복/구버전 저장 회귀 6개.
