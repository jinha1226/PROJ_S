# 영혼석 — 6칸과 3색 교체

기본 원정은 `attack_wait_v1` 규칙을 쓴다. [실행 매핑](attack-wait-soulstones.ko.md)에 영혼석 효과가 정의되어 있다. 아래의 주문·기술 세부 규칙은 비교용 `legacy` 프로필에만 해당한다.

## 기본 원정: 3색 영혼석

| 색 | 발동 | 기본 보정 |
| --- | --- | --- |
| 빨강 · 공격 | 내가 공격하거나 적중할 때 | 공격력 +4 |
| 보라 · 전술 | 내가 대기할 때 | 공격력 +2 · 행동 속도 +5% |
| 초록 · 생존 | 직접 맞을 때 | 최대 HP +20 · 방어 +3 |

색 테두리는 발동 시점, 가운데 아이콘은 효과, 모서리 `＋`·`✸`는 강화·폭발을 뜻한다. 12개 효과 아이콘은 영혼석 칸·가방·드롭·도감에서 공통으로 쓴다. 한 사람에게 색을 섞어 흡수할 수 있고, 색 개수 보너스는 없다.

영혼석 칸은 레벨당 1개씩 열려 최대 6칸이다. 가방은 파티 공용 3개다. 빈 칸 흡수는 안전한 곳에서 가능하다. 같은 색 영혼석은 안전한 곳에서 서로 맞바꿀 수 있고 기존 영혼석은 가방으로 돌아온다. 다른 색을 덮어쓰려면 3·6·9층 보스 뒤 휴식처가 필요하다. 덮어쓴 옛 영혼석은 사라진다. 휴식처에 들어오면 파티 HP·MP가 전부 회복되고 빈사가 풀리며 스트레스가 30 감소한다. 식량과 턴은 소비하지 않는다.

가방이 가득 찬 상태에서 드롭을 보관하려면 기존 영혼석 하나를 골라 버린다. 흡수하거나 두고 갈 수도 있다. 개발용 로드아웃과 아레나는 가방 제한을 적용하지 않는다.

## 비교용 legacy 프로필


아래 표는 `legacy`의 이전 흡수 규칙이다. 기본 원정의 교체는 위 3색 규칙을 따른다.

| 항목 | 규칙 |
| --- | --- |
| 흡수 가능 칸 | 레벨당 1칸, 최대 6칸 |
| 캐릭터·주문 레벨 | 기존 최대 10 유지 |
| 흡수 | 가방에서 1개 소모, 빈칸에 즉시 적용 |
| 교체·해제 | 불가 |
| 중복 | 같은 부위·속성의 영혼석은 한 인물에게 1회만 흡수 |
| 가득 찬 경우 | 흡수 거부, 가방 수량·능력치·기술·주문 유지 |
| 봉인 | 효과만 일시 정지, 칸은 그대로 점유 |
| 동료·NPC | 인물마다 같은 상한. NPC도 사냥으로 기존 영혼석을 교체하지 않음 |
| 역할 조합 | 2·4·6개 구간 유지, 가장 높은 구간의 실제 효과만 적용 |

흡수 즉시 기본 능력치, 패시브, 사용 가능한 기술, 선택 주문을 반영한다. 각 영혼석의 명시적인 주문 목록 안에서 선택한다. 같은 종족의 다른 부위도 서로 독립적으로 고르며, 속성 변종이 다른 부위의 선택을 덮어쓰지 않는다. 영혼석 교체와는 별개다. 안전한 지역·야영지에서 흡수할 수 있으며 전투 중 흡수는 막는다.

상태창 영혼석 탭은 3열 × 2행의 여섯 칸, 활성 조합 효과, 전체 영혼석 효과 요약 순서다. 공유 가방 목록과 장착·해제 메뉴는 없다. 가방의 파츠 상세에서 인물별 흡수를 선택한다. 영혼석 칸을 누르면 정확한 수치·조건·키워드·기술을 확인한다. 요약은 기본 보정 합계와 중복을 제거한 패시브를 표시하며, 조건부 피해·회복을 임의의 합계로 환산하지 않는다. 봉인된 효과는 적용 합계에서 제외한다.

## 빌드의 실제 기술

부위 데이터의 명시적인 `active` 필드로 기술을 부여한다. 설명용 소분류만 읽어서 숨은 보너스를 만들지 않는다. 같은 기술을 여러 부위에서 얻어도 기술·재사용 대기는 공유한다.

| 부위 효과 | 기술 | 비용·제약 |
| --- | --- | --- |
| 사령 효과 | 해골 소환 (`BONE_CALL`) | MP 6, 재사용 3턴, 실제 해골 생성, 빈 인접 칸과 소환 한도 필요 |
| 회복 효과 | 영혼 치유 (`SOUL_MEND`) | MP 5, 재사용 4턴, 자신·인접 아군 HP 12 회복, 체력이 가득 차면 사용 불가 |
| 화염·냉기·전기 부위 | 해당 부위에 연결된 선택 주문 | 기존 MP·시전 실패·레벨 규칙 |
| 저주·거미·뱀·망령 부위 | 연결된 선택 저주 주문 | 기존 의지 판정·상태 규칙 |
| 놀 소환사 부위 | 연결된 선택 소환 주문 | 기존 소환수 규칙 |

예시 빌드와 NPC 초기 주문 선택은 레벨이 가장 높은 실제 전투 주문을 고른다. 단순 유지 버프만 선택해서 공격·소환이 사라지지 않는다. 예시 빌드 11개는 실제 효과 흐름을 유지하는 여섯 부위로 재구성했다. 플레이 중 캐스터 주문은 사용자가 선택할 수 있다.

해골 소환·영혼 치유는 기술 메뉴와 Utility AI 후보에 모두 포함한다. 회복 후보는 자신과 부상한 아군을 구분하며, 예측은 실제 HP를 바꾸지 않는다. 기존 재사용·소환·치유·VFX 경로를 사용한다. 몬스터 전용 공격은 플레이어 기술 목록에 표시하지 않는다.

검증: `essences`, `essence_ui`, `npc_essences`, `part_stones`, `example_builds`, `build_actives`, `stone_magic` 및 전체 회귀 스위트. 이전 10개 구성의 시뮬레이션 결과는 새 6개 규칙의 결과로 간주하지 않는다.

## 부위별 마법 연결

`data/content/essences.json`의 부위 또는 보스 행에 `spells` 배열을 명시한다. 학파 전체를 자동 부여하거나 속성 변종만으로 새로운 주문을 만드는 규칙은 없다. `school`은 기존 역할 스탯 계산용 분류로 남으며, 주문 접근은 `spells`만 읽는다. 물의 정령·거미처럼 기존 비캐스터 부위도 명시한 주문을 사용할 수 있고, 기본 스탯은 바뀌지 않는다.

- 영혼석마다 연결된 주문 중 **하나**를 선택한다. 흡수 시 첫 사용 가능 주문을 자동 선택한다.
- 요구 레벨을 넘는 주문은 잠겨 있으며, 레벨업으로 첫 주문이 열리면 자동 적용한다. 기존 선택을 높은 레벨 주문으로 강제 변경하지 않는다.
- 서로 다른 부위는 독립 선택이다. 같은 주문을 여러 영혼석에서 고르면 중복 시전 버튼은 만들지 않는다.
- 최대 여섯 영혼석의 선택 주문이 모두 사용 가능하다. HUD는 다섯 바로가기만 표시하고 **기술 메뉴에서는 여섯 번째 주문도 사용**한다.
- 봉인은 해당 영혼석의 주문과 학파 실패율 보정을 함께 정지한다. 봉인 해제 후 원래 선택을 복원한다.
- 이전 선택이 새 부위 목록에 남으면 유지한다. 연결되지 않은 옛 선택은 해당 부위의 첫 열린 주문으로 바꾼다.
- 가방과 흡수한 영혼석 상세는 연결된 모든 주문의 이름·레벨·MP·효과를 표시한다. 잠긴 주문은 선택할 수 없다.
- 묘지기의 모든 부위는 별도로 해골 소환을 부여한다. 손은 저주, 뼈·등불은 소환수 강화 주문을 선택하며 사냥개 주문으로 사령 역할을 대신하지 않는다.

현재 기존 마법 50개를 영혼석 31종에 연결했다. 회복 영혼석의 영혼 치유는 선택 주문과 별도의 고정 기술로 유지한다. 전체 연결표는 [영혼석 마법 연결](soulstone-spells.ko.md)을 참고한다.
