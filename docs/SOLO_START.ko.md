# 주인공 단독 시작

기준 commit: `5353da9`.

- 제품의 최초 실행, 새 게임, 종족 선택 후 원정은 주인공 1명으로 시작한다.
- 기존 동료를 추방하거나 숨기는 것이 아니라 시작 동료를 생성하지 않는다.
- 기존 필드 턴, 몬스터, 속성 시험 스킬, NPC와 영입 시스템은 유지한다.
- 여관 시작 시 길드 인물 2명을 자동 영입하던 경로도 단독 시작에서는 건너뛴다.
  길드 후보는 마을에 남지만 원정에 자동 편성하지 않는다.
- 기존 저장의 동료는 제거하지 않는다. 기존 파티 테스트 fixture도 그대로 둔다.
- 새 단독 원정은 주인공의 `solo_start_v1` 태그로 시작 구성을 기록한다.
  저장 재생은 이 태그에 따라 동일한 개체 생성 순서를 복원한다.
  같은 원정/성격 시드 재시작에도 시작 구성을 전달한다.
- 방향별 피격·부상 규칙은 이번 변경 범위가 아니다.

검증: `tests/solo_start_acceptance.gd`에서 기존 2인 저장 보존,
단독 시작/턴 진행/저장 재생, 실제 종족 선택 경로의 단독 원정 및 초상화 1개를 확인한다.
여관에서 실제 원정 출발 후에도 단독 편성/필드 턴/저장 재생이 유지되는 검사까지 통과했다.
