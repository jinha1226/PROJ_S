# DCSS-BALANCE-01 protocol

2026-09-13. 기준 `fd26323` (게임 `b0d60ac`). 사용자가 요청한 범위는 밸런스 참고·적용이다. 원본 코드 이식은 제외한다.

DCSS 안정판 0.34.1을 기준으로 현재 제품에 있는 종족, 무기/개량 무기, 갑옷, 고블린/코볼트를 조정한다. 새로운 몬스터·스킬·거점·반복 원정은 추가하지 않는다. 전투 공식·숙련 계산·AI·부상·지형·아이템 효과 구현은 교체하지 않는다.

무기의 피해 비율과 기본 공격 지연을 가져온다. 현재 고정 피해 단위에서 무숙련 인간의 무기별 raw damage를 DCSS 기본 피해 ×5로 맞추며 기존 actor power 24는 중복 가산하지 않도록 무기 기본 피해에서 빼서 기록한다. 개량 장비는 +1/+2에 대응하는 +5/+10을 추가한다. 공격 지연은 DCSS aut ×10, 쇠뇌는 현재 명시적 재장전 시간을 포함한 총 지연으로 맞춘다.

HP는 DCSS 평균 HP ×10, 기존 기본 명중식의 milli 정확도와 회피 단위는 현재 엔진에 맞는 별도 보정값이다. 원작의 무작위 AC를 구현하지 않고 기존 flat armor를 사용하므로 AC ×2로 압축한다. 이는 원작 전투 분포의 정확한 재현이 아니다. 종족 능력치는 기존 인간 기준 5점 체계를 유지하여 DCSS 종족 기본값 ×5/8 반올림으로 정규화한다. 정확히 대응하지 않는 오크·수인은 기존 값을 유지한다. 출현 구조와 고유 이능은 보존한다.

변경값·원본값·변환 이유를 JSON manifest와 결과 문서에 기록한다. 콘텐츠 ID는 유지하며 content_version을 올린다. 과거 전투 이벤트의 재생에 새 수치를 적용하면 무결성 검증이 달라지므로 저장 파일을 삭제/자동 변환하지 않는다. 새 밸런스 tag marker가 없는 과거 세션은 명시적인 새 게임 안내로 거부하고, 새 밸런스 세션은 저장/재생 일치를 검증한다.

검증: JSON 통합 검증, 무기별 실제 공격 spec의 상대 피해/시간/명중, 실제 새 제품 시작과 몬스터 HP/장비 적용, 실제 전투 행동·전체 world audit·저장/재생, 이전 marker 없는 저장 거부 시 현재 세션 보존. 기존 weapon suite 기준은 9개 중 1개 실패(확장 무기 ID 목록을 오래된 고정 목록과 비교); 새 실패와 구분한다.

## 사용자 추가 범위 — 목록을 최대한 많이 도입

무기/몬스터 목록도 최대한 많이 가져오라는 추가 지시를 반영한다. 참조 목록은 몬스터 YAML 668개(테스트 제외), 명시적 무기 정의 59개(현행 47, 구형 12)다. 전체를 이름·수치·특수 동작 의존성의 참조 catalog로 보관한다.

현재 엔진으로 정직하게 표현 가능한 현행 무기를 등록·아이템화하고 드롭 후보에 연결한다. 기존에 없는 탄종이 필요한 슬링/핸드 캐넌은 참조 상태로 남긴다. 기존 7종 대응 무기와 재료 개량을 보존한다. 약한 무기의 기대 피해가 기존 actor power 24보다 작으면 음수 무기 피해를 만들지 않고 base_damage=0으로 제한하며 그 차이를 기록한다.

특수 동작 없는 단일 일반 물리 공격, 기본 속도, 고유 저항/주문/비행/고유 퀘스트/변신/비출현 없는 몬스터부터 실제 엔티티·종족별 프로필·기본 공격·드롭을 연결한다. 신체/아트는 기존 proxy를 재사용하며 원작의 해부학/전용 아트를 재현하지 않는다. 높은 HD의 적은 데이터로 등록하되 현재 두 층의 저HD 출현 후보에 섞지 않는다. 신규 등록의 전투 프로필 선택과 데이터 조회를 연결하는 자체 코드만 추가하며 원본 알고리즘은 이식하지 않는다.

확장 검증: 새 무기 등록/장착/실제 공격/드롭, 새 몬스터 전체의 생성/프로필/기본 공격 spec·전체 world audit·snapshot decode, 층별 출현 후보 결정성 및 난도 제한, 새로운 종족을 포함한 실제 제품 시작/전투/저장 재생.

## 최종 사용자 범위 수정

사용자가 이전 선택지에 답하여 원본 규칙 분석 후 기존 코드로 구현하고, 초반 던전에 필요한 목록만 실제 적용하도록 지정했다. 최종 런타임 범위는 기존 7종에 초반 무기 12종을 추가한 DCSS 대응 무기 19종, 기존 고블린·코볼트에 HD 1–2 기본 근접 몬스터 6종을 추가한 몬스터 8종이다. 전체 668 몬스터·59 무기 목록은 런타임과 분리된 분석 참고 자료로만 보존한다. 후반·특수 무기는 신규 등록하지 않는다.
