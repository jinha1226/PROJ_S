# 이동 방향 시야 갱신 protocol

- 작업 ID: `VISION-FACING-001`
- 기준 commit: `183365a`
- 사용자 관측: 캐릭터 방향이 바뀌어도 어두운 환경의 방향성 시야가 최초 방향에 고정되어 보인다.

## 원인 가설과 범위

- 필드 턴 이동은 진형이 `NONE`이 아닐 때만 파티 `facing`을 갱신한다. 기본 자유 진형에서는 위치만 이동하고 시야 권위 방향은 초기값에 머문다.
- 성공한 모든 필드 `MOVE`에서 이동 벡터로 파티 방향을 갱신한다.
- 기존 시야 캐시는 방향을 key에 포함하므로 새 방향 권위가 기록되면 별도의 렌더 전용 방향 추정 없이 FOV를 다시 계산한다.
- 이동, 시간, 적 인지, 저장·재현 규칙은 유지한다.

## 검증

- 자유 진형에서 상·하·좌·우 이동 후 `party.facing`이 실제 이동 방향과 일치해야 한다.
- 같은 위치와 조명에서 방향을 바꾸면 전방 가시 셀이 새 방향으로 이동하고 후방 셀은 어두운 시야 규칙대로 제외되어야 한다.
- 시야 관측 DTO와 화면 grid가 갱신된 방향의 결과를 받아야 한다.
