## 1. 핵심 설계 철학

1. **Role은 넷, 누구나 아는 이름으로.** 탱커·딜러·힐러·서포터. 파티 화면에서 한눈에 읽힌다.
2. **Class는 많게, 하지만 겹쳐 쌓아서.** 기본 Class 6개를 레벨 10 안에서 나눠 찍는다. 한 Class에 10 = 한 우물 상위 Class, 두 Class에 나누면 두 우물 상위 Class. 기본 6 + 상위 21 = **27개**.
3. **나눠 찍는 대가가 있다(발더스 게이트 3).** 총 레벨은 늘 10. 넓게 가면 깊이가, 깊게 가면 폭이 준다. 그래서 모두가 모든 걸 하는 파티가 되지 않는다.
4. **장착 스킬은 셋.** 쓸 수 있는 스킬이 많아도 한 번에 세 개. 고르는 것 자체가 준비다.
5. **장비는 Class가 막지 않는다.** Class는 역할과 행동을, 장비는 빌드를 만든다. "무기 피해" 스킬은 무기 형태(베기·타격·찌르기)와 속성을 그대로 탄다.
6. **스킬은 공간과 타이밍으로.** 준비 동작 끊기, 예고 전에 보호막, 방향 막기, 위치 바꾸기, 원소 지형. 숫자 교환이 아니라 멈춘 채 판단할 거리를 준다.
7. **스킬은 효과 부품의 조합(데이터).** 부품 약 20개로 스킬 60개를 만든다. Class를 늘릴 때 데이터만 더한다.

### 3.3 이름: 수식어 + 상위 Class

- 레벨이 높은 쪽 기본 Class의 수식어가 앞에 붙는다. 차이가 1 이하면 균형형으로 수식어가 없다.
- 예: 로그 7 / 위저드 3 = **그림자의 나이트블레이드**(딜러), 5 / 5 = **나이트블레이드**, 3 / 7 = **비전의 나이트블레이드**. 파이터 7 / 클레릭 3 = **방패의 팔라딘**(탱커), 3 / 7 = **기도의 팔라딘**(힐러).
- 수식어 = 주 Role. 균형형은 두 Role 중 주 Role을 고른다.

### 3.4 교차 성장 (레벨 10 나눠 찍기)

| 분배 | 결과 |
| --- | --- |
| 한 Class 1~9 | 기본 Class |
| 한 Class 10 | 한 우물 상위 Class |
| 두 Class, 작은 쪽 1~2 (예: 8 + 2) | 기본 Class + **곁가지**: 작은 쪽 스킬이 그 레벨만큼 열린다(상위 Class 없음) |
| 두 Class, 둘 다 3 이상 | 두 우물 상위 Class. 차이 2 이상이면 기운 형태(수식어), 1 이하면 균형형 |
| 세 Class 이상 | 막는다 |

- 스킬은 **각 Class 레벨**로 열린다: 1 → 첫째, 3 → 둘째, 5 → 셋째. 레벨 7에 그 Class의 **갈래**(둘 중 하나)를 고른다(에슬라봉식).
- 위력은 그 스킬이 속한 Class 레벨을 따른다: 위력 = 0.55 + 0.045 × 레벨(1레벨 0.6, 5레벨 0.78, 7레벨 0.87, 10레벨 1.0). 피해·치유·보호막 양은 위력을 곱하고, 지속은 (0.75 + 0.25 × 위력)을 곱하고, 쿨타임은 (0.8 + 0.2 × 위력)으로 나눈다.
- 두 우물 전용 스킬은 **기대는 쪽 Class의 레벨**로 위력을 정한다. 그래서 7 + 3과 3 + 7은 같은 Class라도 강한 전용 스킬이 다르다.
- 한 우물 강화판: 기본 스킬 셋에 쿨타임 ×0.75, 효과 ×1.25.
- 특성: 기본 Class = 보통, 한 우물 = 강, 두 우물 = 두 Class의 약. 곁가지는 특성을 주지 않는다.
- 갈래(레벨 7):

| Class | 갈래 A | 갈래 B |
| --- | --- | --- |
| 파이터 | **철벽**: 방패 세우기 지속 +1초, 반각 75° | **도전**: 도발 외침 반경 +1, 지속 +1초 |
| 로그 | **암살**: 급소 찌르기가 HP 절반 아래 적에게도 ×2 | **곡예**: 회피 자세 지속 +0.3초, 그림자 돌진 쿨타임 −3초 |
| 레인저 | **명사수**: 관통 사격 쿨타임 −2초 | **덫꾼**: 올가미 덫이 한 번 더 묶는다(두 번 발동) |
| 위저드 | **연소**: 화염구가 화상 +2 | **뇌전**: 번개 사슬이 두 번 더 튄다 |
| 클레릭 | **은총**: 치유가 해로운 상태이상도 지운다 | **수호**: 신앙의 방패 +4 |
| 바드 | **선율**: 용기의 노래 지속 +2초 | **교란**: 불협화음이 1초 기절시킨다 |

### 3.4.1 성장: 등불지기와 주민이 같은 규칙 (구현 2026-09-30)

- 모든 사람(등불지기·주민)이 같은 성장 기록을 가진다: `prog = { level 1~10, xp, points, build }`(`js/core/progress.js`).
- **레벨마다 점수 1.** 새 사람은 레벨 1에 점수 1(첫 Class를 고른다). 점수는 플레이어가 **직업 창**에서 기본 Class 하나에 1씩 찍는다(Class 둘까지, 합은 레벨 이하). 이번에 찍은 것만 되돌릴 수 있고, 다시 나누기는 훈련소(정착지 작업).
- 경험: 누적 80 · 200 · 380 · 620 · 950 · 1400 · 2000 · 2800 · 3800에 레벨 2~10(1구역을 마치면 약 5).
- 등불지기: 쓰러뜨린 적의 최대 HP(보스 두 배)가 경험. 레벨업마다 기본 HP +2, 잃은 HP 절반 회복. 주민: 경험은 파티·훈련소가 들어올 때 붙인다.
- **등불지기 잇기**: 주민이 등불을 이으면 그 사람의 성장 기록이 그대로 등불지기의 것이 된다(레벨만큼 기본 HP도).
- 직업 창은 상태 창(던전)과 주민·등불지기 카드(정착지)에서 연다. 갈래·균형형 주 Role·장착 3칸은 싸우는 중이 아니면 언제든 바꾼다.
- 옛 저장(v9)의 레벨 1~6은 같은 레벨의 새 기록이 되고, 그만큼 찍을 점수가 생긴다.

### 3.4.2 Class 수치 (구현 2026-09-30)

능력치(STR·DEX·INT)는 두지 않는다(`밸런스_기준.md`). 대신 장비가 주는 전투 수치를 Class 레벨마다 조금씩 더한다. 두 Class면 각자 레벨만큼, 합한 뒤 내림. 장비와 합쳐도 상한은 그대로. 상태 창 "전투 수치"의 출처 목록에 Class 줄이 따로 선다.

| Class | 레벨당 | 10레벨 합 |
| --- | --- | --- |
| 파이터 | HP +1 · 방어 +0.3 · 막기 +2% · 이동 −1% | HP 10 · 방어 3 · 막기 20% · 이동 −10% |
| 로그 | HP +0.4 · 회피 +1.5% · 피해 +0.1 · 급소 +2% · 이동 +1% | HP 4 · 회피 15% · 피해 1 · 급소 20% · 이동 +10% |
| 레인저 | HP +0.4 · 회피 +1% · 피해 +0.1 · 이동 +1.5% | HP 4 · 회피 10% · 피해 1 · 이동 +15% |
| 위저드 | HP +0.2 · 주문력 +0.4 · 모든 원소 저항 +1(레벨 4, 8) | HP 2 · 주문력 4 · 저항 +2 |
| 클레릭 | HP +0.6 · 방어 +0.2 · 막기 +1% · 주문력 +0.3 · 모든 원소 저항 +1(레벨 5, 10) | HP 6 · 방어 2 · 막기 10% · 주문력 3 · 저항 +2 |
| 바드 | HP +0.5 · 회피 +1% · 피해 +0.1 · 이동 +1% · 주문력 +0.2 | HP 5 · 회피 10% · 피해 1 · 이동 +10% · 주문력 2 |

- **주문력**: 무기가 아닌 스킬의 피해·치유·보호막 +주문력(구역의 초마다 치유는 절반). 지금은 Class에서만 온다. 장비(예: 보조손 오브 → 주문력 오브)는 따로 정한다.
- 급소는 찌르기 무기에만 붙는다(지금 규칙).
- 측정(6판): 딜러 한 우물 어쌔신 0.17 · 스나이퍼 0.22 · 아크메이지 0.23. 근접하는 봇이라 어쌔신(회피·이동)이 유리하게 나와 20%를 조금 넘는다. 서포터 마에스트로 0.27, 탱커·힐러는 §3.7과 같은 한계.

### 3.5 장착 스킬 3칸

- 열린 스킬 중 셋을 고른다. 한 우물은 5개 중 3, 기운 두 우물은 약 7개 중 3, 균형형은 8개 중 3.
- 무기 자동 공격은 그대로(무기 박자·모양). 스킬은 멈춘 채 고르고, 시전하는 짧은 순간만 시간이 흐른다(`설계_레이드.md` §5.2).

### 3.6 역할 사이 밸런스 목표

- 같은 Role 안에서 한 우물이 가장 높되, **기운 두 우물과 10% 안, 균형형과 20% 안**. 균형형은 대신 두 Role을 다 한다.
- 측정 지표: 딜러 = 표준 무리 전투 시간, 탱커 = 받은 피해, 힐러 = 회복량과 생존, 서포터 = 끊은 횟수와 전투 시간.
- 지금은 파티원이 없어 등불지기 혼자 재는 측정(`tools/arena.mjs`)이다. 탱커·힐러는 대략적인 확인만 된다. 파티 AI가 들어오면 다시 잰다.

| 근접 | 가디언 · 방패의 팔라딘 · 소드마스터 · 어쌔신 · 워로드 | 함성과 되치기로 붙어서 싸운다 |
| 보스 기믹 대응 | (마법사 보스) 위치 헌터 · 바드 · 트릭스터 … | 봉인 사격·불협화음으로 주문을 끊는다 |

- 한 Class가 한 Role만 하지 않는다: 두 우물 상위 Class는 주 Role + 보조 Role. 하지만 스킬 3칸이라 한 번에 두 Role을 온전히 다 하지는 못한다.

## 6. 주민 훈련 및 전직 (정착지 작업에서 연결)

- 정착민 모집 → 훈련소에서 기초 훈련(첫 기본 Class 1레벨) → 원정·자동 탐험 경험으로 Class 레벨 → 레벨마다 어느 Class에 찍을지 고른다 → 3 · 5 · 7 · 10이 성장의 이정표(스킬 · 갈래 · 상위 Class).
- 직업은 영구가 아니다: 훈련소에서 비용과 날짜를 들여 레벨을 다시 나눌 수 있다.
- 성격(HEXACO)은 Class 선택을 막지 않고 **적성**으로 작용한다(적성 Class는 경험 +20%). 원래 직업(대장장이·사냥꾼·약초꾼 …)은 작은 배경 특성을 준다(예: 사냥꾼 출신 레인저의 덫이 오래 간다) — Path of Achra의 문화처럼.
- 메인 파티에 든 주민은 레이드 경험으로 레벨 10 뒤에도 "명성"이 쌓인다(스킬 갈래를 한 번 더 고른다, 초안).

## 7. 훈련소와 정착지 성장 (정착지 작업에서 연결)

- 훈련소 방 등급 1: 파이터·로그·레인저 / 2: 클레릭·위저드·바드 / 3: 두 우물 전직 / 4: 한 우물 전직.
- 시설 연계: 제단(클레릭), 서재(위저드), 사냥꾼 오두막(레인저), 대장간(파이터 장비 훈련).
- 훈련 중인 주민은 정착지 일을 못 한다(기회비용). 숙련 주민(그 Class 7 이상)이 교관이면 훈련이 빨라진다.

## 8. 장비와의 연결

- Class는 장비를 막지 않는다. 무기 스킬(무기 ×N)은 무기의 형태·속성·약점을 탄다: 검객형 로그가 찌르기 무기면 급소 표식, 둔기면 골절.
- 방어구 무게는 이동과 연결할 수 있다(초안: 무거운 몸통 방어구 이동 −5%). 탱커는 무겁게, 딜러·서포터는 가볍게 가는 동기.
- 장비 에고·장신구가 보조 Role을 키운다(예: 치유 +1 반지를 낀 팔라딘).

## 9. 자동 탐험에서의 활용 (정착지 작업에서 연결)

지역마다 요구 점수 몇 개를 두고, 파티 Role·Class로 점수를 채운다. 계산은 단순한 합과 문턱.

| 점수 | 채우는 쪽 |
| --- | --- |
| 전투력 | 딜러(원거리 +, 근접 +) |
| 생존 | 탱커, 힐러 |
| 회복 | 힐러, 드루이드·섀도 프리스트 |
| 함정·정찰 | 로그·레인저·스카우트·스토커 |
| 제어 | 서포터, 위치 헌터 |
| 원소 | 위저드 계열(원소 지역) |

부족한 점수만큼 부상 확률이 오르고, 넘치는 점수는 희귀 자원 확률로 바뀐다. "이 지역엔 이런 조합"이 읽히면 충분하다.

## 10. 향후 Class 확장

- 기본 Class 추가(예: 바바리안 = 저체력일수록 강한 딜러)는 조합 행을 하나씩 늘린다. 데이터: 스킬 3 · 특성 · 갈래 2 + 조합마다 전용 스킬 2.
- 에슬라봉처럼 스킬마다 갈래를 늘리거나, Path of Achra처럼 배경(원래 직업)·신앙 층을 더할 수 있다.

## 11. 예상 문제와 해결

| 문제 | 해결 |
| --- | --- |
| 조합이 많아 무엇을 골라야 할지 모른다 | 수식어 = Role. 훈련소가 파티에 빠진 Role을 알려 준다 |
| 균형형이 애매해진다 | 두 Role을 다 하는 대신 20% 안에서 약하다. 파티 자유 자리에 맞다 |
| 한 우물이 너무 강하다 | 강화판은 ×1.25에 그치고 스킬 선택이 5개뿐이다. 측정으로 10% 안을 맞춘다 |
| 탱커·힐러 측정이 어렵다 | 파티 AI가 들어오기 전까지는 대략. 파티 AI 뒤 다시 잰다 |
| 스킬 60개의 유지 | 효과 부품의 조합(데이터)이라 부품만 테스트하면 된다 |
| 모바일 화면 | 스킬 3칸. 멈춘 채 고른다 |

### 3.7 측정 (2026-09-30, `node tools/arena.mjs classes 6`)

장검 고정, 고블린 3 + 주술사와 족장을 6판씩. 시간 = 목표 상한 대비(낮을수록 빠름).

| Role | 한 우물 | 가까운 두 우물 | 메모 |
| --- | --- | --- | --- |
| 딜러 | 어쌔신 0.21 · 스나이퍼 0.23 · 아크메이지 0.25 | 비전의 인챈터 0.23 · 사냥의 아케인 아처 0.23 · 비전의 룬나이트 0.27 | 한 우물끼리 20% 안. 위치 헌터·드루이드(딜러 쪽)는 0.36~0.42로 느리다(근접 봇이라 원거리·혼합에 불리) |
| 탱커 | 가디언 받은 피해 2% | 룬나이트 0~3% · 워로드 0~5% · 소드마스터 7~8% · 팔라딘 11~15% | 보호막이 받은 피해를 가려 혼자 재는 측정으로는 가디언이 맨 위가 아니다. 파티 AI가 들어온 뒤 도발·대신 맞기로 다시 잰다 |
| 힐러 | 하이 프리스트 남은 HP 86% | 기도의 팔라딘 100% · 기도의 섀도 프리스트 91% | 혼자 재면 자기 회복만 보인다. 파티 뒤 다시 잰다 |
| 서포터 | 마에스트로 0.31 | 노래의 워로드 0.34 · 노래의 인챈터 0.32 | 목표대로 |

- 스킬은 적만 친다. 스킬이 남긴 지형(불붙은 풀, 기름 폭발, 물을 타는 번개)은 누구에게나 위험하다(아크메이지가 자기 화염구에 타던 문제).
- Class를 가진 등불지기는 없는 등불지기보다 훨씬 강하다(족장전이 절반 시간). 던전 난이도는 주민이 Class를 갖추는 흐름(훈련소)이 들어올 때 다시 맞춘다.

## 12. 이번 구현 범위

- `js/data/classes.js`: Role·기본 Class·상위 Class·스킬 60·특성·갈래.
- `js/sim/classes.js`: 레벨 분배 → Class·수식어·Role·열린 스킬·위력, 장착 3칸.
- `js/sim/skillfx.js`: 효과 부품(모양 적중·투사체·원소·치유·보호막·정화·도발·막기·되치기·죽음 유예·묶기·밀치기·끌기·돌진·순간이동·자리 바꾸기·구역·강화·약화·다음 공격 강화·연결·미끼).
- 전투 연결: 도발(노릴 대상), 묶기(속도 0), 막기·되치기·죽음 유예·연결·약화(피해 계산), 구역(틱마다).
- 등불지기: 시험용 Class 레벨 정하기(상태 창) + 스킬 버튼 3칸(꺼져 있던 영혼석 칸 자리) + 조준.
- 측정: `tools/arena.mjs`에 Class별 측정(봇이 스킬을 AI 힌트대로 쓴다).
- 이번에 안 하는 것: 훈련소, 주민 Class 레벨 저장·성장, 파티 AI, 자동 탐험, 레이드.

## 13. 이 직업 시스템이 전체 루프를 강화하는 이유

던전에서 얻은 장비는 Class가 막지 않으니 누구에게나 의미가 있고, 정착지는 주민을 어느 Class로 나눠 키울지 정하는 곳이 되며, 자동 탐험은 Role 점수로 그 결정의 결과를 돌려주고, 레이드는 가장 잘 자란 다섯의 조합을 시험한다. 레벨 10을 나눠 찍는 한 가지 규칙이 "누구를 어떻게 키우고 누구와 함께 갈지"라는 질문을 네 곳 모두에 던진다.
