# 밸런스 기준

상태: 📘 기준 문서 · 실시간 기준으로 고침 (2026-09-30)

작성일: 2026-09-29 · 고침: 2026-09-30 · 대상: `js/` 모듈

모든 시스템(장비·몬스터·상태 이상·자원·파티)이 함께 쓰는 **공식과 기준선, 목표 지표**를 모은 문서다.

- **실제 개별 수치의 기준은 코드 데이터(`js/data/*.js`)다.** 이 문서는 공식과 범위만 들고, 개별 아이템·스킬 하나하나의 값은 적지 않는다.
- 시간 규칙은 `설계_실시간_전환.md`, 방향은 `설계_전체_방향.md`를 따른다. 부딪히면 그쪽이 우선이다.
- 표의 **현재**는 코드에 있는 값, **기준안**은 아직 구현되지 않은 목표값, **초안**은 실시간 전환 뒤 정할 값의 출발점이다.
- 영혼석은 꺼져 있다(`설계_전체_방향.md` §5). 영혼석 전용 규칙은 **보류**로 남긴다.
- 수치를 바꾸면 §10 변경 기록에 한 줄 남긴다.

## 0. 시간 단위

| 기준 | 값 | 쓰는 곳 |
| --- | --- | --- |
| 틱 | 1/20초 | 세계가 나아가는 단위. 시간이 흐를 때만 돈다 |
| 걸음 | 한 칸 = **0.3초** | 횃불 소모, HP 자동 회복, 쉬기, 떠도는 무리, 발견·깨어남 간격 |
| 전투 라운드 | 1라운드 = **1초** | 상태 이상 지속·틱, 원소 환경 변화, 지속 오라 |

- 예전 "N턴"은 걸음 기준이면 N × 0.3초, 라운드 기준이면 N초로 바꾼다.
- 시간은 손을 대고 있을 때(자동 걷기·탐험·쉬기 포함)만 흐른다. 멈춰 있는 동안에는 아무것도 줄거나 차지 않는다.
- 1칸 = 1m로 읽는다.

## 1. 기본 스탯

능력치(STR·DEX·INT)는 두지 않는다. 성장은 레벨(역할 성장, 미정), 장비 강화, 흉터가 맡는다.

| 스탯 | 뜻 | 주인공 기본 | 상태 |
| --- | --- | --- | --- |
| 최대 HP | — | 30 + 정착지 보너스(주민 3명째부터 1명당 +2, 최대 +15) | 현재 |
| 방어 | 물리 피해를 0~방어 사이 무작위만큼 줄임(최소 1은 들어감) | 0 | 현재 |
| 회피 | 적의 직접 공격(근접·화살·돌진)을 피할 확률 | 10% | 기준안 |
| 막기 | 방패만. 막으면 피해 0 | 0% | 기준안 |
| 명중 | 내 무기 공격이 맞을 확률 | 100% (무기 특성으로 −5%) | 현재 100%, 무기 보정은 기준안 |
| 시야 | 빛 반경 | 7칸, 횃불 단계로 줄어듦(§6.1) | 현재 7 |
| 원소 저항 | 불·냉기·번개·독 각각 −3~+3 단계(§3) | 0 | 현재 |

- 장비로 오르는 수치의 상한(방어 8, 회피 40%, 막기 30%, 최대 HP +20)은 `설계_아이템_장비.md` §8.
- 무기 색 배율(같은 색 영혼석 +15%)과 무기 치명 조건은 **끔**(`설계_전체_방향.md` §6).

### 1.1 레벨

- **레벨 = 역할 성장(미정)**. 레벨이 무엇을 여는지는 역할 시스템에서 정한다(`설계_전체_방향.md` §5). 예전 "레벨 = 영혼석 칸"은 보류.
- 경험치 = 쓰러뜨린 적의 최대 HP 합. 보스는 두 배. 레벨업 시 최대 HP +2, 잃은 HP의 절반을 채운다(현재).
- 레벨 상한은 영혼석 칸 6에 맞춘 것이었다. 새 상한은 (미정).

| 레벨 | 누적 경험치 | 대략 도달 시점 |
| ---: | ---: | --- |
| 2 | 15 | 1층 끝 |
| 3 | 45 | 2~3층 |
| 4 | 100 | 4~5층(2구역) |
| 5 | 180 | 6~7층 |
| 6 | 300 | 8~9층(3구역) |

## 2. 피해 계산 순서

```
1. 명중 판정   (무기 공격만. 명중 %)
2. 회피·막기   (적의 직접 공격만. 회피 → 막기 순)
3. 기본 피해   (무기 피해 범위 또는 스킬·원소 고정값)
4. 더하기      (강화 +N, 브랜드, 반지 힘, 되갚음 등 고정 가산)
5. 곱하기      (급소 표식 ×2 / 약점이면 ×2.5, 빙결 대상 물리 ×1.5, 기습 ×1.5)
6. 줄이기      (물리: 방어 / 원소: 저항 배율 §3)
7. 보호막      (먼저 깎임)
8. HP
```

- 곱하기가 여러 개면 모두 곱하고 마지막에 올림.
- 5단계에서 뺀 것: 무기 색 배율, 무기 치명 ×2(치명 조건이 턴 개념이라 끔).
- 예전 "피해가 들어가면 초록 쿨타임 감소"는 영혼석과 함께 보류.

## 3. 저항 7단계

원소 넷(불·냉기·번개·독)마다 −3~+3. 물(젖음)은 피해 원소가 아니다.

| 단계 | 받는 피해 | 표시 |
| --- | ---: | --- |
| −3 | ×2.5 | ▼▼▼ |
| −2 | ×2 | ▼▼ |
| −1 | ×1.5 | ▼ |
| 0 | ×1 | — |
| +1 | ×0.5 | ● |
| +2 | ×0.33 | ●● |
| +3 | ×0.2 | ●●● |

- 출처마다 +1 또는 −1. 모두 더해 −3~+3으로 자른다.
- 상태에 따른 보정: **젖음 = 번개 −1**, **빙결 = 불 −1**(녹으며 증기). 코드에는 넣지 않았다(§10, 2026-09-29).
- 플레이어의 음수는 대부분 −1까지(랜다트 대가, 흉터, 젖음). −2 이하는 몬스터용.
- 상태 이상에 걸리는 확률도 같은 단계로 줄인다: +1이면 걸릴 확률 절반, +3이면 걸리지 않음.

| 몬스터 | 불 | 냉기 | 번개 | 독 | 비고 |
| --- | ---: | ---: | ---: | ---: | --- |
| 고블린 | 0 | 0 | 0 | 0 | — |
| 독칼 고블린 | 0 | 0 | 0 | +2 | — |
| 갑옷 고블린 | 0 | 0 | −1 | 0 | 금속 갑옷 |
| 철갑 멧돼지 | 0 | 0 | −1 | 0 | 금속 갑주 |
| 해골 궁수 | 0 | +1 | 0 | +3 | 뼈: 출혈 없음 |
| 번개 마법사 | 0 | 0 | +3 | +3 | 해골 |
| 화염 마법사 | +3 | −1 | 0 | +3 | 해골 |

- 적을 길게 누르면 정보 카드에 점(●/▼)으로 보인다.

## 4. 상태 이상

라운드 기준(1라운드 = 1초). 틱 피해는 1초마다 들어간다.

| 상태 | 효과 | 지속·양 | 쌓임 |
| --- | --- | --- | --- |
| 출혈 | 1초마다 1 피해 | 스택 수만큼 초(1초마다 1 감소) | 더함 |
| 중독 | 1초마다 1 피해, 불이 닿으면 독 폭발(주변 3) | 초 수 | 긴 쪽 |
| 화상 | 1초마다 1 피해 | 3초 | 갱신 |
| 빙결 | 움직이지도 치지도 못함, 받는 물리 피해 ×1.5, 불이 닿으면 증기 폭발 | 2초(젖었으면 4초, 등불지기는 최대 2초) | 긴 쪽 |
| 감전(기절) | 움직이지도 치지도 못함, 힘 모으기·예고 끊김 | 1초 | 갱신 |
| 젖음 | 번개가 번짐, 불 절반 | 3초(물 위면 유지) | 갱신 |
| 골절 | 이동 속도 절반, 공격 간격 1.5배, 돌진 끊김 | 3초(약점이면 5초) | 긴 쪽 |
| 급소 표식 | 다음 찌르기가 ×2(약점이면 ×2.5) | 다음 찌르기까지 | — |
| 공포 | 도망침 | 두루마리 설정(초) | — |
| 가속 | 이동 속도 1.5배 | 8초 | — |

- 브랜드 등이 상태 이상 수치를 늘릴 수 있다(예: 피 브랜드 출혈 +2). 기본 초 수는 이 표를 따른다.
- 원소 환경 변화(불 번짐, 얼음 녹음 등)도 1초마다 한 번(`envTick`).

### 5.5 스킬 쿨타임

- **영혼석 쿨타임 표는 보류.** 세기별 기본 쿨타임(3·4·5·6), 색 감소(조건마다 −1), 색의 반지(−1, 최소 2)는 영혼석과 함께 꺼 둔다. 기록은 `설계_영혼석_스킬.md`.
- 역할 스킬 쿨타임은 초 단위로 쓴다(미정). 출발점으로 예전 세기 구분을 1라운드 = 1초로 옮긴다(초안).

| 세기 | 쿨타임 (초안) |
| --- | ---: |
| 가벼움(단일 대상, 작은 효과) | 3초 |
| 보통 | 4초 |
| 강함(범위 또는 큰 피해) | 5초 |
| 매우 강함(넓은 범위, 소환, 큰 회복) | 6초 |

- 쿨타임도 시간이 흐를 때만 준다.

| 항목 | 값 (걸음 기준) |

| 1 | 1~3 | 30~34 | 기본 +0~+1 | 0~2 |
| 2 | 3~5 | 34~38 | +1~+2 | 2~5 |
| 3 | 5~6 | 38~42 | +2~+4 | 4~7 |
| 4 | 6 | 40~45 | +3~+5 | 6~9 |

- 예전 "영혼석 칸" 열은 뺐다. 역할 성장 열은 (미정).

### 7.4 파티 인원 보정 (초안)

파티가 커질수록 던전 구역도 어려워진다(`설계_전체_방향.md` §3). 파티원이 늘면 한 사람이 받는 압박이 비슷하게 남도록 맞춘다.

| 파티 | 일반 적 HP | 무리 크기 | 보스 HP |
| --- | --- | --- | --- |
| 등불지기 혼자 | ×1 | 그대로 | ×1 |
| 파티원 1명마다 | +35% (초안) | 두 명마다 +1마리 (초안) | +50% (초안) |

- 적 공격력과 예고 시간은 파티 인원으로 바꾸지 않는다. 늘어나는 것은 버티는 양과 수다.
- 광역 예고(흩어져라·모여라 같은 기믹)는 파티가 있을 때만 나온다. 기준은 `설계_레이드.md`.
- 5인 레이드 보스 수치는 `설계_레이드.md`가 따로 정한다. 혼자 가는 도전의 보상은 (미정).

## 8. 목표 지표

직접 해보고 맞는지 확인하는 기준. 벗어나면 위 수치를 조정한다.

| 지표 | 목표 |
| --- | --- |
| 구역 하나에 흐르는 시간 | 층마다 100~150걸음(흐른 시간 30~45초), 5층 구역이면 150~225초 (초안) |
| 구역 하나에서 횃불 채우기 | 층마다 등잔 1번쯤 (초안) |
| 일반 전투 하나 | 흐른 시간 5~15초, 받는 피해는 최대 HP의 15~35% |
| 보스전 | 흐른 시간 30~60초 (초안), 받는 피해는 최대 HP의 50~90%(소모품 1~2개 사용) |
| 예고 피하기 | 예고를 본 뒤 멈춰서 생각하면 대부분 피할 수 있다 |
| 처음 하는 사람의 1구역 사망률 | 30~50% |
| 익숙한 사람의 1구역 사망률 | 10% 이하 |
| 첫 영혼석, 영혼석 스킬 사용 비율, 영혼석만 좋은 판 비교 | 보류 |

- 예전 "구역 하나(3층)에 300~450턴"을 걸음으로 옮긴 값이다. 구역이 5층으로 늘어난 것은 반영했지만 실제로 재 본 값은 아니다.
