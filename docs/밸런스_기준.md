모든 시스템(영혼석·장비·몬스터·상태 이상·자원)이 함께 쓰는 **공식과 기준선, 목표 지표**를 모은 문서다.

- **실제 개별 수치의 기준은 코드 데이터(`js/data/*.js`)다.** 이 문서는 공식과 범위만 들고, 개별 아이템·스킬 하나하나의 값은 적지 않는다.
- 설계 문서(`설계_*.md`)는 규칙과 의도를 설명하고, 공통 공식은 이 문서를 가리킨다.
- 표의 **현재**는 2026-09-29 `js/main.js` 기준, **기준안**은 아직 구현되지 않은 목표값이다.

## 1. 기본 스탯

능력치(STR·DEX·INT)는 두지 않는다. 성장은 레벨(영혼석 칸), 영혼석 진화, 장비 강화, 흉터가 맡는다.

| 스탯 | 뜻 | 주인공 기본 | 상태 |
| --- | --- | --- | --- |
| 최대 HP | — | 30 + 정착지 보너스(주민 3명째부터 1명당 +2, 최대 +15) | 현재 |
| 방어 | 물리 피해를 0~방어 사이 무작위만큼 줄임(최소 1은 들어감) | 0 | 기준안 |
| 회피 | 적의 직접 공격(근접·화살·돌진)을 피할 확률 | 10% | 기준안 |
| 막기 | 방패만. 막으면 피해 0 | 0% | 기준안 |
| 명중 | 내 무기 공격이 맞을 확률 | 100% (무기 특성으로 −5%) | 현재 100%, 무기 보정은 기준안 |
| 시야 | 빛 반경 | 7칸, 횃불 단계로 줄어듦(§6.1) | 현재 7 |
| 원소 저항 | 불·냉기·번개·독 각각 −3~+3 단계(§3) | 0 | 기준안 |

- 장비로 오르는 수치의 상한(방어 8, 회피 40%, 막기 30%, 최대 HP +20)은 `설계_아이템_장비.md` §8.
- 무기 피해 색 배율: 같은 색 영혼석 1개당 +15%(`설계_아이템_장비.md` §3.4). 피해 계산 §2의 5단계(곱하기)에 들어간다.

### 1.1 레벨 (기준안)

- 레벨 = 영혼석 칸 수(1~6). 레벨 1에 1칸, 레벨이 오를 때마다 1칸.
- 경험치 = 쓰러뜨린 적의 최대 HP 합. 보스는 두 배.

| 레벨 | 누적 경험치 | 대략 도달 시점 |
| ---: | ---: | --- |
| 2 | 15 | 1층 끝 |
| 3 | 45 | 2~3층 |
| 4 | 100 | 4~5층(2구역) |
| 5 | 180 | 6~7층 |
| 6 | 300 | 8~9층(3구역) |

- 레벨업 시 최대 HP +2.

## 2. 피해 계산 순서

```
1. 명중 판정   (무기 공격만. 명중 %)
2. 회피·막기   (적의 직접 공격만. 회피 → 막기 순)
3. 기본 피해   (무기 피해 범위 또는 스킬·원소 고정값)
4. 더하기      (강화 +N, 브랜드, 반지 힘, 되갚음 등 고정 가산)
5. 곱하기      (무기 색 배율, 무기 치명 ×2, 급소 ×2 / 약점이면 ×2.5, 빙결 대상 물리 ×1.5, 기습 ×1.5)
6. 줄이기      (물리: 방어 / 원소: 저항 배율 §3)
7. 보호막      (먼저 깎임)
8. HP
```

- 곱하기가 여러 개면 모두 곱하고 마지막에 올림.
- 피해가 1 이상 들어가면 초록 쿨타임 감소가 일어난다(막기·회피로 0이면 초록 감소만 일어남, `설계_영혼석_스킬.md`).

## 3. 저항 7단계

원소 넷(불·냉기·번개·독)마다 −3~+3. 물(젖음)은 피해 원소가 아니다.

| 단계 | 받는 피해 | 표시 |
| --- | ---: | --- |
| −3 | ×2.5 | ▼▼▼ |
| −2 | ×2 | ▼▼ |
| −1 | ×1.5 | ▼ |
| 0 | ×1 | — |
| +1 | ×0.5 | ● |
| +2 | ×0.33 | ●● |
| +3 | ×0.2 | ●●● |

- 출처마다 +1 또는 −1. 모두 더해 −3~+3으로 자른다.
- 상태에 따른 보정: **젖음 = 번개 −1**, **빙결 = 불 −1**(녹으며 증기).
- 플레이어의 음수는 대부분 −1까지(랜다트 대가, 흉터, 젖음). −2 이하는 몬스터용.
- 상태 이상에 걸리는 확률도 같은 단계로 줄인다: +1이면 걸릴 확률 절반, +3이면 걸리지 않음.

### 3.1 몬스터 저항 (기준안)

| 몬스터 | 불 | 냉기 | 번개 | 독 | 비고 |
| --- | ---: | ---: | ---: | ---: | --- |
| 고블린 | 0 | 0 | 0 | 0 | — |
| 독칼 고블린 | 0 | 0 | 0 | +2 | — |
| 갑옷 고블린 | 0 | 0 | −1 | 0 | 금속 갑옷 |
| 철갑 멧돼지 | 0 | 0 | −1 | 0 | 금속 갑주 |
| 해골 궁수 | 0 | +1 | 0 | +3 | 뼈: 출혈 없음 |
| 번개 마법사 | 0 | 0 | +3 | +3 | 해골 |
| 화염 마법사 | +3 | −1 | 0 | +3 | 해골 |
| 냉기 마법사 | −2 | +3 | 0 | +3 | 해골 |
| 보스 | 설계에 따라 | | | | 약점 하나는 반드시 둔다 |

- 적을 길게 누르면 정보 카드에 점(●/▼)으로 보인다.

## 4. 상태 이상

| 상태 | 효과 | 지속·양 | 쌓임 | 상태 |
| --- | --- | --- | --- | --- |
| 출혈 | 턴마다 1 피해 | 스택 수만큼 턴(턴마다 1 감소) | 더함 | 현재 |
| 중독 | 턴마다 1 피해, 불이 닿으면 독 폭발(주변 3) | 턴 수 | 긴 쪽 | 현재 |
| 화상 | 턴마다 1 피해 | 3턴 | 갱신 | 현재 |
| 빙결 | 행동 불가, 받는 물리 피해 ×1.5, 불이 닿으면 증기 폭발 | 2턴(젖었으면 5턴) | 긴 쪽 | 현재 |
| 감전(기절) | 한 턴 행동 불가, 예고 끊김 | 1턴 | 갱신 | 현재 |
| 젖음 | 번개 −1 단계, 불 절반 | 3턴(물 위면 유지) | 갱신 | 현재 |
| 골절 | 이동 느려짐, 돌진 끊김 | 3턴(약점이면 5턴) | 긴 쪽 | 현재 |
| 급소 표식 | 다음 찌르기가 ×2(약점이면 ×2.5) | 다음 찌르기까지 | — | 현재 |
| 공포 | 도망침 | 두루마리 설정 | — | 현재 |
| 가속 | 적이 한 번 움직일 때 두 번 행동 | 8턴 | — | 현재 |

- 상태 이상 수치는 영혼석·브랜드가 +로 늘릴 수 있다(예: 피 브랜드 출혈 +2). 기본 턴 수는 이 표를 따른다.

## 5. 영혼석 스킬 쿨타임

| 세기 | 기본 쿨타임 | 예 |
| --- | ---: | --- |
| 가벼움(단일 대상, 작은 효과) | 3 | 밀치기, 뼈 화살, 밀쳐내기 |
| 보통 | 4 | 피 내기, 독침, 반격 자세, 물벼락 |
| 강함(범위 또는 큰 피해) | 5 | 번개, 불씨, 보호막, 번개 갑주 |
| 매우 강함(넓은 범위, 소환, 큰 회복) | 6 | 냉기, 폭풍, 불길, 소환, 상처 봉합 |

- 색 감소: 조건마다 −1, 같은 영혼석은 라운드당 최대 1번(`설계_영혼석_스킬.md` §2).
- 색에 맞게 싸우면 실제 쿨타임이 대략 절반.
- 쿨타임을 줄이는 장비(색의 반지 −1)는 기본 쿨타임에 적용하고, 최소 2.

## 8. 목표 지표

직접 해보고 맞는지 확인하는 기준. 벗어나면 위 수치를 조정한다.

| 지표 | 목표 |
| --- | --- |
| 구역 하나(3층)에 걸리는 턴 | 300~450 |
| 구역 하나에서 횃불 채우기 | 1번쯤(등잔 1~2개 사용) |
