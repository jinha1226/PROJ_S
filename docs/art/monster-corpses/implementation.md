# 시체·특수부위·개별 숙련 업데이트

## 동작

- 몬스터의 `entity.died` 기록에서 현재 층·시야 안의 시체를 표시한다. 원본 몬스터 그림을 ±45도 기울이고 허리에서 24도 더 꺾는다. 몸 아래에는 혈흔을 그린다.
- 사망 후 3,000 월드 시간(기본 행동 약 30회)이 지나면 뼈 더미로 바뀐다. 지형, 통행, 아이템 소유권은 바꾸지 않는다. 몸과 뼈 위의 드롭은 작은 모서리 아이콘으로 표시한다.
- 전에는 몬스터 몸을 그리지 않고 혈흔과 드롭만 남겼다. 새 표현은 시체에 문/바닥/전리품 타일을 재사용하지 않는다. 보고된 문 모양의 정확한 발생 위치는 별도로 재현되지 않았다.
- 특수부위는 해당 캐릭터가 먹기 전에는 이름·효과 설명을 `???`로 표시한다. 습득 후 이능 이름, 패시브, 액티브를 표시한다. 가방에서 먹으면 결과 창을 띄우고, 이능 창에서는 새로 습득한 슬롯을 선택한다.
- 식별, 습득 이능, 경험치, 숙련 예산과 투자 내역은 캐릭터별이다. 미장착 아이템 가방은 공유한다.
- 숙련 조회/투자의 기본 대상은 현재 조작 캐릭터다. 상세창은 열어 둔 캐릭터의 성장 상태를 갱신하며, 캐릭터를 바꾸면 이전 투자 확인을 취소한다. 기존 성장 저장 구조를 유지한다.

## 섭취 적응 부작용

모두 300 월드 시간(기본 행동 약 3회) 지속한다. 상태창에 남은 시간이 표시되고 정화로 해제할 수 있다. 행동 속도에 따라 실제 행동 횟수는 달라질 수 있다.

| 부위 계열 | 부작용 | 효과 |
|---|---|---|
| 화염샘 | 화상 | 100시간마다 기본 화염 피해 3, 기존 저항 처리 적용 |
| 냉기샘·서리실 | 오한 | 행동 속도 보정 -25 |
| 물주머니 | 몸이 무거움 | 행동 속도 보정 -15 |
| 전도샘·전하기관 | 감전 | 명중 -15%p |
| 독니·산성혈액 | 독 | 기존 독 지속 피해 |
| 가죽·갑각·암석골격 | 경직 | 행동 속도 보정 -25 |
| 반향·심층눈·그림자 | 어지럼 | 명중 -15%p |
| 포식신경·투척본능·도약 | 떨림 | 명중 -15%p |
| 재생조직·흡혈 | 메스꺼움 | 행동 속도 보정 -15 |

## 저장 호환

섭취 상태는 `party.ability_bound`를 원인으로 하는 검증 가능한 `consumable.status` 기록이다. 새로운 BIND/party-use 명령에는 `part_ingestion` 표시를 저장한다. 표시가 없는 예전 리플레이는 부작용을 소급 생성하지 않는다. 시체 나이는 사망 시간으로 계산하므로 별도 저장 필드가 없다.

## 검증

- `corpse_parts_growth_acceptance`: 실제 사망 후 시체, 뼈 전환, 지형 불변, 시야·층 분리, 실화상 턴/만료, 캐릭터별 식별/포인트, 공유 가방, 확인창 대상 전환, 스냅샷 및 구·신 리플레이 통과.
- `elemental_parts_acceptance`: 원소 부위의 실제 섭취·전투·환경 효과와 저장 후 동일 진행 통과.
- `elemental_drop_replay_acceptance`: 실제 드롭 수집·섭취·전체 세션 리플레이 통과.
- `mastery_live_acceptance`: 실제 전투 경험치, 숙련 투자, UI와 저장 리플레이 통과.
- Godot 렌더링으로 32/40px 시체 표현 확인: [runtime-preview.png](runtime-preview.png).
- 모바일 390px 실제 UI 확인: [섭취 전](part-unknown.png), [섭취 후](part-learned.png).
- 확장 점검 `monster_all_abilities_acceptance`에는 기존 실패 2건이 있다: `PREDATOR_NERVE` 패시브 발동 조건, `REGENERATIVE_TISSUE` 사용 조건. 수정 전 `bd728ac`의 별도 복사본에서도 동일 실패를 확인했다. 테스트의 기존 이능 자체 검증은 섭취 적응 효과를 끈 상태로 분리했다. 이 두 기존 실패는 이번 변경의 통과 목록에 포함하지 않는다.
