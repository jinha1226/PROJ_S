# 먹선 캐릭터에 맞춘 환경 수정 방향

기준은 ink-torso-v1의 짧고 넓은 토르소, 각진 검은 그림자, 저채도 갈색·회색이다.
현재 환경은 외곽선과 형태는 맞지만, 균일하고 매끈한 면과 밝은 주황 조명 때문에 캐릭터보다 부드럽게 읽힌다.

- 거점: 배치 유지. 지붕 아래·문 안·건물 접점에 큰 각진 어둠을 넣고, 주황빛은 창과 불꽃 주변으로 제한한다. 주민도 같은 먹선 토르소로 맞춘다.
- 벽: 차가운 회색 유지. 작은 질감을 늘리지 않고 돌 하단과 모서리에 끊어진 먹선과 굵은 그림자 면을 넣는다.
- 바닥: 따뜻한 회색과 2px 이동 격자 유지. 캐릭터보다 낮은 대비로 두고, 균열·잔무늬는 절제한다.
- 오브젝트: 같은 외곽선 굵기와 광원 방향, 2~3단계 각진 명암으로 통일한다. 매끈한 그라데이션과 장난감 같은 광택은 줄인다.

전체 화면을 일괄 어둡게 하는 대신, 큰 그림자 형태와 재질 표현을 수정한다.
새 에셋 검토는 실제 표시 크기에서 캐릭터·바닥·벽·상자를 한 장면에 놓고 비교한다.
거점·1층 재질·소품에 적용 완료. 이미지와 적용 범위는 [ink-environment-v1.md](ink-environment-v1.md) 참조.
