# 64픽셀 캐릭터·몬스터 제작 규격 제안

상태: 제작 방식 제안. 이번에 캐릭터 방향/동작/장비 시트를 생성하거나 게임에 연결한 것은 아니다.

## 결론

이미지 모델은 **디자인과 기준 포즈**를 정하는 데 사용하고, 승인된 몸체에 방향·프레임·장비를 종속시킨다. 완성 캐릭터를 장비 조합마다 새로 생성하지 않는다. 같은 프롬프트나 한 장의 시트 생성만으로 프레임 간 동일성이 보장되지는 않는다.

현재 소품도 투명 배경 요청을 두 번 실패하고 세 번째에 실제 alpha를 얻었다. 생성 결과의 외형·규격·배경을 검사하는 단계가 반드시 필요하다.

## 고정할 규격

| 항목 | 첫 제작안 |
|---|---|
| 지면 | 64×32, 2:1 아이소매트릭 발판 |
| 인물 프레임 | 64×64, 모든 프레임 공통 발 기준점 (32,56) |
| 일반 인물 크기 | 머리부터 발까지 약 32~40px, 무기 공간은 별도 여백 |
| 광원 | 월드 기준 좌상단, 재질별 명암 단계 고정 |
| 색 | 인간 기준 공통 24~32색 팔레트 초안; 재질별 3~4단계 |
| 좌표 | 이동은 세계 좌표에서, 스프라이트 발은 고정 기준점에 렌더링 |
| 방향 | 화면 NE, SE, SW, NW의 4종. world N→NE, E→SE, S→SW, W→NW |
| 확대 | 정수배 확대 우선, 보간 OFF. 최종 크기로 먼저 판독성 확인 |

픽셀 캐릭터는 바닥과 똑같이 프레임 중앙에 놓는 것이 아니라 발 기준점이 타일 중심과 일치해야 한다. 프레임마다 이미지 외곽을 자동 잘라 재중앙정렬하지 않는다.
4방향 사이의 대각선 이동 방향은 인접한 두 시각 방향 중 마지막 방향 유지로 우선 처리하는 제안이다. 이동 자체의 8방향 규칙을 바꾸지 않는다.

## 제작 순서

1. 인간 모험가 한 명의 무장 없는 기준 몸체를 생성하고 머리/몸통/팔다리 비율과 실루엣을 승인한다.
2. 같은 기준 이미지를 매번 참조해 4방향 정지 포즈를 만든다. 기준이 되는 앞·뒤 모습을 먼저 고정한다.
3. 방향별 이동 루프 4프레임과 기본 근접 공격 4프레임을 만든다. 한 방향의 짧은 시퀀스씩 검수하며 확장한다.
4. 64픽셀 원본에서 발 위치, 손 위치, 머리 크기, 무기 길이, 명암을 정리한다. AI의 프레임을 그대로 이어 붙이지 않는다.
5. 확정된 몸체 포즈 위에 장비를 분리한다. 프레임별 손/머리/몸통 앵커와 가림 순서를 기록한다.
6. 한 인간 + 한 고블린 + 검/방패/갑옷 조합으로 실제 이동·공격을 확인한 뒤 종족과 무기군을 늘린다.

시작 프레임 예산: 정지 1 + 이동 4 + 공격 4 = 방향당 9, 4방향 **36프레임/몸체**. 이후 피격·시전·사망은 별도 추가한다. 검·창·활의 공격 포즈는 동일할 수 없으므로 무기군별 동작이 추가된다.

## 장비는 겹쳐 그리는 구조

그림 레이어 예시: 뒤쪽 무기/망토 → 몸체 → 갑옷 → 얼굴/머리 → 투구 → 앞쪽 손/무기/방패.
이 순서는 방향과 프레임에 따라 바뀐다. 무기를 항상 마지막에 그리면 뒤쪽 손의 무기가 몸을 뚫고 나온다.

- 갑옷/투구: 몸체의 해당 포즈를 가리는 마스크와 같은 방향/프레임을 공유.
- 무기: 손 앵커·각도·앞뒤 가림 정보를 공유. 손이 무기 손잡이를 덮을 수 있어야 한다.
- 방패: 좌우 손을 고정한다. 단순 좌우 반전으로 오른손 검/왼손 방패가 바뀌지 않게 한다.
- 망토/긴 의복: 자체 흔들림이 필요할 수 있어 독립 애니메이션 또는 프레임 시트를 사용.
- 소모품·반지 등: 전부 외형 변화로 만들지 않는다. 먼저 실루엣이 크게 달라지는 장비만 대응한다.

장비는 레이어라고 해서 자동으로 무료가 되는 것이 아니다. 몸체 종류 × 방향 × 포즈에 맞는 작업은 남지만, **모든 장비 조합을 완성 이미지로 제작하는 조합 폭증**을 피할 수 있다.

## 가장 강한 일관성이 필요할 때

캐릭터·장비 수가 많아지면 승인된 디자인을 단순 3D 몸체/공통 리그로 옮겨, 같은 카메라·팔레트로 방향과 동작을 렌더링하고 픽셀 마감을 하는 방식이 더 통제하기 쉽다. 초기 모델링·리깅 비용은 늘지만 체형, 손 앵커, 장비 추적을 한곳에서 관리할 수 있다.

지금은 **인간 36프레임의 작은 세트로 2D 레이어 제작성을 먼저 검증**한다. 몸체 흔들림과 장비 정렬 수정량이 과하면 대량 생산 전에 리그 기반으로 전환한다. 다음 단계 선택 전에 실제 제작 시간과 수정 프레임 수를 기록한다.

## 검수와 납품

- 기준 PNG, 사용 프롬프트, 참조 이미지 버전, 실제 alpha 검사를 보존.
- 방향을 나란히 배치해 머리 크기/키/의상 표식 비교.
- 이동 루프 첫/끝 프레임 연결, 접지 발의 미끄러짐, 공격의 준비→타격→복귀 확인.
- 발 앵커가 고정되는 것은 기준점만을 뜻함. 공격 상체 이동 등 의도된 변형은 허용.
- 무장 없음/검/검+방패/갑옷/갑옷+투구 조합을 네 방향에서 비교.
- 원본의 자동 재생성 대신 수정 대상 프레임·레이어만 수정.
- 몸체, 장비, 그림자, 타격 VFX를 분리. 예고 타일과 전투 판정은 애니메이션 이미지에 종속시키지 않는다.
- 그림자/빛/파티클은 낮은 비용의 렌더 효과로 처리하고 프레임마다 다시 생성하지 않는다.
