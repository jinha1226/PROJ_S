# 8×8 전투 구역 3종 — 첫 플레이용 배치

`preview.html`을 브라우저에서 열면 세 배치를 아이소매트릭 도식으로 전환해 볼 수 있다. 서버가 필요 없는 검토용 정적 사본이며, 실행 데이터의 원본은 JSON이다.

## 적용 범위

- 1·2층의 COMBAT 방 4개에 세 템플릿을 순환 적용한다. 한 층에서 한 종류는 반복된다.
- 기존 3×3 방 연결 그래프, 안전방·위험방·계단방 역할, 입구 좌표는 유지한다.
- 각 템플릿은 8×8 전체를 사용한다. 네 입구와 입구 주변 배치 공간을 비운다.
- 적 3마리는 기존 층별 종족을 유지하되 한 덩어리가 아닌 세 지점에 배치한다.
- 새 원거리·돌진 AI, 파괴 가능한 엄폐물, 보급상자 방어 규칙은 이번 범위에 없다.
- 신규 아트는 **검토용 원본**이다. 게임은 기존 지형 렌더러를 사용하며 아직 동굴·숲 전용 외형을 표시하지 않는다.
- 기존 진행 중인 방에는 소급 적용하지 않는다. 새로 생성된 층으로 확인한다.

## 배치

`#` 이동 차단물, `.` 일반 바닥, `~` 얕은 물, `r` 잔해. 좌표는 좌상단 (0,0).
현재 차단물은 모두 실제 `wall` 규칙이다. 숲의 나무/동굴의 암반은 아트 교체 시 외형만 구분한다.
물·잔해 효과는 기존 지형 규칙을 사용한다. 새 엄폐 보너스는 추가하지 않았다.

| 구역 | 통행 가능 칸 | 핵심 선택 | 후속 확장 |
|---|---:|---|---|
| 무너진 감시소 | 56 | 중앙 직선로 vs 기둥 옆 우회, 적 분리 | 기둥 뒤 궁수 배치 |
| 갈라진 샘 동굴 | 56 | 짧은 물길 vs 바깥의 넓은 육로 | 중앙 돌진 예고 |
| 뿌리 덮인 저장터 | 57 | 엇갈린 차단물을 돌아 접근 순서 조절 | (3,4) 보급품 보호 |

### 무너진 감시소

```text
#......#
........
..#.#...
........
..#..#..
........
...rr...
#......#
```

### 갈라진 샘 동굴

```text

..##....

..~~....
...##...

#......#
```

### 뿌리 덮인 저장터

```text
#......#
........
..#.....
....#...
..r.....
....r...
....#...
#......#
```

공통 적 위치: (5,2), (5,5), (2,5). 네 방향 입구 어느 곳에서도 맨해튼 거리 2 이내에 적을 놓지 않는다.
보호 목표는 데이터에 `enabled: false`로 기록한 후속 설계이며, 실제 보상이나 전투 종료 조건에 연결하지 않았다.

## 아트

`fantasy-terrain-source.png`: 내장 이미지 생성기로 만든 18종 타일 원본.
위부터 던전 / 동굴 / 지하 숲, 왼쪽부터 기본 바닥 / 변형 바닥 / 낮은 장애물 / 높은 장애물 / 물 / 보급상자.
실제 생성 요청은 `prompt.md`에 보존했다. 외부 게임의 원본 에셋을 복사하지 않았다.

시각 검토: 세 테마와 장애물 높이는 구별되며 전체 방향과 조명도 유사하다.
다만 셀별 바닥 기준점·여백·투영비가 정확히 동일하다고 보장할 수 없고, 물 가장자리가 턱처럼 보여 통행 불가로 오해할 수 있다.
현재 원본 그대로 잘라 게임에 배치하면 틈이나 정렬 오차가 생길 수 있어 런타임 교체를 하지 않았다.
타일 추출·알파·크기·발판 기준점 검수 후 기존 충돌 데이터와 1:1 대응시켜 적용해야 한다.
아트의 낮은 장애물은 아직 별도 엄폐 규칙이 없으므로 지금 `rubble`에 그대로 대응시키면 안 된다.
나무 높이는 캐릭터를 가릴 수 있어 선택/위협 표시는 항상 그 위에, 가려진 유닛은 실루엣으로 표시하는 후속 작업이 필요하다.

## 구현 위치

- `data/content/handcrafted_rooms.json`: 편집 가능한 실제 8×8 배치.
- `sim/handcrafted_room_templates.gd`: 지형 배치 함수.
- `sim/nine_room_generator.gd`: 기존 구역 생성기 연결.
- `tests/handcrafted_rooms_acceptance.gd`: 크기, 연결성, 적 중복, 입구 안전 공간, 층별 3종 포함 검사.

밸런스는 아직 모바일 실전 검증 전이다. 입구별 3인 배치와 이동/공격 예고 가독성을 먼저 확인하고 적 역할을 추가한다.
