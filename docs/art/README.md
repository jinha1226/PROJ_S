# 현재 아트 적용 기록

현재 방향은 **단순한 판타지 폰, 굵은 외곽선, 작은 크기에서 읽히는 실루엣**이다. 맵의 벽에는 낮은 입체감을 유지한다.

| 확인할 내용 | 위치 |
|---|---|
| 종족·아이템·타일의 실제 적용 화면 | [fantasy-pawns-v1](fantasy-pawns-v1/README.md) |
| 현재 몬스터 목록·크기 비교 | [fantasy-monsters-v1](fantasy-monsters-v1/README.md) |
| 현재 모바일 UI | [fantasy-ui-v1](fantasy-ui-v1/) |
| 시체·뼈·부위 섭취 화면 | [monster-corpses](monster-corpses/implementation.md) |
| 게임에서 읽는 에셋과 예전 대체 에셋 | [assets 안내](../../assets/README.md) |
| 생성 원본·채택한 참고 이미지·지난 시안 | [art 안내](../../art/README.md) |

이 폴더에는 현재 적용 결과와 검증 기록을 둔다. 새 시안은 `art/`에 보관하고, 실제 채택한 이미지만 가공 후 `assets/`에 넣는다.
