# 1층 환경 · 토르소 캐릭터 기준

2026-09-22. 기존 human/dwarf/elf 토르소를 유지하고 환경을 큰 색면, 검은 외곽선, 적은 질감으로 맞춘 첫 시안.

- 원본: assets/topdown/floor1-flat-v1/materials.png, props.png. 각각 1254×1254.
- 재질 16종: 판석 4종, 벽 정면·상부, 목재, 금속, 물 2종, 진흙, 이끼, 잔해, 흙, 잿불, 젖은 판석.
- 소품 16종: 부서진 기둥, 돌무더기, 상자, 통, 켜진/꺼진 횃불, 화로, 모닥불, 보물상자, 흙더미, 석관, 제단, 유물, 문, 뼈, 바리케이드.
- built-in imagegen으로 생성. 정확한 프롬프트와 참조는 floor1-flat-v1-prompts.json에 보관.
- 배경 제거 및 재채색 없이 생성 원본을 보존. 소품은 실제 알파 채널이 있다. catalog.json의 영역을 AtlasTexture로 읽는다.

## 적용 범위

F1_RUINS의 바닥·벽 재질, 입구·제단·유물·야영지·상자·흙더미 표시를 교체한다. 벽의 높이·세로 연결·모서리 구조는 기존 masonry_tiles를 그대로 사용한다. 다른 층, 캐릭터, 시야와 기억 처리, 충돌·생성·전투 규칙은 유지한다.

장애물과 횃불은 재사용할 수 있도록 준비했으며 추가 스폰은 하지 않는다. 물·잿불 등은 정적 원본이다.

## 미리보기

Godot에서 tools/art/floor1_flat_preview.tscn을 실행한다. 실제 기존 토르소 3종, 연결 벽, 바닥, 물, 소품과 전체 소품 목록을 함께 보여준다.
