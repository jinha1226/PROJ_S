- [실제 가방·장착 화면](inventory.png)
- [실제 런타임 타일로 조합한 연결 검토 화면](connections.png)

이미지는 Godot 4.6.2의 실제 렌더링 결과다. 원정·가방은 450×800, 연결 검토 화면은 640×550이다. 연결 검토 화면은 타일과 캐릭터 렌더러를 사용하는 고정 배치로, 실제 원정 생성기를 대체하지 않는다.

## 변경

- 종족 6종 및 아이템 16종의 체크무늬 제거, 내부 구멍 투명화, 개별 크기·기준점 정리.
- 지도와 초상화의 같은 종족 매핑, 가방·바닥·손 장비의 같은 아이템 매핑.
- 원본 벽의 윗면·앞면을 조합한 16개 연결 형태. 알려진 인접 바닥만 참조하며 시야 밖 지형을 조회하지 않는다.
- 원본에 없는 몬스터·장비·특수 지형 및 식별 전 물약은 기존 에셋을 유지한다. 걷기 프레임과 갑옷 전용 레이어는 이번 원본에 없다.

## 검증 기록

- 게임용 PNG 56개: 6종족 + 16아이템 + 18타일 + 16벽 연결형. 알파 채널, 파일 개수, 불투명 전경 보존 확인.
- `fantasy_pawn_assets_acceptance.gd`: PASS. 종족·아이템·실제 지도 연결, 미관찰 경계 비공개, 장비 표시, 렌더 조회의 시뮬레이션 비변경 확인.
- `topdown_generated64_acceptance.gd`: PASS. 타일 규격, 문 상태, 계단, 기억·미탐색 상태 확인.
- `species_picker_start_regression.gd`: PASS, 0 failures. 실제 화면 입력을 통한 5개 플레이 종족의 새 원정 시작 확인.
- Godot 편집기 임포트·스크립트 검사 및 Web release export 완료.
- 내보낸 `index.pck`를 소스 저장소 밖의 빈 폴더에서 실행: 종료 코드 0, 리소스 누락·스크립트 오류 없음.

초기 연결 검토에서 드러난 벽 윗면의 과한 반복 줄무늬는 원본 돌 한 개의 내부 표면으로 교체했다. 스크린샷은 수정 후 결과다. 게임 규칙과 저장 형식은 변경하지 않았다.
