## Final prompt

Use case: stylized-concept. Asset type: ONE cohesive monster art-direction comparison sheet for a mobile isometric fantasy tactical game. Input image: actual project's terrain tiles, STYLE AND CAMERA REFERENCE ONLY. Create a landscape sheet with three equal columns: GOBLIN, WOLF, KOBOLD. Upper 65 percent: one large isolated full-body idle sprite per column, all facing diagonally down-right, orthographic elevated three-quarter camera looking down at about 35 degrees, see top of head/shoulders/back; NOT frontal side-view sprites. Lower 35 percent: repeat the EXACT SAME three monsters at gameplay scale, each standing centered on ONE identical gray stone diamond tile matching first row of reference. Demonstrate believable small footprint: humanoid feet occupy central 35% of tile width, humanoid height roughly 80% of tile width; wolf length 70% tile width, head height 40%. Upper isolated views have no platforms. GOBLIN: squat olive-green goblin fighter, broad triangular ears, bare face, rust red short tunic and brown leather belt, small blunt iron cleaver and plain small wooden buckler, sturdy readable silhouette. WOLF: lean charcoal/slate gray four-legged wolf, lighter muzzle and back ridge, alert ears, naturally horizontal body and visible back plane, no armor. KOBOLD: smaller ochre/rust reptilian humanoid with projecting snout and long curved tail, dark teal hoodless short vest, short wooden bow held away from body, no shield. Kobold must look distinctly different from goblin, not another green humanoid. Style: coarse hand-placed pixel art, each isolated creature looks like an actual 40–48px tall sprite enlarged with nearest-neighbor, 64x64 sprite-cell design, hard stair-step contours, compact pixel clusters, 4 shades per material, common pixel size for all monsters and tiles, limited earthy palette, upper-left lighting, small dark contact shadows, clean dark silhouette edge. Do not make high-resolution painted art with a pixel filter. Avoid shiny 3D, gradients, excessive tiny texture, chibi giant heads, heroic character proportions, dramatic poses, VFX, extra creatures, scenery, UI panels. Background uniform deep charcoal #101820. Small simple column labels only: GOBLIN / WOLF / KOBOLD. This is an approval sheet, not animation frames or a finished game screenshot.
