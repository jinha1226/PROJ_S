# 육체 상태 기초 수치 표시 protocol

- 작업 ID: `BODY-STATUS-UI-001`
- 기준 commit: `121215d`
- 사용자 요청: 상태창의 육체 상태에 부상뿐 아니라 피부 질김, 뼈 강도, 혈액량 같은 기본 신체 수치도 표시한다.

## 현재 상태

- 육체 상태에는 혈액 비율, 의식, 충격, 상처 수와 부위별 기능 상태가 표시된다.
- 시뮬레이션은 혈액 최대량, 피부 질김, 연부조직 완충, 골절 임계값, 충격·의식 임계값을 이미 권위 값으로 보유하지만 상태 DTO와 UI 일부에는 노출하지 않는다.

## 구현 범위

- 멤버 상세 DTO에 기존 `body_scalars`의 읽기 전용 수치를 명시적으로 투영한다.
- 육체 상태 카드에 현재/최대 혈액량, 피부 질김, 연부조직 완충, 뼈 강도, 충격 현재/임계값을 표시한다.
- 기존 의식, 상처 수, 부위별 기능 상태를 유지한다.
- 신체 생성·피해·출혈·골절 판정 규칙과 저장 형식은 변경하지 않는다.
- 힘 능력치만 `STR`을 사용하고 스트레스 표기는 `TNS`(긴장)로 통일해 중복을 없앤다.

## 검증

- 멤버 상세 DTO가 권위 신체 수치와 정확히 일치해야 한다.
- 상태 카드가 새 항목과 현재/최대 혈액량을 모두 표시해야 한다.
- 360px/450px 상태창에서 텍스트가 자동 줄바꿈되고 기존 상태 탭 흐름이 유지되어야 한다.
- 파티 초상 카드와 상세 상태 게이지 어디에도 스트레스 의미의 `STR`/`ST`가 남지 않아야 한다.
