# 난이도 게이트

`tests/difficulty_gate.gd`가 쓴다. 기준 주인공(1~N−1층을 모두 잡은 레벨과 이능)과 절반만 잡은 주인공이 N층 무리를 하나씩, 매번 HP를 채우고 싸운 결과다. 합격선: 기준 주인공의 전투당 HP 손실 25~40%, 야영 필요, 절반 주인공은 뚜렷하게 더 잃음.

자동 전술 봇의 진단값이다. 매 전투 HP·MP를 채우고 첫 패배에서 중단하므로 실제 원정 완주율로 읽으면 안 된다.
