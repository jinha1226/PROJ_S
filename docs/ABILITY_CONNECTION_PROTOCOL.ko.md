# 몬스터 이능 연결 작업

기준: `9b46957`. 정착지/전투 예고 개편은 범위에서 제외한다.

요청: 몬스터 정수 16종을 획득·결속·모드 선택·실제 효과까지 연결한다. 설명과 드롭 등록만으로 완료 판정하지 않는다.

검증 계약:

- 정수별 정상 결속, 중복/슬롯/모드 검증과 저장·재실행 일치.
- 액티브는 대상·거리·시야·비용 검사 후 하나의 턴 트랜잭션으로 실행한다.
- 패시브는 일반 공격/피격/이동/탐험의 실제 경로에서 발동한다. 파생 피해의 재귀 발동은 금지한다.
- 효과별 장착 전후 변화와 UI 모드 선택을 검증한다. 미연결 효과는 완료로 표시하지 않는다.
- 기존 화염탄·드롭·전투·저장 회귀를 유지한다. 실기기 체감 검수는 자동 테스트와 구분한다.
