# 아이템·던전 탐험 보상 1차 점검

- 날짜: 2026-09-10
- 기준 코드: `6618551a9ebf5107b123d9ad31273d564bb39b7a`
- 범위: 코드·콘텐츠 정적 점검. 드롭률이나 게임 코드를 수정하지 않았다.
- 한계: 실제 여러 시드의 획득량·소모량·플레이 시간 측정은 아직 하지 않았다. 아래 체감 원인은 구조에 근거한 해석이다.

## 결론

보상이 전혀 없는 구조는 아니다. 적의 소지 장비, 일부 종족 드롭, 거점 물자, 귀환 보상과 성장 보상이 있다. 그러나 **새 아이템을 발견하고 장비를 바꾸는 보상 종류가 좁고, 전투 없이 탐험해서 얻는 보상도 거점 자원 중심**이다. 단순 드롭률 증가보다 보상 종류·획득 경로·사용처를 먼저 연결할 필요가 있다.

## 체감 보상이 약해질 수 있는 지점

1. **반복 획득 장비의 변화가 적다.** 고블린 기본 장비가 같고 해당 생성 경로에 옵션 추첨이 없어, 처음 몇 번 이후 장비 교체 기대가 줄어들 수 있다.
2. **종족별 수집 차이가 작다.** 추가 드롭 콘텐츠는 고블린에만 있고, 다른 적은 거점 자원 또는 실제 소지품 회수에 의존한다.
3. **등급 기반과 실제 발견 경로 사이에 간격이 있다.** 등급·옵션을 저장할 수 있다고 해서 희귀 장비 발견 플레이가 구현된 것은 아니다.
4. **탐험 보상이 건설 자원에 치우쳐 있다.** 확인한 물자 배치 경로에서는 장비·소모 도구·특별 보상 선택지가 나오지 않는다. 다른 경로의 존재 여부는 구현 착수 시 전체 생성 경로를 추가 추적해야 한다.
5. **아이템을 가져온 원정과 보상 인정 조건이 다를 수 있다.** 귀환 성공 판정은 `base.resource_gathered`를 요구한다. 일반 아이템만 회수한 원정은 이 조건을 만족하지 못할 수 있다. 실제 UI 경로로 재현이 필요하다.
6. **앞으로 추가할 횃불·어둠 스트레스는 탐험 비용을 늘린다.** 보상과 같이 조정하지 않으면 탐험이 더 손해처럼 느껴질 위험이 있다.

## 개선안 — 구현 전 합의할 우선순위

### 1순위: 현재 보상이 실제로 도착하는지 검증

- 바닥 표시 → 접근 → 줍기 → 인벤토리 → 사용/장착 → 귀환 → 판매/보상 수령을 한 흐름으로 테스트한다.
- 채집 버튼 제거 이후 물자 회수가 현재 줍기 UI로 연결되는지 재검증한다. 버튼을 되살리는 것을 기본 해법으로 삼지 않는다.
- 같은 아이템 반복 획득, 빈 장비 슬롯, 장착 불가 조건을 UI에서 구분한다.
- 일반 전리품만 들고 귀환한 경우도 원정 성과로 인정할지 결정한다. 단순 출입·기존 물품 재반입으로 반복 보상을 받는 허점은 막는다.

### 2순위: 작은 보상 묶음으로 탐험 재미 확보

제안하는 세 종류의 보상을 균형 있게 배치한다. 아직 확정 드롭률이나 제작 지시가 아니다.

- **유지 보상:** 식량·회복 물약·횃불. 탐험을 조금 더 이어갈 수 있는 보상.
- **선택 보상:** 다른 무기·방어구·장신구 또는 소수의 의미 있는 옵션. 무조건 수치 상승보다 플레이 방식을 바꾸는 선택.
- **귀환 보상:** 마석·가치품·명확한 사용처가 있는 재료. 돌아갈 이유를 만드는 보상.

일반 적은 소량의 종족다운 전리품, 위험한 적은 장비 발견 기회, 막다른 방·위험 구역은 전투 없이도 얻을 수 있는 발견 보상으로 역할을 나눈다. 몬스터만 잡아야 보상이 생기는 구조로 제한하지 않는다.

첫 묶음은 기존 실사용 아이템과 기존 옵션을 재활용한다. placeholder를 이름만 바꿔 보상 목록에 넣지 않는다. 소재를 추가할 때는 판매·제작·사용 중 최소 하나의 사용처도 함께 제공한다.

### 3순위: 발견·비교·귀환 피드백

- 바닥의 특별 아이템은 작은 색/반짝임으로 구별하되 24×24 다크판타지 스타일을 유지한다.
- 획득 로그에 이름·수량·등급을 표시하고, 장비 비교에서 달라지는 실제 효과를 보여준다.
- 귀환 화면은 획득 물품·판매 가치·소모한 준비물·성장 성과를 요약한다. 가격이 없는 장비를 임의의 골드 가치로 환산하지 않는다.
- 전체 드롭량만 늘리지 말고 의미 없는 중복 아이템 정리 부담도 측정한다.

### 후속 후보

이능 획득·특별 유물·환경 상호작용 도구는 수집 동기를 강화할 수 있다. 다만 이능 획득/장착 규칙, 활성화된 환경 효과, 사용 UI가 연결될 때 별도 단계로 구현한다. 이번 정적 점검을 대형 제작·경제 시스템 구현 승인으로 해석하지 않는다.

## 개발 전후 측정과 안전장치

- 고정 시드와 행동 기록 여러 개로 짧은 원정·깊은 원정·비전투 탐험·적 다수 처치를 각각 확인한다.
- 측정: 첫 쓸 만한 발견까지 행동/시간, 장비 교체 또는 선택 횟수, 소비/회수 물약·식량·횃불, 귀환 성과, 무보상 구간, 중복 아이템 비율.
- 입구 왕복·저장 재로드·이미 회수한 보상 재방문에서 복제/재추첨이 없어야 한다.
- 실제 적 장비 회수와 추가 보상 생성의 중복 여부를 검사한다. 보상 생성은 시드와 고정 식별자 및 규칙 버전으로 재현한다.
- 모든 실제 등장 종족의 드롭 적용 여부를 검사한다. 몬스터 수 증가로 인벤토리/바닥 아이템 렌더링이 느려지지 않는지도 측정한다.
- 최종 드롭률·가격은 이 측정을 보고 정한다. 현재 점검만으로 원정당 손익이나 적정 수치를 단정하지 않는다.

## 시야 개발서와의 관계

[조명·종족별 시야·횃불 개발서](LIGHT_VISION_TORCH_STEALTH_IMPLEMENTATION_GUIDE.ko.md)는 별도 작업 범위다. 공통 시야 1차 구현은 진행 가능하지만, 횃불 연료와 어둠 스트레스 수치를 최종 조정할 때는 원정 보상·준비물 소모 측정 결과를 함께 검토한다. 이 점검서가 시야 개발 세션의 작업 범위를 자동으로 넓히지는 않는다.
