# 05 · 정착지 · 이야기 이식

먼저 `00_먼저_읽기.md`를 읽는다. 01~04가 끝나 있어야 한다.

## 목표

던전과 정착지가 이어진 한 판. 빈 공터에서 불을 붙이고, 원정에서 돌아오면 마을이 자라 있고, 등불지기가 쓰러지면 누군가 다시 횃불을 든다.

## 옮길 것 (규칙 유지, 영혼석 부분 제외, 시간은 초·걸음)

| 옛 | 새 | 주의 |
| --- | --- | --- |
| `js/core/settlement.js`, `js/core/rooms.js`, `js/data/build.js` | `next/js/town/` | 40×40, 빛 반경, 청사진, 방 인식, 프리셋·알아서 짓기, 나무·돌 비용. **영혼석 제단 방은 옮기지 않는다** |
| `js/core/meta.js` | `next/js/town/meta.js` | 새 저장 키 `torch-next-v1`. 주민·관계·기분·HEXACO·모닥불 밝기 |
| `js/core/visitors.js`, `js/data/visitors.js` | `next/js/town/visitors.js` | 방문자·요청. 영혼석을 요구하는 요청은 다른 재료로 |
| `js/core/succession.js` | `next/js/town/succession.js` | 등불지기 잇기·결말. `heroDied` 사건에 연결 |

| `js/render/settle-view.js`, `furniture.js` | `next/js/render/diorama/` | |

- 흐름은 `설계_진행_레벨디자인.md`의 0장(빈 공터·불 붙이기)부터. 튜토리얼 던전(1장)은 06 이후에 넣어도 된다 — 이 단계에서는 0장 뒤 바로 1구역으로 가도 된다(보고에 적는다).
- 원정 중 정착지 시간: 층 하나 = 12시간(`설계_정착지_건설.md` §2). 귀환 때 "그동안" 요약(1단계 수준: 지은 것·온 방문자·사건).
- 등잔 이름·유품 주인 → "기억할 이름들" → 모닥불 밝기.

## 하지 말 것

- 영혼석 제단·영혼석 요청·영혼석 시작 특성(`설계_스토리_정착지.md`의 보류 항목).
- 정착지 2단계 이상(주민이 재료를 날라 짓기·식량 경제)은 **옛 코드에 없으면 새로 만들지 않는다.** 옮기기만.

## 확인 (`next/tests/town.test.mjs` + 스모크 추가)

1. 새 게임: 빈 공터 → 불 붙이기 → 빛 반경 6.
2. 방 프리셋을 놓으면 비용이 줄고, 닫힌 방이 인식된다.
3. 1구역 보스를 잡고 돌아오면 조각 넣기 → 밝기 상승 → 방문자 판정.
4. 등불지기 사망 → 주민이 있으면 자원자 창, 없으면 나쁜 결말.
5. 옛 `tests/settlement.mjs`·`tests/story.mjs`의 확인 항목을 새 시뮬레이션 API로 옮겨 모두 통과.
