# 04 · 화면 · 조작 · HUD

먼저 `00_먼저_읽기.md`를 읽는다. 01~03이 끝나 있어야 한다.

## 목표

폰으로 `next.html`을 열어 **혼자 1구역을 플레이할 수 있다.** 손을 대면 걷고, 떼면 멈추고, 멈춘 채 생각한다. 위협은 한눈에 읽힌다. 화면 스타일은 나중에 갈아 끼울 수 있다.

## 만들 것

### 렌더 어댑터 (`next/js/render/adapter.js`)
- 인터페이스(모든 스타일이 구현):
  - `mount(el)`, `unmount()`, `resize()`
  - `setMap(world)` — 층이 바뀔 때
  - `frame(world, alpha, dt)` — 매 프레임. 유닛·투사체·예고(`world.telegraphs`)·지형·빛을 **시뮬레이션 상태에서 읽어** 그린다(보간은 `alpha`)
  - `onEvents(events)` — 번쩍임·피해 숫자·휘두르기 궤적·폭발 같은 연출
  - `setFrozen(bool)` — 멈춤 표현(채도 빠짐)
  - `pick(screenX, screenY)` → 칸 좌표 또는 유닛 id
- **첫 구현: `diorama-adapter.js`** — 옛 `js/render/diorama.js`(DioramaKit)와 `dolls.js`·`hero-doll.js`·`entity-view.js`·`fx.js`를 `next/js/render/diorama/`로 옮겨 어댑터 뒤에 둔다. 칸 트윈 대신 매 프레임 위치를 따라간다.
- 참고: `style-lab.html`의 `js/style-lab/style-b.js`(로우폴리)·`style-c.js`(2D)는 같은 장면을 다른 스타일로 그린 예다. 스타일이 정해지면 그 어댑터를 새로 만든다. **이 단계에서는 만들지 않는다.** 다만 어댑터 인터페이스가 세 스타일 모두 담을 수 있는지 확인하고 보고한다.

### 입력 (`next/js/ui/`)
- 떠오르는 조이스틱(화면 아래 42%, 0.14초 누르면 생김) → `intent.move`. PC: WASD·방향키, Space = `hold`.
- 탭: 적 = `intent.target`, 바닥·물건·계단 = `intent.walkTo`. 길게 누르기(조이스틱 영역 밖) = 정보 카드.
- 옛 `js/ui/joystick.js`를 참고해 옮긴다.

### HUD (`설계_HUD.md` 그대로, 요약)
- 위: 미니맵, 구역-층·흐른 초(멈추면 "멈춤"), 타오르는 횃불 그림과 숫자, 보이는 적 수, 보스 체력바.
- 로그 3~4줄(누르면 전체).
- 아래: HP·보호막·상태 이상 한 줄, 소모품 빠른 슬롯 한 줄, 역할 스킬 줄(비어 있음·나중), 버튼(무기·쉬기·탐험·상태·가방), 상황 버튼(떠오름).
- 파티 줄과 파티 명령 줄 자리는 만들되 파티원이 없으면 숨긴다(06에서 채움).
- 가방 = 장비 창(서브탭: 장비·소모품). 옛 `js/ui/inventory.js`를 옮겨 새 시뮬레이션 API에 맞춘다.
- 위험 경고: 예고 범위 안에 서 있으면 화면 가장자리 붉은 맥동.
- 멈춤 표시: 채도 빠짐, 조이스틱이 빛남, "멈춤".

### 앱 (`next/js/app.js`, `next.html`)
- 제목 화면(새 게임·이어하기) → 던전(이 단계는 1구역부터 바로) → 죽거나 귀환하면 제목으로(정착지는 05).
- 루프: `requestAnimationFrame`마다 흐른 실제 시간만큼 `world.step()`(프레임당 최대 3틱), 렌더 어댑터 `frame`.

## 확인 (`next/tests/smoke.mjs`, playwright — `tests/*.mjs`의 실행 옵션을 따름)

1. `next.html`이 오류 없이 뜨고, 새 게임 → 1구역 1층.
2. 조이스틱을 누르면 시간이 흐르고(시계가 오름), 떼면 멈춘다(시계 고정, 채도 빠짐).
3. 적 탭 → 대상 표시, 바닥 탭 → 자동 걷기, 적이 보이면 멈춤.
4. 예고 원·띠·조준선과 적 힘 모으기가 차오르는 모양으로 보인다.
5. 장비 창에서 무기를 바꾸면 휘두르기 궤적이 바뀐다.
6. 390×844에서 버튼이 겹치지 않고, 스크린샷을 `test-results/next/`에 남긴다.
7. 옛 `index.html`과 옛 테스트는 그대로 통과한다(건드리지 않았다).
