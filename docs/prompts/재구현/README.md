# 재구현 프롬프트 세트

지금 게임의 전투 코어를 실시간·파티 전제로 새로 만들고, 좋은 부분은 옮겨 오는 작업을 단계별로 시키는 프롬프트다.

| 순서 | 파일 | 끝나면 |
| --- | --- | --- |
| 0 | `00_먼저_읽기.md` | (모든 단계가 함께 읽는 규칙·폴더·기준 수치) |
| 1 | `01_시뮬레이션_코어.md` | Node에서 도는 틱·유닛·충돌·길찾기·입력 의도 |
| 2 | `02_전투.md` | 자동 공격·힘 모으기·예고·상태 이상·원소, 전투 측정 |
| 3 | `03_던전과_아이템.md` | 1구역 5층 + 족장이 Node에서 끝까지 돈다 |
| 4 | `04_화면과_조작.md` | 폰으로 혼자 1구역을 플레이 |
| 5 | `05_정착지와_이야기.md` | 빈 공터 → 원정 → 귀환 → 잇기까지 한 판 |
| 6 | `06_파티.md` | 첫 동료(수호자·검사·궁수), 파티 AI·명령 |
| 7 | `07_교체.md` | 새 게임을 본편으로, 옛 코드 보관 |

## 주는 법

단계마다 이렇게 준다.

```
docs/prompts/재구현/00_먼저_읽기.md 와 docs/prompts/재구현/0N_….md 를 읽고 0N 단계를 수행해 주세요.
끝나면 00 §6 형식으로 보고해 주세요.
```

- 한 단계가 끝나고 확인 목록이 모두 통과한 뒤 다음 단계를 준다.
- 단계가 끝날 때마다 직접 해 보고(04부터는 폰으로), 느낀 점을 다음 단계 프롬프트 끝에 한두 줄 붙여 주면 된다.
- 그래픽 스타일이 정해지면(스타일 실험실), 04 뒤 아무 때나 "로우폴리/2D 어댑터 만들기"를 따로 준다.
