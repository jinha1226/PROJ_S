# 재구현 프롬프트

처음 1·2·3차 프롬프트처럼, 무엇을 느껴야 하는지와 요구 사항을 번호로 적은 프롬프트다. 한 차수씩 준다.

| 차수 | 파일 | 끝나면 |
| --- | --- | --- |
| 1차 | `1차_실시간_던전.txt` | next/ 에서 혼자 하는 실시간 던전 1구역(5층 + 족장)을 폰으로 플레이 |
| 2차 | `2차_정착지와_이야기.txt` | 빈 공터 → 원정 → 귀환 → 방문자 → 등불지기 잇기까지 한 판 |
| 3차 | `3차_첫_동료.txt` | 마을 사람과 둘이서 내려가기(역할·성향·명령) |
| 4차 | `4차_교체.txt` | 새 게임을 본편으로, 옛 게임 보관 |

- 파일 내용을 그대로 붙여 넣으면 된다.
- 한 차수가 끝나면 직접 해 보고, 느낀 점을 다음 차수 프롬프트 끝에 한두 줄 붙인다.
- 더 늘어나는 파티(셋·넷)와 5인 레이드는 3차를 해 본 뒤 같은 형식으로 쓴다.
- 그래픽 스타일이 정해지면(스타일 실험실) 아무 차수 뒤에 "스타일 바꾸기" 프롬프트를 따로 준다.
- `상세/` 는 구현 방법을 구체적으로 적어 둔 참고 자료다. 프롬프트는 이것을 따르라고 하지 않고, 막힐 때 보라고만 한다.
