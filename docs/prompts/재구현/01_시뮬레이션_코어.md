# 01 · 시뮬레이션 코어

먼저 `00_먼저_읽기.md`를 읽는다.

## 목표

브라우저 없이 Node에서 도는 **실시간 틱 시뮬레이션의 뼈대**. 유닛 여럿이 연속 좌표에서 움직이고, 시간은 흐를 때만 흐른다. 이 단계에는 전투 규칙이 없다(02). 화면도 없다(04).

## 만들 것

### `next/js/sim/world.js`
- `createWorld({ seed, map })` → `world`
  - `world.tick`(정수), `world.time`(초), `world.units`(배열), `world.events`(배열), `world.rng`(씨앗 고정 난수, 옛 `js/util/rng.js`의 mulberry32를 옮김)
  - `world.flowing`(불): 이번 틱에 시간이 흐르는가. 입력 층이 정한다.
  - `world.step()`: `flowing`일 때만 한 틱(1/20초) 진행. 순서: 입력 의도 적용 → 유닛별 행동(두뇌) → 이동·충돌 → 지속 효과 틱 → 사건 정리. `flowing`이 아니면 아무것도 바꾸지 않는다.
  - `world.run(ticks)`: 테스트용, `flowing`을 켜고 n틱.
  - `world.emit(type, data)`: `world.events.push({ t: world.time, type, ...data })`. 화면은 읽고 비운다(`world.drainEvents()`).
- 결정적: 같은 씨앗·같은 입력 순서면 같은 결과. `Math.random`·`Date` 금지.

### `Unit` (`next/js/sim/unit.js`)
- 공통 필드: `id`, `kind`, `team`(`party` | `foe` | `neutral`), `ctrl`(`player` | `ai`), `x`, `y`(칸 단위 실수), `r`(반지름), `speed`(칸/초), `face`(라디안), `hp`, `maxHp`, `alive`, `statuses`(맵), `cooldowns`(맵, 초), `role`(없어도 됨), `brain`(ai일 때 상태).
- `makeUnit(spec)`: 데이터 표(`next/js/data/…`)의 항목에서 만든다.
- 등불지기는 `ctrl: 'player'`, 파티원은 `ctrl: 'ai'`, `team: 'party'`. 적은 `ctrl: 'ai'`, `team: 'foe'`.

### `next/js/sim/space.js`
- 지도: `map.w`, `map.h`, `map.tile[i]`(벽·바닥·문·계단 등), `map.surf[i]`(물·풀·기름·얼음…). 지도 생성은 03에서 옮긴다. 이 단계에는 테스트용 손지도 생성 함수 `testMap(ascii)`만.
- 원 충돌: 벽·닫힌 문에 막힘(벽을 따라 미끄러짐), 유닛끼리 겹치지 않음. 옛 `js/core/space.js`의 `sweep`을 참고해 새로 쓴다.
- 발밑 칸 `cellOf(u)` = 반올림. 칸 기준 판정(바닥 효과·줍기·계단)은 발밑 칸을 쓴다.
- 길찾기 `path(world, from, to)`: 칸 격자 위 A*(8방향, 대각선은 모서리 끼임 금지) → 칸 중심 경유점 목록. 자동 걷기·AI 추적이 쓴다.
- 시야 `canSee(world, a, b, range)`: 칸 기준 레이캐스트(벽·닫힌 문이 막음).

### 입력 의도 (`next/js/sim/intent.js`)
- 등불지기 의도: `{ move: {x, y} | null, hold: bool, walkTo: {x, y} | null, target: unitId | null }`.
- `move`는 조이스틱 방향(길이 0~1). `hold`는 제자리에서 시간을 흘림(Space).
- `world.flowing = !!(move || hold || walkTo 진행 중 || 시전 중)`.
- `walkTo`는 길찾기 경로를 따라 걷고, **적이 새로 보이거나 맞으면 멈춘다.**

## 하지 말 것

- DOM·THREE·`window` 사용(시뮬레이션 폴더 전체).
- 턴·칸 단위 이동·연출 대기.
- 영혼석 필드.

## 확인 (`next/tests/sim-core.test.mjs`, `node --test next/tests`)

1. `flowing = false`면 `step()`을 100번 해도 모든 유닛 위치·`time`이 그대로다.
2. 조이스틱 오른쪽으로 1초(20틱) → 등불지기가 약 3.3칸 이동.
3. 벽으로 밀면 벽 앞에서 멈추고, 비스듬히 밀면 벽을 따라 미끄러진다.
4. 유닛 둘이 서로를 향해 걸어도 겹치지 않는다(중심 거리 ≥ r1 + r2 − 0.01).
5. 닫힌 문에 닿으면 열린다(사건 `door`).
6. `walkTo`가 벽을 돌아 목적지에 닿고, 도중에 적이 시야에 들어오면 멈춘다.
7. 같은 씨앗·같은 입력으로 두 번 돌리면 `world` 상태가 같다(JSON 비교).
8. Node에서 `import`만으로 돈다(브라우저 불필요).
