# 새로 시작 프롬프트

지금 코드와 상관없이 처음부터 새로 만든다는 전제로 쓴 프롬프트다. 처음의 1·2·3차 프롬프트와 같은 형식(느낌과 요구 사항을 번호로)이고, 그래픽은 처음처럼 "꿈꾸는 섬" 디오라마다.

| 차수 | 파일 | 끝나면 |
| --- | --- | --- |
| 1차 | `1차_실시간_던전.txt` | 슈퍼핫식 실시간 전투, 원소·지형·소모품·횃불, 다섯 층 + 첫 보스 |
| 2차 | `2차_장비와_성장.txt` | DCSS식 장비, 레벨, 장비 창과 인형 외형 |
| 3차 | `3차_정착지와_이야기.txt` | 마지막 불씨 이야기, 튜토리얼, 림월드식 정착지, 등불지기 잇기 |
| 4차 | `4차_파티.txt` | 한 명씩 늘어나는 파티, 역할·성향·명령 |
| 5차 | `5차_레이드.txt` | 다섯 명 보스 레이드, 이번 주의 레이드 |

- **`코드정리_가이드.md`를 모든 차수와 함께 준다.** 폴더 구조, 의존 방향, 슈퍼핫 시간 규칙, 규칙과 화면 분리, 테스트와 측정 기준이 들어 있다.
- 파일 내용을 그대로 붙여 넣는다. 한 차수가 끝나면 직접 해 보고, 느낀 점을 다음 차수 끝에 한두 줄 붙인다.
- 기존 코드를 살려 옮기는 방식은 `../재구현/`에 있다.
