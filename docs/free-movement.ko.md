# 자유이동 턴제 전환

2026-09-27 · 자유이동 실험 기록 (일반 원정 기본 모드에서 해제)

일반 원정은 기존 사각 격자 턴제로 복원했다. 이동·사거리·공격 판정은 기존 칸 단위 규칙을 사용한다. 가상 조이패드는 비활성화했으며, 타일 터치로 이동한다. 인접한 빈 칸을 누르면 한 칸 이동하고, 먼 발견 지점은 기존 목적지 이동을 사용한다. 적을 처음 발견하면 자동이동·자동탐험을 멈춘다. 하단 버튼은 **공격 / 대기 / 탐험 / 전술 / 가방**이며 탐험 중에는 탐험 버튼이 중지로 바뀐다. 최근 영혼석·VFX·웹 계산 최적화는 유지했다. 아래는 비교용으로 남긴 자유이동 실험의 규칙이다.

캐릭터의 실제 위치는 `world_pos: Vector2`다. 방향이나 정지 위치를 칸 중심에 맞추지 않는다. `pos: Vector2i`는 발밑 지형·아이템·계단·기존 월드 데이터의 조회용 캐시다. 기본 전투·자동 효과의 사거리와 충돌은 실제 위치를 사용한다. 기존 그리드 전투 시험과 시뮬레이션은 비교용으로 유지한다.

## 이동과 시간

- 화면의 빈 곳을 누르면 그 지점에 가상 조이패드가 생긴다. 끄는 방향으로 이동하고 손을 떼면 멈춘다. 실제 위치의 소수 좌표를 보존한다.
- 이동 한 번의 최대 거리는 1 지형 단위다. 대각선도 같은 거리 예산을 사용한다. 짧은 이동도 한 행동이다.
- 캐릭터 충돌 반경은 0.23이다. 이동 경로 전체에서 벽 모서리·임시 벽·다른 인물과의 충돌을 확인한다.
- 길찾기는 기존 바닥 연결 데이터를 탐색한 뒤 직선으로 이어지는 경로를 합친다. 탐색용 칸 중심에 캐릭터를 강제로 배치하지 않는다. 다른 인물은 원하는 진행 방향을 기준으로 우회한다.
- 이동·공격·대기는 기존 시간 스케줄러를 진행한다. 자동탐험이 멈춘 상태에서 입력 없이 기다리는 동안에는 월드 시간이 흐르지 않는다. 화면의 이동·상태 VFX만 계속 재생한다.
- 동료의 접근·추종·후퇴 후보도 자유 좌표를 사용한다. 성격·태세의 Utility 점수와 영혼석 예상 가치는 유지한다.

## 전투

- 근접 사거리 1은 중심 간 실제 거리 1이며 대각선 포함 여부는 원형 거리로 판정한다.
- 원거리 사거리와 영혼석 주변 효과도 실제 거리와 장애물 차단을 확인한다.
- 몬스터의 기본 이동·추적·순찰은 자유 좌표를 사용한다. 고유 기술의 예고된 지점과 범위 공격은 실제 위치의 원형 범위로 표시·판정한다. 바닥 지형을 바꾸는 효과와 보스의 지형 위험 지역은 지형 데이터를 유지한다.
- 한 번의 대기와 상태 하나로 발동하는 영혼석 규칙을 그대로 사용한다. 강제 대기는 의도적 대기 효과를 만들지 않는다.
- 동료 자리 교환은 실제 거리 1 이내에서 위치를 교환한다. 빈사 구조도 실제 거리를 확인한다.

## 화면과 조작

맵은 가로·세로 전체 뷰포트를 사용한다. 상단 HUD, 최근 로그, 초상화, 효과 아이콘, 하단 버튼은 맵 위에 배치한다. 탐험 때와 전투 때 화면을 별도로 잘라 사용하지 않는다.

하단 주 조작은 **공격 / 대기 / 후퇴**다. 공격은 가까운 적 또는 지정한 적에게 접근하거나 공격한다. 대기는 현재 위치에서 한 행동을 소비한다. 후퇴는 보이는 적과 거리를 늘리는 안전한 방향을 선택한다. 가방·전술은 상단에서 연다.

새 탐험은 입력을 기다린다. 이전 탐험의 이동 목적지·조이패드·이동 애니메이션도 초기화한다. 자동탐험은 메뉴의 탐험 재개·중지로 전환하며 적 발견·피해·팝업·터치에서 멈춘다. 수동 전투가 끝났다는 이유로 자동탐험을 켜지 않는다. 탐험 중 적을 처음 발견하면 자동탐험·목적지 이동·현재 조이패드를 멈춘다. 누른 채 드래그를 계속해도 재개되지 않고, 손을 떼고 새로 누르면 전투 중에도 이동할 수 있다. 공격·대기·후퇴는 즉시 사용할 수 있다. 바닥에서는 누른 위치를 중심으로 반경 46px의 조이패드가 나타난다. 중심 12px 안에서는 움직이지 않는다. 드래그 중 0.12초 간격으로 이동 행동을 입력한다. 프레임에서 남은 시간을 보존하며, 다음 이동은 화면에 보이는 현재 위치에서 이어진다. 애니메이션 완료 대기로 입력 사이에 공백을 넣지 않는다. 장시간 프레임 정지 뒤에도 한 프레임에 이동 턴은 하나만 입력한다. 손 떼기·터치 취소·창 포커스 상실·팝업에서 조작을 해제한다. 화면 터치 지점으로 걸어가는 방식은 사용하지 않는다. 적·인물·상자를 짧게 누르면 기존 상호작용을 한다. 멀리 있는 상자·버섯을 습득할 때는 가까이 이동한 뒤 상호작용한다. 화면 카메라와 각 인물의 그림은 실제 이동 전후 좌표 사이를 보간한다.

이동할 때는 캐릭터 몸체만 화면에서 2~3px 정도 오르내린다. 그림자·발밑 표시·카메라에는 발걸음의 상하 움직임을 적용하지 않는다. 작은 먼지는 실제 발밑 위치에 남았다가 0.24초 안에 사라진다. 물·용암·시야 밖에서는 먼지를 만들지 않고, 동시에 남는 먼지는 32개로 제한한다. 이 시각 효과의 갱신은 턴을 진행하지 않는다.

바닥 물약·두루마리는 인물의 실제 좌표에서 거리 1 이내에 들어오면 자동 습득한다. 습득에 별도 턴을 쓰지 않으며, 벽 너머의 아이템은 줍지 않는다. 상자·버섯 같은 지형 상호작용은 기존 방식으로 유지한다.

이동 중에는 맵 렌더러·HUD 노드를 유지하고 HP·상태·턴수·최근 로그·효과 준비 상태만 갱신한다. 다른 화면으로 전환하거나 파티·영혼석 구성이 바뀌면 화면을 다시 구성한다. 시야와 공격선은 실제 선분이 통과하는 칸만 조사해 장애물 판정을 유지하면서 반복 계산을 줄인다. 벽·바닥의 그리기 명령은 별도 레이어에 유지하고 프레임마다 카메라에 맞춰 위치만 옮긴다. 턴·카메라 칸·화면 크기·층이 바뀌면 해당 레이어를 다시 그린다. 동일 위치에서 시야를 여러 번 갱신할 때는 장애물 스냅샷이 같으면 광선 계산을 재사용한다. 벽 생성·붕괴·만료·기둥 여부·안개 반경 변화는 스냅샷에 반영하며, 발견·전투 전환·도감 처리는 매번 갱신한다. 환경 틱에서는 활성 지형과 최근 접근한 타일을 인덱스로 관리해 전체 맵 순회를 하지 않는다. 타일 수정은 기존 `session.tile()`을 통해 추적하며, 환경 처리 중 가스 폭발이 다른 타일을 활성화해도 원래의 행 순서를 유지한다. 경로 탐색의 타일 중심 간 연결은 모서리 통과 조건으로 검사하며, 실제 이동은 반지름을 포함한 정밀 충돌 판정을 유지한다. 경로를 직선으로 줄일 때는 가장 먼 통과 가능한 지점을 먼저 확인해 불필요한 구간 검사를 생략한다. 시야 밖의 몬스터·NPC·위험 지형도 기존 턴대로 갱신한다.

## 확인 범위

웹은 Godot 기본값인 HiDPI 렌더링을 사용한다. 브라우저 화면의 실제 픽셀 배율에 맞춰 캔버스를 그린다. 예를 들어 CSS 화면이 390×844이고 배율이 3이면 캔버스는 1170×2532다. 성능 조정을 위해 넣었던 `display/window/dpi/allow_hidpi.web=false`는 글자와 이미지가 저해상도 캔버스에서 확대되는 흐림을 유발해 제거했다. 렌더링 해상도를 낮추는 대신 이동 중 HUD·지형 그리기 유지와 시야·환경 계산 최적화를 사용한다.

격자 복원 시 Chromium 모바일 재현에서 390×844 및 430×932 화면 배치, 조이패드 이동 후 손 떼기로 입력이 해제되는지 확인했다. 런타임 오류는 없었다. 실제 아이폰의 프레임 속도를 측정한 결과는 아니다.

`tests/free_movement.gd`는 임의 방향과 소수 좌표 유지, 행동 거리·시간, 원형 근접 사거리, 벽·모서리·인물 충돌, 우회 경로, 동료 접근을 확인한다. `tests/attack_wait_ui.gd`는 실제 터치 조이패드의 이동·중립·손 떼기·추가 손가락·취소, 3개 버튼, 전체 화면 맵과 320×568 / 390×844 / 430×932 배치를 확인한다. 기존 그리드 입력·수동 주문 비교 검사는 명시적으로 그리드 모드에서 실행한다.

다음 실제 플레이에서는 좁은 통로의 추종, 사거리 1의 체감, 후퇴 방향, 자동탐험 속도를 중심으로 조정한다. 기존 칸 거리와 원형 거리가 달라졌으므로 수치를 그대로 옮긴 효과의 전투 밸런스는 재조정 대상이다.
