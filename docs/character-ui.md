# 캐릭터 카드 UI

`../playtest/party_encounter_sandbox.gd`의 상태 folio와 `mastery_panel.gd`의
2열 카드 구성을 현재 원정 데이터에 맞게 적용했다. 신체 실루엣과 숙련 문양은
기존 독립 드로잉 컴포넌트를 가져왔다. 원본 프로젝트 의존성은 없다.

- 상태: 체력·스트레스 게이지, 3열 능력치, 2열 전투 수치, 신체 실루엣과 부위 상태.
- 숙련: 경험치, 남은 포인트, 근접·원거리·마법·방어 2열 카드.
- 투자: 변화량 확인 후 확정. 안전 구역·생존 여부는 Session에서 재검증.
- 성격: 6개 성향 게이지. 기억: 기록별 카드.
- 이능: 장착 카드와 기존 사용 순서·공용 행동 조건을 유지.
- 가방은 독립 창을 유지한다. 현재 구현되지 않은 회피·막기·장비 수치는 추가하지 않는다.

`tests/character_ui.gd`에서 390×844, 430×844, 412×915 화면의
두 캐릭터·다섯 탭 크기와 동료 숙련 투자 확인 절차를 검증한다.
