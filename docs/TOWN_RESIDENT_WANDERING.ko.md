# 마을 주민 배회

## 범위

- 여관 앞 고정 좌표 대신 마을의 이동 가능한 칸에 분산 배치한다.
- NPC는 목적지를 골라 상하좌우 길찾기로 이동하고, 도착하면 잠시 쉰다.
- 건물과 나무를 통과하지 않고 다른 주민의 현재/이동 목적 칸을 예약 충돌 대상으로 취급한다.
- 주인공은 자동으로 돌아다니지 않는다. 작업자는 기존 작업/휴식 위치 표시를 유지한다.
- 화면에 보이는 이동 좌표를 클릭 판정에도 사용한다. 누르기/지도 드래그/핀치 중에는 배회를 멈춘다.
- 마을 장식 이동 갱신은 최대 약 10Hz이며, 보이지 않는 마을 화면과 건설 배치 중에는 멈춘다.

## 상태 경계

`town_resident_motion.gd`는 마을 UI 전용이다. 세계 위치, HP/MP, 원정 시간,
게임 RNG, 저장 명령 이력을 바꾸지 않는다. 동일 지도에서 데이터만 새로 받으면 이동 상태를 유지한다.
마을 화면을 새로 만들거나 지형/건물 배치가 바뀌면 분산 위치를 다시 잡는다.
NPC의 실제 직업/일정/상점 이용 가능 여부를 바꾸는 생활 AI는 이번 범위가 아니다.

## 검증

`town_resident_motion_acceptance.gd`: 16명 fixture에서 분산, 40초 이동,
통행 가능 칸/목적지 중복 금지, 입력 DTO 불변, 주인공 고정,
동일 관찰 갱신 시 위치 유지, 이동한 NPC의 실제 마우스 클릭, 누르는 동안 정지.

함께 수행한 `solo_start_acceptance.gd`는 기존 파티 저장 보존과 단독 원정 출발/재생을 검증한다.
별도 `town_life_acceptance.gd`는 기존 비-living 시나리오의 방문자 수/빈손 귀환 이후 경로에서
13개 실패를 보였다. 단독 시작 여부는 false였고 기존 자동 동료 2명 시작은 유지됐다.
이 오래된 테스트의 전체 실패 원인/기준 버전 비교는 이번 변경에서 완료하지 않았으며,
마을 전체 회귀가 모두 통과했다고 주장하지 않는다.
