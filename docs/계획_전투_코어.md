# 실시간 전투 코어 구현 계획

> **에이전트 작업자용:** superpowers:executing-plans로 과제 단위로 구현한다. 단계는 체크박스(`- [ ]`)로 추적한다.

**목표:** 적도 연속 좌표로 각자의 박자에 움직이고, 모든 공격이 힘 모으기·예고를 거쳐 들어오는 실시간 전투. 무기 12종 모양, 초 단위 상태이상.

**구조:** 세계 상태는 `G` 그대로. 새 규칙은 `js/sim/`(DOM·THREE 없음, Node 테스트). `core/clock.js`의 `step()`이 `sim/tick.js`를 부르고, 0.3초 옛 턴(`endTurn`)은 적을 움직이지 않는 **걸음 박자**(횃불·회복·쉬기)로만 남는다. 사건은 그 틱에 바로 화면으로 간다(`TL`·`Anim` 삭제).

**설계:** `docs/설계_전투_코어.md`

## 전역 제약

- `docs/코드정리_가이드.md`: `core/`·`sim/`은 `render/`·`ui/`·`town/`·`flow.js`를 import하지 않는다. 표·숫자는 `data/`. 파일 400줄 이하. 상태는 `G` 하나. 문구는 `docs/문구_가이드.md`(`jo()`, 시간은 "N초").
- 파일을 만들거나 옮기면 `npm run fix-imports`, 커밋 전 `npm run lint`. 내보내는 이름은 저장소 전체에서 겹치지 않게 한다(도구가 이름으로 파일을 찾는다).
- 브랜치 `feat/combat-core`, 작성자 `jinha1226 <jinha1226@gmail.com>`, 커밋 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. 모두 끝나면 main에 한 번에 올린다.
- 창을 띄우지 않는다: 확인은 Node 테스트와 헤드리스 Playwright만.
- 수치: 틱 0.05초, 프레임당 최대 3틱, 등불지기 4.0칸/초, 보통 적 3.3, 쥐 5.3, 거머리 1.65, 보스 2.5.

## 검토 초점

1. **멈춘 동안 힘 모으기·예고·투사체** — 손을 떼면 모두 그 자리에서 멈춘다(과제 3·4 테스트).
2. **적이 몰려 한 칸에 둘 이상 설 때** — 칸 규칙(원소·줍기)이 발밑 칸의 모두에게 적용된다(과제 5, `entsAt`).
3. **층 이동·정착지 복귀 때 남은 행동·예고·투사체** — 새 층에 남지 않는다(과제 2, `initClock`이 비운다).
4. **옛 코드가 칸만 옮길 때(밀치기·순간이동)** — 소수 위치가 따라간다(과제 2, `moveEnt`).
5. **기절·빙결 중 힘 모으던 행동** — 끊긴다(과제 3).
