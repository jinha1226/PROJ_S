# 이능 획득·결속·성장 개발서

- 작성일: 2026-09-10
- 상태: 문서 분리. 게임 구현 완료를 뜻하지 않는다.
- 범위: 캐릭터의 이능 장착·중복·제거 규칙. 아이템 작업과 독립적으로 구현한다.
- 연계: [아이템 개발서](ITEM_REWARD_PROGRESSION_DEVELOPMENT_PLAN.ko.md)는 이능 획득물 생성·보관까지만 담당한다.

## 1. 이능의 단일 효과·레벨 한도·결속

### 1.1 합의와 제안 구분

- **확정:** 동일 이능은 중복 효과/중복 성장 없음. 소비 횟수에 따른 효과 누적 금지.
- **확정:** 캐릭터 레벨 하나당 이능 한 칸을 열고 최대 6칸으로 제한한다. 장착 한도는 `min(L, 6)`이며 1레벨 1칸, 2레벨 2칸, 6레벨 이후 6칸이다.
- 기존 6칸 UI를 유지하고 아직 열리지 않은 칸에는 해금 레벨을 표시한다. 레벨업은 빈 한도만 늘리며 이능을 자동 획득·장착시키지 않는다.
- **사용자 제안:** 제거를 어렵게 해 무분별한 흡수를 방지한다. 결속·제거의 상세 정책은 아래를 따른다.

### 1.2 권장 흐름

`이능 획득물 줍기·보관 → 효과와 비용 확인 → 빈 한도에 흡수/결속 확정 → 해당 캐릭터에 지속 적용 → 마을에서 제한적 제거`

- 줍기는 안전한 수집이며 흡수와 다르다. 장착 한도를 차지하는 확정 동작에만 경고를 둔다.
- 무제한으로 먹어 두고 언제든 무료로 갈아끼울 수 있으면 제거 제약의 의미가 사라진다. 권장안은 흡수=결속 슬롯 점유이며, 단순 효과 비활성화로 슬롯이 비지 않는다.
- 동일 이능 재흡수는 실행 전에 차단하고 보상을 소비하지 않는다. 같은 능력의 별칭 ID도 canonical 능력 ID로 묶는다.
- 액티브와 패시브는 동일 결속 한도를 사용한다. 결속 가능 수가 늘어났다고 모든 액티브가 자동으로 버튼에 노출되는 것은 아니다. 사용 가능한 액티브 수/UI 정책과 분리한다.
- 제거는 마을의 특정 서비스 + 희귀 비용으로 제한하는 방안을 권장한다. 단순 반복 클릭·저층 골드만으로 사실상 무료 교체가 되지 않게 한다.
- 제거한 이능 소멸/재아이템화/회수 여부와 비용은 **미정**이다. 확인 없이 영구 삭제하지 않는다. 초반 오선택 복구를 위해 최초 1회 저비용 교정은 검토 후보지만 아직 합의한 기능이 아니다.
- 제한 정보, 현재/최대 결속 수, 중복 여부, 제거 조건을 흡수 전에 보여준다. 알 수 없는 효과를 영구 결속하도록 강요하지 않는다.
- 레벨 하락·구버전 저장의 초과 장착은 이능 삭제로 해결하지 않는다. 보존 후 신규 흡수 제한/명시적 재배치 등 정책을 결정한다.

개발 전 추가 결정할 핵심은 **흡수=결속 여부, 제거 후 회수 여부**다. 전체 상한은 6칸으로 확정됐으며 재확인하지 않는다. 남은 결정 전에도 레벨별 한도·중복 차단·효과 미리보기·보상 보관·깊이별 소재 구현은 진행 가능하다.

## 2. 통합과 검증

- 아이템 사용에서 흡수 요청을 받는 경계를 제공하되 이능 슬롯 계산은 이능 시스템 하나에서 수행한다.
- 획득물 소비와 결속은 한 거래로 처리한다. 거절 시 획득물이 소모되지 않는다.
- 레벨 1/2/5/6/7에서 한도 1/2/5/6/6을 확인한다. 액티브·패시브 합산이며 액티브 버튼 수와 별개다.
- 중복 ID/별칭/재흡수/저장 재생으로 효과가 누적되지 않는다.
- 초과 장착 구버전 데이터와 레벨 하락에서 기존 능력을 무단 삭제하지 않는다.
- 흡수=결속 여부, 제거 비용·회수 여부는 미정이다. 구현 전 해당 정책만 확인한다.
- 코드·결과·검증 자료를 커밋해 반환하고 별도 요청 없이 푸시하지 않는다.
