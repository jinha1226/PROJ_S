# 장비 추가안: 데드셀식 무기 색 (DCSS식 위에 얹기)

상태: ⬜ 적용 예정 — 지금 장비 규칙(`설계_아이템_장비.md`, DCSS식, 388182ad) **위에 더하는** 변경이다. DCSS식을 되돌리지 않는다.

작성일: 2026-09-29 · 대상: `js/` 모듈 · 공통 공식은 `밸런스_기준.md`

## 0. 플레이어가 느껴야 할 것

- 무기는 **종류가 아니라 색으로** 고른다. 내 영혼석 색에 맞는 무기면 장검이든 창이든 갈아끼운다.
- 무기마다 **모양과 치명 조건**이 분명해서, 무기를 바꾸면 싸우는 방식이 바뀐다.
- 원거리와 근접, 양손과 한손+방패/오브를 **두 세트**로 들고 상황에 따라 바꾼다.
- 강화 두루마리를 지금 무기에 부을지, 더 깊은 곳의 좋은 무기를 기다릴지 고민한다.

## 1. 원칙

1. **DCSS식 장비 규칙은 그대로 둔다.** 강화 +N과 두루마리, 무기 브랜드·방어구 에고, 반지·목걸이, 랜다트, 유품(픽다트), 미확인과 확인, 드롭 표, 대장장이 강화·학자 확인, 저항 7단계.
2. **무기 색은 영혼석과만 맞물린다.** 장비는 색 수치를 만들지 않는다. 무기 피해가 같은 색 영혼석 개수에 비례한다.
3. **무기 하나 = 모양 한 줄 + 치명 조건 한 줄.**
4. 장비 < 영혼석.

## 2. 무엇이 바뀌나

| 항목 | 지금 (DCSS식) | 바뀐 뒤 |
| --- | --- | --- |
| 무기 종류 | 6종(장검·손도끼·철퇴·전투 망치·단검·창) | **12종**: 색 3 × 베기·타격·찌르기·원거리 (§3) |
| 무기 색 | 없음 | 종류마다 고정 색. 같은 색 영혼석 1개당 피해 +15% (§3.4) |
| 무기 모양·치명 | 창 2칸, 단검 급소 +10% 정도 | 무기마다 모양 + 치명 조건(×2) (§3.2) |
| 원거리 | 없음 | 부메랑·석궁·투석구 (§3.3) |
| 무기 교체 | 가방의 마지막 무기와 교체, 전투 중 한 턴 | **무기 세트 두 벌**(주손 + 보조손), 공격 길게 누르기로 **턴 없이** 교체 (§4) |
| 방패 칸 | 따로 한 칸 | 없어지고 각 세트의 **보조손**으로 (한손 무기일 때만) |
| 오브 | 없음 | 보조손 아이템 3종 (§4) |
| 품질 | 없음 | 구역마다 한 단계, 기본 피해·방어 보정 (§5) |
| 브랜드 | 형태 제한 브랜드(피·파쇄·꿰뚫기) | 그대로. 12종 무기에 형태대로 붙는다. 원거리 무기에도 붙는다 |
| 강화 상한 | 무기 +6 | 그대로 |
| 유품 | 8개 | 그대로. `피의 송곳니`의 기본템만 단검 → **쌍단검** |

- 칸: 무기 세트 A(주손·보조손), 무기 세트 B(주손·보조손), 머리, 몸통, 망토, 장갑, 신발, 목걸이, 반지 2.
- 쓰지 않는 세트의 무기·보조손(방패 막기, 오브, 브랜드·에고)은 적용되지 않는다. 방어구·장신구는 늘 적용.

## 3. 무기 (12종)

### 3.1 색과 손

| 색 | 베기 | 타격 | 찌르기 | 원거리 |
| --- | --- | --- | --- | --- |
| **빨강** (몰아치기) | 손도끼 (한손) | 쇠사슬 도리깨 (한손) | 쌍단검 (양손) | 부메랑 (한손, 베기) |
| **보라** (기다렸다 한 방) | 대검 (양손) | 전투 망치 (양손) | 창 (한손) | 석궁 (양손, 찌르기) |
| **초록** (버티고 되갚기) | 장검 (한손) | 철퇴 (한손) | 레이피어 (한손) | 투석구 (한손, 타격) |

- 무기의 색은 종류로 정해진다. 공격 형태(베기·타격·찌르기)는 적 약점과 부상(출혈·골절·급소 표식)에 쓰인다.
- 빨강은 한손 위주(오브와 잘 맞음), 보라는 양손 위주(창만 한손 → 창 + 방패 가능), 초록은 모두 한손(방패와 잘 맞음).

### 3.2 모양과 치명 조건

치명: 피해 ×2 (약점 형태면 급소와 같은 ×2.5 규칙은 `밸런스_기준.md` §2).

| 무기 | 피해(품질 1) | 모양 | 치명 조건 |
| --- | --- | --- | --- |
| 손도끼 | 3~5 | 앞 1칸 | 출혈 중인 적 |
| 쇠사슬 도리깨 | 2~4 | 앞 3칸 부채꼴(모두 맞음) | 한 번에 3명 이상 맞히면 전부 |
| 쌍단검 | 2~3 ×2 | 같은 적을 두 번 찌름 | 같은 적을 연속 턴에 공격하면 |
| 부메랑 | 2~4 | 사거리 4 직선, 갈 때 한 번·올 때 한 번(경로의 적 모두) | 같은 적을 두 번 맞히면 두 번째 |
| 대검 | 4~6 | 주변 8칸 휩쓸기 | 직전 턴에 대기했으면 |
| 전투 망치 | 5~7 | 앞 1칸 + 1칸 밀침 | 밀쳐서 벽·다른 적에 부딪히면 |
| 창 | 3~5 | 일직선 2칸(둘 다 맞음) | 이번 적 턴에 나에게 다가온 적 |
| 석궁 | 5~8 | 사거리 7 일직선 관통. 쏜 뒤 장전 1턴 | 장전을 대기로 했으면 다음 첫 발 |
| 장검 | 3~5 | 앞 1칸 | 방금 막거나 피한 뒤 첫 공격 |
| 철퇴 | 3~5 | 앞 1칸, 기절 25% | 나를 방금 때린 적 |
| 레이피어 | 2~4 | 앞 1칸. 공격 후 1칸 물러날 수 있음 | 내 HP가 절반 이하일 때 |
| 투석구 | 2~4 | 사거리 4, 맞으면 1칸 밀침 | 나를 방금 때린 적 |

- 적을 탭했을 때 치명 조건이 충족돼 있으면 적 위에 **"×2"** 표시.
- 양손 무기는 한손보다 기본 피해가 대략 +50% 크거나 모양이 넓다.
- 넓은 모양(도리깨·대검)에 원소 옵션이 붙으면 피해 보정으로 맞춘다.

### 3.3 원거리 규칙

- 사거리 안의, 시야가 트인 적을 탭하면 쏜다. 조준 미리보기는 영혼석 스킬과 같은 방식.
- **붙어 있는 적에게 쏘면 피해 절반.** 근접 세트를 함께 들 이유.
- 탄약은 없다(부족한 자원은 횃불이 맡는다).
- 원거리 적중도 적중이다: 빨강 쿨타임 감소, 브랜드·옵션 적용.

### 3.4 색과 영혼석

- 무기 피해 = (기본 피해 + 품질 + 강화 + 옵션) × **(1 + 0.15 × 같은 색 영혼석 개수)**. 영혼석 6개면 ×1.9.
- 장비는 색 수치를 만들지 않는다. 오브도 색 수치가 아니라 자기 색 스킬에 직접 효과를 준다(§4).
- 무기 비교 창에 "빨강 영혼석 4개 → 피해 ×1.6"처럼 지금 배율을 보여준다.

- 무기 피해 식: (기본 피해 + 품질 + 강화 +N + 반지 힘 등) × (1 + 0.15 × 같은 색 영혼석 개수) → 이후 치명·약점 곱하기 (`밸런스_기준.md` §2).

## 4. 무기 세트와 보조손

- 세트 두 벌을 들고 다닌다. **공격 버튼 길게 누르기 = 세트 A ↔ B, 턴 소모 없음.** 가방에서 꺼내 끼우는 것은 지금처럼 전투 중 한 턴.
- 양손 무기를 끼면 그 세트의 보조손은 비워진다(가방으로, 미리 알림).
- 보조손에 무기는 들 수 없다(쌍단검은 한 아이템).

### 4.1 보조손 아이템 (한손 무기일 때만)

| 종류 | 효과 | 어울리는 빌드 |
| --- | --- | --- |
| 버클러 | 방어 +1, 막기 10% | 무엇이든 |
| 방패 | 방어 +2, 막기 20%, 회피 −2% | 초록 |
| 붉은 오브 | 빨강 영혼석 스킬 피해 +1 | 빨강 |
| 보랏빛 오브 | 보라 영혼석 스킬 범위 +1칸 또는 지속 +1턴(스킬마다 정해짐) | 보라 |
| 초록 오브 | 초록 영혼석 스킬을 쓸 때 보호막 +2 | 초록 |

- 막으면 피해 0, 초록 쿨타임 감소는 일어난다.
- 방패는 에고·강화, 오브는 강화·원소 저항이 붙는다(아래).

- 버클러·방패는 지금의 방패 기본템을 그대로 쓴다(에고·강화 그대로).
- 오브는 새 기본템. 강화 +N은 효과 한 단계(피해 +1 / 범위·지속 +1 / 보호막 +1), 최대 +2. 에고 대신 **원소 저항 +1** 하나가 붙을 수 있다. 랜다트 기본템으로도 나온다.

## 5. 품질 (깊이)

| 품질 | 나오는 곳 | 무기 피해 | 방어구 방어 | 이름 앞말 |
| --- | --- | ---: | ---: | --- |
| 1 | 1구역 | +0 | +0 | 낡은 |
| 2 | 2구역 | +1 | +0 | 평범한 |
| 3 | 3구역 | +2 | +1 | 좋은 |
| 4 | 4구역 | +3 | +1 | 명장의 |

- 깊은 구역의 일반 무기가 얕은 구역의 레어보다 나을 수 있다. 자연스럽게 갈아끼운다.
- 품질은 무기·방어구·보조손에만. 장신구는 없다. 강화 +N과 따로 더해진다.
- 대장장이의 강화(+1)는 그대로이고, **창고 장비의 품질을 한 단계 올리는 것**(마석 1 + 광석 2)이 대장장이 선택지에 추가된다.

## 6. 드롭

- 드롭 확률·종류 비율(평범/강화치/속성/랜다트/픽다트)은 지금 표 그대로.
- 무기가 나올 때 12종 균등. 1구역에서는 원거리와 양손을 조금 덜(각 절반 가중치).
- 보조손 비율: 지금 방패 몫을 버클러·방패·오브가 나눈다(오브 40%).

## 7. 아이템 창 (지금 창에 더하기)

### 7.1 화면 (모바일 세로)

```text
┌──────────────────────────────┐
│  세트 A ▶ [창 🟣]  [방패]      │  ← 쓰는 세트가 밝게
│  세트 B   [석궁 🟣 (양손)  ]   │
│   [머리]  (인형 회전)  [목걸이] │
│ [장갑]    [몸통]    [신발]    │
│         [반지]  [반지]        │
├──────────────────────────────┤
│ HP 38 방어 3 회피 14% 피해 4~6 ×1.45 │ ← 누르면 정보 창
├──────────────────────────────┤
│ 가방 12/20                   │
│ ▢▢▢▢▢  (속성 색 테두리,        │
│ ▢▢▢▢▢   무기는 색 점)          │
│ ▢▢▢▢▢                        │
│ ▢▢▢▢▢                        │
└──────────────────────────────┘
```

- 인형은 3D, 드래그로 돌려본다. 세트 줄을 누르면 그 세트로 바뀐다(전투 중에도 턴 소모 없음).
- 가방 칸은 지금처럼 속성 색 테두리. 무기에는 색 점(빨강·보라·초록). 지금 쓰는 것보다 나은 장비에는 작은 초록 화살표.

### 7.2 비교

- 같은 칸(무기는 같은 손)에 입은 것이 있으면 두 창을 위아래로 나란히. 차이값 초록·빨강, 새 옵션은 초록 "새 옵션", 사라지는 옵션은 빨강 줄 긋기.
- 무기는 **색 배율**("빨강 영혼석 4개 → ×1.6"), **모양**, **치명 조건**을 함께 보여준다. 색이 다르면 "색: 보라 → 빨강"을 눈에 띄게.
- 양손 무기로 바꾸면 보조손 장비가 가방으로 간다고 미리 알려준다.
- 반지는 두 칸과 각각 비교하는 탭 두 개.
- 버튼: [장착 → 세트 A / 세트 B] [버리기], 두루마리를 들고 있으면 [확인] [강화].

### 7.3 규칙

- 안전할 때 장착·해제 자유. 전투 중에는 한 번에 한 턴. **세트 교체만 턴을 쓰지 않는다.**
- 버리기는 발밑에 떨어뜨린다.
- 정착지에서는 창고 칸이 함께 보여서 가방과 창고 사이로 옮길 수 있다.

### 7.4 캐릭터 정보 창

- 최종 수치(HP, 방어, 회피, 막기, 피해와 색 배율, 원소 저항 단계, 급소).
- 수치를 누르면 출처가 펼쳐진다: "피해 5 ×1.45 = 창 3~5 + 품질 1 + 강화 1 … × (1 + 0.15 × 보라 3)".

- 지금 창의 서브탭(장비·소모품·영혼석), 이름 표기(+2 화염 장검 / 장검 ?), 모르는 값 "?", [확인]·[강화] 버튼은 그대로.

## 8. 외형 (더하기)

| 칸 | 바뀌는 것 |
| --- | --- |
| 무기 | 종류마다 모양(도끼날, 도리깨 사슬, 쌍단검 두 자루, 부메랑, 대검, 망치 머리, 창 자루, 석궁, 장검, 철퇴, 레이피어, 투석구). 손잡이에 색 리본(빨강·보라·초록) |
| 양손 무기 | 두 손으로 쥐는 자세 |
| 보조손 | 방패(원형, 에고가 있으면 그 색 테두리) / 오브(손 옆에 떠서 천천히 도는 빛나는 구슬, 그 색) |
| 쓰지 않는 세트 | 등에 멘다(양손 무기는 등에 비스듬히) |
| 몸통 | 재질색(천 베이지, 가죽 갈색, 사슬 회색, 판금 은색) + 몸 두께 |
| 장갑·신발 | 손발 구의 크기·색 |
| 목걸이 | 가슴 앞 작은 보석 |

- 강화 +2 이상: 무기 날에 은은한 광택.
- 장착·세트 교체 순간: 인형이 한 번 탄성 있게 튀며 해당 부위에서 반짝이. 세트 교체는 등에서 꺼내 드는 짧은 동작.

- 방어구·장신구 외형과 속성 빛·랜다트 테두리광·유품 금빛은 지금 그대로.

## 9. 코드 연결

- `data/weapons.js`: 12종으로. 각 무기에 `color`, `hands`, `form`, `dmg`, `shape`, `crit`(조건 id), 원거리는 `range`·`reload`.
- `data/gear.js`: `SLOTS`의 `weapon`·`shield` → `setA`, `offA`, `setB`, `offB`(또는 `sets[2]`). 오브 기본템 3종 추가. 품질 필드 `q`(1~4)와 이름 앞말. `UNRANDS.bloodFang.base` → 쌍단검.
- `core/gear.js`: `calcStats`가 **쓰는 세트만** 계산. `swapWeapon` → 세트 교체(턴 없음). 드롭에서 품질 = 구역, 12종 균등.
- `core/combat.js`: 무기 공격을 모양대로(부채꼴·주변 8칸·일직선 관통·되돌아오는 부메랑·밀치기), 치명 조건 판정, 색 배율. 원거리: 붙은 적 피해 절반, 석궁 장전.
- `ui/inventory.js`: 세트 두 줄, 색 점, 비교 창에 색 배율·모양·치명 조건. HUD: 적 위 "×2" 표시.
- 저장: 버전 +1. 옛 무기 → 같은 이름의 새 무기(단검 → 쌍단검), `shield` 칸 → 세트 A 보조손, 가방의 마지막 무기 → 세트 B.

## 10. 확인 목록

1. 무기 12종이 색·손·모양·치명 조건대로 동작한다.
2. 같은 색 영혼석이 늘면 그 색 무기 피해 배율이 오르고, 비교 창에 배율이 보인다.
3. 세트 A ↔ B 교체가 턴을 쓰지 않고, 쓰지 않는 세트의 방패·오브·브랜드는 적용되지 않는다.
4. 양손 무기를 끼면 보조손 장비가 가방으로 간다(미리 알림).
5. 원거리: 붙은 적에게 쏘면 피해 절반, 석궁은 장전 1턴, 원거리 적중도 빨강 쿨타임을 줄인다.
6. 치명 조건이 충족된 적 위에 "×2"가 뜬다.
7. 품질은 구역마다 오르고, 강화 +N과 따로 더해진다. 대장장이가 품질을 올린다.
8. DCSS식 규칙(강화·브랜드·에고·장신구·랜다트·유품·미확인)이 그대로 동작한다 — `node tests/items.mjs` 통과.
9. 옛 저장이 새 칸 구조로 옮겨진다.
