# 장비 제안: 데드셀식 무기 색 (디아블로식 등급 기준으로 작성)

상태: ⬜ 제안 — 방향 결정 필요. 지금 코드는 DCSS식(`설계_아이템_장비.md`, 388182ad)이고, 이 문서는 디아블로식 등급 위에 무기 색을 얹는 안으로 쓰였다

작성일: 2026-09-29 · 대상: `js/` 모듈 · 현재 장비 규칙: `설계_아이템_장비.md`
공통 공식(피해 순서, 저항 단계, 기본 스탯)은 `밸런스_기준.md`를 따른다.

## 0. 플레이어가 느껴야 할 것

- 장비가 떨어지면 등급 빛만 보고도 설렌다.
- 무기는 **종류가 아니라 색으로** 고른다. 내 영혼석 색에 맞는 무기면 장검이든 창이든 바로 갈아끼운다.
- 무기마다 **모양과 치명 조건**이 분명해서, 무기를 바꾸면 싸우는 방식이 바뀐다.
- 원거리와 근접, 양손과 한손+방패/오브를 **두 세트**로 들고 상황에 따라 바꾼다.
- 중간중간 강화로 지금 무기를 키울지, 더 좋은 걸 기다릴지 고민한다.
- 그래도 빌드의 중심은 영혼석이다.

## 1. 원칙

1. **무기 색은 영혼석과만 맞물린다.** 장비는 색 수치를 만들지 않는다. 무기 피해가 같은 색 영혼석 개수에 비례한다.
2. **무기 하나 = 모양 한 줄 + 치명 조건 한 줄.** 특성 설명은 두 줄을 넘기지 않는다.
3. **옵션은 이 게임의 규칙에 걸린다.** 숫자만 올리는 옵션은 절반 이하.
4. **장비 < 영혼석.** 전설 하나의 영향이 영혼석 두 개를 넘지 않는다. 수치에는 상한이 있다(§8).
5. **비교가 쉬워야 한다.** 옵션은 한 줄, 바뀌는 값은 초록(오름)·빨강(내림).

## 2. 장비 칸

| 칸 | 개수 | 들어가는 것 |
| --- | ---: | --- |
| 무기 세트 A | 주손 + 보조손 | 양손 무기 하나, 또는 한손 무기 + 방패·오브(보조손은 비워도 됨) |
| 무기 세트 B | 주손 + 보조손 | 위와 같음 |
| 머리 | 1 | 두건·가죽 모자·투구·뿔 투구·왕관(전설 전용) |
| 몸통 | 1 | 천옷·가죽·사슬·판금 |
| 장갑 | 1 | 천·가죽·판금 장갑 |
| 신발 | 1 | 천·가죽·판금 신발 |
| 목걸이 | 1 | 목걸이 |
| 반지 | 2 | 반지 |

- **세트 교체:** 공격 버튼 길게 누르기로 세트 A ↔ B. **턴을 쓰지 않는다.** 원거리로 쏘다가 붙으면 근접 세트로 바꾸는 흐름이 핵심.
- 쓰지 않는 세트의 효과(방패 막기, 오브 효과, 옵션)는 적용되지 않는다. 방어구·장신구 옵션은 늘 적용.
- 횃불은 칸을 차지하지 않는다(`설계_HUD.md` §7). 이전의 "보조 칸 횃불"은 없앤다.

## 3. 무기 (12종)

### 3.1 색과 손

| 색 | 베기 | 타격 | 찌르기 | 원거리 |
| --- | --- | --- | --- | --- |
| **빨강** (몰아치기) | 손도끼 (한손) | 쇠사슬 도리깨 (한손) | 쌍단검 (양손) | 부메랑 (한손, 베기) |
| **보라** (기다렸다 한 방) | 대검 (양손) | 전투 망치 (양손) | 창 (한손) | 석궁 (양손, 찌르기) |
| **초록** (버티고 되갚기) | 장검 (한손) | 철퇴 (한손) | 레이피어 (한손) | 투석구 (한손, 타격) |

- 무기의 색은 종류로 정해진다. 공격 형태(베기·타격·찌르기)는 적 약점과 부상(출혈·골절·급소 표식)에 쓰인다.
- 빨강은 한손 위주(오브와 잘 맞음), 보라는 양손 위주(창만 한손 → 창 + 방패 가능), 초록은 모두 한손(방패와 잘 맞음).

### 3.2 모양과 치명 조건

치명: 피해 ×2 (약점 형태면 급소와 같은 ×2.5 규칙은 `밸런스_기준.md` §2).

| 무기 | 피해(품질 1) | 모양 | 치명 조건 |
| --- | --- | --- | --- |
| 손도끼 | 3~5 | 앞 1칸 | 출혈 중인 적 |
| 쇠사슬 도리깨 | 2~4 | 앞 3칸 부채꼴(모두 맞음) | 한 번에 3명 이상 맞히면 전부 |
| 쌍단검 | 2~3 ×2 | 같은 적을 두 번 찌름 | 같은 적을 연속 턴에 공격하면 |
| 부메랑 | 2~4 | 사거리 4 직선, 갈 때 한 번·올 때 한 번(경로의 적 모두) | 같은 적을 두 번 맞히면 두 번째 |
| 대검 | 4~6 | 주변 8칸 휩쓸기 | 직전 턴에 대기했으면 |
| 전투 망치 | 5~7 | 앞 1칸 + 1칸 밀침 | 밀쳐서 벽·다른 적에 부딪히면 |
| 창 | 3~5 | 일직선 2칸(둘 다 맞음) | 이번 적 턴에 나에게 다가온 적 |
| 석궁 | 5~8 | 사거리 7 일직선 관통. 쏜 뒤 장전 1턴 | 장전을 대기로 했으면 다음 첫 발 |
| 장검 | 3~5 | 앞 1칸 | 방금 막거나 피한 뒤 첫 공격 |
| 철퇴 | 3~5 | 앞 1칸, 기절 25% | 나를 방금 때린 적 |
| 레이피어 | 2~4 | 앞 1칸. 공격 후 1칸 물러날 수 있음 | 내 HP가 절반 이하일 때 |
| 투석구 | 2~4 | 사거리 4, 맞으면 1칸 밀침 | 나를 방금 때린 적 |

- 적을 탭했을 때 치명 조건이 충족돼 있으면 적 위에 **"×2"** 표시.
- 양손 무기는 한손보다 기본 피해가 대략 +50% 크거나 모양이 넓다.
- 넓은 모양(도리깨·대검)에 원소 옵션이 붙으면 피해 보정으로 맞춘다.

### 3.3 원거리 규칙

- 사거리 안의, 시야가 트인 적을 탭하면 쏜다. 조준 미리보기는 영혼석 스킬과 같은 방식.
- **붙어 있는 적에게 쏘면 피해 절반.** 근접 세트를 함께 들 이유.
- 탄약은 없다(부족한 자원은 횃불이 맡는다).
- 원거리 적중도 적중이다: 빨강 쿨타임 감소, 브랜드·옵션 적용.

### 3.4 색과 영혼석

- 무기 피해 = (기본 피해 + 품질 + 강화 + 옵션) × **(1 + 0.15 × 같은 색 영혼석 개수)**. 영혼석 6개면 ×1.9.
- 장비는 색 수치를 만들지 않는다. 오브도 색 수치가 아니라 자기 색 스킬에 직접 효과를 준다(§4).
- 무기 비교 창에 "빨강 영혼석 4개 → 피해 ×1.6"처럼 지금 배율을 보여준다.

## 4. 보조손 (한손 무기일 때만)

| 종류 | 효과 | 어울리는 빌드 |
| --- | --- | --- |
| 버클러 | 방어 +1, 막기 10% | 무엇이든 |
| 방패 | 방어 +2, 막기 20%, 회피 −2% | 초록 |
| 붉은 오브 | 빨강 영혼석 스킬 피해 +1 | 빨강 |
| 보랏빛 오브 | 보라 영혼석 스킬 범위 +1칸 또는 지속 +1턴(스킬마다 정해짐) | 보라 |
| 초록 오브 | 초록 영혼석 스킬을 쓸 때 보호막 +2 | 초록 |

- 막으면 피해 0, 초록 쿨타임 감소는 일어난다.
- 방패와 오브도 등급과 옵션이 붙는다.

## 5. 방어구

재질이 무거울수록 방어는 오르고 회피는 내려간다.

| 재질 | 몸통 | 머리·장갑·신발 | 외형 |
| --- | --- | --- | --- |
| 천 | 방어 0, 회피 +5% | 회피 +2% | 밝은 천색, 얇음 |
| 가죽 | 방어 1 | 방어 0, 회피 +1% | 갈색 |
| 사슬 | 방어 2, 회피 −3% | 방어 1, 회피 −1% | 회색 격자 무늬 |
| 판금 | 방어 3, 회피 −6% | 방어 1, 회피 −2% | 은색, 두꺼움 |

## 6. 품질과 강화 (중간 업그레이드)

### 6.1 품질 (깊이)

| 품질 | 나오는 곳 | 무기 피해 | 방어구 방어 | 이름 앞말 |
| --- | --- | ---: | ---: | --- |
| 1 | 1구역 | +0 | +0 | 낡은 |
| 2 | 2구역 | +1 | +0 | 평범한 |
| 3 | 3구역 | +2 | +1 | 좋은 |
| 4 | 4구역 | +3 | +1 | 명장의 |

- 깊은 구역의 일반 무기가 얕은 구역의 레어보다 나을 수 있다. 자연스럽게 갈아끼운다.

### 6.2 강화

- **강화 두루마리:** 장비 하나 +1(무기 피해 +1, 방어구 방어 +1, 방패 막기 +3%, 오브 효과 +1단계). 최대 +3. 층마다 평균 0.5장.
- 새 무기로 갈아끼우면 강화는 사라진다 → "지금 무기에 부을까, 더 좋은 걸 기다릴까".
- **정착지 대장장이:** 창고의 장비 하나를 품질 한 단계 올림(마석 1 + 광석 2). 성실한 대장장이는 가끔 재료를 덜 쓴다.

## 10. 전설 = 옛 등불지기의 유품

모두 **돌아오지 못한 옛 등불지기의 유품**이다. 줍는 순간 주인의 이름이 "기억할 이름들"에 오르고 모닥불 밝기 +1(`설계_스토리_정착지.md`).

| 이름 | 칸 | 고유 효과 | 기울이는 빌드 | 이야기 한 줄 |
| --- | --- | --- | --- | --- |
| 물안개 로브 | 몸통(천) | 대기할 때마다 내 주변 1칸이 젖는다 | 보라 + 감전·빙결 | 호숫가 뱃사공 출신 등불지기가 두르던 것 |
| 피의 송곳니 | 쌍단검 | 출혈 중인 적이 죽으면 주변 1칸 적에게 출혈 2 | 빨강 출혈 | 굶주린 해에 사냥으로 마을을 먹여 살린 이의 칼 |
| 가시 판금 | 몸통(판금) | 맞을 때마다 초록 쿨타임이 추가로 1 줄지만 받는 피해 +20% | 초록 | 물러서지 않았던 문지기의 갑옷 |
| 번개 감긴 반지 | 반지 | 번개가 번질 때 1칸 더 멀리 | 감전 연쇄 | 폭풍을 셌던 학자의 반지 |
| 거인의 망치 | 전투 망치 | 밀치기가 1칸 더 멀리, 벽 충돌 시 주변 1 피해 | 보라 밀치기·충돌 | 광산 붕괴에서 동료를 파낸 광부의 망치 |
| 연금술사의 장갑 | 장갑 | 던지는 물건이 두 개로 나뉘어 날아감 | 소모품·지형 | 불씨 단지를 처음 만든 이의 장갑 |
| 첫 불씨 등잔 | 목걸이 | 횃불이 0이 되어도 시야 3칸 유지 | 횃불 | 모닥불을 처음 옮겨 붙인 등불지기의 등잔 |
| 이름 없는 투구 | 머리 | 적의 예고를 한 턴 먼저 봄 | 모두 | 누구의 것인지 아무도 기억하지 못한다 |

- 효과 설명은 두 줄 이내. 해당 영혼석이 없으면 효과가 약하거나 거의 없어야 한다.
- 한 세계(저장)에 같은 유품은 한 번만 나온다.
- 등불지기가 죽으면 **입고 있던 유품은 그 층에 남아** 다음 등불지기가 찾을 수 있다.

## 11. 미확인

- 희귀·전설은 미확인으로 떨어진다("미확인 투구", 옵션 "???"). 전설(유품)은 이름과 이야기만 먼저 보인다.
- 입으면 옵션이 하나씩 드러나고, 한 층을 내려가면 전부 드러난다. 확인 두루마리는 즉시 전부.
- 미확인 장비와의 비교는 기본 수치(피해·방어)와 색 배율만.

## 13. 아이템 창

### 13.1 화면 (모바일 세로)

```text
┌──────────────────────────────┐
│  세트 A ▶ [창 🟣]  [방패]      │  ← 쓰는 세트가 밝게
│  세트 B   [석궁 🟣 (양손)  ]   │
│   [머리]  (인형 회전)  [목걸이] │
│ [장갑]    [몸통]    [신발]    │
│         [반지]  [반지]        │
├──────────────────────────────┤
│ HP 38 방어 3 회피 14% 피해 4~6 ×1.45 │ ← 누르면 정보 창
├──────────────────────────────┤
│ 가방 12/20                   │
│ ▢▢▢▢▢  (등급색 테두리,         │
│ ▢▢▢▢▢   무기는 색 점)          │
│ ▢▢▢▢▢                        │
│ ▢▢▢▢▢                        │
└──────────────────────────────┘
```

- 인형은 3D, 드래그로 돌려본다. 세트 줄을 누르면 그 세트로 바뀐다(전투 중에도 턴 소모 없음).
- 가방 칸은 등급색 테두리. 무기에는 색 점(빨강·보라·초록). 지금 쓰는 것보다 나은 장비에는 작은 초록 화살표.

### 13.2 비교

- 같은 칸(무기는 같은 손)에 입은 것이 있으면 두 창을 위아래로 나란히. 차이값 초록·빨강, 새 옵션은 초록 "새 옵션", 사라지는 옵션은 빨강 줄 긋기.
- 무기는 **색 배율**("빨강 영혼석 4개 → ×1.6"), **모양**, **치명 조건**을 함께 보여준다. 색이 다르면 "색: 보라 → 빨강"을 눈에 띄게.
- 양손 무기로 바꾸면 보조손 장비가 가방으로 간다고 미리 알려준다.
- 반지는 두 칸과 각각 비교하는 탭 두 개.
- 버튼: [장착 → 세트 A / 세트 B] [버리기], 두루마리를 들고 있으면 [확인] [강화].

### 13.3 규칙

- 안전할 때 장착·해제 자유. 전투 중에는 한 번에 한 턴. **세트 교체만 턴을 쓰지 않는다.**
- 버리기는 발밑에 떨어뜨린다.
- 정착지에서는 창고 칸이 함께 보여서 가방과 창고 사이로 옮길 수 있다.

### 13.4 캐릭터 정보 창

- 최종 수치(HP, 방어, 회피, 막기, 피해와 색 배율, 원소 저항 단계, 급소).
- 수치를 누르면 출처가 펼쳐진다: "피해 5 ×1.45 = 창 3~5 + 품질 1 + 강화 1 … × (1 + 0.15 × 보라 3)".

## 14. 외형

| 칸 | 바뀌는 것 |
| --- | --- |
| 무기 | 종류마다 모양(도끼날, 도리깨 사슬, 쌍단검 두 자루, 부메랑, 대검, 망치 머리, 창 자루, 석궁, 장검, 철퇴, 레이피어, 투석구). 손잡이에 색 리본(빨강·보라·초록) |
| 양손 무기 | 두 손으로 쥐는 자세 |
| 보조손 | 방패(원형, 등급색 테두리) / 오브(손 옆에 떠서 천천히 도는 빛나는 구슬, 그 색) |
| 쓰지 않는 세트 | 등에 멘다(양손 무기는 등에 비스듬히) |
| 머리 | 두건, 가죽 모자, 투구, 뿔 투구, 왕관(전설 전용 금색) |
| 몸통 | 재질색(천 베이지, 가죽 갈색, 사슬 회색, 판금 은색) + 몸 두께 |
| 장갑·신발 | 손발 구의 크기·색 |
| 목걸이 | 가슴 앞 작은 보석 |

- 등급 광택: 마법 옅은 파란 테두리광, 희귀 노란 테두리광, 전설 주황 테두리광 + 몸 주변을 도는 작은 불씨 4~6개.
- 강화 +2 이상: 무기 날에 은은한 광택.
- 장착·세트 교체 순간: 인형이 한 번 탄성 있게 튀며 해당 부위에서 반짝이. 세트 교체는 등에서 꺼내 드는 짧은 동작.

## 15. 드롭 연출

- 바닥의 장비는 등급색 빛기둥. 일반은 없음, 마법 낮음, 희귀 중간, 전설 높고 밝음 + 천천히 회전.
- 이름표는 주인공이 3칸 안에 있을 때만. 무기 이름표에는 색 점.
- 전설이 떨어지면 화면이 0.3초 주황빛으로 번쩍이고 로그에 주황 글씨로 유품 주인의 이름.

## 16. 코드 연결

- 상태: `G.eq = { sets: [{ main, off }, { main, off }], active: 0, head, body, hands, feet, neck, ring1, ring2 }`, `G.bag`(최대 20), 장비 객체 `{ id, base, slot, color, hands, quality, plus, rarity, name, affixes, legendary, known }`.
- 지금 구현(§19)의 `weapon`/`off` 한 벌 → 세트 두 벌로 확장. 이전 `off`의 두 번째 무기는 세트 B 주손으로, 횃불 보조는 제거.
- `calcStats()`: 기본 + 장비 + 색 배율(같은 색 영혼석 개수) → 최종 수치. 상한은 여기서 자른다.
- 무기 모양·치명 조건: `data/gear.js`의 무기 정의에 `shape`, `crit(ctx)`, 공격은 `core/combat.js`의 무기 공격이 모양대로 대상 칸을 모아 처리.
- 원거리: 조준과 미리보기는 영혼석 스킬 조준 코드 재사용. 석궁 장전은 무기 상태 `loaded`.
- 저항: 옵션 "원소 저항"을 % 대신 단계(+1)로. `밸런스_기준.md` §3의 배율표를 `core/combat.js` 원소 피해에 적용.
- 유품: `META.unrandsFound`, 죽을 때 입고 있던 유품을 그 층(구역·층 번호)에 기록해 다음에 그 층을 만들 때 놓는다.
- 저장: 장비 형식이 바뀌므로 저장 버전을 올리고 이전 장비를 옮긴다(무기 종류 → 12종 중 가장 가까운 것, 단검 → 쌍단검).

## 18. 확인 목록

1. 무기 12종이 색·손·모양·치명 조건대로 동작한다.
2. 같은 색 영혼석이 늘면 그 색 무기 피해 배율이 오르고, 비교 창에 배율이 보인다.
3. 세트 A ↔ B 교체가 턴을 쓰지 않고, 쓰지 않는 세트의 방패·오브·옵션은 적용되지 않는다.
4. 양손 무기를 끼면 보조손 장비가 가방으로 간다(미리 알림).
5. 원거리: 붙은 적에게 쏘면 피해 절반, 석궁은 장전 1턴, 원거리 적중도 빨강 쿨타임을 줄인다.
6. 치명 조건이 충족된 적 위에 "×2"가 뜬다.
7. 강화 두루마리로 +1(최대 +3), 품질은 구역마다 오른다.
8. 원소 저항 옵션이 단계로 붙고 +3을 넘지 않는다.
9. 유품을 주우면 이름이 "기억할 이름들"에 오르고 모닥불 밝기 +1, 죽으면 입고 있던 유품이 그 층에 남는다.
10. 기존 아이템 창의 동작(비교, 인형 회전, 외형 변화, 창고)이 그대로 동작한다.
11. 장비만 좋은 판보다 영혼석만 좋은 판이 강하다.
