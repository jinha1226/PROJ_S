# 조사물과 도구

기본 실행의 1층 보급 위치 네 곳에 잠긴 상자 두 개와 흙더미 두 개를 배치한다.
출정마다 기본 보급으로 열쇠 2개와 삽 2개를 지급한다. 가방의 `도구` 탭에서 확인한다.
현재 다른 보급품과 마찬가지로 출정 시 초기화하며, 구매·제작이나 디스크 저장은 범위 밖이다.

보이는 조사물을 누르면 설명과 선택지가 열린다. 인접해야 조사할 수 있고,
적이 보이면 조사가 잠긴다. 대각선 인접은 기존 근접 판정을 따른다.
도구가 없어도 맨손 선택은 가능하며, 확률이나 비용을 미리 표시한다.
도구 사용은 1개 소모하며 항상 안전하다. 성공·실패 모두 조사물을 사용 완료 처리한다.
선택 확정만 정상 행동 1회를 소비한다. 창 열기·지나가기는 시간과 자원을 쓰지 않는다.
자동탐험은 처음 발견하는 조사물이 있으면 해당 이동 뒤 정지하며, 이미 본 것은 반복 정지시키지 않는다.

## 확장 지점

`data/content/exploration_curios.json`의 `tools`와 `curios`에 정의한다.
각 조사물은 이름·설명·아이콘과 `options`를 가진다. 각 선택에는 표시 이름,
선택적 도구 ID/소모량, 성공 확률, 성공/실패 결과를 정의한다.
결과는 현재 `loot`, `food`, `damage`, `stress`, `text`를 지원한다.
`expedition/curios.gd`가 모든 검증·차감·결과·행동 처리를 담당한다.
동일한 원정·조사물의 결과는 시드에 고정되어 창을 반복해서 열어도 다시 추첨하지 않는다.

`../`에서 해당 도구-조사물 실행기를 찾지 못해 공통 처리부는 새로 작성했다.
기존 층 생성기의 보급 위치, 기존 피해/스트레스 처리, 이식한 자동탐험 구조는 그대로 사용한다.
기억은 함정 피해 시 기존 SELF_HARM 생성 경로를 사용하며 별도 조사 기억 타입은 추가하지 않았다.

검증: `tests/curios.gd`에 선택 없는 획득 방지, 도구 부족, 중복 보상 방지,
행동 소비, 맨손 비용/함정, 전투/거리 제한, 지나가기, 도구 목록, 발견 정지를 포함한다.
