# 공용 가방 UI 이식

`../playtest/item_inventory_slot.gd`의 사각 음각 슬롯·선택 강조·수량 배지 구조와
`party_encounter_sandbox.gd`의 분류 필터 → 슬롯 그리드 → 별도 상세 팝업 흐름을
현재 데이터/아트에 맞춰 `expedition/inventory_slot.gd`와 `main.gd`로 축소 이식했다.

- 4열 슬롯, 최소 12칸 표시. 빈칸은 표시용이며 용량 제한이 아니다.
- 전체/소모품/장비/파츠/자원 필터. 물약·두루마리 16종, 장비, 파츠, 식량을 표시한다.
- 슬롯 선택 시 그리드를 밀지 않는 상세 팝업에 설명·수량·대상별 사용 버튼을 표시한다.
- 상세 팝업은 가방 PopupPanel의 자식인 transient/exclusive 창으로 구성해 가방 뒤로 열리지 않게 한다.
- 미감정 소모품은 Run마다 달라지는 외관과 `미감정` 표식으로 보인다. 감정 후에만 효과 설명을 보여준다.
- 물약은 대원을 골라 마신다. 광역 물약과 미감정 물약은 층에서 칸을 골라 던질 수 있다(사거리 4, 시선 필요).
- 두루마리는 읽는 즉시 발동한다. 감정·강화 두루마리는 소비 후 선택 팝업에서 종류 또는 장비를 고른다.
- 사용은 조작 중인 대원의 한 행동을 소비하며, 동료에게 마시게 해도 조작 대원은 바뀌지 않는다.
- 바닥 아이템은 대원이 밟으면 자동으로 주워 공용 가방에 들어간다.
- 식량은 야영 때만 소비한다. 장비와 파츠는 야영에서 장착한다.

검증은 `tests/abilities_growth.gd`에 포함한다. 앱 종료 후 영속 저장은 기존처럼 미구현이다.
