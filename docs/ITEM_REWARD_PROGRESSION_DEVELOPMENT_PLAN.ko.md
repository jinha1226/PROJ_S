- 상태: 사용자와 합의한 방향을 정리한 구현 인계용 계획. 이번 작업은 문서 작성이며 게임 구현·밸런스 변경·푸시를 포함하지 않는다.

## 1. 목표

던전에서 얻은 보상이 다음 탐험의 준비, 무기 성장, 새로운 이능, 거점 성장으로 이어지게 한다. 흔한 잡장비를 대량으로 비교·판매하는 작업보다, 필요한 자원을 찾아 위험을 감수하고 돌아오는 선택을 중심에 둔다.

핵심 순환:

`원정 준비 → 적·탐험 장소 선택 → 전리품 확보 → 계속 탐험할지 귀환할지 판단 → 보급·무기 재제작·이능 장착·거점 투자`

## 2. 합의한 설계

### 2.1 네 가지 기본 보상

| 보상 계열 | 목적 | 주된 획득처 방향 | 사용처 |
|---|---|---|---|
| 무기 업그레이드 소재 | 현재 무기의 소재 등급 상승 | 소재에 맞는 적, 광맥, 무기고 | 무기 재제작 |
| 돈·환금품 | 유연한 구매력 제공 | 인간형 적의 돈, 몬스터 마석·가치품 | 보급품·서비스 구매 |
| 몬스터 이능 | 캐릭터의 능력과 조합 확대 | 해당 능력을 가진 종족·정예 | 기존 이능 획득·장착 체계 |
| 거점 업그레이드 재료 | 원정 간 장기 성장 | 유적·물자 더미, 일부 적 | 기존 거점 시설 확장 |

- 모든 적에게 네 계열을 전부 배정하지 않는다. 종족·적 역할·장소별로 주요 보상을 구분한다.
- 돈과 환금품은 같은 경제 보상 계열이다. 짐승이 이유 없이 금화를 떨어뜨릴 필요는 없다.
- 무기 소재와 거점 소재는 기본 사용처를 구분한다. 같은 희귀 재료를 양쪽 필수 재료로 반복 요구하는 구조는 피한다.
- 기본 드롭은 몬스터 사망뿐 아니라 탐험 장소에도 배정한다. 전투를 피하는 원정에도 보상이 있어야 한다.

### 2.2 기본 보상 외 두 종류

- **보급품:** 식량·포션·횃불. 탐험을 더 이어갈 수 있게 하는 회수 자원이다.
- **특별 발견:** 완성 장비·브랜드 장비·랜다트·픽다트. 재료만 모으는 플레이가 되지 않게 발견의 재미를 제공한다.

이 둘은 네 계열을 대체하지 않는다. 특히 랜다트·픽다트를 일반 적의 상시 드롭으로 남발하지 않는다.

### 2.3 단순한 무기 분류

초기 대표 무기는 단검·장검·도끼·철퇴·창·활·쇠뇌의 일곱 종류로 잡는다. 무기군마다 세부형을 여러 개씩 추가하지 않는다.

| 종류 | 설계상 핵심 역할 |
|---|---|
| 단검 | 빠른 공격·빈틈 공략 |
| 장검 | 공격과 방어의 균형 |
| 도끼 | 강한 베기·방어 압박 |
| 철퇴 | 갑옷 상대 타격 |
| 창 | 거리 유지·접근 견제 |
| 활 | 지속적인 원거리 공격 |
| 쇠뇌 | 강한 한 발·재장전 부담 |

이는 역할 목표이며 현재 구현된 효과라고 가정하지 않는다. 기존 찌르기검 등과 대표 분류의 대응표를 먼저 작성하고, 기존 아이템 ID 삭제나 저장 데이터의 무단 치환 없이 호환 경로를 마련한다. 무기별 역할 재설계가 큰 전투 변경을 요구하면 이번 보상 작업과 분리해 보고한다.

## 3. 소재 등급과 업그레이드

### 3.1 구성 원칙

일반 무기의 구조는 **무기 종류 + 소재 등급 + 선택적 브랜드 하나**로 둔다. `+1`, `+2` 등의 별도 강화 수치는 이번 계획에서 도입하지 않는다.

- 무기 종류는 전투 방식, 소재 등급은 기본 성능, 브랜드는 특수 기능을 담당한다.
- 나무검과 철검을 전도성 장단점만으로 동등한 주력 선택지로 만들지 않는다.
- 전도성·가연성 등은 기존 환경 시뮬레이션에 반영하되, 소재 등급의 성장 역할을 지우지 않는다.
- 초기 소재·아이템 목록은 13절의 구현 초안을 따른다. 명칭·경계 층·성능 배율은 튜닝안이며 사용자 확정 수치와 구분한다.
- 활·쇠뇌까지 금속 칼날 소재표를 그대로 쓰지 않는다. 무기별 주재료·핵심 부품을 정의하고 공통 등급에 대응시킨다.
- 소재 데이터와 아이템 정의의 조합은 허용 목록으로 제한한다. 모든 무기×모든 소재를 자동 생성하지 않는다.

### 3.2 재제작 흐름

`대상 무기 선택 → 다음 소재 등급/실제 성능 변화 확인 → 필요한 소재와 비용 확인 → 확정 → 자원 차감과 무기 변경`

- 일반·브랜드 무기는 브랜드를 보존하며 소재 등급을 올릴 수 있게 하는 방향으로 설계한다.
- 무기 재제작에 별도 골드 비용을 부과할지는 경제 튜닝 항목이다. 무기 소재를 쓰는 것과 골드를 동시에 요구하는 것을 혼동하지 않는다.
- 계획상 기본안은 확정 성공이며 실패·파괴·강화 확률은 도입하지 않는다.
- 거래는 원자적으로 처리한다. 실패·취소·저장 오류 시 소재/돈만 사라지거나 무기만 복제되면 안 된다.
- 장착 상태, 소유권, 개체 참조, 브랜드, 무기 런타임 상태를 보존하거나 명시적으로 변환한다. 장전된 쇠뇌를 재제작하면서 탄약이나 장전 상태를 복제하지 않는다.
- 임의의 반복 분해·재제작으로 자원을 늘릴 수 없게 한다. 첫 버전에는 분해·등급 하락·소재 회수 기능을 추가하지 않는다.

## 4. 브랜드·랜다트·픽다트

- 브랜드는 쉽게 설명되는 핵심 효과 하나를 원칙으로 한다.
- 랜다트는 무작위 특성 조합, 픽다트는 직접 설계한 고유 효과로 구분한다. 일반 장비 위에 무조건 붙는 연속 강화 단계가 아니다.
- 소재 한 단계 차이는 유용한 브랜드와 비교할 이유를 줄 수 있지만, 소재 차이가 커지면 교체할 이유도 있어야 한다.
- 랜다트·픽다트가 언제나 일반·브랜드 장비보다 강해야 하는 것은 아니다.
- 기존 이능의 액티브 버튼 체계를 장비마다 새 버튼을 추가하는 방식으로 확장하지 않는다.
- 초기 브랜드 후보는 화염·냉기·전격 등 기존 환경 판정과 연결 가능한 효과다. 실제 상태 적용·시간 처리·피아 피해·이펙트가 검증되기 전에는 완성 콘텐츠로 드롭시키지 않는다.
- 랜다트의 특성 수, 생성 테마, 픽다트 목록, 아티팩트 재제작 허용 여부는 미정이다. 확정 전에는 아티팩트 재제작을 비활성화하고 이유를 표시한다.

첫 구현에서 모든 브랜드와 아티팩트를 완성할 필요는 없다. 검증된 소수의 완성 장비 보상부터 연결하고, 희귀도 이름만 붙인 무효 아이템을 출시하지 않는다.

## 5. 몬스터 이능 획득물 — 아이템 측 경계

- 아이템은 실제 이능 ID를 참조하는 획득물의 드롭·줍기·보관을 담당한다. 미구현 능력은 드롭하지 않는다.
- 줍기만으로 자동 흡수·장착하지 않는다. 이능 시스템의 흡수 승인 후에만 획득물을 소비한다.
- 이능 레벨 한도·중복 효과·결속·제거·귀속은 [별도 이능 개발서](ABILITY_BINDING_DEVELOPMENT_PLAN.ko.md)가 소유한다. 아이템 단계 0~2에 해당 기능 전체를 포함하지 않는다.
- 이능 서비스가 미완료면 보관과 미리보기까지 제공하고 흡수는 명시적으로 잠근다.

## 6. 보상 배치와 경제

| 장소·대상 | 기대 보상 |
|---|---|
| 일반 적 | 종족/역할에 맞는 소량의 기본 보상, 실제 소지 장비 |
| 정예 | 해당 종족 이능 또는 상대적으로 좋은 소재·특별 장비의 획득 기회 |
| 일반 물자 더미 | 보급품·거점 재료 |
| 광맥·무기고 | 무기 소재, 장소에 맞는 완성 장비 |
| 곁길·위험 구역 | 위험을 감수할 이유가 있는 보상 묶음 |
| 특별 장소 | 테마 장비·랜다트·픽다트 후보 |

- 지역의 깊이·위험도·보상 장소가 보상 수준을 결정하게 한다. 플레이어 레벨에 맞춰 모든 장비를 자동 상향하지 않는다.
- 보상 품질은 높일 수 있어도 현재 장비의 상위 호환을 매번 보장하지 않는다.
- 무보상 구간이 길지 않은지 측정하되, 무기 교체나 이능 획득을 매 원정 강제하지 않는다.
- 안전한 입구 반복 사냥이 모든 상위 소재와 이능의 최적 획득 경로가 되지 않게 획득처를 구분한다.
- 상위 소재의 핵심 재료는 지정 깊이에서만 생성한다. 저층 소재 합성, 상점 구입, 적 소지품 회수, 퀘스트 등 우회 경로에도 같은 성장 경계를 적용한다(13절).
- 1·2층의 일반 콘텐츠는 원정 간 초기화하고 3층부터는 상태를 유지한다. 초기화 대상·타이밍·보상 출처 처리는 별도 탐험 개발서를 따른다. 아이템 작업은 출처와 층 세대 정보를 소비한다.
- 흔한 적 장비를 모두 운반·판매해야 경제적으로 유리해지는 설계를 피한다. 환금품 중심의 수익 흐름을 우선한다.
- 기존 적 소지품의 바닥 이동과 추가 드롭은 별도다. 사망 장비를 유지하면서 동일 장비를 생성 표로 또 지급하는 중복을 검사한다.
- 귀환 보상은 새로 가져온 일반 전리품도 성과로 인정할지 검토한다. 기존 물품 재반입·입구 왕복으로 보상을 반복 수령할 수 없어야 한다.

드롭률, 수량, 가격, 업그레이드 비용, 보장 보상 여부는 아직 확정하지 않는다. 테스트용 수치는 별도 튜닝 설정과 결과 문서에 기록한다.

## 7. 데이터·기존 시스템 통합

구현 전 실제 HEAD와 호출 경로를 재확인한다. 기존 레지스트리를 우선 확장하고 UI용 별도 인벤토리·재료 원장을 만들지 않는다.

| 영역 | 기존 통합 후보 | 필요 작업 |
|---|---|---|
| 아이템 | `data/content/items.json`, `sim/item_registry.gd`, `sim/item_instance.gd` | 역할/소재/브랜드 정보의 저장 위치와 구버전 기본값 결정 |
| 무기 | `data/content/weapons.json`, `sim/weapon_registry.gd`, `sim/weapon_attack_rules.gd` | 기본형과 소재 보정의 단일 계산 경로 |
| 소재 | `sim/material_registry.gd` | 게임 등급과 물리적 성질의 구분, 중복 정의 방지 |
| 추가 드롭 | `data/content/species_drop_tables.json`, `sim/species_drop_registry.gd` | 보상 계열과 출처별 테이블, 검증·규칙 버전 |
| 사망·소유권 | `sim/systems/corpse_loot_system.gd`, `sim/world_item_operations.gd` | 기존 소지품 이동 보존, 중복 사망 처리 방지 |
| 탐험 자원 | `sim/base_resource_cache_rules.gd`, `sim/base_monster_supply_rules.gd` | 네 계열과 기존 거점 재료 경로의 대응 |
| 거점·거래 | `sim/base_production_rules.gd`, `playtest/party_playtest_session.gd` | 재제작·경제 원자성, 실제 보유 재료 확인 |
| 이능 | 기존 이능 획득·장착 관련 호출 경로 조사 | 보상에서 해금/보관으로 연결, 중복·귀속 정책 |

논리적으로 필요한 보상 데이터는 출처 ID, 대상 종족/장소, 보상 계열, 정의 ID, 수량 범위, 확률/가중치 의미, 허용 지역/등급, 규칙 버전이다. 기존 JSON의 엄격한 키 검증을 확인하고 필드 추가와 검증·마이그레이션을 함께 변경한다.

## 8. UI·UX

- 바닥 표시 → 줍기 → 인벤토리 → 사용처까지 연결한다. 채집 버튼을 다시 추가하는 것을 기본 해법으로 삼지 않는다.
- 네 기본 보상은 아이콘·이름·용도 표기로 구분한다. 색상만으로 구분하지 않는다.
- 재료 설명에 '무기 재제작용', '거점 건설용' 등 주 사용처를 표시한다.
- 획득 로그는 이름과 수량을 간결하게 표시하고, 이능·특별 장비만 강조한다. 기존 3줄 로그에서 재료 메시지가 중요 전투 로그를 밀어내지 않도록 묶는다.
- 재제작 화면은 현재/다음 소재, 실제 성능 변화, 보존되는 브랜드, 필요/보유 재료, 비용을 보여준다.
- 귀환 화면은 회수 물자·보급품 소모·신규 이능·특별 장비를 요약한다. 가격 없는 물품에 임의의 골드 가치를 부여하지 않는다.
- 기존 24×24 픽셀 아이콘, 정수 배율, 9-slice 다크판타지 UI를 재사용한다. 새로운 아트 생성은 별도 작업으로 명시한다.

## 9. 단계별 실행 계획

### 단계 0 — 현재 흐름과 데이터 계약

전체 획득/소비/보관 경로와 대표 무기 대응표를 작성한다. 13절 목록을 기존 ID에 대응시키고 깊이 제한, 층 세대 인터페이스, 이능 획득물 인터페이스와 구버전 규칙 전환을 기록한다. 미결정 사항이 해당 단계 구현을 막으면 그 항목만 질문한다.

### 단계 1 — 네 보상 계열의 최소 연결

각 계열에 최소 한 개의 실제 사용 가능한 보상을 연결한다. 일반 적·물자 장소·정예 후보에 역할별로 배정하고, 획득→귀환→보관/사용처 흐름을 검증한다. 이능 획득물은 실제 정의를 참조하고 미완료 흡수 기능은 잠근다. 깊이와 층 세대 정보를 보상 생성에 연결하되 층 초기화 자체와 경험치·결속은 별도 개발 범위다.

### 단계 2 — 소재 등급 재제작

우선 대표 무기 하나에서 두 소재 등급의 전환과 거래·저장 검증을 완료한 뒤, 승인된 대표 무기 목록으로 확장한다. 브랜드 보존과 기존 장착 상태를 검증한다. 별도 강화 수치는 넣지 않는다.

### 단계 3 — 특별 발견과 보상 배치

검증된 브랜드 장비와 소수의 완성 장비를 탐험 보상으로 배치한다. 랜다트·픽다트는 효과/생성 정책이 정해진 범위만 구현한다. 고유 아이템 대량 제작은 별도 후속 범위다.

### 단계 4 — UI·경제·성능 검증

재료 용도·재제작 비교·귀환 성과 표시를 완료한다. 고정 시드의 행동 기록으로 소모와 획득을 비교하고 초기 튜닝 결과를 제출한다.

기본 인계는 **단계 0~2의 최소 플레이 가능 흐름 완료 후 검토**로 잡는다. 단계 3~4 전체 확대는 반환 결과를 보고 진행한다. 다만 줍기/재제작에 필요한 최소 UI, 저장·회귀·성능 검증은 각 단계부터 함께 수행한다.

- [ ] 모든 실제 등장 종족/장소의 보상 배정 또는 의도적인 무보상이 명시돼 있다.
- [ ] 보급품과 특별 장비 발견이 네 계열과 별도로 유지된다.
- [ ] 무기 기본형·소재·브랜드가 일관되게 표시되고 별도 +강화 수치가 없다.
- [ ] 소재 재제작은 정상 완료 시 한 번만 소비하고 취소/실패 시 상태가 보존된다.
- [ ] 재제작 후 브랜드·장착·소유권·무기 런타임이 정상이며 복제/탄약 생성이 없다.
- [ ] 이능 획득은 기존 장착을 덮어쓰지 않는다. 중복 보상은 확정 정책에 따라 처리되거나 보존된다.
- [ ] 저층 보상·상점·적 소지 장비·합성에서 깊이 제한을 우회해 상위 핵심 소재를 생성하지 않는다.
- [ ] 같은 사망/상자/보상 출처를 중복 처리해도 보상이 다시 생기지 않는다.
- [ ] 동일 시드·동일 행동 기록의 보상과 저장/재생 결과가 같다. UI 열기·미리보기·로드로 재추첨되지 않는다.
- [ ] 기존 저장에는 과거 규칙 재현과 새 규칙 전환 경계가 있다. 새로운 테이블로 과거 드롭을 조용히 다시 계산하지 않는다.
- [ ] 입구 왕복·기존 물품 재반입·반복 재제작으로 무한 보상이 생기지 않는다.
- [ ] 줍기·포션 사용·휴식·무기 교체·전투 후 저장·거점 거래의 기존 회귀 테스트가 통과한다.
- [ ] 아이템/보상 증가로 매 프레임 전체 맵·이벤트 이력을 순회하지 않는다. 다수 드롭 장면의 처리/렌더링 성능을 비교한다.

측정 항목은 원정 길이별 획득량과 소모량, 첫 유용한 보상까지 행동/시간, 장비 교체 고민 횟수, 신규/중복 이능 비율, 귀환 성과, 무보상 구간, 잡장비 정리 부담이다. 실제 측정 없이 적정 드롭률이나 흑자 원정을 단정하지 않는다.

## 11. 인계 요청문

> 이 문서의 아이템 범위에 한해 단계 0~2를 구현해줘. 네 기본 보상의 생성·회수·사용처와 깊이별 소재 재제작을 연결하고 기존 소유권·브랜드·저장 호환성을 보존해줘. 이능은 획득물과 흡수 서비스 인터페이스까지만, 층은 깊이/세대 정보와 보상 중복 방지까지만 담당해줘. 이능 장착·삭제, 숙달 경험치, 층 초기화 엔진, 길드 튜토리얼 전체 구현은 이 요청에 포함하지 마. 다른 세션 변경과 겹치면 조정하고 미완료 기능을 사용 가능하게 표시하지 마. 코드·검증·결과를 커밋해 반환하고 별도 요청 없이 푸시하지 마.

## 13. 구현할 아이템 목록과 깊이별 성장 초안

### 13.1 확정 원칙과 초안의 구분

상위 소재의 깊이 제한은 합의 사항이다. 아래 **이름·ID·T1/T2/T3·3~4층/5층 이상 구간은 이번 문서에서 구체화한 초기 콘텐츠안**으로, 사용자 확정 수치가 아니다. 실제 층 수와 현재 콘텐츠를 확인한 뒤 데이터로 조정한다. 아직 없는 층이나 효과를 구현됐다고 표시하지 않는다.

| 등급 | 초기 획득 구간 | 핵심 재료 | 의미 |
|---|---|---|---|
| T1 | 1~2층 및 시작 장비 | 철재·질긴 목재 | 손실 복구와 기초 장비. 반복 보급 허용 |
| T2 | 3~4층 | 강철재·심재 | 첫 비초기화 구간 진입이 필요한 성장 |
| T3 | 5층 이상 | 흑철재·흑수목 심재 | 더 깊은 구간의 핵심 재료가 필요한 후속 성장 |

깊이는 생성 출처의 최소 깊이다. 깊은 곳에서 얻은 장비를 들고 저층에 오는 것은 허용한다. 저층에서 새로 생성한 상점 재고·적 기본 장비·환금 보상·퀘스트 보상은 이 경계를 우회할 수 없다. 상위 소재는 저급 소재 대량 합성이나 돈만으로 대체하지 않는다.

### 13.5 이능 보상과 특별 장비의 최소 목록

아래 능력은 **신규 설계 후보**다. 기존 능력과 동일하면 기존 ID를 사용하며, 효과 구현 전 드롭 금지 원칙을 따른다. 출처가 되는 몬스터가 없다면 능력만 독립 생성하지 않는다.

| 제안 보상 ID | 이능 | 형태 | 효과 계약 | 출처 후보 |
|---|---|---|---|---|
| `ESSENCE_NIGHT_SIGHT` | 야간시력 | 패시브 | 공통 시각 프로필의 저조도 불이익 완화. 어둠 스트레스 저항과 별개 | 동굴 적응 몬스터 |

| `ESSENCE_FIRE_BOLT` | 화염탄 | 액티브 | 기존 화염 계열 액티브를 재사용해 열 부여. 비용·행동 시간 적용 | 화염 능력을 실제 사용하는 적 |

획득물은 능력의 운반 형태이고 장착된 이능과 구분한다. 위 목록은 세 가지 테스트 능력에 한정하며 저층에서 세 가지를 모두 반복 파밍하도록 강제하지 않는다.

특별 장비 초기안은 화염 장검·냉기 창·전격 철퇴의 브랜드 변형 3개다. 소재 등급은 생성 깊이를 따른다. 랜다트는 검증된 브랜드 1개와 호환되는 보조 특성 1개의 제한된 조합부터 검토한다. 픽다트 후보는 적중 시 일정 시간 주변을 밝히는 장검 '등불지기' 1개로, 동적 광원·인지 갱신 검증 후 특별 장소에 배치한다. 해당 이름/효과는 제작 초안이며 전부 단계 0~2의 필수 구현으로 확장하지 않는다.
