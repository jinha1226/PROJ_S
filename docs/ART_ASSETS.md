# Backview Duel Art Assets

이미지 생성 도구로 경기장, 플레이어, 보스를 각각 제작하고 모바일 웹 해상도로 최적화했다. UI, 원근 투영, 그림자, 공격 궤적과 타격 이펙트는 Godot 코드로 렌더링한다.

## 파일

- `assets/duel/arena_courtyard.png`: 720×1280 불투명 경기장 배경
- `assets/duel/player_back.png`: 504×768 투명 백뷰 플레이어
- `assets/duel/warden_front.png`: 507×768 투명 정면 보스

## 공통 시각 방향

- 프리미엄 핸드페인티드 2D 모바일 게임 아트
- 차가운 청색 환경광과 가장자리의 따뜻한 등불빛
- 비에 젖은 산사원 석조 경기장
- 플레이어는 청록색 천 갑옷과 붉은 스카프를 착용한 검객
- 보스는 짙은 금속 갑옷과 버건디 망토를 착용한 인간형 검객
- 상표, 로고, 문자, 기존 작품 캐릭터는 사용하지 않는다.

## 생성 지시문 요약

### 경기장

세로 9:16 모바일 전투 배경으로, 낮은 3인칭 백뷰 카메라와 강한 바닥 원근을 지정했다. 아래쪽은 플레이어와 조작 UI, 위쪽 중앙은 보스를 위한 빈 공간으로 남겼다. 비에 젖은 폐허 산사원, 청회색 돌, 안개, 소나무, 소량의 호박색 등불을 사용하고 캐릭터와 UI는 제외했다.

### 플레이어

경기장 색감을 기준으로 엄격한 후면 전신 검객을 생성했다. 짙은 청록색 천 갑옷, 붉은 스카프, 오른손의 직검과 읽기 쉬운 실루엣을 지정했으며 실제 투명 배경, 한 명의 캐릭터, 잘리지 않은 전신을 요구했다.

### 보스

경기장과 플레이어의 붓질을 기준으로 엄격한 정면 전신 보스를 생성했다. 비대칭 청동·먹색 갑옷, 버건디 망토, 철 가면, 긴 외날검과 호박색 가슴 균열을 지정했다. 생성된 체크무늬 배경은 별도 배경 추출 단계로 실제 투명 채널로 교정했다.
