# 이능 정리 및 던전 구현 범위

2026-09-12, 기준 b6f38c1 이후 작업. 이번 작업은 시험용 자동 지급 제거와 코드 현황 조사이며 새 이능/몬스터 배치를 추가하지 않는다.

## 제거한 플레이 경로

- 역할별 무료 기술: 주인공 강타·밀치기, 동료 화염탄·응급 치유 자동 지급 제거.
- 물 생성·냉각·방전·시험 화염구 자동 지급 제거. 결속 및 실제 플레이 기술 사용 서비스에서도 차단.
- 시작 위치의 화염탄 정수 샘플 제거. 기존 장비·식량 배치는 유지.
- 정식으로 결속한 비시험 이능은 유지. 기술 원본 정의와 환경 효과 엔진은 실험 코드/참조용으로 보존한다. 모든 기술 구현 파일을 삭제한 것은 아니다.
- 구형 패시브의 획득/장착 및 기존 이능 정수 아이템 정의는 제거하지 않는다. 이미 소유한 정수도 자동 삭제하지 않는다.

## 정의된 패시브 계열

| 이능 | 연결 종족 ID | 정의된 효과 |
|---|---|---|
| 포식 신경 | goblin, kobold | 근접 태그 조건, 피해 +2 및 상처 난 적 추가 효과 훅, 스트레스 부작용 |
| 가죽 각질 | wolf, boar | 방어 +2, 회피 -25/1000, 화염 내성 -10 |
| 부식성 혈액 | ooze, slime | 피격 시 근접 공격자 산성 반격 훅, 치유량 감소 부작용 |
| 심층안 | aberration | 숨은 것 감지 훅, 밝은 곳 명중 저하 부작용 |

출처: `data/content/growth_builds.json`. 첫 유효 처치(직접 처치 또는 시야 내 목격 조건)에서 종족 계열 이능을 확정 해금하는 구형 규칙이고, 바닥 정수 드롭 방식이 아니다. 장착 칸은 3개다.

중요: `GrowthBuildCalculator`는 효과 보정과 훅을 빌드 DTO에 투영하지만, 현재 실제 전투의 장비 보정/피해 계산 경로가 이를 통합하지 않는다. `WOUNDED_TARGET_BITE`, `MELEE_ATTACKER_ACID`, `REVEAL_CONCEALED` 등의 실행 소비자도 확인되지 않았다. 표의 효과를 전부 실제 동작한다고 해석하면 안 된다.

## 액티브 계열

| 정의 | 현재 연결 |
|---|---|
| 화염탄 FIREBOLT | ESSENCE_FIRE_BOLT 소비 → 결속 → 시전 가능. 종족 드롭 표에는 연결 없음. 시작 샘플은 이번에 제거. 길드 튜토리얼 지원 경로는 남아 있음. |
| 강타 STRIKE / 밀치기 SHOVE / 응급 치유 MEND | 실행 코드 존재. 몬스터/정수 획득 연결 없음. 무료 역할 지급 제거. |
| 보호막 BARRIER | 정의는 있지만 메인 기술 사용 허용 목록에 없음. 몬스터 연결 없음. |
| 시험 화염구 / 물 생성 / 냉각 / 방전 | 일반 플레이 지급·결속·사용 차단. 환경 엔진 참조 정의만 보존. |

`sim/item_reward_rules.gd`의 정수→기술 매핑은 현재 화염탄 하나뿐이다. `data/content/species_drop_tables.json`에는 고블린의 마석·식량·돈이 있고 이능 정수 드롭은 없다.

## 던전 범위

- 메인 세션의 `MAX_IMPLEMENTED_CAMPAIGN_FLOOR = 2`.
- 출발/다음 층 이동/저장 명령 검증 모두 이 상한을 사용한다. 실제 플레이 가능 범위는 1~2층이다.
- 보상 정의의 15층 같은 숫자는 적용 가능 깊이 범위이며, 그 층까지 구현됐다는 뜻은 아니다.
- 현재 시드 기반 로스터의 일반 적 배치는 고블린/코볼드다. 늑대·멧돼지·슬라임·이형체의 이능 연결 정의가 있다고 해서 이들이 현재 층에 배치된 것은 아니다.

## 확인

- `ability_cleanup_acceptance.gd`: 무료 주인공/동료 기술 없음, 환경 시험 기술 차단, 결속한 화염탄 유지.
- `dungeon_0x72_acceptance.gd`: 새 게임/던전 직행/동료 허용/NPC 배치/에셋 회귀.
- `starting_ability_drop_acceptance.gd`: 샘플 제거, 무료 기술 없음, 장비 변경 및 저장 재생. 기존 샘플 지급 기대를 새 계약에 맞게 변경.
- 향후 순서 제안: 실제 사용할 이능과 획득 몬스터 확정 → 구형 패시브 효과를 전투 권위 코드에 연결 → 드롭/슬롯/숙련 적용 규칙 통일 → 수치 비교. 이번에는 이 후속 작업을 수행하지 않는다.
