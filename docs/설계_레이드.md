# 레이드 설계 (5인 파티, Eslabong식 주장 + 전술)

상태: ⬜ 미구현 · 설계

작성일: 2026-09-29 · 참고: Eslabong(주장을 직접 조종하거나 전술을 정해 자동 전투, 용병 로스터 관리, 매주 바뀌는 협동 던전 "Defend the Iron Gate")
이어지는 문서: `설계_정착지_건설.md`(주민·방·창고), `설계_스토리_정착지.md`(모닥불 밝기·등불지기 잇기), `설계_아이템_장비.md`, `밸런스_기준.md`, `문구_가이드.md`

## 0. 플레이어가 느껴야 할 것

- 혼자 내려가던 어둠에 **처음으로 마을 사람들과 함께** 간다. 내가 키운 마을의 힘을 확인하는 순간.
- 나는 등불지기 한 명을 움직이고, 동료들은 **내가 정해 둔 성향대로** 알아서 싸운다. 전술이 잘 맞아떨어질 때 쾌감.
- 보스는 혼자서는 못 푸는 문제를 낸다. **역할 분담**(막고, 치고, 쏘고, 고치고)이 답이다.
- 동료가 쓰러지면 **다친 채로 마을에 돌아온다.** 무리한 레이드는 마을을 멈춘다.

## 1. 원칙

1. **평소 던전은 그대로 혼자다.** 레이드는 따로 여는 특별 원정이다.
2. **조작은 등불지기 하나.** 동료 넷은 AI가 움직인다. 플레이어는 전투 전에 역할과 성향을, 전투 중에는 짧은 파티 명령만 준다. 원하면 등불지기까지 자동.
3. **격자 턴제 유지.** 실시간은 쓰지 않는다(원형 턴제 파일럿에서 답답함이 확인됨).
4. **주민은 죽지 않는다.** 쓰러지면 부상으로 돌아온다(정착지 규칙과 같음). 등불지기는 평소처럼 죽을 수 있다.
5. 모바일 세로 한 손. 5명 + 보스 + 졸개가 한 화면에서 읽혀야 한다.

## 2. 해금

- 조건: **주민 6명 이상**, **1구역 보스 처치**, 정착지에 **훈련장**(방: 훈련 인형 가구)을 지음.
- 해금되면 출발 화면에 "레이드" 탭이 생긴다.

## 3. 파티

### 3.1 구성

- 등불지기 1(주장) + 주민 4. 출발 전에 고른다. 부상 중인 주민은 고를 수 없다.
- 주민이 레이드에 가 있는 동안 정착지에서는 그 주민의 일이 빈다(원정 중 시뮬레이션 규칙 그대로).

### 3.2 역할 (주민)

훈련장에서 주민마다 역할 하나를 정한다. 바꾸는 데 하루.

| 역할 | 하는 일 | 기본 스킬 3개 (쿨타임) |
| --- | --- | --- |
| **수호자** | 적을 붙잡아 둔다 | 도발(4) · 방패 막기(3) · 밀쳐내기(3) |
| **검사** | 붙어서 딜 | 휩쓸기(3) · 출혈 베기(3) · 돌진(5) |
| **궁수** | 멀리서 딜 | 관통 사격(3) · 발 묶기(4) · 물러나며 쏘기(3) |
| **치유사** | 회복 | 치유(2) · 정화(4) · 보호막(5) |
| **주술사** | 원소·방해 | 물벼락(4) · 불씨(4) · 빙결(5) |

- 직업 특기가 어울리는 역할에 보너스(대장장이·광부 → 수호자, 사냥꾼 → 궁수, 약초꾼 → 치유사, 학자 → 주술사, 그 밖 → 검사). 다른 역할도 고를 수 있다.
- 스킬은 영혼석이 아니라 역할에서 온다(영혼석은 등불지기만). 원소 시너지·지형 규칙은 모두 같다.
- 주민 장비: 창고의 장비를 입힐 수 있다(무기 1 + 방어구). 무기 색 배율은 없다(영혼석이 없으므로).

### 3.3 주민의 성장

- 레이드 경험으로 **주민 레벨**(1~10)이 오른다. 레벨마다 HP·피해가 조금 오르고, 3·6·9에 역할 스킬이 한 단계 강해진다.
- 주민 레벨은 정착지 일에도 작은 보너스(작업 속도 +2%/레벨).
- 등불지기 잇기 때 레이드 경험이 많은 주민이 자원자로 더 잘 나선다.

## 4. 조작과 전술

### 4.1 턴 순서

`등불지기 → 동료 넷(AI, 빠르게 연출) → 적` 순서. 한 라운드가 한 번에 흘러가고, 동료 행동은 짧게 이어서 보여준다(두 번 탭하면 건너뜀).

### 4.2 성향 (전투 전, 주민마다)

| 성향 | AI가 하는 것 |
| --- | --- |
| 공격적 | 가장 약한 적이나 등불지기의 대상부터, 스킬을 아끼지 않음 |
| 신중 | HP 절반 아래면 물러나고, 예고 범위를 먼저 피함 |
| 지원 | 가장 다친 동료를 돕고, 보호·치유 우선 |

- 기본 성향은 **성격**에서 온다: 감정성 높음 → 신중, 원만성 높음 → 지원, 외향성 높음 → 공격적. 바꿀 수 있다.
- 성격은 가끔 명령을 흔든다: 성실성 낮으면 가끔 스킬을 늦게, 감정성 높으면 동료가 쓰러질 때 한 턴 움츠림(짧은 말풍선).

### 4.3 파티 명령 (전투 중, 한 손가락)

화면 아래 버튼 한 줄(평소의 행동 버튼 줄이 레이드에서는 이것으로 바뀌고, 등불지기 행동은 칸 탭 + 영혼석 칸):

| 명령 | 효과 (다음 명령까지) |
| --- | --- |
| 🎯 집중 | 모두 등불지기의 대상을 친다 |
| ⤧ 흩어져 | 서로 2칸 이상 떨어진다(광역 예고 대비) |
| ⤨ 모여 | 등불지기 곁으로 모인다(치유·보호 받기) |
| ↩ 물러나 | 입구 쪽으로 물러나며 싸운다 |
| 🤖 자동 | 등불지기까지 AI에게 맡긴다(다시 누르면 해제) |

## 5. 레이드 던전

### 5.1 형식

- 한 층짜리 **큰 방**(보스 방) + 앞마당(졸개 방 1~2). 층이 넘어가지 않는다.
- 횃불은 레이드에서 줄지 않는다(대신 라운드 제한, §5.3).
- 귀환 두루마리 쓸 수 없음. 파티가 전멸하거나 보스가 쓰러지면 끝.

### 5.2 보스 기믹 (역할이 필요한 문제)

| 기믹 | 예고 | 푸는 법 |
| --- | --- | --- |
| **표적 집중** | 보스가 위협이 가장 높은 대상을 노림 | 수호자가 도발로 붙잡는다 |
| **넓은 내려치기** | 보스 앞 부채꼴 붉은 칸 | 수호자 말고는 옆으로 |
| **흩어져라** | 모두의 발밑에 작은 원 | 흩어져 명령, 겹치면 피해 두 배 |
| **모여라** | 한 사람에게 큰 원 | 모여 명령, 나눠 맞으면 버틴다 |
| **졸개 부르기** | 벽 틈이 빛난다 | 검사·궁수가 먼저 정리 |
| **원소 약점 전환** | 보스 색이 바뀜 | 주술사·등불지기가 맞는 원소로 |
| **격노** | 라운드 제한 가까이 | 그 전에 끝낸다 |

### 5.3 첫 레이드 보스 (R1)

**잊힌 파수병** — 이름을 잃은 옛 경비대장의 그림자. HP 180, 3단계.

| 단계 | HP | 쓰는 것 |
| --- | --- | --- |
| 1 | 100~70% | 표적 집중, 넓은 내려치기 |
| 2 | 70~35% | + 졸개 부르기(해골 궁수 2), 흩어져라 |
| 3 | 35~0% | + 모여라, 원소 약점 전환(불 ↔ 냉기) |

- 격노: 30라운드. 격노 뒤에는 매 라운드 모두에게 큰 피해.
- 쓰러뜨리면 파수병의 이름이 돌아온다(기억할 이름들, 모닥불 밝기 +3).

## 6. 보상과 대가

| 결과 | 보상 · 대가 |
| --- | --- |
| 승리 | 레이드 재료(단단한 뼈·검은 강철 등 고급 가구·장비용), 유품 확률 높은 상자 1, 주민 경험, 모닥불 밝기 +3(처음), 연대기 한 장면 |
| 동료가 쓰러짐 | 그 주민은 **부상 3일**(정착지 일 못 함, 침대 필요). 이기면 부상 2일 |
| 등불지기가 쓰러짐 | 파티가 이기면 **살아서 돌아온다**(동료들이 업고 옴, 부상). 전멸하면 평소처럼 죽음 → 등불지기 잇기 |
| 전멸 | 보상 없음, 모든 참가자 부상 |

- 같은 레이드는 7일에 한 번(달력). Eslabong의 매주 바뀌는 층처럼, 이후에는 기믹 조합이 바뀌는 "이번 주의 레이드"를 둔다(R3).

## 8. 코드 연결

- 새 모듈: `js/core/raid.js`(레이드 흐름·라운드·보상·부상), `js/core/party.js`(동료 AI·성향·명령·위협), `js/data/raid.js`(역할·스킬·보스·기믹), `js/ui/raid-hud.js`, `js/town/`에 훈련장 방과 레이드 준비 화면.
- 동료는 던전의 `G.ents` 안에서 `ally: true, member: npcId`로 움직인다. 지금의 소환수 AI(`allyAct`)를 역할 AI로 넓힌다.
- 위협(어그로) 값: 피해·치유·도발로 쌓이고, 보스 표적 집중이 읽는다.
- 원소·지형·예고·상태 이상은 기존 규칙을 그대로 쓴다.
- 부상: `META.npcs[].injured`(남은 날), 정착지 일 배정에서 빠진다.
- 저장: 레이드 중 저장은 하지 않는다(짧게 끝나는 한 판). 결과만 기록.

## 9. 단계별 구현

| 단계 | 넣는 것 |
| --- | --- |
| **R1** | 해금·훈련장, 파티 고르기, 역할 5종 + 스킬, 동료 AI·성향, 파티 명령 5개, 위협, 레이드 방 1곳 + 잊힌 파수병(3단계 기믹), 보상·부상, 레이드 HUD |
| R2 | 주민 레벨과 성장, 주민 장비, 레이드 보스 두 번째(원소 전환 중심), 성격이 명령을 흔드는 연출 |
| R3 | 이번 주의 레이드(기믹 조합이 바뀜), 레이드 전용 제작 |

## 10. 확인 목록 (R1)

1. 주민 6명 + 1구역 처치 + 훈련장이 있으면 출발 화면에 레이드가 생긴다.
2. 파티 4명을 고르고 역할·성향을 정할 수 있다. 부상 중인 주민은 고를 수 없다.
3. 등불지기 턴 뒤 동료 넷이 역할과 성향대로 움직인다(수호자는 도발, 치유사는 가장 다친 동료).
4. 파티 명령 5개가 즉시 동료 행동을 바꾼다. 🤖 자동으로 등불지기까지 AI가 움직인다.
5. 보스 3단계 기믹이 예고와 함께 나오고, 흩어져라·모여라가 명령으로 풀린다.
6. 동료가 쓰러지면 부상으로 돌아오고, 등불지기가 쓰러져도 이기면 살아서 돌아온다. 전멸하면 등불지기 잇기.
7. 레이드 중 한 라운드(동료 넷 + 보스 + 졸개) 연출이 3초를 넘지 않는다(두 번 탭하면 건너뜀).
8. 기존 던전·정착지 테스트 통과, `tests/raid.mjs` 추가.
