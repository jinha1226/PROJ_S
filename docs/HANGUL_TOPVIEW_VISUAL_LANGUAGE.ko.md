# 한글 몸체 + ASCII 장비 2D 탑뷰 시각 언어

## 목표

메인 파티 화면은 한글 자음 몸체를 중심으로 한 2D 탑뷰를 기본으로 사용한다. 시뮬레이션의 종족·장비·지형 데이터는 그대로 유지하고, 렌더러만 종족은 한글 자음, 장비는 모양이 직관적인 ASCII로 투영한다.

## 캐릭터 규칙

몸체 글리프는 장비와 무관하게 항상 고정한다. 완성형 음절로 합성하지 않는다.

| 계층 | 의미 | 예시 |
|---|---|---|
| 중앙 몸체 | 종족 | 인간 `ㅇ`, 고블린 `ㄱ`, 코볼트 `ㅋ` |
| 좌우 외곽 | 방어구 | 왼쪽 `[`, 오른쪽 `]` |
| 진행 방향 쪽 | 무기 | 베는 검 `/`, 찌르기검 `|`, 도끼 `7`, 철퇴 `!`, 창 `^`, 활 `)`, 석궁 `+` |

대표적인 시각 묶음은 다음과 같다. 아래 표기는 개념 표기이며 실제 렌더러는 세 문자를 한 문자열로 만들지 않고 같은 셀 안의 독립적인 글리프로 배치한다.

| 상태 | 인간 | 고블린 |
|---|---:|---:|
| 맨몸 | `ㅇ` | `ㄱ` |
| 방어구 | `[ㅇ]` | `[ㄱ]` |
| 검 + 방어구 | `[ㅇ]/` | `[ㄱ]/` |
| 활 + 방어구 | `[ㅇ])` | `[ㄱ])` |

이 방식은 한국어를 모르는 사람도 실루엣으로 무기와 방어구를 구분할 수 있게 하며, 장비를 바꿔도 인간 `ㅇ`과 고블린 `ㄱ`의 정체성이 흔들리지 않는다. 장비 표시는 한 셀 안에 제한되며 충돌·클릭 영역을 넓히지 않는다.

인물 카드의 인장은 장비가 바뀌어도 종족 식별이 흔들리지 않도록 기본 몸체만 표시한다. 따라서 주인공 인장은 항상 인간 기준 `ㅇ`이다. 미니맵과 전체 지도의 주인공 위치 상수도 `ㅇ`을 사용한다.

## 월드 글리프

- 지형: `돌`, `나`, `쇠`, `깨`, `물`, `벽`
- 환경/흔적: `불`, `피`
- 구조물: `입`, `문`, `닫`, `출`
- 바닥 아이템: 무기 `)`, 방어구 `[`, 물약 `!`, 두루마리 `?`, 장신구 `=`, 재료 `*`
- 적 인지 상태: `의`, `경`, `추`, `수`, `귀`

바닥 지형은 낮은 명도, 행위자·위험·출구는 높은 명도로 그려 반복되는 글자 사이에서도 우선순위가 드러나게 한다.

## 카메라와 조명

- 기본 모드는 축 왜곡이 없는 정사각형 2D 탑뷰다.
- 기존 2.5D 투영은 비교용 선택 모드로만 남긴다.
- 불은 약 2.3셀 반경에 결정론적 흔들림을 가진 빛을 만든다.
- 조명은 현재 `VISIBLE` 셀과 그 안의 행위자에만 적용한다. `MEMORY`와 `UNSEEN` 셀의 불이나 적 정보는 밝기로 유출하지 않는다.

## 근접 공격 표현

- 무기 글리프를 회전하거나 휘두르는 모션은 사용하지 않는다.
- 공격자는 목표 방향으로 짧게 전진했다가 제자리로 복귀하는 캐릭터 전체 범프를 사용한다. 몸체와 고정 장비가 함께 움직인다.
- 접촉 순간에는 대상 셀 안의 타격선·섬광·파편, 짧은 히트스톱과 화면 흔들림을 함께 사용한다.
- 범프와 VFX는 표현 계층이며 공격자의 실제 위치, 대상 판정, FOV, 턴 시간에는 영향을 주지 않는다.

## 구현 경계

글리프는 표현 계층일 뿐 저장·전투·충돌 판정의 권위가 아니다. 종족이나 장비를 글자에서 역으로 추론하지 않고 구조화된 상태에서 매 프레임 투영한다. 따라서 세이브 호환성과 결정론적 리플레이는 이 시각 교체의 영향을 받지 않는다.
