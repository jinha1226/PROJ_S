# 게임 속 바바리안으로 살아남기: 능력 참고 자료

작성일: 2026-09-26 · 용도: 영혼석 목표 빌드 설계 참고
출처: 나무위키 등장인물 문서(세부 문서가 있는 인물). WebFetch 요약을 거쳤으므로 세부 수치는 원문과 대조할 것. 원문은 옮기지 않고 요약했다.
표기: [P]/[패시브] 패시브, [A]/[액티브] 액티브

순서: 정수 체계 → 주인공 파티 → 애플 나라크·고대 → 악령·라프도니아 → 기타 → 오르큘리스 → 클랜·탐사단 인물(분류:등장인물 추가분).

## 정수 체계

출처: https://namu.wiki/w/게임%20속%20바바리안으로%20살아남기/설정 , https://namu.wiki/w/게임%20속%20바바리안으로%20살아남기/설정/정수
(본문 문서 https://namu.wiki/w/게임%20속%20바바리안으로%20살아남기 에는 정수 규칙 상세 서술이 거의 없음)

- **획득**: 몬스터 처치 시 아주 낮은 확률(기본 0.01%)로 빛의 구슬 형태로 드롭. 흡수하면 스탯 보정 + **액티브 스킬 1개 + 패시브 스킬 1개**를 얻음.
- **색깔**: 같은 몬스터 정수라도 색깔에 따라 액티브 스킬이 달라짐(예: 빨강=화염 계열, 파랑=수계). 원하는 색 정수를 얻기 매우 어려움.
- **길들이기**: 흡수 후 신체 변화에 집중하는 "길들이기" 과정을 거치면 새 능력에 빨리 적응.
- **슬롯**: 레벨이 오르면 영혼력이 오르고 최대 흡수 가능 정수 수가 +1. 영혼력은 5레벨까지 레벨당 10, 이후 30씩 증가.
- **중복 불가**: 이미 가진 패시브/액티브와 같은 스킬을 주는 정수는 아예 흡수되지 않음.
- **약화**: 정수 스킬은 원본 몬스터 스킬보다 성능이 크게 낮고, 개체 고유 능력은 정수로 얻을 수 없음.
- **등급**: 9등급(최하) → 1등급(최상). 등급이 높을수록 드롭률 하락·가격 폭등. 3등급부터 극히 희귀.
- **삭제/교체**: 신전(대신전)에서만 삭제 가능. 비용은 500만 스톤에서 시작해 삭제할 때마다 2배. "절제된 소망" 같은 히든 피스로 동급 정수를 무작위 교체 가능.
- **특수 정수**
  - 수호자 정수: 기본 스탯 1.5배, 해당 몬스터의 액티브 스킬을 전부 습득(3개면 3개), 무지개색으로 표시.
  - 계층정수(계층군주 정수): 캐릭터당 1개만, 신전 삭제 불가, 영혼에 깊이 스며듦.
  - 변종 정수: 지하층 합성 마물에서 획득, 여러 몬스터 스킬 조합으로 강한 시너지 가능.
  - 맞춤형 정수: A/B/C 장치로 스탯/패시브/액티브를 조합.
- **빌드/시너지**: 최종 조합을 목표로 구간별 필요 정수·아이템과 대체 정수를 미리 설계하는 것이 핵심. 정수들의 스탯 보정이 누적되어 최종 성능을 결정.
- **오러**: 기사 계열이 습득하는 능력, 방어력 무시 공격.
- **대표 정수 예시**(설정/정수 문서)
  - 8급 데스핀드: [패시브] 재생력 상승 / [액티브] 구울 소환
  - 7급 오우거: [패시브] 물리 내성 2배 / [액티브] 웅크리기(내성 20배 증가)
  - 5급 오크 히어로: 영웅의 길(체력이 낮을 때 버프) / 거대화
  - 3급 벨라리오스: 탐욕의 비늘(항마력 방어) / 재해(필드 효과)
  - 2급 인면조(수호자): 어미새(소환수 MP 80% 환급) / 종말의 노래(무한 증식)
  - 1급 타이타누스(수호자): 혜성분열(투사체 복사)
  - 1급 스닉투라: 회광반조(능력치 2배) / 최후의 날(광역 재해)

# 주인공 파티

## 비요른 얀델
- 역할/전투 스타일: 탱커(역할군 "수호자", 방패 바바리안). 근력보다 물리 내성을 먼저 올리는 방패 중심의 방어형 전위. 클랜 단장이자 1팀 전위.
- 무기·공격 형태: 방패 + 둔기(망치) 타격. 거대화로 몸집을 키워 범위와 위협을 넓힌다.
- 정수 목록(현재 보유):
  - 눈물의 정수(계층군주 등급)
    - 불허 [P]: 생명력이 0%가 되어도 바로 죽지 않는다. 대신 10%까지 재생해야 한다. 조건: 생명력 0%일 때.
    - 절대적 고통 [P]: 받는 피해의 50%를 고정 피해로 바꾼다. 상시.
    - 말뚝: 문서 요약에 효과가 나오지 않음.
  - 맞춤형 정수(아르벳 + 우움달 + 오크 히어로 합성, 3+4+5등급): "어지간한 2등급보다 나은 조합"으로 평가됨
    - 거대화 [A]: 체격 약 1.771배, 위협 수치와 육체 수치 상승. 원래 오크 히어로 정수의 핵심 스킬이었고, 오크 히어로 정수는 이 맞춤형 정수로 대체됨.
    - 영혼연결: 장비(아이기스의 장벽)에 적용해 절대 파괴되지 않게 만든다(장비 항목 참고).
  - 심해거인(3등급)
    - 태초의 세포 [P]: 변신계 이능을 쓰는 동안 가장 높은 능력치 1.5배(초월 시 2.25배). 변신계 이능의 영혼력 소모 75% 감소. 조건: 변신계 이능(거대화 등) 사용 중.
    - 영혼잠수 [A]: 소모한 영혼력에 비례해 재생. 쿨타임 30분.
  - 볼-헤르찬(3등급)
    - 진화형 외피 [P]: 물리 내성에 비례해 4단계로 보너스를 준다. 도검류 내성 85%, 관통상 75% 감소. 상시.
    - 철옹성 [A]: 진화형 외피 효과를 1.5배로 올린다.
  - 스톰거쉬(3등급)
    - 기원 [P]: 바닷물 속에서 재생력 상승. 조건: 바닷물에 있을 때.
    - 폭풍의 눈 [A]: 반경 안의 적을 끌어당긴다(초월 시 20m 거리 단일 대상).
  - 바이욘(3등급)
    - 초월 [A/P]: 모든 패시브를 1.5배로 강화하거나 액티브 스킬의 강화판을 연다(타락 후 효과가 바뀜).
  - 오우거(3등급, 뱀파이어(수호자) 정수를 밀어내고 흡수)
    - 무쇠가죽 [P]: 물리 내성 2배, 베기 공격에 대해 추가로 2배. 상시.
    - 휘두르기 [A]: 둔기 파괴력이 근력에 비례해 오른다. 근력 1200 이상이면 2배 피해.
  - 벨라리오스(3등급)
    - 순환의 고리 [P]: 반경 10m 안에서 3등급 이상 몬스터가 죽으면 확률적으로 스탯이 오른다. 조건: 주변 처치.
    - 탐욕의 비늘 [A]: 항마력에 비례해 마법 피해 감소(항마력 500이면 50%).
  - 만티코어(5등급, 나중에 지움)
    - 유전 [P]: 마석을 먹을 때마다 스탯이 영구적으로 오른다(최대 200스택, 항마력 +200까지). 200스택 뒤 정수를 지웠고 항마력 40은 영구로 남음. 조건: 마석 섭취.
    - 도약 [A]: 도약력 10배, 착지할 때 충격파.
  - 시체골렘(7등급)
    - 산성체액, 살점폭발: 문서 요약에 효과가 나오지 않음. 정수 자체로 고통 내성 +70.
- 교체·삭제된 정수: 오크 히어로(맞춤형으로 대체), 만티코어(유전 완료 후 삭제), 뱀파이어(수호자)(오우거로 교체), 가챠본(외형 변경용, 삭제).
- 기타 고유 능력/특성/장비:
  - 바바리안 종족: 골격이 크고 단단하다. 정신 방벽이 두꺼워 검증 마법이 통하지 않는다.
  - 불사자 각인 — 야성분출 [A]: 위협 수치 3배, 육체 보너스. 각인 9단계는 아이나르의 [웅크리기]와 연계된다.
  - 아이기스의 장벽(넘버스 No.3): 방패 바바리안의 졸업 방패. 가볍고, 합일·거대화 때 방어 범위가 넓어진다. 영혼연결 적용으로 파괴 불가, 경험치를 먹여 성능 5%씩 강화.
  - 크라울의 악마 분쇄기(No.87, 망치): 휘두르기 위력 500% 증가.
  - 공성 살육자(No.687, 교체용 무기): 근력 40% 상승.
- 파티 시너지: 거대화와 야성분출로 위협을 끌어 모으고 폭풍의 눈으로 적을 모아 딜러가 치게 한다. 에르웬과 넘버스 아이템 "신뢰"를 나눠 써서 딜과 안정성을 함께 올린다. 아이나르의 [웅크리기]와 불사자 각인 9단계가 연계된다. 미샤의 높은 행운이 비요른의 나쁜 운을 메운다.

## 미샤 칼스타인
- 역할/전투 스타일: 근접 딜러("빙결 쌍수 검사"). 냉기로 적을 얼린 뒤 몰아치는 스타일. 수인족.
- 무기·공격 형태: 초반에는 단검, 비요른의 권유로 쌍검으로 바꿈. 베기·찌르기에 냉기와 독 부가 피해.
- 정수 목록:
  - 홉 고블린(7등급)
    - 독성부여 [A]: 무기에 독을 입힌다.
  - 예티(7등급, 이후 지하 1층 합성 몬스터 정수로 바뀐 것으로 추정됨)
    - 냉기응축 [A]: 냉기 감응도를 크게 올린다(푸른 입자가 보임).
    - 오한 [P]: 모든 공격에 냉기 피해를 더하고 적의 냉기 내성을 낮춘다. 상시.
  - 비톨(7등급)
    - 강화 [A]: 입힌 상처 주변을 얼려 재생을 막는다.
  - 라이칸스로프-수호자(7등급)
    - 설원의 피 [P]: 냉기 감응도 1.5배.
    - 얼음분쇄 [A]: 동상이나 빙결 상태인 적에게 주는 피해 증가. 조건: 대상이 동상/빙결 상태.
    - 불굴 [A]: 행동 불가 상태를 풀어낸다. 영혼력 소모가 큼. 조건: 행동 불가 상태일 때.
  - 이름 미공개(5등급)
    - 돌연변이 [A]: 민첩을 일시적으로 근력으로 바꾼다.
  - 그 밖에 "빙하의 혼"과 은신 능력을 주는 정수를 가졌다는 언급만 있음. 효과는 문서에 없음.
- 기타 고유 능력/특성/장비:
  - 영혼수 "빙하마수 스카디아"(강화계, 스탯 보너스 최대)
    - 빙하의 축복(1차 각성) [P]: 냉기 스킬과 냉기 아이템의 자원 소모 50% 감소.
    - 절대영도(2차 각성) [P]: 첫 타격이 무조건 대상을 빙결시킨다. 조건: 전투 첫 타격.
  - 서리혼령 가락지(No.9425): 정수 1개를 봉인하는 대신 수인 특수 능력을 강제로 각성시킨다.
  - 독사의 송곳니(No.5991): 관통력 보너스, 중독 피해 2배.
  - 가르파스의 목걸이(No.7777): 정신을 지탱해 주며 사용 횟수를 다 쓰면 반환된다.
- 파티 시너지: 절대영도로 첫 타에 빙결을 걸고 얼음분쇄로 추가 피해를 넣는 냉기 연계. 불굴로 스스로 CC를 풀어 딜을 이어간다. 비요른이 전위에서 어그로를 잡는 동안 옆에서 딜을 넣는 1팀 근접딜 1번 자리.

## 히쿠로드 무라드
- 역할/전투 스타일: 탱커(역할군 "수호자", LV.4). 장비만 갖추면 4층 이상에서도 통한다는 평가.
- 무기·공격 형태: 망치(타격)와 작은 버클러 방패. 전격 속성 공격.
- 정수 목록:
  - 일라트렉(7등급)
    - 전격 [A]: 몸 일부에서 강한 전류를 일으킨다.
  - 아이안트로(7등급)
    - 균형추 [P]: 넉백 면역, 충격 흡수. 상시.
  - 리빙아머(8등급)
    - 긴급복원 [A]: 장비를 5분 전 상태로 되돌린다. 방패가 자주 부서져도 금방 복구한다.
  - 이름 미공개
    - 방출 [A]: 다른 이능의 기운을 몸 밖으로 뿜어낸다.
- 기타 고유 능력/특성/장비:
  - 전격 + 방출 콤보: 전류를 구체 형태로 날린다(원거리 공격으로 확장).
  - 수호자의 팔목 보호대(넘버스 No.3112, 1층 핏빛성채에서 획득).
- 파티 시너지: 문서에 구체적 전투 시너지 정보 없음. 노아르크 전쟁 때 아브만과 함께 스벤 파라브를 구출했다는 서사만 있음.

## 리올 워브 드왈키
- 역할/전투 스타일: 지원형 마법사(왕가 공인 8급 마법사). 생활·행정 마법이 전문이고 저주와 냉기 마법으로 전투를 돕는다.
- 무기·공격 형태: 마법 지팡이. 저주 계열 디버프와 냉기 마법.
- 정수 목록: 문서에 정수 정보 없음.
- 보유 마법(개별 효과는 문서에 적혀 있지 않음):

    - [패시브] 혼돈회로: 모든 자원이 하나의 게이지로 합쳐진다. 자원을 전부 쓰고 나면 1분 동안 자원이 소모되지 않는다.
    - [액티브] 융합: 패시브 스킬만 대상으로 하는 변환 능력이다. 패시브를 조합해 새 능력을 만든다.

    - [패시브] 속성강화: 사대속성 피해가 모두 오른다.

    - [패시브] 절대집중: 캐스팅 스킬의 피해가 2배가 된다.
    - [액티브] 집중사격: 차징(캐스팅) 시간이 길수록 소모량과 피해가 함께 커진다.

    - [패시브] 먹이사슬: 자신의 레벨에 비례해 몬스터에게 주는 피해가 늘어난다.
    - [액티브] 파열: 일정 피해 이상을 넣으면 내성을 무시하는 고정 피해를 준다.
  - 늑대 괴수 칼반(5등급)
    - [패시브] 절반의 축복: 도핑형 버프가 반복해서 걸린다.
  - 멧크로우(4등급)
    - [패시브] 추격자의 눈: 시각 관련 스탯이 3배가 되고 원거리 보정을 받는다.
  - 출처 정수가 적혀 있지 않은 스킬
    - [액티브] 고속연사: 하늘에서 쏟아지는 화살비('하늘비')를 쏜다.
  - 합성 몬스터 정수: 문서에 상세 설명이 없다.

  - 탐색꾼 능력
    - 소리에 매우 민감하고 야간시력이 좋다.
    - 인도자 재능 없이도 감각만으로 5층 포탈을 찾아낸다.

  - 탐색과 척후를 맡는다.

- 파티 시너지: 스킬 봉인 환경에 강한 스탯형 탱커 겸 딜러. 체력이 낮을수록 단단해지는 역전형 패시브를 참고할 수 있음.

# 클랜·탐사단 인물 (분류 페이지 추가분 2)

## 벨레그 슈시아 디 테르시아
- 소속·역할/전투 스타일: 아나바다 클랜. 역할군은 궁수(탐색꾼 성격)지만 활을 직접 쓰지 않고, 소환수를 부려 싸우는 소환 지원형. 전투력은 2~3등급 수준으로 평가됨.
- 무기·공격 형태: 무기 명시 없음. 소환수가 공격함. 맨손(무기 미장착) 상태가 핵심.
- 정수 목록: 정수 이름 미공개([???])
  - 기술 전수 [액티브]: 자신이 가진 '활 계열' 정수 능력을 소환수에게 공유함.
  - 성군 [패시브]: 무기를 장착하지 않았을 때 소환수 공격력이 2배가 됨.
  - 영혼의 나팔 [액티브]: 소환수 여럿이 같은 대상을 때리면 추가 피해가 들어감(집중 공격 보너스).
- 기타 고유 능력/특성/장비 효과:
  - 특기는 추적과 탐지.
  - 인도자 능력: 파티를 미궁 안에서 인도할 수 있음. 5층까지는 무난하고, 6층은 섬 종류에 따라 다르며, 7층부터는 한계가 있음.
- 파티 시너지: 정찰·추적·길 안내 담당. 본인 무장을 포기하는 대가로 소환수 딜을 끌어올리는 구조("무기 미장착 → 소환수 강화", "다수 소환수 일점사 → 추가 피해"). 활 정수를 소환수에게 넘겨주는 식으로 버프를 전달하는 설계의 참고 사례.
- 출처: https://namu.wiki/w/벨레그%20슈시아%20디%20테르시아

## 아우옌 록로브
- 소속·역할/전투 스타일: 아나바다 클랜, 7레벨. 항해사(비전투직)로 "싸우는 것 빼고는 다 잘한다"는 평가를 받음. 전투력은 오크 이하로 추정되며 호신용 스킬 하나만 가짐.
- 무기·공격 형태: 무기 명시 없음. 호신기 '파쇄'는 원거리 즉발 공격이며, 근접에서 쓰면 위력이 커짐.
- 정수 목록:
  - 벨라리오스 (3등급, 노란색) — 스탯 보너스: 항마력 +200, 모든 속성 감응도 +30
    - 순환의 고리 [패시브]: 반경 안에서 3등급 이상 마물이 죽으면 일정 확률로 스탯이 오름.
    - 파쇄 [액티브]: 회피할 수 없는 즉발형 원거리 공격. 근접해서 쓰면 위력이 올라감.
  - 정수명 미확인
    - 순풍 [액티브]: 선박 이동속도 증가(요약 과정에서 50%로 언급됨), 배에 탄 모든 캐릭터의 영혼력이 빠르게 회복됨.
  - 정수명 미확인
    - 무역로 [액티브]: 키를 고정하고 있는 동안 타고 있는 선박의 이동속도가 300% 증가.
  - 유령섬 관련 정수 (유령섬 주변에서 얻음)
    - 유령선 [액티브]: 효과 설명 없음.
  - 지하 1층에서 얻은 정수
    - 비행선 [액티브]: 배를 하늘로 날게 함. 시전자가 쓴 공격 스킬을 탄환으로 바꾸고 위력을 1000% 올림.
- 기타 고유 능력/특성/장비 효과:
  - 알론소의 여행가방 (No.1001, 넘버스 아이템): 마물이 느끼는 위협 수치 감소. 반경 안에서 마물이 죽으면 마석을 추가로 얻음.
  - 뮐 아르민도 극찬한 항해술. 마부 경험, 요리, 정비 기술이 있음. 배멀미에 강함.
- 파티 시너지: 이동·보급을 맡는 유틸리티 담당. 탈것(배)에 탄 파티 전원에게 영혼력 회복을 주고, 동료의 공격 스킬을 선박 포격(탄환)으로 증폭함. 전투 중 파티가 3등급 이상 마물을 잡으면 성장하고, 전리품(마석)이 늘어남. 비전투원이 파티를 강화하는 슬롯의 참고 사례.
