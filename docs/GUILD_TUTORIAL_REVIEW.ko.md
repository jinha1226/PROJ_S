## 발견 사항

1. **P1 — 1층 전리품 획득 후 심층에서 귀환하면 귀환 의뢰 미완료.**
   `sim/guild_tutorial_rules.gd::_progress`는 귀환 분기보다 먼저 `floor_index != 1`이면 건너뛴다.
   같은 원정의 1층 전리품 기록을 확보했더라도 마지막 층이 2 이상이면 인정하지 않는다.
   귀환은 현재 층 필터가 아니라 원정별 1층 전리품 확보 이력으로 판정해야 한다.

2. **P2 — 시작 물건 재줍기로 전리품 목표 우회.**
   `item.picked_up`라는 이벤트 종류만 확인하고 아이템 생성 출처를 확인하지 않는다.
   시작 물약을 버리고 다시 주운 기록으로 전리품 의뢰가 완료된다. 귀환 의뢰의 전리품 기록에도 같은 문제가 있다.

3. **P2 — 원정 상태가 없는 기록도 1층으로 간주.**
   수락 직후 `floor_index=1`, `expedition_index=0`에서 시작하고 출발 여부를 요구하지 않는다.
   출발 기록이 없는 이동 세 건으로 이동 의뢰가 완료되는 것을 규칙 단위에서 재현했다.
   이는 판정 계층의 결함이며 실제 마을 UI에서 동일 이동 기록을 생성하는지는 이번 검사에서 재현하지 않았다.

4. **미완성 — 던전 내 선택 의뢰 진행 안내.**
   게시판은 마을에서만 조회 가능하고, 개발서의 1층 HUD 한 줄 진행/완료 안내 연결은 확인되지 않았다.

5. **성능 위험 — 전체 기록 재탐색.**
   `state`가 전체 기록을 읽고 수락된 의뢰마다 `_progress`가 다시 전체 기록을 읽는다.
   개발서의 추가 이벤트 인덱스는 없다. 현재 최대 다섯 의뢰이므로 지수적 연산은 아니지만 긴 기록에서 UI 비용이 늘어난다. 지연 수치는 측정하지 않았다.
